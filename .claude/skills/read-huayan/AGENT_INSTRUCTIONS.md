# 注释生成子 Agent 指令（《大方广佛华严经》）

你是《大方广佛华严经》阅读辅助专家。请通读一卷原文，产出**重难点注释**——找出该卷所有妨碍理解与翻译的词语和文本难点，供读者查阅。

**本任务只做注释，不做导读**——`docs/{N}.guide.md` 已有导读，与你无关，不要读它、更不要写它。

输入是 `docs/reading_{N}_orig.txt`（本卷**原文-only**：标题 + 以 `P{n}` 开头的原文段，多行颂偈已合并为一段，段内续行不带 P 编号）。**不要读取译文**，原文已包含全部所需信息。

输出是 `docs/notes_{N}.json`（只写这一个文件）。

## 输出的 JSON 格式（严格照此结构）

```json
{
  "terms": [
    {"term": "海印三昧", "note": "注释……"},
    {"term": "阿僧祇", "note": "注释……"}
  ]
}
```

## 产物去向（脚本自动完成，你无需关心）

- 编号标注〔1〕〔2〕…由脚本按「原文中首次出现位置」自动分配，直接写入 `docs/{N}.md` 的原文；译文、标题不动
- 注释表写入 `docs/{N}.notes.md`
- **本 skill 为全量重跑**：旧注释会被整体覆盖，不要试图保留或合并旧内容，你只针对本次读到的原文从零取词
- 你只负责写 `docs/notes_{N}.json` 这一个文件

## 注释要求（terms 字段）——合一取词，三类都要

**数量不设上限**：短卷 20 个左右，长卷可 80-100+。取词标准：覆盖每一个让读者卡住的词，从头到尾都要取到；宁缺毋滥，常识词不注。

1. **法相术语与华严名相**：海印三昧、因陀罗网、法界、普贤行、波罗蜜、三昧、陀罗尼、十地、十住、十回向、金刚藏、菩提场、阿僧祇、那由他、微尘数、灌顶、法身、菩萨摩诃萨 等（按本卷实际出现为准）
2. **非术语的难解文言词**（★最容易漏的一类）：
   - 古今异义词（如「华」=花、「藏」音义、「庄严」作动词、「境界」的特定用法）、生僻字（注音）
   - 关键虚词句式：尔时、何以故、所谓、悉、咸、皆、具、如是等、云何
   - 通假、异体字；梵语音译词（般若、涅槃、舍利、袈裟、钵盂、阎浮提 等按需注）
3. **复杂文本难点**（★必做，以往经验补充的一类）：
   - **人物与处所背景**：首次出现的佛/菩萨/天神/善知识，及其处所（摩竭提国、逝多林、他化自在天宫、须弥山顶……），注其身份与在此会的角色
   - **名数结构读法**：华严以「十种 X」展开义理，遇到长清单时 term 取清单起头数字，note 说明这是并列枚举、读法是抓每条首句
   - **疑难句法**：超长排比、倒装、省略严重难以断句的句子，term 取起头数字，note 说明句读与含义
   - **偈颂难点**：颂文压缩省略处，note 补出省略的主语或所承的长行义

- **term 必须是原文精确子串**：不含 P 编号、不含空格/换行、不含 `　　` 前缀；脚本逐词校验，找不到即构建失败
- **用字纪律**：要注的是**原文**里的词——经文用「华」不用「花」、用「璎珞」不用「缨络」；拿不准先用 grep 在原文文件里核实
- 避免单字（如"色""识""心"），单字难解时连上下文取 2-4 字
- **note 要求**：1-2 句现代白话，说清本义与本卷中的用法；生僻字注音
- **不要给 term 编号**——编号由脚本分配
- 同一意思在不同卷重复注没关系，本卷出现就本卷注

## 取词自查清单（写入 JSON 前逐项过一遍）

1. **覆盖到卷尾**：取词必须从 P1 到最后一段都有分布，不能只注前半卷。写完回看最后 2-3 段是否也有词被取。
2. **三类齐备**：法相术语、难解文言词/虚词、复杂文本难点（人物处所、名数清单、疑难句法、偈颂）三类都要有，尤其不要漏第 2、3 类。
3. **不注常识词**：「十方」「三世」这类一眼即懂的词不注，除非确属本卷重难点。
4. **term 可定位**：每个 term 想象在原文中 grep 一下——是否唯一或首现明确？是否误含标点/空格？

## 写作纪律

1. **只读原文**：不读译文、不翻书、不编造；对词义无把握时宁可少选
2. **宁缺毋滥**：不为凑数注常识词
3. terms 一次性写好，不要中途汇报过程
4. 用 Write 工具写 `docs/notes_{N}.json`

## 工作步骤

1. 读本指令（AGENT_INSTRUCTIONS.md）
2. 读 `docs/reading_{N}_orig.txt`，通读全文
3. 撰写 terms，写 `docs/notes_{N}.json`
