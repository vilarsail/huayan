# 大方广佛华严经卷第二十三 导读

## 一、内容总览

本卷对应唐译《大方广佛华严经》卷第二十三，含两个品目：前为「兜率宫中偈赞品第二十四」，后为「十回向品第二十五之一」。前品承夜摩天宫之后，如来升兜率天宫，十方各有一大菩萨（金刚幢、坚固幢、勇猛幢、光明幢、智幢、宝幢、精进幢、离垢幢、星宿幢、法幢）与万佛刹微尘数眷属俱来集会，世尊从两膝轮放光普照十方，十菩萨一一承佛神力说颂偈赞佛，共说一百零六颂，从「佛不出世不涅槃、以愿力示现」到「佛身非心行处、离言绝相」，层层开显法身与色身、出世与涅槃、一与多的无碍关系。后品为「十回向品」之开端，金刚幢菩萨承佛神力入「菩萨智光三昧」，十方同名金刚幢诸佛现前加持、与智、摩顶，从定起宣说菩萨十种回向之名，并广释第一「救护一切众生离众生相回向」之行相、大愿与空观，最后以颂偈收摄。全卷以「偈赞法身无碍 → 入定加持 → 开演回向」一线贯之，是从「十行」转入「十回向」的关键枢纽，亦是由「解」到「行」、由「行」到「愿」的递进。

## 二、结构层次（★重点）

- **十方菩萨来集 → 世尊两膝放光**：十方各一大菩萨与万佛刹微尘数眷属，从妙宝、妙乐等十世界来，所事佛为无尽幢等十佛，名号悉同、平等无差别；菩萨化身作宝藏狮子座，随方结跏趺坐，身放百千亿那由他阿僧祇清净光明 → 显示主伴齐现、法界平等。世尊从两膝轮放百千亿那由他光明普照十方尽法界虚空界，彼此互见神变，明菩萨与毗卢遮那往昔同根、得无差别法界之身 → 由「众集」引出「放光加被」。
- **十菩萨偈赞佛德（理）**：金刚幢至法幢十菩萨，一一承佛神力普观十方说颂，义理递进：
  - 金刚幢：如来不出世不涅槃，以本愿示现；色声非佛亦不离色声；少智不知佛境，久修乃了；欲成无上觉应以净妙心修菩提行。
  - 坚固幢：佛出过言语道如虚空；导师为开演甚深法现此身；欲为诸法本应起胜希望。
  - 勇猛幢：以「明净眼因日睹色」「精进力尽海源底」「良田出生佛法」「伽陀药消毒」等譬喻，明净心、智力、善知识之功用；又明佛身非色相、寂然不动而普现，如虚空不生灭。
  - 光明幢：一佛身普现一切佛；菩提无二法无诸相而现相庄严；法身清净随应化现；佛身非变化非非化；法界无差别无所依止而示现无量身。
  - 智幢：身不在处不住法；如来所示现身不可数；以「净满月普现一切水，本月未曾二」喻佛身无二；佛身非过去非未来，一念现成道与涅槃。
  - 宝幢：佛身无量能现有量身、无处所充满一切处如空；以「翳眼所睹非内外」喻世间见佛；如来出世间而实无兴世；以「净日轮不与昏夜合」喻三世劫不与如来合而说三世佛。
  - 精进幢：诸佛身同义亦然普随应现；佛身不在内外神力显现；以「随意珠满众生愿」喻佛法满一切愿；随愿力普应十方。
  - 离垢幢：如来大智光普净世间；以佛为境界专念不息得见佛；佛身世间一切无我，悟此成正觉；导师无来去无所住远离颠倒。
  - 星宿幢：如来无所住普住一切刹；诸佛不思议；一切法皆如，了达法性者无佛无世界；佛体不可得彼亦无所见；正觉超语言假以语言说。
  - 法幢：宁可恒受世间苦不远如来；一闻佛名决定成菩提；一念发道心必成无上尊；未知真实法不名供养；虽经无量苦不舍菩提行；众生无始流转，不了真实法故诸佛兴世；诸法不可坏亦无能坏者。
  - 收束：十菩萨偈义层层递进，由「佛不出世不涅槃」到「法性空寂无生灭」到「闻法发心必成佛」，以「理」收摄，为「十回向」奠基。
- **入定加持 → 开演十回向（行 + 愿）**：金刚幢菩萨承佛神力入「菩萨智光三昧」，十方各十万佛刹微尘数诸佛皆同号金刚幢现前，广说加持因缘（为令菩萨得清净无畏、无碍辩才、入普门法界等）并劝演说；诸佛与无量智慧、无碍辩、分别句义善方便等，复以右手摩顶；菩萨从定起告众，先列十回向总名（救护众生离众生相、不坏、等一切佛、至一切处、无尽功德藏、入一切平等善根、等随顺众生、真如相、无缚无著解脱、入法界无量），三世诸佛已说当说今说 → 由「理」转入「行愿」。
- **广释第一回向（救护众生离众生相回向）**：此菩萨行六波罗蜜及慈悲喜舍，以善根回向，发愿为众生作舍、护、归、趣、安、明、炬、灯、导师、大导师；于非亲友守护回向与亲友等无差别，入一切法平等性故不生一念非亲想；以大海、日天子等譬喻，明菩萨不为一生、不为净一刹、不为信一佛，而普为救护一切众生、普净一切刹；复观众生造恶受苦不见三宝，发愿代受地狱等苦、以身为质救赎恶道众生；明世间五欲之乐无非是苦、众魔境界，菩萨不为己乐求无上菩提；复以善根回向令众生得究竟乐等十种乐，作调御师、主兵臣、大智炬、善巧船师；末以「日轮但一无二」喻菩萨独修善根普摄众生，广明「不取相、不分别、不着因缘、以法界印印善根」等空观回向 → 行相 + 大愿 + 空观三段具足。
- **颂偈收摄**：金刚幢菩萨观察十方入深句义，以无量心修习胜行，复说二十九颂，重宣第一回向之义：从「不思议劫修行道」到「三世如来所付嘱，住于无上大法城」，以「菩萨如是修回向，功德方便不可说，能令十方世界中，一切诸佛皆称叹」收束。

## 三、关键结论

- 如来不出世亦无涅槃，以本大愿力示现自在法——佛之出世与涅槃皆为度生之方便示现，法身本无来去生灭。
- 佛身非心所行处、出过言语道、清净如虚空——见佛不在色身音声，亦不离色声，须以智慧到彼岸乃见诸佛境。
- 十方菩萨、世界、佛名号悉同等无差别——显示法界平等、主伴不二，一切佛法同一法身。
- 菩萨救护一切众生而离众生相——回向之心普缘一切众生，又不著众生相、业报相、因缘相，以法界印印诸善根，是名真实回向。
- 菩萨宁独受众苦不令众生堕地狱，以身为质救赎恶道——大悲代苦、自他平等，是第一回向之极致。
- 世间五欲之乐无非是苦、众魔境界——菩萨不为五欲乐修菩提行，但为安乐一切众生发心修习。

## 四、易混辨析

- **十住 vs 十行 vs 十回向**：十住（卷十六前后）重在「心住于理」，是菩萨初安住于佛法；十行（卷十九至二十一）重在「起行度生」，于住理之上发起利他之行；十回向（本品起）重在「回自向他、回事向理」，将所修善根回向一切众生与无上菩提，是「行」之升进与「愿」之圆满。本品金刚幢菩萨即十回向主，承同名诸佛加持入智光三昧而说。
- **救护一切众生 vs 离众生相**：前者是「回向之所为」——普缘一切众生令得解脱、究竟一切智；后者是「回向之所观」——虽度众生而不著众生相、不取业报相、不分别因缘。二者不即不离：救护是事，离相是理，事理无碍方名真实回向。
- **法身 vs 色身**：法身是佛所证真如理体，无形无相、清净如虚空、离言绝虑；色身是佛为度生所示现的相好身，有量而能现无量、无处而充满一切处。偈赞品十菩萨反复明「色身非是佛亦不离色声」「法身清净随应化现」，即法身与色身不二。
- **智光三昧 vs 善思惟三昧**：善思惟三昧是十行品功德林菩萨所入之定（卷十九），于善法如实思择发起十行；智光三昧是十回向品金刚幢菩萨所入之定，以智慧光明照了法界、成就回向，是从「行」升入「回向」之定。二菩萨同名「幢」，皆承十方同名诸佛加持而说法，名号互为呼应。
- **回向 vs 发愿**：发愿是立誓希求未来果（如「愿成无上菩提」「愿度一切众生」）；回向是将已修善根转向特定目标（众生与菩提），含「回自向他、回事向理、回因向果」三义。本品明菩萨以六度善根回向众生与菩提，是「已修善根之愿」。

## 五、阅读提示

读本卷可带着两个问题：一是十菩萨偈赞如何层层开显「佛身无碍、法性空寂」之理，为后品「回向」奠基？二是金刚幢菩萨广释第一回向时，「救护众生」与「离众生相」如何并行不悖——菩萨既发愿代众生受苦、以身为质，又不著众生相、业报相、因缘相？把握此「事理无碍」一线，即可贯通全卷。
