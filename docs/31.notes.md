# 大方广佛华严经卷第三十一 词语注释

① 十回向　《华严经·十回向品》所说菩萨十种回向位（救度众生、不坏、等一切佛、至一切处、无尽功德藏、随顺平等善根、随顺等观一切众生、真如相、无著无缚解脱、法界无量）。本卷为第九。
② 菩萨摩诃萨　「摩诃萨」意为「大有情」「大心众生」，指发大心、修大行、堪入大乘的菩萨。本卷中菩萨摩诃萨是修无著无缚解脱回向的修持主体。
③ 无著无缚解脱回向　十回向中第九回向之名。以不执着（无著）、不被系缚（无缚）、心得自在（解脱）之心，将所修善根回向众生与菩提，为本卷主题。
④ 善根　能生善法、长养菩提的根本，如信、戒、施、精进、礼敬、随喜等。本卷开篇即说菩萨于一切善根「心生尊重」，以此善根作回向。
⑤ 尊重　于法生殷重敬顺之心，不轻慢、不下劣。本卷云菩萨于出生死、悔过业、礼敬诸佛等一切善根「皆生尊重，随顺忍可」。
⑥ 塔庙　安置佛舍利的建筑，梵音「窣堵波」。本卷云「顶礼塔庙，心生尊重」「分布其身起塔庙」，皆表对佛的恭敬与供养。
⑦ 随顺忍可　随顺即依从不违，忍可即印可、信受。谓于一切善根法门深生信解、决无违逆，为修回向的心理前提。
⑧ 陀罗尼门　陀罗尼意为「总持」，即忆持佛法不令散失的法门。本卷列「无碍音声陀罗尼门」「见一切佛陀罗尼门」「解了一切音声陀罗尼门」「一切劫住陀罗尼门」等。
⑨ 十方　东、南、西、北、东南、西南、东北、西北、上、下十方。本卷中「普遍十方」「普现十方一切世界」显示普贤行愿周遍一切处。
⑩ 不可说不可说　佛经中极大的数量词，表示难以言说的劫数、众生数、世界数。本卷反复出现，极言普贤行愿所历时长、所度众生之广。
⑪ 十力智　佛的十种智慧力（处非处、业、定、根、欲、性、至处道、宿命、天眼、漏尽）。本卷「念念中令不可说众生住十力智」即令众生安住佛智。
⑫ 普贤行　普贤菩萨所修的广大行愿，即尽未来际、遍法界修菩萨行而不休息。本卷数十处「修普贤行」「成普贤行」即指此。
⑬ 法界　一切法所依的真理总体，亦即诸法本源。本卷「尽虚空遍法界」「入无边法界心」「知一切法界无所得」等，皆显示回向心量周遍法界。
⑭ 调伏　调和制伏众生烦恼，令其离恶修善。本卷「教化调伏一切众生」「调伏想」「如来调伏一切众生而无所碍」皆指此。
⑮ 普贤回向　以普贤大愿为体的回向，把所修善根普皆回向一切众生与无上菩提。本卷云「成满普贤回向行愿」「入普贤回向，行方便地」。
⑯ 金刚界　喻智慧坚固不可坏如金刚。本卷「了知一切佛法金刚界根」「如来不思议自在力如金刚菩提心」皆喻坚利不坏之智。
⑰ 佛刹　一佛所教化的国土，即一佛所住的清净或染净世界。本卷「一身遍满一切佛刹」「普摄一切佛刹置于一处」显示一多相容。
⑱ 二乘　声闻乘与缘觉乘，唯求自了生死，不及菩萨大行。本卷云「永不发起二乘之心」，显示回向心唯趣大乘菩提。
⑲ 想倒　颠倒妄想之一，于境起虚妄分别。本卷「舍离一切想倒、心倒、见倒」即以无著无缚心破三颠倒。
⑳ 心倒　心念颠倒，于无常计常、苦计乐等。与想倒、见倒并称三倒，回向时一并舍离。
㉑ 见倒　知见颠倒，如身见、边见等恶见。本卷与想倒、心倒同列，为无著无缚所破。
㉒ 因陀罗网　帝释天宫中的网，网目皆缀宝珠，珠珠相映、重重交光。华严宗借以喻法界重重无尽、事事相即。本卷云「以因陀罗网分别方便普分别一切法界」。
㉓ 普贤菩萨　华严经中以大行愿著称的菩萨，表「法门」与「行愿」的极致。本卷所修一切「普贤身语意业」「普贤行愿」「普贤回向」皆以普贤境界为归。
㉔ 灌顶　古印度立太子时以四海水灌顶的仪式，佛教借喻菩萨入一生补处位、将得佛果。本卷「得佛灌顶，于一念中入方便地」即菩萨受佛智职之位。
㉕ 三昧　梵语 samādhi，意为「正定」，心专一缘、不散乱。本卷广列「菩萨无量三昧相」「甚深三昧」「法界三昧」「大庄严三昧」等。
㉖ 甚微细　极其微细、难可测知的境界。本卷特倡「甚微细智」一门，菩萨于一念中如实了知色、身、刹、劫、众生、法界等一切极微细境，即华严「微细相容安立门」。
㉗ 一生补处　菩萨修至尽此一生即补佛位的阶位，如弥勒现居兜率天。本卷以「菩萨一生补处甚微细」列于菩萨行门之中。
㉘ 兜率天　欲界第四天，一生补处菩萨下生人间前的住处。本卷「菩萨生兜率天甚微细」「一切世界兜率中，自然觉悟人师子」即指如来降生前住兜率。
㉙ 魔军　障碍修行的魔众。本卷颂云「遍满三千大千界，一切魔军兴斗诤」「震动一切魔宫殿」，即菩萨成道时降伏魔军之事。
㉚ 师子吼　佛说法无畏如狮子吼，百兽慑伏。喻佛说法能伏外道、破魔军、安众生。本卷「师子游行七步」「大师子吼出妙音」皆指如来。
㉛ 善巧方便　善巧即巧妙契合根机，方便即随宜施设的方法。菩萨以善巧方便度生、说法、示现，本卷反复称之。
㉜ 阿僧祇劫　无数劫，表极长时劫。本卷诸劫甚微细智中以阿僧祇劫与一劫互相摄入，显示时间相即无碍。
㉝ 阿僧祇　梵语 asaṃkhyeya，意为「无数」，是佛教极大的数量单位。本卷「以阿僧祇劫入一劫」「以一劫入阿僧祇劫」显示劫数长短相即。
㉞ 萨婆若　梵语 sarvajña，意为「一切智」，即佛智。本卷云「分别诸法萨婆若智」，指佛地总持一切法的智慧。
㉟ 等正觉　「平等正觉」之略，即佛所证无上正等正觉。本卷「不分别若菩萨行、若等正觉」显示行与果平等无二。
㊱ 僧祇　「阿僧祇」之略，无数之意。本卷「僧祇」即指无量劫数，与阿僧祇劫同义。
㊲ 菩提萨埵　梵语 bodhisattva 的音译，意译「觉有情」，即菩萨。本卷「不分别若菩提、若菩提萨埵」即不分别菩提与菩萨。
㊳ 施物　布施所施之物（财、法等）。本卷回向时不分别「若施物、若受施者」，显示施者、施物、受者三轮皆不可得。
㊴ 受施者　接受布施的一方。本卷「不分别若施物、若受施者」即回向时不执能施、所施物与受者，三轮体空。
㊵ 金刚轮围山　即铁围山，环绕一世界的外围，极坚不可坏。本卷结叹云「一切金刚轮围山所不能坏」，喻菩萨回向心坚固不可动摇。
㊶ 金刚幢菩萨　说《十回向品》的本尊菩萨，名「金刚幢」，表其德坚高如幢、不可倾动。本卷长行与颂偈皆由其承佛神力宣说。
㊷ 含识　含有情识的众生，即一切有情。本卷颂云「悉为利益诸含识」，即利益一切众生。
㊸ 人师子　佛的尊称。师子（狮子）为百兽之王，佛于人中最尊，故喻为人中师子。本卷颂偈中屡称「人师子」「人中师子」「师子吼」。
㊹ 般涅槃　梵语 parinirvāṇa，意为「圆寂」，即佛入灭、究竟寂灭。本卷颂「乃至最后般涅槃，分布其身起塔庙」指如来八相之末。
㊺ 世间灯　佛的尊称之一，以佛智慧光照世间如灯破暗。本卷颂云「常见一切世间灯」，即常见一切诸佛。
