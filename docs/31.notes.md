# 大方广佛华严经卷第三十一 词语注释

〔1〕 于阗国　古西域城邦国（今新疆和田一带），大乘佛典的重要传译之地。
〔2〕 三藏　对精通经、律、论三藏之法师的尊称，置于译人名前。
〔3〕 实叉难陀　梵名 Śikṣānanda，意译学喜，于阗高僧，唐时应召来华主译八十卷《华严经》。
〔4〕 十回向品　《华严经》第二十五品，说菩萨十种回向之行；「第二十五之九」谓本卷是此品的第九分，内容为第九回向。
〔5〕 菩萨摩诃萨　菩萨的尊称全称，摩诃萨意为大有情，指求佛道、度众生的大菩萨。
〔6〕 无著无缚解脱回向　本卷所说的第九回向。著即执着，缚即系缚；以不执着、不被系缚的解脱之心，将一切善根回向众生与佛道。
〔7〕 所谓　经中提领列举的固定用语，义为「即是下面所说的」。
〔8〕 塔庙　塔即窣堵波（stūpa），安置佛舍利的建筑。偈颂「分布其身起塔庙」谓佛灭后分身舍利起塔供养。
〔9〕 随顺忍可　忍可即认可、印可而安住于心。谓对种种善根随顺信受、心无违逆。
〔10〕 陀罗尼门　陀罗尼（dhāraṇī）意译总持，能持善法不失、令法义不忘之力；门谓由此法门而入。
〔11〕 见一切佛陀罗尼门　当断句为「见一切佛·陀罗尼门」——恒见十方一切佛的总持法门，不要误读为「佛陀·罗尼门」。
〔12〕 十力　佛所独具的十种智力，如知是处非处、知业报、知诸根、知宿命、漏尽智等。
〔13〕 普贤行　普贤菩萨所代表的广大行愿——遍入一切世界、修一切菩萨行而无所障碍；本卷反复以「成就普贤自在力」「成普贤行」贯穿全篇。
〔14〕 一切智地　佛地。一切智谓遍知一切法总相别相，地谓所到之位。
〔15〕 法界　一切法的总体、真如实相之境；华严以此为本宗所观所证之境。
〔16〕 无量方便　自此至「说一切法无余方便」是一张并列清单，列举种种方便法门；读时抓每条末尾「方便」前的中心词即可。
〔17〕 法轮　以轮喻佛法：辗转相传、摧破烦恼，故说法称转法轮。
〔18〕 智印　以智慧为印信，楷定诸法实相、决断无疑，故云智印普照。
〔19〕 聪利根　自此至「清净无碍根」列举菩萨所得种种「根」（能生善法的根机之力，如信根、慧根）；并列清单，抓每条首句。
〔20〕 不退转记　记即授记，佛预记菩萨当来成佛；不退转记谓授以永不退转之记别。
〔21〕 金刚界　坚固不可破坏如金刚的佛境界；此句谓得能了知一切佛法金刚界的根。
〔22〕 无量广大力神力　自此至「大智慧门神力」是并列的神力清单，每条以「神力」收尾；读时抓每条首句。
〔23〕 二乘　声闻乘与缘觉乘，重在自了生死而不普度众生，与大乘菩萨道相对。
〔24〕 生如来家　证得真如法性、入于佛家而为佛真子，喻如生在如来家中。
〔25〕 毛端　毛发之末端，极言其小。「一毛端量处包容一切国土」是华严显示大小互摄无碍的常喻。
〔26〕 尔许　如许、这么多。「现一切众生尔许劫念心」谓现出与一切众生相应那么多劫的心念。
〔27〕 想倒　与「心倒」「见倒」连称三种颠倒：于无常等法妄计常乐我净，分别起于想、心、见三层。
〔28〕 仰世界　偈颂作「仰覆别」。世界形状各异：仰谓仰置如盂，覆谓倒覆覆合，与「十方网」等并列形容世界形类无量。
〔29〕 十方网　以网喻十方世界交罗互摄、重重无尽，故云不可说十方网一切处广大世界。
〔30〕 因陀罗网　帝释天宫所悬的宝珠网，一珠现一切珠影，重重无尽；华严借喻法界万法互相映摄、一多相即。
〔31〕 灌顶　本为印度太子即位时以海水灌顶之礼；菩萨将成佛时，诸佛以智慧水灌其顶、授法王位，故云「得佛灌顶」。
〔32〕 众生想　自此至「如是等想」是「想」的长清单（众生想、法想、刹想、方想……），谓菩萨悉能了知而离于一切想；读时抓每条首二字。
〔33〕 三昧　梵语 samādhi 音译，意译正定、正受，心住一境、湛然不散。
〔34〕 种性　谓成佛的种子族类。「具三世诸佛种性」谓与三世诸佛同一种性。
〔35〕 靡不　靡（mǐ），无、没有谁。靡不即无不、全都。
〔36〕 欲解　欲乐与胜解，谓众生的意向偏好与信解取向；偈颂作「欲乐」。
〔37〕 甚微细　本卷高频句式。「某事甚微细（智）」谓其相极微细难知，而菩萨于一念中悉能如实了知；长清单读每条首句即可。
〔38〕 一缘　心专缘一境而不散乱。「其心一缘」与下文寂定、分别、安住并举。
〔39〕 攀缘　心如猿猴攀附外境而生念，即心驰求于境、执取不舍。
〔40〕 离翳　翳（yì），蔽目之眼病，喻无明障蔽。离翳三昧谓离一切障蔽的三昧。
〔41〕 一生补处　补处谓补佛位处。一生补处即再经一生必定成佛的菩萨，如兜率天的弥勒。
〔42〕 兜率天　梵语 Tuṣita 音译，欲界第四天。菩萨成佛前居此天说法，然后下生人间；偈云「兜率中，自然觉悟人师子」即指此。
〔43〕 坐道场　谓佛坐菩提树下证觉成道，故成佛亦称坐道场、坐菩提座。
〔44〕 魔军　魔王及其眷属军众。佛成道前降魔军成正觉；偈颂「魔军兴斗诤」同此。
〔45〕 阿耨多罗三藐三菩提　梵语 anuttarā-samyak-saṃbodhi 音译，意译无上正等正觉，即佛所证之觉悟。
〔46〕 师子吼　佛说法定无疑惧、能慑伏众生，喻如狮子吼百兽潜踪；偈中「大师子吼」「人师子」同此喻。
〔47〕 涅槃　梵语 nirvāṇa 音译，意译灭度、圆寂，谓烦恼生死之火永灭。「师子吼大涅槃」谓佛最后入灭的示现；「般涅槃」之般是入义。
〔48〕 护念　佛以神力护持、忆念修行人，令其安隐不退；「诸佛之所护念」是经中常语。
〔49〕 金刚幢　本品说法主菩萨之名。幢为庄严具，喻功德高显；「金刚幢回向之门」即本品所说之回向法门。
〔50〕 非心地　心地谓心识所行之境；非心谓无心识之法。「尽知一切心、非心地境界之藏」谓有心、无心一切境界尽能了知。
〔51〕 戏论　无益于解脱的虚妄言说与分别；「异道戏论」指外道邪见之论。
〔52〕 萨婆若　梵语 sarvajña 音译，意译一切智，佛所成就的遍知之智。
〔53〕 如影智　自此连举如影、如梦、如幻、如响、如化、如空等智，谓了知一切法如影像梦幻、无有实体。
〔54〕 菩提萨埵　梵语 bodhisattva 音译全称，即菩萨，意译觉有情。
〔55〕 等正觉　梵语 saṃyak-saṃbuddha，遍正觉者，指佛；「不分别若菩萨行、若等正觉」谓能行与所证不作分别。
〔56〕 金刚轮围山　轮围山即环绕世界的铁围山；金刚轮围山极言其坚固不坏，以喻此回向不可动摇。
〔57〕 在在　处处、无论何处。「在在生处」谓无论受生于哪一处。
〔58〕 值遇　值，逢也。值遇即遇到、碰上。
〔59〕 尔时　那时。经中承前启后的固定衔接语，此处引出金刚幢菩萨说偈。
〔60〕 含识　具有心识的一切有情，众生的异名。
〔61〕 人尊　人中最尊贵者，指佛。
〔62〕 人师子　佛的譬喻称号，谓人中狮子、说法无所畏。偈中「人中师子」「人中尊导」「人中主」皆指佛。
〔63〕 降神　佛示现八相成道之一：自兜率天降下，神识入于母胎。
〔64〕 无暂已　已，止息。无暂已谓没有片刻停止。
〔65〕 帝释　忉利天主；同句「梵王」为色界初禅大梵天王。佛初生时诸天皆恭敬瞻侍。
〔66〕 瞻侍　瞻仰侍奉。
〔67〕 遐迩　遐（xiá）远、迩（ěr）近。「无始无末无遐迩」谓佛的示现无始无终、无远无近。
〔68〕 沈欲海　沈，同「沉」。谓众生沉没于贪欲之海。
〔69〕 三有　欲有、色有、无色有，即三界生死。
〔70〕 应然　然，同「燃」。「应然明净智慧灯」谓应点燃明净的智慧灯。
〔71〕 愚痴闇　闇，同「暗」。无明愚痴如黑暗覆障，故应以智慧灯照破。
〔72〕 六趣　天、人、阿修罗、畜生、饿鬼、地狱六种轮回去处。
〔73〕 咸　皆、全都。「六趣众生咸离苦」谓六道众生全都离苦。
〔74〕 三千大千界　一佛所化的世界范围：由小世界千倍、百万倍、十亿倍层层集成的大千世界。
〔75〕 采女　帝王宫中的侍女。偈谓佛示现受生王宫时采女围绕。
〔76〕 世间灯　佛的譬喻，如灯照破世间黑暗；偈中「无等尊」「导师」等亦皆佛之代称。
