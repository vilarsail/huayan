# 大方广佛华严经卷第三十四 导读

## 一、内容总览

本卷是《大方广佛华严经·十地品第二十六》的开篇，位居全经最核心的大品之首。此卷承接前文普贤行愿的总持，正式进入「菩萨修行阶位」的系统性叙述——所谓「十地」，即菩萨从初发心到成佛之间所历的十个果位阶次。本卷由金刚藏菩萨承佛神力宣说，佛陀仅以眉间放光、诸佛现身加持的方式幕后护持，全卷主轴是「宣名—默然—三请三辞—放光—说初地」，最终在第一地「欢喜地」处详尽展开，为后续九地铺设骨架。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷按「**序分→请分→三请三默→佛光加持→正宗分（初地）**」五段推进，是典型的「请—默—请」递进结构：

- **序分（境众庄严）**：他化自在天王宫摩尼宝藏殿 → 金刚藏等诸藏名号菩萨众集 → 显示此法唯在欲界顶层天说，非凡夫境。
- **入定加被**：金刚藏菩萨承佛神力入「菩萨大智慧光明三昧」 → 十方诸佛现身同名金刚藏 → 与身、与辩、与智、与念、与慧、与力等十种加持 → 伸右手摩顶 → 显此法须佛力方堪说。
- **宣名默然（核心张力）**：金刚藏菩萨出定，宣说「欢喜、离垢、发光、焰慧、难胜、现前、远行、不动、善慧、法云」十地名已 → 默然不复解释 → 大众生渴仰。
- **三请三默（层层逼问）**：
  - 一请：解脱月菩萨颂问「何故说地名而不解释？」 → 金刚藏颂答「微细难可见，离念超心地…世间无能受，默然而不说」。
  - 二请：解脱月再陈大众已净、能证甚深 → 金刚藏答「有其余劣解众生…闻此生疑堕恶道，我愍是等故不说」。
  - 三请：解脱月举「字母为本」喻，明十地是一切佛法根本，得佛护念必生信受 → 诸菩萨众同声颂请 → 世尊眉间放光、十方诸佛同放光明，光中出颂劝请。
- **正宗分（初地详说）**：金刚藏菩萨观察十方，先以颂明「地行难说难受，如空中鸟迹」 → 正说第一欢喜地：
  - **起信发心**：菩萨以大悲为首、智慧增上，发求佛智之心 → 超凡夫地、入菩萨位、生如来家。
  - **多欢喜**：成就多欢喜、多净信等十种欢喜 → 永离不活、恶名、死、恶道、大众威德五怖畏。
  - **净治地法**：信、惭、敬、施、戒等二十种心行 → 安住欢喜地。
  - **十大愿**：供养诸佛、受持正法、佛兴示现、菩萨行、众生界、世界、净土、同行、不退轮、一毛端成佛——每愿皆「广大如法界，究竟如虚空，尽未来际」。
  - **十尽句**：以众生界尽等十尽为愿尽之缘，而众生界不可尽故愿亦无尽。
  - **大悲与大舍**：观众生十二因缘苦聚 → 生大悲大慈 → 财施、法施乃至头目髓脑身分皆舍。
  - **十种净诸地法**：信、悲、慈、舍、无疲厌、知经论、世智、惭愧、供养、依教修行。
  - **金师炼金喻**：善根回向一切智地，数数入火转转明净。
  - **商主问道喻**：菩萨住初地已知诸地障对治乃至转入如来地，将众生过生死旷野至萨婆若城。
  - **果报作用**：多作阎浮提王，舍家出家得一念百三昧、见百佛、动百世界等百类自在。

## 三、关键结论

1. **十地是三世诸佛共由之道**：过去、未来、现在诸佛已说、当说、今说，无佛国土不说此十地——它是菩萨向菩提的「最上道」与「清净法光明门」。
2. **此法难说难受**：地智微细难见、离念超心地、如空中鸟迹、如空中风相，故须佛力加持方堪宣说、方堪信受；劣解众生闻之生疑反堕恶道，故金刚藏三默。
3. **初地断证**：才发菩提心即超凡夫地、入菩萨位、生如来家、永离五怖畏、得不动相应；以大悲为首、檀波罗蜜增上，为十波罗蜜之始。
4. **大愿无尽**：菩萨大愿以「十尽句」为缘，而众生界、法界等十界皆不可尽，故愿亦无有穷尽——这是华严「愿与法界等」的根本义。
5. **一地即摄十地**：住初地者已知诸地障对治、成坏、相果、得修、清净、转行、处非处、殊胜智、不退转乃至转入如来地，菩萨商主喻即明此意。

## 四、易混辨析

- **金刚藏菩萨 vs 解脱月菩萨**：金刚藏是此会主说者，承佛力入大三昧、宣十地、三默后受请而说；解脱月是请法者，代表大众三度启请，二人构成「主答—启请」对扬。
- **他化自在天 vs 兜率天**：此会说法处是「他化自在天王宫」（欲界第六天，他化所成，表法高超），非兜率（第四天，补处菩萨所居）；经中「兜率天宫没」是讲佛下生八相之一，非此会所在地。
- **十地次第 vs 十地各别**：本卷详说第一「欢喜地」，仅列二至十地名相；十地是有先后阶次的因果位，每地各有入、住、出、相、果、修法，非平列分类。
- **阿僧祇 vs 那由他 vs 微尘数**：阿僧祇意为「无数」，是印度大数单位之首；那由他更大；「佛刹微尘数」是将一佛刹磨为微尘而计数，喻极多——本卷中三者皆用作数量级。

## 五、阅读提示

读本卷可先抓「三请三默」的戏剧张力：为何金刚藏明知大众欲闻却反复沉默？——因「地智」非言辞所及、非凡念所及。带着此疑读至世尊眉间放光、诸佛同声劝请，便能体会此法之难遇；再读初地详说时，注意「大悲为首、智慧增上、善巧方便所摄」三句是十地共同的心要骨架，初地如此，后九地亦然。
