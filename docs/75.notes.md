# 大方广佛华严经卷第七十五 词语注释

① 善财童子　《华严经·入法界品》核心人物，童子身，历参五十三位善知识求菩萨行；本卷为其中一参，参瞿波女。
② 阿耨多罗三藐三菩提　梵语 anuttarā samyaksaṃbodhi 音译，意为「无上正等正觉」，即佛所证之究竟觉果。善财每参皆先自陈「已发此心」。
③ 三业　身、语、意三业。「清净庄严无上三业」指佛三业究竟清净。
④ 十力　佛所独具之十种智力（处非处、业、根、欲、界、至处、宿命、天眼、漏尽等），如来独得。
⑤ 三昧　梵语 samādhi 音译，意为「定」「等持」，心专一境不散乱。本卷屡言「菩萨三昧海」「念念所入三昧海」，指菩萨所证种种深定。
⑥ 善知识　梵语 kalyāṇamitra，引导众生舍恶修善、趣向佛道之良师。本卷强调「亲近善知识」为菩萨行之根本，列「十种法承事善知识」。
⑦ 菩萨摩诃萨　梵语 bodhisattva mahāsattva，意为「大菩萨」，指已发大心、修大行、入大位的菩萨，区别于初发心菩萨。
⑧ 三恶趣　即地狱、饿鬼、畜生三恶道，众生造恶业所感之苦处。
⑨ 想倒　于无常计常、苦计乐等之颠倒想，与「见倒」「心倒」合称三倒。
⑩ 随眠　梵语 anuśaya，微细潜伏之烦恼种子，随逐众生眠伏于心，为烦恼之根。
⑪ 释氏女　即释迦族之女，指瞿波。本卷言善财「推求彼释氏女」。
⑫ 师子之座　佛菩萨所坐之座，以师子喻威神无畏；「师子座」表说法无畏、降伏邪妄。
⑬ 采女　宫中侍女、宫女。本卷屡言太子、王者「采女围绕」「五百采女」「八万四千采女」。
⑭ 波罗蜜　梵语 pāramitā 音译，意为「到彼岸」「度」，指菩萨所修六度（檀、戒、忍、精进、禅、般若）等究竟之行。
⑮ 瞿波　梵语 Gopā，释种女，为释迦太子之妃，本卷善知识。亦称「释迦瞿波」。
⑯ 辟支佛　即独觉、缘觉，无师自悟之圣者，果位同阿罗汉而智胜。
⑰ 因陀罗网　即帝释天宫之网，网珠交映、重重无尽，喻法界事事无碍、一多相入。本卷标「因陀罗网普智光明菩萨之行」为总法门。
⑱ 胜解　梵语 adhimukti，于所缘境深信印可、不动摇之胜智。本卷言「得广大胜解」「胜解广大如虚空」。
⑲ 解脱门　入解脱之门户，指依某法门修习而得自在解脱。瞿波所证为「观察一切菩萨三昧海解脱门」。
⑳ 佛刹　梵语 buddhakṣetra，一佛所教化之国土。「佛刹微尘数」喻数量极多，如微尘之不可数。
㉑ 微尘数　以粉碎物质至极微所得之量，喻极多、不可计数；「佛刹微尘数劫」即极长远之时间量。
㉒ 独觉　梵语 pratyekabuddha，亦译辟支佛，无佛之世自观十二因缘而悟道者，属二乘之一。
㉓ 世界种　华藏世界海中之世界集群单位，由无量世界层层相累而成，如「普现三世影摩尼王」世界种。
㉔ 毗卢遮那　梵语 Vairocana，光明遍照义，即华严教主法身佛。本卷言「毗卢遮那世尊此华藏世界海」为本愿所成。
㉕ 华藏世界海　即「莲华藏世界海」，毗卢遮那如来历劫修行所严净之广大世界海，含十方无量世界种，每一世界种含无量世界。
㉖ 檀波罗蜜　梵语 dāna-pāramitā，布施度，六度之首，分财施、法施、无畏施。本卷太子誓「尽未来际行檀波罗蜜，舍内外物」。
㉗ 四天下　即须弥山四方四大洲：东胜身、南赡部（阎浮）、西牛货（瞿耶尼）、北俱卢（郁单越），一王所统即一四天下。
㉘ 阎浮提　即南阎浮提，须弥山南之大洲，即吾人所居之人间世界。
㉙ 伊尼耶鹿王　伊尼耶（eniya）鹿王，喻太子腨（小腿）圆满如鹿王之腨，三十二相之一。
㉚ 梵音　佛菩萨之音声，清净深远如梵天之声，具六十种殊胜。「出梵音声」「声如梵音」。
㉛ 尼拘陀树　梵语 nyagrodha，榕树类，枝叶繁茂覆广，佛经常喻身形洪满。
㉜ 转轮王　梵语 cakravartin，以正法治世之圣王，具七宝（轮、象、马、珠、女、藏臣、主兵），王四天下或一洲。本卷威德主太子继位为转轮王王阎浮提。
㉝ 乾闼婆　梵语 gandharva，八部众之一，寻香神、天乐神。
㉞ 迦楼罗　梵语 garuḍa，八部众之一，金翅鸟，以龙为食。
㉟ 紧那罗　梵语 kiṃnara，八部众之一，人非人，歌神。
㊱ 摩睺罗伽　梵语 mahoraga，八部众之一，大蟒神、地龙之类。本卷列天龙八部集会。
㊲ 色究竟天　梵语 akaniṣṭha，色界最顶天，色界十八天之极顶，五净居天之一。
㊳ 修多罗　梵语 sūtra 音译，意为「契经」「线」，指佛所说之经教。本卷「普眼灯门修多罗」。
㊴ 灌顶　梵语 abhiṣeka，古印度王太子继位时以四海水灌顶，佛教借用为菩萨受佛智水、登地或成佛之仪式。
㊵ 陀罗尼　梵语 dhāraṇī 音译，意为「总持」「能持能遮」，以少文摄多义、令善法不散、恶法不起。本卷佛说「一切法义离闇灯陀罗尼」。
㊶ 那由他　梵语 nayuta 音译，极大数名，或云十万、百万、亿等，泛指极多。本卷言「六十万那由他人」得解脱。
㊷ 七宝　转轮王所具之七宝：轮、象、马、珠、女、藏臣、主兵，表王之德化。
㊸ 支提　梵语 caitya，意译为塔、庙、灵庙，供奉佛舍利于处。本卷「一一僧坊立佛支提」。
㊹ 那罗延　梵语 nārāyaṇa，天上力士名，喻坚固勇猛之力。本卷言「金刚那罗延精进」。
㊺ 摩耶　梵语 Māyā，释迦牟尼之生母，本卷末瞿波指善财往参之下一位善知识，即佛母摩耶夫人。
