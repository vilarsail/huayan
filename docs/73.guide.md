# 大方广佛华严经卷第七十三 导读

## 一、内容总览
本卷为《入法界品》第三十九之十四，善财童子五十三参中的第三十八参——大愿精进力救护一切众生夜神。善财在夜神处得「教化众生令生善根解脱门」，夜神并为他说出自己久远劫前以太子身救度罪人、蒙佛授记的本生因缘，卷末指向下一参：岚毗尼园林神妙德圆满。

## 二、结构层次（文章骨架与逻辑推进）
- **见身起敬 → 生十种心 → 得同行**：善财见夜神坐普现一切宫殿摩尼王藏师子座、现二十余种色身 → 一心顶礼，对善知识生十种心 → 又得佛刹微尘数「同行」（同念、同慧……同出离共八十四种）。
- **偈赞发问**：善财以偈赞叹，问三事：解脱门名为何？发心已来几时？何时当成佛？
- **说法正答（法门名）**：夜神宣说「教化众生令生善根」解脱门，列举九十余种色身名目——了知法性无别而恒现无量色相，令众生随乐调伏、舍恶住善；再以一一身、一一相、一一光层层展开成佛度生的连锁。
- **譬喻答「发心久如」（智轮群喻）**：智轮离分别（不可用劫数长短计量）→ 日轮无昼夜 → 日影现于净水而日实不来 → 船师度人不依两岸不住中流 → 虚空持刹无成坏分别 → 如幻化人无生死十事——层层说明菩萨智轮超越三世时间相，无众生可度而以大悲大愿现前教化。
- **本生正答**：善光劫宝光世界，法轮音虚空灯王佛世，胜光王造狱禁闭众生，太子善伏入狱慰问、以身代罪，触怒朝臣几遭处死，王后求得半月布施之期，佛率众来临大会说《普照因轮》，太子即证此解脱门 → 揭示太子即夜神前身、所救罪人即拘留孙等贤劫千佛、欲害太子的五百大臣即提婆达多等徒党、胜光王即萨遮尼乾子 → 复述五百岁出家得百万陀罗尼、次第受生供养诸佛（善光劫一万佛、日光劫六十亿佛）→ 结偈重颂。
- **谦己指路**：唯知此门，彼诸菩萨功德无量 → 指授岚毗尼园林神妙德圆满 → 善财礼辞而去。

## 三、关键结论
- 菩萨智轮超越时间：发心久远不可用劫数计量，「言其止住前劫后劫」只是随顺众生心念的方便说法。
- 大悲救苦是证入解脱的直接因缘：太子因舍身救狱囚而得「教化众生令生善根解脱门」，下卷岚毗尼林神亦以「生如来家」相承。
- 怨害者终当成佛：欲害太子的五百大臣即提婆达多等五百徒党，蒙佛教化后亦当作佛——示佛性平等、恶人可度。

## 四、易混辨析
- **本卷夜神与下卷岚毗尼林神**：本卷大愿精进力夜神主「教化众生令生善根」，下卷妙德圆满主「生如来家」，一为化他之始，一为入佛家之阶。
- **智轮与日轮**：日轮是譬喻，智轮是菩萨的根本智慧；日轮尚有出没昼夜，智轮连出没与三世也无，只是「随心现」。
- **《普照因轮》与「教化众生令生善根」**：前者是本生中佛所说的经名，后者是夜神（前身太子）所证的法门名，二者同起于一场法会。

## 五、阅读提示
读本卷可带着一问：为何救几个死囚的太子能得如此深法？答案在譬喻群中——太子自言「我若不救此众生者，云何能救三界牢狱诸苦众生」，救一狱囚即救三界，大悲即是大行。
