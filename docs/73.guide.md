# 大方广佛华严经卷第七十三 导读

## 一、内容总览

本卷为《入法界品第三十九》之十四，承前善财童子参访大愿精进力救护一切众生夜神之后，进而参访开敷一切树华夜神，是善财五十三参的后续环节。本卷主旨为：开敷一切树华夜神自述所证「菩萨出生广大喜光明解脱门」，以夜神度生日用之妙用为引，进而追述毗卢遮那如来往昔行菩萨道时之本生——一切法音圆满盖王于五浊恶世兴大悲心、行大布施、摄化众生之事，以此说明菩萨因地修行与果地威德的相承关系，最终引出善财再往大愿精进力救护一切众生夜神处参请，构成参访链的环扣。

## 二、结构层次（★重点）

全文按「能入之人 → 所证之法 → 法之展开（本生故事） → 重颂结归 → 指归下参」一线推进，层层展开：

- **善财请法 → 夜神自陈所证**（P3-P12）：善财顶礼请问菩萨行、一切智；夜神先述日用度生之相（日没之时密护众生还归正道、对治五欲、对机说六度十波罗蜜），继而自言已成就「菩萨出生广大喜光明解脱门」。
- **释解脱门境界 → 普摄众生巧方便智**（P12-P16）：问答展开「云何普摄」，说明一切众生所受诸乐皆如来威德所成；进而追念毗卢遮那往昔为菩萨时，见众生苦而起大悲、发二十种心、现大神变普雨资具，念念成熟众生、严净佛刹、遍入法界三世。
- **明发心久近 → 重颂显深**（P17-P21）：善财问「发心久如」，夜神先叹此法难知难入、唯佛境量，继以长颂广明：非染恼凡夫、非着有众生所能知，唯亲近善知识、心净如虚空、具大慈悲者方能证入。
- **本生故事：一切法音圆满盖王**（P22-P40）：远溯古劫普光明真金摩尼山世界海中，一切法音圆满盖王于五浊起时，见众生苦，发十种大悲语、击鼓普施、开库藏尽舍内外一切；长者女宝光明以偈赞王本生德业（父净光、母莲华光、王于莲华化生、降伏恶趣、广演法音），王授女宝衣，并记别往昔因缘——王即今毗卢遮那，父即净饭王，母即摩耶夫人，女即夜神本身，所摄众生即今此会菩萨。
- **重颂结归 → 指向下参**（P41-P45）：夜神再以颂自述广大眼、清净耳、他心智、宿命智等于一念中了知刹海微尘劫诸佛菩萨众生，自谦唯知此一解脱门，复指善财往诣大愿精进力救护一切众生夜神，问教化众生、严净佛刹、承事如来、修行佛法。善财礼辞而去。\n
全文骨架：**请法 → 自证 → 普摄 → 发心久远 → 本生故事（王施、女赞、授记） → 重颂 → 下参**，由现量（夜神今所证）溯至因量（毗卢遮那往昔行），由因量再溯至本生（一切法音圆满盖王之事），层层回溯、果因相映。

## 三、关键结论

1. **众生所受诸乐，皆是如来威德力故**：一切众生之乐，溯其本源皆依佛智日光所照、性净业力所摄，非自他有，这是「普摄众生巧方便智」的理据。
2. **大悲起行、尽舍内外**：一切法音圆满盖王于五浊恶世见众生苦，发十种大悲语，施一切资生乃至头目髓脑、妻子王位——华严布施波罗蜜的极致标本。
3. **念念成熟、念念严净**：菩萨修行非一劫一事，而是于念念中成熟众生、严净佛刹、遍入法界三世、现一切佛成等正觉，体现华严「一念含三世」的圆融观。
4. **因位即果位、果位即因位**：本生中之一切法音圆满盖王即今之毗卢遮那，所摄众生即今之菩萨——因地所摄众生于果地皆得不退，显示因果同时、能所不二。
5. **善知识难遇、功德难知**：夜神重颂广明「非贪恚痴憍慢所覆者能知佛境界」，唯亲近善知识、心净无分别者方能证入，凸显参访善知识在华严修行中的根本地位。

## 四、易混辨析

- **开敷一切树华夜神 vs 大愿精进力救护一切众生夜神**：前者为本卷主答善财者，所证「出生广大喜光明解脱门」，自述为往昔宝光童女；后者为本卷所指下一参之善知识，亦是前卷善财已参者，二者同为夜神，各有所证、互相指授，构成参访链环扣。
- **毗卢遮那如来 vs 一切法音圆满盖王**：前者为今之果地佛身（法身/报身之通称，此经中即释迦牟尼之法身），后者为往昔本生之王身——同一人因位与果位之不同名，记别中明言「尔时一切法音圆满盖王者，今毗卢遮那如来是」。
- **五浊 vs 五欲**：五浊（劫浊、见浊、烦恼浊、众生浊、命浊）指劫末浊世之总相，本卷述为「寿命短促、资财乏少、形色鄙陋、多苦少乐、不修十善」等；五欲指色声香味触之贪染，P8「盛年好色，憍慢放逸，五欲自恣」即此。二者一为时世共业，一为个体烦恼。
- **波罗蜜 vs 愿波罗蜜、力波罗蜜、智波罗蜜**：本卷于六度外特举后四波罗蜜（方便、愿、力、智）中之三种，对治乐小乘者、福智微劣者、心闇昧者——华严十波罗蜜之后四度，皆就菩萨利他大行立名，非声闻乘所有。

## 五、阅读提示

读本卷宜扣「因行—果德—度生」三线：先看夜神今所证（果），再循其忆念往昔（因），最后归宿于本生故事中王之大施与女之赞叹（行），体会华严「一修一切修、一成一切成」的圆顿义。颂偈部分（P21、P38、P42）为长行之重颂，宜对照长行读，可助记其要。
