# 大方广佛华严经卷第十五 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第十五，属「贤首品第十二之二」，承接上卷文殊师利菩萨答智首菩萨之问、由贤首菩萨以偈颂广答。全卷为贤首菩萨一人长篇偈颂，主题是「菩萨三昧与光明不可思议」：先以「安乐三昧」总起，广说菩萨放种种光明、利益众生、成就佛果之行；次说「方网三昧」于根尘、身份、器界间出入自在；最后以日、月、水、海、龙王、帝释、天鼓、修罗、幻师等世间譬喻，显菩萨神通自在远胜彼等，劝信此法。卷末记说偈已，十方震动、诸佛摩顶赞叹作结。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷为单一偈颂长行，无散文衔接，但内部分明可辨四大推进层次：

- **总起三昧光明（境用）**：以「有胜三昧名安乐」开篇 → 历举菩萨所放一切光明之名与用（善现、照耀、济度、灭爱、欢喜、爱乐、福聚、具智、慧灯、法自在、能舍、除热、忍严、勇猛、寂静、慧严、佛慧、无畏、安隐、见佛、乐法、妙音、施甘露、最胜、宝严、香严、杂庄严、严洁、大云、严具、上味、大财，及眼耳鼻舌身意色声香味触法清净光等）→ 每一光皆「觉悟一类众生 → 令行一行 → 成就此光明」三段成例，构成排比推进。
- **三昧体相收束（毛孔与三昧力）**：以「如是等比光明门，如恒河沙无限数，悉从大仙毛孔出」收束 → 显一一光皆从菩萨毛孔出、皆大仙三昧力与智自在 → 以「生盲不见日」喻明有福德者见、邪信凡愚不见。
- **方网三昧（自在出入）**：转说「有胜三昧名方网」 → 于东方入定西方出、西方入东方出 → 推及十方普遍 → 再于眼色、耳声、鼻香、舌味、身触、意法六根六尘间出入自在 → 又于童子、壮年、老年、善男善女、比丘、辟支佛、如来、诸天、龙、夜叉、鬼神、一毛孔、一切毛孔、一微尘、金刚地、摩尼树、佛光明、河海、火、风、地、天宫、虚空中辗转出入，结「三昧自在难思议，十方一切诸如来，于无量劫说不尽」。
- **譬喻显德（他劣显胜）**：连用「声闻八解脱现神变」「日月影像」「水中四兵」「海神善音」「辩才妇人」「幻师」「修罗战败匿」「帝释象王三十三头六牙七池七华七天女」「修罗蹈金刚际」「帝释千眼金刚」「忉利天鼓」「帝释普应天女」「他化自在六天王」「大梵王」「摩醯首罗」「龙王数滴」「大风起世间」「大海平等印」「龙王兴云降种种庄严雨」等喻 → 每喻皆「彼尚有贪恚痴而能如是，况菩萨具方便智神通」反诘显胜 → 末结此法稀有难信，能信者福德最胜过于承事十方诸佛。

层次推进之过渡靠两类套语：每段光明以「又放光明名……」起、以「是故得成此光明」结；每喻以「彼有贪欲瞋恚痴，犹能……，况……」作反诘收束。全卷由「光明」铺陈至「三昧」、由「三昧」转入「譬喻」、由「譬喻」归于「劝信」，一线到底。

## 三、关键结论

1. 菩萨三昧所放光明无量无边，一一光皆能觉悟一类众生、令行一度生之行，是菩萨利他功用的根本载体。
2. 「方网三昧」体现华严宗「一即一切、一切即一」的圆融观：于根尘、身份、器界、微尘、毛孔之间任运出入，主伴相即、一多无碍。
3. 菩萨神通自在远胜声闻、天、龙、修罗、帝释、梵王等——彼等尚带贪恚痴而能有自在力，菩萨具足慈悲方便智慧，故其自在不可思议。
4. 此法稀有难信：以顶戴三千界一劫、手擎十佛刹一劫、承事十方诸佛一劫作对比，皆不及能信受此品之福，凸显信解之难与功德之大。
5. 全卷以「光明」为修因感果之枢纽：因中修施、戒、忍、进、禅、慧、供养、说法等行，果上即得相应光明与三昧，因果不虚。

## 四、易混辨析

- **三昧 vs 陀罗尼**：三昧（梵语 samādhi）译「正定」，是心一境性的禅定力，本卷特指菩萨所证「方网三昧」「安乐三昧」「日灯三昧」等，重在「定中起用」；陀罗尼（dhāraṇī）译「总持」，是忆持不忘法义之慧力，本卷「令得无尽陀罗尼，悉持一切诸佛法」即此。三昧偏定、陀罗尼偏慧，然菩萨所证二者互摄。
- **六根清净光 vs 六尘清净光**：六根（眼耳鼻舌身意）是能缘之根，六尘（色声香味触法）是所缘之境。本卷分别说「眼清净光令盲者见色」「色清净光令见诸佛色」等，一一根、一一尘各有一种清净光，体现「能所不二、根尘圆融」之意，不可混作一光。
- **那由他 vs 阿僧祇**：二者皆为极大数词。那由他（nayuta）通常表「百亿」「千亿」级，本卷「九十有二那由他天女」即用此；阿僧祇（asaṃkhyeya）译「无央数」表「不可数」，量级更大。本卷多用「那由他」「无央数」「恒河沙」「十刹微尘数」等渐次加大之喻，宜辨其层级。
- **他化自在天 vs 化乐天 vs 兜率陀天**：此三皆欲界上三天（六欲天之上三天）。他化自在天为欲界顶，第六天魔王所居，于他变化之物自在受用；化乐天（第五天）自化五尘而乐；兜率陀天（第四天）知足，补处菩萨所居。本卷龙王兴云一段，逐一列出六欲天云、电、雷、雨之色与物之差别，是辨识六天的好材料。

## 五、阅读提示

本卷偈颂排比极繁，初读勿求尽记每一光名与喻相，宜抓住三组主线：「光明觉悟众生之因果」「方网三昧于根尘身份器界间出入自在」「世间神力喻显菩萨自在」。读到末段「能信此法倍更难」处，回头观照前述光明与三昧皆为劝信之资，方得全卷归趣。
