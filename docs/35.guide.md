# 大方广佛华严经卷第三十五 导读

## 一、内容总览

本卷为《十地品第二十六》之二，承前卷初地（欢喜地）之后，依次宣说菩萨十地中的第二地与第三地。第二地「离垢地」以十种深心为入门，核心在护持十善业道、远离十不善业，并以大悲心观照众生苦聚，由戒行清净而得布施、持戒满足；第三地「发光地」则由观一切有为法苦、无常、不净发起厌离，进求佛智，由勤求佛法、修习四禅八定与慈悲喜舍，发四无量心、得六神通，于法转更明净。两地的展开皆遵循「入地深心 → 核心行相 → 利益众生 → 见佛供养修施戒 → 偏重一度一摄 → 果报与神通 → 颂偈重宣」的固定结构，层层递进。

## 二、结构层次（★重点）

全卷由两地的并列结构组成，每地内部以「请 → 说 → 颂」三段推进，由金刚藏菩萨说、解脱月菩萨请：

- **第二地·离垢地**
  - 众欢喜散华赞叹 → 解脱月请说第二地 →
  - 起十深心（正直、柔软、堪能…广大意）入第二地 →
  - 护持十善业道：身三、口四、意三，一一举出远离相与正面行（不杀乃至不邪见） →
  - 十善与三乘摄属：上品十善修治清净，心狭劣成声闻，自觉悟成独觉，心广大具悲愿成菩萨，一切种净成佛十力 →
  - 十不善业道三品（上中下）与十善各二种人中等流果 →
  - 于一切众生起十种心（利益、安乐、慈、悲…大师心），以大悲代众生拔苦，由戒增慈悲 →
  - 愿力见多佛，布施持戒清净满足，喻如真金置矾石中炼已明净 →
  - 四摄中爱语偏多，十波罗蜜中戒度偏多 →
  - 果报：多作转轮圣王，一念得千三昧、见千佛、动千世界、现千身 →
  - 颂偈重宣（质直柔软十心入二地…）

- **第三地·发光地**
  - 众闻第二地已欢喜散华 → 解脱月请说第三地 →
  - 起十深心（清净、安住、厌舍…广大心）入第三地 →
  - 观一切有为法如实相：无常、苦、不净、败坏、刹那生灭，如幻不实 →
  - 见佛智无量利益，于众生起十种哀愍心，发「应救、应脱、应净、应度」大愿 →
  - 思惟度生方便：无碍解脱智 ← 如实觉 ← 无生慧光 ← 禅善巧观察 ← 善巧多闻 → 勤求正法，为闻法能舍内外财、投身火坑 →
  - 修四禅、四无色定，行慈悲喜舍四无量心 →
  - 得六神通：神足、天耳、他心智、宿命、天眼、于诸禅三昧入出自在 →
  - 愿力见多佛，闻法修行，邪贪瞋痴除断，善根转明净，喻如真金炼治不减 →
  - 四摄中利行偏多，十度中忍波罗蜜偏多 →
  - 果报：多作三十三天王，一念得百千三昧、见百千佛、动百千世界 →
  - 颂偈重宣（清净安住明盛心…）

两地的内层逻辑同为：**入地心 → 戒定根本 → 悲智双运 → 见佛修施 → 偏重一度 → 果报神通**，由戒净、定明、慧光渐次增上。

## 三、关键结论

1. 第二地以「离垢」立名，根本在十善业道：身离杀盗淫、口离妄语两舌恶口绮语、意离贪瞋邪见，由十善净治通出三乘——心狭劣成声闻，自觉成独觉，悲愿广大成菩萨，一切种净成佛果。
2. 十不善业各有三品（上中下）对应地狱、畜生、饿鬼；纵生人中亦各有二种等流果（如杀生得短命多病、偷盗得贫穷共财不自在等），因果丝毫不爽。
3. 第三地「发光」之要在「观有为法如实相」起厌离、见佛智无量起悲愍，由厌离与悲愍双驱而勤求正法，乃至为一句未闻法能入大火坑、受阿鼻苦而不退。
4. 度生方便之因果链为：欲度众生 ← 无障碍解脱智 ← 一切法如实觉 ← 无行无生慧光 ← 禅善巧观察智 ← 善巧多闻，故「多闻」为菩萨行之本。
5. 第三地以四禅八定为依，发四无量心与六神通，然不随禅力受生，唯以愿力满菩提分，显示菩萨「行而无所乐着」的中道。

## 四、易混辨析

- **离垢地 vs 发光地**：第二地离十不善垢，重在戒净与十善业道，偏重持戒度、爱语摄；第三地由戒净发定慧之光，重在观有为起厌离、勤求正法、发禅定神通，偏重忍度、利行摄。前者「戒」为体，后者「定慧」为体。
- **十善业道 vs 十善戒**：本卷所说「十善业道」即身三（不杀、不盗、不邪淫）、口四（不妄语、不两舌、不恶口、不绮语）、意三（不贪、不瞋、不邪见），为一切世出世间善法根本，由心行广大不同而通三乘乃至成佛，非仅人天戒。
- **声闻乘 vs 独觉乘 vs 菩萨乘**：同修上品十善，差别在「心」与「悲」——声闻心狭劣、怖三界、阙大悲、从他闻声而解，故成声闻；独觉不从他教、自觉悟而大悲方便不具足，悟因缘法，故成独觉；菩萨心广无量、具悲愍、发大愿、不舍众生、求佛大智，故成菩萨广大行。
- **四禅 vs 四无色定**：四禅（初至第四禅）属色界，次第由「离生喜乐」至「舍念清净」；四无色定（空无边处、识无边处、无所有处、非有想非无想处）属无色界，次第舍离色等粗想。菩萨修此八定而不随其力受生，唯以愿力满菩提分。
- **四流 vs 四谛**：本卷「欲流、有流、无明流、见流」为四流（亦名四暴流、四轭），系三界烦恼之总名，众生为四流漂没生死；与四谛（苦集灭道）名同实异，勿混。

## 五、阅读提示

读本卷可循两线：一为「十善业道如何通三乘」——留心上品十善由心行差别而分三乘佛果的判摄；二为「菩萨度生方便的因果链」——注意「多闻 → 禅善巧 → 无生慧光 → 如实觉 → 无碍解脱智 → 度生涅槃」的逆推次第，此即《华严》「因陀罗网」式因果在十地中的具体展开。
