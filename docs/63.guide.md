# 大方广佛华严经卷第六十三 导读

## 一、内容总览

本卷为《入法界品第三十九》之四，紧接善财童子南行参访善知识的主线。全文依次记述善财参访三位善知识：**弥伽**（市中说法者，得妙音陀罗尼）、**解脱长者**（住林聚落，入普摄一切佛刹无边旋陀罗尼）、**海幢比丘**（摩利聚落经行侧入三昧，身出无量众生教化法界）。三人各自显示一种「自心即法界」的菩萨行相，由浅入深，层层推展，最后由海幢比丘身中一一毛孔、一一部位出无量身，普雨法雨，充满十方法界，归宗于「唯心」与「般若波罗蜜」。卷末指引善财再往海潮处参优婆夷休舍，五十三参脉络延绵不断。

## 二、结构层次（★重点）

全文按「寻访 → 赞叹 → 得法 → 思惟 → 再寻访」的循环推进，三次参访结构同构而境界递升：

- **弥伽段（市中说法）**：善财至自在城求觅弥伽 → 顶礼请问「菩萨云何学菩萨行」一连串设问 → 弥伽惊而下座，散华供养，称叹发菩提心功德（「则不断一切佛种……」一连「则」字排比） → 出面门光召诸天梵众，为说轮字庄严法门 → 自言唯得妙音陀罗尼，能通三千大千及十方世界一切语言 → 指示南行参解脱长者。

- **解脱长者段（住林入定）**：善财思惟诸菩萨门，游行十二年方至住林 → 见解脱长者，自陈发心因缘（一长串「为欲……」排比） → 长者依佛威神、文殊忆念入「普摄一切佛刹无边旋陀罗尼」三昧 → 身中显现十方各十佛刹微尘数佛及种种行相 → 出定开示：诸佛皆由自心，如梦如幻如响 → 以「应以善法扶助自心……」十句归结「自心」修法 → 指示南行参海幢比丘。

- **海幢比丘段（毛孔说法）**：善财至摩利聚落见海幢结跏趺坐入三昧 → 从足下、两膝、腰间、两胁、胸前卐字、背上、两肩、腹、面门、两目、眉间白毫、额上、头上、顶上各出无量身众（长者居士、刹帝利、仙人、龙、阿修罗、声闻独觉、夜叉、紧那罗、转轮圣王、日轮、帝释、梵天、菩萨、如来） → 一一各随类现身说法、雨宝、照光、转法轮 → 毛孔复出阿僧祇光明网充满法界 → 善财观察七日六夜 → 比丘出定，明三昧名为「普眼舍得」（又名般若波罗蜜境界清净光明） → 自言唯知此一三昧，指示南行参优婆夷休舍。

三段皆以善财「辞退而行」收束，构成五十三参的标准节拍。

## 三、关键结论

1. **发菩提心为成佛根本**：弥伽以「则不断一切佛种」「则严净一切佛刹」一连排比，将发心功德等同于续佛慧命、严净法界，点明善财此行之所为。
2. **一切佛皆由自心**：解脱长者以「如梦、如影像、如水、如幻、如响」五喻显佛与心不二，将外在的他方净土收摄为心内所现，是本卷最精要的法义。
3. **一身普现法界，以般若为体**：海幢比丘从周身各部位出无量身、雨无量法，总名「普眼舍得」「般若波罗蜜境界清净光明」，即般若三昧的神通妙用。
4. **善知识为见一切智之因**：善财于每一善知识处皆「依善知识、事善知识、敬善知识，由善知识见一切智」，并起慈母慈父想，确立参学轨则。
5. **三乘同归一乘，五乘悉皆度脱**：海幢出声闻独觉说二乘法，出转轮圣王修十善，出如来身为十地菩萨雨法雨，统收五乘入于一乘。

## 四、易混辨析

- **善财童子 vs 善男子**：善财是本卷主角，福城出生、受文殊指教南行参访的童子；「善男子」是善知识对善财的通称（弥伽、解脱、海幢均如是唤之），并非另一人。
- **妙音陀罗尼 vs 普摄一切佛刹无边旋陀罗尼 vs 普眼舍得三昧**：分别为弥伽所证（通解十方诸趣语言）、解脱长者所入（身中现十方佛）、海幢比丘所修（般若波罗蜜境界），三者依次由语言、刹土、般若三层面展开，境界逐层增上。
- **佛刹 vs 世界 vs 三千大千世界**：本卷「三千大千世界」指一佛所化之境；「佛刹」泛指一佛净土；「十方各十佛刹微尘数」则以微尘喻其多，解脱长者身中所现即此量级。
- **解脱长者 vs 解脱门**：解脱长者是住林聚落一位在家居士（长者），其名「解脱」；「如来无碍庄严解脱门」是他所证的法门名，二者一名一人，不可混同。

## 五、阅读提示

读本卷可带着两个问题走：第一，三位善知识各自用「身」或「语言」显现什么？弥伽以语言通诸趣，解脱长者以一身现十方佛，海幢以全身各部位出无量身——这条「语言→刹土→全身」的递进正是般若境界的展开。第二，卷中反复说「一切佛皆由自心」，这「自心」是否就是众生当下之心？留意解脱长者「如梦、如影像、如水、如幻、如响」五喻，看其如何避免「真心实有」的执取。
