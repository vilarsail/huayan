# 大方广佛华严经卷第二十四 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第二十四，属「十回向品第二十五」之二，接续卷二十三所述十回向位的展开。由金刚幢菩萨承佛神力宣说，依次阐释十回向中第二至第四位——**不坏回向**、**等一切佛回向**、**至一切处回向**。每一回向皆以「佛子！云何为菩萨摩诃萨……回向」起问，先长行广明菩萨所修善根与回向行相，再以颂偈重颂其义。全卷主线为「于三宝众生起不坏信 → 随顺三世佛所学 → 善根普至一切处」，层层扩展回向的所缘与体性，由「信」而「学」而「遍至」，显示菩萨善根功德广大无碍、三轮体空而不舍饶益众生的根本精神。

## 二、结构层次（★重点）

全卷以「三回向 + 各以长行颂偈相承」为骨架，每一回向内部又有「立信 → 积善 → 回向 → 显益」的递进：

- **第二不坏回向**（P3-P11）
  - 立十种不坏信（佛、菩萨、佛法、佛教、众生、白净法、回向道、法师、佛神通、善巧方便行）→ 总起善根所依
  - 积集善根 → 以阿僧祇供养具供养诸佛与舍利 → 十种回向方便（无执着、无依止、如实法印等）
  - 显益：虽随生死而不改变，知业如幻、业报如像，住无著行 → 颂偈重颂

- **第三等一切佛回向**（P36-P69）
  - 随顺三世佛回向道 → 于色等境不生爱憎得安乐
  - 回向三处：回向诸佛（增胜佛乐）→ 回向菩萨（满愿净心）→ 回向众生（离恶趣生善根）
  - 居家不弃菩提心 → 施畜生一抟食亦发大愿 → 如过去佛修无著回向 → 列十九种回向名（第一、胜、最胜……）
  - 显益：入佛种性，现身世间而心无所著 → 颂偈重颂

- **第四至一切处回向**（P70-P88）
  - 善根愿至一切处 → 譬如实际无处不至（物、世间、众生、国土、法、虚空、三世、有为无为、语言音声）
  - 诸佛普现一切世界 → 法身遍往无差别、如来藏身不生不灭
  - 以无量香盖、摩尼宝盖等供养 → 列十种回向心（不乱、一心、无住、无依……）
  - 十种「普摄」（诸佛、诸法、菩萨众、菩萨行、佛神通、佛力无畏、三昧辩才陀罗尼、善巧方便、三世佛事、十方世界……）
  - 显益：得至一切处身语意业、神足通、总持辩才、入法界、遍入身、普见劫、普见念 → 颂偈重颂

- **贯穿手法**：每段以「佛子」起问、以「是为菩萨摩诃萨第×回向」收束，长行之后接「尔时金刚幢菩萨……即说颂言」重颂，形成「问 → 行 → 益 → 结 → 颂」的固定节律；回向对象由佛 → 菩萨 → 众生递展，所缘由一佛刹 → 一切世界 → 尽法界虚空界层层扩大。

## 三、关键结论

1. 不坏信是回向善根的根基——于佛、法、僧、众生、白净法等十处得不坏信，方能成就不坏回向。
2. 回向的核心是「无所著而回向」——虽修善根功德、虽度众生，而离我想、我所想，以如实法印印诸业门，知业如幻、如像、如化、如响、如影。
3. 等一切佛回向的标志是随顺三世诸佛所学——于色等境不生爱憎，居家不弃菩提心，乃至施畜生一抟食亦发度生大愿。
4. 至一切处回向以「实际无处不至」为喻——善根普至一切处，法身遍往无差别，于一毛孔普入一切世界，于一众生身普入一切众生身。
5. 三种回向皆以「无所得方便」为究竟——不于业中分别报、不于报中分别业，虽无所作而恒住善根，三轮体空而不舍饶益。

## 四、易混辨析

- **不坏回向 vs 等一切佛回向 vs 至一切处回向**：不坏重在「信」之坚固不可坏；等一切佛重在「随顺所学」与三世诸佛同等；至一切处重在「善根所至之处」普周法界。三者由内信 → 效学 → 遍至，体性同是无著回向，所缘逐步扩大。
- **回向 vs 随喜回向**：回向是将己所修善根转向众生与菩提；随喜回向是于自他三世善根随喜后再行回向，本卷「等一切佛回向」中颂偈提及「尽以随喜益众生」，属回向中含随喜义。
- **实际 vs 法界 vs 法性**：实际指诸法究极真际（如虚空无所至而无不至）；法界是理事交彻的所缘境；法性是一切法共同之体性。本卷以「实际无处不至」为喻、以「入法界」为益、以「法性无依处」为所观，义各有别。
- **萨婆若 vs 一切智智 vs 一切种智**：萨婆若（Sarvajña）即一切智，佛果总智；一切种智是知一切道相差别之智；本卷混用，大旨皆指佛果究极之智，回向终归趣向此智。

## 五、阅读提示

读本卷可带着两个问题：菩萨既「无所著」又「不舍众生」，二者如何并行不悖？留意原文中每一回向末尾的「虽……而……」句式（虽随生死而不改变、虽无分别而普入法界、虽无所作而恒住善根），此即「般若真空与悲愿大用」不二的枢纽。
