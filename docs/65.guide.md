# 大方广佛华严经卷第六十五 导读

## 一、内容总览

本卷属〈入法界品第三十九之六〉，承接善财童子南行参访善知识的主线。善财已于前卷陆续参访，本卷连续呈现五参——慈行童女、善见比丘、自在主童子、具足优婆夷、明智居士，是「五十三参」中段集中涌现的一组。五位善知识身份各异：王女、比丘、童子、优婆夷、居士，所修法门亦各别——般若普庄严、随顺灯解脱、工巧神通智、无尽福德藏、随意出生福德藏，共同彰显「一法门中见一切法界」的华严宗要：法界缘起、重重无尽、一多相即。

## 二、结构层次

全卷按善财童子次第参访展开，每一参呈固定结构：到彼 → 觐见 → 自陈已发菩提心请问 → 善知识开示所证法门 → 推荐下一位善知识 → 善财辞退。五参层层推进，结构清晰：

- **总起（P3）** → 善财于善知识所起尊重心，列举「实际、常住际、虚空际」等十种「际」，标举其心境已契法界，为五参设伏笔。
- **第一参·慈行童女（P4-P16）** → 王女居毗卢遮那藏殿说般若波罗蜜普庄严门。
  - 善财入宫 → 见殿中一一壁、一一镜、一一宝皆现法界一切如来本生行相（境即法界）
  → 童女开示此法于三十六恒河沙佛所求得 → 列举百千陀罗尼门（佛刹、众生、三昧、世界成坏等）→ 谦推善见比丘。
- **第二参·善见比丘（P17-P26）** → 三眼国林中经行，相貌圆满、诸天围绕。
  - 自述于三十八恒河沙佛所净修梵行 → 一念中现前十方、世界、众生、诸佛、菩萨行、三昧海等（一念顿摄）
  → 自言唯知「菩萨随顺灯解脱门」→ 谦推自在主童子。
- **第三参·自在主童子（P27-P35）** → 名闻国河渚上，聚沙为戏，十千童子围绕。
  - 述从文殊师利所学书数算印，得工巧神通智法门 → 详列菩萨算法（洛叉、俱胝、阿庾多…乃至不可说不可说转）→ 谦推具足优婆夷。
- **第四参·具足优婆夷（P36-P52）** → 海住城，素服垂发，一万童女围绕，前置一小器。
  - 得「无尽福德藏解脱门」→ 一小器出生无量美味饮食充遍十方 → 声闻独觉食之证果、一生所系菩萨食之成佛 → 谦推明智居士。
- **第五参·明智居士（P53-P70）** → 大兴城市四衢道七宝台上。
  - 得「随意出生福德藏解脱门」→ 仰视虚空，所需从空而下 → 各随所求说法（饥者说福德行、饮者说舍爱着等）→ 谦推法宝髻长者，收束全卷。

## 三、关键结论

1. **善知识法门平等**：王女、比丘、童子、优婆夷、居士皆可作善知识，所证一法即摄法界全貌，呼应「一即一切」的华严要旨。
2. **境即法界**：慈行童女殿中一一宝镜皆现诸佛本生，善见一念顿摄十方，自在主算法算至不可说，具足一小器出无量食——皆示「事相中见法界」。
3. **谦己推贤**：每位善知识自陈「我唯知此一门，云何能知彼功德行」，并指明下一位，构成无尽参访链。
4. **福德与智愿双运**：从般若庄严（智）到福德藏（福），从经行梵行到工巧算法，示菩萨行含摄世间出世间一切事业。

## 四、易混辨析

- **慈行童女 vs 具足优婆夷**：同为女相在家善知识，前者居王宫修般若智门，后者居俗宅修福德藏门，一智一福相对。
- **般若波罗蜜普庄严门 vs 随顺灯解脱门 vs 无尽福德藏解脱门**：三名皆指一善知识所证之主法门，前者重「智周法界」，中者重「一念普照如灯」，后者重「福出无尽」。
- **俱胝、阿庾多、那由他、频婆罗、矜羯罗**：本卷所列菩萨算法的层层递进的大数单位，皆以「倍倍相乘」进位，并非同一数量级；不可混称「极大数」。
- **声闻、独觉、一生所系菩萨**：声闻为闻佛教证四果，独觉自悟证辟支佛，一生所系菩萨为最后身将成佛者——具足优婆夷之食三种人皆得利益，层次递升。

## 五、阅读提示

读本卷可带着一个问题：五位善知识身份、处所、法门各不相同，却都说「我唯知此一门」并谦推下一位——华严借这种结构要说明什么？留意每一参中「境相」（殿、林、河渚、宅、市台）如何即是法界显现。
