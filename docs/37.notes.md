# 大方广佛华严经卷第三十七 词语注释

① 自在天王　第七地菩萨多作之天王，即他化自在天主；于此位以自在力为众生说证智法令其证入。
② 金刚藏菩萨　十地品中由佛力加持而宣说十地法门的主讲菩萨，为十方金刚藏菩萨之一，于此会中受解脱月之请而广说十地行相。
③ 解脱月菩萨　十地品中请法的当机菩萨，于诸地之间次第发问「以何行相入后地」，引导金刚藏菩萨展开下一地之解说。
④ 现前地　十地中第六地之名，谓般若智光、空三昧等如实现前；此地以缘起观、三解脱门为修相，般若波罗蜜偏多。
⑤ 十平等法　入第六地时所观十种平等：一切法无相、无体、无生、无成、本来清净、无戏论、无取舍、寂静、如幻等十相、有无不二。由此随顺无生得入第六地。
⑥ 如幻　十喻之一，常与如梦、如影、如响、如水中月、如镜中像、如焰、如化并列，喻诸法缘生无性、虽有相而无实体。
⑦ 明利随顺忍　第六地所证之忍，谓随顺无生法之智明利而未实证无生，故名「随顺忍」，犹居顺忍位而非无生忍。
⑧ 无生法忍　于无生法实相忍可、决定不退之智；第六地未得，第七地始得「无生法忍光明」，八地以上方圆满。
⑨ 名色　十二支中第四支，识与色（色蕴）名（受想行识四蕴）共生之位，于胎中渐具身心；与识共生四取蕴为名色。
⑩ 六处　十二支中第五支，又名六入、六根，指眼耳鼻舌身意六根于名色中增长成就，根境识和合生触。
⑪ 十二有支　即十二因缘：无明、行、识、名色、六处、触、受、爱、取、有、生、老死。本卷以世间门、第一义谛门、唯心门三度展开，又各支皆有二业。
⑫ 三道　十二有支归纳为烦恼道（无明、爱、取）、业道（行、有）、苦道（余七支），三道相束如芦，离我我所但有生灭。
⑬ 三苦　十二有支亦可分三苦：无明至六处为行苦，触、受为苦苦，余支为坏苦；三苦断即无明灭行灭之灭谛。
⑭ 空解脱门　三解脱门之一，观诸法无我无人、自性空而入；与无相、无愿共为三解脱门，由缘起观次第现前。
⑮ 无相解脱门　三解脱门之一，观诸有支皆自性灭、毕竟解脱、无少法相生而入，依空解脱门后现前。
⑯ 无愿解脱门　三解脱门之一，入空无相已无有愿求，唯除大悲为首教化众生，是菩萨不取证灭之根本。
⑰ 般若波罗蜜　十波罗蜜之第六，到彼岸之智；第六地般若波罗蜜偏多，现前名无障碍智光明；第七地念念具足。
⑱ 无障碍智光明　第六地所得般若波罗蜜之异名，谓观有为多过患、自性寂灭而恒起大悲，于空寂与起悲两无障碍，故名无障碍智光明。
⑲ 十空三昧　第六地所得十种空三昧门：入空、自性空、第一义空、第一空、大空、合空、起空、如实不分别空、不舍离空、离不离空，为首摄百千空三昧。
⑳ 方便慧　第七地所修十种方便慧起殊胜道，谓虽证空无相无愿而起慈悲不舍众生等十对权实双行；由第六地入第七地之关键。
㉑ 波罗蜜　梵语 Pāramitā，到彼岸、究竟圆满之义；十波罗蜜为檀那、尸罗、羼提、毗梨耶、禅那、般若、方便、愿、力、智，第七地念念具足。
㉒ 那由他　梵语 Nāyuta，极大数名，或云亿、或云万亿，表不可胜数；本卷多用以状诸佛、三昧、劫数之多。
㉓ 阿耨多罗三藐三菩提　梵语 Anuttarā-samyak-saṃbodhi，无上正等正觉，即佛果之智；菩萨以善根悉皆回向于此。
㉔ 毗琉璃　梵语 Vaiḍūrya，青色宝，即青琉璃；本卷以真金以毗琉璃数数磨莹喻第六地菩萨善根转更明净。
㉕ 善化天王　第六地菩萨多作之天王，于他化自在天之下化作他化自在，谓以善巧变化化导众生，故名善化。
㉖ 远行地　十地中第七地之名，谓功用行至此已远、纯一清净，将入无功用行之深远处；此地以方便波罗蜜偏多为相。
㉗ 檀那波罗蜜　十波罗蜜之初，即布施到彼岸；第七地中以所有善根施与众生名檀那波罗蜜。
㉘ 尸罗波罗蜜　十波罗蜜之二，即戒度；能灭一切诸烦恼热名尸罗波罗蜜。
㉙ 羼提波罗蜜　十波罗蜜之三，即忍辱度；慈悲为首不损众生名羼提波罗蜜。
㉚ 毗梨耶波罗蜜　十波罗蜜之四，即精进度；求胜善法无有厌足名毗梨耶波罗蜜。
㉛ 禅那波罗蜜　十波罗蜜之五，即禅定度；一切智道常现在前未尝散乱名禅那波罗蜜。
㉜ 方便波罗蜜　十波罗蜜之七，即方便度；能出生无量智名方便波罗蜜，第七地此度偏多。
㉝ 四摄　菩萨化他之四法：布施、爱语、利行、同事；第七地念念具足，亦为诸地化生根本。
㉞ 三十七品　三十七道品，即四念处、四正勤、四如意足、五根、五力、七觉支、八正道，为大小乘共修之菩提分法。
㉟ 无功用行　谓不假作意策励、任运自然之行，自第八地始；第七地为有功用行之极，故为功用与无功用的转折地。
㊱ 转轮圣王　梵语 Cakravartin，以正法治四天下之圣王；本卷以乘天象宝游四天下喻初至七地未超烦恼位。
㊲ 无生法忍光明　第七地由善净三业无相行所得，谓无生法忍之初分光明，犹未圆满，至八地乃圆满证无生忍。
㊳ 灭定　灭尽定，灭心心所令不现起之定，二乘极果所入；菩萨从第六地能入，第七地念念入灭定而不证，示菩萨权实双行。
㊴ 乾闼婆　八部众之一，天界乐神，不食酒肉、以香为食；本卷列举天、龙、夜叉、乾闼婆等以状七地菩萨庄严出过彼等所有。
㊵ 摩睺罗伽　八部众之一，大蟒神或地龙；本卷于七地菩萨庄严超出列名中举之。
㊶ 阎浮提　梵语 Jambudvīpa，吾人所居之南赡部洲；本卷以阎浮提地所有泥潦日光能干竭，喻七地菩萨干竭众生惑泥。
