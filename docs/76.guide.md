# 大方广佛华严经卷第七十六 导读

## 一、内容总览

本卷属《入法界品》第三十九之十七，承续善财童子五十三参之历程。善财自大愿精进力救护一切众生夜神处得法已，渐次游行至岚毗尼林，谒见妙德（岚毗尼林）神，请问菩萨云何修菩萨行、生如来家、为世大明。神为说「菩萨十种受生藏」，复自述本缘：往昔曾为乳母净光，于古佛诞生时承事、得菩萨普眼三昧与「示现受生自在解脱门」，并广述岚毗尼园中菩萨将诞生时所现十种神变、十种光明瑞相，以及此解脱门于一念中普见十方刹海诸佛示现受生之境界。卷末指路迦毗罗城释种女瞿波，续善财参访之链。

## 二、结构层次（★重点）

全文以「请问 → 正说十法 → 自述本缘 → 重颂 → 推荐下一位善知识」五段推进：

- **请问缘起**：善财至岚毗尼林见妙德神坐宝莲华座，为说《受生海经》→ 善财顶礼请问「云何生如来家」。
- **正说十种受生藏**：神先标举「十种受生藏」总名，再逐一广释。十法按「始集善根 → 发菩提心 → 观法门勤修 → 深净心照三世 → 平等光明 → 生如来家 → 佛力光明 → 观普智门 → 普现庄严 → 入如来地」由浅入深、由因到果递进，每一法以「云何名……受生藏？善男子！此菩萨……」之固定句式展开，收束于「趣一切智，入法界门」。
- **重颂**：岚毗尼林神以十颂重宣十受生藏之义，一一对应前十法，并自述「我从无量劫来得此自在受生解脱门」。
- **自述本缘与神变**：神自述往昔愿力生阎浮提岚毗尼园，专念菩萨下生；世尊降生时林中现十瑞相，摩耶夫人入林复现十光明，菩萨将诞生复现十神变（摩耶身毛孔现三千世界、现往昔行因、现舍头目血肉等），层次递进至菩萨从母胁生、了达诸法如梦如幻。
- **古佛本缘与重颂**：追溯过亿刹尘劫前悦乐劫中，乳母净光（即神本身）于初佛自在功德幢诞生时得普眼三昧与受生自在解脱；复以长颂重宣；末以「我唯知此解脱，如诸菩萨……我当云何能知能说」谦推，指路瞿波。

层次间以「尔时」「复次」「善男子！云何名……」「答言」等过渡，先法说后本缘，先自述后推人，结构严整。

## 三、关键结论

1. 菩萨成就「十种受生藏」即生如来家、念念增长善根，十法总摄从初发心到入如来地之全过程，以「受生」贯通因果。
2. 岚毗尼林神所证「示现受生自在解脱门」，于一念中普见十方微尘数刹海中诸佛示现受生神变，体现华严「一念摄一切劫、一尘含无量刹」之法界缘起观。
3. 摩耶夫人于菩萨将诞生时现十神变，身毛孔中普现如来往昔修行舍身命财、值佛闻法等一切因缘，表明佛母之身即法界之映现，受生即说法。
4. 神之本缘溯至亿刹尘劫前乳母净光，示「初发心即成正觉」之因地，一念承事金色身即得普眼三昧，因果平等不二。
5. 卷末指路瞿波，续善财参访，体现善知识层层引介、法门渐次广深之参学范式。

## 四、易混辨析

- **受生藏 vs 受生解脱门**：「受生藏」是菩萨生如来家的十种因法（供养、发心、观门等）；「受生自在解脱门」是岚毗尼林神所证之果地境界——能于一念普见十方诸佛示现受生。前者是「云何生如来家」的答法，后者是「此解脱门境界云何」的答境。
- **摩耶夫人 vs 岚毗尼林神（妙德神）**：摩耶是菩萨（毗卢遮那如来）之生母，现诞生十神变；林神是岚毗尼园主神，自守此园百年专念菩萨下生，并自述往昔为乳母净光。二者一为生佛之母，一为护园证法之神，皆以「受生」为法门核心而角色不同。
- **童真位 vs 灌顶法**：童真位是菩萨第八受生藏所住之阶（住童真位观一切智门），表清净无染之初阶；灌顶法是第十受生藏所受（于三世诸如来所受灌顶法），表将登佛地之胜进。一前一后，一表清净一表继位。

## 五、阅读提示

读本卷可带着三问：菩萨「生如来家」究竟生的是什么家？岚毗尼林神守园百年所证之「受生自在」与摩耶夫人诞生菩萨之十神变有何关系？善财参至此处，法门如何由「救护众生」转入「示现受生」？留意「十」「十」「十」之三重十法叠层（十受生藏、十瑞相、十神变），以及「一念」「微尘」「刹海」等华严量词之用法。
