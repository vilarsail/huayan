# 大方广佛华严经卷第七十六 导读

## 一、内容总览

本卷为《入法界品》第三十九之十七，承释迦瞿波女之后。善财一心欲诣摩耶夫人所，先得主城神宝眼教以「心城」法门、身众神放光授眼、罗刹鬼王善眼劝发求善知识之心，随后于普纳十方法界藏楼观中谒见摩耶夫人。夫人示现无量色身，自述「菩萨大愿智幻解脱门」——以愿智幻化之身，为尽世界海一切受生菩萨之母，并追溯净光劫道场神发愿之本缘。卷末依次参天主光童女（无碍念清净庄严解脱）、遍友童子师（唯指荐）、善知众艺童子（善知众艺菩萨解脱，唱四十二字母）、贤胜优婆夷（无依处道场解脱）、坚固解脱长者（无著念清净庄严解脱）、妙月长者（净智光明解脱）、无胜军长者（无尽相解脱）、最寂静婆罗门（诚愿语解脱），指归妙意华门城德生童子、有德童女。本卷九参皆短，是五十三参后段「集众短参」的密集体。

## 二、结构层次（文章骨架与逻辑推进，★重点）

1. **神众赞导（P13-P40）**：主城神教心城十法 → 身众神放光令得十眼 → 罗刹鬼王说十法、十三昧，劝求善知识。
2. **见摩耶（P43-P52）**：大宝莲华涌现 → 普纳十方法界藏楼观 → 摩耶夫人现无量方便门、无量色身，善财现等身数礼拜证三昧。
3. **大愿智幻（P55-P88）**：自述为一切受生菩萨之母（净饭王宫菩萨下生瑞相、兜率降神、贤劫诸佛乃至未来弥勒）→ 追溯净光劫道场神本缘，转轮王即毗卢遮那 → 结「我唯知此菩萨大愿智幻解脱门」。
4. **九参链（P91-P226）**：天主光（忆念恒河沙劫诸佛）→ 遍友（指荐）→ 善知众艺（四十二字母入般若门）→ 贤胜（无尽三昧）→ 坚固解脱（无著念净）→ 妙月（净智光）→ 无胜军（见无量佛得无尽藏）→ 最寂静（诚愿语）→ 指德生童子、有德童女。
   - 每参皆「我得菩萨解脱，名：某 → 我唯知此 → 汝诣彼问」三段式，卷末收束。

## 三、关键结论

1. 大愿智幻：摩耶以愿力幻化为母，受生是幻、为母亦是幻——菩萨受生即神变。
2. 一切受生菩萨皆「常为我子，我常为母」，母子皆愿力所现，非世间血缘。
3. 天主光之「无碍念」：历劫供养诸佛、明忆无遗，是念力解脱的极致。
4. 四十二字母：字字入般若波罗蜜门，音声法门之代表。
5. 后段诸参法门渐趋平实（净智光、无尽相、诚愿语），显示行愿内敛、收摄于诚。

## 四、易混辨析

- **摩耶夫人 vs 妙德神**：妙德神（岚毗尼林神）是前卷（卷七十四）善知识，说「受生藏」；本卷摩耶夫人是佛母，说「大愿智幻解脱门」，二人均与「受生」有关而位格不同。
- **大愿智幻 vs 示现受生自在**：前者是摩耶夫人本卷所说之门；后者（菩萨于无量劫遍一切处示现受生自在解脱）是前卷大愿精进力救护一切众生夜神之门。
- **遍友 vs 善知众艺**：遍友童子师只引荐不说法（无解脱门）；真正说法者是善知众艺童子。
- **德生·有德**：本卷末只作结指；其「幻住解脱」在卷七十七正说。

## 五、阅读提示

本卷参数多而篇幅短，宜先抓住摩耶夫人一参的主体地位，其余八参按「法门名→指下一参」的链条快速推进；四十二字母段不必逐字研读，知其「字字入般若门」之结构即可。
