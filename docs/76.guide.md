# 大方广佛华严经卷第七十六 导读

## 一、内容总览
本卷为《入法界品》第三十九之十七，善财童子五十三参的中后段。善财为求「菩萨云何学菩萨行、修菩萨道」，次第参访十位善知识：摩耶夫人→天主光女→童子师遍友→善知众艺童子→贤胜优婆夷→坚固解脱长者→妙月长者→无胜军长者→最寂静婆罗门，卷末指向德生童子与有德童女。全卷以摩耶夫人的「大愿智幻解脱门」为核心，其余诸参篇幅渐短、法门渐简，一卷之内节奏由宏大转入轻快。

## 二、结构层次（文章骨架）
- **摩耶夫人参（主体，约占全卷一半）**：宝眼主城神先说「净修心城」三十一种心喻（护持、庄严、照耀、安立……心城），蠲除见佛、闻法等五种障难 → 身众神放光，善财得十种净眼 → 罗刹鬼王说亲近善知识之十法与十种三昧门 → 大宝莲华座「普纳十方法界藏」涌出，见摩耶夫人于一切众生前现四十余种色身 → 夫人自陈「大愿智幻解脱门」：右胁诞生悉达太子、腹中容受十方菩萨受生神变、贤劫千佛皆为其母 → 善财问得此解脱已多久，夫人溯净光劫道场神本生（见转轮王护道场成佛，发愿常为其母）→ 指路三十三天天主光。
- **天主光参**：得「无碍念清净庄严」，于诸劫中供养恒河沙佛，忆念诸佛从住胎、诞生、出家、成道至法尽的一切事迹 → 指路遍友。
- **遍友参**：只作指路人，直指其弟子善知众艺童子。
- **善知众艺参**：宣说四十二字母——唱阿字、多字、波字……一字各入一门般若波罗蜜门，以「字智」总摄无量法门 → 指路贤胜。
- **尾声五短参**：贤胜（无依处道场、无尽三昧）→坚固解脱（无著念清净庄严）→妙月（净智光明）→无胜军（无尽相）→最寂静婆罗门（诚愿语），皆是「自陈法门一名→自谦不知他德→指路下一善知识」的紧凑循环，直至卷末指向德生、有德。

## 三、关键结论
- 佛母非血缘而是愿力：摩耶以「大愿智幻」一身为一切世界受生菩萨之母，「非一处住，非多处住」，愿力幻化遍在一身。
- 忆念即道：天主光以无碍念总持诸佛一切行迹，正念不忘本身就是菩萨修行。
- 文字即法门：四十二字母每字各开一门般若波罗蜜，示「字智」为入道方便。
- 诚愿语：最寂静婆罗门以真诚誓愿之语令菩萨至于菩提无有退转，言必以诚。

## 四、易混辨析
- **大愿智幻解脱门 vs 无碍念清净庄严**：前者重「以愿力幻智为诸佛之母」，后者重「以念力总持诸佛事迹」。
- **遍友 vs 善知众艺**：遍友是童子师，本卷中只指路不说法；善知众艺是其弟子，才是四十二字母的说法者。
- **贤胜的无依处道场 vs 佛道场**：此处「道场」指心地所依，以「无依」为道场，正与卷首主城神「应知心城自性，谓：知一切法皆无有性」呼应。

## 五、阅读提示
带着「为什么一切佛皆以摩耶为母」读前半；后半诸短参注意每位善知识只用一两句点出自家法门便谦己指路，体会参访链「一参一法门」的节奏。
