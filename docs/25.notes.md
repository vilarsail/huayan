# 大方广佛华严经卷第二十五 词语注释

① 十回向品　《华严经》十地之前的重要位次，阐述菩萨将所修善根回向众生、菩提、实际，共十位。本卷为第三部分，讲第五、第六回向。
② 菩萨摩诃萨　梵语 Bodhisattva-mahāsattva，「摩诃萨」意为「大」，合称「大菩萨」，指已发大心、行大行、证大果的菩萨。
③ 无尽功德藏回向　十回向之第五。菩萨以忏悔、礼敬、劝请、随喜所起善根回向严净佛土，得十种无尽藏，功德无尽如虚空。
④ 善根　能生善法之根本，即无贪、无瞋、无痴三善根及其所摄一切善法。经中忏悔、礼敬、劝请、随喜所起功德皆称善根，为回向之体。
⑤ 劝请　请佛说法、请佛住世。菩萨以此所起善根回向，既利益众生又增长自他善根。
⑥ 随喜　见自他一切善根功德而生欢喜赞叹之心。本卷列三世诸佛、一切众生所有善根皆生随喜，为起善根的重要因行。
⑦ 转正法轮　佛出世说法度生，喻如转轮圣王转宝轮。菩萨回向愿常见诸佛转无障碍不退法轮。
⑧ 般涅槃　梵语 Parinirvāṇa，意译「圆寂」，即究竟寂灭。经言三世诸佛示现入般涅槃乃至正法灭尽，菩萨悉随喜。
⑨ 佛刹　佛所教化之国土，又称佛世界、佛土。本卷广列庄严、清净、平等乃至无譬谕等二十九种佛土名相。
⑩ 法界　梵语 Dharma-dhātu，诸法之界，一切法所依所缘之理。本卷反复言「尽法界、虚空界」，显示回向境界广大无边。
⑪ 虚空界　喻法界广大无边际，与「法界」连用表示回向所缘之境穷尽一切空间。
⑫ 三昧　梵语 Samādhi，意译正定，心一境性。本卷言「入不思议自在三昧」「安住甚深三昧境界」，为菩萨所证之定。
⑬ 阿僧祇　梵语 Asaṃkhyeya，意为「无数」，为极大数词。经中「阿僧祇金网」「阿僧祇河」等形容庄严之具无量无数。
⑭ 萨婆若　梵语 Sarvajña，意译「一切智」，指佛智。经中「趣萨婆若」即趣向佛的一切智地。
⑮ 补伽罗　梵语 Pudgala，意译「数取趣」或「人我」，指轮回主体。经言「悟一切法无补伽罗」即了达诸法无我。
⑯ 十力地　佛十力所依之果地。菩萨于念念中得「不可说不可说十力地」，即趣入佛智之位。
⑰ 如意摩尼　梵语 Cintāmaṇi，如意宝珠，随意所求皆能出之。经言菩萨成就「如意摩尼功德藏」，随有所须一切乐具皆得。
⑱ 十力　佛所独具之十种智慧力用，如处非处智力、业报智力等。本卷言「得十力地」「得十力无畏无尽藏」。
⑲ 离垢缯　以无垢白叠（白丝布）系于头顶，为灌顶之相。经言转轮王「以离垢缯而系其顶」，又言菩萨得十力无畏无尽藏时「以离垢缯而系其顶」，表位登法王、一切智现前。
⑳ 金刚幢菩萨　《十回向品》说法主，在此品中为大众宣说十回向义，本卷末以颂偈重宣第五回向。
㉑ 随顺坚固一切善根回向　十回向之第六。菩萨以种种布施（饮食、身肉、王位等）所起善根回向众生，善摄五蕴及一切资具，令善根坚固不坏。
㉒ 四摄法　菩萨摄受众生的四种方便：布施、爱语、利行、同事。转轮王以此四法摄化众生。
㉓ 转轮王　梵语 Cakravartin，以正法治世之圣王，具七宝。本卷言菩萨为帝王临御大国即为转轮王，以四摄法摄诸众生。
㉔ 那罗延　梵语 Nārāyaṇa，天上力士之名，喻坚固大力。经言「那罗延坚固之身」指菩萨得大力成就、无能屈伏。
㉕ 僧坊　出家人所居之寺院、僧房。菩萨施地造立僧坊、房舍、殿堂以为住处。
㉖ 无遮大施　不分贵贱、不限对象、平等普施之大布施会。菩萨以一切资生之物普设此会，悉令满足。
㉗ 惭愧衣　以惭愧为衣，喻持戒之相。菩萨施衣时回向愿众生得惭愧衣以覆其身，舍离邪道。
㉘ 阿伽陀药　梵语 Agada，意为「普去」即万病总药，能除一切毒。经中喻众生如阿伽陀药能除一切烦恼众毒。
㉙ 波罗蜜　梵语 Pāramitā，意译「到彼岸」，菩萨六度（布施、持戒、忍辱、精进、禅定、般若）之总称。本卷言「菩萨波罗蜜戒」「檀波罗蜜」等。
㉚ 六波罗蜜　布施、持戒、忍辱、精进、禅定、般若，菩萨度生之六种法门。经言「依六波罗蜜住」。
㉛ 摩尼　梵语 Maṇi，如意宝珠之名，能出众宝。经言「摩尼灯」「珊瑚摩尼珠宝」等庄严之具。
㉜ 栴檀　梵语 Candana，香木名，有白檀、赤檀等，焚烧或涂身香气殊胜。经列「栴檀灯」「栴檀器盛天衣服」。
㉝ 琉璃　梵语 Vaiḍūrya，七宝之一，青色宝物。经列「琉璃器盛种种宝」等宝器。
㉞ 砗磲　梵语 Musāragalva，七宝之一，贝类之宝，白色。经言「砗磲器盛赤真珠」。
㉟ 码瑙　即玛瑙，七宝之一，色如马脑之宝。经言「码瑙器盛满珊瑚摩尼珠宝」。
㊱ 檀波罗蜜　梵语 Dāna-pāramitā，即布施波罗蜜，六度之首。菩萨以一切物普施一切，满足三世檀波罗蜜。
