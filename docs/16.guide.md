# 大方广佛华严经卷第十六 导读

## 一、内容总览

本卷为《华严经》卷第十六，含三品跨节：自「升须弥山顶品第十三」起，经「须弥顶上偈赞品第十四」，至「十住品第十五」全。场景由阎浮提菩提树下升至须弥山帝释殿，佛不离菩提树下而升须弥，帝释奉座、十方皆同；十方菩萨云集，十大慧菩萨次第以颂赞佛；法慧菩萨承佛神力入无量方便三昧，受诸佛加持，广说菩萨十住法门，并以长颂总摄。本卷是从「信解境界」转入「行位次第」的关键枢纽——前十住为菩萨初阶行位的总纲。

## 二、结构层次（★重点）

本卷以「升座集众 → 颂赞显理 → 入定说住 → 颂摄全位」四段推进，由事入境、由境入行：

- **升座集众（境事）**：佛威神力令十方阎浮同见佛坐树下说法 → 世尊不离本座而升须弥向帝释殿 → 帝释庄严妙胜殿、设普光明藏师子座 → 佛受请入殿，殿宇广博 → 帝释忆念过去十佛皆曾入此殿而说颂（迦叶至然灯十佛，明此殿最吉祥）。→ 此段以「不离而升」显佛自在力，以「十方同时」显一即一切。

- **颂赞显理（理境）**：十方各一大菩萨与佛刹微尘数眷属俱来，各化作毗卢遮那藏师子座 → 法慧、一切慧、胜慧、功德慧、精进慧、善慧、智慧、真实慧、无上慧、坚固慧十大菩萨，依次承佛威力说颂。→ 每一颂皆层层递进：法慧总述佛自在与阎浮皆见佛；一切慧起破「取相」立「法性本空寂」；胜慧以暗宝、翳目、瞽者三喻明不了真性则不见佛；功德慧由「妄取真实相」推至「无见即是见」；精进慧辨「有见即垢」「远离诸见乃见佛」；善慧立「能见所见皆遣」之中观义；智慧菩萨明「生死涅槃二俱不可得」破二边；真实慧发「宁受地狱苦得闻佛名」之深愿，立「一即多、多即一」之缘起义；无上慧明「无一无二、无二亦无」之究竟见；坚固慧归到「佛为利群迷兴于世间」之大悲。→ 十颂一线贯穿「破相显性、会相归性」。

- **入定说住（行位）**：法慧菩萨承佛威力入「菩萨无量方便三昧」 → 十方千佛刹微尘数法慧同名同号诸佛现身加持，与十种智（无碍、无著、无断等）→ 诸佛申右手摩顶 → 法慧出定告众，广说菩萨十住：初发心住、治地住、修行住、生贵住、具足方便住、正心住、不退住、童真住、王子住、灌顶住。→ 每一住皆以「云何为某住 → 此菩萨行某十法 → 应劝学某十法 → 何以故欲令…」三段式展开，由所行（体）到所学（用）到动机（益），结构严整如阶梯。

- **颂摄全位（收束）**：法慧再以长颂总摄十住功德与初发心不可思议境界 → 十方世界六种震动、雨天妙华、天乐自鸣 → 十方法慧同名菩萨云集作证，明「十方所说十住文句义理无增减」。→ 以瑞相与十方同说收束，显一即一切、法界平等。

## 三、关键结论

1. 「不离一切菩提树下而上升须弥」——佛以一身普现十方，事相上的升降与十方同见，正显法界缘起一多相即之实相。
2. 十住为菩萨行位之始——从初发心至灌顶，十阶位次第安立，是华严「行布不碍圆融」的典范；每一住皆劝学十法、修十法，体用相即。
3. 见佛之要在离相——十菩萨颂虽各出手眼，根本一致：取相则不见佛，了法性空寂、无能所、无生灭，方能见卢舍那真身。
4. 初发心功德不可思议——长颂极言一念发心即能了知无量刹、无量劫、无量众生、无量佛法，下摄二乘所不能测，上同诸佛所行。

## 四、易混辨析

- **十住 vs 十地**：十住是菩萨初阶行位（此卷所说，自初发心至灌顶），十地是更高阶位（后文十地品所说）；「住」表安住佛法，「地」表能生万法。灌顶住已是十住之极，仍不及十地。
- **毗卢遮那 vs 卢舍那**：本卷颂中两见，皆指法身/报身之佛，译名异而所指同；偈赞中多称「卢舍那」，长行多称「毗卢遮那」。
- **法慧菩萨（说法者）vs 法慧诸佛（加持者）**：本卷法慧菩萨承佛力说法，而十方千佛刹微尘数同名「法慧」之佛现身加持，同名同号示法界平等，非同一尊。
- **善男子 vs 佛子**：诸佛呼法慧为「善男子」（表其堪受法器），法慧呼听众为「佛子」（表从佛化生、绍佛种性），用法有别。

## 五、阅读提示

读本卷可带着两个问题：一、为何佛「不离菩提树下」而又「升须弥」？此中如何体现一身与十身、一处与一切处的关系？二、十住既各有「十法应劝学」，彼此如何递进？留意每住末「欲令…有所闻法即自开解不由他教」一句，它是贯通十住的心要。
