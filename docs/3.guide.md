# 大方广佛华严经卷第三 导读

## 一、内容总览

本卷为《大方广佛华严经》「世主妙严品第一」的第三部分，承接前两卷道场庄严与众海云集之势，转入各类世主（天神眷属之主）各自陈述所得「解脱门」并共说颂偈赞叹如来。全卷依「八部众 → 昼夜方空风诸神」之序，逐一列举十二类主众（乾闼婆、鸠槃荼、龙、夜叉、摩睺罗伽、紧那罗、迦楼罗、阿修罗、主昼神、主夜神、主方神、主空神、主风神），每类先列十位眷属及其所得法门，复由其上首王承佛威力说颂十偈。其旨在于：如来境界无量，各类众生各随其根器契入一解脱门，共显一乘法界之普周无尽。

## 二、结构层次（★重点）

本卷以「类聚枚举 → 上首颂赞」为基本单元，十二组重复而递进，形成严整的层叠结构：

- **总式（每类皆然）**：「复次，某王得…解脱门；某王得…解脱门…（十位）」→「尔时，某上首王承佛威力，普观一切某众而说颂言」→ 十首四句颂偈。每类十位眷属法门各异，颂偈则由上首总赞佛德并略点各眷属所得。
- **枚举次第（有情世间）**：
  - 天乐之属：乾闼婆（香神/乐神）→ 鸠槃荼（瓮形鬼）→ 龙 → 夜叉
  - 天歌之属：摩睺罗伽（大蟒神）→ 紧那罗（歌神）→ 迦楼罗（金翅鸟）
  - 非天之属：阿修罗
- **转入时方之属**：主昼神 → 主夜神 → 主方神 → 主空神 → 主风神
  - 由有情众（八部）转入无情形相所主之境（昼夜方空风），从「众生类」收束到「法界周遍」，指向后卷如来品相之展开。
- **颂偈内部结构**：每偈常以「佛德广大 → 救护众生 → 某王悟入」收束，形成「赞佛 → 度生 → 印可」三段式；十偈合观，正对十位眷属法门，前后呼应。

层次推进：先列有情八部（杂类随类得度），后列主方神（境主说法界周遍），以「风神」殿后，收于「随顺一切众生行无碍力」，显如来大悲普应群机、周遍法界之相。

## 三、关键结论

1. 各类世主各契一解脱门，而同赞一佛功德，显「一门即一切门」之普贤境界——无量差别归于无差别。
2. 颂偈反复强调佛昔劫海修诸行、大悲救护众生，说明如来功德皆由因行克果，非自然而有。
3. 众生苦（痴惑、业障、流转）与佛智光（普照、调伏、说法）构成全卷张力，佛以方便随类应现令苦灭乐生。
4. 「佛身如虚空、无生无得无自性」「一切诸佛一法身真如平等」等偈，已显法身无相、真如平等之大乘深义，为后文法界品伏脉。

## 四、易混辨析

- **乾闼婆 vs 紧那罗**：同为天界乐神，乾闼婆事香（香音）、紧那罗事歌（法乐），一主香气一主歌呗，皆以音声度生。
- **鸠槃荼 vs 夜叉 vs 罗刹**：同属鬼道眷属，鸠槃荼状如瓮鬼、主恼害；夜叉勇健飞行、有福报；本卷鸠槃荼主灭怨害、夜叉主救护恶众生，各转其本习为法门。
- **摩睺罗伽 vs 迦楼罗**：摩睺罗伽为大蟒神（地行），迦楼罗为金翅鸟（飞行，以龙为食）；经中二者列于紧那罗前后，构成八部众中「形异而同列」之对照。
- **主昼神 vs 主夜神 vs 主方神 vs 主空神 vs 主风神**：依「时—处—空—动」次第——昼主时之明、夜主时之暗、方主处所之向、空主无碍之容、风主周行之动，五者共显法界无所不周。
- **阿修罗 vs 天**：阿修罗译「非天」，有天福无天德，常与帝释争；本卷列阿修罗众赞叹佛德，示佛调伏乃至非天之类。

## 五、阅读提示

读时不妨带着两个问题：其一，十二类众生法门各异，其共同指向是什么？（答：佛德普周、大悲救护。）其二，颂偈中反复出现的「佛昔修诸行」「劫海」等，在全卷论证中起什么作用？（答：确立佛功德的因果依据，令赞非虚誉。）
