# 大方广佛华严经卷第三十六 导读

## 一、内容总览

本卷属《大方广佛华严经·十地品第二十六》的第三部分，承接前三地而说第四焰慧地、第五难胜地二地行相。由金刚藏菩萨宣说，解脱月菩萨启请，以「地地相承、层层增胜」为线索：先以颂偈回向第三地功德、起请第四地，长行详述焰慧地修十法明门、四念处、四正勤、四神足、五根、五力、七觉分、八正道等三十七道品，离身见等六十二见，喻如真金；再由天女赞佛、解脱月请第五地，长行述难胜地以十平等清净心趣入、善知四谛及十谛、起大悲光明、修世间技艺、喻如日月星宿，颂偈收束。全卷以「请—说—颂」三段为骨架，复于二地中各以「所修法→所得德→见佛喻→果报」四阶推进。

## 二、结构层次（★重点）

全文按「请法→第四地详说→第五地详说→二颂收束」推进，二地内部结构平行而内容递进：

- **赞叹启请（P3-P16）**：天王散华、天女同赞、解脱月请说第四地行相 → 以「于百千劫甚难得，我今忽然而得闻」点明此法难闻，请说后地。

- **第四焰慧地（P17-P22，长行）**，其内层层展开：
  - **入地因缘（P17）**：第三地善清净已，欲入第四地，当修十法明门（观察众生界、法界、世界、虚空界、识界、欲、色、无色、广心、大心信解界）→ 以十法明门得入。
  - **生如来家（P18 上）**：以十种智成熟法，生如来家、得不退 → 十智列「深心不退、三宝净信、诸行生灭、法性无生」等。
  - **三十七道品（P18 中）**：四念处→四正勤→四神足→五根→五力→七觉分→八正道，一一皆「依止厌、依止离、依止灭，回向于舍」→ 总摄三十七道品为一地所修。
  - **大悲为本（P18 下）**：修如是功德，为不舍众生、本愿所持、大悲为首 → 指出道品修习以大悲为根本指向。
  - **离身见（P19）**：以身见为首，我、人、众生、寿、蕴、界、处等执着皆离 → 舍如来所诃、行如来所赞。
  - **得十心与精进（P20）**：润泽心、柔软心……至善分别道非道精进，心界清净、佛亲护念 → 由忍调柔寂灭，发九种精进。
  - **见佛与喻（P21）**：愿力见多百千亿那由他佛，喻如金师炼治真金、摩尼宝清净光轮 → 下地善根所不能及，众魔不能坏。
  - **果报（P22）**：略说第四地，多作须夜摩天王，一念得亿数三昧等 → 以菩萨愿力自在示现过此数。

- **第四地颂（P23-P57）**：重宣长行义，结构略同而以偈颂串摄，以「我为佛子已宣说」收束。

- **第五难胜地（P58-P87，长行）**，与前地结构平行而内容递进：
  - **赞叹启请（P58-P77）**：天女奏乐歌赞佛，喻佛如须弥出海、莲华不染 → 解脱月请说第五地行相。
  - **入地因缘（P79）**：第四地圆满，以十种平等清净心趣入第五地 → 列「三世佛法、戒、心、除见疑悔、道非道智」等十心。
  - **得不退转（P80）**：由善修菩提分、净深心、转求上胜、随顺真如等十一因缘 → 得不退转心。
  - **善知谛理（P81）**：如实知苦、集、灭、道四圣谛，复善知俗谛、第一义谛、相、差别、成立、事、生、尽无生、入道智、菩萨地次第成就、如来智成就等谛 → 以信解智力知，非以究竟智力知。
  - **大悲光明（P82）**：知有为法虚妄诳惑，于众生转增大悲、生大慈光明；观前后际无明有爱流转；念凡夫愚痴可愍，发心独修福智令众生毕竟清净 → 由谛智起大悲，为大悲而求佛智。
  - **得名（P83）**：名为念者、智者、有趣者、惭愧者、坚固者、觉者……乃至日夜远离余心者 → 列二十余种德号。
  - **教化方便（P84）**：以布施、爱语、利行、同事，乃至现神通力等十种方便教化众生 → 心恒相续趣佛智慧。
  - **世间技艺（P85）**：文字、算数、图书、印玺、方药、歌舞、宝藏、星宿、身相、四无色等靡不该习 → 为利益众生咸悉开示，渐令安住无上佛法。
  - **见佛与喻（P86）**：愿力见多佛，出家闻法得陀罗尼为闻持法师；喻如真金以砗磲磨莹转更明净，又如日月星宿风力所持不可沮坏 → 下地及二乘善根不能倾动；十波罗蜜中禅波罗蜜偏多。
  - **果报（P87）**：多作兜率陀天王，摧伏外道邪见，一念得千亿三昧等 → 愿力所作过于是。

- **第五地颂（P88-P132）**：重宣长行，以「念处为弓根利箭，正勤为马神足车」等喻摄道品，以「如以妙宝磨真金」「譬如星宿在虚空」二喻收束，以「我以种种方便力，为诸佛子宣说竟」结。

## 三、关键结论

1. 第四焰慧地以「十法明门」为入因，以三十七道品为正修，以离身见等六十二见为断障，以大悲为首、本愿所持为根本指向——道品非二乘自利，乃菩萨为度众生而修。
2. 第四地喻真金炼治，第五地喻真金砗磲磨莹——地地善根转更明净，下地所不能及，显十地行相层层增胜。
3. 第五难胜地以「十平等清净心」趣入，以善知四谛及十种谛为核心，由此谛智转生大悲光明——由「智」发「悲」，为第五地的枢纽。
4. 菩萨修世间技艺（文字、算数、医方、星宿等）非为世利，乃为「渐令安住无上佛法」——世间技艺是度生方便，与三十七道品同为菩提分所摄。
5. 二地分别多作须夜摩天王、兜率陀天王，于一念顷得亿数、千亿数三昧——十地各有其胜报与自在示现，而皆以愿力为根本。

## 四、易混辨析

- **焰慧地 vs 难胜地**：第四地名「焰慧」，约所修三十七道品、智慧增明如焰而言；第五地名「难胜」，约善知谛理、世出世间智慧俱通、难以超胜而言。前者重「修」，后者重「知」与「悲」。
- **四谛 vs 十谛**：四圣谛（苦集灭道）是根本；十谛（俗、第一义、相、差别、成立、事、生、尽无生、入道智、菩萨地次第乃至如来智成就）是第五地于四谛基础上展开发起的差别谛相，以信解智随应众生而立。
- **须夜摩天王 vs 兜率陀天王**：前者为第四地菩萨多作之天主，属夜摩天；后者为第五地菩萨多作之天主，属兜率天——十地配十王位，地升则天升。
- **真金喻**：第四地喻「金师炼治真金作庄严具」，重在炼治；第五地喻「真金以砗磲磨莹」，重在磨莹——同为真金，而磨治之功益深。

## 五、阅读提示

读本卷可带着两个问题：其一，三十七道品本属声闻所修，菩萨于此地修之与二乘有何不同（注意「依止厌、离、灭，回向于舍」与「为不舍一切众生故」的连接）？其二，第五地由谛智转生大悲光明的逻辑环节如何（注意「知有为虚妄」→「转增大悲」→「生大慈光明」的次第）？
