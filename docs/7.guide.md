# 大方广佛华严经卷第七 导读

## 一、内容总览

本卷含两品：**普贤三昧品第三**与**世界成就品第四**，是华严经正式展开「法门海」的枢纽。前一品承上一卷「世主妙严品」之庄严，由普贤菩萨于如来前入「一切诸佛毗卢遮那如来藏身三昧」，以三昧力发起十方诸佛共同加持、摩顶、赞叹，并由诸佛放光说颂，确立普贤为宣说法门的当机者。后一品则由普贤承佛神力，遍观十种海（世界、众生、诸佛、法界等），向道场众菩萨宣告「世界海」的十种事相——起具因缘、所依住、形状、体性、庄严、清净、佛出兴、劫住、劫转变差别、无差别门，构成全经对器世间（国土）的总纲，为后续「华藏世界品」铺路。两品合看，是由「能入之普贤三昧」开出「所入之世界海」，能所不二。

## 二、结构层次（★重点）

本卷以「三昧发起 → 诸佛加持 → 普贤宣说世界海十事」一线贯穿，由定起说、以颂重宣：

- **入定发起（境）**：普贤于如来前入「一切诸佛毗卢遮那如来藏身三昧」→ 此三昧普入法界、出生一切三昧、含藏佛力菩萨智 → 尽法界一一尘中各有微尘数普贤同入此定（总起，显示「一即一切」）。
- **诸佛加持赞说（缘）**：十方诸佛现前同声赞「善哉」→ 列十种「所以入此三昧」之因（转法轮、开智海、照安立、净杂染等）→ 复与普贤十种智（一切智性力、法界无边量等）→ 各舒右手摩顶，手中现三世菩萨愿海、如来法轮、诸佛影像（能加持之佛与所加持之普贤交彻）。
- **从定起、众获益（用）**：普贤从三昧起，即从一一三昧门海起 → 诸菩萨各得微尘数三昧、陀罗尼、方便、辩才、修行等海云（定起即用，利益流注）。
- **世界成就品总纲（普贤宣告）**：普贤遍观十海 → 列「诸佛智不可思议」三十余句（清净佛身、色相光明、调伏众生等）→ 说「为令众生入佛智海」等十大因缘，标举说法宗旨（由赞叹佛德转入宣说世界海）。
- **世界海十事分述（主体，长行+重颂）**：
  - 起具因缘（十因缘：如来神力、法应如是、众生行业、菩萨成智、普贤愿力等）→ 颂重宣；
  - 所依住（或依庄严、依虚空、依宝光明、依佛音声、依菩萨身、依普贤愿等）→ 颂广说种种依住形相；
  - 形状（圆、方、水漩、山焰、树、华、宫殿、众生、佛形等）→ 颂；
  - 体性（宝庄严、宝光明、不可坏金刚、佛力持、一念心、佛言音等）→ 颂；
  - 庄严（出妙云、说菩萨功德、示众生业报、现普贤行愿等）→ 颂；
  - 清净方便（亲近善知识、净修波罗蜜、观察诸地、出生净愿等）→ 颂；
  - 佛出兴差别（小身大身、短寿长寿、一乘无量乘、调伏少分无边众生等）→ 颂；
  - 劫住（阿僧祇、无量、无边、无等、不可数、不可称、不可思、不可量、不可说劫等）→ 颂；
  - 劫转变差别（法如是、染污众生住、修福众生住、信解菩萨住、发菩提心、菩萨云集、佛入涅槃、佛出现、佛神通变化等致劫转变）→ 颂；
  - 无差别门（一一世界海中世界数、诸佛威力、道场、众会、佛光明、变化名号、佛音声、法轮方便、普入一尘、三世佛境界皆无差别）→ 颂。
- **收束**：以「一一尘中三世佛，体性无来亦无去，以愿力故遍世间」收束，归于一真法界、愿力周遍。

## 三、关键结论

1. **普贤三昧即法界总持**：入此三昧即普入一切佛平等性，于一一微尘中现世界海微尘数佛刹、佛、普贤，皆同入此定，显示「一尘含法界」的华严事事无碍义。
2. **诸佛加持是法门流出的根本缘**：十方诸佛共同加持、与智、摩顶，方有普贤从定起而宣说，强调法门非自作，乃佛力所成。
3. **世界海皆由因缘而起**：如来神力、法应如是、众生行业、菩萨愿力等十缘和合而成，破斥世界为实体自性之执，显缘起性空。
4. **劫随众生心行转变**：染污众生住则劫染污，发菩提心则劫清净，佛出世则广博严净，明示「心、业、佛力」与器世间成坏的相互感召。
5. **一一尘中三世佛境界无差别**：十种无差别门收归于「一微尘中普现三世诸佛广大境界」，圆满「一即一切、一切即一」的法界观。

## 四、易混辨析

- **普贤三昧品 vs 世界成就品**：前者是「能入」——普贤入定、诸佛加持、定起获益；后者是「所入」——依定而起说，宣示世界海十事。能所不二，定即说、说即定。
- **世界海 vs 佛刹 vs 三千大千世界**：佛刹指一佛所化之土（如娑婆、极乐）；世界海为十方无量佛刹之总聚，含微尘数刹，重重无尽；三千大千世界乃一佛刹之范围，在世界海中如一微尘。
- **劫住 vs 劫转变差别**：劫住言世界存在之时劫长短（阿僧祇劫、不可说劫等）；劫转变差别言同此劫中，由众生心、业、佛力之变而世界相随之染净成坏。
- **染污劫 vs 染净劫 vs 纯清净劫**：染污劫——染污众生住所致；染净劫——修福或信解菩萨住所致，杂染与清净相参；纯净清净劫——无量众生发菩提心、佛神通变化所致。

## 五、阅读提示

读本卷可带着两个问题进入：普贤入定后为何要由十方诸佛共同加持摩顶才可起说？「世界海十事」中，为何最后收于「无差别门」——前面种种差别相与「一一尘中普现三世佛」如何统一？把握「能入之三昧」与「所入之世界海」的对应，即抓住本卷主线。
