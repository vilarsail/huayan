# 大方广佛华严经卷第六十五 词语注释

〔1〕 实叉难陀　于阗（今新疆和田）僧人，八十卷《华严经》的译主；"三藏"是精通经、律、论的法师称号。
〔2〕 入法界品　《华严经》末会品名，叙善财童子遍参善知识求菩萨道；"第三十九之六"谓此品的第六卷。
〔3〕 尔时　佛经惯用连接语，"那时候"，承上文所说之时。
〔4〕 善财童子　入法界品的主人公，因出生时众宝自然涌现而得名，为求菩萨道南行遍访善知识的青年菩萨。
〔5〕 善知识　教人善法、引人入正道的良师益友；本品即以善财遍求善知识、一一参问为主线。
〔6〕 实际　佛法名词，指一切法的真实边际、真如理体，非现代语"实际上"之义；与此卷"常住际""无二际"诸"际"同为表法之词。
〔7〕 师子奋迅城　善财此参所到之城，"师子奋迅"喻狮子振威奋迅之勇猛迅疾；城中善知识为慈行童女。
〔8〕 慈行童女　师子幢王之女，五百童女之主，实为久证的菩萨，住毗卢遮那藏殿说般若波罗蜜普庄严门。
〔9〕 毗卢遮那藏殿　慈行童女所住宫殿名；"毗卢遮那"意为光明遍照，"藏"谓含藏众宝。
〔10〕 龙胜栴檀　栴檀（檀香木）中之一种；此句谓座以龙胜栴檀为之，敷以足金线网与天衣。
〔11〕 玻璃　古义非今之玻璃，指天然水晶类宝珠（水玉之类），佛经七宝之属。
〔12〕 阎浮檀金　阎浮河中所产之金，佛经中最上等的金色，色泽赤中带紫。
〔13〕 窗牖　牖 yǒu，窗；窗牖即窗户。
〔14〕 阿僧祇　梵语 asaṃkhya 音译，意为"无数"，佛经中的极大数名。
〔15〕 摩尼　梵语 mani 音译，宝珠，能随人意出生诸宝，故亦称如意珠。
〔16〕 庄校　校（jiào），装饰；庄校即以众宝庄严装饰。
〔17〕 绀青色　绀 gàn，红中带青的深色；绀青形容头发深青泛紫之色。
〔18〕 梵音　清净梵妙之音声，指佛菩萨说法之音，深远和雅，闻者不厌。
〔19〕 阿耨多罗三藐三菩提　梵语 anuttara-samyak-saṃbodhi 音译，意译"无上正等正觉"，即佛的觉悟；"发阿耨多罗三藐三菩提心"即立愿成佛。
〔20〕 璎珞　珠玉串成的颈饰、胸饰，印度传统严身之具。
〔21〕 靡不　靡 mǐ，无、没有；"靡不"即"无不、没有不"。
〔22〕 般若波罗蜜　梵语 prajñā-pāramitā 音译，"般若"是智慧，"波罗蜜"是到彼岸；慈行童女所证法门即名"般若波罗蜜普庄严门"。
〔23〕 恒河沙　以恒河（印度大河）沙粒之数比喻极多，佛经最常用的数量譬喻。
〔24〕 异门　不同的门径、角度；谓三十六恒河沙佛各从不同侧面令她悟入此法门。
〔25〕 陀罗尼　梵语 dhāraṇī 音译，意译"总持"，能总摄忆持无量法义而不失的功能；"陀罗尼门"谓入此总持之门户。此下百余个"××陀罗尼门"是并列列举，抓每条首词即可。
〔26〕 佛刹　刹 chà，梵语 kṣetra，国土、世界；佛刹即一佛所教化的国土。
〔27〕 福德助道具　"助道具"即资助成就修行的因缘资具；福德助道具谓助成福德之法，与"智慧助道具"对举。
〔28〕 稠林　茂密的森林；佛法中喻烦恼、生死密密层层缠缚众生，如"照心稠林""生死稠林"。
〔29〕 烦恼习气　烦恼是现起的身心困扰，习气（梵语 vāsanā）是烦恼断除后残留的习惯势力，更难除尽。
〔30〕 智眼无翳　翳 yì，遮蔽眼目的白膜；谓智慧之眼没有障蔽，明见法界。
〔31〕 思惟菩萨所住行甚深　自"思惟菩萨所住行甚深"至"思惟业庄饰世间甚深"共十三句排比并列，写善财辞行路上的思惟，读法是抓每句"思惟……甚深"的框架。
〔32〕 三眼国　善财第二参所到的国土，善见比丘住此；"三眼"表能见三世（过去、现在、未来）之眼。
〔33〕 善见比丘　三眼国林中经行的比丘，善财所参善知识，证"菩萨随顺灯解脱门"，以一念中现一切境之慧教化。
〔34〕 经行　佛教修行方式，在固定处所往返徐步，摄心防倦，与坐禅相对；善见比丘正在林中经行。
〔35〕 肉髻　佛三十二相之一，头顶骨肉隆起如髻。此处写善见比丘相貌如佛。
〔36〕 颈文三道　颈部有三道纹理，大人相之属，与下文诸相同为佛相之描写。
〔37〕 莲华　华同"花"，古无"花"字，佛经一律用"华"。
〔38〕 频婆果　梵语 bimba，一种鲜红色果实，喻唇色红润光洁；注意与后文数名"频婆罗"相区别。
〔39〕 卍字　卍音同"万"，吉祥海云相；佛胸前的卍字为三十二相之一，表万德庄严。
〔40〕 七处平满　三十二相之一，谓两足下、两手、两肩及颈上七处平正丰满。
〔41〕 网缦　手足指间有如水鸟之蹼的薄膜相连，佛三十二相之"手足网缦相"。
〔42〕 净居天　色界第四禅最上诸天（无烦、无热等五天），唯证不还果以上的圣者所居，容貌殊妙。
〔43〕 尼拘陀树　梵语 nyagrodha，枝干高大直耸的榕树类大树，喻身量端直。
〔44〕 一寻　寻为长度单位，八尺为一寻；"圆光一寻"谓身光周匝一寻，即佛三十二相之"常光一寻相"。
〔45〕 若沈若举　沈同"沉"；沉指昏沉（心暗昧），举指掉举（心浮动）。此句谓无论沉掉、智与不智、动转戏论，一切皆已止息。
〔46〕 乾闼婆　梵语 gandharva 音译，帝释的乐神，唯以香气资身，八部众之一。
〔47〕 摩睺罗伽　梵语 mahoraga 音译，大蟒神（腹行神），八部众之一。
〔48〕 护世　护世四天王，即持国、增长、广目、多闻四大天王，职在护持世间。
〔49〕 梵行　梵语 brahmacarya 意译，清净离欲之行，特指持守不淫之净戒。
〔50〕 那由他　梵语 nayuta 音译，极大数名，通常谓千亿或万亿。
〔51〕 不可说不可说　佛经数名的极致，谓其大已不可言说；本卷中与"恒河沙""微尘数"同为极言其多的惯用语。
〔52〕 大劫　劫（kalpa）为极长时间单位；成、住、坏、空四个中劫合为一大劫。
〔53〕 波罗蜜海　波罗蜜即六度（六种到彼岸之行），"波罗蜜海"言其深广如海。
〔54〕 普贤乘　普贤菩萨所代表的大乘行愿之门；谓依普贤行愿之乘而出离成佛。
〔55〕 一念中　自"一念中，一切十方皆悉现前"至"一切三世海皆悉现前"共十二句排比：每句先说一念中所现之境，句末"……故"字点出能现的原因（愿力智力），读时前后对看。
〔56〕 十力　佛独有的十种智力（知是处非处、知业报、知诸禅解脱等），唯佛具足。
〔57〕 微尘数　把世界碎为微尘以计数，比喻极多；"佛刹微尘数"即一佛国土碎为微尘之数。
〔58〕 常然智灯　然同"燃"，通假字；谓智慧之灯常燃不灭。
〔59〕 沮坏　沮 jǔ，败坏；沮坏即毁坏。
〔60〕 河渚　渚 zhǔ，水中小洲；河渚即河中沙洲。
〔61〕 自在主　名闻国河渚上的童子，曾随文殊师利学习书数算印，以工巧智化导众生，为善财所参善知识之一。
〔62〕 文殊师利　文殊菩萨，善财发心参学的第一位善知识；自在主童子曾在其处修学书数算印。
〔63〕 工巧　即工巧明，古印度五明之一，包括书写、算数、建筑、医药、农商等种种技艺。
〔64〕 风痫　痫 xián；风痫指风疾、癫痫一类疾病。
〔65〕 商估　估 gū，贩卖交易；商估即经商买卖，与田农对举，谓各种营生。
〔66〕 缘觉　观十二因缘而独自觉悟者，即下文之"辟支佛"；与声闻合称二乘。
〔67〕 一切智地　佛一切智的地位，谓究竟成佛。
〔68〕 菩萨算法　自"一百洛叉为一俱胝"以下是层层递增的数名长串：每两个同名数相乘即得下一数之名（如"俱胝俱胝为一阿庾多"），不必逐名记诵，知其表菩萨能算知极大之数即可。
〔69〕 洛叉　梵语 lakṣa 音译，十万。
〔70〕 俱胝　梵语 koṭi 音译，千万（一说一亿），佛经常用大数名。
〔71〕 阿庾多　佛经数名，俱胝俱胝相乘所得之更大数。
〔72〕 频婆罗　佛经数名，阿庾多之后更大的数；注意非"频婆果"。
〔73〕 矜羯罗　佛经数名，紧接频婆罗之后的更大数；"广说乃至"谓此类递增数名极多，中间从略。
〔74〕 优钵罗　梵语 utpala，青莲花；此处借用花名作递增大数之名。
〔75〕 波头摩　梵语 padma，红莲花；此处亦作递增大数之名。
〔76〕 由旬　梵语 yojana 音译，古印度长度单位，约四十里（诸说不一），帝王一日行军之路程。
〔77〕 优婆夷　梵语 upāsikā 音译，受持五戒的女性在家信徒；此卷中具足优婆夷证无尽福德藏解脱门。
〔78〕 三有　三种存在的领域，即欲界、色界、无色界，代指生死轮回。
〔79〕 关钥　钥 yào，锁钥；"开三有城所有关钥"谓打开三有生死之城的门锁，喻解脱生死。
〔80〕 三十三天　即忉利天，帝释所居，中央一天与四方各八天城合为三十三；此卷以「三十三天于（须弥山）中止住」喻善知识教可安住依止。
〔81〕 帝释　忉利天（三十三天）之天主，梵语 Śakra 意译，佛经中常见的护法天神。
〔82〕 修罗军众　修罗即阿修罗，与帝释天常战斗的多嗔恶神；"能伏异道、修罗军众"谓能降伏外道与阿修罗。
〔83〕 素服垂发　素服即白色衣服（不着华服），垂发谓发不束髻不加饰；写具足优婆夷不事装饰、朴素庄严之相。
〔84〕 资生　资养生活所需之物，即衣服饮食、床座医药等生活资具。
〔85〕 采女　宫廷中的侍女；此喻一万童女威仪色相如天宫侍女。
〔86〕 不退转　梵语 avaivartika，谓菩萨修行位位增进不再退失，不退堕二乘或生死。
〔87〕 律仪心　律仪即戒律仪则（梵语 saṃvara）；住律仪心谓安住于持戒防非之心。
〔88〕 阎浮提　梵语 Jambudvīpa，即南赡部洲，我们所居的这个世界。
〔89〕 一四天下　一个世界的四大洲（须弥山四方之东胜身、南赡部、西牛货、北俱卢），即一日月所照的世界。
〔90〕 小千世界　一千个"一四天下"为一小千世界，一千小千为中千，一千中千为三千大千世界，即一佛国土。
〔91〕 种种鬘　鬘 màn，以花或珠串成的花环、颈饰，与璎珞同类。
〔92〕 末香　研成粉末的香，供散撒涂布之用；与涂香、烧香对举。
〔93〕 辟支佛　梵语 pratyekabuddha 音译，即缘觉，无佛之世独自觉悟的圣者。
〔94〕 最后身　声闻、辟支佛及一生补处菩萨在生死中的最后一次受生，此后即超出轮回、证果成佛。
〔95〕 一生所系　"一生所系菩萨"谓只剩余一生便当成佛的菩萨（一生补处），如住兜率天的弥勒菩萨。
〔96〕 以不　犹言"与否"；"汝见……以不"即"你见了……没有"，古文问句格式。
〔97〕 如意珠　即摩尼宝珠，能随人意出生所需之物，故称如意。
〔98〕 奥藏　奥 ào，深邃；奥藏谓深藏宝物之处，喻善知识教中深藏法财。
〔99〕 明智居士　大兴城中的居士，善财所参善知识，证"随意出生福德藏解脱门"，凡有所求皆随愿满足并为说法。
〔100〕 四衢　衢 qú，四通的大路；"市四衢道"即市中四通八达的十字大道。
〔101〕 帝青　帝释青（梵语 indranīla），青蓝色宝石，即上等蓝宝石，为宝中之贵者。
〔102〕 毗琉璃　梵语 vaiḍūrya 音译，青色宝珠（青绿色宝石），佛教七宝之一。
〔103〕 鹅王　白鹅（雁）之王，羽翼洁白，行于水而不染浊；佛经常以之喻圣者净行，其羽用作拂扇。
〔104〕 羽翮　翮 hé，鸟羽的茎轴，代指羽毛。
〔105〕 长者　佛经中对年高德劭、资财丰厚之男子的尊称；此卷中明智居士与法宝髻皆称长者。
〔106〕 憩止　憩 qì，休息；憩止即歇息。"无时憩止"谓瞻仰善知识无一刻歇息。
〔107〕 生如来家　谓发菩提心、入佛种姓，如生于佛家而为佛子。
〔108〕 白法　梵语 śukladharma，善净之法（"白"表清净），与黑法（恶法）相对；"增长白法"谓增长一切善净功德。
〔109〕 法喜禅悦食　佛法以闻法之喜、禅定之乐滋养身心，如饮食养身，称法喜食、禅悦食（二种出世间食）。
〔110〕 摩诃衍　梵语 Mahāyāna 音译，即大乘；"摩诃衍乘"重言以强调。
〔111〕 周赡　赡 shàn，供给充足；周赡即普遍供给周足，无一缺漏。
〔112〕 如应　随宜、应机；"如应说法"谓随众生根机相应而说法。
〔113〕 普雨　雨读 yù，降落、降下（作动词）；"普雨一切资生之具"谓如雨般普遍降下一切生活资具。
〔114〕 法宝髻　师子宫中的长者，善财下一参将访的善知识（此卷末预告）。
