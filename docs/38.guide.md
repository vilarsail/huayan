# 大方广佛华严经卷第三十八 导读

## 一、内容总览

本卷属《大方广佛华严经·十地品第二十六之五》，承接前卷第七地（远行地）之后，由金刚藏菩萨为解脱月菩萨及大众宣说**第八不动地**与**第九善慧地**。两地位次居十地之中段，前承七地功用行已极，后启十法云地与如来果海，是菩萨从「功用」转入「无功用」、由「自利寂灭」转向「利他说法」的关键转折。卷首以诸天兴供赞叹、解脱月启请为缘起，继以长行详述二地行相，末以颂偈重宣其义；第九地开章又别起一段「如来现通、天众赞叹」的缘起，结构自成一段。

## 二、结构层次（★重点）

本卷以「两段缘起 + 两段长行 + 两段偈颂」为骨架，依地次第展开：

- **第八地缘起（P4–P27）**　天王天众闻七地胜行欢喜 → 雨华奏乐供养 → 以偈赞叹如来一毛端中现无量刹、说无量法之神力 → 众会默然，解脱月请说第八地行相。
- **第八地长行（P28–P39）**　金刚藏告解脱月，按「得忍入地 → 诸佛劝发 → 起智利生 → 身智自在 → 地德异名 → 果报胜用」之序展开：
  - 七地善修方便慧 → 入一切法本来无生 → **得无生法忍**，入第八不动地（P29）；
  - 譬比丘入灭尽定、梦中渡河，明「舍一切功用、得无功用法」（P30）；
  - 诸佛现前劝发：汝虽得寂灭解脱，然十力无畏未得，当愍念众生、忆念本愿，勿舍此忍门（P31）；
  - 诸佛与起智门故，一念所生智业远胜七地前诸行；如船入海乘风而往（P32）；
  - 起无功用智观世间成坏、微尘差别、三界差别（P33）；
  - 随众生信解差别，于一切佛刹现身教化，乃至现声闻、缘觉、菩萨、如来形（P34）；
  - 知十种身（众生、国土、业报、声闻、独觉、菩萨、如来、智、法、虚空）互相作，得十种自在（P35）；
  - 得无过失三业、善住十力、地德立十异名（不动、不转、难得、童真、生、成、究竟、变化、力持、无功用）（P36–P37）；
  - 多作大梵天王，愿波罗蜜增上，一念得百万三千大千世界微尘数三昧（P39）。
- **第八地偈颂（P40–P84）**　重宣长行义，自七地修方便慧起，至「若欲次第广分别，经于亿劫不能尽」收束。
- **第九地缘起（P85–P111）**　如来说此菩萨八地时现大神通 → 震动十方、放光照耀 → 菩萨踊空供养 → 大自在王天与众天女奏乐赞叹 → 解脱月请说九地所行道。
- **第九地长行（P112–P120）**　金刚藏告解脱月，按「入地因缘 → 善慧胜用 → 四无碍辩 → 陀罗尼法师 → 答难利生 → 果报胜用」之序展开：
  - 以无量智思量，更求转胜寂灭解脱，修如来智慧、入秘密法、净陀罗尼三昧，入第九善慧地（P113）；
  - 如实知善不善无记乃至有为无为诸法行；知众生心、烦恼、业、根、解、性、乐欲、随眠、受生、习气、三聚差别等「稠林」相，各八万四千（P114）；
  - 善演三乘法，随根性欲解而为说法（P115）；
  - 作大法师，起**四无碍辩**（法、义、辞、乐说），以十门展转分别（P116）；
  - 得百万阿僧祇陀罗尼门，坐法座说法，一音普令大众解了，乃至一毛孔演法音、一微尘出法门（P117）；
  - 一念领受三千乃至不可说世界众生无量问难，一音普释（P118）；
  - 昼夜见佛不离，得说法陀罗尼，善根如真金作宝冠，力波罗蜜最胜，多作二千世界主大梵天王（P119–P120）。
- **第九地偈颂（P121–P169）**　重宣长行，自「无量智力善观察」起，至「我为佛子已宣说」收束。

## 三、关键结论

1. **第八地以「无生法忍」为门，舍功用而入无功用**：菩萨于七地善修方便慧，证一切法本来无生无起无相，离心意识分别，得无生法忍，即入不动地，一切身口意业念务皆息，住于报行。
2. **诸佛劝发是八地转入利他的关键**：菩萨得住寂灭易堕涅槃，诸佛现前以起智门劝发，令其不舍本愿、愍念众生、修集佛法，故能于一念所起智业远胜前七地经无量劫所修。
3. **第八地得十种自在与十种异名**：以善知十身互相作、十自在故，名为不动、不转、难得、童真、生、成、究竟、变化、力持、无功用，入佛境界，梵释四王金刚力士侍卫。
4. **第九地以「四无碍辩 + 陀罗尼」为门，作大法师**：菩萨住善慧地，如实知众生心、烦恼、业、根、解等稠林差别，起法义辞乐说四无碍辩，得百万阿僧祇陀罗尼门，一音普应无量问难。
5. **二地果报皆作大梵天王**：八地主千世界，九地主二千世界，皆能演说三乘、慈光普照除众惑，体现「地高则利他境广」的递进。

## 四、易混辨析

- **无生法忍 vs 无功用行**：无生法忍是八地所证之理（忍可印持一切法本来无生之实相），无功用行是依此理所起之行（任运现前、不加造作）。前者是「所见」，后者是「能行」；得忍即入住不动地，住地即舍功用。
- **八地不动 vs 十地法云**：八地「不动」指离一切相想执着、不为功用所动，偏就「自证寂灭」立名；十地「法云」指法身周遍、雨大法雨，偏就「利他圆满」立名。八地是功用已息之始，十地是功用圆极之终。
- **四无碍辩之「法」与「义」**：法无碍智知诸法自相、自性、现在差别；义无碍智知诸法别相、生灭、过未差别。简言之，「法」就当体自相立，「义」就差别、因果、时处立；辞无碍约言音无错谬，乐说无碍约随乐无尽说。
- **稠林（如心稠林、烦恼稠林）**：喻众生心、烦恼、业、根、解、性、乐欲、随眠、受生、习气等重重交络、难可究尽，如林木稠密；九地菩萨以善慧一一如实了知，故能为众生随机说法。

## 五、阅读提示

读本卷宜抓「地次递进」之脉络：先看八地如何从「功用」到「无功用」、从「自寂」到「佛劝利他」；再看九地如何从「知众生稠林」到「四无碍辩、陀罗尼说法」。两处长行之后各有偈颂重宣，可对照读，颂偈每四句一转，便于记诵。
