# 大方广佛华严经卷第二十八 导读

## 一、内容总览

本卷为《大方广佛华严经·十回向品第二十五之六》，承接前五卷十回向义，广说第六「随顺坚固一切善根回向」的具体行相，并收束于金刚幢菩萨的颂偈重宣。全卷以菩萨摩诃萨「种种布施 → 善根回向 → 无着无缚」一线贯穿：先列十一类布施（叹佛出世、施大地、施僮仆、施身、以身供佛、施身给众生、给侍诸佛、施王位王都、施内宫眷属、施妻子、施舍宅园林、设大施会、施资生具），每一次施皆配「如是回向」之愿；末后总明回向时心无所着、法性本空，并以颂总结菩萨「舍一切而不生取着心」的般若回向义。本卷是十回向品的收束，从「广行布施」转入「三轮体空」，为后「十地」作铺垫。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷按「别举十二类施 → 总说回向无着 → 释名总结 → 颂偈重宣」四段推进：

- **别举布施（P3-P19）**：每段用「佛子！菩萨摩诃萨……如是回向，所谓：『愿一切众生……』」的固定程式展开 → 以「何等布施 → 善根回向 → 为令众生……故」三段式收束。
  - P3 叹佛出世回向 → P4 施大地 → P5 施僮仆 → P6-P9 以身布施（施乞者/供佛/施众生/给侍佛）四组递进 → P10-P11 施王位王都 → P12 施内宫眷属 → P13 施妻子（举须达拏太子等本生例）→ P14-P15 施舍宅园林 → P16 设大施会 → P17-P18 施一切资生具与随求给济。
  - 层次推进：外财施（地、仆、城、宫、妻、宅、园、大会）↔ 内身施（身、命、给侍）↔ 法施（叹佛、闻法供养），内外财法交替铺陈，显示「一切皆舍」之广。
- **总说回向无着（P19-P20）**：以「非想非非想」「不着色，不着色生灭」「无有少法可取可着」一串否定 → 显三轮体空；复以「永度世间乃至永出世法」十句释「回向」名义 → 「则为随顺佛住……」十随顺收束。
- **释名总结（P21）**：「是为菩萨摩诃萨第六随顺坚固一切善根回向」一句结归本位，明其坚固不退、诸佛护念。
- **颂偈重宣（P22-P23）**：金刚幢菩萨入字句甚深义、承佛神力说颂 → 将前散说重摄为偈颂，自「菩萨现身作国王」至「常于世间无退转」，重申菩萨行施、回向、观法性空三大主题。

## 三、关键结论

1. 第六回向以「随顺坚固一切善根」为名，核心是菩萨于一切施中「心无中悔、无取着」而坚固不退，所集善根尽回向一切智、回向众生。
2. 每一类布施后皆以「愿一切众生……」十愿（或更多）回向，显示回向的所缘是众生与佛果双轨，而非自求果报。
3. 回向的终极相状是「无着无缚」：无众生想、无人我想、非想非非想、不着色受想行识及其生灭——三轮本空，方为真实回向。
4. 「不断诸业道，不舍菩萨行」与「了知诸业其用广大，解一切法皆无所作」并行：空性不坏业果，业果不碍空性，是华严理事无碍义在回向中的具体体现。
5. 一切回向即随顺三世诸佛所行，「如三世佛所回向，菩萨亦修如是业」，回向即与诸佛平等。

## 四、易混辨析

- **菩萨摩诃萨 vs 菩萨**：经中通称「菩萨摩诃萨」，「摩诃萨」意为「大」，特指已发大心、行大道、堪任大位的地上菩萨，与一般发心菩萨有别；本卷反复用此全称，强调行第六回向者是大乘胜位菩萨。
- **回向 vs 随顺坚固一切善根回向**：「回向」是通名，将己善根转向他处、趣向佛果；本卷特标「第六」之专名，强调「随顺（诸佛教法）+ 坚固（不退）+ 善根（一切施等）」三层内涵。
- **内财施 vs 外财施**：外财指地、宅、城、妻子、僮仆、资具等身外之物；内财指身、命、血肉骨髓。本卷 P6-P9、P13、P23 偈中「施头施眼施手足」皆属内财施，与外财施交替，显施之究竟。
- **非想非非想 vs 三界非想非非想处**：经中「非想非非想」是般若否定句式（「无有想、无无想……非想非非想」），破一切相执；非指无色界最高处之非想非非想天，二者同名异实，须依上下文辨。
- **三轮体空 vs 断灭空**：本卷明「无有少法可取可着」「法性非有亦非无」，然同时「不断诸业道，不舍菩萨行」「业理次第终无尽」——空而不断、有而不着，不同于外道断灭见。

## 五、阅读提示

读本卷可抓「布施—回向—无着」三段式程式：每一段施事之后必有一组「愿一切众生……」回向，再以「为令众生……故」收束；读回向愿时留意其愿所缘（众生与佛果），读末段无着时留意「非……非……」与「不着……不着……」的双重否定结构，这是般若空义在华严回向品中的典型表达。
