# 大方广佛华严经卷第四十四 词语注释

〔1〕 实叉难陀　于阗国高僧（652-710），本八十卷本《华严经》的译者；「三藏」指精通经律论三藏的法师，「奉制译」谓奉皇帝敕命翻译。
〔2〕 十通品　品名。「通」即神通，神妙通达无碍的作用；本品说菩萨的十种神通，境界远超声闻六通。
〔3〕 普贤菩萨　华严会上的主菩萨，代表「普贤行」；本卷十通、十忍两品皆由他向众菩萨宣说。
〔4〕 十种通　名数清单：他心智通、天眼智通、宿住随念智通、知尽未来际劫智通、天耳智通、住无体性神通、分别言音智通、无数色身智通、一切法智通、灭尽三昧智通；读法是每段抓住「是名……第X……神通」的总名即可。
〔5〕 他心智通　能如实了知一切众生心念差别的神通。
〔6〕 三千大千世界　一个须弥山世界为一小世界，千个小世界为小千，千个小千为中千，千个中千为大千；泛指一佛所教化的国土范围。
〔7〕 所谓　提示下文列举的引导词，相当于「即是、那就是说」。
〔8〕 独觉　即辟支佛：无师独悟、观十二因缘而得道的圣者，出无佛世，不广为他说法。
〔9〕 夜叉　八部鬼神之一，捷疾能飞的鬼类，已受佛化、为护法众。
〔10〕 乾闼婆　八部众之一，帝释天的乐神，不食酒肉、唯以香气滋养，故译「香神」。
〔11〕 阿修罗　八部众之一，果报似天而无天德、好斗多嗔的神类。
〔12〕 迦楼罗　八部众之一，即金翅鸟，翅翼金色，以龙为食，后皈依佛法。
〔13〕 紧那罗　八部众之一，歌神，形貌似人而头上有角，故称「疑神」。
〔14〕 摩睺罗伽　八部众之一，大蟒神，人身蛇首，亦是护法乐神。
〔15〕 阎魔王处　阎魔王即阎罗王，审断亡者罪福、治理地狱饿鬼之神；此处指生死流转中相关的众生心类之一。
〔16〕 那由他　梵语音译的巨大数名，义为亿或万亿，形容极多。
〔17〕 佛刹微尘数　把一个佛国土碾碎为微尘，一尘作一数；佛经中形容多到无法计量的惯用语。
〔18〕 善趣　「趣」谓投生去处；善趣指天、人等善道，与恶趣（地狱、饿鬼、畜生）相对。
〔19〕 宿住随念智通　「宿住」即过去世的经历住处；随念谓随顺忆念。此通能忆知自身及一切众生无量过去世之事。
〔20〕 结使　烦恼的别名；烦恼缠结众生、驱使众生流转生死，故名结使。
〔21〕 尔所　文言指示词，谓「这么多」，指前文所说的微尘数之量；「尔所劫」「尔所佛刹」即那么多劫、那么多佛刹。
〔22〕 最胜二大弟子　指每位佛座下最殊胜的两位弟子，如释迦牟尼佛的舍利弗与目犍连。
〔23〕 无余依般涅槃界　即无余依涅槃：烦恼与所依之身都灭尽的究竟涅槃，与身尚存的有余依涅槃相对；「界」谓境域。
〔24〕 般涅槃　梵语 parinirvāṇa 音译，「般」义为入，即入涅槃、圆寂。
〔25〕 邪定　众生三品类之一：邪定聚必入邪途，正定聚必入正道，余为不定；此处列举未来众生善根、罪业种种差别。
〔26〕 与使俱　「使」即烦恼随眠；「善根与使俱」谓善根与烦恼相杂而起，与「不与使俱」（善根离染清净现前）对举。
〔27〕 四维　东南、西南、东北、西北四个隅角方向；与四方及上、下合称十方。
〔28〕 无体性神通　本段连举无体性、无作、平等、广大……随诣等十四种神通名目，而总名是「住无体性无动作往一切佛刹智神通」；读法抓住总名即可，诸名目皆形容其以无体无作为体。
〔29〕 不动本处　身不离原处而能现身他方；与「而见其身在彼佛所」连读，即所谓「无往而往」的神通境界。
〔30〕 性欲　「性」指众生根性禀赋，「欲」指意乐偏好；谓菩萨能随众生根性欲乐而为之说法。
〔31〕 阿僧祇　梵语 asaṃkhya 音译，义为无数量，印度数目的极名。
〔32〕 无边色　自「无边色」至「具足一切普贤行色」，列举百余种色身名目，皆标举菩萨无数色身的功德相；读法是每条抓「某某色」二字领起即可，不必逐条求解。
〔33〕 瑕翳　翳音 yì；瑕是玉的斑痕，翳是遮光的障膜。「离瑕翳色」喻色身纯净无疵、无障蔽。
〔34〕 随好　梵语 anuvyañjana，佛身八十种细微好相，随从三十二大人相而显现，故名随好。
〔35〕 磨莹　莹音 yíng，磨治珠玉使生光泽；「善磨莹色」喻色身如磨光之宝，洁净明彻。
〔36〕 譬谕　「谕」同「喻」；「过诸譬谕色」谓此色身之美超过一切比喻所能形容。
〔37〕 华鬘　「华」即花；鬘音 mán，串编花朵而成的花环，古印度用以庄严身首。
〔38〕 无有种性　本段以「无有名字、无有种性，无来无去，非异非不异……」等数十重双遣两边的话说一切法之空性；读法须知其皆在否定对待分别，不是下定义。
〔39〕 第一义　即胜义谛、真谛，诸法究竟真实之理；「不取世俗谛，不住第一义」谓真俗二边俱不住着。
〔40〕 降霔法雨　霔音 zhù，同「澍」，及时雨；「兴布法云、降霔法雨」谓普施教法如云布雨降，润泽众生。
〔41〕 灭尽三昧　即灭尽定，灭尽一切心与心所的深定；此处「一切法灭尽三昧」谓于定中了达一切法寂灭，而仍不废菩萨行、大悲度生之事。
〔42〕 波罗蜜　梵语 pāramitā 音译，义为「到彼岸」，谓菩萨所修之行能度越生死此岸而至涅槃彼岸。
〔43〕 佛种性　「种性」（梵语 gotra）谓成佛的种子族类；「入佛种性」谓进入决定成佛之流。
〔44〕 羸瘦　羸音 léi，瘦弱；谓菩萨入定虽经尔所劫而身体不离散、不消瘦、不变异。
〔45〕 十忍品　品名。「忍」谓于法深信忍可、安住不动的智慧；本品说菩萨十种忍，由普贤菩萨宣说。
〔46〕 音声忍　十忍之一：闻诸佛深法（音声教法）不惊不怖不畏，深信悟解、安住修习。
〔47〕 顺忍　十忍之二：于诸法思惟观察、随顺无违，令心清净而趣入成就。
〔48〕 无生法忍　十忍之三：忍可印证诸法本自无生；下文以「无生则无灭，无灭则无尽……无来无去」层层推衍其理。
〔49〕 如幻忍　十忍之四：了知一切法皆如幻师所变，从因缘起而无一实物，于一多相即而无碍。
〔50〕 如影忍　十忍之八：了知菩萨之身如影，如影现于水镜油中而无所染，于无二法中善巧分别二相。
〔51〕 如化忍　十忍之九：了知世间出世间一切皆如幻化所现，无实生灭，而菩萨所行亦如化而无舍。
〔52〕 如空忍　十忍之十：以虚空为喻，了一切法界、世界、众生行、佛法、佛身皆如虚空，无相无起而无碍。
〔53〕 何以故　文言设问语，「为什么这样说呢」；下文即自问自答申明理由。
〔54〕 成就蕴　「蕴、处」即五蕴（色受想行识）与十二处（六根六境），代指身心构成要素；「虽成就蕴处而永断所依」谓虽现起蕴处之身而不执为实所依。
〔55〕 阳焰　春日旷野上因日光蒸动而现的水气幻影，渴兽误以为水；经中以之喻世间虚妄无实，即「如焰忍」所观之境。
〔56〕 谷响　山谷回声，从缘而起、无来无去；喻一切音声皆如空响而非实有。
〔57〕 舍支　又作舍脂，帝释天正夫人、阿修罗王之女；传说她一音中能出千种音声，此处喻菩萨说法一音随类、各得解了。
〔58〕 广长舌相　佛三十二相之一：舌广长柔软，能覆面至发际，表语业清净、出言真实。
〔59〕 法流　谓圣道之法相续不断如流水；「不随世间流，亦不住法流」谓染净两边俱不住着。
〔60〕 揽触　揽音 lǎn，持取；「不可揽触」谓化事虚幻，无从捉执触碰。
〔61〕 化士　幻术师所变化之人；喻菩萨「虽无有身而现一切身」，于诸佛刹无所依住。
〔62〕 铁围　铁围山，环绕大咸水海最外层的山；与「须弥」连用，谓佛世界中心与外围的大山也不能障碍菩萨之身。
〔63〕 无隅　隅音 yú，角落；虚空无方无隅却能显现无边方隅，喻菩萨无业无报而能显示种种业报。
〔64〕 劫火　坏劫时烧毁世界的大火；谓如虚空不为劫火所烧，喻菩萨坚固之身不可破坏。
〔65〕 善轭　轭音 è，驾车时套在牲口颈上的曲木；「不舍众善轭」谓如牛负轭不弃，喻不舍种种善法而行精进。
〔66〕 三十三天　即忉利天，帝释天所居；中央一天、四方各八天，合为三十三。颂中借其共器而食喻业感差别。
〔67〕 共同一器食　偈颂难点：三十三天诸天子由共业福报同用一器进食，而各人所尝滋味随自业不同——喻同处一境界而受用千差，皆由业别，不由外来。
〔68〕 自然咸在器　「咸」谓皆、都；谓三十三天子所食随其自业，自然而然都现于器中，不从十方而来。
〔69〕 授记　佛为修行者预先记别其将来成佛之时节、名号、国土；颂谓菩萨住此忍时普见诸佛同时授记。
〔70〕 受佛职　「职」谓职位；受佛职即绍继佛位，如第十地菩萨受灌顶位而堪成佛，故云「斯名受佛职」。
〔71〕 工幻师　技艺精巧的幻术师；颂文以幻师变现色像而毕竟无所得，喻世间诸法如幻。
〔72〕 戏论　无实义、由虚妄分别增益的言论与观念；「寂灭无戏论」谓离一切妄分别而入实相。
〔73〕 憍慢　憍音 jiāo，自恣高举；憍慢即骄矜傲慢之心，应除灭之烦恼。
〔74〕 无言际　言说之外的境地，即「言语道断」之处；「善入无言际，而能示言说」谓入于无言而能普现言说，如响应物。
〔75〕 调御师　佛十号之一「调御丈夫」，谓能以种种方便调伏制御众生者；颂中「调御师智海」即指佛的智慧深广。
〔76〕 刹尘　「刹」即佛国土；国土碎为微尘之数，形容无量无边。颂谓众生数与刹尘数尚可计算，菩萨功德则不可测其限量。
