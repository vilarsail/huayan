# 大方广佛华严经卷第四十四 词语注释

① 普贤菩萨摩诃萨　本卷说法主，华严经中表「大行」的菩萨，此处为诸菩萨宣说十通与十忍。
② 菩萨摩诃萨　「摩诃萨」意为「大」，即大菩萨，指已达地上、行愿广大的菩萨。本卷十通、十忍皆为其所修所证。
③ 他心智通　十通第一，能知他众生心之种种差别相，从善心、不善心到天、龙、夜叉等心皆悉分别了知。
④ 三千大千世界　一佛所教化的范围，即一须弥山日月所照为一小世界，千倍递进成中千、大千，合称三千大千世界。
⑤ 那由他　梵语数量词，意为极多，约当千亿或万亿。文中常与「百千亿」连用以显数量广大。
⑥ 佛刹微尘数　华严常用极大数，谓将一佛刹（一佛国土）碎为微尘，一一尘皆为一数。表不可说不可说之极多数。
⑦ 无碍清净天眼智通　十通第二，能无碍明见众生死此生彼、善恶趣、福罪垢净等相，乃至佛刹微尘数世界中众生。
⑧ 宿住随念智通　十通第三，能知自他过去无量劫中宿命之事，乃至诸佛名号、众会、说法、涅槃后法住久近皆悉忆念。
⑨ 劫　梵语「劫波」之略，极长的时间单位。文中以「不可说不可说佛刹微尘数劫」表时间之极长远。
⑩ 使　随逐众生、使令系缚的烦恼异名，即随眠。文中「善根与使俱」指善根犹为烦恼所杂。
⑪ 无余依般涅槃界　即无余涅槃，指佛灭度后烦恼与身智皆尽、无所依余的究竟寂灭境界。
⑫ 般涅槃　梵语，意译入灭。佛依无余依般涅槃界而般涅槃，即入于无余涅槃，永尽烦恼、不余身智。
⑬ 法住　佛涅槃后，教法住世的时间。文中「法住久近」谓灭后正法住世久暂，菩萨皆能忆知。
⑭ 善根　能生善法之根，指无贪无嗔无痴等善法及所修福慧。文中多次辨「善根与使俱」「具足善根」「摄取善根」等差别。
⑮ 知尽未来际劫智通　十通第四，能知尽未来际一切劫中众生受生、业行果报，乃至诸佛发心修行入灭等事。
⑯ 邪定　三定之一，谓众生根性决定趣于邪、不决定出离者；与正定、不定相对，菩萨于尽未来际皆能了知。
⑰ 正定　三定之一，谓根性决定趣向正道、必能出离者。
⑱ 无碍清净天耳　十通第五所依之天耳根，圆满广大、聪彻离障，于一切音声欲闻不闻随意自在。
⑲ 住无体性无动作往一切佛刹智神通　十通第六，菩萨闻远世界中佛名即不动本处而见身在彼佛所，经无量劫普至十方而无所往。
⑳ 善分别一切众生言音智通　十通第七，能了知不可说世界中众生种种言辞，随其性欲为出言辞令其解了。
㉑ 阿僧祇　梵语数量词，意为无量数，表极大。「出生无量阿僧祇色身庄严智通」即十通第八。
㉒ 色身　指佛菩萨物质形态的身相。十通第八名「出生无量阿僧祇色身庄严智通」，谓能现种种色身度生。
㉓ 法界　华严核心法相，指一切法的真如实性，诸法本源。菩萨深入无色法界而能现种种色身。
㉔ 一切法智通　十通第九，了知一切法无名字、无种性、不生不灭、一相无相等，而以方便辩才随义开演。
㉕ 第一义　即胜义谛，指诸法究竟实相、离言绝相的绝对真理。文中「不住第一义」显菩萨不取理证。
㉖ 世俗谛　二谛之一，指世间因缘和合、名言施设的相对真理；与「第一义谛」（胜义谛）对举。
㉗ 一切法灭尽三昧　十通第十所入之三昧，念念入一切法灭尽定而不退菩萨道，可住一劫乃至不可说不可说劫。
㉘ 三昧　梵语，意译「正定」，谓心一境性。十通第十、十忍所依之定慧境界。
㉙ 波罗蜜　梵语，意译「到彼岸」，指菩萨所修的六度（或十度）等究竟之行。文中「修习波罗蜜未尝休息」。
㉚ 十忍　本卷所明菩萨十种忍：音声、顺、无生法、如幻、如焰、如梦、如响、如影、如化、如空。得此忍即到无碍忍地。
㉛ 音声忍　十忍第一，闻诸佛所说深法不惊不怖不畏，深信悟解，爱乐趣向，修习安住。
㉜ 顺忍　十忍第二，于诸法思惟观察平等无违，随顺了知令心清净，正住修习趣入成就。
㉝ 无生法忍　十忍第三，不见有少法生、亦不见有少法灭，亲证一切法本无生灭之实相，为十忍之枢纽。
㉞ 如幻忍　十忍第四，了知一切法皆如幻从因缘起，于一法解多法、多法解一法，成就神通变化。
㉟ 如焰忍　十忍第五，知一切世间同于阳焰，无有方所、非有非无，但随世间言说显示。
㊱ 如梦忍　十忍第六，知一切世间如梦，非世间非离世间，非三界而有示现，梦体本无生灭方所。
㊲ 如响忍　十忍第七，知一切音声悉同于响（回声），无来无去，虽无所说而广说诸法，随类各解。
㊳ 如影忍　十忍第八，菩萨如影普现，非于世间生没、非内非外，于一身中现差别身，别与不别无所障碍。
㊴ 如化忍　十忍第九，知一切世间皆悉如化，意业、诸行、苦乐、烦恼乃至如来大悲皆化所现，非有非无。
㊵ 如空忍　十忍第十，了一切法界、世界、法、众生行、佛等皆如虚空，无相无起无二，得如虚空身语意业。
㊶ 阳焰　即「如焰」之焰，谓春日旷野中远看似水、近之则无的光影，喻世间诸法现而非实。
㊷ 舍支　帝释夫人阿修罗女之名，能于一音中出千种音而不作意，喻菩萨随类音声自在。
㊸ 广长舌相　佛三十二相之一，舌覆面至发际，表语言真实。菩萨亦以广长舌相普演法音。
㊹ 授记　佛对菩萨作未来成佛之记莂（预言）。颂中「普见诸如来，同时与授记，斯名受佛职」即指十忍位菩萨受佛职位。
