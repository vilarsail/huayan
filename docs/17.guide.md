# 大方广佛华严经卷第十七 导读

## 一、内容总览

本卷含两品：《梵行品第十六》之末段与《初发心功德品第十七》全文，由法慧菩萨为正念天子与天帝释两番请问而说。前半「梵行清净」以十法（身、身业、语、语业、意、意业、佛、法、僧、戒）为所缘，逐一勘破「何者是梵行」之执，归于无相、无二、平等；复说修习如来十力，了知境界如幻梦，初发心时即得阿耨多罗三藐三菩提。后半「初发心功德」则借天帝之问，以一连串极度夸张的譬喻（供养十方众生、教令持戒修定证果、过不可说世界、知劫数、知众生根欲方便心业烦恼、起塔供养诸佛）层层衬托：菩萨初发菩提心之功德，百分千分乃至优波尼沙陀分亦不及一；末以十方诸佛同名法慧现身印证、六种震动、雨华庄严，并由法慧以长偈重颂初发心之广大境界。全卷一线贯穿：**以无所得为方便修梵行 → 以无齐限发心契法界 → 即心自性、不由他悟**。

## 二、结构层次

- **梵行清净（破执层）**：先立「十法为所缘」→ 再以「若身是梵行耶……乃至戒是梵行耶」之连环诘问，将身业、语业、意业乃至佛、法、僧、戒逐一勘验，显其皆非梵行本体 → 归结「三世皆空、无作无受、此世不动彼世不变」 → 由「不可得」而入「清净梵行」。
- **修习十力（承启层）**：由梵行清净转入修习如来十力 → 一一咨问、起大慈悲、观法如幻 → 收束于「初发心时即得阿耨多罗三藐三菩提，知一切法即心自性，成就慧身，不由他悟」，自然过渡到初发心主题。
- **初发心功德·校量层（叠喻递进）**：天帝问「功德几何」→ 法慧先以「难」字十叹显深 → 继以两大譬喻（供养十方众生一劫持戒；供养十方十阿僧祇世界众生百劫乃至百千那由他亿劫修十善、四禅、四无量、四无色定、四果、辟支佛道）层层叠加 → 一律以「百分千分……优波尼沙陀分亦不及一」收束，凸显发心功德不可称量。
- **初发心功德·展转譬喻层（世界/劫/解/根/欲/方便/心/业/烦恼九番）**：自「过世界」起，九类所缘皆设十人展转、十方齐说，所知各有边际而发心善根无际 → 每番末以「菩萨不齐限，但为知尔所……故发心；为尽知……故发心」点明：发心非为限量所知，乃为尽知法界、度尽众生。烦恼一番特详，列出轻/重/眠/起、无明/爱、贪瞋痴/等分、我/我所/我慢、颠倒分别生/身见六十二见、盖/障诸烦恼网。
- **供养譬喻与发心体性（归宿层）**：复以十人展转供养诸佛众生、起塔庄严之大喻 → 转入「菩萨摩诃萨不齐限，但为供养尔所佛故发心；为供养尽法界虚空界不可说诸佛故发心」 → 列「为不断如来种性」等十一种发心因缘 → 显发心已即与三世诸佛同等、得如来一身无量身、即于三世少无所得，唯求一切智。
- **瑞相印证与长偈重颂（收束层）**：十方各万佛刹微尘数世界六种震动、雨天华香盖 → 十方同名「法慧」之佛现身印证，授记万佛刹微尘数菩萨同劫成佛号「清净心如来」 → 法慧普观众会，以长偈重颂初发心广大境界，归宗于「欲知一切诸佛法，宜应速发菩提心」。

## 三、关键结论

1. 梵行清净不在事相上求，而在以十法为所缘、层层勘破能所，达三世空寂、无作无受、所行无二、方便自在，方名清净梵行。
2. 初发心功德非世间善法（持戒、四禅、四无量、四无色定、四果、辟支佛道）所能校量，乃至优波尼沙陀分亦不及一，以发心所缘为尽法界、尽众生、尽诸佛种性故。
3. 发心之量无齐限：非为一方一界一劫一众生，乃为悉知一切世界成坏、众生垢净、根欲心业烦恼、三世诸佛境界平等，故其功德无可测度。
4. 初发心时即与三世诸佛同等：能信、能受、能修、能得、能知、能证、能成就诸佛功德，以「知一切法即心自性、成就慧身、不由他悟」为体。
5. 十方诸佛同名法慧共说此法、现身印证授记，显此「初发心功德」为十方三世一切诸佛所共说、共护念、共庄严之法界同体法门。

## 四、易混辨析

- **梵行 vs 戒**：戒是十法所缘之一（坛场、问清净、教威仪、三说羯磨、和尚、阿阇梨、剃发、袈裟、乞食、正命等事相），梵行则以十法为所缘、勘破能所所显之清净无相行；戒为入门，梵行为究竟清净。
- **菩萨初发心 vs 菩萨摩诃萨**：本卷「初发心功德」重在「初发菩提心」之因位功德，其量已不可测；「菩萨摩诃萨不齐限」则就地上大行而言，强调发心所缘无有限量。二者一体：初发心即趣向摩诃萨之大行。
- **须陀洹/斯陀含/阿那含/阿罗汉 vs 辟支佛**：前四为声闻四果（预流、一来、不还、应供），辟支佛为无佛世自悟之独觉；本卷将此五者并列为世间所能证之极果，用以反衬发心功德远超三乘出世间法。
- **那由他 vs 阿僧祇 vs 优波尼沙陀**：阿僧祇为「无数」，那由他为其倍数级之「亿那由他」大数，优波尼沙陀则极言其细分（析尘为分），三者层层递降用于校量，皆为不可数之喻，递显发心功德不可比。

## 五、阅读提示

读本卷可带着两个问题：其一，法慧何以用「若身是梵行耶」这种近乎否定一切的方式定义梵行？其二，初发心何以功德超过教化十方众生证四果辟支佛？把握「无所得为方便」与「所缘无齐限」两条线索，便知本卷不是在比数字大小，而是在显发心之体—即心自性、即法界、即诸佛之母。
