# 大方广佛华严经卷第五十六 导读

## 一、内容总览

本卷为《大方广佛华严经》「离世间品第三十八之四」，承接前三卷普慧菩萨二百问、普贤菩萨两千答的结构，继续以「佛子！菩萨摩诃萨有十种……」的格式逐一展开菩萨行门的种种功德差别。本卷主旨是广说菩萨在因位所修所证的「十种」行相——从「无碍用」到「决定解知众生界」，统摄境、行、果三轮，尽显菩萨「不舍世间、不住生死」的中道大用。全卷二十余组「十法门」层层递进，由作用（无碍用、游戏）而体性（境界、力、无畏、不共法），再由身语意业（身、身业、语、净修语业）到心行根本（心、发心、周遍心、根、深心、增上深心、勤修、决定解），最后收束于对「世界」「众生界」的了知，圆满收摄一切所化之境。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷以「无碍大用 → 自在游戏 → 体性功德 → 身语意业 → 心行根本 → 所知境界」六大板块一线贯穿，每组法门皆以「佛子！菩萨摩诃萨有十种……何等为十？所谓……是为十。若诸菩萨安住此法，则得如来无上……」为固定句式作总—分—结：

- **无碍用十门（P3-P15）**：先总标十种无碍用（众生、国土、法、身、愿、境界、智、神通、神力、力），再逐一展开 → 以「得此十无碍用者，于阿耨多罗三藐三菩提欲成、不成，随意无违」收束，点出无碍之根源在大愿善巧示现。
- **游戏、境界、力、无畏（P16-P19）**：由「用」转入「相」——菩萨以一身现一切身而不坏本形谓之「游戏」；进而开示「境界」「力」与十种「无畏」（每条皆以「作如是念……以不见故，心得无畏」反复申明，对治菩萨行中一切疑怯）。
- **不共法十门（P20）**：以「不由他教」贯穿十法（六度、四摄、回向、方便、权实双行、三业随智、大悲、众生乐见、不失一切智心宝、不离善知识），凸显菩萨异于二乘、凡夫的「不共」特质。
- **身、语、业三业（P21-P28）**：列举十种业、十种身（不来不去等）、十种身业、复十种身（波罗蜜、四摄、大悲等）、十种语、净修语业十事 → 得守护 → 成办大事，形成「修因 → 得护 → 成果」的因果链。
- **心行根本（P29-P36）**：从「十种心」（如大地、大海、须弥等喻）到「发心」「周遍心」「根」「深心」「增上深心」「勤修」「决定解」，由浅入深、由相归性，层层说明菩萨心行的体性与差别。
- **所知境界收束（P37-P38）**：最后以「决定解知诸世界」「决定解知众生界」两组十法门收束全卷——菩萨一切修行终归于「了知所化之境」，世界、众生皆摄入一毛孔、一身、一音，圆融无碍，呼应卷首「无碍用」之旨。

## 三、关键结论

1. 菩萨以「十无碍用」于众生、国土、法、身等十境自在无碍，其根本在「发大誓愿，入无边无碍用门，善巧示现」——非由智力独擅，实由愿力成就。
2. 十种「游戏」揭示菩萨化他自在之相：一身现一切身而互不坏乱，生死涅槃两不相舍，显示「不坏假名而证实相」的中道妙用。
3. 十种「无畏」皆以「作如是念：不见……相」为能破之因——菩萨之所以无畏，不在外求护佑，而在内观空寂、不见可怖可损之相。
4. 十种「不共法」以「不由他教」贯穿，凸显菩萨行异于二乘凡夫的独有特质：自觉修行六度、权实双行、不舍众生、处染不染。
5. 全卷由「用」到「相」到「体」到「心」到「境」，最终以「知世界」「知众生界」收束——菩萨一切行门终归于圆满了知所化境，故能于一尘一毛普现一切世界众生。

## 四、易混辨析

- **无碍用 vs 游戏**：无碍用偏就「作用无障」立名，侧重菩萨功德之用（能化他、能动刹等）；游戏偏就「现身自在、彼此不坏」立名，侧重菩萨化他之相（于一身现一切身而互不损）。前者约「能」，后者约「相」。
- **十种身（不来不去等）vs 复十种身（波罗蜜等）**：前者约「法身理体」立名，显其不生不灭、不坏不动之性；后者约「修因所感之身」立名，显其由六度、四摄、大悲等行所成之用身。一约理体，一约行用。
- **深心 vs 增上深心**：深心指菩萨内心「不染世间、不杂二乘」的清净意乐；增上深心则在深心基础上更进一层，约「积集善根、解如来密语、普入法门」等「增上」差别立名，侧重由深心所起的殊胜力用。
- **境界（P10无碍用中）vs 境界（P17）**：前者属「无碍用」门下，侧重菩萨住于佛境界而不舍魔境界、住涅槃而不舍生死之「无碍」作用；后者独立列门，侧重「示现无边法界门令众生得入」等「化他境界」之相。

## 五、阅读提示

本卷属典型的「十法门」广说体例，阅读时不必逐一记诵十项差别，宜抓三要点：一辨每组「十」的「立名角度」（约用、约相、约体、约心、约境）；二看每组结尾的「若诸菩萨安住此法，则得如来无上……」收束句，即此法门所趣之果；三留意「无畏」「不共法」两组中反复出现的「作如是念」「不由他教」等关键句，这是菩萨「内观空寂而外行大悲」的行相所在。
