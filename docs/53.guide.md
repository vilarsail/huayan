# 大方广佛华严经卷第五十三 导读

## 一、内容总览
本卷是《大方广佛华严经》「离世间品第三十八」之首卷（之一），承前「十定品」「十通品」「十忍品」等菩萨行位之后，转入对菩萨「行法」的总体宣说。全卷以普贤菩萨在普光明殿入「佛华庄严」三昧、起已答普慧菩萨之问为线索，借「十十相扣」的问答体，集中铺陈菩萨摩诃萨从「依、行、善知识」直至「变化、力持」等一系列修法名目，揭示大乘菩萨行如何在世间发起、又如何不著世间而契入佛智，故名「离世间」——非离世间别求出离，即世间而离世间。

## 二、结构层次（文章的骨架与逻辑推进）
全文按「序分 → 蹑问 → 答十十法」三段推进：

- **序分（P3-P4）**：先立「处、佛、众」三缘 → 摩竭提国阿兰若法菩提场普光明殿、莲华藏师子座、佛之德相 → 与不可说微尘数菩萨俱，皆一生补处、具菩萨方便智慧 → 普贤入「佛华庄严」广大三昧，地动、出声而起，显示此品由「定中流出」。
- **普慧总问（P5）**：以一段极长句一口气抛出近二百个「何等为……」之问 → 总括从「依、奇特想、行、善知识」到「身语意业、四无量、四谛义法、魔与佛业、兜率降生乃至成道转法轮涅槃」全谱，等于一张菩萨行法的总目录。
- **普贤别答（P6-P47）**：自「十依」起，每段以「佛子！菩萨摩诃萨有十种X」开头，作「十X → 十一种相 → 收束利益」的固定格式 → 依次答出：依→奇特想→行→善知识→勤精进→心得安隐→成就众生→戒→受记→入菩萨→入如来→入众生行→入世界→入劫→说三世→知三世→无疲厌心→差别智→陀罗尼→说佛→普贤心→普贤行法→起大悲→发菩提心因缘→尊重善知识心→清净→波罗蜜→智随觉→证知→力→平等→佛法实义句→说法→持→辩才→自在→无著→平等心→出生智慧→变化→力持。
- **逻辑推进走向**：由「立所依」→「发心行」→「入佛入众生入世界入劫」之三类「入」（理事、自他、时空并举）→「陀罗尼、佛、普贤心行」之果地体相 → 「起悲、发心因缘、清净、波罗蜜」之因行 → 「智、力、平等、实义、辩才、自在、无著」之德用 → 「出生智慧、变化、力持」之利他妙用。三段收束皆归「疾得满足普贤行愿」「得如来无上大智」之类，显示全卷以「普贤行愿」为宗。

## 三、关键结论
- 菩萨行虽名目繁多，统归「依菩提心、依善知识、依波罗蜜、依大愿」之所依，依立则行立。
- 「十种入」含入三世、入众生、入世界、入劫，明菩萨行即于一念中周遍三世十方，时劫可即非劫，显华严十玄无碍义。
- 「佛」有十种（成正觉佛、愿佛、业报佛、住持佛、涅槃佛、法界佛、心佛、三昧佛、本性佛、随乐佛），示佛非独色身，法界、心、三昧、本性皆是佛，破一佛之执。
- 「平等」与「无著」反复出现：于众生、法、刹、愿、波罗蜜、行、佛皆平等，于世界、众生、法、所作、善根、受生、愿、行、菩萨、佛皆无著，二者互为表里。
- 「佛法实义句」归结为「一切法但有名、如幻、如影、缘起、业清净、文字所作、实际、无相、第一义、法界」十句，是全卷对法性的最简括表达。

## 四、易混辨析
- **普贤心 vs 普贤行法**：前者是「发心」——发大慈、大悲、一切施、念一切智为首等十种心，重在「立志」；后者是「行法」——愿住未来一切劫、愿供养未来一切佛等十种愿行，重在「履愿」。心为行之体，行为心之迹。
- **十依 vs 十奇特想**：「依」是菩萨所立足处（菩提心、善知识、波罗蜜等）；「想」是菩萨面对一切法时的心态转换（于一切善根生自善根想、于一切众生生菩提器想），一为外缘安立，一为内心观照。
- **说佛（十种佛）vs 见佛**：本卷「说十种佛」列佛的体相差别（成正觉、愿、业报、住持、涅槃、法界、心、三昧、本性、随乐），是佛之「类别」；「见佛」属后文所问，是行者之「观见」。
- **波罗蜜 vs 普贤行**：「十波罗蜜」（施、戒、忍、精进、禅、般若、智、愿、神通、法）是行门分类；「普贤行法」是此诸波罗蜜在普贤愿海中的展开，偏重「愿」的贯摄。

## 五、阅读提示
读本卷宜抓住「十十相扣」之骨架，不必逐项记忆；可留意每段结尾的收束句，皆指归「如来无上大智」「普贤行愿」，即知全卷以「普贤行愿 → 入佛智」为宗。又可对照后卷普慧之问续答（如四无量、四谛、佛业等），本卷乃其总序。
