# 大方广佛华严经卷第二十二 词语注释

① 兜率陀天　欲界第四天，意为知足天，补处菩萨所居。本卷为如来升此天宫说法之处。
② 摩尼藏　摩尼为如意宝珠，藏指宝聚。摩尼藏师子座即以如意宝聚所成之佛座。
③ 那由他　极大数名，通常指千亿乃至更大之数，经中常与阿僧祇连用表无量。
④ 阿僧祇　梵语 asaṃkhyeya，意为无数、无央数，为菩萨行位中所历劫数之极。
⑤ 栴檀　梵语 candana，香木名，有白檀赤檀等，焚烧或涂身能去秽净心。
⑥ 频婆　频婆果之色，赤润可爱，此处指频婆色宝帐，以果色形容宝之赤红。
⑦ 因陀罗　梵语 Indra，即天帝释。因陀罗金刚宝、因陀罗摩尼宝，指帝释所持之宝。
⑧ 毗卢遮那　梵语 Vairocana，意为遍一切处，佛之法身、报身通名。毗卢遮那摩尼宝，指光明遍照之宝。
⑨ 阎浮檀　阎浮树河边所出之金，色赤黄，为世间最胜金。阎浮檀摩尼宝指此金色宝。
⑩ 阿楼那香　天界一种甘美之香，香气普熏，味甘如蜜。
⑪ 拘苏摩华　梵语 kokoma，意译为团花或妙意花，天界所生之华，色香俱美。
⑫ 波头摩华　梵语 padma，红莲华，又作钵头摩，为八莲华之一。
⑬ 优钵罗华　梵语 utpala，青莲华，又作优钵罗，色青味香。
⑭ 拘物头华　梵语 kuṃmuda，白莲华，又作拘勿头，秋时盛开。
⑮ 芬陀利华　梵语 puṇḍarīka，白莲华中最胜者，亦为佛之德号。
⑯ 曼陀罗华　梵语 māndārava，天界白色适意花，亦为天雨华之名。
⑰ 多罗树　梵语 tāla，棕榈类高大乔木，形如棕榈，宝多罗树即以宝所成之树形严饰。
⑱ 悉底迦　梵语 siddhika，意为成就、吉祥，能除众恶之宝，此处指吉祥宝具。
⑲ 箜篌　天界弦乐器，形如竖琴，出微妙音声以供养佛。
⑳ 牟陀罗　梵语 mṛdaṅga，天界鼓名，又作牟陀罗鼓，击之出大妙音。
㉑ 陀罗尼　梵语 dhāraṇī，意译总持，摄持无量法义令不忘失。陀罗尼音即演总持法义之音。
㉒ 治地菩萨　十住位第二，治心地烦恼令净，心净欢喜。
㉓ 生贵菩萨　十住位中第四住，生于佛家、种性尊贵，住胜志乐，亦作生贵住。
㉔ 正心住菩萨　十住位第六，心正直住，勤修一切菩萨道。
㉕ 童真菩萨　十住位第八，离过失、童真清净，得一切菩萨三昧光明。
㉖ 法王子菩萨　十住位第九，从法化生、堪绍佛位，入不思议诸佛境界。
㉗ 灌顶菩萨　十地满心、等觉位菩萨，蒙诸佛智水灌顶，受佛职位，能现如来十力。
㉘ 檀波罗蜜　梵语 dāna-pāramitā，布施度，六度之首，能一切施。
㉙ 尸波罗蜜　梵语 śīla-pāramitā，持戒度，具持众戒无亏。
㉚ 忍波罗蜜　梵语 kṣānti-pāramitā，忍辱度，心不妄动，悉能忍受一切佛法。
㉛ 精进波罗蜜　梵语 vīrya-pāramitā，精进度，能行无量出离精进。
㉜ 禅波罗蜜　梵语 dhyāna-pāramitā，禅定度，具足无量禅定光明。
㉝ 般若波罗蜜　梵语 prajñā-pāramitā，智慧度，智慧光明能普照耀。
㉞ 夜叉王　又作药叉，鬼道之一，住空中或地上，有威力，此处顶上合掌礼佛。
㉟ 乾闼婆王　梵语 gandharva，天界乐神，以香为食，奉侍帝释，此处起净信心。
㊱ 迦楼罗王　梵语 garuḍa，金翅鸟，以龙为食，此处口衔缯带礼佛。
㊲ 紧那罗王　梵语 kiṃnara，天界歌神，人首马身，此处欢喜踊跃。
㊳ 摩睺罗伽王　梵语 mahoraga，大蟒神，地龙之类，此处欢喜瞻仰。
㊴ 摩醯首罗天王　梵语 maheśvara，即大自在天，居色界顶，此处恭敬供养。
㊵ 阿迦尼吒天　梵语 akaṃiṣṭha，色界最高之色究竟天，此天之后即入无色界。
㊶ 灌顶天子　兜率天中修灌顶善根之天子，举身持佛高座，与灌顶菩萨阶位悬殊。
㊷ 无生法忍　菩萨证诸法本来无生之理，心安住不动。经中无生法忍所生之衣即顺此理所修之供具。
㊸ 萨婆若　梵语 sarva-jñā，意译一切智，佛之智体。萨婆若心即求一切智之心。
㊹ 善逝　梵语 sugata，佛十号之一，谓行八正道而入涅槃，善去不还。
㊺ 结跏趺坐　佛之常坐法，双足相盘置于二股之上，降魔成道之坐姿。
