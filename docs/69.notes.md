# 大方广佛华严经卷第六十九 词语注释

① 善财童子　华严经入法界品之主人公，福城少年，初于文殊师利童子处发菩提心后，次第南行参访五十三位善知识，求菩萨行。本卷为其参访之第五十四、五十五参。
② 婆珊婆演底夜神　前卷善财所参之夜神，本卷开篇承接其「初发菩提心所生菩萨藏」等境界，由此过渡至普德净光夜神。
③ 菩萨地　菩萨所证之阶位，华严立十地（欢喜、离垢、发光、焰慧、难胜、现前、远行、不动、善慧、法云）。善财请问「云何修行、出生、成就菩萨地」即问地之修相。
④ 普德净光夜神　本卷善财所参第一位夜神，住菩提场附近，所证为「寂静禅定乐普游步解脱」，能普见三世诸佛及彼净土道场众会。
⑤ 阿耨多罗三藐三菩提心　梵语 anuttarā-samyak-saṃbodhi，意为「无上正等正觉」。发此心即立愿成佛度生，为菩萨行之根本。
⑥ 三昧　梵语 samādhi 音译，意为定、等持。本卷「初禅」「第二禅」等四禅及「诸三昧海」「寂灭定总持」皆属三昧门。
⑦ 寂静禅定乐普游步　普德净光夜神所证解脱门之名。意为于寂静禅定中得法乐，普游三世一切诸佛刹土而无障碍。
⑧ 解脱门　入解脱之法门。菩萨各依所证解脱门度生，本卷二夜神各立一门——「普游步」「普喜幢」。
⑨ 初禅　色界初禅天之定，离欲恶不善法，有觉有观、喜乐一心。本卷普德净光夜神「修习初禅，息一切意业」。
⑩ 第四禅　色界最高之定，舍念清净。本卷云「修第四禅，增长圆满一切智愿，出生一切诸三昧海」。
⑪ 善知识　能引导众生舍恶修善、趣向佛道之师友。本卷以「见善知识」八义与「由亲近善知识」十力用为骨干，强调善知识为菩萨行之本。
⑫ 波罗蜜　梵语 pāramitā，意为到彼岸、度。菩萨所修六度或十度之总名。本卷以十波罗蜜为喜目夜神毛孔身云之纲。
⑬ 菩萨摩诃萨　「摩诃萨」意为「大」，即「大菩萨」。指已登地、行愿深广之菩萨，非初发心者可比。本卷中夜神谦推「如诸菩萨摩诃萨」即此义。
⑭ 卢舍那如来　即毗卢遮那之意译，华严宗所立法身佛，即华藏世界之教主。颂中「卢舍那如来，道场成正觉」即此。
⑮ 喜目观察众生夜神　本卷善财所参第二位夜神，于菩提场右边，坐莲华藏师子座，入「大势力普喜幢解脱」，一一毛孔出变化身云说法度生。
⑯ 莲华藏　即莲华藏世界，华严经所说毗卢遮那佛所住之华藏庄严世界海。喜目夜神坐「莲华藏师子之座」即此意。
⑰ 大势力普喜幢　喜目观察众生夜神所证解脱门之名。「幢」为高出不动之相，表菩萨以大势力普令众生欢喜，如幢直立不被他动。
⑱ 檀波罗蜜　即布施度，六度之首。颂云「行檀波罗蜜，难舍能舍」，于一切事无恋着、内外悉施。
⑲ 普贤菩萨　梵语 Samantabhadra，华严三圣之一，表大行、大愿。本卷中喜目夜神本生之觉悟夜神即普贤菩萨化现，且善财「堪修普贤菩萨行」为得法之因。
⑳ 智波罗蜜　十度之第十，菩萨究竟之智。本卷广列其「所知法、所知业、所知刹、所知劫、所知世」等，最为详尽。
㉑ 色究竟天　梵语 Akaniṣṭha，色界最顶之天。本卷列「与色究竟天、善现天、善见天、无热天、无烦天相似身云」，即色界五净居天。
㉒ 大梵　即大梵天，色界初禅之主。本卷列「大梵、梵辅、梵众天相似身云」即初禅三天。
㉓ 尸波罗蜜　即持戒度，梵语 śīla。颂云「行尸波罗蜜，弃舍王位、宫殿、眷属，出家学道」，表戒行清净。
㉔ 羼提波罗蜜　即忍辱度，梵语 kṣānti。颂云「行羼提波罗蜜，能忍世间一切苦事」，心不动不乱。
㉕ 禅波罗蜜　即禅定度，梵语 dhyāna。本卷述其「所有资具、所有修习、所有成就、所有清净、所有起三昧神通」皆悉显示。
㉖ 般若波罗蜜　即智慧度，梵语 prajñā。本卷云「大智慧日、大智慧云、大智慧藏、大智慧门，皆悉显示」。
㉗ 方便波罗蜜　十度之第七，梵语 upāya。菩萨以善巧方便度生，本卷云其「所有修行、所有体性、所有理趣」皆悉显示。
㉘ 愿波罗蜜　十度之第八，菩萨大愿所成。本卷云其「所有体性、所有成就、所有修习」皆悉显示。
㉙ 力波罗蜜　十度之第九，菩萨所具殊胜力用。本卷云其「所有资具、所有因缘、所有理趣」皆悉显示。
㉚ 毗卢遮那　梵语 Vairocana，意为「遍一切处」，即法身佛之异名。本卷云善财「毗卢遮那如来曾所化故」，显示其与法身佛之宿缘。
㉛ 那由他　梵语 nayuta 音译，极言数量之大，古译或作亿、或作兆。本卷颂中「百万那由他俱胝四天下」「十亿那由佛」等屡见。
㉜ 俱胝　梵语 koṭi 音译，汉译千万或百万。颂中「百万那由他俱胝四天下」即以俱胝为数量单位。
㉝ 四天下　即四洲：南阎浮提、北郁单越、东弗婆提、西瞿耶尼。转轮王以法化「普及四天下」即统御四大洲。
㉞ 三十二种相　即佛转轮王所具之三十二大丈夫相，为福德所感之殊胜身相。颂中「三十二种相，随好以庄严」即此。
㉟ 莲华中化生　非胎生，于莲华中化生，表清净无染。颂中转轮王「莲华中化生，金色光明身」即此殊胜身相。
㊱ 阎浮界　即南阎浮提，佛教世界观中人所住之洲。颂中「腾空照远近，普及阎浮界」指光明遍照人间。
㊲ 由旬　梵语 yojana，印度里程单位，一说约四十里。颂中「身出金色光，照及千由旬」即此度量。
㊳ 转轮圣王　亦称转轮王，以正法治四天下之圣王，具轮宝、象宝等七宝。本卷喜目夜神本生为转轮王宝女，颂中详述王之相好、千子、臣佐。
㊴ 文殊师利童子　梵语 Mañjuśrī，亦译曼殊室利，意为妙德、妙吉祥。华严三圣之一，表大智。本卷揭示喜目夜神本生中转轮王即文殊师利之化现。
