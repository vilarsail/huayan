# 大方广佛华严经卷第六十九 导读

## 一、内容总览

本卷为「入法界品第三十九之十」，紧承前卷善财童子参访婆珊婆演底夜神之后，连续记述善财参访两位夜神：**普德净光夜神**（说「寂静禅定乐普游步解脱」）与**喜目观察众生夜神**（说「大势力普喜幢解脱」）。两位夜神所入法门皆以「普见三世一切诸佛」「一一毛孔出变化身云」为相，层层展开菩萨如何以一身遍现法界、调伏众生的境界。本卷是善财五十三参中部幅度较大的两参，由「明心见佛」推进至「从初发心至究竟地之相续次第」，并借喜目夜神之长颂，回溯其历劫供养诸佛、得文殊师利童子与普贤菩萨觉悟的本生因缘，为下卷继续参访普救众生妙德夜神埋下伏笔。

## 二、结构层次（★重点）

本卷由两次参访构成，各以「善财请问 → 夜神答法 → 颂偈重宣 → 善财得法、辞退」为节，但第二参远详于第一参：

- **第一参（普德净光夜神）**：
  - 善财请问菩萨地「云何修行、出生、成就」 → 夜神先以「成就十法圆满菩萨行」总答（十法皆从「见佛、知佛功德、知佛调伏力」展开）→ 再自述所得「寂静禅定乐普游步解脱」：以十门「非去非来、非生非灭」观如来 → 修四禅调伏众生 → 以不净想等十三想度在家放逸者 → 以惭愧法度住空闲者 → 复令众生止恶生善、增长善根。
  - 颂偈重宣：卢舍那于道场成正觉、一毛孔放光普照群生、佛昔修诸行已曾摄受我、此近有夜神名喜目观察——由「自法」过渡至「指路」。
  - 收束：善财辞退，往诣喜目夜神。
- **善财途中思惟（过渡段）**：善财以「见善知识」八义自策（难见难遇、令心不散乱、破障碍山、入大悲海、得智慧光、修行一切智道、睹见十方佛海、忆持法轮）→ 喜目神遥加其心，令知亲近善知识十种力用 → 善财复自念十种「由亲近善知识」所得，层层递进，将「参访」升华为「善知识即一切菩萨行之本」。
- **第二参（喜目观察众生夜神）**：
  - 善财诣彼 → 见夜神坐莲华藏师子座、入「大势力普喜幢解脱」、一一毛孔出无量变化身云说法 → 逐层列举所现身云：檀波罗蜜身云、尸波罗蜜身云、羼提波罗蜜身云、精进波罗蜜身云、禅定身云、般若身云、方便身云、愿波罗蜜身云、力波罗蜜身云、智波罗蜜身云——以十波罗蜜为纲，层层展开菩萨度生之相。
  - 复出天、龙、八部、声闻、独觉、诸佛乃至地水火风等相似身云，周遍十方充满法界 → 以种种音声（风轮声、海潮声、天王声等）说夜神从初发心所集功德与十波罗蜜相续次第。
  - 善财见闻已得同分解脱 → 以偈赞夜神 → 复请问「发心几时、得解脱久如」。
  - 夜神以长颂答本生：过去刹尘劫前，于「寂静音」劫中作转轮王宝女，夜神梦中觉悟令见德海佛，遂发菩提心；其后历劫供养诸佛——初功德海佛、第二功德灯佛……乃至功德幢佛为说无依妙法门，方得入普贤道、了知十法界差别门。
  - 收束：揭示本生因缘中转轮王即文殊师利童子、觉悟夜神即普贤菩萨之化现 → 自云唯得此解脱门，复指路普救众生妙德夜神 → 善财辞退。

两参以「菩萨自述所证 → 谦推指路」同构收束，并以「文殊师利、普贤菩萨」两位大士隐于本生因缘中，将善财参访的能化之师与所入之法圆融收摄。

## 三、关键结论

1. 善知识是菩萨行之本：善财于途中自念「由亲近善知识」十种力用，并蒙喜目神遥加其心，显示「参访善知识」非仅为求法，更是菩萨一切行愿、一切波罗蜜得以出生增长的增上缘。
2. 普贤行愿与文殊智慧为本卷两位夜神所证之根：普德净光夜神所入「普游步」与喜目夜神所入「普喜幢」，皆以「普」字标宗；喜目夜神本生因缘中明示转轮王即文殊师利、觉悟夜神即普贤之化，将两参收归文殊、普贤二大士。
3. 「一一毛孔出变化身云充满法界」是本卷核心观境：显示菩萨一身即法界身，于一一毛孔中出生十波罗蜜、八部、人天、声闻、缘觉乃至诸佛身云，重重无尽，度脱众生而不取著。
4. 历劫供养诸佛而「未得慧眼入解脱海」：喜目夜神历劫供无量佛，皆自云「然未得深智」「未得清净忍」，直至功德幢佛为说无依妙法门方入普贤道——显示菩萨行须历劫熏修、渐次深入，非一供即得。

## 四、易混辨析

- **普德净光夜神 vs 喜目观察众生夜神**：前者所入为「寂静禅定乐普游步解脱」，重在「寂静禅定」与「普见三世诸佛」；后者所入为「大势力普喜幢解脱」，重在「一一毛孔出变化身云、十波罗蜜身云充满法界」。二神所居相邻（一在菩提场右边不远），然所证法门层次有别，前者为善财指后者，非同一人。
- **普游步 vs 普喜幢**：「普游步」是「普游法界、步步见佛」之禅定解脱；「普喜幢」是「大势力普令众生欢喜、如幢直立不动」之解脱，二者皆以「普」标宗，然侧重不同——前者偏于「游观」，后者偏于「现化度生」。
- **文殊师利童子 vs 普贤菩萨**：本卷中两位大士皆隐于喜目夜神本生因缘——转轮王「十方主」即文殊师利童子化现（能绍隆佛种），觉悟夜神即普贤菩萨化现。文殊表智、普贤表行，读者勿将二者混为同一菩萨。
- **十波罗蜜 vs 六波罗蜜**：本卷喜目夜神一一毛孔所现身云依次为檀、尸、羼提、精进、禅、般若、方便、愿、力、智十种，比常途六波罗蜜多出方便、愿、力、智四门，为华严十地菩萨所修之十度，非声闻六度。

## 五、阅读提示

读本卷可带着两个问题：其一，善财于途中何以反复赞叹「见善知识」之功德，与两位夜神所证法门如何呼应？其二，喜目夜神历劫供养诸佛皆自云「未得深智」，直至功德幢佛为说何法方入普贤道？把握这两条线索，即可见本卷由「善知识功德」收束至「文殊普贤化现」的圆融结构。读长颂中历劫佛名不必逐个记诵，留意其「供佛—谦推—最终入普贤道」的递进脉络即可。
