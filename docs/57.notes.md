# 大方广佛华严经卷第五十七 词语注释

〔1〕 于阗国三藏实叉难陀　实叉难陀是唐代来自于阗国(今新疆和田)的三藏法师,"三藏"指精通经、律、论的译经师;八十卷《华严经》即由他主译。"奉制译"谓奉皇帝诏命翻译。
〔2〕 离世间品　《华严经》第三十八品名,"离世间"谓菩萨虽在世间行化而不染世间。本卷是该品第五部分,全卷以"菩萨摩诃萨有十种X"的问答体逐项开列菩萨行门。
〔3〕 菩萨摩诃萨　梵语 Bodhisattva-mahāsattva,"摩诃萨"意为大有情,指德位高深的大菩萨,非一般初发心者。
〔4〕 习气　此处指菩萨久行所熏成的习惯倾向(如菩提心习气、善根习气),与烦恼习气相对;安住此法则"永离一切烦恼习气"。
〔5〕 何等为十　全卷反复出现的设问句式:"是哪十种?"下文即以"所谓"起首逐一列举,以"是为十"收束。读到长清单时抓每条末句"故"字前的因果即可。
〔6〕 波罗蜜　梵语 pāramitā 音译,意译"到彼岸",指由生死此岸度到涅槃彼岸的修行法门。
〔7〕 有十种取　此"取"非烦恼之执取,而是菩萨主动担取、立志承担之意——取众生界、取世界、取菩提,谓以大愿担荷一切而不断菩萨行。
〔8〕 严净　庄严清净,谓以功德装饰净化佛国土;"究竟严净"即净化到底。
〔9〕 相好　佛身显著的形相为"相"(三十二相),细微圆满之妙为"好"(八十随形好);"积集诸佛相好功德"谓修福成佛身。
〔10〕 匪懈　匪,非也;匪懈即不懈怠。"修勤行匪懈"谓勤修而不懈。
〔11〕 十力　佛独具的十种智力,如知是处非处、知业报因果等;本卷P12"学佛十力"下即逐条列其内容。
〔12〕 耽着　耽(dān)沉溺、贪恋沉迷。"耽着三昧"谓贪住定境之乐而不起利他之行,故列退失佛法。
〔13〕 三昧　梵语 samādhi 音译,义为正定,心专注一境而不散乱。
〔14〕 二乘　声闻乘与缘觉乘,只求自了脱生死;"乐二乘道"列为退失佛法之一,因其不发大悲利他之心。
〔15〕 离生道　离(三界)受生之道。本段十种皆示"离而不离"之妙:已出离生死,却仍入世间教化众生,不与世共亦不杂二乘。
〔16〕 得预如来众会　预通"与",参预;谓决定能参与诸佛的法会大众。
〔17〕 阿僧祇　梵语 asaṃkhya 音译,意为"无央数",印度数目的极大单位,泛指无量无数。
〔18〕 大丈夫名号　"大丈夫"喻勇猛无畏之伟人;此十种名号皆以"萨埵"结尾,各配一句"故"说明得名之由。
〔19〕 萨埵　梵语 sattva 音译,义为有情、众生。"菩提萨埵"即觉有情(菩萨),下文"第一萨埵""胜萨埵"等九种皆仿此立名。
〔20〕 空、无相、无愿　三解脱门:观诸法无自性(空)、观相寂灭(无相)、于诸法无所愿求(无愿);修此三门得解脱,故亦称三三昧。
〔21〕 四行是菩萨道　四种修行:忏悔罪障、随喜福德、劝请佛转法轮、回向善根,合称忏、喜、请、向四行。
〔22〕 五根　信、精进、念、定、慧五种能生一切善法之根;下文"净信坚固、起大精进、一向正念、巧知三昧、善分别智"即依此展开。
〔23〕 六通　六种神通:天眼、天耳、他心、宿命、神足、漏尽,下文逐条解释,每条末句"故"前是义理所在。
〔24〕 七念是菩萨道　七种忆念:念佛、念法、念僧、念舍、念戒、念天、念众生——比常说的六念多出"念众生"一条;下文逐条解释。
〔25〕 兜率陀天宫　梵语 Tuṣita,即兜率天;一生补处菩萨(如弥勒)在此待机缘下生成佛,"念天"即忆念此补处菩萨。
〔26〕 一生补处　补处谓候补佛位;一生补处指只隔最后一次受生即继佛成佛的菩萨。
〔27〕 八圣道　即八正道:正见、正思惟、正语、正业、正命、正精进、正念、正定;下文逐条解释,是佛道之总纲。
〔28〕 离语四过　口业四种过失:妄语、两舌、恶口、绮语;"常行正语"即离此四过而随顺圣言。
〔29〕 头陀　梵语 dhūta,意为抖擞(抖落尘垢),指少欲知足的苦行法;下文"四圣种"即其要目。
〔30〕 四圣种　圣者知足之法种:常乞食、着粪扫衣、树下坐、乐断乐修;经中每与"头陀知足"连言,指安贫乐道之行。
〔31〕 入九次第定　依次第层层深入而无杂的九种定:四禅、四无色定、灭尽定;本段列举并示"入定而不舍菩萨行"之妙。
〔32〕 离欲恚害　欲、恚、害是欲界三种粗重之结使,离此方能入初禅,故九次第定以此为入门。
〔33〕 觉观　即寻伺:粗略思量为觉(寻),细察为观(伺);初禅以上渐次离之。"灭除觉观"谓入无寻无伺之定,却仍能以智慧观察教化。
〔34〕 无色定　空处、识处、无所有处、非想非非想处四种无色界定;"入无色定而不舍欲、色受生"示菩萨定不碍化。
〔35〕 灭一切想受定　即灭尽定,九次第定之顶,止息一切想与受;"虽住灭定而亦不息菩萨行"是本段要点。
〔36〕 是处、非处　十力之首:"是处"谓某因必得某果,有此道理;"非处"谓无此道理。下文列举佛十力即从此起。
〔37〕 诸使　"使"是烦恼的异名,喻烦恼驱役众生流转生死,有贪、瞋、痴等十使;"乐欲、诸使、惑习"谓众生的欲乐、烦恼及其习气。
〔38〕 助道　助成正道之法,即趣向觉悟的资粮(三十七道品等);下文"无量助道"谓其资粮如虚空、法界等无量。
〔39〕 一切智智　佛智之总名;"一切智"上再加"智"字,表智中之智、究竟圆满的知一切,非声闻之偏智可比。
〔40〕 如热时焰　阳焰,春天旷野日光下浮动的幻影,渴鹿误以为水。连同"如幻如梦、如影如响、如镜中像、如水中月"等喻,皆说菩萨所修无实体、离一切执着。
〔41〕 施设安立　人为建立名相制度之意;"离言说修"谓远离这种人为安立,不可言说而修。
〔42〕 真如实际　真如谓法之本真不妄;实际谓究极实相。"不坏真如实际修"谓深入真如而不坏世间假有。
〔43〕 声闻　闻佛音声说法而悟四谛、证阿罗汉之圣者;菩萨"入声闻道而不以此道取出离",涉而不滞。
〔44〕 辟支佛　梵语 Pratyekabuddha 音译,意译缘觉、独觉,无师自悟十二因缘者;菩萨入其道而起大悲不休息。
〔45〕 采女　帝王宫中的歌舞侍女;谓菩萨虽享人间宫乐侍从而不暂舍禅定。
〔46〕 阇梨和尚　"阇梨"即阿阇梨(梵 ācārya),轨范师;"和尚"即亲教师。菩萨实为众生无上师,却示现尊敬师长,示谦下之德。
〔47〕 灌顶　原为古印度王子即位时以水灌顶之仪式,喻佛为菩萨授成佛之记;十地之末(法云地)受灌顶位,"一切如来所共灌顶"即此。
〔48〕 法缯　缯(zēng)丝织品;"无碍法缯以冠其首"谓以妙法之缯系于顶上,如王子受灌顶加冠,表法王之位。
〔49〕 阿耨多罗三藐三菩提　梵语 anuttara-samyak-saṃbodhi 音译,意译"无上正等正觉",即佛果。
〔50〕 有十种足　自此以下以足、手、腹、藏、心、甲、器仗、首、眼、耳、鼻、舌、身、意等身体器物为喻,每喻配十种行法,"足"喻行法之基础凭借;读法皆抓每条末句"故"前的因果。
〔51〕 菩提分法　即三十七菩提分法(道品),趋向觉悟之法门的总称;"集一切菩提分法不退转"为精进足。
〔52〕 一向忍可　忍可即认可领受而不疑;"一向"谓专一、彻底,于佛所说全盘信受。
〔53〕 先意问讯　不等对方开口,先致意问候,示谦敬主动;"舒展右掌相迎引"即其相。
〔54〕 拔出欲泥　泥即泥淖(nào),喻五欲能陷溺人;"令超三界手"救众生拔出欲泥而置于彼岸。
〔55〕 四暴流　欲流、有流、见流、无明流四种烦恼之流,势猛漂溺众生如洪水;"置于彼岸手"即于四暴流中救溺。
〔56〕 性质直　断句为"性/质直":质性正直,不是"性质"直;谓其心坦诚无虚伪。
〔57〕 险诐　诐(bì)邪僻不正;"无险诐"谓心地坦平,无阴险奸邪。
〔58〕 邪定众生　与"正定众生"(决定趋向解脱)、"不定众生"(尚未决定)并为三类;菩萨于正定者令成熟、不定者令相续、邪定者发大悲度之。
〔59〕 师子吼　师子即狮子;佛说法无所畏惧,如狮子吼百兽慑伏。本段以十句"我当……"的誓言为狮子吼,读时抓每句誓愿与其下的定性语(如"是菩提心大师子吼")。
〔60〕 十八不共法　唯佛独具、菩萨二乘所无的十八种功德(身语意无失、无异想、无不定心等),表佛德之究竟。
〔61〕 大梵住　梵住即慈、悲、喜、舍四无量心,如梵天普护众生;"佛法大梵住心"谓以此四心安住佛法而救护众生,不局限于一乘。
〔62〕 卐字相　卐音wàn,佛三十二相之一,胸前吉祥万德之标;此心坚固如卐字金刚,众魔不能动其一毛。
〔63〕 被甲　被(pī)同"披",披挂铠甲;"被大慈甲"谓以大慈大悲等十法为铠甲,护身摧伏魔军。
〔64〕 含识　即有情众生,具有心识者之通称;"度脱一切诸含识"。
〔65〕 普门　普遍通达之门,谓一法门摄一切法而无碍;"生普门善根""见普门法界"皆言其周遍无碍。
〔66〕 器仗　仗通"杖",兵器;以布施、持戒等十法为"器仗",喻借以摧破悭吝、烦恼等之武器,乃至"生死是菩萨器仗"、"烦恼是菩萨器仗",谓即染成净、转物为用。
〔67〕 悭吝　悭(qiān)吝啬贪惜;布施器仗摧破之。
〔68〕 邪命　不正当的谋生方式(如占相吉凶、傲世诱众以求利养);正命即离此而活命。
〔69〕 结使　结与使皆烦恼异名:结谓结缚众生于生死,使谓驱役众生流转;"长夜所集烦恼结使"谓无始劫来积集的烦恼。
〔70〕 三千界　三千大千世界之略,一佛所教化的世界范围。
〔71〕 肉髻相　佛三十二相之一,顶上隆起之髻,常人不能见其顶(无能见顶);"荷戴众生首"即成就此相,喻担荷众生。
〔72〕 肉眼　五眼之一。五眼为肉眼、天眼、慧眼、法眼、佛眼,由劣而胜的五重能见之力;本段十种眼以前五为体、后五(智眼、光明眼等)为其胜用。
〔73〕 毁呰　呰(zǐ)同"訾",诋毁;"闻毁呰声，断除瞋恚"谓闻毁而不怒。
〔74〕 六度、四摄　六度即六波罗蜜:布施、持戒、忍辱、精进、禅定、智慧;四摄为布施、爱语、利行、同事,皆摄化众生之行。
〔75〕 等分之行　"等分"谓贪、瞋、痴三毒混杂均等;闻其衣物肢体之香即知其所行烦恼之类别轻重。
〔76〕 伏藏　埋藏于地下的宝藏;闻伏藏草木之香即知其处,"皆如对目前"。
〔77〕 阿鼻地狱　梵语 Avīci 音译,意译无间地狱,罪苦无有间断之处,诸苦之最。
〔78〕 有顶　有顶天,即无色界最高处"非想非非想天",三有(生死)之顶;"下至阿鼻地狱、上至有顶"极言其遍知范围。
〔79〕 无学身　小乘修学分"学地"(尚须修学,预流至不还果)与"无学"(阿罗汉,学道已毕);"学身"示现学地,"无学身"示现阿罗汉果。
〔80〕 意生身　梵语 mano-maya,随意念而化现之身,来去自在;菩萨以此善巧出生教化。
〔81〕 客尘　烦恼如客(外来暂住而非本有)如尘(染污可拂);"客尘不能染着"谓心性本体不为烦恼所污。
〔82〕 我所　我所有,与"我"相对的身外执著;"无我、我所"谓入三昧时离人我、法我二执。
〔83〕 令速转还　谓令众生速从色界、无色界的定境中回转,不滞于定乐而趣向佛道。
〔84〕 阿兰若　梵语 araṇya 音译,寂静空闲之处,修行者所居;"阿兰若住"谓住静处证大禅定。
〔85〕 授记　佛预记某菩萨当来成佛(何劫、何国、何名号);"得忍住，满足授记故"谓得无生忍则授记圆满。
〔86〕 转轮王坐　转轮圣王(以十善德化天下的理想王者)之坐;菩萨坐此兴起十善道,下"四天王坐""帝释坐""梵天坐"皆仿此,示现天身说法。
〔87〕 帝释坐　帝释即忉利天(三十三天)之主因陀罗;坐此示为众生之胜主。
〔88〕 金刚坐　佛于菩提树下成道时所坐之金刚石座,喻其坚固能降魔;"金刚坐，降伏众魔及外道故"。
〔89〕 憺怕　憺(dàn)怕,即澹泊,安静恬淡之意;"寂静卧，身心憺怕故"。
〔90〕 有为、无为　有为指因缘所生、有生灭造作之法;无为指无生灭之实性(如真如、涅槃)。菩萨于此二者平等安住。
〔91〕 不出正位　正位指无相解脱门之定境;"以无相为所住处，不出正位故"谓安住无相而不出定。
〔92〕 忍法成满　忍法谓无生法忍;"以念慧为所住处，忍法成满故"谓念慧增上使忍法成熟圆满。
〔93〕 授记别　记别即授记(佛分别预记弟子将来果位);"一切法平等为所住处，得授记别故"。
〔94〕 满足念处故　念处即四念处:观身不净、观受是苦、观心无常、观法无我;以正念为所行处则四念处满足。
〔95〕 杂谈戏　"以与一切众生杂谈戏为所行处":随俗与众谈笑游戏,以平常谈吐为教化之场,令其永离诸恶。
〔96〕 恶慧众生　邪恶错误的分别智,即持邪见诡辩者;菩萨令其除疑破执。
〔97〕 破有见　有见谓执"存在"为实有的见解;"令除疑惑破有见"谓为恶慧众生破此执著。
〔98〕 奋迅　狮子、象王等振起威势之状,喻菩萨力用奋扬迅疾;本段以牛王、象王、龙王、金翅鸟王、师子王等奋迅为喻,读时抓每条末句"故"前的功能。
〔99〕 夜叉　梵语 Yakṣa 音译,捷疾鬼神,天龙八部众之一。
〔100〕 乾闼婆　梵语 Gandharva 音译,香音神,司帝释天之乐,天龙八部众之一。
〔101〕 甘露雨　甘露为梵语 amṛta,天上的不死之药,喻法味能令众生得不死(涅槃);兴大法云降甘露雨即说法利生。
〔102〕 大金翅鸟王　即迦楼罗(Garuḍa),金翅鸟王,以龙为食的巨鸟;此喻以大智竭贪爱之水、破愚痴之壳、捕捉烦恼恶龙。
〔103〕 愚痴㲉　㲉(qiào)同"壳",卵壳;"破愚痴㲉"谓打破众生愚痴之卵壳使其出生死。
〔104〕 搏撮　搏(bó)撮(cuō),抓取捕捉;谓如金翅鸟捕龙,降伏烦恼恶毒。
〔105〕 蕴、界、处　佛分析身心的三科:五蕴、十八界、十二处;"知蕴、界、处及诸缘起"谓通达一切法的分类与因果关系。
〔106〕 诸难处　即八难之处——地狱、饿鬼、畜生、长寿天、边地、聋盲喑哑、世智辩聪、佛前佛后,障碍见佛闻法;誓愿除灭之。
〔107〕 补伽罗　梵语 pudgala 音译,即补特伽罗,义为"数取趣",指轮回中一再受生的个体(我);与"我、众生、寿命"并举,皆破我执之词。
〔108〕 无生法忍　认可诸法本自不生不灭之理而不动摇,是高阶菩萨的重要悟解;"无生法忍大师子吼"即宣说此理。
〔109〕 最后生菩萨　一生补处菩萨的最后之身,即示现成佛前那一世的身(如悉达太子);本段写其降诞、七步、狮子吼的完整事迹。
〔110〕 释、梵、四王　帝释天(忉利天主)、梵天王与四大天王;佛菩萨示现受生时,诸天咸来赞请护持。
〔111〕 自行七步　佛诞生的传说:太子降生后向四方各行七步而宣言"我于世间最胜第一";此谓最后生菩萨在王宫示现降诞事迹。
