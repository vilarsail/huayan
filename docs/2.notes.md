# 大方广佛华严经卷第二 词语注释

① 毗卢遮那　梵语 Vairocana 音译，意为「遍一切处」，即法身佛，为华严经所说之教主。本卷言大众皆因毗卢遮那往昔摄受而得入解脱门。
② 劫海　劫波（kalpa）如海，喻时间之长远无量。「于无边大劫海为众生故求菩提」，谓佛于无尽长劫中修菩萨行、求无上道。
③ 四摄事　菩萨度生之四法：布施、爱语、利行、同事，以此四法摄受众生。缘起段明毗卢遮那往昔「以四摄事而曾摄受」今之道场众海。
④ 善根　能生善法之根，即过去所修之善行以为未来善果之因。「一一佛所种善根时」「发起一切众生善根」皆指培植善法之根本。
⑤ 游戏神通　菩萨、天神于诸三昧神通中任运自在、无滞无碍之境界，如童子游戏之自由。总缘起谓大众「得于诸佛解脱之门游戏神通」。
⑥ 大自在天王　色界顶天（摩醯首罗天）之王，于诸天中地位最尊。本卷首列妙焰海大自在天王，统领其下诸天，率先得法界虚空界解脱门。
⑦ 法界　梵语 dharma-dhātu，一切法所依之理体，亦为诸佛所证之境界。本卷颂中常言「佛身普遍法界」「法界如如常不动」，指佛身与法界相即周遍。
⑧ 虚空界　指无边无际的虚空，喻法界之广大无量。妙焰海天王所得「法界、虚空界寂静方便力解脱门」，以虚空之无碍无际显法体之寂静。
⑨ 解脱门　入佛功德之方便门径。本卷反复出现的「得……解脱门」，非指个人解脱果，而是各天神以某一法门契入如来功德大海的能入之径。
⑩ 天王　诸天界之主，统辖该天众的天神首领。本卷列举大自在天、广果天、遍净天、梵天、自在天、善化天、知足天、时分天、三十三天、日天、月天等诸天之王。
⑪ 无功用行　八地以上菩萨任运度生、不假作意加行的境界。此处「不生不灭……无功用行」连用，显法性本然、无修而修的解脱相。
⑫ 十方　东、南、西、北、东南、西南、东北、西北、上、下十方，泛指一切方位、一切处。本卷常与「普现」「遍满」连用，显佛身佛德周遍无遗。
⑬ 菩提　梵语 bodhi 音译，意为觉、无上正等正觉。「为众生故求菩提」「佛昔修习菩提行」皆指求证、修习无上觉道。
⑭ 法性　诸法之真实本性，即真如、实相，本空本寂、无生无灭。颂中「法性平等无所依」「法性究竟无生起」「法性本净无诸垢」屡见，是本卷核心法义。
⑮ 佛刹　梵语 kṣetra，佛所教化之国土，即佛国、佛世界。颂中「一毛孔中皆示现」「十方所有诸国土悉在其中而说法」，显一即一切的法界缘起。
⑯ 调伏　调柔身心、伏灭烦恼，即善巧化导众生离恶向善。诸天神所得法门多涉「调伏众生」「随其根欲而调伏」。
⑰ 陀罗尼　梵语 dhāraṇī 音译，意为总持、能持能遮，忆持无量法义不忘失之法门。「普门陀罗尼海所流出」「总持边际不可得」皆指此总持之力。
⑱ 总持　陀罗尼之意译，谓能总摄忆持无量佛法而不散失。总持大光明天王得「陀罗尼门光明忆持一切法无忘失解脱门」。
⑲ 微尘数　以极微细之尘沙为喻，表数量之多至不可算数。本卷屡言「刹海微尘数」「等众生数」，喻佛德、法门、所度众生之无量无边。
⑳ 兜率天　梵语 Tuṣita 音译，意为知足，欲界第四天，为补处菩萨下生前所住之处。演庄严音天王所得法门涉及「菩萨从兜率天宫没下生时」。
㉑ 尸弃　梵语 Śikhin 音译，意为顶髻，此处为大梵天王之名号。尸弃大梵王得「普住十方道场中说法而所行清净无染着解脱门」。
㉒ 梵王　色界初禅天之主，统梵众、梵辅、大梵三天。尸弃梵王即大梵天王，为色界诸天之代表。
㉓ 三昧　梵语 samādhi 音译，意为等持、定，心一境性之禅定。慧光梵王所得「使一切众生入禅三昧住解脱门」，即令众生安住禅定。
㉔ 因陀罗　梵语 Indra 音译，即帝释天、释提桓因，欲界忉利天之主。本卷「释迦因陀罗天王」即帝释，统领三十三天。
㉕ 善化天　即化乐天，欲界第五天，天神能自化作五欲之乐而享受。「善化」即善巧化现，亦指善于化导众生。
㉖ 波罗蜜　梵语 pāramitā，意为到彼岸、度，指菩萨所修之六度或十度等。颂中「具修广大波罗蜜」，指佛于往昔劫中圆满修习诸度。
㉗ 知足天　即兜率天，梵语 Tuṣita 意译为知足，谓此天于五欲知止足。本卷知足天王得「一切佛出兴世圆满教轮解脱门」。
㉘ 时分天　欲界夜摩天之异译，以昼夜时分受乐而得名。时分天王得「发起一切众生善根令永离忧恼解脱门」。
㉙ 法轮　佛法之代称，以轮喻佛说法能辗碎烦恼、转凡成圣。「转法轮成熟众生方便」「能转清净妙法轮」皆指宣说佛法度化众生。
㉚ 三十三天　即忉利天（Trāyastriṃśa），欲界第二天，位于须弥山顶，以帝释为中央、四方各有八天共三十三天。释迦因陀罗天王即其主。
㉛ 日天子　日宫之主，又名日天、苏利耶天，掌日照昼。日天子得「净光普照十方众生尽未来劫常为利益解脱门」。
㉜ 月天子　月宫之主，又名月天、旃陀罗天，掌月光照夜。月天子得「净光普照法界摄化众生解脱门」，与日天子同表光明普化。
