# 大方广佛华严经卷第十 导读

## 一、内容总览
本卷为《大方广佛华严经》卷第十，属「华藏世界品第五之三」，承接上卷普贤菩萨之说法，继续以「香水海—世界种—世界」三层结构展开华藏世界海之庄严布局。本卷主旨有二：一是广列围绕华藏世界海的众多香水海及其所依世界种，逐一点名最下方、与金刚幢齐等、与娑婆齐等、最上方四层世界与当处佛号；二以普贤重颂总收，阐明一切刹土皆依众生业力、菩萨愿力、佛神力而现，形色成坏种种差别，最终归于一心净业所见清净刹。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全卷由「枚举香水海 → 总收世界种 → 重颂显理」三段一线贯穿：

- **香水海枚举（P4–P13）**：以「诸佛子！彼……香水海外，次有香水海，名：……；世界种，名：……」为固定句式，依次列出离垢焰藏海东十海、无尽光明轮外十海、金刚焰光明外十海、帝青宝庄严外十海、金刚轮庄严底外十海（此段略去四层世界之详，唯列海种）、莲华因陀罗网外十海、积集宝香藏外十海、宝庄严外十海、金刚宝聚外十海、天城宝堞外十海。
  - 每一香水海群以「如是等不可说佛刹微尘数香水海」收束 → 指出最近轮围山之香水海与世界种 → 依「最下方 → 金刚幢齐等 → 娑婆齐等 → 最上方」四层纵向定位世界与佛号。
  - 层次关系：横向枚举（海海相次）↔ 纵向定位（四层上下），构成一张立体的世界网。
- **世界种总收（P14）**：以「十不可说佛刹微尘数」总结 → 用「各各……」九重排比铺陈每一世界种之庄严 → 以「递相接连，成世界网」收束，点明华藏世界海周遍建立。
- **重颂显理（P15–P16）**：普贤承佛威力以偈重宣 → 先颂刹种安布庄严（境） → 次以「譬如」连举林叶、种子、心王宝、龙王、幻师、画师等十数譬喻，阐明刹土由业力愿力所成（因） → 再广列刹之形色（山网轮华、座杵髻月、毫相佛手等）、住劫久近、有佛无佛、光明种类、音声差别（相） → 终归「佛放大光明，化佛满其中，其光普照触，法界悉周遍」。

推进走向：枚举（广）→ 总收（摄）→ 重颂（理 + 相 + 用），由事入理，由境归心。

## 三、关键结论
1. 华藏世界海非一孤立世界，而是以香水海为纬、世界种为经、层层世界为节，纵横交织而成的「世界网」。
2. 每一世界种皆「依现一切菩萨形摩尼王幢庄严莲华住」，说明华藏刹体即菩萨行愿之映现。
3. 刹土形色成坏、净染苦乐、光明音声，皆随众生业力、菩萨愿力、佛神力而现，非实有生灭。
4. 「众生心净故，得见清净刹」——本卷归宗在一心：净业见净土，染业见浊世，三界唯心，万刹唯业。
5. 刹中有佛有佛，无佛则有他方佛变化来应，示现降神、处胎、出生、降魔、成觉、转法轮，明佛出世不离众生根欲。

## 四、易混辨析
- **香水海 vs 世界种 vs 世界**：香水海是承载之水体，世界种立于其中（以音声等为体），世界中又有层层世界围绕——海含种、种含世界，三层嵌套。
- **世界种 vs 世界海**：世界种（刹种）是一香水海中所立之世界丛聚；世界海（如华藏庄严世界海）是更大范围的总摄，含无数世界种。
- **金刚幢世界齐等 vs 娑婆世界齐等**：均为纵向定位标高——「与金刚幢齐等」约在十佛刹微尘数世界上，「与娑婆齐等」即吾人所居之层级，二者并非同一高度。
- **业力刹 vs 愿力刹 vs 佛力刹**：业力刹由众生染净业感（如地狱铁铜土、天宫七宝）；愿力刹由菩萨普贤愿所净治；佛力刹由佛神力加持普现。本卷三力并举，不可偏废。

## 五、阅读提示
读本卷可带二问：其一，普贤为何不厌其烦地枚举十组香水海？其二，重颂中「譬如」连用十余喻，欲说明什么？前者显事相之广，后者显理体之一——事相虽无量，理唯业愿佛三力所成、一心所现。把握此「事—理」张力，便不致被密集名相淹没。
