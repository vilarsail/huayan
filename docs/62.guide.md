# 大方广佛华严经卷第六十二 导读

## 一、内容总览
本卷为《入法界品》第三十九之三，是著名的「善财童子五十三参」之开端，在整部《华严经》中地位关键：前此诸品多由普贤、文殊等大菩萨于法会中敷演法界因果，至此转入「善财童子」一人南行参访的实践叙事，将「法界」从菩萨境界落实到学人可循的次第修行之路。全卷主线为：文殊师利菩萨至福城东庄严幢娑罗林说法 → 善财童子因七宝涌现而得名 → 发菩提心、说颂求道 → 奉文殊指教南行 → 参访德云比丘、海云比丘、善住比丘，依次得「忆念一切诸佛境界智慧光明普见法门」「普眼法门」「无碍解脱门」。文殊为始，善财为缘，三参为门，构成「发心 → 亲近善知识 → 历境渐修 → 转指下一善知识」的参访范式。

## 二、结构层次（★重点）
全文按「说法现场 → 善财缘起 → 参访展开」三大段推进，参访段内部又以「文殊指授 → 善财求觅 → 善知识说法 → 转指下一善知识」为反复回环之结构：

- **道场说法 → 龙众得度（P3-P4）**：文殊劝比丘发心后南行至福城东大塔庙处 → 说「普照法界修多罗」 → 大海诸龙来闻法、舍龙身、得不退转。先立「善知识说法能转根器」之典范。
- **大众云集 → 善财得名（P5-P6）**：福城四众（优婆塞、优婆夷、童子、童女各五百）来集 → 文殊观察善财因缘 → 述其入胎时七宝楼阁、七伏藏、五百宝器自然涌现 → 故名「善财」 → 又知其已曾供佛、心净如虚空。此为善财「堪受大法」之根器说明。
- **文殊说法 → 善财发心说颂（P7-P9）**：文殊为说「十种佛法」（积集、相续、次第…） → 善财发菩提心 → 说长颂三十余偈，以「三有城廓」「妙智日轮」「愿轮大悲毂」等喻，总摄菩萨行愿与求道之恳切。
- **文殊再劝 → 指示南参（P10-P17）**：文殊赞其发心为难中之难 → 劝「求真善知识勿生疲厌，勿见过失」 → 指南方胜乐国妙峰山德云比丘。确立「善知识为一切智最初因缘」之根本教诫。
- **第一参：德云比丘（P18-P25）**：善财南行、七日方见 → 德云说「忆念一切诸佛境界智慧光明普见法门」，列举二十一种念佛门（智光普照、令一切众生、安住力…住虚空等） → 转指海云比丘。此参立「忆念诸佛」之念佛三昧法门。
- **第二参：海云比丘（P26-P42）**：善财专念十种观察门南行 → 海云述发菩提心之十种心相（大悲、大慈、安乐…） → 述住海门国十二年思惟大海十种相 → 见海中莲华如来、佛摩顶说「普眼法门」 → 以十种陀罗尼光明领受无量品 → 转指善住比丘。此参立「普眼法门」总摄法界。
- **第三参：善住比丘（P43-P52）**：善财至楞伽道海岸聚落 → 见善住于虚空中经行、诸天八部围绕供养 → 善住说「无碍解脱门」，列举十一种「无所障碍」（心行、没生、宿命、未来劫事…）及神通变现 → 转指达里鼻荼国弥伽。此参立「无碍解脱」之自在身通。

全文以「文殊指授 → 南行求觅 → 见已请问 → 善知识自说所得法门 + 谦言唯知此一门 → 转指下一善知识 → 善财礼辞专念而去」为固定回环结构，每一参皆重复此模式，是五十三参的叙事范式。

## 三、关键结论
1. **善知识为成佛最初因缘**：文殊反复强调「亲近供养诸善知识，是具一切智最初因缘」，且教诫「于善知识善巧方便勿见过失」——确立华严「依善知识」的修行根本。
2. **发心为难，求行倍难**：发菩提心已是难事，发心之后能求菩萨行更是难中之难；善财之可贵在于发心之后随即起行参访。
3. **法门各别，皆归普贤**：德云之「忆念诸佛」、海云之「普眼法门」、善住之「无碍解脱」，三善知识各得一法门，皆自谦「唯知此门」，并指下一善知识——显示菩萨行无量门而一门深入、辗转增上之修学次第。
4. **善财童子为「法器」典范**：以其入胎七宝涌现之瑞相、已曾供佛之善根、心净如虚空之信解，说明堪受大法者须先具足根器与福德因缘。

## 四、易混辨析
- **文殊师利童子 vs 文殊师利菩萨**：本卷或称「童子」或称「菩萨」，同指一人；「童子」表其示现少年形、智慧清明，非年龄义，亦为下文「善财童子」之呼应。
- **普眼法门 vs 忆念诸佛境界智慧光明普见法门**：前者为海云所闻、佛摩顶所说之总持法门，以「普眼」照见一切如来境界；后者为德云所证，重在「忆念」与「普见」诸佛；二门皆含「普见」义，但一约「佛境界」、一约「如来演说」，层次不同。
- **优婆塞 vs 优婆夷 vs 童子 vs 童女**：优婆塞为在家男众（清信士），优婆夷为在家女众（清信女），童子、童女为少年男女；本卷四众各五百来集，显示善财之同参大众。
- **那由他 vs 阿僧祇 vs 不可说不可说**：那由他为「极大量」之数词（约10的百余次方量级），阿僧祇意为「无数」（本卷未直接出现但「阿修罗」「阿兰若」等含「阿」之词另有所指），「不可说不可说」为华严极数，层层递进显示数量之不可思议。

## 五、阅读提示
读本卷可带着两个问题：(1) 善财每参一位善知识，所得法门与前一参有何递进关系？(2) 文殊为何不自行说尽一切法，而要善财辗转南参？注意「谦言唯知此门」与「转指下一善知识」的反复出现，这是五十三参叙事的密码。
