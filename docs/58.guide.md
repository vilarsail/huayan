# 大方广佛华严经卷第五十八 导读

## 一、内容总览

本卷为《大方广佛华严经·离世间品第三十八》之第六段，承前续讲普慧菩萨二百问、普贤菩萨广答之体系。全卷由「菩萨十种清净行 → 十种义/法 → 福智二种助道具 → 十明足 → 十种求法/明了法/修行法 → 十种魔与魔业及舍离 → 十种见佛/佛业/慢业 → 智业 → 魔所摄持与佛所摄持 → 法所摄持 → 兜率十业与下生十事」一线贯穿，前半以「十种」为基本结构枚举菩萨自利利他之净行，后半转入降生兜率、现瑞下生的具体事相，为下卷释迦降生人间作铺垫。主旨：菩萨行从因位净业到果位度生，层层圆备，皆以普贤大行贯摄。

## 二、结构层次（★重点）

全文按「法数枚举 → 摄持抉择 → 兜率垂迹」三大段推进：

- **总起（清净六度门）**：清净施→戒→忍→精进→禅→慧，以六度为骨干，每一度开十种 → 显示菩萨自行之基。
  - 接「四无量心」：清净慈→悲→喜→舍各十种 → 由自利转入利他，慈悲喜舍为度生之本。
- **义/法/助道（境智门）**：十种义→十种法→十种福德助道具→十种智慧助道具→十种明足 → 由「行」转「解」，福智双修，明足圆具。
- **求法与阶次（根机门）**：十种求法→十种明了法（凡夫、四向四果、辟支、菩萨各别）→十种修行法 → 显示从凡至圣的修学次第。
- **魔事与对治（障道门）**：十种魔→十种魔业→十种舍离魔业→十种见佛→十种佛业→十种慢业→十种智业 → 先列魔相与魔业，再列对治之佛业、智业，构成「障—对治」对照结构。
- **摄持抉择（依估门）**：十种魔所摄持→十种佛所摄持→十种法所摄持 → 显示菩萨当舍魔依佛、依法不依人，由「外护」转入「法住」。
- **兜率垂迹（果后方便门）**：住兜率天十种所作业→将下生现十种事 → 由「法」转「事」，从理入事，以兜率十业成熟根机，以十种光明瑞相引导下生，收束全卷，启下卷降生之机。

层与层之间以「佛子！菩萨摩诃萨有十种……」固定句式过渡，末段以「从兜率天下生人间」收束，显「不离本处而现受生」之普贤行。

## 三、关键结论

1. 菩萨一切净行皆以「十种」结构展开，每一类皆归结「若安住此法则得如来无上……」，显因行即果德之因，因果不二。
2. 六度、四无量、福智二种助道具前后相承：自利（六度）→ 利他（慈悲喜舍）→ 助道（福智）→ 圆明（明足），构成完整的菩萨道修学次第。
3. 魔与佛相对：魔业、魔所摄持皆从「忘失菩提心、志乐狭劣、乐二乘」立言，显示大乘菩萨道最大的魔障是小乘自了与放逸懈怠，对治则以「不舍菩提心、近善知识、求一切智」为根本。
4. 见佛与佛业显示「十种佛身」（安住佛、愿佛、业报佛、住持佛、涅槃佛、法界佛、心佛、三昧佛、本性佛、随乐佛）之差别，强调佛身非一非异、随缘普现。
5. 兜率十业与下生十事，以「光明」为枢纽：从足下、眉间、右掌、两膝、卍字、毛孔、宝殿、宫殿、足下、随好各放光明，遍照三千大千世界，显示菩萨下生时身、座、宫、阁皆放光现瑞，为一代时教之开端。

## 四、易混辨析

- **蕴魔 vs 烦恼魔 vs 业魔 vs 心魔 vs 死魔 vs 天魔**：蕴魔就五蕴生取；烦恼魔就恒杂染；业魔就能障碍；心魔就起高慢；死魔就舍生处；天魔就自憍纵。前五约自体，天魔约他化。又「善根魔、三昧魔、善知识魔、菩提法智魔」四者，皆是「执取」所成，纵是善法、禅定、师友、智解，一念着之即成魔事。
- **魔业 vs 慢业 vs 智业**：魔业约「忘失菩提心、诽谤正法、乐二乘」等背离大乘之行；慢业约「于师僧父母、说法师、有德人」起高慢心；智业则正相反，约「信解业报、不舍菩提心、近善知识、乐法乐义」等，是离慢离魔之正行。
- **魔所摄持 vs 佛所摄持**：魔摄从「懈怠、志乐狭劣、于少行生足、受一非余、不发大愿」等小乘自了之心立言；佛摄从「初发菩提心、生生持菩提心、觉诸魔事、闻波罗蜜如说修行」等大乘悲智之行立言。一念退堕即魔摄，一念进求即佛摄。
- **见佛之十种佛身**：安住世间成正觉佛、愿佛、业报佛、住持佛、涅槃佛、法界佛、心佛、三昧佛、本性佛、随乐佛，非十佛并立，而是「一身多义、随见不同」，与《华严》「十身」义通，读者勿作十尊佛解。

## 五、阅读提示

读本卷可带着两个问题：一、「十种」之数反复出现，其内在逻辑为何？二、前半之「行」与后半之「事（兜率下生）」如何衔接？抓住「因行—果用」一线，便见普贤行从净业到垂迹之圆融。
