# 大方广佛华严经卷第四 导读

## 一、内容总览

本卷是《大方广佛华严经·世主妙严品第一》的第四部分，承接前三卷对菩萨众与诸天神众的列举，继续展开各类世间主神的赞叹。卷中依次出现主火神、主水神、主海神、主河神、主稼神、主药神、主林神、主山神、主地神、主城神、道场神、足行神、身众神、执金刚神等十四类神众。每类皆以「长行（散文）列举诸神及其所得解脱门 → 尔时上首神承佛威力说颂赞叹」的固定结构反复推进，通篇颂偈围绕如来往昔修行、大悲方便、神通普现、度生无尽而展开，最终由执金刚神收束，显佛身色相无边、神力周遍法界。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷按「世间主神序列 + 长行颂偈双结构」一线贯穿，由境及众、由众及法：

- **总框架（贯穿全卷）**：每一类神众皆按同一模板展开 →
  - 长行（P3/P6/P9…）列举该类十位主神名号 + 各各所得「解脱门」（法门的别称）；
  - 「尔时，某某神，承佛威力，遍观一切某某神众而说颂言」（P4/P7…）作过渡句；
  - 颂偈（P5/P8…）以十颂对应十神，每颂末句点出能悟之神名，回扣长行。

- **神众序列推进（从燥烈到柔润，从外护到内护）**：
  - 主火神（炽然猛利，破暗照世）→ 主水神、主海神、主河神（柔润利益，息恼清凉）↔ 一燥一润并列对比；
  - 主稼神、主药神（滋养色身、疗治烦恼）→ 主林神、主山神、主地神（草木山土，安立世间）↔ 从受用到住处递进；
  - 主城神、道场神、足行神、身众神（城邑道场、佛足所履、随佛身众）→ 执金刚神（密迹力士，护法金刚）↔ 由世间外护收归金刚内护。

- **颂偈内在逻辑（每类皆然）**：先赞佛往昔修行 → 次赞佛大悲方便普现 → 末赞神通度生无尽 → 落脚到「某神于此悟入」，形成「因行—果德—化用—证入」四段式。

- **过渡衔接**：每段以「复次」另起一类神众，以「尔时…承佛威力…而说颂言」承上启下，环环相扣而不重复。

## 三、关键结论

1. 各类世间主神所得「解脱门」并非自利小果，皆以「普」「无边」「一切众生」为量，表明世主妙严即法界大用——神众即是菩萨化现。
2. 全卷反复强调「佛昔修行无量劫」「大悲方便等众生」，将如来果德溯因于往昔行愿，确立「因赅果海」的华严宗义。
3. 「一一毛孔」「一一毛」放光现法、普现十方身，是本卷核心意象，显示佛身与法界互融互入、一即一切。
4. 以执金刚神殿后，以「法王法如是」「法界无不及」收束，从世间柔润之神回归金刚坚固定力，显悲智双运。

## 四、易混辨析

- **解脱门 vs 三昧门 vs 方便门**：长行中诸神所得或名「解脱门」、或名「三昧门」（如海潮雷音主海神「普入法界三昧门解脱门」）、或称「方便」；总体皆属入佛境界之门，侧重不同——解脱门侧重离障自在，三昧门侧重正定契理，方便门侧重应机化他，本卷中常互换使用。
- **主稼神 vs 主药神**：主稼神主五谷滋味，以「法滋味令成就佛身」为喻，重在长养；主药神主草木药石，以「疗治盲冥」「灭一切众生病」为喻，重在对治；一养一治，对应法身滋养与烦恼对治两门。
- **道场神 vs 主城神**：道场特指佛成道处（菩提树下）及其庄严具，道场神守护「菩提树」「道场庄严」；主城神守护人间城邑、调伏城居众生。前者围绕圣迹，后者围绕世间聚落。
- **足行神 vs 身众神**：足行神主佛足所行之处、举足下足皆度生；身众神为随佛身侧之众、示现种种威仪色相。一主「行迹」一主「身相」，皆表佛身普现。

## 五、阅读提示

读本卷可带着两个问题：其一，每一类神所得的「解脱门」如何与该神的职能（火、水、稼、药…）形成隐喻对应？其二，颂偈末句为何都要点出「某神于此悟入」，这种「法门—神众—证入」的对应在表达什么？抓住这两点，便能看到本卷并非罗列，而是以神众为镜、映照法界大用。
