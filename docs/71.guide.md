# 大方广佛华严经卷第七十一 导读

## 一、内容总览

本卷属《入法界品》第五十三参至五十六参的中间环节，为善财童子参访的第二参（承普救众生妙德夜神之后），参访对象为寂静音海夜神。全卷以「问答得法 → 自述行法 → 本生因缘 → 重颂结说」四段一线贯穿，集中宣说「念念出生广大喜庄严解脱门」，并由此展开夜神于清净光金庄严世界中历经多劫承事诸佛的本生故事，终以长行与偈颂双重宣说此解脱功德，为善财指往下一参开敷一切树华夜神处。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷按「问→答→本生→重颂→指授」的华严参访标准范式展开：

- **发起请问（P3-P6）**：善财于前一所夜神处得法已，转诣寂静音海夜神所 → 顶礼绕匝 → 自陈已发心、欲学菩萨行 → 夜神先赞所求 → 正示所得法门名「念念出生广大喜庄严解脱门」 → 善财再问四事（何事业、何境界、起何方便、作何观察）。

- **正释法门，由心→法→境→体四层递进（P7-P12）**：
  - **发心（P8-P9）**：以「我发起……心」连环排比，先自述十六种清净乐欲心（离垢、不退、普现救护等），复述「发是心已，复为说法」——以三十六组「若见众生……我为说法」对机施教，涵盖贪瞋痴、王宫采女、贫穷丑陋、四隅诸方等各类机根，皆令至一切智地，结以「无量法施摄诸众生……得广大欢喜法光明海」。
  - **观境（P10-P11）**：先观菩萨道场众会之「种种」庄严（三昧、神变、光明、国土、佛海）；再观毗卢遮那如来身相——念念出清净色身、放光充满法界、一一毛孔出佛刹微尘数光明海、宝焰山云、香光明云、诸相庄严身云、佛变化云、天王等身云——皆于一一毛孔如是出现、如是说法，结以「生大欢喜……量与法界萨婆若等」。
  - **明体（P12）**：以「此解脱无边……无际……甚深……广大……无坏……无底」六义总摄，复以二十七重譬喻（大地、大水、大火、大风、大海、须弥、大城、虚空、大云、净日、满月、真如、影像、呼响、大树王、金刚、如意珠、离垢藏摩尼宝王、喜幢摩尼宝等）显此解脱体性周遍、无生、如幻。

- **本生因缘，明发心久远与历劫修因（P13-P22）**：
  - 善财问「汝发心来其已久如」 → 夜神先述世界海方位（华藏东过十世界海，一切净光宝世界海，清净光金庄严世界，普光幢劫）。
  - 自述于不退转法界音佛所，为菩提树神，初见佛成道即发心得「普照如来功德海」三昧 → 历事十佛（法树威德山、一切法海音声王、宝光明灯幢王、功德须弥光、法云音声王、智灯照耀王、法勇妙德幢、师子勇猛法智灯、智力山王），每值一佛即得一一三昧。
  - 复转生为天、龙、夜叉等十类身，经佛刹微尘数劫供养修菩萨行 → 命终生此华藏娑婆，历值迦罗鸠孙驮、拘那含牟尼、迦叶、毗卢遮那四佛，于毗卢遮那所始得此念念出生广大喜庄严解脱。
  - 得法已，入十不可说不可说佛刹微尘数法界安立海，于一一尘中见一一佛土毗卢遮那坐道场，以速疾陀罗尼受持一切文义，层层悟入法门、修多罗、法海、法品、法云、法流、大喜海、地、三昧海、见佛海、智光海。
  - 复知无量如来往昔行海、波罗蜜海、菩萨地等，从初发心乃至法灭，念念悉知见。
  - 结答发心久远：过二佛刹微尘数劫前，于清净光金庄严世界初发心，经二佛刹微尘数劫修菩萨行方生此娑婆贤劫。

- **偈颂重宣与谦己推胜（P23-P28）**：夜神承佛神力以长偈重颂本生——历十组十佛（共百佛）次第出现，初、二、三……各悟法门，复述曾供养须弥尘数劫诸佛而得此解脱 → 颂末自谦「我唯知此解脱」，推赞菩萨摩诃萨无边行愿 → 指示善财往参开敷一切树华夜神。

- **善财赞礼辞退（P27-P29）**：善财一心观察夜神身，说偈赞其「身量无边、远离五蕴、心集无边业、悉在一尘中」等不思议境界 → 礼足绕匝，殷勤瞻仰，辞退而去。

## 三、关键结论

1. **法门核心在「念念」二字**：所谓念念出生广大喜，是指于每一刹那中，亲见毗卢遮那如来出清净色身、放光、毛孔现佛刹微尘数光明与种种身云说法，由此生大欢喜，量等法界萨婆若。
2. **发心为先，法施为业**：夜神先发十六种清净乐欲心，复以三十六类对机说法为事业，以无量法施摄诸众生，令离恶道、脱三界、住一切智，方得广大欢喜法光明海——发心与利他互为因果。
3. **历劫承事一佛一三昧**：于清净光金庄严世界值十佛、于娑婆贤劫值四佛，每承事一佛即得一三昧，最终于毗卢遮那所圆成此解脱，显示法门须多劫熏修，非一生可就。
4. **解脱体性周遍如幻**：以二十七喻显此解脱——犹如大地为众生依、大水以悲润、大火干贪爱、大风速疾趣智、如金刚不可坏、如如意珠出生自在、如真如周遍一切处——明法界一相、无生、如幻、影像之义。
5. **善知识相续不绝**：夜神自谦唯知一法，推赞菩萨摩诃萨无边行愿，复指善财参下一善知识开敷一切树华夜神，显示善财五十三参「一参接一参」的法脉相续结构。

## 四、易混辨析

- **夜神 vs 天王 vs 菩萨**：本卷夜神自述多劫中曾为天王、龙王、夜叉王乃至梵王等身，又为菩提树神、道场主夜神——「夜神」是主夜之神（夜间护法神将），属八部之一的天龙八部系统，而非色界天人；菩萨为度生可示现此等身，然身是化现，本是菩萨行愿。
- **解脱门 vs 三昧 vs 陀罗尼**：本卷夜神历值诸佛所得者多称「三昧」（如普照如来功德海三昧），最终圆成者称「解脱门」（念念出生广大喜庄严解脱门），得法后复得「速疾陀罗尼力」——三昧为定中境界，解脱门为依定所发之总持自在，陀罗尼为忆持文义不忘之力，三者有浅深次第而相摄。
- **华藏庄严世界海 vs 娑婆世界 vs 清净光金庄严世界**：华藏是毗卢遮那所依之广大世界海，娑婆世界在此华藏之中、贤劫之内；清净光金庄严世界则在华藏之东过十世界海处，是夜神初发心之本土，三者为不同层级的宇宙结构。
- **佛刹微尘数 vs 不可说不可说佛刹微尘数 vs 须弥尘数**：均表极多数，「佛刹微尘数」以一佛刹碎为微尘之数为计量，「不可说不可说」更倍之，颂中「须弥尘数劫」则以须弥山碎尘为劫数计量，皆华严数事喻极多之习语，非实数。

## 五、阅读提示

读本卷可带着两个问题：(1) 「念念」二字如何统摄全卷——从发心、说法、观佛身相到历劫本生，处处不离「念念」之相续？(2) 夜神二十七喻中，哪几喻明体性周遍、哪几喻明利他大用、哪几喻明如幻无生？辨清这三类，便抓住了此解脱门「体、相、用」三分的大纲。
