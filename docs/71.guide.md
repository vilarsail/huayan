# 大方广佛华严经卷第七十一 导读

## 一、内容总览
本卷为《入法界品》第三十九之十二，善财童子五十三参中的第35、36两参：先访**寂静音海夜神**，得「念念出生广大喜庄严解脱」；再访**守护一切城增长威力夜神**，得「菩萨甚深自在妙音解脱」。两参共用「问答自陈得法→追溯发心久如→重宣偈颂→谦己推胜→指路下一善知识」的固定结构，一卷之内连续演示两次，最宜对照阅读。

## 二、结构层次（文章的骨架与逻辑推进）
- **寂静音海参（前半卷）**：往诣启请（云何学菩萨行、修菩萨道）→ 夜神自陈得「念念出生广大喜庄严解脱门」→ 发起十九种心，并随四十余种众生机宜一一施以对治说法 → 观毗卢遮那如来二十七重境界（清净色身、光明海、宝焰山云、香光明云、佛变化云、天王等八部身云……每一重皆以「既见是已，生大欢喜」收束）→ 以三十余喻显此解脱之德（大地、大水、大火、大云、净日、满月、真如、金刚……）→ 善财问云何修行 → 十大法藏 → 发心久如（清净光金庄严世界、普光幢劫、不退转法界音佛所发心，历二佛刹微尘数劫）→ 重宣偈颂 → 谦己推胜 → 指路守护一切城夜神 → 善财赞偈、礼辞。
- **守护一切城参（后半卷）**：随前夜神之教思惟观察 → 往诣，见夜神坐一切宝光明摩尼王师子座，现十种身 → 夜神自陈得「菩萨甚深自在妙音解脱」（为大法师、十种观察法界、十种大威德陀罗尼轮、闻思修慧等二十余类说法）→ 发心久如（离垢光明劫、法界功德云世界：转轮王出家护法呵责恶比丘、其女法轮化光比丘尼即夜神前身，历须弥山微尘数佛）→ 重宣偈颂 → 善财得入此解脱、以偈赞叹 → 礼辞而去。

## 三、关键结论
- 「念念出生广大喜庄严」点出前一解脱以念念之中出生大欢喜为体；「守护一切城」以妙音说法为体，卷末「守护心城，舍三界城，住一切智无上法城」正是点题。
- 两段本生皆示「久远发心、历劫修行」：发心不在一时，而在二佛刹微尘数劫、须弥山微尘数劫的相续供养诸佛、修菩萨行。
- 善财每参必问「发心久如」，夜神皆以本生世界、劫、佛、自身角色作答——把个人的发心放进无量时空的坐标中。

## 四、易混辨析
- **寂静音海 vs 守护一切城**：前者法门名带「喜庄严」，重在观佛起信生喜；后者带「妙音」，重在以法音说法度生。
- **世界海／世界种／世界**：华严的宇宙结构由大到小三层，发心段先定世界海，再定世界种，再定一个世界。
- **陀罗尼 vs 三昧**：陀罗尼是总持法义、令不忘失的力量；三昧是相应正定。寂静音海参所得多为三昧，守护一切城参特出十种陀罗尼轮。
- **闻思修慧**：从听闻佛法、如理思惟、实际修习三个层次所得的智慧，本卷末参夜神以此三类法开示众生。

## 五、阅读提示
读时抓住两把钥匙：一是「既见是已，生大欢喜」——示范如何一重重观佛而步步生喜；二是「我唯知此……」——善财参访一贯的谦辞，每参只知一法，故须遍访善知识，直至弥勒、普贤。
