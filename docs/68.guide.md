# 大方广佛华严经卷第六十八 导读

## 一、内容总览
本卷属《入法界品第三十九》之九，是善财童子五十三参的延续部分，集中记述善财依次参访婆须蜜多女、鞞瑟胝罗居士、观自在菩萨、正趣菩萨、大天神、安住地神、婆珊婆演底主夜神七位善知识。本卷以「善财逐位参问 → 各善知识自述所得法门及本生因缘 → 指示下一位善知识」为基本循环，层层推进，贯穿「烦恼即菩提」「悲智双行」「三世一念」「一毛孔中现一切法界」的华严圆融义。七位善知识分属在家女、居士、大菩萨、天神、地神、夜神等不同身份，显示菩萨道遍于一切境界而无所不在。

## 二、结构层次（★重点）
本卷按善财参访次第展开，整体为「参访—请问—自述法门—本生因缘—指路下一参」的递归结构，七位善知识次第相承：

- **总起善财境界（P3）**：先以善财所得九种陀罗尼、大悲力、清净愿等总明其参访资格 → 标示求法者本身的根器已熟。
- **婆须蜜多女——离贪欲际（P4-P22）**：善财入险难国宝庄严城 → 城人疑其求女不应有贪染 → 善知识者赞其决定拔众生贪爱毒箭 → 见女身出光明普照，女自述「随欲现身」与「暂见、暂语、暂执手、暂升座、抱持、咂唇」等皆令众生离贪得三昧 → 自述本生于高行如来所供养一宝钱、文殊师利为说法令发心 → 指示南方鞞瑟胝罗居士。
- **鞞瑟胝罗居士——不般涅槃际（P23-P35）**：居士自述「不生心言某佛已般涅槃」 → 开栴檀座佛塔门得「佛种无尽三昧」，一念中见三世诸佛从迦叶至弥勒、毗卢遮那等不可说微尘数佛及其发心、成道、转法轮 → 以颂指示补怛洛迦山观自在菩萨。
- **观自在菩萨——大悲行解脱门（P36-P47）**：善财至补怛洛迦山见菩萨坐金刚宝石 → 自述以布施、爱语、利行、同事及现色身、光明网、音声、威仪等摄取众生 → 发愿令众生离十八种怖畏 → 称名念我皆免怖畏 → 东方正趣菩萨从空而来。
- **正趣菩萨——普门速疾行解脱（P47-P58）**：从东方妙藏世界普胜生佛所而来 → 一一念中举不可说佛刹微尘数步，遍入诸佛刹供养、随类现身说法 → 指示南方堕罗钵底城大天神。
- **大天神——云网解脱（P59-P71）**：示现金银七宝等聚如山、五欲之具、无数童女众 → 教善财取物供养如来、施一切众生修檀波罗蜜 → 对贪欲者示不净、瞋慢者示罗刹形、惛沈者示王贼水火重疾 → 指示摩竭提国菩提场安住地神。
- **安住地神——不可坏智慧藏（P72-P83）**：百万地神相谓「此童子即是佛藏」 → 安住地神以足按地涌出百千亿阿僧祇宝藏 → 自述从然灯佛来常随菩萨，于妙眼佛所（须弥山微尘数劫前庄严劫月幢世界）得此法门 → 指示迦毗罗城主夜神婆珊婆演底。
- **婆珊婆演底主夜神——破一切众生痴暗法光明解脱（P84-P116）**：善财日没时入迦毗罗城见夜神处虚空宝楼阁 → 毛孔中现化度恶道众生及种种教化方便 → 自述于夜暗中救济海难、陆难、山险、旷野、稠林等诸恐怖众生 → 回顾本生：须弥山微尘数劫前寂静光劫出生妙宝世界一切法雷音王如来所，为法慧月王夫人发心；后又于无忧遍照劫须弥幢寂静妙眼如来所为名称长者之女妙慧光明，得「出生见佛调伏众生三世智光明轮三昧」 → 说长颂重明六根清净、一毛孔中见三世诸佛刹 → 指示菩提场普德净光主夜神 → 善财以颂赞叹夜神功德，辞退而去。

## 三、关键结论
1. 七位善知识虽身份各异（在家女、居士、大菩萨、天神、地神、夜神），所示法门各别，然其共同指向「于一法门深入即能普入一切法界」的华严义——婆须蜜多的离贪际、观自在的大悲行、正趣的普疾行、婆珊婆演底的光明照暗，皆从一功德门而通法界海。
2. 烦恼与菩提不二：婆须蜜多以贪欲为度生方便，众生暂见、暂语乃至抱持咂唇皆离贪得三昧，显示菩萨「先以欲钩牵，后令入佛智」的善巧方便；大天对贪着五欲者示不净、对瞋慢者示恐怖形，亦是随类调伏。
3. 三世一念、一微尘中见三世诸佛：鞞瑟胝罗居士「佛种无尽三昧」一念见不可说微尘数佛，婆珊婆演底「念念增长」遍往不可说佛刹微尘数世界，正趣菩萨一一念举不可说步遍入诸佛刹——皆显华严「一念三世」「一尘含法界」的圆顿观。
4. 善知识即如来：善财于善知识生如来想（P85「由善知识得周遍眼」「善知识者则是如来」），显示参善知识即参诸佛，法门从恭敬中得。
5. 悲智相资、福慧双修：观自在菩萨以大悲行门摄取众生并令离十八怖畏，婆珊婆演底于夜暗中救济诸难并回向众生离苦，大天教善财取宝施一切——皆以大悲为根本、以智慧为导首。

## 四、易混辨析
- **婆须蜜多 vs 观自在**：婆须蜜多所示为「离贪欲际解脱」，以欲界形相对治贪欲，法门近于「转烦恼为菩提」的方便；观自在所示为「大悲行解脱门」，以四摄、光明网、音声威仪普摄众生并令离怖畏，法门近于「大悲普度」。前者重在对治一烦恼（贪），后者重在普度一切怖畏众生。
- **不般涅槃际 vs 佛种无尽三昧**：二者皆鞞瑟胝罗居士所得。前者是其所证解脱之境——了知诸佛毕竟无般涅槃、唯为调伏众生示现；后者是开栴檀座佛塔门时所得三昧，以此三昧念念见三世诸佛。一是所证之理，一是能观之三昧，相辅相成。
- **正趣菩萨普疾行 vs 婆珊婆演底念念遍往**：正趣菩萨从东方妙藏世界而来，一一念举不可说步、一一步过不可说佛刹，重在「身遍十方」的速疾周遍；婆珊婆演底得三昧后见自身遍往百、千、百千乃至不可说佛刹微尘数世界，重在「心遍法界」的念念增长。一偏重身行疾遍，一偏重心境遍入。
- **安住地神不可坏智慧藏 vs 婆珊婆演底破暗法光明**：安住地神所得重在「智慧藏」——常随菩萨领受诸佛所说、诸佛神变，偏于「持法不忘」；婆珊婆演底所得重在「破众生痴暗」——以光明照夜暗中恐怖众生，偏于「化他破暗」。一偏自持，一偏化他。

## 五、阅读提示
读本卷可带着三个问题：①七位善知识所示法门虽别，其共同指向是什么？（注意每位末后「如诸菩萨摩诃萨……而我云何能知能说彼功德行」的谦退与推赞。）②婆须蜜多以欲治贪、大天以不净与恐怖形调伏，这种「以烦恼对治烦恼」的方便与一般渐修行门有何不同？③善财每至一处必先「顶礼其足、合掌而立、白言：我已先发阿耨多罗三藐三菩提心」，这一固定请问仪轨在结构上有何用意？
