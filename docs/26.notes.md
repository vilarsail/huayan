# 大方广佛华严经卷第二十六 词语注释

① 回向　将所修善根转趣无上菩提或一切众生，使功德广大无尽。本卷每施毕皆「以诸善根如是回向」。
② 菩萨摩诃萨　菩萨中的大菩萨，已发大心、行大行、趣大果者。本卷反复以此为主语，标举能修之人。
③ 声闻　闻佛声教而悟四谛、证阿罗汉果者，二乘之一。本卷将声闻与独觉并列布施。
④ 福田　堪受供养、能为众生生福之处，如佛、僧、父母、贫穷等。本卷言「奉施诸佛及诸菩萨……如是无量种种福田」。
⑤ 琉璃　梵语吠琉璃耶，青色宝物，又作玻璃、颇梨。本卷施车、施座皆以琉璃为庄严。
⑥ 栴檀　梵语旃檀，即檀香，香气清妙。本卷施栴檀车、栴檀沉水香普熏，表香庄严。
⑦ 师子座　师子即狮子，佛说法无畏如师子吼，故其座名师子座，表最胜。本卷施座段明其高广庄严。
⑧ 采女　宫廷随侍之宫女，亦作「彩女」。本卷诸宝车载「百千采女」「端正女人」表严饰。
⑨ 玻璃　古译水玉或颇梨，似水晶之宝，非今玻璃。本卷施玻璃宝车以众宝严饰。
⑩ 幢幡　以宝竿宝缯所制之军旗式庄严具，幢圆体幡片状，供佛道场之饰。本卷专设施幢幡段。
⑪ 码瑙　玛瑙之古译，宝石名，色泽纹理如马脑。本卷施码瑙藏车、码瑙宝车。
⑫ 一切智　知一切法总相之智，为佛智之一分；本卷多与「力」「无畏」连用，表究竟智果。
⑬ 法界　诸法所依之界，一切法互具互入之实相。本卷回向言「心广大如法界」「普覆法界、虚空界」。
⑭ 十力　如来所具十种智力，知处非处乃至知漏尽等。本卷多段回向愿众生「究竟十力」「首冠十力」。
⑮ 普贤行　普贤菩萨所修之广大行愿，表愿海无尽、遍周法界。本卷结处愿众生「满足普贤菩萨行愿而无厌倦」。
⑯ 善知识　能教导菩萨修行、摄受善根之有德之师。本卷专设「施善知识车」一段，愿众生心常忆持其教。
⑰ 三昧　梵语三摩地，意译正定，心一境性。本卷言「逮得一切三昧境界」「菩萨诸三昧华」。
⑱ 波罗蜜　梵语，意为到彼岸，指菩萨所修究竟之行，通言六度或十度。本卷言「成就第一波罗蜜行」「平等波罗蜜乘」。
⑲ 独觉　又名额支佛、缘觉，无佛之世自悟十二因缘而解脱者。本卷施声闻、独觉车，以尊敬心、福田心起施。
⑳ 那由他　梵语大数，十万或百万千万乃至极数之通名，表极多。本卷言「百千亿那由他」「那由他劫」。
㉑ 劫　劫波之略，极长时之名，有大中小劫之分。本卷言「百千亿那由他劫修习心」「不可说劫修菩萨行」。
㉒ 檀波罗蜜　六度之布施度，檀即施。本卷施声闻段愿众生「具足无上檀波罗蜜」。
㉓ 含识　含有情识之众生，即有情之通称。本卷言「以净福田摄诸含识」「普救含识」。
㉔ 九十六种外道　佛世印度诸外道总数之泛称。本卷回向愿众生舍离九十六种外道邪见。
㉕ 摩尼　梵语，如意宝珠，能出种种所求之物。本卷施摩尼宝车、摩尼璎珞等。
㉖ 阎浮提　南赡部洲之古译，佛经所说四大部洲之一，即吾人所居之洲。本卷言「阎浮提第一女宝」「王阎浮提」。
㉗ 灌顶王子　受灌顶礼将嗣位之王子。本卷施码瑙宝车言「灌顶王子身载其上」。
㉘ 四轮乘　本卷所举成满菩萨梵行之四法：住好国土、依止善人、集胜福德、发大誓愿。
㉙ 灌顶　古印度立太子时以四大海之水灌其顶之礼，喻受位；密教引申为加持授法。本卷施座段有灌顶大王，施冠段言「得诸佛法之所灌顶」。
㉚ 转轮王　以正法治世之圣王，具七宝四德，王四洲或一洲。本卷施座段言转轮王以宝庄严座施于如来福田。
㉛ 阿僧祇　梵语，意为无数、无央数，表极长时或极多。本卷言「阿僧祇众妙宝物」「过彼苦阿僧祇倍」。
㉜ 沉水　沉香之一种，入水能沉，香气浓郁，又名沉香。本卷言「栴檀、沉水妙香普熏」。
㉝ 辟支佛　即独觉之果位称，梵文音译。本卷施幢幡段言「施声闻及辟支佛」。
㉞ 那罗延　梵语，天上力士之名，表坚固勇猛之力。本卷施幢段愿众生得「大智慧那罗延幢」。
㉟ 髻中珠　王顶发髻所藏之明珠，最尊贵不轻示人。本卷施冠段言菩萨舍灌顶王位摩尼宝冠及髻中珠。
㊱ 阿逸多　梵语，慈氏之意，即弥勒菩萨之姓。本卷救牢狱段引「阿逸多菩萨」为舍身救生之证。
