# 大方广佛华严经卷第四十 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第四十，属「十定品第二十七」之初（之一），承前诸品之后转入对菩萨「大三昧」的系统开示。全卷以普眼菩萨三度求见普贤而不得为引线，由佛点明普贤境界甚深不可思议，进而由如来嘱普贤菩萨为众宣说「十三昧」（即十大三昧），并开始详释第一「普光明三昧」与第二「妙光明三昧」的善巧智。本卷主旨：阐明普贤菩萨秘密境界之难见难思，以及菩萨入大三昧后于一多相即、延促互入、幻化无碍中所证得的法界自在。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷按「设场 → 三问三不见 → 嘱说十定 → 广释初二定」一线展开：

- **设场与众俱（P3）**：世尊于普光明殿入刹那际诸佛三昧 → 与十佛刹微尘数菩萨摩诃萨俱，列名号百二十菩萨 → 皆与毗卢遮那如来同修善根。此为下文「普贤难见」预设底蕴：众本皆大菩萨，犹不见普贤。

- **初问·佛指普贤自在（P4-P5）**：普眼菩萨起请 → 问普贤成就几何三昧能入出安住 → 佛赞其问，并指普贤已成就不可思议自在神通，出过一切菩萨之上，令众「应请彼自说」。

- **三求三不见（P6-P9）**：众闻普贤名即得无量三昧 → 渴仰欲见而周遍观察竟不睹 → 佛答「普贤住处甚深不可说故」并说普贤以法界藏为身、入师子奋迅定 → 普眼入十千阿僧祇三昧复求仍不见 → 佛以「幻中幻相尚不可说」为喻，显普贤秘密身语意境界 → 教众「更礼敬、深心信解、发与普贤同一行愿」方得见。

- **礼请·普贤现身（P10-P11）**：普眼及众三称「南无普贤」顶礼 → 普贤以解脱神通力现色身，令众见其亲近如来、坐莲华座，并于一切佛所次第而来 → 佛威神与菩萨信解、普贤本愿力共起，雨十千种云、震动世界、放光灭恶趣，令不可说菩萨入普贤行成菩提。

- **叹德·嘱说十定（P12-P13）**：普眼以十种「住」叹普贤（大威德、无等、无过……）→ 佛印可并广赞普贤阿僧祇清净功德 → 如来嘱普贤为众说「十三昧」，列十定名目（普光、妙光、次第遍往诸佛国土、清净深心行、知过去庄严藏、智光明藏、了知一切世界佛庄严、众生差别身、法界自在、无碍轮）→ 广明修此十定之果德（名为佛、如来、十力人、一切智……）与十种法门之用。

- **广释初二定（P15-P19）**：普贤承旨，先释第一「普光明大三昧」——十无尽法、十无边心、十方入定出定之差别智、以三千大千为一莲华变现的善巧智、阿修罗王现身喻、比丘不净观喻；次释第二「妙光明大三昧」——以阿僧祇世界入一世界、日影七宝山互现喻、幻师一日现百年喻、幻化无我与虚空世间无差别之理。两定皆以「善巧智」收束，层层递进，由「相即摄入」推至「幻化无我、法界平等」。

## 三、关键结论

1. 普贤菩萨境界甚深不可思议、已过量、无有量，以法界藏为身、入师师奋迅定，非佛神力加持与众生深心发愿同普贤行愿，则不能见。
2. 十大三昧是三世诸佛已说当说现说之法，菩萨爱乐修习即名为佛、为如来、为十力人、为一切智——十定即成佛之门。
3. 普光明三昧的善巧智，在于以一身普现无量身、入多世界而无错乱，所示现者「非一非多」，此即法界一多相即之理在禅定中的实证。
4. 妙光明三昧以日影互现、幻师变现二喻，明一切世间同于幻化、虚空与世间无差别，菩萨住幻际、尽幻智而心无所著，达三世与幻无别之境。
5. 全卷以「见—不见—终得见」为眼目：求见普贤的过程本身即是入普贤行的方便，礼敬、信解、发愿、趣向相续不绝，皆获利益无空过者。

## 四、易混辨析

- **普眼菩萨 vs 普贤菩萨**：普眼是此会提问者、求见者，代表「以智眼周遍观察」的菩萨众；普贤则是被求见者、被嘱说者，代表「法界藏为身」的等觉大士。一为能观之眼，一为所观之境。

- **普光明三昧 vs 妙光明三昧**：前者为十定之首，侧重「一身普现无量身、入多世界」的一多相即与无尽法、无边心、十方入出定之差别智；后者为第二定，侧重「以多世界入一世界」的延促相入与幻化无我，并以日影互现、幻师变现显其无碍。前者明「身」之普现，后者明「世界」之互入。

- **秘密身境界 vs 秘密语境界 vs 秘密意境界**：佛以幻中幻相喻普贤三种秘密境界——身、语、意三业所行皆深不可说，非世间文字所能诠表，故凡夫及未入此定之菩萨俱不能见。

- **不思议解脱 vs 大三昧**：本卷中「普贤住不思议解脱之力」是能住之德，「十大三昧」是所修之法；解脱是果地受用，三昧是因中善入之门，二者体一而用异。

## 五、阅读提示

读本卷可带着两个问题：其一，普眼及众已是十佛刹微尘数大菩萨，何以三求不得见普贤？佛所教「发与普贤同一行愿」方得见，与下文普贤自现身之间，是怎样的因果次第？其二，十大三昧之名目既已列出，第一、第二两定的善巧智何以皆以「幻」与「影」为喻？这与你平时理解的「三昧=定」有何不同？循此二问读下去，可见本卷「由境及行、由行证境」的双向结构。
