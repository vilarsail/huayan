# 大方广佛华严经卷第六十六 导读

## 一、内容总览

本卷属《入法界品第三十九》之七，承善财童子五十三参的中段。善财自明智居士处得法后，继续南行，依次参访五位善知识：宝髻长者、普眼长者、无厌足王（阿那罗）、大光王、不动优婆夷。各善知识皆示现一法门，从「福德宝藏」到「香和合」、「如幻解脱」、「大慈幢行」、「求法无厌足」，层层递进，共同指向菩萨行的无量方便与不思议境界。全卷以「善财参访 → 善知识自述法门 → 推荐下一位」为基本循环，串起一组以在家、王身、童女身现世的菩萨示范。

## 二、结构层次（★重点）

全卷按五位善知识依次展开，每位知识内部又循「善财诣问 → 知识示法 → 自谦推贤」的固定节律推进：

- **宝髻长者（福德宝藏门）**：善财诣长者家 → 观十层楼阁（施食、施衣、施庄严具…乃至第五地菩萨、诸般若波罗蜜门、一生所系菩萨、一切如来）→ 长者自述往昔以一丸香供佛回向三处而致此报 → 唯知此一解脱门，推南方普眼长者。
- **普眼长者（疗病和香门）**：善财至藤根国普门城 → 长者自述能疗众生诸病、施衣食财宝、随病说法（贪欲多者教不净观等）、称扬十波罗蜜 → 又善知和合诸香、燃香普见诸佛 → 自谦如大药王，推南方无厌足王。
- **无厌足王（如幻解脱门）**：善财至多罗幢城 → 见王坐金刚座、猛卒围绕、治罚罪人楚毒号叫，心生疑虑 → 天告忆念善知识教 → 王自述实未作恶业，乃化作恶人受苦以警示众生，令舍十恶住十善道；身语意未曾恼害一众生 → 自谦如无生忍菩萨，推妙光城大光王。
- **大光王（大慈幢行门）**：善财至妙光城 → 城以七宝所成、七重金刚垣、八功德水、无量楼阁 → 见王坐摩尼宝莲华藏师子座，二十八相八十随好严身 → 王自述修大慈幢行，以慈为主，众生于其国无有恐怖，库藏恣取 → 入「大慈为首随顺世间三昧」，城六种震动、众生怖畏心皆消灭、鸟兽起慈心 → 自谦如高盖、满月、净日等喻，推安住城不动优婆夷。
- **不动优婆夷（求法无厌足门）**：善财至安住城 → 入其宅，金色光明触身即得五百三昧门 → 优婆夷身相端正世无与等，毛孔恒出妙香，见者烦恼悉灭 → 自述往昔于离垢劫修臂佛所发心，历阎浮提微尘数劫不生欲、瞋、我见，常见诸佛、常闻法海 → 入一万三昧门，十方不可说佛刹六种震动 → 自谦如金翅鸟、商客、渔师、日轮等，推南方无量都萨罗遍行外道。

结构走向：福德 → 疗病和香 → 如幻调伏 → 大慈化世 → 求法无厌。由「外相福德」逐层深入「心性三昧」，并以「如幻」「大慈」为枢纽，过渡到不动优婆夷「劫来不生一念欲心」的甚深行持。

## 三、关键结论

1. 善知识不以形相论：长者、王者、童女皆可是菩萨化身，王之「酷刑」实为如幻调伏，童女之「身相」实为求法无厌之果。
2. 菩萨方便不可思议：化作恶人受苦以警众生，是大悲与善巧的结合，非实造恶业。
3. 一香、一丸、一念回向，可致无量福德庄严——功德在心之回向，不在物之多寡。
4. 大慈为首的随顺世间三昧，能令一切众生怖畏、恼害、诤论之心悉自消灭，乃至鸟兽山树皆起慈心。
5. 求一切法无厌足，于一文一句无不思惟、观察，历微尘数劫不失一法，是菩萨难摧伏智慧藏之基。

## 四、易混辨析

- **菩萨摩诃萨 vs 菩萨**：本卷屡见「如诸菩萨摩诃萨」作推贤语。菩萨摩诃萨特指大菩萨、已登地、功德深广者；善知识自谦「唯知此一法门」，将自己置于地上菩萨之下，是参访中固定谦辞。
- **如幻解脱 vs 如幻三昧**：无厌足王所得为「如幻解脱」，重在「化作恶人受苦」之作用；大光王入「随顺世间三昧」，重在「入定即令众生怖畏心消灭」之境。同体而异用。
- **十波罗蜜 vs 六波罗蜜**：普眼长者称扬檀、尸、忍、精进、禅、般若、方便、愿、力、智十波罗蜜，比常说的六度多出方便、愿、力、智四项，对应菩萨登地后别别断德。
- **优婆夷 vs 比丘尼**：优婆夷是居家信女、未出家受具足戒者；不动优婆夷「身是童女，父母守护」，故非出家众，却示现最深三昧。

## 五、阅读提示
