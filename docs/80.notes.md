# 大方广佛华严经卷第八十 词语注释

① 善财童子　《入法界品》主人公，福城长者子，遍参五十三位善知识求菩萨行。本卷为其参学圆满之终局，经文殊按顶、见普贤身、得普贤摩顶而与普贤等、与诸佛等。
② 弥勒菩萨摩诃萨　善财前一所参大士，本卷开篇即言善财依其教渐次而行至苏摩那城，为五十三参中毗卢遮那楼阁参的承接。
③ 苏摩那城　普门国之城名，善财至此思惟文殊、求见普贤之地，为五十三参最后归处。
④ 文殊师利　表「智」之大菩萨，本卷遥伸右手过一百一十由旬按善财顶，呵责劣心、开示信根，令成就阿僧祇法门后还摄不现，表因位智门的启发与归隐。
⑤ 由旬　古印度长度单位，一由旬约合数十里。文殊按顶之手过一百一十由旬，表菩萨神通力远超凡量。
⑥ 善男子　佛经中对在家修行男子的敬称，此处为文殊、普贤对善财的称呼，亦泛指闻法发心之男众。
⑦ 信根　五根（信、进、念、定、慧）之首，为入佛法之根本。文殊告诫善财若离信根则心劣忧悔、功行不具、退失精勤，可见信为善财参学圆满的根本前提。
⑧ 善知识　能教化众生令舍恶修善、趣向佛道之人。善财一路参访微尘数善知识，本卷又言「不为善知识之所摄护」则不能了知法性，表善知识为菩萨行的外部增上缘。
⑨ 阿僧祇　梵语 asaṃkhyeya，意为「无数」「不可数」，为极大数单位。本卷言「成就阿僧祇法门」，表所证法门数量不可思议。
⑩ 陀罗尼　梵语 dhāraṇī，意译总持，即忆持佛法令不忘失之法门。本卷言善财得「菩萨无边际陀罗尼」，表总持之力周遍无际。
⑪ 三昧　梵语 samādhi 音译，意译正定，心一境性之定。善财得「无边际三昧」与「一切佛刹微尘数三昧门」，一一三昧复以微尘数三昧为眷属。
⑫ 普贤行　普贤菩萨所修之广大菩萨行，为华严宗修行的核心行门。善财被令「入普贤行道场」，表其参学归宿即普贤行。
⑬ 微尘数　将一世界碎为微尘的数量，华严用以状极多至不可思议之数，如「一切世界微尘数诸善知识」「一切佛刹微尘数三昧门」。
⑭ 佛刹　一佛所教化之国土，即三千大千世界。本卷屡言「一切佛刹微尘数」以状极广之数。
⑮ 金刚藏菩提场　如来成正觉之金刚道场，即菩提树下成道处。善财于此毗卢遮那师子座前求见普贤。
⑯ 毗卢遮那　梵语 Vairocana，意译遍一切处，华严宗所立法身佛，即释迦牟尼之法身。本卷言善财于此如来师子座前见普贤，表法身佛为普贤行之所依。
⑰ 普眼　菩萨所具能普见一切法界之眼。善财「以普眼观察十方一切诸佛、诸菩萨众所见境界」，表所见周遍无碍。
⑱ 梵天　色界初禅天之主，普贤毛孔出梵天身云劝诸如来转妙法轮，表菩萨行上摄天众、下化众生。
⑲ 阿耨多罗三藐三菩提　梵语 anuttarā-samyak-saṃbodhi 音译，意译无上正等正觉，即佛果之智。本卷多次言令众生发此心、得不退转。
⑳ 须弥　须弥山，世界之中轴。普贤身分毛孔中所现三千大千世界含须弥山，表一毛孔即摄一完整法界。
㉑ 铁围　铁围山，世界外周之山。与须弥山同为三千大千世界构成要素。
㉒ 天龙八部　天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽八类护法神众。本卷言普贤毛孔所现世界中含「天龙八部、人与非人」。
㉓ 贤首佛　东方莲华德世界之佛。本卷言「于东方莲华德世界贤首佛所，现神通力亦复如是」，表普贤神通十方平等。
㉔ 波罗蜜　梵语 pāramitā，意译到彼岸，菩萨所修之六度（施戒忍进禅智）或十度等。本卷善财见普贤身即得十种「智波罗蜜」。
㉕ 娑婆世界　梵语 sahā，意译堪忍，即释迦牟尼所教化之此世界。本卷言「如此娑婆世界毗卢遮那佛所，普贤菩萨摩善财顶」，表娑婆与十方平等。
㉖ 转轮王位　转轮圣王之王位，为世间最胜之主权。普贤自述往昔为求法「舍施转轮王位」，表难舍能舍之菩萨行。
㉗ 那由他　梵语 nayuta 音译，意译兆、亿等极大数。本卷言普贤色身「无量千亿那由他劫难见难闻」，状劫数之久远。
㉘ 优昙华　梵语 udumbara 音译，意译灵瑞华，三千年一开之稀有之华。颂中以喻佛出世难值难遇。
㉙ 无量寿　即阿弥陀佛，西方极乐世界之教主。颂言「或见如来无量寿，与诸菩萨授尊记」，表一佛身中见十方佛。
㉚ 观自在　即观世音菩萨，梵语 Avalokiteśvara，阿弥陀佛之眷属。颂中与无量寿佛并提。
㉛ 灌顶地　菩萨十地之究竟位，表受职成佛之阶。颂言「悉已住于灌顶地」「或现法水灌其顶」，明普贤行圆满即至灌顶位。
㉜ 阿閦如来　东方妙喜世界之佛，梵语 Akṣobhya，意译不动。颂中「或见此三千界，种种庄严如妙喜，阿閦如来住在中」，表佛随类现身种种不同。
㉝ 十二行法轮　佛转法轮之十二种行相，即三转十二行相（苦集灭道各转三转成十二行）。颂言「转于十二行法轮」赞佛说法圆满。
㉞ 四念　四念处，身受心法四种观行，三十七道品之首。颂言「或闻四念四正勤，神足根力及觉道」，明佛随众生机说三十七道品。
㉟ 三脱门　空、无相、无愿三解脱门，为入涅槃之要门。颂言「令其闻说三脱门，使得出苦涅槃乐」，表声闻乘出离法门。
㊱ 袈裟　梵语 kasāya/kāṣāya 音译，意译坏色衣，出家僧众所着法衣。颂言佛现沙门身「剃除须发服袈裟」，表佛随类现身。
㊲ 阿迦尼吒天　梵语 akaniṣṭha 音译，色界最高之色究竟天。颂言「或至阿迦尼吒天，为说觉分诸宝华」，表佛说法上至色界之顶。
