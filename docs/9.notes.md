# 大方广佛华严经卷第九 词语注释

〔1〕 于阗国　古西域佛国，在今新疆和田一带，盛产玉石、佛法兴盛；本经译主即出于阗。
〔2〕 实叉难陀　梵语 Śikṣānanda 音译（652—710），意译「学喜」，于阗高僧；武周时应邀入华，重译八十卷《华严经》即本经。「三藏」是精通经、律、论三藏的法师尊称，「奉制译」谓奉皇帝诏命而译。
〔3〕 华藏世界　华同「花」，藏（zàng）谓含藏；无数世界层叠含藏于一朵大莲华之中，故名华藏世界海。本卷是〈华藏世界品〉的第二部分，普贤菩萨续说这一世界海的构成。
〔4〕 尔时　就在那时；佛经承接前文、开启新段落的惯用发端词。
〔5〕 普贤菩萨　梵语 Samantabhadra，华严三圣之一，以大行大愿著称；本卷即由他向大众描述华藏世界海的结构。
〔6〕 诸佛子　普贤对听众的称呼；「佛子」谓能继承佛之慧命的菩萨，如佛之真子。
〔7〕 香水海　华藏世界海中的大海，海水质地香洁，故名。每个香水海中出生一大莲华，莲华上住着一个「世界种」，是本卷铺陈的基本单位。
〔8〕 摩尼　梵语 maṇi 音译，宝珠的总名，多指能随人心意出生诸物的如意宝珠；经中「摩尼云」「摩尼王」皆谓以宝珠为庄严。
〔9〕 世界种　住在香水海中大莲华上的世界体系，如花枝层叠，自下而上安列二十层世界，每层之外另有众多世界围绕；「种」谓能含藏、出生无量世界。
〔10〕 为体　固定句式「以……音声为体」，谓该世界种中的佛菩萨皆以此类音声说法教化众生，即此世界的特质。如「吼音」即狮子吼般的说法大音。
〔11〕 此中最下方　每一世界种最底层（第一层）的世界；此后经文皆按「此上过佛刹微尘数世界，有世界……」的格式自下而上逐层列举，直到最上方第二十层。
〔12〕 弥覆　弥，遍满；弥覆即普遍地覆盖在上面，形容种种「云」严饰于世界上空。
〔13〕 佛刹微尘数　刹（chà）指佛国土；谓把一个佛国土碾碎为微尘，以尘数比喻极多，是华严惯用的大数，非实指。
〔14〕 纯一清净　谓该层世界全部是清净的净土，没有秽恶国土掺杂其中。
〔15〕 此上过　从下一层向上越过这么多世界之后，即「上一层」的固定句式；每条末尾「佛刹微尘数世界围绕」谓该世界外围还有这么多世界如眷属般环绕。
〔16〕 华蕊　蕊（ruǐ），花心、花须；「宝华蕊海」谓由众宝之花的花蕊所成的海。
〔17〕 真珠幢　真珠即珍珠；幢（chuáng）是用丝帛制成的柱形庄严具，立如柱、张如旗，佛菩萨常用来严饰道场。
〔18〕 师子座　师子即「狮子」的古写；佛菩萨所坐之座，喻说法无畏如狮子王，并非真的狮皮之座。
〔19〕 尸利　梵语 śrī 音译，义为吉祥、胜德；「尸利华光轮」即「吉祥华光轮」。
〔20〕 常雨　雨（yù）作动词，谓如降雨般降下；「常雨香水」即时常降下香水。
〔21〕 身云　华严常以「云」喻无量、遍布；「身云」谓佛菩萨化现的身相无量无数，如云弥漫覆盖。
〔22〕 梵音　梵，清净之义；梵音即清净远彻、能遍及远方的音声。
〔23〕 卐字　卐音 wàn，佛胸前三十二相之一的吉祥纹记，象征功德圆满；「形如卐字」谓世界平面呈卐字形。
〔24〕 因陀罗网　帝释天宫殿所悬的宝珠网，珠珠相映、影影互摄、重重无尽；华严借此喻法界缘起、一多互摄无尽的景象。
〔25〕 须弥　须弥山，梵语 Sumeru，佛教宇宙观中一个世界中央的高山，四大部洲环绕其周；经中多以之为形状、所依之喻。
〔26〕 帝释　帝释天，忉利天主，梵语释提桓因（Śakra，即因陀罗）之略称；经中「帝释形」谓其形相如帝释天之庄严。
〔27〕 迥照　迥（jiǒng），遥远、明亮；迥照即光明远照。
〔28〕 法界　梵语 dharmadhātu，一切诸法的总体、真如法性，是华严宗义理的核心；佛号、世界名中冠「法界」，表其智德周遍一切法。
〔29〕 城廓　廓同「郭」，外城城墙；「广大城廓」形容世界的形状像一座巨大的城池。
〔30〕 四洲　一个世界单位中的四大部洲（东胜身洲、南赡部洲、西牛货洲、北俱卢洲）；「状如四洲」谓世界形如四洲环绕须弥山的布局。
〔31〕 璎珞　用珠玉串成的颈饰、严身之具；经中多作庄严之物名。
〔32〕 开敷　（花朵）开放、盛开；「开敷华」即盛开之花。
〔33〕 阿修罗　梵语 Asura 音译，六道之一的「非天」神，力大而多嗔；此处只取其身形作世界形状之喻。
〔34〕 栴檀　梵语 candana 音译，即檀香木，香气浓郁；亦作「旃檀」，本经用「栴檀」。
〔35〕 八隅　隅（yú），角落；八隅即八个角，谓世界呈八角形。
〔36〕 漩流　漩（xuán），水流回旋；「香水漩流」形容海水旋绕流转之状。
〔37〕 大商主　商队之首领；喻佛如商主引导众生穿越生死旷野、趣向涅槃宝所。
〔38〕 右旋　顺时针方向；华藏世界海中诸香水海绕中央依次右旋排列，故本卷每以「右旋」衔接下一个香水海。
〔39〕 毫相　佛眉间之白毫，三十二相之一，其毛旋转如琉璃筒，常放光明；「眉间毫相」即指此。
〔40〕 帝青宝　帝青，梵语因陀罗尼罗（indranīla）之意译，青色宝中最胜，即蓝宝石。
〔41〕 周回　回环、曲折环绕；「其状周回，有无量角」谓该世界轮廓回环而带众多棱角。
〔42〕 间错　间（jiàn）杂错落、交错镶嵌；「众宝间错」谓众宝交错相间为饰。
〔43〕 帝网　即因陀罗网——帝释天宫的宝珠网，珠影重重、无尽映现；经中「帝网云」「帝网幢」皆取此严饰之义。
〔44〕 法身　佛三身（法身、报身、化身）之一，以真如法性为身，无形无相而遍一切处。
〔45〕 波罗蜜　梵语 pāramitā 音译，义为「到彼岸」，谓菩萨修行法门能令众生由此岸生死度至彼岸涅槃。
〔46〕 频申　又作「频呻」，舒展身体、屈伸自如；「师子频申」如狮子奋迅舒身，喻佛威神自在、说法无畏之相。
〔47〕 不唐现　唐，徒然、空自；「不唐现」谓佛不虚然出现于世，现身必能利益众生。
〔48〕 不退转　谓菩萨修行至一定阶位后不再退失堕落；佛号中之「不退转」谓其功德坚固不退（另「不退轮」谓说不退之法轮）。
〔49〕 紧那罗　梵语 kiṃnara 音译，天帝的歌舞乐神，人形而头上有角，善奏妙音；「大树紧那罗」亦是著名的菩萨名。
〔50〕 多罗　多罗树（tāla），东印度高大的棕榈科树木，叶长而韧，古时用以书写经文（贝叶经）。
〔51〕 栏楯　栏杆、护栏；楯（shǔn）指栏的横木，「形如栏楯」谓世界形状如曲折的栏杆。
〔52〕 香象　身出香气、力大稳重的巨象，象中第一；喻大力量、大行愿（亦为菩萨名）。
〔53〕 心王　心为诸法之王，能统御一切；此处是摩尼宝之名，喻此宝在众宝中如王最胜。
〔54〕 菩萨地　菩萨修行之阶位（如十地等）；此处句读为「一切菩萨地·方便法·音声为体」，谓以演说菩萨诸位与方便法门之音声为体，勿误连读为「地方」。
〔55〕 珠髻　髻（jì），盘结于头顶的发髻；珠髻谓以宝珠庄严的发髻。
〔56〕 善惯习　惯习，串习、熟练修习；「善惯习」谓善于熏修串习善法。
〔57〕 天城宝堞　堞（dié），城墙顶部齿形的矮墙（女墙）；「天城宝堞」谓天人之城、以众宝为堞。
