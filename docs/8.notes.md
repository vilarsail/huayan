# 大方广佛华严经卷第八 词语注释

① 普贤菩萨　本卷说法主，承佛神力为大众宣说华藏庄严世界海之相。于华严会中表「行」之大用，以普贤行愿为入华藏之钥。
② 诸佛子　普贤对与会菩萨大众之称呼，意谓佛之弟子、法王子。本卷十数度以「诸佛子」起告，引出各层庄严。
③ 华藏庄严世界海　本卷所讲的总世界，由毗卢遮那往昔愿行所严净，以香水海中大莲华为胎，金刚轮山周匝围绕。即整部《华严经》所安立的总报土。
④ 毗卢遮那　梵语 Vairocana，意为「遍一切处」，指法身佛所显他受用身，为华藏世界海教主。新译作毗卢遮那，旧译作卢舍那，所指同一。
⑤ 微尘数　华严常用量词，以极微尘数喻不可算计之极多，非实指具体数目，而表数量不可思议。本卷反复出现「世界海微尘数」「佛刹微尘数」。
⑥ 风轮　持载世界下方之风力层，层层上持。最下名平等住，最上名殊胜威光藏，共须弥山微尘数，层层托起香水海与大莲华。
⑦ 摩尼　梵语 mani，意译珠玉、如意宝珠，能满足所愿、放光现相。本卷大量以「摩尼」为庄严材料，宝中能现佛身、现境界。
⑧ 香水海　充满香水之海，为世界所依之水体。最上风轮持普光摩尼庄严香水海，海生大莲华，华藏世界即住其中。
⑨ 种种光明蕊香幢　香水海所生大莲华之名，华藏庄严世界海即住此莲华之中。「蕊」指花蕊，「幢」表高显，光明与香气共成高显之相。
⑩ 金刚轮山　围绕华藏世界海外围之金刚所成山脉，作护持界垣，周匝围绕，坚固不可沮坏。
⑪ 调伏　调和降伏众生烦恼，令入正法。本卷颂中「种种方便示调伏」「一切众生悉调伏」指佛以神力方便化导群机。
⑫ 大轮围山　本卷所述华藏世界海内的大山，住于日珠王莲华之上，栴檀摩尼为身，威德宝王为峰，是围护香水海及大地的内围山。
⑬ 栴檀　梵语 candana，香木名，即白檀香，香气清妙。本卷以栴檀摩尼为山身、栴檀细末澄于海下，皆表戒香福德。
⑭ 甘露　梵语 amrta，意译不死之药，喻涅槃与佛正法。本卷「演说如来甘露法」以甘露喻佛所说能令众生离生死之妙法。
⑮ 佛刹　梵语 ksetra，一佛所教化之国土。本卷「佛刹微尘数」为常用量词，表一佛土之微尘数，极言其多。
⑯ 阶陛　台阶阶级。「十宝阶陛行列分布」指香水海周以十宝所成阶梯层层分布。
⑰ 栏楯　栏杆。横为栏，竖为楯，围绕台座阶陛之护栏。本卷以十宝栏楯周匝围绕庄严。
⑱ 四天下　即四王天所护之须弥山四方：南阎浮提、北郁单越、东弗婆提、西瞿耶尼。本卷以「四天下微尘数」为量词表庄严之数。
⑲ 芬陀利　梵语 pundarika，白色莲华，亦表大白莲华，佛教中喻清净无染。本卷屡以芬陀利华庄严香水海与大地。
⑳ 那由他　梵语 nayuta，极大数词，或译亿、兆，表极多。本卷「不可说百千亿那由他数」叠用极数以状庄严之繁。
㉑ 尸罗幢　梵语 sila 译戒，「尸罗幢」即以戒德所成之宝幢，高显戒行。本卷「众色金刚尸罗幢海」「十宝尸罗幢」皆以戒德为庄严。
㉒ 十力　佛所具十种殊胜智力，如处非处力、业力智力等。本卷颂「悉以十力广开演」指以佛十力广说诸佛境界。
㉓ 世界种　华严特有概念，指香水海中安住的一类世界聚落，一世界种含不可说佛刹微尘数世界。各有依住、形状、体性等差别。
㉔ 回转形　世界种形状之一，回旋盘曲之形，如水流回环；与「漩流形」相近而有别，回转偏于盘曲，漩流偏于水旋。
㉕ 轮辋　车轮之边框。本卷「轮辋形」指如车轮外缘之圆环状世界，区别于「轮围山」之山体。
㉖ 坛墠　筑土为坛，除地为墠，皆祭神修法之所。本卷列「坛墠形」为世界种形状之一，以方坛之形喻世界。
㉗ 胎藏　本卷列为世界种形状之一，喻如母胎含藏子体，世界依胎藏之形安住，表含摄生成之义。
㉘ 佉勒迦　梵语 khaka 音译，本卷列为世界种形状之一，具体所指古来多解，约指某种器物或瓶形，表世界形相之一种差别。
㉙ 门闼　门与小门/门楼。本卷「一切门闼形」列世界种形状之一，以门阙之形喻世界之相。
㉚ 含识　含心识之众生，即一切有情。本卷末颂「普化一切诸含识」指佛化导一切有心识之众生。
㉛ 因陀罗网　梵语 Indra，即帝释天；因陀罗网为帝释天宫之网，网孔皆缀宝珠，珠珠互映、重重无尽，喻一多相即、事事无碍。
㉜ 帝青宝　帝释天所具青色宝，色如蔚蓝，喻澄净。本卷「恒出现帝青宝光明」世界即以此宝光明为名。
㉝ 娑婆　梵语 saha 意译「堪忍」，即吾人所居之秽土。本卷明示娑婆为中央世界种第十三重，毗卢遮那所都——秽土本是华藏庄严之一分。
