# 大方广佛华严经卷第三十 导读

## 一、内容总览

本卷为《大方广佛华严经·十回向品》第二十五之八，是十回向位的最后一品（第八回向），即「真如相回向」。在十回向的次第中，前七回向（不坏、等一切佛、至一切处、无尽功德藏、入一切平等善根、随顺一切坚固、等心随顺一切众生）层层展开菩萨以善根回向利益众生的愿行；至第八「真如相回向」，则将一切善根回向与「真如」之性相契——善根回向的体性与真如无异，故称「真如相」。本卷主旨：菩萨以深心、智方便集诸善根，观善根无量差别，悉回一切种智，复以「譬如真如」的连珠譬喻，将回向善根与真如之性一一对应，显明回向即真如、真如即回向的平等一相，最后由金刚幢菩萨以颂重宣其义。

## 二、结构层次（★重点）

全文按「释义 → 修相 → 譬喻对应 → 平等利益 → 颂结」五段推进：

- **释义（P3-P5）**：先标名「真如相回向」，继述菩萨正念坚住、成不坏业、志求大乘的根本德相 → 由此发起慧眼普观，列述善根在「求缘、办具、治净、趣入、专励、起行、明达、精审、开示」等十类修相中的种种门、境、相、事、分、行 → 悉回向一切种智，唯一无二，并分列「愿得无碍身口意业」等大愿。
- **修相（P6-P8）**：先以「为己身如是回向，如是而为一切众生」总起 → 列「愿一切众生永离地狱畜生」等回向众生的愿文（约「离苦、灭障、得智、入菩提」展开） → 再举见可爱乐国土园林时的方便回向，连发数十「可爱乐」愿 → 复述善根修习时得智慧明、为善知识摄受、永灭痴冥的修证次第。
- **譬喻对应（P8 末-P20，本卷核心）**：以「譬如真如……善根回向亦复如是」的连珠句式，将真如约百种德相（遍一切处、真实为性、恒守本性、无相为相、不可破坏、体性寂静、常住无尽、不可言说、遍三世、超数量、体性不动……）与善根回向一一对应，构成「真如—回向」的等流。中间夹叙「不着世间、不取众生、正念诸法、观诸法性皆悉寂灭」的般若行相作为引子，显明回向之所以同真如，正因契入诸法实相。
- **平等利益（P21）**：以「菩萨如是回向时，得一切佛刹平等、一切众生平等、一切菩萨平等、一切诸佛平等、一切法平等、一切世间平等、一切菩萨行平等、一切时平等、一切业果平等、一切佛自在神通平等」十种平等收束，显回向的果德。
- **颂结（P22-P24）**：先总结第八真如相回向的功德——证无量清净法门、得佛无量圆满身音力神通解脱三昧辩才等 → 最后由金刚幢菩萨承佛威力以长颂重宣，点出「真如遍一切、业亦如是无有边」「菩萨观心不在外亦不在内」「了知诸世间悉与真如性相等」的旨归。

过渡语以「佛子」「菩萨尔时」「譬如真如」「尔时，金刚幢菩萨」层层勾连，由修因到证果、由譬喻到平等、由长行到颂偈，环环相扣。

## 三、关键结论

1. 真如相回向的「相」即真如之性相——善根回向之所以可与真如一一对应，正因菩萨契入诸法实相，了知业性空、法无自性、同一实相。
2. 回向的根本行相是「不着世间、不取众生、正念诸法、离分别见」——以般若空慧为体，以无所得为方便，方契真如。
3. 回向善根与真如「平等、无二、无尽」——遍一切处时、常住无尽、不可破坏、体性清净，二者体性一致，故回向即真如的显现。
4. 此回向成就十种平等——佛刹、众生、菩萨、诸佛、法、世间、菩萨行、时、业果、佛自在神通皆悉平等，显一相无相的大乘究竟。
5. 菩萨住此回向即得佛无量圆满功德——一身充遍、一音开悟、一毛孔容一切国土，是十回向位通向十地、佛果的关键阶位。

## 四、易混辨析

- **回向 vs 回向门 vs 正回向门**：「回向」是菩萨将所修善根转向一切智、众生利益的行法总名；「回向门」指其作为一种法门轨则；「正回向门」特指契合三世诸佛正理、无偏无倒的回向，文中「不违三世一切诸佛正回向门」即此。
- **真如 vs 真如相 vs 真实相**：「真如」是诸法本然之理体；「真如相」指真如所显现的种种性相（遍一切处、常住、清净等）；「真实相」即诸法实相，文云「不坏如来真实之相」「了一切法同一实相」即此。
- **一切智 vs 一切种智 vs 一切智智**：「一切智」是知诸法总相空之智；「一切种智」是知诸法种种别相之智（佛智）；「一切智智」则为佛果圆满之智，文中「获得平等一切智智」即指佛果智。
- **十回向 vs 十地**：十回向是菩萨三贤位（十住、十行、十回向）之终，是通向十地（欢喜地至法云地）的前行；本卷第八真如相回向位已能得佛无量功德，显回向位与佛地因果相即。
