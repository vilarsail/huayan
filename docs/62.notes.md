# 大方广佛华严经卷第六十二 词语注释

① 入法界品　《华严经》最后一品（第三十九品），以善财童子五十三参为线索，显示由凡夫入法界的修行次第；本卷为该品之三。
② 文殊师利　Manjushri，智慧第一的大菩萨，本卷中劝比丘发心、南行至福城说法，并指授善财童子起行参访，为五十三参的发起者。
③ 阿耨多罗三藐三菩提　梵语 Anuttara-samyak-sambodhi 的音译，意为「无上正等正觉」，即佛果之智；本卷反复出现「发阿耨多罗三藐三菩提心」，即发成佛度生之心。
④ 福城　善财童子故乡之城，文殊师利说法所在地；音译或作「福城」（Drona 之意译），传为善财诞生之处。
⑤ 娑罗林　即娑罗双树林，佛教圣树；本卷特指「庄严幢娑罗林」，为往昔诸佛曾所止住教化众生之大塔庙处。
⑥ 大塔庙　即佛塔与塔庙（stupa/caitya），本卷谓「往昔诸佛曾所止住教化众生大塔庙处」，亦是世尊往昔修菩萨行能舍难舍之处。
⑦ 佛刹　梵语 buddha-ksetra，一佛所教化之国土世界；本卷「无量佛刹」「佛刹微尘数佛」等反复出现，极言所缘之广。
⑧ 乾闼婆　Gandharva，天龙八部之一，天上的乐神、香神；本卷作供养众与海中大莲华之庄严者出现。
⑨ 阿修罗　Asura，天龙八部之一，性好斗；本卷「百万阿修罗王执持其茎」为海中大莲华之庄严。
⑩ 迦楼罗　Garuda，天龙八部之一，金翅鸟；本卷作供养众与莲华庄严出现。
⑪ 紧那罗　Kimnara，天龙八部之一，人非人之乐神；本卷作供养众出现。
⑫ 摩睺罗伽　Mahoraga，天龙八部之一，大蟒神；本卷列于供养众。
⑬ 修多罗　梵语 sutra 的音译，意为「契经」「经」；本卷「普照法界修多罗」为文殊所说之经名，以无量修多罗为眷属。
⑭ 那由他　梵语 nayuta 的音译，极大量之数词；本卷「百万亿那由他修多罗以为眷属」用以形容经法眷属之众多。
⑮ 优婆塞　Upasaka 的音译，意为「清信士」，即在家受五戒之男众；本卷有五百优婆塞随大智优婆塞来集。
⑯ 优婆夷　Upasika 的音译，意为「清信女」，即在家受五戒之女众；本卷有五百优婆夷来集。
⑰ 善财童子　Sudhana，本卷主角；入胎时七宝楼阁、七伏藏、五百宝器自然涌现，父母与相师因「财」瑞相故名之善财；已曾供佛、心净如虚空，为五十三参之参学者。
⑱ 七宝　佛教所说七种珍宝，本卷作「金、银、琉璃、玻璃、真珠、砗磲、码瑙」；善财入胎时七宝楼阁、七伏藏自然出现。
⑲ 砗磲　梵语 musaragalva 之意译，一种海中贝类宝物，色白润；七宝之一。
⑳ 码瑙　即玛瑙，梵语 asmagarbha 的意译，七宝之一；本卷作善财入胎涌现之宝物。
㉑ 摩尼　梵语 mani 的音译，意为「宝珠」「如意珠」，随人意而现种种宝；本卷多处「摩尼器」「火摩尼」「水摩尼」等。
㉒ 善知识　梵语 kalyanamitra，指能教导众生舍恶修善、引导趣向菩提之师友；文殊反复强调「亲近善知识是具一切智最初因缘」「勿生疲厌、勿见过失」。
㉓ 三有为城　善财颂偈喻辞；「三有」指欲有、色有、无色有三界，「三有为城」即以三界生死喻为城郭，憍慢为垣墙，以喻众生流转之相。
㉔ 三有　指欲有、色有、无色有三界之存在；「三有为城」「三有凡愚宅」皆以三界喻为流转之宅舍城郭。
㉕ 总持　即陀罗尼之意译，总摄无量法义、持而不失；本卷「总持广大箱」「总持坚固力」「总持清净光」等以总持喻为法乘之庄严。
㉖ 三昧　梵语 samadhi 的音译，意为「正定」「等持」；本卷颂中「三昧为采女」「三昧三昧箱」等以三昧喻为法乘之庄严。
㉗ 四摄　菩萨摄受众生的四种方便：布施、爱语、利行、同事；本卷颂「四摄圆满轮」「四摄无尽藏」即指此。
㉘ 德云比丘　善财所参第一善知识，住妙峰山；证「忆念一切诸佛境界智慧光明普见法门」，以二十一种念佛门普见十方诸佛。
㉙ 胜乐国　文殊所指南方国土名，妙峰山所在；其山有德云比丘，为善财第一参之所。
㉚ 妙峰山　胜乐国中之山，德云比丘所住处；善财于此山东西南北四维上下观察求觅，经七日方见于别山上见德云。
㉛ 阎浮提　Jambudvipa，即南赡部洲，人类所居之洲；本卷「阎浮提微尘数佛」「阎浮檀金」皆以此洲立名。
㉜ 微尘数　华严常用极数，以一佛刹中所有微尘之数为量；本卷德云所举「阎浮提微尘数佛」「佛刹微尘数佛」乃至「不可说不可说佛刹微尘数佛」，极言诸佛之多。
㉝ 海云比丘　善财所参第二善知识，住海门国；住彼十二年思惟大海十种相，见海中大莲华如来摩顶说「普眼法门」，以十种陀罗尼光明领受。
㉞ 波罗蜜　梵语 paramita 的音译，意为「到彼岸」「度」，菩萨修行之六度或十度；本卷「令我载此乘」之颂中隐摄六度。
㉟ 因陀罗尼罗宝　Indra-nilamani 的音译，帝释青宝，一种青色宝石；本卷为海中大莲华之茎材。
㊱ 阎浮檀金　Jambu-nada-suvarna，产于阎浮树间之紫磨金，色赤黄；本卷为海中大莲华之叶材。
㊲ 普眼法门　海云比丘所闻佛摩顶而得之法门，开示一切如来境界，显发一切菩萨诸行，一切法轮悉入其中；海云自言「唯知此普眼法门」。
㊳ 陀罗尼　梵语 dharani 的音译，意为「总持」「能持能遮」，以少字摄无量法义；本卷海云比丘以十种陀罗尼光明领受普眼法门之无量品。
㊴ 由旬　梵语 yojana 的音译，古印度计距单位，一说一由旬约四十里；本卷「从此南行六十由旬」至海岸聚落。
㊵ 楞伽　Lanka，即今斯里兰卡一带；本卷「楞伽道边海岸聚落」为善住比丘所住处。
㊶ 善住比丘　善财所参第三善知识，住楞伽道海岸聚落；于虚空中经行，成就「无碍解脱门」，得无住无作神通力，身遍十方佛刹供养诸佛。
㊷ 无碍解脱门　善住比丘所证法门，以「无住无作神通力」故，于众生心行、没生、宿命、未来劫事等一切无所障碍，身遍十方佛刹。
