# 大方广佛华严经卷第三十四 词语注释

① 十地　菩萨修行十种阶位：欢喜、离垢、发光、焰慧、难胜、现前、远行、不动、善慧、法云。三世诸佛已说当说今说，为菩萨向菩提最上道。
② 他化自在天王宫　欲界第六天（最高天）之天宫，此天以他人所化乐事而自受用，故名他化自在。十地法在此说，表此法超越下界诸天境界。
③ 摩尼宝藏殿　由如意宝（摩尼）所成之宝藏殿堂，为此次说法之道场，喻法界功德宝藏。
④ 阿耨多罗三藐三菩提　梵语 anuttarā-samyak-saṃbodhi 音译，意为「无上正等正觉」，即佛果之智。本卷谓诸菩萨于此「不退转」，即已得不退失于佛智。
⑤ 助道　资助正道（菩提）之诸善法，如六度万行。初地菩萨「善集助道」「具足菩萨福智助道」，方能进趣佛智。
⑥ 三昧　梵语 samādhi 音译，意为「定」「等持」，心一境性。本卷金刚藏所入「菩萨大智慧光明三昧」为说十地之本定。
⑦ 三摩钵底　梵语 samāpatti 音译，意为「等至」，较三昧更广，含定中种种差别境界，如八解脱、八胜处等，皆名三摩钵底。
⑧ 法界　梵语 dharmadhātu，诸法之体性，一切法所依、所归。本卷菩萨愿行「广大如法界」，以法界为量。
⑨ 金刚藏菩萨　本会主说法菩萨，以金刚智藏为体，承佛神力入菩萨大智慧光明三昧、宣说十地，为十方同名金刚藏诸佛所加持。
⑩ 毗卢遮那　梵语 Vairocana，意为「遍一切处」「光明遍照」，此经指法身佛，乃十地法门之本愿力、威神力所依。
⑪ 陀罗尼　梵语 dhāraṇī 音译，意为「总持」「能持能遮」，以少字少句总摄无量法义，使久持不失。本卷「无错谬总持」即此。
⑫ 解脱月菩萨　本会请法菩萨，知大众心念而三度颂请金刚藏菩萨广释十地，代表已净深心、能证甚深之机。
⑬ 菩萨摩诃萨　梵语 bodhisattva-mahāsattva，意为「大菩萨」「菩萨大士」，指已登地或已发大心的上首菩萨，胜于初发心者。
⑭ 佛刹微尘数　将一佛刹（佛国土）碎为微尘而计其数，喻极多。本卷中十方各十亿佛刹微尘数诸佛现身加持金刚藏。
⑮ 善男子　佛对在家出家修行者之尊称，此经中诸佛称金刚藏菩萨为「善男子」，表其堪受大法。
⑯ 应、正等觉　如来十号中「应供」（应受天人供养）与「正等正觉」（无上正真之觉）之合称，此处指毗卢遮那如来。经中作「如来、应、正等觉」。
⑰ 灌顶　梵语 abhiṣeka，本为古印度立太子时以水灌顶之礼，佛教借指菩萨将登佛位时受诸佛智水灌顶。本卷谓金刚藏受一切佛灌顶。
⑱ 欢喜地　十地之初地，梵语 Pramuditā。初证二空、生如来家、得从未有之欢喜，故又名极喜地。以不动相应，永离五怖畏，檀波罗蜜增上。
⑲ 菩萨力焰明　世尊眉间所放清净光明之名，喻菩萨十力、智慧焰明，为说十地之瑞光。
⑳ 阿僧祇　梵语 asaṃkhyeya 音译，意为「无数」「无央数」，印度大数单位之一，极言数量之巨。本卷常以「百千阿僧祇」「百万阿僧祇大愿」言愿行无量。
㉑ 白净法　无漏之善法，以其清净无垢、能生善果，故名白净。初地菩萨「善集白净法」为入地资粮。
㉒ 善知识　梵语 kalyāṇamitra，意为「好师友」「胜友」，能引导人发菩提心、修菩萨行者。本卷强调初地菩萨应从诸佛菩萨善知识所推求请问诸地相果。
㉓ 法轮　佛所说正法能破众生烦恼，如轮王之轮宝，碾摧一切，故名法轮。转法轮即说法度生。
㉔ 善巧方便　梵语 upāya-kauśalya，善用种种方便善巧度化众生之智，与般若同为菩萨二大道。初地菩萨发心即以「善巧方便所摄」。
㉕ 波罗蜜　梵语 pāramitā 音译，意为「到彼岸」「度」，谓由生死此岸到涅槃彼岸之菩萨行。十波罗蜜：施、戒、忍、精进、禅、般若、方便、愿、力、智。
㉖ 毛竖　即「毛竖」，毛骨悚然竖立之相，指众生惊怖时身毛皆竖。本卷谓菩萨入欢喜地已，永离「怖畏毛竖等事」。
㉗ 兜率天宫没　佛八相成道之第一相「下生」：从兜率天（补处菩萨所居）降神入胎。本卷菩萨愿于诸佛兴世时亲近供养。
㉘ 三界　欲界、色界、无色界，众生生死流转之总域。本卷谓凡夫「于三界田中复生苦芽」，即于三界中循环受苦。
㉙ 六趣　众生轮回之六道：地狱、饿鬼、畜生、阿修罗、人、天（亦名六道）。本卷菩萨愿教化入六趣一切生处之众生令入佛法。
㉚ 名色　五蕴之初二：受想行识合为「名」，色即色身。十二因缘中「识缘名色」即此，名色共生不离，增长则生六处聚落。
㉛ 帝网　帝释天宫殿所悬之珠网，珠珠互映、重重无尽。本卷以「如帝网差别」喻世界重重互入、差别无量。
㉜ 十尽句　菩萨大愿成就之所依：众生界尽、世界尽、虚空界尽、法界尽、涅槃界尽、佛出现界尽、如来智界尽、心所缘界尽、佛智所入境界界尽、世间转法转智转界尽。十界不可尽故愿亦无尽。
㉝ 欲流、有流、无明流、见流　四流（caturaśrava）：欲流（欲界烦恼）、有流（上二界烦恼）、无明流（痴暗）、见流（种种邪见），众生为此四流所漂，不出三界。经中作「欲流、有流、无明流、见流，相续起心意识种子」。
㉞ 那由他　梵语 nayuta 音译，意为「亿」级大数，比阿僧祇更巨。本卷屡见「亿那由他佛」「百千亿那由他劫」。
㉟ 檀波罗蜜　梵语 dāna-pāramitā，即布施度，十波罗蜜之首，欢喜地所增上。财施、法施、无畏施皆摄。
㊱ 萨婆若　梵语 sarva-jña 音译，意译「一切智」，即佛智。本卷商主喻谓菩萨将众生至「萨婆若城」，即令众生成佛。
㊲ 阎浮提　梵语 Jambudvīpa，即南赡部洲，人类所居之洲。初地菩萨多作阎浮提王，以法化民。
㊳ 五怖畏　不活畏、恶名畏、死畏、恶道畏、大众威德畏。初地菩萨离我想、离我见、不希他供、志乐无等、必不离诸佛，故五畏皆永离。
