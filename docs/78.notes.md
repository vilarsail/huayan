# 大方广佛华严经卷第七十八 词语注释

① 弥勒菩萨　梵语Maitreya，慈氏，此生补处菩萨，灌顶地中佛长子。本卷为善财广说菩提心功德。
② 阿耨多罗三藐三菩提　梵语，意译无上正等正觉，即佛果。善财每参必先自陈已发此心，弥勒亦以「一生当得」授记。
③ 波罗蜜　梵语pāramitā，意译到彼岸，菩萨所修六度等之总称，圆满即到彼岸。弥勒叹善财「已圆满一切波罗蜜」。
④ 三昧　梵语samādhi，意译定、正受，心一境性。弥勒已成就一切三昧法。
⑤ 陀罗尼　梵语dhāraṇī，意译总持，忆持佛法不忘之法门。弥勒已证得一切陀罗尼辩才。
⑥ 灌顶　古印度立太子以四海水灌顶之礼，借喻菩萨入第十地或等觉位，蒙佛授记。弥勒「已受佛灌顶」。
⑦ 菩萨摩诃萨　摩诃萨意为大，合称大菩萨，指已入地、行愿深广之菩萨，如弥勒。本卷以「菩萨摩诃萨亦复如是」反复立喻。
⑧ 善知识　梵语kalyāṇamitra，能教菩萨行、益菩提心之师友。善财经一百一十善知识，最初由文殊劝导发心。
⑨ 福城　善财初发心处，文殊师利于此劝导善财南行参访善知识。
⑩ 一百一十善知识　善财自福城南行所参善知识之总数，弥勒为最后一参之终。
⑪ 无明　梵语avidyā，愚痴不明，为生死流转之根本。菩提心如利锯能截无明树。
⑫ 甘露　梵语amṛta，不死之药，喻佛一切智法水，能灭烦恼、令安住不死界。
⑬ 菩提心　梵语bodhicitta，愿求无上正等正觉、度脱一切众生之心。本卷以百余则譬喻广说其功德，为一切菩萨行之根本。
⑭ 那由他　梵语nayuta，极大数词，约当千万亿。余菩萨经无量百千万亿那由他劫乃能满足菩萨愿行。
⑮ 善男子　佛及菩萨对求法者的敬称，此处弥勒以此称善财。
⑯ 文殊师利　梵语Mañjuśrī，妙吉祥，大智菩萨。善财曩于福城受文殊教，展转南行求善知识。
⑰ 二乘　声闻乘与缘觉乘之合称，修四谛、十二因缘，求自了生死。菩提心功德恒胜二乘。
⑱ 须弥山　梵语Sumeru，世界之中枢，极高峻，喻菩提心于诸众生心平等、功德高出。
⑲ 铁围山　一小世界外之铁轮围山，坚固不动，喻菩提心摄持一切诸世间。
⑳ 莲华　喻菩提心出于世法而不染，如莲华不染一切诸罪垢。华严常取此喻。
㉑ 金刚　梵语vajra，最坚最利之物，喻菩提心之坚不可坏、利能穿彻一切法、能摧诸邪见山。
㉒ 栴檀　梵语candana，香木名，有白赤黑等种。白栴檀除众欲热，黑沉香能熏法界。
㉓ 毗笈摩药　天竺神药，能令毒箭自然堕落，喻菩提心令贪恚痴诸邪见箭自然脱落。
㉔ 帝释　梵语Śakra，忉利天主，名因陀罗。喻菩提心于一切主中最为尊。
㉕ 毗沙门　梵语Vaiśravaṇa，北方多闻天王，喻菩提心能断一切贫穷苦。
㉖ 如意珠　如意摩尼宝，能雨一切庄严具、除一切贫穷。喻菩提心能满一切众生愿。
㉗ 那罗延　梵语Nārāyaṇa，天上大力士，喻菩提心能摧一切我见敌、有大那罗延力方堪持。
㉘ 阿伽陀药　梵语agada，万应灵药，喻菩提心能令无病永安隐。
㉙ 帝青宝　帝释青色宝，喻菩提心出过世间二乘智。
㉚ 翳形药　隐身之药，喻菩提心令一切诸魔不能得见。
㉛ 摩尼　梵语maṇi，意译宝珠，如意宝，能出种种所须。本卷广以摩尼喻菩提心宝。
㉜ 转轮王　梵语cakravartin，人间有威德之圣王，具七宝。喻菩提心大摩尼宝能破诸趣无明黑暗。
㉝ 由旬　梵语yojana，印度长度单位，约当数十里。自在王珠去日月轮四万由旬。
㉞ 阎浮檀金　阎浮树所在河沙之金，色赤黄，最胜金。喻菩提心除一切智心王大宝外余无及者。
㉟ 波利质多罗　梵语Pāricitraka，忉利天上香树，其皮香气最胜，喻菩提心树功德香超胜二乘。
㊱ 诃宅迦　天竺药汁，一两能变千两铜成真金，喻菩提心回向智药能变一切业惑成一切智相。
㊲ 他化自在天王　欲界顶天主，喻菩提心大愿天冠胜一切凡夫二乘功德。
㊳ 迦陵频伽　梵语kalaviṅka，妙音鸟，在卵㲉中即有大势力，喻菩提心初发即胜二乘。
㊴ 金翅鸟　梵语garuḍa，吞龙之猛禽，王子初生即目明飞捷，喻菩提心为佛王子，大悲勇猛胜二乘。
㊵ 摩竭鱼　梵语makara，海中巨鱼，能吞舟。喻入生死海不为业烦恼所害，乃至入二乘实际亦不留难。
㊶ 安缮那　天竺隐身药，涂目则人所不见，喻菩提心能方便入魔境界而不为所见。
㊷ 金刚杵　释天所执兵器，喻菩提心摧伏一切诸魔外道。
㊸ 机关木人　以机栝牵动之木偶，无楔则身离散，喻无菩提心则菩萨行不能成就一切佛法。
㊹ 金刚座　佛成等正觉之处，喻菩提心能持菩萨一切愿行波罗蜜而令成佛。
㊺ 毗卢遮那　梵语Vairocana，意译遍一切处、光明遍照，即华严教主法身佛。楼阁名「毗卢遮那庄严藏」，表法界藏。
