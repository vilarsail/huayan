# 大方广佛华严经卷第三十七 导读

## 一、内容总览

本卷属《大方广佛华严经·十地品第二十六之四》，紧承前几卷对初地至五地的解说，专明菩萨十地中的**第六现前地**与**第七远行地**。全卷由金刚藏菩萨宣说、解脱月菩萨请问，以长行（散文）与重颂（偈颂）两种文体交替展开。第六地以「十平等观」入「缘起观」，由般若波罗蜜现前而得无障碍智光明；第七地以「十种方便慧起殊胜道」于有功用行之极，过渡至无功用行，为进入第八不动地作准备。两地的共同轴心是：从观空到起悲，从缘起性空到方便善巧，构成大乘不二中道的修证进阶。

## 二、结构层次（★重点）

全文以**长行 → 重颂**的二段式重复两次（第六地一次、第七地一次），每一地内部又循「请 → 答 → 重颂」的层次：

- **第六现前地**（解脱月问 → 金刚藏答）
  - 天众供养赞佛（P4–P20）→ 解脱月起问「以何行相入后地」（P21）
  - 答分三步：
    1. **十平等观入地**（P23）：以无相、无体、无生、本来清净、如幻如梦等十种平等观，得明利随顺忍，未得无生法忍。
    2. **缘起逆顺观察**（P24–P27）：三度复述十二因缘——世间生灭门（业为田、识为种）、第一义谛门（无明为不了第一义谛）、唯是一心门（三界所有唯是一心）；再举「无明有二种业」等十二支各有二业，最终归纳为「烦恼道、业道、苦道」三道如束芦，以及十种逆顺观缘起。
    3. **三解脱门与般若现前**（P28–P33）：由缘起观入空、无相、无愿三解脱门；以大悲不舍众生，得般若波罗蜜现前，名无障碍智光明；住十空三昧门，得第三明利顺忍。
  - **功德校量与摄报**（P33–P34）：真金以毗琉璃磨莹喻善根明净，月光喻灭烦恼炽火；多作善化天王；一念得百千亿三昧。
  - **重颂**（P35–P79）：四十余偈重宣五地满入六地、缘起十观、三解脱门、月光喻等。

- **第七远行地**（天众再赞 → 解脱月再问 → 金刚藏再答）
  - **入地方法**（P106）：十种方便慧起殊胜道——虽修空无相无愿而不舍慈悲、虽知诸法如幻而随心作业等十对「虽…而…」的权实双行，是本卷最难也最关键的一段。
  - **行相展开**（P107–P108）：入无量众生界、无量诸佛境界等二十种「无量」；念念具足十波罗蜜，并以四摄、三十七品、三解脱门总摄一切菩提分法。
  - **诸地比较**（P109–P110）：解脱月问「但七地满菩提分法耶」，答十地皆满而七地最胜，以七地为功用行满、转入无功用之枢纽。杂染净行二世界中间难过之喻在此。
  - **超烦恼行辨析**（P111–P113）：初地至七地未名超烦恼行，舍功用入八地乃名超；七地菩萨不名有烦恼、不名无烦恼——烦恼不现行故、求佛智未满故。转轮圣王乘象宝喻。
  - **善净三业与无生法忍光明**（P114–P116）：三业无相行，得百万三昧，超过二乘，得无生法忍光明。
  - **超过二乘与入灭定**（P117–P121）：王子喻——初地超二乘但由愿力，七地超二乘由自智力；六地能入灭定，七地念念入灭定而不证。
  - **大方便示现**（P122）：十二对「虽…而…」权实双行——示生死而住涅槃、眷属围绕而乐远离、得佛境而示魔境等。
  - **功德校量与摄报**（P123–P124）：真金以众宝间错喻、日光竭爱水喻；多作自在天王；一念得百千亿那由他三昧。
  - **重颂**（P125–P167）：四十余偈重宣方便慧十对、念念波罗蜜、诸地比较、王子喻、乘船入海喻、日光喻等。

## 三、关键结论

1. **第六地的核心是「缘起观」与「三解脱门」**：由十平等观随顺无生，由逆顺观察十二有支，证知无我无作者，依次现前空、无相、无愿三解脱门；般若波罗蜜现前，名无障碍智光明。
2. **第七地的核心是「方便慧起殊胜道」**：以十对「虽证空而起悲」的双行，于功用行极处而过渡到无功用行——既行实际而不作证，是远行地的根本相貌。
3. **十地满菩提分法，七地最为殊胜**：因第七地功用行满，得智慧自在，是染净二世界之间的难关，须以大愿方便慧乃能越过而入八地。
4. **七地超二乘由自智力，非如初地由愿力**：初地超二乘如王子生而胜臣众，由王力非自力；七地则以自所行智慧力出过二乘之上。
5. **大悲与般若恒共相应**：两地反复申明「唯除大悲为首」「念念以大悲为首」，构成菩萨不取证灭、不舍众生的根本动力。

## 四、易混辨析

- **现前地 vs 远行地**：第六地名「现前」，指般若智光、空三昧等如实现前；第七地名「远行」，指功用行至此已远、将入无功用之深远处。一为「智光现前」，一为「功用行远」。
- **明利顺忍 vs 无生法忍**：第六地得「明利随顺忍」「第三明利顺忍」，仍未得无生法忍；第七地始得「无生法忍光明」（亦非圆满无生忍）。顺忍是随顺无生之忍，无生忍是实证无生之忍，二者有深浅之别。
- **烦恼道 vs 业道 vs 苦道**：十二有支中，无明、爱、取三支属烦恼道（能发业之惑）；行、有二支属业道（所作业果）；其余识、名色、六处、触、受、生、老死七支属苦道（所受果报）。三道相束如芦，互依而立，无独立实我。
- **有功用行 vs 无功用行**：有功用行指以心作意、勤策力用而修，从初地至七地皆属此摄；无功用行指无功用心、任运自然，自第八地始。第七地是有功用行之极，第八地是无功用行之始，故二地之间名为「难过」。
- **超烦恼行 vs 超过二乘**：初地至七地虽舍烦恼业（回向菩提、分得平等道），但未名「超烦恼行」，因为求佛智未满、烦恼种子未尽；至八地舍功用行乃名超烦恼。超过二乘则从初地即已开始，但初地由愿力，七地由自智力。

## 五、阅读提示

读本卷可带着三个问题：（1）十二因缘有三种讲法——世间门、第一义谛门、唯心门——它们如何对应？（2）十对「虽…而…」的方便慧，每一对「虽」的所证与「而」的所起是什么关系？（3）「行于实际而不作证」与「无生法忍光明」之分，对理解菩萨与二乘的根本差异有何意义？把这三条线索理清，第六、七地的修证骨架即朗然现前。
