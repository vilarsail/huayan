# 大方广佛华严经卷第六 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第六，即「如来现相品第二」（实叉难陀译本）。紧承卷五「世主妙严品」之末诸菩萨大众云集、普贤入三昧而起，本卷以「诸菩萨请问 → 如来现相答 → 十方菩萨云集赞叹 → 眉间放光、莲华现相、胜音菩萨说颂」一线展开，是华严法会上「问—光—身—颂」四重庄严的集中呈现。主旨在于：以佛神力与菩萨威神，令十方世界海一切菩萨众于华藏世界海中同集一处，由诸菩萨代众发问、由如来面门与眉间放光现相作答，显明毗卢遮那如来法界身、普贤行愿与一多相入的华严境界。

## 二、结构层次（★重点）

全文按「问 → 颂请 → 放光现相 → 十方云集 → 眉间光、莲华出、胜音说颂 → 十菩萨次第说颂」的递进结构展开：

- **菩萨发问（P3）**：诸菩萨及一切世间主作是思惟，以一连串「云何是诸佛地……云何是诸佛智」之十数问，总问佛果境界、佛力、佛三昧、佛六根、佛光明、佛智，并愿佛说世界海、众生海、法海等「十海」及菩萨誓愿、行、波罗蜜等「十海」→ 由境及行、由佛果及菩萨因。
- **颂请（P5）**：菩萨于供养具云中出音说颂，重申请法之意，并将所问归纳为「佛地—佛境—加持—所行—力—三昧—无畏—神通—自在—眼耳鼻舌身意—光明—声—智」之次第，以颂摄问。
- **如来面门放光（P6-P7）**：世尊知众心所念，于面门众齿间放佛刹微尘数光明，一一复有佛刹微尘数光明以为眷属，普照十方；光中出颂，告十方菩萨众「毗卢遮那大智海，面门舒光无不见，今待众集将演音」→ 以光召集。
- **十方云集（P8-P19）**：十方世界海菩萨各从其方来诣毗卢遮那如来所，按东、南、西、北、东北、东南、西南、西北、下、上十方次第，一一列其世界海名、国土名、佛号、菩萨名及其所现十种供养云（华云、摩尼王云、楼阁云、树云、师子座云、帐云、盖云、光明云、光焰云等），各现云已、作礼供养、化作宝庄严师子座、结跏趺坐 → 以十方配十种供养云，呈「一即一切」之相。
- **毛孔光明与念念度生（P19）**：十亿佛刹微尘数菩萨坐已，身毛孔各现十世界海微尘数光明，光中复现菩萨坐莲华藏师子座；一一尘中皆有十佛世界微尘数广大刹、一一刹中皆有三世诸佛；念念中以十种法门开悟众生，复令如须弥山微尘数众生离苦、入正定、生天、住二乘地、发菩提心、得不退转、净智眼、住如来家 → 由「集」到「入」，由「相」到「用」。
- **光明中说颂（P21）**：诸菩萨光明中同时发声说颂，总叹菩萨「劫海修行、性寂灭、三世诸佛愿、一毛端遍动十方、一念现三世」之境界。
- **眉间放光、莲华现相、胜音菩萨出（P22-P24）**：世尊复放眉间光名「一切菩萨智光明普照耀十方藏」，光入足下；佛前忽现大莲华，具十种庄严；白毫相中有菩萨摩诃萨「一切法胜音」与世界海微尘数菩萨俱出，坐莲华台，承佛威神说颂（P25）→ 以「光—华—身」三重现相作答。
- **十菩萨次第说颂（P25-P45）**：胜音菩萨之后，观察一切胜法莲华光慧王、法喜慧光明、香焰光普明慧、师子奋迅慧光明、法海慧功德藏、慧灯普明、华焰髻普明智、威德慧无尽光、法界普明慧、精进力无碍慧等十菩萨，各承佛威神观察十方说颂，层层叹佛身充满法界、一毛现多刹、法身如虚空、影像普现、一音周闻十方等义 → 由一菩萨之颂展转至于十菩萨之颂，呈重重无尽。
- **收束（P46）**：以「如此四天下道场中……十方各有一亿世界海微尘数诸菩萨众而来集会；一切世界海、一一四天下诸道场中悉亦如是」收束，显一处即一切处、一会即一切会。

全文骨架：问 → 光 → 集 → 颂 → 光华身三相现 → 十菩萨十颂 → 一即一切收束。

## 三、关键结论

1. 佛不立言答，而以「面门放光、眉间放光、莲华现相、菩萨出兴」四重现相作答，光明即佛说，现相即法门，显华严「以相说」之特质。
2. 十方菩萨各现十种供养云、各化作宝庄严师子座、结跏趺坐，呈「十方—十云—十座」的对应结构，具体呈现「一即一切、一切即一」的法界相入。
3. 毛孔光明中一一尘皆有十佛世界微尘数广大刹、一一刹中皆有三世诸佛，念念中以十种法门开悟如须弥山微尘数众生，明「微尘含刹、一念度生」的华严事事无碍义。
4. 毗卢遮那佛以法为身、清净如虚空，所现众色形皆令入法中；佛身无生无相而普现诸国，色相如影像、平等如虚空——此即法界身与应化身的不二。
5. 十菩萨次第说颂，皆承佛威神、观察十方，所说义趣层层递进而归于同一旨归：普贤行愿能入、法界周遍、一多相即、性相无碍。

## 四、易混辨析

- **毗卢遮那 vs 卢舍那**：本经中「毗卢遮那」即「卢舍那」之异译（Vairocana），意为「遍一切处」「光明遍照」，指法身佛、报身佛之总名；本卷卷尾诸颂中「毗卢遮那大智海」「毗卢遮那佛，能转正法轮」即此，是华严教主，与「卢舍那」非为二佛。
- **世界海 vs 世界种 vs 国土**：本卷层次为「世界海」（如华藏庄严世界海）→「世界种」（彼世界海中之「世界种」）→「国土」（世界种中之「国土」，各有佛号）→「佛刹」；世界海为最外、国土为最内，故每段云「此华藏世界海东，次有世界海……彼世界种中，有国土……佛号……」。
- **菩萨 vs 菩萨摩诃萨**：菩萨通指发心修行之人；「摩诃萨」意为「大」，菩萨摩诃萨指已登地、行大行、堪与佛果相邻之「大菩萨」，本卷十方来集之菩萨摩诃萨即此类，胜音、慧灯普明等皆称菩萨摩诃萨。
- **面门光 vs 眉间光**：本卷先于「面门众齿之间」放佛刹微尘数光明，作用在召集十方菩萨众同来集会、并告以「今待众集将演音」；后于「眉间」放光名「一切菩萨智光明普照耀十方藏」，作用在令菩萨得如来无边境界神通力，光右绕于佛从足下入、引发佛前大莲华现相——两度放光作用不同、次第分明。

## 五、阅读提示

读本卷时可带着三组问题：第一，诸菩萨所问「云何是诸佛地……云何是诸佛智」之问，佛以何方式作答？（注意「不立文字」与「以光、华、身现相」之间的关系）；第二，十方菩萨所现十种供养云（华云、摩尼王云、楼阁云、树云、师子座云、帐云、盖云、光明云、光焰云等）与十方方位如何对应、各有何表法？第三，十菩萨所说十颂，其主题如何由「佛身充满法界」层层展转至于「一毛现神变、一切佛同说」之重重无尽？把握此三组问题，即可将本卷读作一部「以相说法」的现相品。
