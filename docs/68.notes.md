# 大方广佛华严经卷第六十八 词语注释

〔1〕 实叉难陀　于阗国三藏法师，此八十卷本《华严经》的译者，奉武则天之制命译出。
〔2〕 入法界品　《华严经》末会品名，叙善财童子遍访善知识、证入法界的经过；本卷为其中第九卷之续。
〔3〕 尔时　「正当那时」，经中承前启后起叙的时间连接词。
〔4〕 善财童子　本卷主角，因出生时种种财宝自然涌出而得名；发菩提心后南行参访诸位善知识，是经中修学菩萨行的典范。
〔5〕 陀罗尼门　陀罗尼（dhāraṇī），义为总持，能持善法、不忘失；「门」指入手之处。「言音陀罗尼门」即能总持一切语言音声。
〔6〕 险难国　善财所到的国名（内有宝庄严城），与「宝庄严」相对，喻此行历险难而得宝。
〔7〕 婆须蜜多女　梵语音译，宝庄严城的女性善知识；示现以「离贪欲际」解脱度生，众生以何种贪欲亲近她，即以此缘而离欲证定，是转欲染为法门的典范。
〔8〕 谛视一寻　寻，八尺左右；「谛视一寻」谓目光专注不逾一寻、目不斜视，形容善财定心不散。
〔9〕 净想　对女色生起的「清净」妄想，属颠倒想；与「欲想」连用，指观不净为净的错误认知。
〔10〕 依怙　怙音 hù，依靠；「依怙」即依赖、救护者，「无所依怙」谓无所依靠。
〔11〕 市廛　廛音 chán，店铺、集市；「市廛之北」即市场以北。
〔12〕 宝堑　堑音 qiàn，壕沟；围绕宅院的护沟，中盈香水、金沙布底，故称宝堑。
〔13〕 优钵罗华　梵语音译，青莲花；下文波头摩（红莲）、拘物头（黄莲）、芬陀利（白莲），为经中常见的四种莲花。
〔14〕 芬陀利华　梵语音译，白莲花，莲花中最胜者；后文以「人中芬陀利华」喻菩萨稀有难得。
〔15〕 门闼　闼音 tà，门扇；「门闼、窗牖相望间列」谓门窗依次排列、彼此相对。
〔16〕 窗牖　牖音 yǒu，窗。
〔17〕 网铎　铎音 duó，大铃；「咸施网铎」谓处处悬挂宝网与铃铎以为庄严。
〔18〕 沉水　沉水香，即沉香；「烧诸沉水」谓焚烧沉香。
〔19〕 栴檀　梵语音译，檀香木，香气浓郁，经中常用于涂身、造像、建塔。
〔20〕 绀青　绀音 gàn，青中带红的深色；「目发绀青」形容眼目与头发色泽，是佛相好之一。
〔21〕 梵世　色界初禅诸天统称梵世（梵天世界）；「音声美妙超诸梵世」谓其声音胜过梵天。
〔22〕 璎珞　贯串珠玉而成的颈饰、身饰，为菩萨常用的庄严具。
〔23〕 如意摩尼　摩尼（maṇi）宝珠之最胜者，能随人意出生所求之物，故称如意；此处用作宝冠。
〔24〕 阿耨多罗三藐三菩提心　梵语 anuttara-samyak-sambodhi 音译，意译「无上正等正觉」；发此心即立志成佛、度尽众生，是善财每参善知识必先陈述的表白。
〔25〕 菩萨解脱　善知识所证的法门境界，与一般「解脱生死」义不同，指菩萨特有的自在妙用；经中常作「我得菩萨解脱，名……」的句式。
〔26〕 离贪欲际　婆须蜜多女所得菩萨解脱之名；「际」即实际、边际。以身为缘，随众生亲近方式的不同令其离贪欲、证三昧。
〔27〕 菩萨无著境界三昧　下文连列「暂与我语得无碍音声三昧」直至「咂我唇吻得增长福德藏三昧」，是十种三昧的并列清单，读法是抓住「若有众生……则离贪欲，得……三昧」的固定句式，逐条对应。
〔28〕 三昧　梵语 samādhi 音译，义为正定，心专注一境而不散乱。
〔29〕 频申　又作频呻，舒展身体、奋迅动作之貌；「见我频申」谓见其自在舒展之相，也是度生的一种示现（下文「师子频申」同源）。
〔30〕 目瞬　瞬音 shùn，眨眼；「见我目瞬」亦为令众生离欲证定的示现之一。
〔31〕 咂我唇吻　咂音 zā，吮吻；十种亲近方式中最重的一种，所证为「增长一切众生福德藏三昧」，显示此法门能转最深的欲染为福德。
〔32〕 门阃　阃音 kǔn，门槛；「入于王城蹈彼门阃」谓佛足踏城门门槛，全城为之震动。
〔33〕 文殊师利童子　梵语 Mañjuśrī，表大智的菩萨，善财的发心之师；此处追述他为高行如来的侍者，曾为婆须蜜多说法。
〔34〕 鞞瑟胝罗　梵语音译，善度城居士之名，善财的下一参善知识，常供养栴檀座佛塔。
〔35〕 绕无量匝　匝音 zā，圈；右绕尊者无量圈以示敬礼，是经中常见的礼节。
〔36〕 不般涅槃际　鞞瑟胝罗所得菩萨解脱之名；谓其了知诸佛毕竟无有涅槃，唯为调伏众生而方便示现灭度。
〔37〕 般涅槃　梵语 parinirvāṇa 音译，意为圆寂、入灭。
〔38〕 佛种无尽　鞞瑟胝罗开栴檀座如来塔门时所得三昧之名；入此三昧即念念中得见一切诸佛次第出现，成佛之因种（佛种）相续无尽。
〔39〕 所谓　提示下文列举内容的引导词，相当于「即是下列这些」。
〔40〕 迦叶佛　释迦牟尼之前已成之佛；下文拘那含牟尼、拘留孙、尸弃、毗婆尸等皆过去诸佛之列，此处按由近及远的次第逆数列举，读法是视作一份名单通看。
〔41〕 毗卢遮那佛　梵语 Vairocana，意译「光明遍照」，华严经的教主；此处作为现在一切佛的代表。
〔42〕 独觉　于无佛之世独自观因缘而悟道者，即辟支佛；与「声闻」合称二乘，属自了而不度人的小乘。
〔43〕 佛法印　印即印契、印证；「住佛法印」谓安住于佛法的真理之中而不动摇。
〔44〕 补怛洛迦　梵语 Potalaka 音译，又译普陀洛迦，南方海上之山，观自在菩萨的住处；下偈「海上有山多圣贤」即咏此山。
〔45〕 蓊郁　蓊音 wěng，草木茂盛貌；「树林蓊郁」形容林木繁茂。
〔46〕 右旋　顺时针方向；「香草柔软，右旋布地」谓草旋纹右转铺地，右旋在佛门中表随顺恭敬之相。
〔47〕 观自在菩萨　即观世音菩萨；善财的下一参善知识，于补怛洛迦山金刚宝石上说法，自述「大悲行门」，以种种方便救护怖畏众生。
〔48〕 结跏趺坐　修行坐姿，两足交叠置于左右大腿上；观自在菩萨于金刚宝石上如此端坐说法。
〔49〕 善知识　能教导正法、引人入善道的师长；善财所遍访的诸位皆称善知识，经中以「善知识者，则是如来」等一连串譬喻极力推崇。
〔50〕 十力　佛独具的十种智力（知是处非处、知业报、知众生根性等）；「十力宝因」谓善知识是证得十力的宝贵之因。
〔51〕 爱语　与布施、利行、同事连举，即四摄法，菩萨摄受众生的四种方式；爱语指随众生根性以柔和言语引导。
〔52〕 离险道怖　下文自「离险道怖」至「离忧悲怖」共十八种怖畏并列，读法是抓住每条「愿一切众生，离……怖」的重复句式逐条扫读。
〔53〕 轮围山顶　轮围山（又译铁围山），围绕世界边缘的大山；正趣菩萨从空中来至娑婆世界轮围山顶，以足按地令世界震动。
〔54〕 正趣菩萨　从东方妙藏世界空中而来的菩萨，善财的下一参善知识；得「普门速疾行」解脱，一步能过微尘数佛刹。
〔55〕 护世　护世四天王，居须弥山腹四方、各护一四天下的天王；与「释、梵」（帝释、梵王）连举，其光明皆被正趣菩萨身光所映蔽。
〔56〕 遽即　遽音 jù，立刻；「遽即往诣」谓随即立刻前往。
〔57〕 普门速疾行　正趣菩萨所得菩萨解脱之名；「普门」谓遍一切处之门，「速疾行」谓一步遍历微尘数世界。
〔58〕 发来久如　「久如」即多久；此句问正趣菩萨从出发至今已经多久，属「……久如」的疑问句式。
〔59〕 四维　东南、西南、东北、西北四个方位；与上、下合称，即遍一切处。
〔60〕 堕罗钵底　梵语音译城名，善财的下一参处所，城中有神名大天。
〔61〕 大天　堕罗钵底城的天神，善财的下一参善知识，现广大身为众说法，得「云网」解脱，以无量财宝、五欲之具教众生行施。
〔62〕 长舒四手　舒展四只手臂；大天为多臂天神之相，四手取四大海水洗面、持金华散善财，示现神力自在。
〔63〕 希出世间　希通「稀」，稀少；「希出世间，于众生中最为第一」谓菩萨稀出于世间、最为难得。
〔64〕 云网　大天所得菩萨解脱之名；如云网覆盖一切，能示现金银宝聚、五欲娱乐之具，教化众生修布施。
〔65〕 玻璃　即吠琉璃、颇梨一类宝珠，非今日之玻璃；与砗磲（chēqú，海中大贝）、码瑙（即玛瑙）等皆为经中珍宝名，此处一一示现如山。
〔66〕 宝珰　珰音 dāng，耳坠；与宝钏（手镯）、宝锁等皆身饰庄严具。
〔67〕 五欲　色、声、香、味、触五种感官欲乐；大天为贪着五欲者示现不净境界，令生厌离。
〔68〕 檀波罗蜜　檀即檀那（dāna，布施），檀波罗蜜即布施度；「能舍难舍」谓能施舍最难舍之物。
〔69〕 罗刹　梵语 Rakṣasa，食人恶鬼；大天为瞋恚憍慢者示现罗刹饮血啖肉之可怖形，令其惊恐调伏。
〔70〕 惛沈　惛音 hūn，昏沉，心识昏昧无力的状态；大天为惛沈懒惰者示现王、贼、水、火及重疾之厄，令自勉策。
〔71〕 帝释　忉利天主释提桓因，常率天众与阿修罗作战；此处以帝释摧伏阿修罗军，喻菩萨降伏一切烦恼。
〔72〕 见取幢　「诸见取幢」谓种种邪见高举标榜如幢；见取为五见之一，谓执劣见为胜见，幢喻其高立招摇。
〔73〕 摩竭提国　梵语 Magadha，中印度大国，佛陀成道说法之地；此后诸参善知识皆集于其菩提场附近。
〔74〕 菩提场　佛陀成道之处（菩提道场）；本会诸地神、夜神皆以此处为依托。
〔75〕 主地神　掌管一方土地的神祇；「安住」是摩竭提国菩提场的主地神，善财的下一参善知识。
〔76〕 无明㲉藏　㲉音 què，同「壳」，蛋壳；「无明㲉藏」喻众生被无明外壳包裹的烦恼藏，地神言善财必能普坏之。
〔77〕 法缯　缯音 zēng，丝帛；「以离垢无碍法缯而冠其首」喻以正法为其加冠，表已生法王（佛）种中。
〔78〕 伏藏　埋藏于地、待福德之力自然显现的宝藏；「百千伏藏自然踊现」表善财宿世善根的果报。
〔79〕 阿僧祇　梵语 asaṃkhya 音译，意为无数，华严经大数之名；「百千亿阿僧祇宝藏」极言其多。
〔80〕 不可坏智慧藏　安住地神所得菩萨解脱之名；谓其智慧如宝藏不可毁坏，能常随诸菩萨、忆持一切佛事。
〔81〕 然灯佛　即燃灯佛（提洹竭佛），释迦牟尼因地处曾蒙其授记之佛；此处安住地神言自然灯佛以来常随菩萨恭敬守护。
〔82〕 修多罗门　修多罗（sūtra）即契经，佛经的通称；「广说一切修多罗门」谓广说一切经教之门。
〔83〕 贤劫　现在的大劫之名，因此劫中将有一千尊佛出世（拘留孙、迦叶、释迦、弥勒等）而称贤善之劫；「始从初得乃至贤劫」言历劫承事诸佛。
〔84〕 如来、应、正等觉　佛十种名号中的三种：如来（乘如实道而来）、应（应供，堪受人天供养）、正等觉（真正遍知者）；经中常连用作佛的尊称。
〔85〕 迦毗罗城　梵语音译城名，主夜神婆珊婆演底所居之处；经文与摩竭提国连举，示此诸善知识皆在佛成道处一带。
〔86〕 主夜神　守护夜间、救护夜行众生的神祇；婆珊婆演底是迦毗罗城主夜神，善财的下一参善知识，得「破一切众生暗法光明」解脱。
〔87〕 婆珊婆演底　梵语音译，迦毗罗城主夜神之名；于夜暗风雨中以种种现身救济迷途怖畏众生，并追述其多劫前为王夫人法慧月时发心因缘。
〔88〕 师子频申　狮子奋迅舒身之相，喻菩萨教化众生的自在威势；夜神毛孔中所现「菩萨师子频申」即此类教化游戏之一。
〔89〕 劣解　理解力低劣、见解狭劣；夜神于「劣解众生」起「令兴大解心」，是其对各类众生所起十种心之一。
〔90〕 慞惶　慞音 zhāng，惊惧慌乱；「慞惶忧怖」谓慌张惊恐不知所出。
〔91〕 藤萝所罥　罥音 juàn，缠绕、罗网；「藤萝所罥、云雾所暗」形容行于险道被藤蔓缠绕、云雾遮蔽而迷失。
〔92〕 萨婆若　梵语 sarvajña 音译，一切智，佛所证的遍知；「住一切佛萨婆若境」谓安住于佛的一切智境界。
〔93〕 六处聚落　以「聚落」比喻眼、耳、鼻、舌、身、意六根之处；「不贪乐六处聚落」谓不执著六根所对之境，速出离生死。
〔94〕 沟洫　洫音 xù，田间水道、沟渠；「欲度沟洫，示其桥梁」为夜神光中所作的种种指引之一。
〔95〕 想心见倒　想倒、心倒、见倒，三种颠倒；下文「无常常想、无乐乐想、无我我想、不净净想」即四颠倒的具体展开，谓众生以无常为常、以苦为乐等。
〔96〕 蕴界处　五蕴（色受想行识）、十八界、十二处，佛法分析身心的三种分类；「坚固执着我人众生、蕴界处法」谓执著我与诸法为实有。
〔97〕 呰辱　呰音 zǐ，诋毁；「呰辱伤害」谓毁谤、侮辱诸菩萨。
〔98〕 五逆　弑父、弑母、弑阿罗汉、出佛身血、破和合僧五种极重之罪，感无间地狱之报。
〔99〕 普贤乘　以普贤菩萨广大行愿为所乘之教法；「示普贤乘，开十力道」谓为发心众生开示成佛之道。
〔100〕 五趣　天、人、畜生、饿鬼、地狱五种轮回去处（或加阿修罗为六趣）；「轮回五趣中，常受无量苦」谓于诸趣生死流转。
〔101〕 如如　真如、法性平等不动之貌；「三世等如如」谓身遍三世而与真如平等无异。
〔102〕 卢舍那　即毗卢遮那的旧译，光明遍照之义，指佛的报身；偈中「十方刹尘内，悉见卢舍那」谓十方世界微尘之中皆见佛坐菩提树下成道说法。
〔103〕 四天下　一世界的四洲（东胜身、南赡部、西牛货、北拘卢），须弥山四方咸海之中；「王四天下」谓以轮王之德统领四洲。
〔104〕 七宝　轮王七宝（金轮、白象、绀马、明珠、玉女、主藏臣、主兵臣）之属；「成就七宝，王四天下」谓具足转轮圣王的福德。
〔105〕 岂异人乎　反问句式：「难道是别人吗？」意即「正是此人」，下接「我身是也」，是经中揭示说话者前身的惯用句。
〔106〕 普德净光　菩提场内另一位主夜神之名；婆珊婆演底自述最初发菩提心即依此神，并推荐善财前往参问。
