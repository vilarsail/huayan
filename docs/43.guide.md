# 大方广佛华严经卷第四十三 导读

## 一、内容总览

本卷为《十定品第二十七》之四，是普贤菩萨向普眼菩萨等宣讲「菩萨摩诃萨十大三昧」的最后一部分——第十「无碍轮三昧」。此三昧为普贤行之极顶，菩萨住此三昧即等同如来而不舍菩萨行。卷末以「伊罗钵那象王」为喻，收束全品，点明菩萨「不舍普贤行、不断菩萨道」而又「现成正觉」的不二义，并总结「十种三昧」之名，圆满回向品前之定门。

## 二、结构层次

本卷以「无碍轮三昧 → 十喻明菩萨行 → 问答辨位 → 象王大喻 → 总结十定」一线贯穿：

- **三昧体用（P3-P4）**：先标「无碍轮三昧」之相——身语意业、国土、众生、光明、法轮皆无碍；继而以「摩尼宝置色衣」「虚空持世界」「涅槃」「萨婆若」四喻，阐明菩萨观一切智而不舍菩萨行，心无疲厌。
- **莲华变现（P5-P6）**：菩萨于大莲华上结跏趺坐，一一毛孔出不可说光明，重重变现楼阁、师子座、佛、神变、法轮、修多罗——以「一一现一一」之无尽重重，显示普贤境界之广大。后段广述菩萨功德：自性清净、法界实相、五眼成就、入不二门而广说诸法。
- **无碍方便门（P7-P8）**：以「虽知诸法……而演说……」之三十余组对偶句，明菩萨知法性空而恒起大悲、广转法轮；复列举「入不可说智门」等二十余种三昧深入之相。
- **普贤行愿无尽（P9-P10）**：以「如意珠」「凡夫生心」「龙王降雨」「然火」四喻明菩萨心行无尽；十方诸佛现前，与菩萨念力、辩才、神通，令其圆满普贤行，调伏众生尽未来际。
- **十大法藏与同佛十法（P11-P14）**：菩萨恒住十大法藏（忆念诸佛、调伏众生大悲等）；住三昧得十种法同去来今诸佛（相好、光明网、神通、圆音等）。
- **问答辨位（P15-P17）**：普眼菩萨发问——既同诸佛，何故不名为佛、十力、一切智？普贤答以「已修入智境界名佛，于如来所修菩萨行无休息名菩萨」之对偶义，阐明「佛与菩萨、实际与不舍、休息愿与未息愿」之不二。
- **象王大喻（P18-P19）**：以伊罗钵那象王于金胁山七宝窟中不动，化现三十三天受乐、承事帝释为喻，明菩萨不舍普贤行而现成正觉、广度众生之理。
- **总结十定（P20）**：收束全品，标示「普贤行十大三昧轮」之名。

## 三、关键结论

1. **无碍轮三昧是普贤行之极顶**：菩萨住此三昧，身语意业、国土、众生、法轮皆无碍，等同如来而不舍菩萨行，是十大三昧之收束。
2. **「虽知……而演说」是菩萨不二法门的核心**：知法性空（无生、无相、无言说）而恒转法轮、广度众生——非断灭空，亦非执有。
3. **菩萨与佛「同而不同」**：已修入智境界故名佛，修菩萨行无休息故名菩萨；二者非一非异，菩萨「不舍普贤行」即「不舍菩萨道」。
4. **「重重变现」是普贤境界的相状**：一一毛孔现一一光明，一一光明现一一楼阁、佛、法轮——重重无尽，即帝网重重之义。
5. **象王喻统摄全品**：本身不灭而化现天身，正喻菩萨不舍普贤行而现成正觉、广度众生的「无碍」义。

## 四、易混辨析

- **无碍轮三昧 vs 普贤行**：无碍轮三昧是「所入之定」，普贤行是「所修之行」；菩萨以无碍轮三昧为体，起普贤行愿为用，二者体用不二。
- **「名佛」与「名菩萨」**：从「已修入智境界」边说名佛，从「修菩萨行无休息」边说名菩萨——同一菩萨，约义立名，非有二体。
- **实际 vs 涅槃**：实际是诸法本际（法性本净），涅槃是灭度之果；菩萨「常观实际而不证入亦不舍离」，故不同于二乘之取涅槃。
- **伊罗钵那象王 vs 帝释**：象王于宝窟不动而化现天身受天乐，喻菩萨不舍菩萨身而现佛事；「象之与天更互相似」正明菩萨与佛无二而差别。

## 五、阅读提示

读本卷可带着两个问题：菩萨既已同佛，为何仍名菩萨？为何要「不舍普贤行」？抓住「虽知……而演说」的句式与象王喻，即可贯通全卷「无碍」与「不二」之旨。
