# 大方广佛华严经卷第七十三 词语注释

① 夜神　守护夜晚、于夜分说法教化众生的神祇，多为女身，华严善财五十三参中有多位夜神善知识。本卷主角「大愿精进力救护一切众生夜神」即其一。
② 摩尼　梵语 maṇi 音译，宝珠，泛指能随人心愿出种种珍宝的如意宝。
③ 师子之座　佛与菩萨说法时所坐的宝座，比喻说法者无畏如狮子王。也作「狮子座」。
④ 微尘数　以微尘比喻极多。「佛刹微尘数」即把佛国世界碾成微尘那样的数量，形容多得不可思议。
⑤ 善知识　能引导众生向善、教导佛法的老师。善财童子五十三参所访的每一位都是他的善知识。
⑥ 同行　指与诸菩萨相同的行持。夜神赐予善财的八十四种「同某某」行持，如同念、同慧、同大悲等。
⑦ 三昧　梵语 samādhi 音译，即正定、禅定，心专注一境而不散乱的修行境界。
⑧ 陀罗尼　梵语 dhāraṇī 音译，意为「总持」，能总摄忆持无量佛法的法门或咒语。
⑨ 修多罗　梵语 sūtra 音译，意为「契经」，指佛所说经典中的长行散文体经文。
⑩ 波罗蜜　梵语 pāramitā 音译，意为「到彼岸」，指菩萨从生死此岸渡到涅槃彼岸的修行法门。
⑪ 阿耨多罗三藐三菩提　梵语 anuttarā-samyak-saṃbodhi 的音译，意为「无上正等正觉」，即佛所证的究竟觉悟。
⑫ 须弥山　古印度宇宙观中矗立于世界中央的高山，四大洲围绕其周。
⑬ 法轮音虚空灯王如来　本卷本生故事中，善光劫最初出世、令夜神前身太子证得解脱门的佛陀。
⑭ 阎浮提　须弥山南方的人类居住世界，即南赡部洲，经中常代指人间。
⑮ 囹圄　监狱，古代牢狱之名。本卷胜光王「造立囹圄」囚禁罪人。
⑯ 杻械　拘束手脚的刑具。杻锁手，械锁脚。
⑰ 榜笞　鞭打拷问之刑。榜为击打，笞为用鞭杖抽打。
⑱ 膑割　古代削去膝盖骨（膑骨）的酷刑。
⑲ 采女　王宫中供役使的宫女。本卷王后「与千采女」一同为王太子求情。
⑳ 夜叉　梵语 yakṣa 音译，行动迅捷的鬼神，有善有恶，此处为护法八部众之一。
㉑ 乾闼婆　梵语 gandharva 音译，香神、乐神，不食酒肉唯以香气为养，八部众之一。
㉒ 迦楼罗　梵语 garuḍa 音译，金翅鸟神，以龙为食，翼展极大，八部众之一。
㉓ 紧那罗　梵语 kiṃnara 音译，歌神，头上有角似人非人，八部众之一。
㉔ 摩睺罗伽　梵语 mahoraga 音译，大蟒神，人形而蛇首，八部众之一。
㉕ 那由他　梵语 nayuta 音译，古印度的巨大数词单位，泛指极多。
㉖ 法眼净　观见诸法实相的智慧之眼。得法眼净即于佛法得初步的证悟（相当于见道）。
㉗ 无学地　指声闻乘的最高果位阿罗汉，已断尽烦恼、无可再学，故称无学。
㉘ 提婆达多　佛的堂兄弟，曾谋害佛、破坏僧团，是经中典型的恶人。本卷说他也将在未来成佛。
㉙ 拘留孙　贤劫千佛中的第一尊佛（拘留孙佛）。本卷说被太子所救的罪人即拘留孙等贤劫千佛。
㉚ 贤劫　现在所处的大劫之名，因此劫中将有一千尊佛相继出世而称「贤劫」。
㉛ 阿僧祇　梵语 asaṃkhya 音译，意为无量数，印度用来表示不可计数的极大数目。
㉜ 萨遮尼乾子　佛世时的外道大论师，曾建论幢与佛论辩而被降伏。本卷说他即前世欲处死太子的胜光王。
㉝ 般若波罗蜜　「般若」即智慧，「般若波罗蜜」即凭智慧到达彼岸，六度之一。
㉞ 转轮王　统一四天下的圣王，即位时有轮宝自然出现，随其轮宝而行能降伏四方。
㉟ 帝释　忉利天（三十三天）的天主帝释天，佛教重要的护法天神。
㊱ 兜率天　欲界第四天，一生补处菩萨（如弥勒）所居之地。
㊲ 毗沙门天王　四大天王之一，护持北方的多闻天王，也是财宝福德之神。
㊳ 鸠槃荼　梵语 kumbhāṇḍa 音译，鬼类名，形如瓮腹的鬼王，护法八部众之一。
㊴ 岚毗尼　园林名，佛陀的诞生地，位于今尼泊尔境内。本卷卷末善财即前往此园参访。
㊵ 妙德圆满　岚毗尼园林的神祇（女神），善财下一参（卷74）的善知识，主「生如来家」。
