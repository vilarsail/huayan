# 大方广佛华严经卷第七十三 词语注释

① 大愿精进力救护一切众生夜神　本卷末所指下一参之善知识，与前卷已参者同名同体，善财循指再往参问。
② 阿耨多罗三藐三菩提心　意为「无上正等正觉心」，即发成佛之心。善财每参善知识皆自陈已发此心，作为请法的前提。
③ 菩萨甚深自在妙音解脱门　善财在前一参所证之解脱门，于此卷开头作为修行增进的阶次，引出下一参访。
④ 开敷一切树华夜神　本卷主答善财之善知识，居众宝香树楼阁，所证「菩萨出生广大喜光明解脱门」，自述往昔为宝光童女。
⑤ 师子座　即狮子座，佛菩萨所坐之座，以师子喻威猛无畏。
⑥ 五欲自恣　指对色、声、香、味、触五种欲境放纵无度。夜神对盛年放逸者示现老病死相以令舍离。
⑦ 悭吝　吝啬、不肯施舍。夜神对悭吝者赞叹布施以对治贪着。
⑧ 般若　梵语prajñā，智慧之义，六度之一。对「住恶慧者」令学般若，即以正智对治邪慧。
⑨ 愿波罗蜜　十波罗蜜之第八，即以大愿成就众生。本卷对「乐着三界诸趣中者」令住此度。
⑩ 力波罗蜜　十波罗蜜之第九，谓菩萨以力用成熟众生。对「福智微劣、为结业所逼迫者」令住此度。
⑪ 智波罗蜜　十波罗蜜之第十，谓菩萨以智光照破众生闇昧。对「其心闇昧，无有智慧」者令住此度。
⑫ 出生广大喜光明解脱门　开敷一切树华夜神所证之法门之名，由此能知如来普摄众生之巧方便智。
⑬ 毗卢遮那　梵语Vairocana，意为「遍一切处」，此经中指法身佛，即释迦牟尼之法身。夜神忆念其往昔菩萨行海。
⑭ 应、正等觉　如来十号中之「应供」与「正等正觉」之略称，佛之德号，毗卢遮那如来之后所缀。
⑮ 着我、我所　执着「我」与「我所」（即属于我之一切）。众生因执我我所而住无明闇室，入诸见稠林。
⑯ 稠林　密林之义，喻邪见交错难出。「入诸见稠林」谓众生为种种邪见所缠绕，如入密林不得出。
⑰ 法漩澓　法之漩涡、深流。「深入一切法漩澓心」谓深入法之深妙流注处，不怖其深。
⑱ 金刚杵　密法中之法器，喻坚利能破。以「大智金刚杵破一切众生烦恼障山」比喻智杵摧破烦恼。
⑲ 念念　每一刹那、每一心念。华严特重念念中修行，谓菩萨于念念中成熟众生、严净佛刹、遍入法界三世。
⑳ 世界种　华严世界海中层级结构之一，一世界海含若干世界种，一种复含若干世界。
㉑ 世界海　华严宇宙观中最高层级之世界集合，含无量世界种、世界。
㉒ 善知识　能引导众生趣向佛道之善友、师长。善财参访诸善知识即华严修行之核心方法。
㉓ 修多罗　梵语sūtra音译，意译契经，佛所说之法。本卷言一一佛说世界海微尘数修多罗。
㉔ 须弥山　又作苏迷卢山，世界之中心。本卷以须弥山微尘数喻四天下之数。
㉕ 由旬　古印度长度单位，一由旬约数十里。本卷述四天下纵广十万由旬。
㉖ 阎浮提　即南赡部洲，人类所居之洲。本卷中阎浮提人寿万岁，有王都名坚固妙宝庄严云灯。
㉗ 采女　宫中侍女、宫女。一切法音圆满盖王有六万采女。
㉘ 五浊　劫浊、见浊、烦恼浊、众生浊、命浊之总称，指劫末浊世之五种浊恶。本卷述其时人寿短促、资财乏少等。
㉙ 阿僧祇　梵语asaṃkhyeya，意为无数、无央数，华严常用极大数词。P30「得百万阿僧祇大悲门」。
㉚ 四衢道　四通八达之十字路口。王于此处设大施会，普施一切。
㉛ 那由他　梵语nayuta，极大数词，或译亿兆。本卷中屡用以表无量众生、无量劫数。
㉜ 栏楯　栏杆与栏楯，栏间横木。施会处及师子座皆以十宝栏楯周匝围绕。
㉝ 那罗延　梵语Nārāyaṇa，天上力士之名，喻坚固不可沮坏。「那罗延身」谓王身坚固如天力士。
㉞ 忉利天王　即三十三天主帝释。P30以诸天王所受快乐不及王见乞者之欢喜。
㉟ 夜摩天王　夜摩天（第三层天）之主，与忉利等天王并列，以喻诸天快乐不及菩萨欢喜。
㊱ 兜率陀天王　兜率天（第四层天）之主，亦用以衬托菩萨见乞者生欢喜之胜。
㊲ 光音天王　光音天（二禅天）之主，所受天乐亦不及菩萨欢喜。
㊳ 遍净天王　遍净天（三禅天）之主，所受天乐亦不及菩萨见乞者之欢喜。
㊴ 净居天王　净居天（五不还天）之主，所住寂静乐亦不及菩萨见乞者之欢喜。
㊵ 萨婆若　梵语sarvajña，一切智、佛智之音译。「常乐观察萨婆若道」即恒乐观察一切智之道。
㊶ 福田　堪受人供养、令植福者，喻如田之能生福。王于来乞者生福田想，意谓视乞者为己之福田。
㊷ 鬘盖　以华鬘所成之盖，供养庄严之具。求鬘盖者施与鬘盖。
㊸ 绀青　深青而带赤色。宝光明女「目发绀青」，为相好之一。
㊹ 梵音　清净、和雅之音声。「口演梵音」谓女口所发如梵天之声。
㊺ 四摄法　菩萨摄化众生之四种方便：布施、爱语、利行、同事。王以此所摄众生即今此会菩萨。
㊻ 十地　菩萨修行之十种阶位（欢喜地乃至法云地）。所摄众生或住初地乃至十地。
㊼ 他心智　知他人心念之智，六通之一。夜神以此于一念中悉了诸心海。
㊽ 宿命智　知过去世生死之智，三明或六通之一。夜神以此智能忆知往昔诸佛菩萨之事。
