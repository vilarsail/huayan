# 大方广佛华严经卷第三十二 词语注释

〔1〕 于阗国　古西域佛教国家，在今新疆和田一带；本卷译者实叉难陀即于阗人。
〔2〕 三藏　经、律、论三藏；通达三藏的法师尊称「三藏（法师）」，此处是对译经僧的尊称。
〔3〕 实叉难陀　Śikṣānanda（652—710），意译「学喜」，唐代自于阗来华的译经三藏，八十卷本《华严经》的译者。
〔4〕 十回向品　《华严经》〈十回向品〉叙说菩萨十种回向；本卷为该品第十卷，说第十「等法界无量回向」。
〔5〕 云何　如何、怎样，经中常用的设问发语词，下文即依次解答。
〔6〕 菩萨摩诃萨　菩萨即觉有情；摩诃萨（mahāsattva）意为「大有情」，指德行深广的大菩萨。
〔7〕 法界　诸法体性的总称，华严宗核心概念；本卷屡以「等法界」「如法界」形容善根回向广大无边。
〔8〕 回向　pariṇāmanā，将所修善根转施于众生与菩提、愿共成佛；本品全卷皆围绕「以善根回向」反复展开。
〔9〕 离垢缯　缯（zēng）丝帛；以离垢白丝带系顶，象征受职任法师位（类灌顶受职之礼），故下文说「住法师位，广行法施」。
〔10〕 法施　法布施，以佛法开示利益众生，为诸施之首；与财施相对。
〔11〕 安立　佛教用语，谓建立、施设、安置；「安立众生」即将众生安置于善处正道。
〔12〕 菩提心　bodhicitta，求无上菩提之心，上求佛道、下化众生；本卷视为修行与回向之本。
〔13〕 调御师　即佛十号中「调御丈夫」之意，谓能调伏驾驭众生心行、导其入道的师长。
〔14〕 法藏日　佛法宝藏如日光普照；喻菩萨以善根智慧之光破除众生痴暗。
〔15〕 商主　商队首领，古时率众逾险贸易的导师；喻菩萨引导众生入安隐正道。
〔16〕 安隐　即「安稳」，古今字通用，谓平安稳定；「安隐正道」即安稳之道。
〔17〕 白法　谓清净的善法，与染污的「黑法」相对。
〔18〕 善知识　教导善法、引人向道的良师益友；「终无离佛善知识想」谓始终不失「佛是善知识」之想。
〔19〕 谄诳　谄（chǎn）曲意逢迎，诳（kuáng）欺诈妄语；「心无谄诳」谓心地正直无此二过。
〔20〕 境界　佛教谓心识所缘涉的范围、领域；「一切智门无边境界」谓一切智法门所摄的无边境域。
〔21〕 庄严　装饰严饰，经中兼作动词，谓以功德严饰身土（如后文「以无量庄严庄严佛种性」，后一「庄严」即动词）。
〔22〕 梵行　brahmacarya，清净离欲之行；本卷有长段列举种种梵行，是本品核心项目之一。
〔23〕 所谓　即「所说的如下」，用于引出下文的列举内容。
〔24〕 不破梵行　起头词：下文自「不破梵行」至「无恚梵行」共约二十种梵行并列枚举，读法是抓每条首词（不破、不缺、不杂、无点……），皆形容梵行纯净无瑕；「点」谓瑕疵黑点。
〔25〕 无诤　araṇā，不与世间诤，心住无违诤之行。
〔26〕 何以故　为什么呢？经中设问之词，下文自作解答。
〔27〕 和忍　和顺与安忍；谓以善根调伏自心，使之柔和堪忍。
〔28〕 疑悔　疑惑与忧悔，修行之二障；「永离疑悔」谓于佛法决定无疑、无有追悔。
〔29〕 外道　佛教称佛法之外的宗派学说为「外道」；「外道异论」即外道的错误议论。
〔30〕 分位　阶段、位分差别；「一一法分位」谓一一法的位分差别。
〔31〕 无所畏　即佛的四无所畏，于大众中说法无所畏惧之德；此处谓菩萨愿获此德。
〔32〕 四辩才　即四无碍辩：法无碍、义无碍、辞无碍、乐说无碍，谓通达说法的四种自在能力。
〔33〕 随其类音　随顺众生种类各自的语言音声而说法，即「随类音」。
〔34〕 俾无迷惑　俾（bǐ），使也，文言使令虚词；「俾无迷惑」即使（众生）无有迷惑。
〔35〕 众会道场　无量大众聚集闻法之处；谓菩萨示现遍满法界的说法道场。
〔36〕 住持　谓安住任持不坏；此处作动词，「住持等法界无量佛刹」谓住持庄严无量佛国土。
〔37〕 佛刹　刹（chà）即国土、世界（梵 kṣetra）；佛刹谓佛所教化的国土。
〔38〕 陀罗尼　dhāraṇī，总持，能总摄忆持无量佛法而不忘失的功德（亦指咒语）；此处指菩萨所成就的陀罗尼门。
〔39〕 不思议住　「住」谓菩萨修行的阶位（如十住）；不思议住即不可思议的菩萨阶位。
〔40〕 福德平等　起头词：下文「福德平等、智慧平等、力平等……」共十一项「平等」并列枚举，谓愿一一与佛同等圆满，读法是逐项抓「××平等」。
〔41〕 我所　「我所有」之略，谓执外物为我所拥有；与「我」（我执）合为我、我所二执，此处谓离自贪着摄受之心。
〔42〕 如法界无量　起头句：下文以「如法界无量（无边、无限……），善根回向亦复如是」连用十喻，谓回向一一如法界之德性，读法是抓每喻首词。
〔43〕 齐限　齐谓齐整有限；「无有齐限」即没有边际限定。
〔44〕 承事　承奉侍奉，谓恭敬地事奉供养诸佛菩萨。
〔45〕 往觐　觐（jìn）朝见尊长；「往觐」谓前往拜见诸佛。
〔46〕 佛事　佛化度众生的事业（说法、示现、教化等）；此处谓众生见佛能作佛利生之事。
〔47〕 无起性回向　起头词：下文「如法界无起性回向、如法界根本性回向……」共十项并列，谓回向体性一如法界（无起、无依、寂静、无差别等），皆以「如法界……性回向」为句式。
〔48〕 护念　摄护忆念，谓佛时时加被护持、心中忆念修行者；「常为诸佛之所护念」即常蒙诸佛护持。
〔49〕 无屈法师　起头词：下文自「无屈法师」至「安隐一切世间法师」共约二十种「法师」并列枚举，谓愿众生皆成种种说法之师，读法是抓每条「作××法师」的定语。
〔50〕 问难　难（nàn）诘问、责难；「问难」即提出疑问责询以试法义深浅。
〔51〕 妙相　殊妙庄严之相，指佛的三十二相好。
〔52〕 大法云　佛法如云普覆、如雨润物；「持大法云，受大法雨」谓受持佛法，如云含雨而普润众生。
〔53〕 雨诸佛法　雨（yù）作动词，降下之意；「兴大法云，雨诸佛法」谓兴起大法云、降下佛法之雨。
〔54〕 胜幢　幢（chuáng）佛教旗幡类庄严具，象征降魔得胜；「建无胜幢」谓树立无可胜过之幢。
〔55〕 实际　真如实际，诸法究极的实相边际；「令入实际」谓令众生证入实相。
〔56〕 取着　执取贪着；本段连用十个「不以取着……故回向」，谓回向不夹杂对业、报、心、法等的执着。
〔57〕 名句文身　佛教术语：名是名称概念，句是句子，文即字母文字；「身」谓聚集，合指语言文字的构成要素。
〔58〕 耽着　耽（dān）沉溺、贪恋；「耽着」即深深贪着。
〔59〕 诸有　指三有（欲有、色有、无色有），即生死轮回中的一切存在；「乐诸有」谓贪恋三有之乐。
〔60〕 声闻　闻佛声教而悟四谛、求自了脱的弟子之乘；此处谓回向不落于声闻小果。
〔61〕 辟支佛　缘觉（独觉），观十二因缘无师自悟者；与声闻合称二乘，菩萨不以此为归。
〔62〕 一切智智　一切智中之智，即究竟圆满遍知一切的佛智，以别于菩萨的一切智。
〔63〕 佛种性　佛的种性、成佛之因性；谓以无量功德庄严成就众生成佛之因。
〔64〕 被坚固大愿铠　被（pī）同「披」，穿戴；铠（kǎi）铠甲；谓披上坚固大愿之甲胄，喻誓愿护身、入生死而不退。
〔65〕 畜生趣　趣（qù）即所往生之处（六趣）；畜生趣即六道中的畜生道。
〔66〕 阎罗王　地狱之主，管领罪人受报之处；「不往阎罗王处」谓不堕地狱。
〔67〕 十力轮　十力谓佛的十种智力；轮即法轮；「入十力轮」谓入于佛十力所转之法轮。
〔68〕 菩提心器　器谓容器、法器；谓令众生承受菩提心的器量（心量）圆满具足。
〔69〕 一切种智　佛智，通达一切法总相（一切智）与别相（种智）的究竟智慧；「一切种智心」谓发求佛果之心。
〔70〕 正念清净回向　起头词：下文连用数十个「……回向」「为……故回向」的短句并列枚举，谓以种种清净心行功德而回向，读法是逐条抓其心行名目。
〔71〕 大舍　与上文「住大慈、住大悲、住大喜」连读，即慈、悲、喜、舍四无量心；舍谓平等舍离怨亲憎爱。
〔72〕 二着　两种执着，谓执着生死与执着涅槃（空、有二边）；「永离二着」谓不住两边。
〔73〕 缘起法　因缘和合而生起的诸法；谓思惟演说一切法因缘生起之理。
〔74〕 憍慢　憍（jiāo）同「骄」，自高自大；憍慢即憍傲我慢。
〔75〕 爱欲网　贪爱欲望如网罗缠缚众生；「裂爱欲网」谓撕裂断破此贪爱之网。
〔76〕 愚痴闇　闇（àn）同「暗」，黑暗；谓无明愚痴如暗冥遮蔽心智。
〔77〕 阿僧祇　asaṃkhya，数名，意为「无央数」，极言其多；「阿僧祇劫」谓无量久远的时劫。
〔78〕 三有　欲有、色有、无色有，即三界生死之存在；「贪着三有」谓贪恋轮回。
〔79〕 五欲境界　色、声、香、味、触五尘所起的贪欲境界；谓不应贪着世间五欲。
〔80〕 无贪善根　起头词：下文「无贪、无瞋（chēn）、无痴、不害、离慢、不谄、质直、精勤、修习」九种善根并列；无贪、无瞋、无痴即三善根，谓应以如是清净善根回向。
〔81〕 质直　质朴正直，谓心无谄曲。
〔82〕 设大施会　设立大布施法会；谓广行布施、普摄众生。
〔83〕 天鼓音　天界之鼓，不击自鸣、自然演出法音；喻说法音声自然美妙。
〔84〕 那由他　nayuta，印度大数之名，极言其多。
〔85〕 痴翳　翳（yì）眼翳、障蔽，如白膜遮眼；「远离痴翳」谓远离愚痴之障蔽。
〔86〕 金刚句　谓语句坚固如金刚、不可破坏，能破邪见；「普摄持不可思议法金刚句」谓摄持不可思议法之金刚语句。
〔87〕 长夜　比喻众生无明流转生死、久处暗夜；「长夜睡眠」喻众生为无明所覆、不觉正道。
〔88〕 光明身　起头词：下文「光明身、离浊身、无染身……」共十种清净妙身并列枚举，谓愿得种种清净身，读法是抓每条身名。
〔89〕 现诸业像　像，影像；谓于一切世界示现众生业报之相，与下文「现言说像」「现安立像」并列，皆谓应化示现如镜中像自然显现。
〔90〕 均普　均，平等；普，周遍；「大悲均普」谓大悲心平等周遍、量同法界。
〔91〕 众生根　根谓众生的根机、根性（信、进、念、定、慧五根等）；「知众生根」谓了知根机而应时说法。
〔92〕 一刹那顷　刹那（kṣaṇa）最短的时间单位；「一刹那顷」谓一刹那之间，极言念念不舍。
〔93〕 善巧方便　upāya，随众生机宜灵活施教、善巧度生的智慧手段。
