# 大方广佛华严经卷第二十九 导读

## 一、内容总览

本卷为《大方广佛华严经·十回向品》第二十五之七，承接前六回向（救护众生、不坏、等一切佛、至一切处、无尽功德藏、随顺坚固善根）之后，宣说第七「等随顺一切众生回向」，由金刚幢菩萨承佛神力，先以长行广说菩萨回向行相，复以颂偈重颂其义。此回向以「积集一切善根 → 普施一切众生 → 令入一切智智」为脉络，重在「等」——以平等心、广大心将所修善根遍施众生，无一遗漏，三轮体寂而回向菩提。

## 二、结构层次

全文以长行（P3-P17）为主干、颂偈（P18-P19）为收束，依「立名→积善→施物→回向愿→平等不二→总结功德」层层推进：

- **立名与积善（P3-P5）**：先标回向名「等随顺一切众生」，次列菩萨所积集种种善根（小、大、广、多、无量、微尘数、阿僧祇…直至普覆育一切世间善根），并明此善根皆是菩提心所积集发起 → 善根增进永不退转。
- **广施外物（P6-P7）**：菩萨发愿，尽未来劫，以阿僧祇世界珍宝、衣服、妙香、宝象、宝马、妓女、男女乃至己身、己头、己眼、血肉骨髓、自在王位等 → 普施一切众生，于一众生如是，于尽众生界亦复如是。
- **施心清净（P8-P9）**：明布施时之心行——无著、无缚、解脱、无寿者等十八种清净心 → 复于念念中发十种愿，回向一切众生财宝丰足、得清净平等心、离诸难处得一切智。
- **回向愿海（P10-P11）**：以「为令一切众生…」为枢纽，广列百余愿，从住施心、住净戒、得堪忍、般若波罗蜜，到具相好、得六十音声、转法轮、灌顶、成等正觉 → 摄尽菩萨道一切行果。后归结于「究竟安隐、究竟清净…具足十力调伏众生」十种究竟愿。
- **不著与平等（P12-P16）**：回向时不着业、不着报、不着身、不着物乃至不着一切法、不着无一切法 → 得「不违」法门：众生与刹不违、业与报不违、法性与法相不违、过去未来不违、世平等与佛平等不违 → 得业、报、身、方便、愿、众生、刹、行、智、三世佛十种平等。
- **结成与颂偈（P17-P19）**：总结第七回向成就，摧灭魔怨、拔诸欲刺、得无碍耳、净慧眼；金刚幢菩萨以颂重宣——功德回向无边际、头目骨髓普施、平等愿力无分别、了知诸法空而业报不失、寂灭非寂灭远离二边。

## 三、关键结论

1. **善根皆是菩提心所成**：菩萨所修一切善根，无论小大微尘数乃至佛境界，皆以菩提心为根本，是心所积集、所发起、所增益——回向之体即菩提心。
2. **普施尽未来劫而无倦**：于一众生尽未来劫施物不倦，复展至尽虚空遍法界一切世界、一切众生，大悲普覆终无间息，乃至一弹指顷不生疲倦心。
3. **三轮体寂而不著**：施时不着业、不着报、不着身、不着物、不着刹、不着众生、不着一切法亦不着无一切法——回向而无所回向，方为真回向。
4. **平等不二为归趣**：回向成就「不违」法门，刹与众生、业与报、法性与法相、过去与未来、世间与佛，悉皆平等不违，得十种平等，住无二性。
5. **了知诸法空而业报不失**：颂偈点明「菩萨了知诸法空…无有造作及作者，众生业报亦不失」，空与因果并彰，远离二边分别，是华严空有不二中道义。

## 四、易混辨析

- **等随顺一切众生回向 vs 随顺坚固善根回向（第六）**：第六重在「随顺」善根本身坚固不坏；第七重在「等」——以平等心将善根遍施一切众生，无一遗漏，侧重普施与平等。
- **回向 vs 布施**：布施是六度之一，将财物身命施他；回向是将所修一切善根（含布施功德）转趣菩提、普施众生，范围更广，且重在「心转」而非「物予」。
- **不着一切法 vs 着无一切法**：不着一切法是不执有；不着无一切法是不执空——双遮二边，方契中道，与颂中「于二不二并皆离」相呼应。
- **平等不违 vs 相即相入**：本卷「不违」侧重法法之间不相妨碍、各住自性而相顺；不同于前卷「相即相入」之重重无尽，此处重在「一味平等」。

## 五、阅读提示

读本卷可带着两个问题：菩萨既将一切善根普施众生，自己还剩什么？答在「得无所得」「不着」——所施者是物与善根之相，所得者是平等与智。又，颂云「了知诸法空…业报亦不失」，空与因果如何并行？此即华严「理事无碍」之入口。
