# 大方广佛华严经卷第六十一 导读

## 一、内容总览

本卷属《入法界品第三十九》之二，是「入法界」大序幕的展开。前半卷承上一卷「师子频申三昧」，由普贤菩萨以十种法句广演此三昧境界，复以颂偈重宣；如来眉间白毫放光普照法界，逝多林菩萨大众于一一微尘中各见佛刹微尘数佛成道转法，悟入无量三昧神变。后半卷笔锋一转，文殊师利童子从善住楼阁出，南行人间；尊者舍利弗率六千新学比丘随行，文殊为诸比丘说「十种趣大乘无疲厌心」，令得「无碍眼见一切佛境界三昧」，再劝其安住普贤行——为后文善财童子五十三参正式拉开帷幕。

## 二、结构层次

全卷以「三昧神变 → 菩萨叹德 → 文殊南行 → 比丘得法」四段一线贯穿，由深定境界渐次推出能入法界之人：

- **普贤演说三昧（P3-P5）**：普贤以等法界方便观察众会，开示「师子频申三昧」十种法句 → 颂偈重宣「一一毛孔中微尘数刹海」之重重无尽。
- **如来放光普照（P6-P7）**：眉间白毫放「普照三世法界门」光 → 大众于微尘中各见佛刹微尘数诸佛国土、道场众会 → 指出此皆毗卢遮那往昔善根摄受，引出「或入法身……或入佛所住三昧」十种悟入路径。
- **菩萨具德与神变（P8-P10）**：先列「普庄严法界三昧」等百千三昧名目（重重无尽枚举）→ 再述诸菩萨「大智神通明利自在」之功德藏 → 以得不思议正法光明故，化现十种大庄严云充满法界。↔ 文殊颂偈（P11-P12）重宣逝多林一一境界皆现佛身、一一毛孔皆现难思变化身。
- **入法界之缘起（P13-P14）**：菩萨以佛三昧光明照故入三昧，得不可说大悲门，化身普现一切众生之前，往天、龙、夜叉乃至地狱六道住处，平等摄化——为「入法界」立实践根据。
- **文殊南行度比丘（P15-P24）**：文殊从善住楼阁出，与诸神王、菩萨众南行 → 舍利弗率六千新学比丘随行 → 途中观文殊身相圆光伏藏等十德 → 比丘发心奉见 → 文殊说「十种趣大乘法心无疲厌」→ 比丘得「无碍眼见一切佛境界三昧」，见十方诸佛及一切众生差别 → 文殊劝住普贤行，入大愿海，得大神通。

## 三、关键结论

1. **师子频申三昧即法界总持**：一毛孔含微尘数刹海，一一刹中皆有佛坐道场，重重无尽、互摄互入，是华严「帝网重重」境界的定型表达。
2. **「等」字贯穿能入所入**：普贤以「等法界、等虚空界、等众生界」等十种平等方便开发三昧，说明此三昧非别证一境，而是与法界全幅平等相应。
3. **善根摄受为悟入之因**：众生得见佛神力，皆由毗卢遮那往昔以四摄、教化、同种善根之所成熟——强调佛果不舍因行。
4. **无疲厌心为大乘入门**：文殊所传十种趣大乘法，核心是「心无疲厌」，从积集善根到成熟一切众生界，行愿无尽即入如来地。
5. **普贤行收束全程**：比丘先得无碍眼三昧，再被劝住普贤行，由「智」入「愿」，由「见佛境界」到「成就佛法」，点明善财参访前已立根本。

## 四、易混辨析

- **师子频申三昧 vs 师子奋迅三昧**：本卷主定为「频申」（亦作频申、奋迅混用），意为如师子王舒展身心、震动自在，华严用以总摄法界神变；「奋迅」侧重奋起迅疾，二者义近而侧重略异。
- **法身 vs 色身**：P7「或入法身，或入色身」对举，法身指佛真如理体（无形无相、周遍法界），色身指佛所示现的相好应身；神力能入二者，故境智无碍。
- **文殊师利童子 vs 文殊师利菩萨**：本卷于「出楼阁」一段特称「童子」，表文殊表「根本智」、童真无染；于说法劝发段复称「菩萨」，表大行运悲，称谓随义而变。
- **舍利弗 vs 善财**：舍利弗乃声闻弟子代表，率六千新学比丘；文殊南行后所遇当机者（后卷）乃善财童子。前者示声闻回心、后者示童蒙直入，皆入法界之机。

## 五、阅读提示

读时把握两条线：一是「定中境界」（普贤演说、如来放光、菩萨入三昧）展示法界重重无尽之相；二是「出定起行」（文殊南行、度诸比丘住普贤行）展示由定发愿、由智起行的实践次第。后者正是下一卷善财童子五十三参的序曲。
