# 大方广佛华严经卷第七十四 导读

## 一、内容总览

本卷属《入法界品第三十九》之十五，是善财童子五十三参中的一站。善财在大愿精进力救护一切众生夜神处得法之后，渐次游行至岚毗尼林，参访妙德（岚毗尼林）神。林神为说「菩萨十种受生藏」，令其知菩萨如何生如来家；又自述往昔于「悦乐劫」金华园作乳母净光，捧持初生菩萨而得「普眼三昧」与「示现受生自在解脱」，至今念念见毗卢遮那佛于微尘中示现受生神变。最后指示善财往迦毗罗城参释种女瞿波。全卷由「十受生藏」与「诞生十神变」两大法门构成，归于「菩萨受生自在解脱」一境。

## 二、结构层次（★重点）

本卷以「请法 → 受生藏 → 诞生神变 → 自证缘起 → 推荐下参」一线贯穿，层层展开：

- **请法（总起）**：善财至岚毗尼林，见林神妙德坐宝莲华座，为说菩萨受生海经 → 善财顶礼请问「菩萨云何生如来家」 → 引出十受生藏。

- **十受生藏（分述，法门主体）**：先总标「十种受生藏，成就则生如来家」，再以「云何名…受生藏？」格式逐层展开：
  - 一愿常供养佛 → 二发菩提心 → 三观诸法门勤修行 → 四以深净心普照三世 → 五平等光明 → 六生如来家 → 七佛力光明 → 八观普智门 → 九普现庄严 → 十入如来地受生藏。
  - 每藏皆先列名，再释其行相、功德，从「始集善根」到「入如来地」，呈现由初发心到灌顶成佛的完整次第。
  - 林神以十颂重明其义，归摄十藏为一「生如来家、为世清净光明」之境。

- **自证缘起（承接：林神自述得法因缘）**：善财问「境界云何」→ 林神自述往昔愿力生阎浮提岚毗尼园，专念菩萨下生，见佛降生十瑞相、摩耶夫人入园十光明、将诞十神变 → 引出本师降生岚毗尼之盛况。其中「将诞十神变」层层放大摩耶夫人身毛孔所现，从三千世界、往昔修行、舍所难舍到诸佛入胎庄严，乃至出菩萨宫殿、化菩萨众、涌大莲华。

- **本事追忆（深溯：乳母前生）**：善财问「得此解脱其已久如」→ 林神追溯「悦乐劫」普宝世界中初佛自在功德幢降生金华园，自己作乳母净光捧持菩萨金色身，谛观不见顶，因思惟功德发大菩提心，从此念念见佛受生神变；以十颂重宣此义。

- **谦己推德 → 推荐下参（收束）**：林神自谦「唯知此受生自在解脱」，赞叹菩萨摩诃萨一念为劫藏、一切趣现受生之大功德，推善财往迦毗罗城参释种女瞿波 → 善财礼辞而去。

全文骨架为「请法 → 法门（受生藏）→ 事相（诞生神变）→ 因缘（乳母前生）→ 谦推引下参」，由理及事，由今及古，由自及他。

## 三、关键结论

1. 菩萨「生如来家」之因在于成就十种受生藏，从初发心供养诸佛到入如来地受灌顶法，构成完整的菩萨道修证次第。
2. 摩耶夫人身诸毛孔皆现如来往昔修行因缘，乃至舍头目血肉等难舍之物——表明佛之诞生非世间常途，实为无量劫行愿之凝聚示现。
3. 岚毗尼林神之得法源于「悦乐劫」作乳母捧持初生菩萨时即得「普眼三昧」与「示现受生自在解脱」，自此念念见佛于微尘中受生，所谓「一念见亿刹微尘数菩萨」。
4. 佛之受生神变于一一微尘中皆现，念念不断，无尽无尽——显示法界缘起、重重无碍的华严境界。
5. 善财童子之参访始终贯彻「谦己推德、引向下参」的华严善知识范式，由林神引向瞿波，参访链环环相扣。

## 四、易混辨析

- **受生藏 vs 受生海**：「受生藏」是十种菩萨生如来家的法门之总称，重在能生之因行；「受生海」（菩萨受生海经、受生自在解脱）是所入之境与所证之果，重在受生神变之量周法界。藏以十数列之，海以无量叹之。

- **岚毗尼林 vs 岚毗尼园**：林指林神所居之法界林苑，是善财参访妙德神之所；园特指摩耶夫人入园诞生之处。林神因地得名，园为诞生场。

- **摩耶夫人 vs 喜光夫人**：摩耶是此世界毗卢遮那佛（释迦化身）之母；喜光是「悦乐劫」普宝世界初佛自在功德幢之母，二者在彼与此、今与昔中角色对应，林神自言「亦复如是」，显示佛佛道同。

- **普眼三昧 vs 菩萨于一切处示现受生自在解脱**：普眼三昧是乳母净光捧持菩萨时所得之定，重在「普见十方无量诸佛」之能见；示现受生自在解脱是依此三昧进一步所得之用，重在「于一切处示现受生」之能现，见与现一体两面。

## 五、阅读提示

读此卷宜把握两层：一是「十受生藏」之法理次第，看菩萨如何从初发心到入如来地；二是「诞生十神变」与「乳母前生」之事相因缘，看佛之降生如何即事即法、即一即多。可带着「菩萨为何要生如来家」「佛的诞生究竟意味着什么」两问读入，方见华严事理圆融之妙。
