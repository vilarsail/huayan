# 大方广佛华严经卷第三 词语注释

① 乾闼婆王　乾闼婆为天界香神、乐神，事帝释奏乐；此处列十位乾闼婆王，各得一解脱门。
② 解脱门　通达解脱之法门，即证入一种自在境界之方便门。本卷各类世主各称所得解脱门，各契一法。
③ 十方　东、南、西、北、四维、上下之十方，表空间周遍；本卷屡言「十方」「遍照十方」，显佛光普被。
④ 承佛威力　蒙佛神力加持而能说法、说颂。诸世主颂偈非自力所能，皆承佛力而说，显佛为法源。
⑤ 普观一切　说法前周遍观察会众，表说法契机、等心摄受；诸王说颂前皆先「普观一切某众」。
⑥ 无量劫　极长远之劫数；本卷「佛于往昔无量劫」「无量劫中修苦行」等屡见，表佛因行历时久远。
⑦ 刹那　梵语 kṣaṇa，极短之时分；本卷「一刹那中百千劫」「一一刹那中普雨无边大法雨」，显如来一念摄无量劫之延促无碍。
⑧ 鸠槃荼王　鸠槃荼为鬼道之一，状如瓮，腹大面丑，属增长天王所领；本卷十王主灭怨害、成就清净等门。
⑨ 大悲　佛菩萨无缘大慈同体大悲，普救一切众生苦；本卷反复出现，为如来度生之本怀。
⑩ 调伏　调柔其心、伏灭烦恼，即佛以善巧令众生离恶向善；本卷屡言「调伏众生」「普使悉调伏」。
⑪ 法轮　佛所说之教法，轮为转摧烦恼之义；本卷「普转法轮无不解」等，谓转法教化众生。
⑫ 龙王　龙属畜道而有福报，护法之神。本卷列十一位龙王，如娑竭罗、德叉迦、无热恼等，各得救护众生之解脱门。
⑬ 娑竭罗龙王　梵名 Sāgara，意译「咸海」龙王，为诸龙之首，经中常见；此王得一念中转自龙形示现无量众生身之解脱门。
⑭ 德叉迦龙王　梵名 Takṣaka，八大龙王之一，经中屡见；此王以清净救护音灭除一切怖畏。
⑮ 无碍　无障无碍、自在无留滞，如「无碍光焰」「普行无碍」「无碍力」等；显佛神通智慧周遍通达。
⑯ 夜叉王　夜叉译「轻捷」「勇健」，飞行鬼神之属，多护法；毗沙门（多闻天）所领，本卷十王主救护恶众生等门。
⑰ 法身　佛三身之一，以真如理为身，无形无相、平等周遍；本卷「法身广大不思议」「一切诸佛一法身」皆显此义。
⑱ 法器　堪受佛法之根器；本卷「普使世间成法器」，谓佛令众生堪任接受一乘大法。
⑲ 无央数　即阿僧祇之意，谓不可限量之数；本卷「无央数劫」「无央劫」表时极久。
⑳ 十力　佛所独具之十种智慧力用，如处非处智力等；本卷「佛于是中修十力」「忆念出生佛力智光明」即指此。
㉑ 摩睺罗伽王　摩睺罗伽译「大蟒神」「大腹行」，八部众之一，人身蛇首；本卷十王主令众生除烦恼、入清净法等门。
㉒ 甘露　梵语 amṛta，译「不死」「甘露」，喻涅槃、佛法能令众生离生死苦；本卷「示甘露道使清凉」。
㉓ 福田　众生植福之处，如农夫种田得果；佛、法、僧为胜福田，本卷「普为众生作福田」即此义。
㉔ 法界　诸法所依之真如理体，亦指一切法差别重重之境界；本卷主方神、主空神等皆显「法界周遍」「普入法界」义。
㉕ 波罗蜜　梵语 pāramitā，译「到彼岸」「度」，菩萨六度或十度之行；本卷多次出现，如「普净广大波罗蜜」「波罗蜜海悉圆满」。
㉖ 紧那罗王　紧那罗译「疑人」「歌神」，帝释之法乐神，似人而头有一角；本卷十王主生喜乐、演妙音等门。
㉗ 迦楼罗王　迦楼罗译「金翅鸟」，以龙为食，翅金金色，八部众之一；本卷十王主普观察众生、成就波罗蜜等门。
㉘ 真如　诸法真实常住一如之理体，无为无相；本卷「一切诸佛一法身，真如平等无分别」即显此义。
㉙ 罗睺阿修罗王　罗睺（Rāhu）为阿修罗王之一，传说能障蔽日月；此王得现为大会尊胜主解脱门。
㉚ 阿修罗王　阿修罗译「非天」，有天福无天德，常与帝释争战；本卷列罗睺、毗摩质多罗等十王，各得一门赞叹佛德。
㉛ 善根　能生善果之根本，即信、精进、念、定、慧等善法之根；本卷「善根光照」「成熟善根」「集不可坏善根」等，谓众生依佛力而长养善本。
㉜ 主昼神　主司白昼之天神，属日天眷属；本卷十位主昼神，主普入世间、开发信解等门。
㉝ 主夜神　主司夜分之天神，属月天眷属；本卷十位主夜神，主禅定乐、救护众生等门。
㉞ 主方神　主司十方方位之天神；本卷十位，主普救护、破闇生喜、普现名号等门，显方法界周遍。
㉟ 主空神　主司虚空之天神；本卷十位，主普知众生心、普入法界、除业惑障等门，显空界无碍。
㊱ 主风神　主司风之天神；本卷十位，主普入佛法、以香风灭病、破魔军等门，以风之周行喻法界普动。
