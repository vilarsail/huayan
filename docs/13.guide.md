# 大方广佛华严经卷第十三 导读

## 一、内容总览

本卷含两品，是《华严经》「解」门之要。《光明觉品第九》承前「净行」「贤首」之余势，以佛足轮下放光为缘起，光明由一三千大千世界渐次扩广至尽法界虚空界一切世界，一一世界中皆见佛坐莲华藏师子座、十佛刹微尘数菩萨围绕，各处文殊师利同时发声说颂，共十番，义由浅入深，自利升至圆融。《菩萨问明品第十》由文殊发问，依次问觉首、财首、宝首、德首、目首、勤首、法首、智首、贤首九大菩萨，各以颂答，最后诸菩萨反问文殊，文殊以「如来深境界」一颂总答。两品合观：前者以光显境，明事相上「一即一切」；后者以问答显理，明理体上「一多相即」，事理交彻，为后菩萨行铺下理论基础。

## 二、结构层次（★重点）

本卷以「放光递展 → 问答显理」两轴构成，前事相、后理体：

**光明觉品：光势由狭至广层层推开，每番扩广对应文殊一颂**
- 佛足轮下放百亿光明照一三千大千世界（P3）→ 第一颂：明「解脱离诸漏」「一中解无量」之自利行
- 光明遍照十方十佛国土（P5）→ 第二颂：明「破诸烦恼障」「不舍地狱苦」之悲智双运
- 过十照百世界（P7）→ 第三颂：明「佛了法如幻」，佛八相成道之化现
- 过百照千世界（P9）→ 第四颂：明佛「体性常不动」「非有遍诸有」之空寂
- 过千照十千世界（P11）→ 第五颂：明「如是业应作」之十种菩萨所应作业
- 过十千照百千世界（P13-P14）→ 第六颂：明「病眼颠倒见」「如来非以相为体」，破相见性
- 过百千照百万世界（P16-P17）→ 第七颂：明「如来最自在」「多中无一性」之圆融
- 过百万照一亿世界（P19-P20）→ 第八颂：明「方便力」之十波罗蜜行
- 过一亿照十亿世界（P22-P23）→ 第九颂：明「誓度众生是其行」之十大悲愿
- 尽照法界虚空界一切世界（P25）→ 第十颂：明「一念普观无量劫」「佛遍虚空」之究竟

规律：光势每番扩一阶（十→百→千→百万→亿→十亿→尽虚空界），颂义由自利到利他、由有相到无相、由差别到平等，收归「佛遍虚空亦如是」之极圆融境。

**菩萨问明品：十番问答，皆立「一与多」之疑而化解之**
- 文殊问觉首：心性是一云何见种种差别？→ 答：诸法无作用无体性，各各不相知（如河中水、大火聚、长风、地界）
- 问财首：众生非众生云何随其种种现身教化？→ 答：身假安立、寿命如旋火轮、世间唯心
- 问宝首：众生等有四大云何苦乐不同？→ 答：随业受报，如镜现像、如田种子、如机关木人
- 问德首：如来唯悟一法云何说无量？→ 答：如地一、火一、海一、风一，一法出生多
- 问目首：福田等一云何果报不同？→ 答：如大地随种、如水因器，福田一而众生心异
- 问勤首：佛教是一云何不即断烦恼？→ 答：懈怠如樵湿火灭、钻燧数息，须精进
- 问法首：受持正法云何复起烦恼？→ 答：非但多闻，如水漂渴死、设膳自饿，须修行
- 问智首：智为上首云何复赞施戒等？→ 答：佛知众生心性不同，随应说法，次第修习
- 问贤首：诸佛一道出离云何佛土众事不同？→ 答：一道一法身，差别皆随众生心业见殊，非佛过咎
- 诸菩萨反问文殊：何等是佛境界？→ 文殊总答：如来深境界量等虚空，一切众生入而实无所入

衔接：每问皆立「一与多」「平等与差别」之矛盾，每答皆以「一法出生多」「业力差别」化解，最后文殊以「法界众生界究竟无差别」收束。两品合观：光明觉品以光之扩展显事相之「一即一切」，问明品以问答显理体之「一多相即」，事理二门互为表里。

## 三、关键结论

1. **一即一切，一切即一**：光明觉品光明由一世界渐遍尽虚空界，一一世界皆见佛坐莲华藏座，事相显「一即一切」；问明品德首、贤首之答显理体「一法出生多」，理事交彻，是华严「事事无碍」法界之雏形。
2. **心佛众生三无差别**：问明品诸答皆归「众生心」「业力」为差别之源，佛境界平等无分别；光明觉品亦由「心净离众着」起，终于「众生分别故见佛种种身」，心为根本。
3. **多闻须修行，懈怠不能度**：勤首、法首两答以九喻（火樵湿、钻燧数息、水漂渴死、设膳自饿等）警策，多闻若不修行如数他宝自无半钱分，是本卷最切实之修行警策。
4. **破相见性，离相乃见佛**：光明觉品第六颂「病眼颠倒见」、第十颂「分别取相不见佛，毕竟离着乃能见」前后呼应，明见佛须离相。
5. **佛境界量等虚空，入而实无所入**：文殊总答之「入无所入」与光明觉品「无住无所入」「一念普观无量劫」义理一贯，明法界本无出入。

## 四、易混辨析

1. **文殊师利 vs 一切处文殊师利**：前者指十方各来大菩萨之首；后者「一切处」谓光明所照一切世界中各有一文殊同时发声，显智之遍在，非一人分身，乃法界本尔。
2. **佛刹 vs 世界 vs 三千大千世界**：三千大千世界指一佛所化之境（百亿日月）；世界为通名；佛刹多就一佛教化区域或净土而言。本卷「十佛刹微尘数菩萨」谓十方佛刹磨为微尘之数，非「十个佛刹」之菩萨。
3. **一道出生死 vs 一法出生多**：贤首答之「一道」谓诸佛同以一实相道出离，就「能出之行」言；德首答之「一法」谓如来所悟唯一实相而能现无量，就「所悟之理」言。
4. **多闻 vs 修行**：法首答「非但以多闻能入如来法」破斥，多闻是闻慧，修行是思修二慧，须三慧具足方入法性，非贬多闻，乃破「多闻即足」之执。

## 五、阅读提示

读光明觉品，留意光明扩展阶次与颂义升进相应——光势愈广，颂义愈深，可作「十地」旁通读。读问明品，抓「一与多」「平等与差别」之矛盾结构，每问答先立疑后以喻化解。两品合观，事相之光明递展即理体之问答所明，事理不二，方见华严之妙。
