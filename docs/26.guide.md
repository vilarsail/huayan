# 大方广佛华严经卷第二十六 导读

## 一、内容总览
本卷为《大方广佛华严经·十回向品第二十五》之四，承接前卷，继续宣说菩萨摩诃萨以财施、法施摄受众生，并将所修善根回向一切智。全卷以「施物差别 → 回向愿海」为骨架，依次举出施宝车、施善知识车、施僧、施声闻独觉、施贫穷、施象马、施座、施盖、施幢幡、施宝、施庄严具、施宝冠、救牢狱囚、代刑赎命等种种布施；每一施后必「以诸善根如是回向」发大愿海，愿一切众生同得此益、共证一切智。主旨是：菩萨行施不为自利，乃借施门成就众生、回向无上菩提，使有情趣入佛智。

## 二、结构层次（★重点）
全卷结构高度整齐，每个施门皆循「明施境/施物 → 起心 → 回向愿文 → 结说所为」四段，层层推进：

- **总标施境与施心**（P3）→ 列举奉施对象（佛、菩萨、师长、善友、声闻、缘觉、贫穷孤露）与来意（远来、近来、闻名来、因缘来、愿来、请来），引出「众妙宝车」种种差别庄严，奠定全卷「财施摄众」基调。
- **施宝车回向**（P4–P9，六段一组施车）→ 按「佛 → 善知识 → 僧 → 声闻独觉 → 贫穷孤独」次第展开，每段施物或同或异（琉璃、白银、杂宝、栴檀、玻璃、码瑙、光明宝、香车等），而回向愿文各契其境，皆收归「成一切智」「乘无上智乘」。其中施贫穷段（P8–P9）特详菩萨自悔拜跪、随其所求悉皆施与，显大悲平等。
- **施象马、座、盖、幢幡、宝、庄严具、宝冠**（P10–P16）→ 施物由车马器物渐次升进至灌顶宝冠、髻中明珠，象征舍王位、舍身命之增上施；每段回向愿皆以「乘」「座」「盖」「幢」「宝」等喻收归佛法，愿众生成满普贤行愿、得如来十力。
- **救牢狱囚、代刑赎命**（P17–P18）→ 由外财转入「舍身命布施」：先救枷锁牢狱众生，次见死刑囚自舍身代受，引阿逸多、妙眼王等菩萨为证，明菩萨为救护一切众生发一切智菩提心，乃本卷施门之极。
- **收束**（P4 结等）→ 各段「为令众生……」之结语反复出现，将所有施门善根统一回向「令众生得一切智乘、究竟出离」，与十回向品总旨相贯。

## 三、关键结论
1. 十回向的核心是「以施门成愿、以愿海回向」——菩萨非仅行施，而是将一施之善根扩充为无尽愿，愿一切众生同得此益。
2. 施物由粗至细、由外财至身命：车马 → 座盖幢幡 → 宝冠 → 自身，层层升进，终至舍身代命，显菩萨布施波罗蜜之究竟。
3. 施境平等：从诸佛、菩萨、僧宝到声闻独觉、贫穷孤露乃至死刑囚，皆为福田，菩萨一律恭敬承事、无疲倦悔吝。
4. 每一施皆「回向一切智」：愿众生乘无碍智乘、成普贤行愿、得如来十力——回向之所趣唯一无上菩提。
5. 回向愿文中以「乘」为高频喻：不退转乘、清净因乘、四轮乘、智慧乘、佛乘、一切智最上宝乘等，贯摄全卷，表「运载众生至究竟位」。

## 四、易混辨析
- **福田 vs 善知识**：福田泛指一切堪受供养、能生福者（佛、僧、父母、贫穷皆是福田）；善知识特指能教导、摄受菩萨修行之人，是有德之师，福田中之一类。
- **声闻 vs 独觉（辟支佛）**：声闻闻佛声教而悟道；独觉无佛世自悟十二因缘，又称缘觉、辟支佛，本卷二种并列施之。
- **檀波罗蜜 vs 波罗蜜**：波罗蜜通指「到彼岸」之六度或十度；檀波罗蜜特指布施度，本卷施声闻段言「具足无上檀波罗蜜」即此。
- **回向 vs 愿**：愿是发心希求（「愿一切众生……」）；回向是将已修善根转趣无上菩提，愿为能发，回向为能转，二者一体两面。
- **灌顶王 vs 转轮王**：灌顶王为受灌顶位之刹帝利王；转轮王为以正法治世、具七宝之大王，本卷施座段兼举灌顶大王与转轮王，表王位之舍。

## 五、阅读提示
读本卷可带着两个问题：（1）每一施物之后，菩萨是如何把「这一物之施」转化为「无尽愿海」的？留意「愿一切众生」的反复句式与「为令众生……」的结语收束；（2）施物为何从外财层层升进到舍身代命？这背后是菩萨「为救护一切众生发一切智菩提心」的根本动力（见 P18 自述）。把握此二端，则全卷财施回向之脉络可贯通。
