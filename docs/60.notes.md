# 大方广佛华严经卷第六十 词语注释

〔1〕 实叉难陀　于阗（今新疆和田）僧人，梵语音译，意译「学喜」；八十卷《华严经》的译者，「三藏」指精通经、律、论的法师，「奉制译」谓奉皇帝诏命翻译。
〔2〕 入法界品　《华严经》第三十九品之名，也是全经最后一品；「法界」指一切法的广大无尽的实在，「入法界」即契入其中，善财童子五十三参即在此品展开，本卷是此品的开篇。
〔3〕 逝多林　梵语 Jeta 音译，即祇陀太子的树林；与「给孤独园」合为佛陀著名道场（祇树给孤独园），本卷如来的一切神变都示现于此。
〔4〕 给孤独园　舍卫城长者须达多（号给孤独）买祇陀太子园林建精舍供佛，故名；与逝多林为同一道场。
〔5〕 菩萨摩诃萨　梵语音译：「菩萨」意译觉有情，「摩诃萨」意译大有情；指发大菩提心、求一切智的大菩萨。
〔6〕 摩尼　梵语 maṇi 音译，意译如意宝、宝珠；传说能随心愿出种种宝物与光明，经中一切宝庄严多冠以「摩尼」。
〔7〕 世主　世间之主，指天王、龙王、人王等统摄一方的神与王；此处「诸世主」是与会护法众之一。
〔8〕 普贤行愿　普贤菩萨所代表的广大修行与誓愿（后世归纳为十大愿王）；本卷说诸菩萨「皆悉成就普贤行愿」，即以普贤的愿行为自体。
〔9〕 声闻　闻佛声教、悟四谛而证果的弟子；本卷特意反复安排「诸大声闻在逝多林却看不见如来神变」，以显示菩萨境界非二乘所能及。
〔10〕 离结、使、缚　「结」如绳结缠人、「使」如役使驱人，都是烦恼的异名，「缚」即缠缚；合指声闻断尽烦恼系缚。
〔11〕 不请友　不待众生祈请而主动亲近、教化的良友，形容佛菩萨慈悲主动、恒勤守护众生。
〔12〕 生如来家　以真如、大愿为家而入于佛家，成为真正的佛子；与前句「不断佛种」连读，谓绍隆佛种、延续佛的慧命。
〔13〕 如来加持　加持即佛以威神力加护众生令其受持；此处列举如来境界、智行、加持等十事，谓皆非凡夫二乘能通达。
〔14〕 三昧　梵语 samādhi 音译，意译正定、正受，心住一境而不散乱的定境；华严经中以种种三昧显示佛菩萨的定慧境界。
〔15〕 加被　即保佑、覆护、摄受；「诸佛加被之力」与下文宿世善根力等并列，是众生能见佛神变的助缘。
〔16〕 宿世　过去世、前生；「宿世善根之力」指往昔多生累积的善根之力。
〔17〕 善知识　教人善道、导归佛道的师友；「诸善知识摄受之力」是能趣入佛境界的助力之一。
〔18〕 波罗蜜　梵语 pāramitā 音译，意译「到彼岸」，指从生死此岸渡到涅槃彼岸的修行法门；常举布施等六种（六度）。
〔19〕 本事因缘　「本事」指佛在过去世的故事（本生、本行）；「往昔所有本事因缘」即请佛叙说自己过去修行的因缘。
〔20〕 净佛国土　庄严清净佛国土，即菩萨为摄化众生而修的净土之行；此处是请佛宣说的往昔修行之一。
〔21〕 师子频申三昧　「频申」又作频伸，舒展屈伸之貌；「师子频申」即狮子奋迅，喻佛入此三昧时威势奋动、境界开展，是本卷如来所入的核心三昧。
〔22〕 阎浮檀金　梵语音译，传说阎浮提河流中出产的金，色赤黄、光焰殊胜；经中常用以形容最上等的金色。
〔23〕 危楼迥带　「迥」（jiǒng）远貌，「带」环绕；此句与下文「阁道傍出，栋宇相承，窗闼交映」并列，描写楼阁高耸、飞廊回环、窗牖相映的建筑庄严，宜作一组连读。
〔24〕 阶、墀、轩、槛　墀（chí）指台阶或台上空地，轩指堂前长廊，槛（jiàn）指栏杆；四字连言概指殿前台阶廊庑栏槛诸设施，皆以妙宝庄严。
〔25〕 栏楯　楯（shǔn）即栏杆；「阶隥（dèng，台阶）栏楯」谓台阶与栏干，其数无量，皆摩尼宝所成。
〔26〕 佛刹微尘数　把一个佛国土碎为微尘来计量数目，极言其多；下文「世界海微尘数」同例，是华严惯用的大数表达。
〔27〕 阿僧祇　梵语 asaṃkhya 音译，华严十大数之一，意为无数无量；「阿僧祇宝」极言宝物之多。
〔28〕 多罗树　梵语 tāla 音译，棕榈科高直大树，其叶可书写经文（贝叶经）；「宝多罗树」谓宝质的多罗树，庄严道侧。
〔29〕 洄澓　澓（fú），水流回旋；「湍激洄澓」形容香河水势湍急、回旋成涡。
〔30〕 不思议　「不可思议」之略，谓超越言语思虑的境界；华严经的高频词，多形容佛境界、神变、数目之广大深妙。
〔31〕 芬陀利华　梵语 puṇḍarīka 音译，白莲花，莲花中的最上品；此处「不思议宝芬陀利华」指宝质的白莲。
〔32〕 菡萏芬敷　菡萏（hàn dàn），含苞将放的荷花；芬敷（fēn fū），花开敷而散香之貌。
〔33〕 氛氲　氲（yūn），烟气香气浓郁盛起之貌；「香气氛氲」即妙香弥漫。
〔34〕 宝缯幢　缯（zēng），丝帛、绢帛；幢是柱状丝帛旗幡类的庄严具，「宝缯幢」即以宝丝帛所作之幢，以下宝幡幢、宝鬘幢等并列。
〔35〕 本事海　佛过去世的行业故事深广如海，故称「本事海」；上方菩萨于毛孔中普现诸波罗蜜本事。
〔36〕 须弥山云　难点：以上诸句「种种涂香烧香须弥山云」等，皆谓种种香、香水、摩尼宝堆聚如须弥山形状的云，非另有所指之物。
〔37〕 妓乐　「妓」通「伎」，妓乐即伎乐、音乐歌舞；「不可说妓乐云」谓状如音乐歌舞的云。
〔38〕 白法　善法。白表纯净无垢，与「黑法」（恶法）相对；「如来白法悉圆满」谓佛一切善法圆满如满月。
〔39〕 成、住、坏、劫　世界成立（成）、安住（住）、破坏（坏）三期及其所历时间（劫），说世界变迁的四阶段；此句谓佛能于一毛孔普现十方世界历此变迁之相。
〔40〕 顶礼佛足　五体投地、以己首接佛足的最敬礼，亦名接足礼；以下十方菩萨来集皆先顶礼佛足再化座而坐。
〔41〕 结跏趺坐　趺（fū）足背；两足交叠置于左右股上的坐姿（盘腿端坐），是佛与菩萨端坐的威仪。
〔42〕 涂香　涂身的香料，与「烧香」（焚熏之香）相对，皆为供养具。
〔43〕 栴檀　檀香木，梵语 candana 音译；木质香烈，经中常用作涂香、楼阁材料。
〔44〕 发趣　发心趣向菩提；「出一切众生发趣音」谓冠上摩尼发出引导众生发起趣求菩提之心的音声。
〔45〕 契经　契理契机之教，经藏的总称；「转法轮契经门名号海」谓佛所转法轮的法门名号如海。
〔46〕 牟尼　梵语 muni 音译，意译寂默（寂静止默）；释迦牟尼之「牟尼」即此，颂中「牟尼悉超越」谓佛超越「量」与「无量」二边。
〔47〕 授记　佛预言某众生未来当得作佛及其名号、劫寿等；「已得授记、未授记者」指诸佛中已受成佛之记与尚未受记者。
〔48〕 檀那波罗蜜　檀那＝布施，即布施波罗蜜；此段历数佛过去世行布施、持戒、忍辱等诸波罗蜜的本生故事（本事海）。
〔49〕 尸罗波罗蜜　尸罗＝持戒，即戒波罗蜜。
〔50〕 羼提波罗蜜　羼提（chàn tí）＝忍辱，即忍辱波罗蜜；「割截肢体心无动乱」暗用佛前生被歌利王截割身体而心不动的故事。
〔51〕 帝青　帝释青，即青金石一类深蓝宝，色如帝释天之青；传说「帝青宝能青一切色」，喻见佛者皆发起菩提之行。
〔52〕 修多罗　梵语 sūtra 音译，意译「经」；「修多罗海」形容佛所说经法如海之多。
〔53〕 诸有　「有」指三有、二十五有等生死存在的类别；「知一切诸有生起如热时焰」谓了知一切生死现象如阳焰幻影。
〔54〕 热时焰　即「阳焰」，暑天旷野上似水波流动的蒸气幻影，佛经常用以比喻虚幻不实之法。
〔55〕 十力　佛独具的十种智慧力（知处非处、业报、禅定、诸根、种种欲、种种性、一切至处道、宿命、天眼、漏尽）；与「无畏」（四无所畏）并称佛果功德。
〔56〕 刹那　梵语 kṣaṇa 音译，最短的时间单位；「一念之顷」「刹那顷」极言时间之促而菩萨神用之速。
〔57〕 上首诸大声闻　此句下历数舍利弗、大目揵连、摩诃迦叶、须菩提等十大弟子之名；「上首」谓众中之首。
〔58〕 阿㝹楼驮　㝹（nóu），即阿那律，佛十大弟子之一，天眼第一；此处列名于大声闻之中。
〔59〕 如来游戏　「游戏」谓佛于神通境界自在往来、从容无碍，如儿戏般轻松，非嬉戏之义；与神变、尊胜等并列，皆是声闻所不能见之事。
〔60〕 频申　又作频伸，舒展身体之貌；「菩萨频申」列于菩萨种种自在事中，指菩萨如狮子频申式的三昧威势。
〔61〕 二乘　声闻乘与缘觉乘，相对于菩萨乘（大乘）而言；经中反复强调普贤智眼境界「不与一切二乘所共」。
〔62〕 无有谛　谓声闻于「无有」（我空、空寂无所有）的谛理得决定解，故常住实际而离大悲、舍众生；与大乘悲智双运相对，是本段解释声闻不能见佛的要义。
〔63〕 恒河　印度恒河，佛经常以「恒河沙数」极言其多；此段以恒河边饿鬼因业障覆眼、虽住河边而不见河，比喻声闻不见如来神力。
〔64〕 搏撮　撮（cuō），抓取；「乌鹫豺狼竞来搏撮」形容饿鬼被禽兽争相抓食之苦。
〔65〕 无明翳瞙　翳瞙（yì mào），眼中遮障视线的薄膜（白翳）；喻声闻被无明遮蔽其眼，虽在逝多林而不见佛神力。
〔66〕 萨婆若　梵语 sarvajñā 音译，意译一切智，指佛智；「萨婆若地」即一切智地（佛果位），声闻不曾种植此善根。
〔67〕 善见大城　帝释天在须弥山顶所住的都城（喜见城）；此段以大会中有人昏睡梦见天城严好而旁人不知不见，比喻声闻与菩萨同处而不见佛境界。
〔68〕 采女　宫中供役使的歌舞女侍；天宫亦有诸采女歌咏美音，此处属梦境中天宫庄严的描写。
〔69〕 伏藏　埋藏于地中待发掘的宝藏；「善能分别一切伏藏」比喻菩萨以慧眼知佛功德藏所在，无福德者至宝藏处而不见。
〔70〕 赈恤　赈（zhèn），救济；「赈恤亲属」即周济亲属，下文「靡不均赡（shàn）」谓老病穷乏无不周遍供给。
〔71〕 四摄　布施、爱语、利行、同事四种摄化众生的方法；「以四摄摄受众生」是菩萨利他之行。
〔72〕 遍处定　观地、水、火、风、青、黄、赤、白、虚空、识等遍满一切处的禅定（加一切语言音声、一切所缘共十二种）；入定者自见所缘境界，其余大众悉不能见，喻菩萨见佛境界而声闻莫睹。
〔73〕 翳形药　「翳」（yì）此处义为隐蔽，翳形药即隐形药，涂眼能令人不可见而自能见物；比喻如来超世普见世间，而声闻不能得见。
〔74〕 同生　与「同名」二天：人生时有二天恒相随逐，一名同生、一名同名，记录人之善恶；「天常见人，人不见天」，比喻佛在菩萨会中现大神通而声闻不见。
〔75〕 灭尽定　灭尽六识与受想的深定（灭受想定）；「六根作业皆悉不行……定力持故，不般涅槃」谓由定力持身、不起现行而不入灭，喻声闻具足六根却于佛境界不知不觉。
〔76〕 非其器　不是承受此法的根器；本段结语，谓如来神变、菩萨众会等事声闻「悉不知见」，因其器量狭小、不堪受此大法。
〔77〕 承佛神力　仰仗佛的威神加持；以下各菩萨说颂之前皆以此句与「观察十方」起首，表示说法非凭自力，是本卷颂文的固定套语。
〔78〕 善逝　梵语 sugata 意译，佛十号之一，善往涅槃彼岸、善逝世间之意；颂中与「法王」「世灯」等皆为佛的别称。
〔79〕 无央数　央即尽头；「无央数」即无数无量。
〔80〕 缘觉　观十二因缘而自觉的圣者，即辟支佛；与声闻合称二乘，皆不能知菩萨行境界。
〔81〕 安隐　即「安稳」，「隐」通「稳」；颂中「安隐诸世间」谓令世间众生得安稳。
〔82〕 释师子　释迦牟尼佛的譬称，佛说法无畏如狮子王，故称「释师子」；下文「能师子吼」同此喻。
〔83〕 含识　具有意识情虑的众生，一切有情的异称；「饶益诸含识」「普导诸含识」即利益、引导一切众生。
〔84〕 渴爱　如渴者求水的贪爱，喻众生贪欲之切；「见佛能除诸渴爱」谓见佛清净能除贪渴之恼。
〔85〕 无师智　无师独悟之智，即不由他教、自然开觉的自然智；颂以「海具众宝」为喻，谓见者悉开悟。
〔86〕 举足下足事　偈颂难点：谓佛一举足、一下足（寻常行住之间）所含的境界；佛的每个动作皆深不可测，三世声闻缘觉尚不能知，何况凡夫。
〔87〕 结使　烦恼的异名：结如绳结缚人，使如使者驱人；「结使所缠缚」谓凡夫为烦恼所困，故不能知佛。
〔88〕 智身非是身　偈颂难点：佛的智身不是物质形躯，无碍而不可思议；下文「从不思议业，起此清净身」谓此身由不可思议愿行所成，不著三界。
〔89〕 三有　欲有、色有、无色有，即三界生死；「普净三有处」谓如日普照，净除三界众生之障。
〔90〕 回向　以所修功德回转趣向于特定目标（如菩提、众生、佛道）；「一切悉回向，诸佛所求道」谓所修功德悉皆导向佛道。
〔91〕 蕴界　五蕴（色受想行识）与十八界（根、尘、识）等，泛指一切有为法；颂谓凡夫执著蕴界诸法，菩萨舍离而专求佛功德。
〔92〕 婴妄惑　婴，古义为缠绕、被……所缠；「凡夫婴妄惑」即凡夫被虚妄惑业所缠缚，故于世间生死流转。
〔93〕 大福田　佛为世间最上福田，供养佛能生大福；颂文下文即说供养见佛能除恶道畏、消灭诸苦之利。
〔94〕 两足尊　佛的尊号：于两类二足众生（人、天）中最为尊贵，亦解作福德、智慧二足圆满之尊。
〔95〕 宁代诸众生　偈颂句式难点：此段以下数联皆「宁……终不……」的让步句式——宁可代众生受一切苦、宁可生于恶道恒闻佛名，也终究不舍佛；是菩萨悲愿的极端表达。
