# 大方广佛华严经卷第四十一 导读

## 一、内容总览

本卷为《大方广佛华严经》第四十一卷，承接第三十九、四十卷「十定品第二十七」之一，是十定品的下半（「十定品第二十七之二」）。经文以普贤菩萨回答佛子之问的形式，逐一阐明菩萨摩诃萨所入的十种大三昧中第三至第七共五种：次第遍往诸佛国土神通三昧、清净深心行三昧、知过去庄严藏三昧、智光明藏三昧、了知一切世界佛庄严三昧。每一品皆以「佛子！云何为菩萨摩诃萨……三昧？」发问，再以「佛子！是为菩萨摩诃萨第N……大三昧善巧智」收束，层层展开菩萨以三昧力遍入三世十方、了知众生根欲、成就佛事功德的境界。本卷主线是：菩萨于时劫国土无所分别，以善巧方便起三昧用，令自他皆得圆满。

## 二、结构层次（★重点）

全卷按「五定次第展开 → 每定以『问—答—喻—结』四段构成」一线贯穿，由总到分、由时入空：

- **总起（P2）**：标品题「十定品第二十七之二」，衔接上卷第一、二定。
- **第三定：次第遍往诸佛国土神通三昧（P3）**　
  - 法相展开：菩萨过东方无数世界，复过微尘数世界 → 以刹那至不可说不可说劫种种时劫入三昧 → 列举时劫阶次（须臾→日→月→年→劫→不可说不可说劫），构成一条由近至远、由短至长的递进序列。
  - 不二收束：「不作二、不作不二，不作普、不作别」→ 心无分别而神通起用。
  - 日天子喻：日出为昼、日没为夜，昼不生、夜不灭 → 印证菩萨于时劫无分别而妙用不息。
- **第四定：清净深心行三昧（P4）**　
  - 供养展开：以妙香、妙华、盖、庄严具、摩尼宝、上味饮食等十类供养具，于阿僧祇世界微尘数诸如来所供养 → 举身布地、请问佛法、赞佛平等。
  - 阳焰喻：日中阳焰远望似水、近之则无 → 诸佛有相无相皆是想心分别，菩萨不分别如来出世及涅槃相。
  - 寤梦喻：从睡得寤、忆所梦事 → 入三昧见佛闻法，起已忆持不忘，以此开晓众会。
- **第五定：知过去庄严藏三昧（P5）**　
  - 次第智展开：劫次第→刹次第→佛出现→说法→心乐→根→调伏→寿命→亿那由他年岁数量，构成一条「时—土—佛—法—机—根—化—寿」的因果链条。
  - 灌顶法：从三昧起，于如来所得十种不可思议灌顶法（辩不违义、说法无尽……调御妙法）。
  - 歌罗逻喻：如入胎藏一念托生 → 菩萨从定起一念即得十法。
- **第六定：智光明藏三昧（P6–P7）**　
  - 未来佛了知：知未来一切劫中所有诸佛，名号、授记、出现、利益、成觉皆悉了知。
  - 劫数阶次：由一劫至不可说不可说佛刹微尘数劫，与佛刹微尘数并列递进。
  - 十种持门：佛持、法持、行持、力持、智持、大悲持、差别善巧句持、师子受生法持、智力持、善友力持、无住力持、法力持 → 由入持得相应功德。
  - 日出喻：日光平等无分别，而令有目者见种种相 → 三昧体性平等而能知差别。
  - 十种不空：见、闻、同住、发起、行、亲近、愿、善巧法、雨法雨、出现，皆令众生不空。
  - 八部礼赞：诸天、龙、夜叉、阿修罗、迦楼罗、梵天、紧那罗、摩睺罗伽、乾闼婆、人王皆来亲近供养。
- **第七定：了知一切世界佛庄严三昧（P8–P12）**　
  - 十方次第入：次第入东、南、西、北、四维、上下一切世界 → 见诸佛神力、游戏、威德、师子吼、所修诸行、种种庄严、神足变化、众会云集。
  - 众会量等展开：众会量等阎浮提→四天下→小千→中千→大千→百千亿那由他佛刹→不可说不可说佛刹微尘数佛刹，由小至大递进。
  - 自身普入：自见身在彼说法、受持佛语、住虚空、住法身、普入诸地、普入真如、普入无诤、普入诸法 → 不分别国土、众生、佛、法、身、身业、心、意。
  - 佛身量喻：佛身由七肘至不可说不可说大千世界量；以虚空喻（芥子孔不减、无数世界不增）、月轮喻（阎浮见小不减、月中见大不增）、命终受生喻（不离于心所见清净）三重印定「如来身不增不减」。
  - 十速疾法、十法印：成就速增诸行、转法轮度生等十速疾法；复得十法印，同去来今诸佛平等善根、无边际智慧法身、不二法、十力无碍等。
  - 帝释髻珠喻：帝释顶髻置摩尼宝，初获即得十法过三十三天 → 菩萨初得此三昧即得十种广大智藏。
  - 十清净威德身、十圆满、十佛事：放光明轮、化种种身、雨香华云、毛孔出音乐等十威德身；令众生见佛、深信、闻法、发菩提心等十圆满；以音声、色形、忆念、震动世界、梦中现相、放大光明、成正等觉、转法轮、现住寿命、示般涅槃等作十种佛事。

## 三、关键结论

1. 菩萨于时劫（刹那至不可说不可说劫）与国土（一佛刹至不可说不可说佛刹微尘数）皆「不生分别、心无染着」，而起三昧妙用，是为十定品的根本义。
2. 三昧力令菩萨一念遍入三世十方，了知过去佛、现在佛、未来佛之名号、说法、众生根欲、调伏次第，穷尽法界差别相而体性平等。
3. 诸佛有相无相、出世涅槃皆是想心分别；菩萨以阳焰、寤梦、虚空、月轮等喻了达「如来身不增不减」，于相离相。
4. 菩萨由三昧得起十种灌顶法、十种持门、十种不空、十速疾法、十法印、十清净威德身、十圆满、十佛事，层层增上，成就与诸如来平等无二的善根智慧。
5. 一切功德的枢纽是「善巧方便」：虽离分别而不舍于行，随世所作而无所执着，以大悲智光普摄取众生，令皆不空。

## 四、易混辨析

- **菩萨摩诃萨 vs 菩萨**：「摩诃萨」意为「大有情」，指已发大心、登地以上的大菩萨；本卷所言「菩萨摩诃萨」皆指十地以上、能入十种大三昧的胜义菩萨，与小乘菩萨或初发心菩萨有别。
- **三昧 vs 陀罗尼**：三昧（正定）是心一境性的定力，本卷所明十定皆以三昧为体；陀罗尼（总持）是忆持不失的慧用，P6「入法持故得十种陀罗尼光明无尽辩才」即由定发慧、由慧起辩的递进。
- **佛刹 vs 世界 vs 三千大千世界**：佛刹指一佛所化之土；世界通指一四天下等器世间；三千大千世界（小千→中千→大千）是佛刹的另一种量度。本卷将三者并列于「众会量等」「佛身量等」的递进序列中，须依上下文辨其所指范围。
- **灌顶位 vs 灌顶法**：灌顶位是十地满心、等觉将成佛的阶位（P6「当入灌顶位」）；灌顶法是菩萨从第五定起于如来所受的十种法（辩不违义等），是因位所得的功德法，非阶位本身。

## 五、阅读提示

读本卷宜把握「时—土—佛—法—机」五重次第的展开骨架，并将每一三昧末尾的譬喻（日天子、阳焰、寤梦、歌罗逻、日出、虚空月轮、帝释髻珠）视为对该定义理的印定，由喻入义，方能贯通「不分别而善巧知」的菩萨境界。
