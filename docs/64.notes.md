# 大方广佛华严经卷第六十四 词语注释

〔1〕 尔时　文言时间词，「那时、这时候」，佛经叙事惯用的开头语。
〔2〕 善知识　指能引导人向善、教授佛法的良师益友；本卷指善财童子一路南行参访的各位老师，卷首即以一连串比喻赞叹善知识的恩德。
〔3〕 津济　津，渡口；济，渡水。比喻引导众生渡过生死之流的渡口或桥梁。
〔4〕 海潮　海水潮汐所至之处，作地名用；善财童子南行至海滨「海潮处」，附近即普庄严园。
〔5〕 普庄严园　海潮处的园林名，为善财本卷第一位善知识休舍优婆夷所居，园中众宝庄严，故以为名。
〔6〕 周匝　周围、环绕一圈；「周匝围绕」即四周围拢起来。
〔7〕 宝华树　华，同「花」，经文一律用「华」不用「花」。本段以「一切宝X树」排比列举园中宝树，读法是抓每句首词（宝华、宝香、宝鬘、摩尼宝王、宝衣、音乐、庄严具）。
〔8〕 氛氲　（fēn yūn）香气浓郁盛多的样子。
〔9〕 宝鬘　鬘（mán），花环、珠串；宝鬘即用珍宝串成的花环璎珞。
〔10〕 阎浮檀金　译自梵语 Jambūnada，阎浮提河流中所出之金，佛经中最上等黄金的通称。
〔11〕 毗卢遮那　梵语音译，意为「光明遍照」，即大日如来，《华严经》的主佛；此处借其名形容摩尼宝的光明。
〔12〕 栏楯　（lán shǔn）栏杆，纵的叫栏、横的叫楯。
〔13〕 八功德水　具有澄净、清冷、甘美、轻软、润泽、安和、除饥渴、长养诸根八种功德的水，佛净土池水常用此称。
〔14〕 栴檀　（zhān tán）梵语旃檀那的略称，即檀香木，香气浓郁，佛经常用作妙香的代表。
〔15〕 凫雁　凫（fú），野鸭；凫雁泛指池中水鸟。
〔16〕 俱枳罗鸟　梵语音译的水鸟名，音声和雅，净土中常见的鸣禽。
〔17〕 多罗树　梵语 tāla，棕榈科高直大树，叶可刻写经文（即贝叶经），佛经常以之为「高树」标准。
〔18〕 由旬　古印度里程单位，一由旬约四十里（一说三十里），用于形容光明照达之远。
〔19〕 陂池　陂（bēi），蓄水的池塘；陂池即池沼。
〔20〕 重楼挟阁　挟，两侧夹辅；多层楼房两旁连接小阁，形容宫殿层叠错落的建筑。
〔21〕 所谓　「就是所说的……」，经文列举名目时的提示语，其后接一串并列清单。
〔22〕 师子　即「狮子」的古写，经文用「师子」不用「狮」；常喻佛菩萨威猛无畏，如师子座、师子奋迅等。
〔23〕 帝释　忉利天（三十三天）之主帝释天，即因陀罗，佛经中的护法天主；此处「帝释所著摩尼宝帐」形容宝帐如帝释所用之庄严。
〔24〕 如是等　「诸如此类」，长清单的收尾语，后接「其数多少」，表示同类项目还有极多。
〔25〕 璎珞　（yīng luò）珠玉串成的项链、胸饰，菩萨与天人的重要庄严具。
〔26〕 曼陀罗华　梵语 māndārava 音译，天界妙花，天人散花供养时常用；「出过诸天曼陀罗华」谓胜过天界的妙花。
〔27〕 采女　宫女、侍女；此处指虚空中飞下来的天女侍从。
〔28〕 休舍优婆夷　本卷第一位善知识，居普庄严园。优婆夷即受持五戒的女居士；休舍是她的名字，门下有八万四千亿那由他大众同行。
〔29〕 绀青发　绀（gàn），红中透青的深蓝色；绀青发即深青色的头发，形容其身相庄严。
〔30〕 如意摩尼　即如意宝珠（梵语 cintāmaṇi），能随人心愿出生种种珍宝的宝珠王。
〔31〕 曲躬　弯腰、屈身，表恭敬行礼。
〔32〕 悉得除灭　悉，全、都；「悉得除灭」即全都得以消除灭尽。这类「悉／皆／咸」是经文常用的总括副词。
〔33〕 见刺　错误见解如毒刺在身；「拔诸见刺」即拔除身见、边见等种种邪见。
〔34〕 一切智　佛的智慧，总知一切法；善财以门、乘、船、炬、道、灯、桥、盖、眼、潮十个比喻赞叹善知识是「趣向一切智」的凭借，读法是抓每句「善知识者，则是……故」的句式。
〔35〕 总持门　总持即陀罗尼，能总摄忆持无量佛法而不忘失；总持门即入此能力的法门。
〔36〕 三昧　梵语 samādhi 音译，意译正定、等持，心专注一境而不散乱的禅定境界。
〔37〕 绕无数匝　绕，右绕（顺时针方向）行走的礼节；匝即一圈。「绕无数匝」极言恭敬之至。
〔38〕 阿耨多罗三藐三菩提　梵语 anuttarā-samyak-saṃbodhi 音译，意译「无上正等正觉」，即佛的究竟觉悟；「发阿耨多罗三藐三菩提心」即发起求成佛之心，为善财每参的固定开场语。
〔39〕 云何　文言疑问词，「如何、怎样」；善财逢每一位善知识必问「云何学菩萨行、修菩萨道」。
〔40〕 唐捐　虚废、白费；「悉不唐捐」即凡与我接触者都不会白费无功。
〔41〕 不退转　梵语 avaivartika，修行达于不再退失、堕落的阶位；「得不退转」即稳登不退之地。
〔42〕 菩提心　求无上菩提（佛觉）之心，大乘修行的起点；下文长段排比皆解释菩萨「为何发菩提心」。
〔43〕 久近　时间的长短；「为久近耶」即「已经多久了呢？」问发心的时间。
〔44〕 然灯佛　即燃灯佛（「然」同「燃」），释迦牟尼前世曾供养并受记的古佛；此处为休舍优婆夷所忆最早供养之佛。
〔45〕 梵行　清净之行，特指离欲持戒的清净修行。
〔46〕 次前　再往前、此前；休舍历数供养诸佛时用，指前一佛之前更前一佛，连举十佛及三十六恒河沙佛。
〔47〕 恒河沙　以恒河沙粒比喻极多之数；「三十六恒河沙佛所」即三十六个恒河沙数那么多的佛处。
〔48〕 承事　承侍奉事，亲身随侍供养。
〔49〕 调伏　调理制伏；指教化众生，使其离恶就善、身心调柔。
〔50〕 不可说不可说转　华严经中最大的数位单位之一；「转」表示倍倍相转、超越常规进位，形容多到言语不可宣说。
〔51〕 阎浮提　梵语 Jambudvīpa 音译，即南赡部洲，我们人类所居世界的名称。
〔52〕 微尘数　以极细的微尘之数比喻极多；「阎浮提微尘数世界」即把世界碎为微尘、一尘一世界，形容数量不可计。
〔53〕 三千大千世界　一个世界千倍聚为小千世界，再千倍为中千、大千，即一佛所教化的国土范围。
〔54〕 佛刹微尘数　把一个佛国土碎为微尘、以尘数计数，华严表示极多世界的固定句式；「十佛刹微尘数世界」即十个佛刹碎为微尘那样多的世界。
〔55〕 住持　此处作动词，安住维持、护持不令消失（非后世「方丈住持」之义）；指护持如来遗留在世的教法。
〔56〕 遗法　佛灭度后遗留在世间的教法；「如来遗法」即佛的教法遗产。
〔57〕 法眼　佛五眼之一，能见众生根机与诸法差别；「持一佛法眼」即受持佛的法眼智慧。
〔58〕 心海　众生之心深广如海，含藏一切；与根海、业海、行海、烦恼海、烦恼习海为一组排比，读法是抓「不为知一众生X海故」的句式。
〔59〕 烦恼习　即烦恼习气（梵语 vāsanā），烦恼断尽后残留的习惯势力，比烦恼更微细难除；故菩萨愿「拔一切众生烦恼习海」。
〔60〕 悉无余　全部彻底、毫无遗留；本段以「欲……悉无余故发菩提心」排比，说明菩萨发心是为度尽、成就一切，非为一己。
〔61〕 取要言之　提要而言之、概括地说。
〔62〕 阿僧祇　梵语 asaṃkhya 音译，意为「无数」，印度大数名；「百万阿僧祇方便行」极言发心所具方便之多。
〔63〕 安隐　即「安稳」（隐通稳）。休舍所得解脱名「离忧安隐幢」：离忧恼、得安稳，幢为高显庄严的旗柱，喻众生可依之而立。
〔64〕 菩萨摩诃萨　摩诃萨（摩诃萨埵）意为「大有情」；菩萨摩诃萨指道位高、愿力广大的大菩萨。
〔65〕 善见药　佛经中的灵药名，一触即能除一切病；此处喻菩萨能除众生烦恼重病。
〔66〕 那罗素　国名，善财辞别休舍优婆夷后南行所到的国度，毗目瞿沙仙人所居。
〔67〕 毗目瞿沙　梵语音译的仙人名，那罗素国中领徒一万的大仙人（苦行者），自称得「菩萨无胜幢解脱」，为善财第二位参访的善知识。
〔68〕 扶疏布濩　扶疏，枝叶繁茂四布；布濩（bù hù），散布遍布。形容树叶繁盛铺展之貌。
〔69〕 沉水树　即沉香树，木质坚重、入水即沉，香气悠远，故称沉水香。
〔70〕 波吒罗树　梵语 pāṭala 音译，花极香的乔木；下文尼拘律、阎浮檀等树名皆梵语音译，只须知是印度圣林中的树即可。
〔71〕 尼拘律树　梵语 nyagrodha 音译，即榕类大树，枝叶广大能荫蔽众人；「耸擢（zhuó）」即高耸挺拔。
〔72〕 优钵罗华　梵语 utpala 音译，青色莲花。
〔73〕 波头摩华　梵语 padma 音译，赤色莲花。
〔74〕 十力　佛独有的十种智力（知是处非处、知业报、知众生诸根等）；「生十力光」谓生出如佛十力的智慧之光。
〔75〕 涅槃城　涅槃是超出生死的解脱境地，喻如安稳之城；「得入涅槃城」即达到解脱。
〔76〕 夷险道　夷，平坦；险，艰险。即辨明道路的平坦与险恶，喻善知识令人看清正路歧路。
〔77〕 大慈凉　大慈如伞盖遮蔽烈日，令众生得清凉；承上句「一切智盖」（智的伞盖）而来，谓依智盖而生大慈的清凉。
〔78〕 含识　具有心识者，即一切有情众生的别称。
〔79〕 阎罗王界　阎罗王所辖的幽冥之界；「转去阎罗王界」谓令众生永离恶趣生死。
〔80〕 难处　指八难之处——地狱、饿鬼、畜生、盲聋喑哑、世智辩聪、生边地、生长寿天、佛前佛后等无暇修学佛法之处。
〔81〕 苦蕴　蕴，积聚；苦蕴即众苦的积聚，指五取蕴之身众苦所集。
〔82〕 轮围山　围绕世界最外层的铁围山（梵语 Cakravāḍa）；「以福德大轮围山围绕世间」喻福德如山环护世间。
〔83〕 无胜幢解脱　毗目瞿沙所得解脱门之名，「无胜幢」即无能胜之幢，喻此法门殊胜、一切魔外不能胜。
〔84〕 摩善财顶　以手抚顶，为佛菩萨加持、授记、安慰之相；毗目瞿沙摩善财顶并执其手，随即以神力携其遍游十方佛土。
〔85〕 相好　佛身的「相」与「好」——大相三十二种、随形好八十种，指佛的殊胜庄严身相。
〔86〕 阿庾多　印度大数名（梵语 ayuta）；「阿庾多亿年」极言经历时间之久远。
〔87〕 陀罗尼　梵语 dhāraṇī 音译，意为总持，能总摄忆持无量佛法而不忘失的智慧力（后亦指真言咒语）。
〔88〕 般若波罗蜜　梵语 prajñā-pāramitā 音译，意译「智慧到彼岸」，六度之一，指证悟实相的究竟智慧。
〔89〕 虚空藏　藏（zàng），库藏；虚空藏喻功德广大如虚空、含藏无量法门，此处为三昧名「佛虚空藏轮三昧」。
〔90〕 分形　分身、分化色身；「分形遍往十方国土」即一身分化多身，同时遍至十方世界。
〔91〕 伊沙那　聚落（村庄）名，胜热婆罗门所居之处。
〔92〕 婆罗门　古印度四姓中最高的祭司种姓，常修苦行、专司祭祀诵经。
〔93〕 胜热　婆罗门的名字；外现邪见苦行之相（刀山火聚）、内实大菩萨之行，是善财参访中的逆行善知识。
〔94〕 皆依想所住　一切境界都依「想」（认知构想）而安住成立，说明万境由心所现；这是善财此段所得三昧的观法之一。
〔95〕 正命　八正道之一，以正当的方式谋生；善财所叹「难得」诸事之一。
〔96〕 十千　十个一千，即一万；佛经常用「十千」表万数，如「十千梵天」即一万位梵天。
〔97〕 五热炙身　胜热婆罗门的苦行法——于东西南北中五方烈日下炙烤其身（本卷示现为四面火聚、刀山投火）；外现极苦之行，实则借火光利益诸天、龙、鬼等众生，为其说法消苦。
〔98〕 映夺　光亮强过并遮盖他物，使其黯然失色；诸天宫殿在天火光明下皆相形失色。
〔99〕 聚墨　聚拢的一团墨；「皆如聚墨」言诸天庄严宫殿在火光映照下都黯淡如墨团。
〔100〕 化乐天　欲界六天之一，此天众生能自己变化五欲享乐之具，故名化乐。
〔101〕 一切智智　以一切智为智、智中之智，即佛智——于一切智中更为殊胜，故重言「智智」。
〔102〕 兜率天　欲界六天之一，分内院（弥勒菩萨所居净土）与外院；此处兜率天王率眷属来供养闻法。
〔103〕 三十三天　即忉利天，帝释天所居；须弥山顶中央一天、四方各八天，合为三十三。
〔104〕 六种震动　佛出现、说法等时的瑞相，大地有动、起、涌、震、吼、觉六种摇动之相；诸天见婆罗门时须弥山震动而发菩提心。
〔105〕 金翅鸟　梵语 garuḍa（迦楼罗），以龙为食的大鸟，龙的天敌；故诸龙闻法能「离热沙怖、金翅鸟怖」。
〔106〕 鸠槃荼　（jiū pán tú）梵语音译的鬼类名，腹大如瓮、厌魅于人，属夜叉类；闻婆罗门说法亦生慈心发菩提。
〔107〕 如应说法　如，随顺；随应众生根机而说相应的法，即「应机说法」。
〔108〕 乾闼婆　（qián tà pó）梵语音译，帝释天的司乐之神，不食酒肉、唯以香气为滋养，即飞天乐神。
〔109〕 舒右膝轮　舒，伸展；膝轮，膝盖（喻其圆如轮）。即舒展右膝、右膝着地的致敬之相（胡跪）。
〔110〕 忍地　安住忍辱之位，指修行中安忍不动的心地阶位；阿修罗闻法后「安住忍地，坚固不动」。
〔111〕 迦楼罗王　即金翅鸟王，天龙八部之一；此处「勇力持王」为其上首，化作外道童子之形来听法。
〔112〕 紧那罗王　（jǐn nà luó）梵语音译，歌神，形似人而头有角，天宫中的音乐之神。
〔113〕 缯带　缯（zēng），丝织品的总称；缯带即丝帛制的飘带、绶带。
〔114〕 佛事　佛的教化事业（说法、度生、示现等）；「作佛事已，而般涅槃」即度生因缘完毕而入灭。
〔115〕 般涅槃　般（bō），梵语 parinirvāṇa 音译的一部分，意为「圆满、入」；般涅槃即圆寂、佛灭度。
〔116〕 阿鼻　阿鼻地狱（梵语 Avīci），意译「无间地狱」，受苦无有间断，是地狱中最苦处；婆罗门火光照之，令狱苦暂息。
〔117〕 无尽轮解脱　胜热婆罗门所得解脱门之名；轮喻法轮辗转摧破一切而无有穷尽。
〔118〕 见惑　由错误见解所起的迷惑（身见、边见、邪见等），与修惑（思惑）相对；婆罗门的火能「烧一切众生见惑」。
〔119〕 那罗延　梵语 nārāyaṇa，力士天之名，其力无穷无尽；「金刚藏那罗延心」喻其心坚固如金刚、勇健如那罗延力士。
〔120〕 风轮　世界最底层承托大地的巨大风轮；喻菩萨愿力如风轮一样普载一切精进大誓而不退。
〔121〕 师子奋迅　善财下一参的城名；师子奋迅本指狮子抖擞毛发、奋迅威势之相，喻佛菩萨威德勇猛。
〔122〕 慈行　师子奋迅城中童女之名，善财将参访的下一位善知识；本卷至其辞退为止，未入城。
