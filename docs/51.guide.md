# 大方广佛华严经卷第五十一 导读

## 一、内容总览
本卷为《如来出现品》第三十七之二，紧承上卷「如来身相」，专讲如来「音声」与「心」两种境界，仍由普贤菩萨演说。全卷以「音声十相 → 音声十无量 → 重颂 → 心十相 → 重颂」为序，借十种世间譬喻（呼响、天鼓、善口天女、大梵音、众水一味、诸龙王降雨、微尘经卷等），开显如来音声无生灭、无方所、普入法界，及如来心意识俱不可得、唯智无量之义，归结「无一众生而不具有如来智慧」之圆教极唱。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全卷以「十相 × 二」对称展开：先音声十相，后心十相，各配重颂收束。每相皆「世间譬喻 → 如来音声（心）亦复如是 → 是为第N相」三段式。

- **总起：音声问题（P3）**　普贤问「菩萨应云何知如来音声」→ 立「十相」框架。
- **音声十相（P4-P13）**，递进如下：
  - 一相（世界将坏四音）→ 如来出四种音，度人、天、二乘、大乘四机；
  - 二相（呼响）→ 音无形无方所，随欲解缘出；
  - 三相（天鼓「觉悟」）→ 无主无作遍告放逸天子，喻无功用智音；
  - 四相（善口天女一口出百千声）→ 一音出无量声，随心乐遍至；
  - 五相（大梵王音不出众外）→ 音遍会众而根未熟者不闻，各谓「独为我说」；
  - 六相（众水一味随器异）→ 唯解脱味，随心器差别；
  - 七相（阿那婆达多兴云雨）→ 不从内外出而饶益；
  - 八相（摩那斯七日凝云）→ 先兴法云成熟众生，待熟乃降，免惊怖；
  - 九相（大庄严龙王降百千庄严雨）→ 一音无量差别，随根所宜；
  - 十相（娑竭罗龙王兴云网）→ 最广最长，以「身云 → 光明电光 → 三昧雷声 → 法雨」四重庄严遍覆法界，为十种根机各雨不同法雨，收摄前九相。
- **音声十无量（P14）**　以「如虚空、如法界、如众生界、如诸业、如烦恼、如言音、如欲解、如三世、如智慧、如佛境界」推向极致。
- **重颂一（P15-P55）**　普贤以偈重明音声十相。
- **总起：心问题（P56）**　转问「应云何知如来心」→ 立「心意识俱不可得，但以智无量故知如来心」之宗纲。
- **心十相（P57-P69）**：
  - 一相（虚空无所依）→ 如来智为世出世间智所依而无所依；
  - 二相（法界无增减）→ 如来智出一切智而无增减；
  - 三相（大海水潜流四天下）→ 佛智潜入一切众生心，随心行异所得不同；
  - 四相（大海四宝珠：积集、无尽藏、远离炽然、具足庄严）→ 四智宝出生三乘一切智慧，薄福者不见；
  - 五相（大海底四炽然大宝：日藏、离润、火焰光、尽无余）→ 四智宝光触菩萨，令舍散善波浪→舍三昧味着→舍神通→舍功用，渐至如来平等地；
  - 六相（三界依虚空而住）→ 声闻、独觉、菩萨一切智皆依如来智起、住；
  - 七相（雪山药王树「无尽根」）→ 以大悲愿为根、善巧方便为茎、波罗蜜为枝、三昧为叶、总持辩才为华、诸佛解脱为果，唯于二乘深坑及坏善根非器处不能生长，然亦不厌舍；
  - 八相（劫火中干草必烧）→ 反显如来智慧分别三世一切众生国土劫数诸法无不知，若言不知无有是处；
  - 九相（风灾中「散坏」与「能障」二风）→ 「能灭」智风灭菩萨习气，「巧持」智风护根未熟菩萨不断烦恼，令超二乘地；
  - 十相（大经卷在一微尘内）→ 圆教极唱：如来智慧本具众生身中，但以妄想执着不证，如来破妄想令自见佛智。
- **重颂二（P71-P116）**　末以「诸佛大慈悲，令其除妄想，如是乃出现，饶益诸菩萨」收束全卷。

## 三、关键结论
1. 如来音声不从身出、不从心出、不从外来，无主无作、无生灭、无方所，而能随众生根欲乐解普现差别——其体是法界，其用是悲愿。
2. 如来心意意识俱不可得，不可作「有心说法」解；但以智无量故知如来心，智为所依而智无所依，犹如虚空。
3. 佛智本具于一切众生身中，众生以妄想颠倒执着而不证得；若离妄想，一切智、自然智、无碍智则得现前——此即华严「一切众生本有佛智」之根本立场。
4. 如来教化有渐次：先兴法云成熟众生（免惊怖），次降法雨演甚深法；先以「巧持」智风护根未熟菩萨不断烦恼，后以「能灭」智风灭其习气，令超二乘、住如来地。
5. 如来音声与心皆「平等无分别」而「随众生根欲不同」示现差别——差别在机不在佛，是本卷反复申明的根本原则。

## 四、易混辨析
- **如来音声十相 vs 如来心十相**：前者讲「佛以何等言音度生」，重在外现教化之用；后者讲「佛心体性为何」，重在内证智体。二者旨归都是「差别在机、平等在佛」。
- **「能灭」智风 vs 「巧持」智风**：能灭者，灭已根熟菩萨烦恼习气，令证究竟；巧持者，护根未熟菩萨不断烦恼，免堕二乘地。前者主动断惑，后者遮止过早断惑，二风相须而用。
- **大海四宝珠（第四相） vs 大海底四炽然光明大宝（第五相）**：四宝珠出生一切智慧之宝，重在「生」；四炽然大宝饮缩海水、转乳为酪为酥为醍醐，重在「炼」——令菩萨层层升进。一生一炼，对举分明。
- **四龙王降雨喻（七→八→九→十相）**：阿那婆达多示「不从内外出而饶益」；摩那斯示「先兴云七日成熟众生，待作务竟乃降」之渐次；大庄严示「一水降百千庄严雨」之差别相；娑竭罗集前三者之大成，以四重庄严遍覆法界，为十相之极唱。

## 五、阅读提示
读本卷可紧扣两条线：一是每相「譬喻 → 亦复如是 → 是为第N相」的三段结构，二是「差别在机、平等在佛」这一反复出现的收束语。第十音声相（娑竭罗）与第十心相（微尘经卷）为全卷两大高峰，前者广说法门差别，后者直指众生本具佛智，宜细读。
