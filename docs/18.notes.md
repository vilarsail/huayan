# 大方广佛华严经卷第十八 词语注释

〔1〕 实叉难陀　唐代于阗（今新疆和田）高僧，八十卷本《华严经》的译者；「三藏」指精通经、律、论的法师。
〔2〕 明法品　本品品名，「明法」谓阐明法义；内容为法慧菩萨答精进慧菩萨所问，讲初发心菩萨应如何修习、令诸佛欢喜并成就大法师之德。
〔3〕 尔时　那时。佛经常用的时间连接词，承上启下。
〔4〕 精进慧菩萨　本品的提问者，代表新发意菩萨向法慧菩萨请问菩萨修行之法。
〔5〕 白法　白净的善法；与「黑法」（恶法）相对。
〔6〕 一切智心　求一切智（佛智）之心，即初发菩提心。
〔7〕 一切智乘　通向佛果一切智的教法车乘；「乘」（shèng）喻运载众生达于彼岸之法。
〔8〕 摄受　佛以慈悲摄取护念众生而不舍弃。
〔9〕 云何　如何、怎样。疑问代词。
〔10〕 悉　全、都。经中列举时常用的总括虚词。
〔11〕 波罗蜜行　修六度等到彼岸之行。波罗蜜（pāramitā），意译「到彼岸」，谓由此岸生死度至涅槃彼岸。
〔12〕 咸　皆、都。
〔13〕 靡不乐闻　靡（mǐ）＝无、没有；即没有不乐于听闻的。
〔14〕 复次　再者、其次。经中承接列举时常用的发端语。
〔15〕 魔怨　魔是与佛道为敌者，怨指烦恼怨敌；泛指障碍修行的一切恶魔。
〔16〕 恶趣诸难　恶趣指地狱、饿鬼、畜生等恶道；诸难（nàn）谓生于恶道、难闻佛法之苦难。
〔17〕 总持三昧　总持即陀罗尼，忆持善法不失；总持三昧谓于定中能总持一切法门。三昧（samādhi），意译「正定」，心专注一境之禅定。
〔18〕 六通　六种神通：天眼、天耳、他心、宿命、神足（如意）、漏尽通。
〔19〕 三明　三种圆满通明之智：宿命明、天眼明、漏尽明，即六通中前三通的极致。
〔20〕 四无所畏　佛说法时四种无所畏惧：正等觉、漏尽、说障法、说出道无所畏。
〔21〕 相好　佛身的三十二相、八十种好，佛庄严色身之特征。
〔22〕 不共佛法　唯佛独有、不与二乘菩萨共的功德法，通常指十八不共法。
〔23〕 一切智智　智中之智，指佛最极圆满的智慧；区别于声闻缘觉偏于空性的一切智。
〔24〕 佛事　泛指佛菩萨教化、利益众生的一切事业，非后世「做佛事」法事之义。
〔25〕 阿僧祇　asaṃkhya，华严常用的极大数名，意为「无央数」；阿僧祇劫即不可计数的漫长时间。
〔26〕 沮坏　沮（jǔ）坏，毁败、破坏。
〔27〕 乾闼婆王　乾闼婆（gandharva），帝释的奏乐之神，唯以香气为滋养，天龙八部之一；此处与其余诸王同列护法闻法。
〔28〕 摩睺罗伽王　摩睺罗伽（mahoraga），大蟒神（腹行神），天龙八部之一，亦来听法护持。
〔29〕 同灌其顶　诸王与如来同以手灌菩萨之顶，即「灌顶」之礼，喻授职、受记，许其绍继佛位。
〔30〕 护念　佛以智慧慈悲护忆惦念行者，令其道业不退。
〔31〕 无师智　不待师授、自然开悟之智，指佛无师自悟的智慧。
〔32〕 离生位　离烦恼受生之位，指证无漏智、脱离恶趣受生之阶位（相当于见道或初地）。
〔33〕 唐捐　虚弃、白费；「不唐捐」谓功不虚弃。
〔34〕 邻上尊　邻＝接近；谓所获妙道力接近佛（上尊），仅次于佛。
〔35〕 犹如莲华不着水　偈颂喻语：谓菩萨处世度生如莲花出水而不染着，承长行「于诸世间心无所依、无有执著」之义。
〔36〕 法慧菩萨　本品的说法者，此前曾在《十住品》宣说十住法门，此处应问详说菩萨修行次第。
〔37〕 谛听　谛（dì）＝仔细；留心谛听，佛说法时叮嘱听众认真听闻的套语。
〔38〕 少分　一小部分；说法者自谦所言仅是佛法的少分。
〔39〕 不放逸　防护身心、勤修善法而不放纵懈怠；本品以此为首纲，先列住不放逸之十法。
〔40〕 质直　朴实正直，无谄曲之心。
〔41〕 谄诳　谄（chǎn）＝曲意逢迎；诳（kuáng）＝欺骗；谓心不正直而虚伪矫饰。
〔42〕 二乘　声闻乘与缘觉乘，只求自了生死、不发广度众生之心，故菩萨须永离而独行菩萨道。
〔43〕 自相续力　相续指身心念念连续不断之体；谓恒常善自观察自身修行相续之力。
〔44〕 不沈不举　沈＝昏沉（昏昧困倦），举＝掉举（心散浮动）；谓住于深定时既不昏沉也不散乱。
〔45〕 和尚　upādhyāya 音译，即亲教师，教导自己学法之师；此谓见众生一发菩提心即如见己师般尊重承事。
〔46〕 阿阇梨　ācārya 音译，意译「轨范师」，教授威仪规矩、可为示范之师，与和尚同为受戒之师。
〔47〕 无诤门　无诤（zhēng），不与物竞、止息诤论之行（如无诤三昧）；入无诤门谓由此安稳之道深入佛法。
〔48〕 法印　印证佛法真伪的标准，如三法印（诸行无常、诸法无我、涅槃寂静）；「不违法印」谓说法不违佛理。
〔49〕 无作门　无作即无为、不假造作；依无作门谓任运自然地修净行，不取相而为。
〔50〕 所谓　即是、就是。引出具体列举内容之词。
〔51〕 无生忍　深信忍可诸法本不生灭之理而不动摇的智慧；安住无生忍即于无生之理心得决定。
〔52〕 速入诸地　「地」指菩萨十地（欢喜地至法云地）；此下列举十种法为并列枚举，读法可抓每条首句。
〔53〕 地地法门　地地＝每一地；谓于十地中每一地的法门都心无所住、不生执著。
〔54〕 何以故　为什么呢。经中自设问答时常用的发问语。
〔55〕 山王　万山之王，即须弥山；喻菩萨其心坚固、一切世界风所不能动。
〔56〕 依怙　怙（hù）＝依靠；「为所依怙」谓常得善人可依止庇护。
〔57〕 尽未来劫　未来之劫无穷无尽；谓直到永远、永劫如是。
〔58〕 一切种智　佛智，能遍知一切法的总相与别相，唯佛具足。
〔59〕 无尽藏　藏（zàng）＝蕴积；功德蕴积、用之不竭。本卷列十无尽藏：普见诸佛、总持不忘、决了诸法等。
〔60〕 随其所应　应（yìng），随众生根机所相应；谓针对各人根器恰如其分地施教。
〔61〕 三毒　贪、瞋、痴三种根本烦恼，毒害众生善根，故称三毒。
〔62〕 三苦　苦苦、坏苦、行苦；对乐着生死者说三苦，令知生死之中无有真实之乐。
〔63〕 舛谬　舛（chuǎn）谬（miù），错乱错误；谓说法文句相属、义理不乱。
〔64〕 真实际　真如实际之理，即诸法真实的究竟边际。
〔65〕 譬谕　谕同「喻」，譬喻；谓说法时巧设比喻，令众生易于开悟。
〔66〕 檀波罗蜜　檀（dāna）即布施；檀波罗蜜＝布施度。自此处起逐条说六度清净之相。
〔67〕 尸波罗蜜　尸（śīla）即戒；尸波罗蜜＝持戒度。
〔68〕 五欲境　五欲指色、声、香、味、触五种感官欲乐；谓于五欲之境无所贪着。
〔69〕 三摩钵底　saṃpatti 音译，意译「等至」，谓达于身心平等安和之定；与三昧同为禅定之名。
〔70〕 实相印　一实相印，大乘以诸法真实之相为唯一法印，印证所说是否究竟了义。
〔71〕 无功用道　无功用＝不加刻意作意；谓佛道任运自然起用、不待勉强的修行境地。
〔72〕 普门慧　普遍通达一切法门的智慧；乘此慧入于一切智智之门。
〔73〕 诸趣　五趣六道，众生随业受生之处。
〔74〕 流转还灭　流转指顺烦恼造业而在生死中轮回；还灭指逆生死之流、还归涅槃寂灭。
〔75〕 等分行者　贪、瞋、痴三毒平均、不偏重一端的修行人。
〔76〕 欲恚恶不善法　欲＝贪欲，恚（huì）＝瞋恚；离欲恚等恶不善法是初禅所离之盖障，为对欲界众生所说之法。
〔77〕 毗钵舍那　vipaśyanā 音译，意译「观」，即以智慧观察诸法的观修法门；对色界众生说此观慧。
〔78〕 十力　如来十种智力（知处非处、知业、知根、知界、知至处、知宿命、知天眼、知漏尽等），唯佛具足。
〔79〕 大师子吼　师子＝狮子；师子吼喻说法无畏、能慑伏一切，大菩萨发此誓言度脱恶道众生。
〔80〕 六和敬法　僧团和合共住之法：身、口、意、戒、见、利六项互敬同修；常修之则僧种不断。
〔81〕 绍隆三宝　绍＝继承，隆＝兴隆；谓继承兴隆佛法僧三宝，令种性永不断绝。
〔82〕 回向　将所修一切功德转趣于一切智（佛果）与众生，不令封着自己的果报。
〔83〕 瑕玷　瑕（xiá）玷（diàn），玉上的斑点；喻身口意三业的过失。
〔84〕 佛刹　刹（chà）＝国土；佛刹即佛所教化、庄严清净的国土。
〔85〕 阿耨多罗三藐三菩提　anuttara-samyak-saṃbodhi 音译，意译「无上正等正觉」，即佛果。
〔86〕 善见　传说中的一种药名，众生一见此药众毒即除；此喻菩萨成就功德，众生一见即灭诸烦恼毒。
〔87〕 金刚定　金刚三昧，定体坚固如金刚，能灭一切心垢烦恼而不为所坏。
〔88〕 大法师　代佛宣扬正法、受持广大法藏之师；此谓菩萨行满，堪于无边世界中为大法师。
〔89〕 无碍辩　四无碍辩：法无碍、义无碍、辞无碍、乐说无碍；谓说法自在、毫无滞碍。
〔90〕 一音演畅　以一种音声演说妙法而遍畅众会，令各类众生随类得解、皆生欢喜。
〔91〕 陀罗尼　dhāraṇī 音译，意译「总持」，能持善法不失、遮恶法不起的法门力与念慧力。
〔92〕 无见顶者　佛顶微妙无人能见（无见顶相）；与「无映夺者」连读，谓菩萨威德唯除诸佛及大菩萨外无人能胜、无人能掩。
〔93〕 三千大千世界主　即大梵天王，为一三千大千世界之主；此设喻谓道场众生威德色相皆如大梵天，而菩萨一现身犹能映蔽之。
〔94〕 映蔽　映＝遮，蔽＝盖；谓菩萨才一现身，即以威光笼罩压倒大众。
〔95〕 助道法　助成佛道之法，通常指三十七助道品（四念处、四正勤、四如意足、五根、五力、七觉支、八正道）。
〔96〕 有海　三有（欲有、色有、无色有）生死之海；喻众生沉溺的轮回苦海。
〔97〕 甘露　天上不死之药，味甘如蜜；喻所演妙法能除众生热恼、滋养法身慧命。
〔98〕 象王　象中之王，行步安详徐缓；喻菩萨进止威仪安重（如象王）而勇猛无畏（如师子）。
