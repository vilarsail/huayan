# 大方广佛华严经卷第三十三 导读

## 一、内容总览
本卷为《大方广佛华严经·十回向品第二十五》的第十一会，即十回向位的最后一位——**第十住等法界无量回向**。由金刚幢菩萨承佛神力，于兜率陀天宫宣说。主旨是菩萨以法施等一切善根，回向愿令一切佛刹悉以无量妙宝庄严、一切众生皆得普贤行愿之果。全卷以「愿庄严佛刹 → 愿成就众生 → 安住法界无量平等 → 显普贤自在力」为一线贯穿，收束十回向位，归宗于普贤行愿。

## 二、结构层次（★重点）
全卷是「长行发愿 → 颂偈收束」的标准结构，以「为令…故回向」排比句层层铺展：

- **法施回向庄严佛刹（P3）**：菩萨以法施善根回向，愿一切佛刹皆悉清净 → 以「阿僧祇宝座、宝帐、宝盖…」长串枚举，分三组宝庄严具（器物庄严、宝河海树等自然庄严、宝身口意等法门庄严）层层铺陈 → 结归「如来善根所起」。→ 是器世间庄严。
- **一毛端量遍满法界（P4）**：一佛刹、一方、一处、一毛端量皆有无量菩萨充满 → 推广至尽虚空遍法界，一一刹悉如是 → 引出香华鬘衣盖等十种庄严，次第乃至过此百倍。→ 由一处显一切处。
- **为长养善根成就众生（P5-P6）**：以法施善根「为令一切众生…」二十余条排比回向 → 众生心净不动、入甚深佛法、得平等无碍眼、得同普贤行等 → 转入「欲成就清净行威力」诸法光明三昧辩才大悲等，由众生转向菩萨自行。→ 是众生世间庄严。
- **安住法界无量平等（P7-P8）**：「以住法界无量…回向」三十余条排比，从身语意业、蕴界处，到染净、众生、佛刹、法、法界无二 → 菩萨如是回向时，安住法界无量平等清净身语意、众会道场、一切法光明无畏 → 能以一音断众生疑。→ 是智正觉世间庄严，三轮收束。
- **第十回向名体与普贤自在（P9）**：点题「第十住等法界无量回向」 → 成满普贤无边行愿 → 列十四种自在力（广大自在力…以圆满智普入三世）与十种清净（众生清净…入无边世间令众生皆作所应作）→ 以「皆得平等、皆悉现前…到于彼岸」九重排比收束长行。
- **瑞相与十方同说（P10-P12）**：佛神力故六种震动、雨华天乐、十方各百万佛刹微尘数菩萨来集 → 同号金刚幢、从金刚光世界金刚幢佛所来，证「十方所说不增不减」 → 显示此法周遍法界、同体一味。
- **颂偈总结（P14-P107）**：金刚幢菩萨观察法界已说颂，分两大段：
  - 第一段（P14-P43）：赞菩萨「法」之德——成就法智慧、为法导师、饮法海、法日出现、受灌顶、成法身、作法灯 → 以法施回向众生愿如普贤。→ 呼应长行法施回向。
  - 第二段（P44-P107）：广说供养诸佛之回向——一念觐等众生数佛、一毛端摄诸法、以众生数等之华盖涂香末香供养、穷劫供养一无厌足 → 摄法界尽无余 → 结归「善住此回向，是诸佛子号普贤」，普贤行愿功德边际无能测。→ 由愿起行，行归普贤。

## 三、关键结论
1. 第十回向名为「等法界无量回向」，以法施为主、统摄一切善根，回向庄严佛刹、成就众生、安住法界平等，是十回向位的究竟收束。
2. 庄严佛刹的「阿僧祇宝」种种，本质是「如来善根所起」——器物庄严实为法门庄严、功德庄严，宝即法、法即宝。
3. 「住法界无量平等」是本卷的核心修法：身语意业、蕴界处、染净、众生、佛刹、法，一一安住法界无量平等，三轮清净。
4. 菩萨成满普贤无量行愿，得十四种自在力与十种清净，能一音断一切众生疑，念念中见一切佛出兴于世。
5. 十方金刚幢菩萨同说此法、不增不减，显示「一即一切、一切即一」的法界缘起同体义。

## 四、易混辨析
- **十回向 vs 十地**：十回向是十住、十行之后的位次，回向位重在「回自向他、回因向果、回事向理」，为入十地作准备；十地是证理之位。本卷「第十回向」属贤位之极，非圣位十地。
- **法施 vs 财施**：法施以说法、教化、回向善根为体，本卷以「法施所修善根」为主回向体；财施以身外财物为体。本卷所列「宝庄严」看似财物，实是法施善根所起的法门庄严。
- **等法界无量回向 vs 等随顺一切众生回向**：前者是第十回向之名（本卷），重在「住法界无量平等」；后者属前位回向，重随顺众生根欲。名相近而易混。
- **金刚幢菩萨 vs 金刚幢佛**：说法主是此界兜率天宫的金刚幢菩萨；来证的同号菩萨来自「金刚光世界金刚幢佛所」——菩萨与佛同名号，表因果同体。

## 五、阅读提示
读本卷可抓两个轴：一是「庄严三世间」——器世间（佛刹宝严）、众生世间（愿令众生得普贤行）、智正觉世间（安住法界平等身语意）；二是「法界无量平等」这一贯穿全卷的修法关键词，凡见「以住法界无量…平等回向」即为其展开。颂偈部分可对照长行的「法施回向」与「供养诸佛」两门读。
