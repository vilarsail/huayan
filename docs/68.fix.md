- **原译文**：*善财童子见到和听闻这些之后，内心非常欢喜，便五体投地，向那位夜神顶礼双足，绕了无数圈，然后在他面前合掌，这样说道：“圣者！我已经发了无上正等正觉的心，我心里希望能依靠善知识，获得各位如来的功德和法藏。惟愿您能为我指示通往一切智慧的道路，让我在其中修行，最终到达佛的十种力量的境地！”*

- **新译文**：*善财童子见到和听闻这些之后，内心非常欢喜，便五体投地，向那位夜神顶礼双足，绕了无数圈，然后在她面前合掌，这样说道：“圣者！我已经发了无上正等正觉的心，我心里希望能依靠善知识，获得各位如来的功德和法藏。惟愿您能为我指示通往一切智慧的道路，让我在其中修行，最终到达佛的十种力量的境地！”*

### 段落 93 【翻译错误】 ✅ 已修复

- **原文**：　　“为在陆地一切众生于夜暗中遭恐怖者，现作日月及诸星宿、晨霞、夕电种种光明，或作屋宅，或为人众，令其得免恐怖之厄。复作是念：‘以此善根，回施众生，悉令除灭诸烦恼暗。’一切众生，有惜寿命，有爱名闻，有贪财宝，有重官位，有着男女，有恋妻妾，未称所求，多生忧怖；我皆救济，令其离苦。
- **原译文**：*“对于在陆地上的一切众生，在黑夜中遭遇恐惧的人，我显现为日月、星辰、朝霞、晚霞等各种光明，或者化作房屋，或者化作人群，让他们得以免除恐惧的灾厄。我又这样想道：‘我将这份善根，回向布施给众生，让他们都能除灭各种烦恼的黑暗。’一切的众生，有的珍惜寿命，有的喜爱名声，有的贪恋财宝，有的看重官位，有的执着于男女，有的贪恋妻子和侍妾，因为没有满足自己的追求，大多生起忧愁和恐惧。我都去救济他们，让他们脱离痛苦。”*
- **校对问题**：「晨霞、夕电」译为「朝霞、晚霞」，「电」（闪电）被漏译，且「夕电」误作「晚霞」，与「晨霞」语义重复，原义中傍晚闪电之光明的意象丢失。
- **修改建议**：改为「我显现为太阳、月亮、各种星宿、清晨的朝霞、傍晚的闪电等各种光明」。
- **判断依据**：原文「晨霞、夕电」中的「电」是闪电，译作「朝霞、晚霞」既漏掉闪电意象又与「晨霞」语义重复，确属误译。改为「清晨的朝霞、傍晚的闪电」忠实原义。
- **新译文**：*“对于在陆地上的一切众生，在黑夜中遭遇恐惧的人，我显现为太阳、月亮、各种星宿、清晨的朝霞、傍晚的闪电等各种光明，或者化作房屋，或者化作人群，让他们得以免除恐惧的灾厄。我又这样想道：‘我将这份善根，回向布施给众生，让他们都能除灭各种烦恼的黑暗。’一切的众生，有的珍惜寿命，有的喜爱名声，有的贪恋财宝，有的看重官位，有的执着于男女，有的贪恋妻子和侍妾，因为没有满足自己的追求，大多生起忧愁和恐惧。我都去救济他们，让他们脱离痛苦。”*

### 段落 96 【翻译错误】 ✅ 已修复

- **原文**：　　“善男子！若有众生，乐着国土而忧苦者；我以方便，令生厌离。作是念言：‘愿一切众生不着诸蕴，住一切佛萨婆若㉟境。’
- **原译文**：*“善男子！如果有众生，因为贪恋执着于自己的国家而感到忧愁和痛苦，我就会用方便法门，让他们生起厌离之心。我这样想道：‘愿一切众生都不再执着于色、受、想、行、识这五蕴，而能安住于一切佛陀的般若境界。’”*
- **校对问题**：术语错误：「萨婆若」（sarvajñā，即「一切智」，指佛的一切智）被译为「般若境界」。般若（prajñā）是智慧/慧，与萨婆若（一切智）是不同概念，混淆了经中固定译名。
- **修改建议**：改为「而能安住于一切佛陀的萨婆若（一切智）境界」或「而能安住于佛的一切智境界」。
- **判断依据**：「萨婆若」（sarvajñā）即「一切智」，与般若（prajñā）是不同概念；原文「住一切佛萨婆若境」译作「般若境界」属术语错误。前后文亦作「一切智平坦正道」「一切智城」，改为「一切智境界」与经中译名一致。
- **新译文**：*“善男子！如果有众生，因为贪恋执着于自己的国家而感到忧愁和痛苦，我就会用方便法门，让他们生起厌离之心。我这样想道：‘愿一切众生都不再执着于色、受、想、行、识这五蕴，而能安住于一切佛陀的一切智境界。’”*
