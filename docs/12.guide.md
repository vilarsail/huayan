# 大方广佛华严经卷第十二 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第十二，含两品：**如来名号品第七**与**四圣谛品第八**，皆属「六品因果」中「差别因果」之首，由文殊师利菩萨主讲。承接前六品「平等因果」之后，本卷转入「佛名号与四圣谛」的差别现身教化：如来名号非一非多，随众生心而立百亿万种；四圣谛义本一味，于十方世界各立四百亿十千名。两品同显一理——佛法身平等无二，而应化身、言教方便则无量无边，皆随类调伏而说。

## 二、结构层次

全卷以「请法缘起 → 十方云集 → 名号差别 → 谛义差别」四段推进：

1. **序分·菩萨请法（P3-P6）**：世尊于普光明殿始成正觉 → 与十佛刹微尘数菩萨俱 → 诸菩萨思惟请佛演说十住、十行、十地乃至如来十力、十八不共等法 → 世尊知念现神通。
2. **十方菩萨云集（P5）**：十方各过十佛刹微尘数世界，各有世界、有佛、有菩萨，依次而来 → 东方文殊、南方觉首、西方财首、北方宝首、四维与上下诸首菩萨 → 各化莲华藏师子座结跏趺坐 → 表十信法门遍布十方。
3. **如来名号品第七（P7-P31）**：文殊承佛威力普观大众而说 → 总标「佛国土乃至佛菩提皆不可思议，由众生乐欲不同」 → 先述娑婆四天下如来十名（释迦、毗卢遮那等） → 次述此娑婆十方次第世界各十名 → 再扩至娑婆百亿四天下、娑婆外十方诸世界 → 层层放大：四天下 → 娑婆 → 十方尽法界虚空界 → 末以「世尊昔为菩萨时以种种方便成熟众生」收束。
4. **四圣谛品第八（P33-P45）**：文殊告诸菩萨 → 先说娑婆四谛各有十名（苦、集、灭、道四百亿十千名） → 次说密训、最胜、离垢、丰溢、摄取、饶益、鲜少、欢喜、关钥、振音等世界四谛各有十名 → 末以「十方尽法界虚空界一一世界各说四谛亦各有四百亿十千名，随众生心悉令调伏」收束。

两品结构平行：皆先举娑婆为本地样本，次列十方世界为同类广衍，末以尽法界虚空界为穷尽圆满，体例整饬。

## 三、关键结论

1. **名号即法身之用**：如来名号虽千差万别（释迦、毗卢遮那、瞿昙氏、大沙门等），皆是同一法身随类而现，非一非异；名号本无自性，为度众生假立。
2. **四谛义一味多名**：苦集灭道其义决定，然于不同世界、不同众生心中，各有百亿万种异名——如娑婆苦谛又名「罪、逼迫、变异」等，密训苦谛又名「营求根、不出离」等，皆「随众生心，悉令调伏」。
3. **教化随机而不离本**：佛说法随众生乐欲、根性、信解、地位而差别，然所趣归一——调伏烦恼、趣向涅槃。
4. **文殊为差别智之主**：两品皆由文殊师利宣说，表「差别即平等」之般若妙慧——能于一法中说无量名、于一谛中立无量义。

## 四、易混辨析

- **释迦牟尼 vs 毗卢遮那 vs 卢舍那**：释迦牟尼为此娑婆应化身的族称名号；毗卢遮那译「遍一切处」，为法身、报身圆融的总名，本卷列为娑婆如来名号之一，明示应化身即法身之示现。
- **四天下 vs 娑婆世界 vs 三千大千世界**：四天下为一日月所照的小世界单元；娑婆世界含百亿四天下，即释迦牟尼佛教化之一三千大千世界；本卷名号列举以四天下为基本单位层层扩展。
- **苦圣谛 vs 苦集圣谛**：苦谛指有漏果报的逼迫相（如「罪、逼迫、痈疮处」）；集谛指招苦之因，即烦恼业因（如「系缚、爱着义、戏论」），二者一果一因。
- **苦灭圣谛 vs 苦灭道圣谛**：灭谛指烦恼寂灭、生死已断的果（如「无诤、寂静、无相」）；道谛指趣灭之行、能证之因（如「一乘、导引、平等」），一果一因，与集、苦相对。

## 五、阅读提示

读此卷宜把握「一多相即」主线：名号与谛义皆是「一理多名、一名多义」。不必逐条记诵百亿名号，可选取娑婆十名与一两他方世界对照，体会如来如何「随众生心之所乐」而设教。
