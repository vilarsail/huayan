# 大方广佛华严经卷第四十九 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第四十九，品属「普贤行品第三十六」。前承诸品广陈菩萨行位与如来依正庄严，本卷由普贤菩萨摩诃萨重告大众，承上启下，直指菩萨行的根本心要与广大境界。全卷以「一瞋心成百万障门」为警策起点，次第展布「十法→十清净→十广大智→十普入→十胜妙心→十佛法善巧智」六重十法门，再以颂偈广演普贤行界、三世诸佛出现、世界成坏、法身周遍、妄想起灭等义，收束于「一切智方便边际不可得」之无碍观行。要旨：以息瞋、不舍众生为菩萨行之纲领，以十门次第为修入之阶，以法界缘起、念念互入为观行之极。

## 二、结构层次

全卷由「长行」与「颂偈」两大段组成，长行立纲、颂偈广演，二者前后呼应，层层推进：

- **警策发起（P3-P5）**：普贤承佛神力告大众 → 先明诸佛出世本意为度我执颠倒众生 → 特举「菩萨于他菩萨起一瞋心即成百万障门」为全卷警策 → 广列百万障相（不见菩提、不闻正法、生恶趣、根缺、恶知识、乐小乘、断智慧、坏善根等） → 反显欲疾满菩萨行须修十法。
- **六重十法门次第展开（P6-P11）**：以「住此十法已则具足…」为衔接句，环环相扣 →
  - 十清净（通达甚深法、护持佛法、深入法界等）
  - 十广大智（知众生心行、业报、陀罗尼、辩才、普现其身等）
  - 十普入（一切世界入一毛道、一念入不可说劫等——事事无碍之核心）
  - 十胜妙心（住虚空界、法界、三世诸佛平等心等）
  - 十佛法善巧智（了达甚深、出生广大、证入平等、差别无差别等）
  → 收束于「少作功力疾得阿耨多罗三藐三菩提」之劝持。
- **瑞相与十方菩萨作证（P12-P13）**：佛神力故十方世界六种震动、雨种种云 → 十方十佛刹微尘数同名普贤菩萨从普胜世界普幢自在如来所来诣作证 → 显此法平等无增减、三世诸佛同说。
- **颂偈广演（P14-P256）**：普贤以佛神力、自善根力观察法界，欲开示菩萨行而说颂 →
  - 追溯往昔诸佛发愿修行（贤劫千佛、无量劫诸佛次第兴世）
  - 普贤行广大境界：于一微尘中悉见诸世界、一切三世入一念（重申十普入）
  - 世界成坏、劫量修短、刹土染净皆由众生业与妄想所起
  - 法身周遍世间无所著，如净水影像无来去
  - 世间如幻如化如焰如影如响如梦，了达假名无实
  - 菩萨兴大悲普净世间，不住实际不入涅槃，念念成正觉而修菩萨行
  - 收束：三世诸佛一切悉知、名为住普贤行，一切智方便边际不可得。

## 三、关键结论

1. **瞋心为大过失**：菩萨于他菩萨起一瞋心即成就百万障门，障不见菩提、不闻正法、坏失善根智慧——此为本卷最重之戒，菩萨行人首须息瞋。
2. **十法为菩萨行根本**：心不舍众生、于菩萨生如来想、不谤佛法、知土无尽、深信菩萨行、不舍虚空法界菩提心等十法，是疾满足菩萨行的方便。
3. **事事无碍为普贤境界**：一切世界入一毛道、一念入不可说劫、一法入一切佛法——大小、久暂、一多相即相入，乃华严十玄门之精义。
4. **世界染净由业由想**：国土庄严或杂染、众生或生天或堕狱，皆由众生业行与妄想所现；菩萨了知唯想所起，故能入幻网而不著。
5. **法身周遍而不著**：如来法身普入世间，如净水影像无来去；菩萨如是离染、兴大悲、普净世间，不住实际不入涅槃。

## 四、易混辨析

- **菩萨 vs 菩萨摩诃萨**：菩萨通指发菩提心行者；摩诃萨意为「大」，指已入地上、行愿深广之大菩萨。本卷普贤对「菩萨摩诃萨」说十法，示其位次之深。
- **普贤行 vs 普贤愿 vs 普贤慧**：普贤行指菩萨所修之广大行法（不舍众生、净治三业等）；普贤愿指其所发大愿；普贤慧指依行愿所成之无碍智慧。三者递进，行满则愿满、慧成。
- **十清净 vs 十广大智 vs 十胜妙心**：清净约断障显理、约行无染；广大智约所知境界之周遍；胜妙心约能证心安住法界。三者由「行」到「智」到「心」，层层深入。
- **法身 vs 化身 vs 色身**：法身周遍法界、无生无灭、如虚空如水月；化身示现成佛度生、处处般涅槃；色身则有相好、有寿量。本卷明法身普入世间无所著，与化身示现不同。

## 五、阅读提示

读本卷可循「瞋心之害→十法之因→十门之果→法界无碍→如幻度生」一线而下：先警策，立行本；次第十门，示修入；颂偈广演，显境界。遇「一毛道入一切世界」「一念入不可说劫」等句，勿作玄谈，当作菩萨亲证之境界观之。遇「众生皆妄起，善恶诸趣想」等句，当知世间相皆唯想所现，菩萨度生而不著有、不离有，是为普贤行之极致。
