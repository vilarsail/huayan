# 大方广佛华严经卷第四十四 导读

## 一、内容总览
本卷位于《大方广佛华严经》第四十四卷，含两品：**十通品第二十八**与**十忍品第二十九**，皆由普贤菩萨为诸菩萨演说。前品明菩萨摩诃萨所成就的十种神通（他心智、天眼、宿住、尽未来际、天耳、无体性无作往一切佛刹、善分别言辞、出生无数色身、一切法智、一切法灭尽三昧），后品明菩萨所修的十种忍（音声、顺、无生法、如幻、如焰、如梦、如响、如影、如化、如空），并以长行后的颂偈重宣其义。两品合观，一明菩萨之**大用**（神通化他），一明菩萨之**深智**（忍可法性），用不离体，体起为用，是华严「因果同时、理智不二」的展开。

## 二、结构层次
全卷由普贤菩萨两次宣说串起，呈「通（用）→ 忍（体）→ 颂（收束）」的递进结构：

- **十通品：总起分十**　普贤先告众「菩萨有十种通」 → 逐一分述：从知众生心（他心智通，最切近的有情心行）→ 知众生死此生彼（天眼通，所见由近及远、由一界至不可说佛刹微尘数）→ 知过去宿住 → 知尽未来际 → 天耳闻法 → 无体性无作而遍往佛刹 → 善分别言辞 → 出生无数色身 → 一切法智 → 一切法灭尽三昧。十通按「所知境」由狭至广、由事至理展开，最后两通转入法性与三昧，已为下品十忍埋下伏笔。
- **十通品：小结叹德**　以「住此神通，悉得一切三世无碍智神通」收束 → 转入下品。
- **十忍品：总起列名**　普贤先举十忍之名 → 明「得此忍则到一切菩萨无碍忍地，一切佛法无碍无尽」。
- **十忍品：别解十忍**　先释前三种（音声、顺、无生法），是就闻思修次第入理；再释后七种，以「幻、焰、梦、响、影、化、空」七喻配「色心因果言音身行」诸法，每一忍皆以「非X非不X」的双非句显法性离相 → 又以「虽…而…」显菩萨不舍大悲、不舍度生。其中如幻、如化、如空三段最为详尽，是全卷重心。
- **十忍品：重颂收束**　「尔时，普贤菩萨欲重宣其义而说颂言」 → 以偈颂将十忍义理再演一遍，先明闻法堪忍，次第配释七喻，末以「如是十种忍…智慧及所行，众生莫能测」叹德结归。

## 三、关键结论
1. **十通的根本是「无碍」**：由知一界众生心到不可说佛刹微尘数世界众生心，由见现在死此生彼到尽未来际劫，菩萨所知境皆以「不可说不可说佛刹微尘数」为量，体现华严「一多相即、广狭无碍」的境界。
2. **十忍的根本是「无生」**：从音声忍（不惊不畏）顺入，到无生法忍（不见少法生灭）为枢纽，后七喻皆以「非此非彼」显法性本寂，菩萨于无生法中起大悲用。
3. **体用不二**：十通之「色身庄严」「一切法智」「灭尽三昧」已转入法性与三昧，十忍则直就法性立名；通与忍非二事，通是依忍所起之用，忍是通所依之体。
4. **不舍众生**：每讲一忍，必以「虽…而…不舍大悲」「为度一切转于法轮」收束，明菩萨虽证寂灭而不舍度生，是「悲智双流」的典范。
5. **授记成佛**：如影忍中明「菩萨从于如来种性而生」、颂中明「普见诸如来，同时与授记，斯名受佛职」，标示十忍位即菩萨受佛职位，阶位极高。

## 四、易混辨析
- **十通 vs 六通**：六通（天眼、天耳、他心、宿命、漏尽、神足）是声闻、缘觉与菩萨共通的；十通是华严菩萨摩诃萨所特有，境量达「不可说佛刹微尘数」，且后三通（一切法智、灭尽三昧、出生色身）已入法性，非二乘所及。
- **无生法忍 vs 灭尽三昧**：无生法忍是「慧」——于理上不见少法生灭；灭尽三昧（灭尽定）是「定」——于事上念念入灭尽而不退菩萨道。前者是忍，后者是通，相辅相成。
- **如幻忍 vs 如化忍**：幻多就「因缘所现、本无实法」而说，偏于色相喻；化多就「意业、愿力、大悲所起」而说，偏于身行喻。幻重在「解」，化重在「行」。
- **忍 vs 通**：忍是「忍可」于心、于理决定不疑；通是依此定慧所发之神用。本卷先通后忍，即先显用、次归体。

## 五、阅读提示
读本品可抓住一条主线：每一通/每一忍，皆先说「所缘境无量」（事），再说「菩萨悉知/悉见/悉能」（用），最后归到「知法无相、随俗方便、不舍度生」（体）。把握「事→用→体」三层，便不会迷失于繁复的列举与「非X非不X」的双非句中。颂偈部分可对照长行细读，许多深义在偈中更为凝练。
