# 大方广佛华严经卷第六十七 词语注释

① 法界　诸法所依之理、一切法的界域。本卷善财思惟善知识为「普入法界无障碍道因」，师子频申入「法界差别」「法界圆满」等般若波罗蜜门。
② 善财童子　《入法界品》中遍参五十三位善知识的求道者，本卷主角。因福城听文殊说法而发心，一路南行参学。
③ 遍行外道　都萨罗城善得山上的善知识，外示外道相而内修菩萨行，名「遍行」。已住「至一切处菩萨行」，普入天、龙、地狱等一切诸趣随机说法。
④ 善知识　能引导众生舍恶修善、趣向菩提的师长道友。本卷反复强调善知识是成就菩萨行、波罗蜜、普入法界等一切善法的根本因。
⑤ 阿耨多罗三藐三菩提　意译无上正等正觉，是佛所证的最高觉悟。善财每见一位善知识必先自陈「已发」此心，作为参学的根本前提。
⑥ 菩萨行　菩萨所修的自利利他之行，本卷五位善知识所住法门皆名为某「菩萨行」，示现菩萨行遍于一切身份行业。
⑦ 善男子　善知识对善财的称呼，亦泛指发心修菩萨行的在家、出家男女众。佛经中佛与善知识对请法者的通称。
⑧ 至一切处菩萨行　遍行外道所证法门，谓能普于世间种种方所、种种形貌、种种行解、种种没生一切诸趣中，以种种方便智门利益众生。
⑨ 普观世间三昧门　遍行外道所成就的三昧，于一切世间普能观察，为其随机说法之所依。
⑩ 普门般若波罗蜜　遍行所证的般若波罗蜜，「普门」谓遍入一切门类、一切诸趣，以般若智随机教化。
⑪ 乾闼婆　天乐神，东方持国天王的眷属，以香为食、奏乐供养。本卷屡列天龙八部之一。
⑫ 阿修罗　六道之一、八部之一，果报似天而非天，常与帝释争斗。本卷多处列为所化众生之一。
⑬ 迦楼罗　即金翅鸟，以龙为食，八部之一。本卷在诸趣列举与日光园众会中屡见。
⑭ 紧那罗　歌神，似人而头有一角，八部之一，与乾闼婆同司天乐。
⑮ 摩睺罗伽　大蟒神，八部之一，亦称地龙。本卷列于诸趣与众会之中。
⑯ 陀罗尼　意译总持、能持，即摄持善法不散、遮伏恶法不失之慧力。遍行为说世间技艺令得「巧术陀罗尼智」。
⑰ 波罗蜜　意译到彼岸，指菩萨所修度门（六度、十度等）。遍行说「普门般若波罗蜜」，无上胜说诸波罗蜜回向一切智位。
⑱ 阎浮提　即南赡部洲，人类所居之洲。经中以阎浮提为基准，递推四天下、三千大千世界乃至十方无量世界。
⑲ 菩萨摩诃萨　「摩诃萨」意为大，即大菩萨。各善知识谦退时多以「如诸菩萨摩诃萨」推赞上位大菩萨的广大功德，以显法门无尽。
⑳ 鬻香长者　「鬻」音育，卖也。广大国中卖香兼善调诸香的长者优钵罗华，以香法为菩萨行门。
㉑ 优钵罗华　音译「优钵罗」，意译青莲华。本卷既是鬻香长者之名，亦是日光园中所覆池面的青莲华之一。
㉒ 三昧　意译正定、等持。本卷所说法门多名「三昧」「三昧王」，如师子频申得「出生一切法三昧王」，是出生一切法的胜定。
㉓ 栴檀香　即檀香，梵名旃檀那。本卷谓摩罗耶山出牛头栴檀，涂身入火不烧，为名贵香品。
㉔ 沉水香　即沉香，树脂沉水者。本卷谓阿那婆达多池边出「莲华藏」沉水香，一丸如麻子大即普熏阎浮提。
㉕ 先陀婆　梵音译词，兜率天所出之香名。于一生所系菩萨座前烧一丸，兴大香云遍覆法界，雨一切供养具供养诸佛菩萨。
㉖ 一生所系菩萨　即此生即成佛的补处菩萨，如弥勒等。兜率天「先陀婆」香即于补处菩萨座前焚烧。
㉗ 婆施罗　楼阁城船师之名，意为「自在」等。住「大悲幢行」，航海运商、济贫说法，以航海为菩萨行喻。
㉘ 大悲幢行　船师婆施罗所修法门。「幢」高出、胜义，谓以大悲为高胜之行，先以世物济贫、复施法财，引导众生入一切智海。
㉙ 漩澓　「澓」音复，回旋的水流。船师善知海中漩涡浅深、波涛远近，为航海利生的智慧之一。
㉚ 晷漏　古代测时之器，日影为晷、滴水为漏。船师善别知日月星宿运行度数、昼夜晨晡、晷漏延促，以定航行安危。
㉛ 无上胜　可乐城长者之名。住「至一切处菩萨行门无依无作神通之力」，于三千大千乃至十方不可说佛刹微尘数世界广说五乘因果。
㉜ 三十三天　即忉利天，欲界第二天，帝释所居。日光园中师子频申为三十三天众说「厌离门」法门。
㉝ 兜率陀天　即兜率天，欲界第四天，补处菩萨所居。经中多处举兜率天及一生所系菩萨。
㉞ 他化自在天　欲界最高第六天，魔王所居处，亦为菩萨所化众生之一。
㉟ 不可说　佛经中极大之数名，亦表其数超言绝虑。本卷与那由他、佛刹微尘数连用，形容世界与所化众生之广。
㊱ 那由他　梵语数名，意为亿、兆等极大之数。本卷谓「十不可说百千亿那由他佛刹微尘数世界」。
㊲ 师子频申　「频申」即「频申」舒展义，亦作「频申」。迦陵迦林比丘尼之名，住日光园，遍坐一切宝树下，对各趣众生各说不同法门，成就「成就一切智」解脱。
㊳ 毗卢遮那　意译遍一切处、光明遍照，即法身佛名。日光园中有摩尼宝树名「毗卢遮那藏」，座名「毗卢遮那摩尼王藏」，表法身遍照义。
㊴ 阿僧祇　梵语数名，意为无量数、不可数。本卷谓「阿僧祇色相摩尼宝周遍庄严」，形容数量极大。
㊵ 八功德水　具备八种功德的净水（甘、冷、软、轻、清净、不臭、饮不伤腹、饮不喉涩等异说）。日光园泉池皆具八功德水盈满。
㊶ 波头摩华　即红莲华。日光园池中与优钵罗、拘物头、芬陀利四色莲华遍覆水面。
㊷ 拘物头华　即黄莲华（一说赤白二色）。日光园四色莲华之一。
㊸ 芬陀利华　即白莲华。经中多以此喻佛、比丘尼等清净无染者。
㊹ 十地　菩萨修行的十个阶位（欢喜地乃至法云地）。师子频申对各阶地菩萨各说一法门，显示位位有其差别行相。
㊺ 般若波罗蜜　六度之一，到彼岸之智慧。师子频申入「普眼舍」等十般若波罗蜜门为首，入无数百万般若波罗蜜门。
㊻ 意生身　菩萨依意愿所变化之身，随念能往十方世界。师子频申入「成就一切智」门得意生身，于十方一切世界一生所系菩萨前现不可说佛刹微尘数身供养。
㊼ 婆须蜜多　险难国宝庄严城中的女人，下一位善知识，师子频申所指授。
