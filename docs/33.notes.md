# 大方广佛华严经卷第三十三 词语注释

① 十回向品　《华严经》第六会（他化自在天会/兜率天宫）所说，明十回向位菩萨行。本卷为十回向品之第十一会，即第十回向位。
② 菩萨摩诃萨　「摩诃萨」意为「大」，即大菩萨，指已发大心、行大行、证大理的菩萨。本卷说法主与回向行者均称此号。
③ 法施　法布施，以佛法教化众生、为说正法，为六度布施之一。本卷以「法施所修善根」为回向的根本所依。
④ 回向　将所修善根转向众生与佛果，不自私己有。回是回转、向是趣向，回自向他、回因向果、回事向理。
⑤ 佛刹　佛所教化的国土，即一佛之教化区。本卷愿令一切佛刹皆悉清净庄严。
⑥ 法界　一切法所依之理体，亦指一切法的总相。本卷核心概念，回向安住「法界无量平等」，显示法界缘起互摄义。
⑦ 阿僧祇　梵语 asaṃkhyeya，意为无数、不可计数，是佛教极大的数单位。本卷宝庄严具多以「阿僧祇」计其数。
⑧ 却敌　城墙上的防敌楼台，即城堞、女墙。此处「宝却敌，大宝所成」为佛刹庄严具。
⑨ 门闼　门与闼（小门、门屏），泛指门户。此处「宝门闼，妙宝璎珞周匝垂布」。
⑩ 璎珞　以玉、珠、宝串成的颈饰，戴于身者。此处「宝璎珞，一一璎珞百千菩萨上妙庄严」。
⑪ 窗牖　窗户。窗与牖皆指墙上通风透光的孔洞，此处以妙宝庄严。
⑫ 多罗　梵语 tāla，多罗树，形如扇如半月。此处「宝多罗，形如半月，众宝集成」，为庄严具之一。
⑬ 芬陀利华　梵语 puṇḍarīka 音译，即白莲花，亦作分陀利。佛教喻法之最胜者，此处「宝芬陀利华常出妙法芬陀利声」。
⑭ 须弥山　梵语 Sumeru，意译妙高山，一小世界的中心。此处「宝须弥山，智慧山王秀出清净」，以山喻智慧高出。
⑮ 幢　梵语 dhvaja，以宝丝系于竿上的圆筒形庄严具，表法之高显。此处「妙宝幢」「如来幢相迥然高出」。
⑯ 幡　梵语 patākā，长条形旗帜，多悬于佛前作为庄严。此处「宝幡，悉能普雨无量宝幡」。
⑰ 三昧　梵语 samādhi，意译定、正定，心一境性。此处「宝宫殿生诸菩萨三昧快乐」「宝衣服著者生诸菩萨无比三昧」。
⑱ 袈裟　梵语 kāṣāya，意为坏色、不正色，出家人所着法衣。此处「宝袈裟，著者才始发心则得善见陀罗尼门」。
⑲ 陀罗尼　梵语 dhāraṇī，意译总持，能摄持无量佛法令不散失。此处「善见陀罗尼门」为菩萨所得之法门。
⑳ 结跏趺坐　佛之坐法，两足交叉置于两股之上，表最安稳、易发定力。此处「一身结跏趺坐周遍十方法界」。
㉑ 那罗延　梵语 nārāyaṇa，天上力士名，表勇猛坚固之力。此处「具足菩萨那罗延身，勇猛坚固」。
㉒ 跋陀树　跋陀，梵语 bhadra，意为贤。宝跋陀树为佛刹庄严树之一，与因陀罗网庄严。
㉓ 因陀罗网　梵语 indra-jāla，帝释天宫所悬的宝网，网目皆悬宝珠，珠珠互映重重无尽，喻法界缘起互摄。
㉔ 十力　佛所独具的十种智力（处非处智力乃至漏尽智力）。此处「宝眼，鉴十力宝，无所障碍」。
㉕ 普贤行愿　普贤菩萨所修之行与所发之愿，总摄一切菩萨大愿大行，华严宗归宗于此。本卷屡称「皆令如普贤」「皆得同于普贤行」。
㉖ 摩尼宝　梵语 maṇi，如意宝珠，能出一切所须之物，为佛教极贵重之宝。经中常以喻自性清净心。
㉗ 微尘数　以微观尘粒计其数，喻极多、不可计。本卷「百万佛刹微尘数世界」「百万佛刹微尘数诸菩萨」即此用法。
㉘ 六种震动　佛说大法时大地震动的六相：动、起、涌、震、吼、击，各有「遍」「等遍」三阶，共十八相。
㉙ 沉水香　即沉香，树脂凝结于木中入水能沉，为佛教重要香料，供佛与庄严具用。
㉚ 栴檀香　栴檀即檀香（梵语 candana），牛头栴檀为最胜者，香气能治病辟恶，常供于佛。
㉛ 那由他　梵语 nayuta，极大数名，亦译那庾多，表百亿、千亿之类不可计之数。此处「百千那由他诸天」。
㉜ 兜率陀天宫　梵语 Tuṣita，意译知足天，欲界第四天，一生补处菩萨所居。本卷于此天宫宝庄严殿说。
㉝ 金刚幢菩萨　本卷说法主，承佛神力说十回向位。与十方来证之菩萨同号金刚幢，表因果同体、十方同说。
㉞ 调御师　佛十号之一「调御丈夫」之略，谓佛能善调伏众生使离烦恼。此处「为法光明调御师」「人中调御者」。
㉟ 灌顶　梵语 abhiṣeka，古印度王子继位时以四大海之水灌顶表受位，佛教喻菩萨入十地受佛智职。此处「诸佛法王所灌顶」。
㊱ 普贤地　普贤菩萨所证之果地，即圆满普贤行愿所成之地位。偈颂「速得安住普贤地」。
