# 大方广佛华严经卷第十一 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第十一，独占一品——**毗卢遮那品第六**。前四卷（世主妙严品、如来现相品、普贤三昧品、世界成就品）从「当下祇园法会」铺陈如来现相与法界庄严；本卷则由普贤菩萨承佛神力，**回溯往古**：过世界微尘数劫、复倍是数之前，有世界海名「普门净光明」，其中有世界名「胜音」，佛号「一切功德山须弥胜云」，由此展开对毗卢遮那佛本生因行的追述。主旨在于说明：**今之毗卢遮那如来，并非无因出世，而是历劫修因、承事多佛、严净刹海所得之果**；而大威光（太子、童子、菩萨、转轮王、天王的累世身份）正是其因地化身与法器，从一佛至下一佛辗转增上，于一一佛所得一一法门，构成「因圆果满」的范式。

## 二、结构层次（文章的骨架与逻辑推进）

全卷以普贤菩萨的叙述为框，采用「**往古远因 → 多佛相承 → 大威光累世增上**」的回溯式结构，其骨架如下：

- **境位铺陈（远劫依正庄严）** → 先立「胜音世界」的依报：摩尼华网海、华焰普庄严幢须弥、摩尼华枝轮大林、焰光明大城，及围绕其外的天、龙、夜叉、乾闼婆等八部王城，构成「一佛出世之舞台」。
- **第一佛出世 → 现相 → 调伏** → 一切功德山须弥胜云佛于大林莲华中出现，眉间放「发起一切善根音」光明，光照众生令其开悟、裂盖摧障；世间主并眷属悉诣佛所。
- **大威光初遇佛 → 得十法门 → 说颂** → 太子大威光以昔善根力，证十种法门（三昧、陀罗尼、般若、慈喜舍、神通、愿、辩才等）；承佛力说颂，赞佛光明神通、利乐众生。
- **王与眷属集众 → 闻法 → 大威光再得十智光明** → 喜见善慧王召集诸王大臣俱诣佛所，佛说「普集一切三世佛自在法修多罗」；大威光闻法获「法海光明」——十种智光明，复说颂自述往昔承事诸佛、舍身舍宫、修普贤行愿以严净刹海。
- **第一佛为授记说颂 → 第二佛继出 → 大威光（童子位）再得十千法门** → 佛为大威光说颂，记其当得深智海、当成无上道；第一佛灭后，波罗蜜善眼庄严王如来继出，大威光以童子身见佛，得念佛三昧、大智力法渊陀罗尼、四无量心、般若、神通、辩才、智光等十千法门，复说颂劝众发心趣菩提、住普贤愿。
- **第二佛为说颂 → 第三佛继出 → 大威光（转轮王位）得三昧** → 波罗蜜善眼佛灭、喜见善慧王去世后，大威光受转轮王位；第三佛最胜功德海出，王与四兵众持七宝奉佛，闻「菩萨普眼光明行修多罗」，得「大福德普光明」三昧，了知三世福非福海；佛为说颂，记其当入普贤愿行、当成一切智。
- **第四佛 → 大威光命终生天 → 闻法得三昧 → 收束** → 名称普闻莲华眼幢佛复出，大威光于此前命终、生须弥山上寂静宝宫为天王「离垢福德幢」，与天众俱诣佛所，闻「广大方便普门遍照修多罗」，得「普门欢喜藏」三昧，入一切法实相海，还归本处——全卷由「往古多佛相承」回到「当下法会」的圆收。

全文用「**尔时/诸佛子/时/复有**」层层衔接，每一佛出世即有大威光随位升进、得一法门、说一颂、佛记一颂，形成「**佛出→机感→得法→颂赞→授记→次佛继出**」的回环递进。

## 三、关键结论

1. 毗卢遮那如来的果德，溯源于往古胜音世界历劫修因；**因行圆满故果海无量**，此即「因该果海、果彻因源」的华严宗义之具体演示。
2. 大威光一身辗转于太子、童子、菩萨、转轮王、天王诸位，**于每一佛所皆得一一法门**，体现「初发心时即具足一切智」之理——位次虽殊，所证法门层层增上而互摄。
3. 多佛相承（胜云 → 波罗蜜善眼 → 最胜功德海 → 莲华眼幢），显示**佛佛道同、相承不断**，一佛灭度即有次佛继出，调伏未曾中断。
4. 普贤菩萨是此品叙述者与「往昔行愿」的载体——大威光所修即「普贤大愿」「普贤所有行」，本卷实为普贤行愿在因地的史证。
5. 闻法得益的层次分明：从「十种法门」→「十智光明」→「十千法门」→「三昧」，显示**法门无尽、智光渐广**，而终归于「普门欢喜藏、入一切法实相海」之一实相。

## 四、易混辨析

- **大威光太子 / 大威光童子 / 大威光菩萨 / 大威光转轮圣王 / 离垢福德幢天王**：同一补处菩萨的累世不同身份，非不同人。太子位属初遇第一佛时，童子位遇第二佛，菩萨位贯第三、四佛，转轮王位遇第三佛，天王位遇第四佛——位次升进即修行阶次之表征。
- **胜音世界 vs 普门净光明世界海**：前者是海中之一个世界，后者是包含胜音世界的世界海；本卷叙述聚焦于胜音世界，因其为诸佛出世之依报。
- **一切功德山须弥胜云佛 / 波罗蜜善眼庄严王佛 / 最胜功德海佛 / 名称普闻莲华眼幢佛**：胜音世界摩尼华枝轮大林中相承出世的四尊佛，须依出现顺序区分，不可混作一佛。
- **修多罗 vs 眷属修多罗**：每佛所说之根本经典（如「普集一切三世佛自在法修多罗」「法界体性清净庄严修多罗」）称修多罗；「世界微尘数修多罗而为眷属」则指围绕根本经的无数伴经，体现华严「主伴无尽」之结构。

## 五、阅读提示

读本卷可带着两个问题推进：其一，大威光每一次见佛所得法门与前次有何递进关系？其二，四佛出世与四度「说颂—授记」的回环结构，如何为后文「普贤行愿品」之愿王埋下伏笔？把握「累世增上」与「普贤愿行」两条线索，便能将本卷繁复的依正庄严与多佛相承读成一条清晰的因行果德脉络。
