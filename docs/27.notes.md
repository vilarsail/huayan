# 大方广佛华严经卷第二十七 词语注释

〔1〕 于阗国　古代西域王国（今新疆和田一带），八十卷《华严经》译主实叉难陀的故乡。
〔2〕 实叉难陀　唐代来华的于阗三藏法师（三藏：精通经、律、论），八十卷本《华严经》的译者；「奉　制译」指奉皇帝诏命翻译。
〔3〕 十回向品　《华严经》八十卷本第二十五品，本卷是其第五部分；「回向」指把修行功德转向既定目标（众生、菩提、真如），本品专讲菩萨以诸善根回向众生。
〔4〕 菩萨摩诃萨　梵语 bodhisattva-mahāsattva 音译，意为「大菩萨」，指发大心、位高的圣位菩萨。
〔5〕 连肤顶髻　连带头皮肤肉的头顶发髻；菩萨割取施人，是舍身布施中极难行的一种。
〔6〕 宝髻王菩萨　髻：束在头顶的发结；此类菩萨名是列举往昔曾行此施的榜样，本卷宝髻王、欢喜行、月光王等名号皆属此类，不必一一考实。
〔7〕 阎浮提　梵语 Jambudvīpa 音译，又译「赡部洲」，佛教所说人类所居的世界（南洲）。
〔8〕 一切智　通知诸法总相的智慧；经中常与「一切种智」（佛遍知总相别相的圆满智慧）对举。
〔9〕 善知识　教导正道、于己有益的良师益友；此处把乞者视同善知识，因其来而成就我的布施。
〔10〕 所谓　文言提示语，义为「即是、如下所列」，用于引出下文的列举内容。
〔11〕 无见顶　佛三十二相之一的「无见顶相」，佛顶高妙，无人能见其顶。
〔12〕 绀青　绀（音 gàn），红中带青的深蓝色；佛发为绀青色，故愿众生得绀青发。
〔13〕 卐字　卐音同「万」，古代吉祥符记，佛身多处现右旋卐字纹理，象征功德圆满。
〔14〕 结习　「结」即烦恼结使，「习」是久习成性的习气；指烦恼及其残余习气。
〔15〕 闇翳　闇（音 àn，同「暗」）昏暗，翳（音 yì）遮蔽眼膜的障物；喻烦恼尘垢遮蔽心眼。
〔16〕 陀罗尼　梵语 dhāraṇī 音译，意为「总持」，于一切善法能持而不忘的总持力。
〔17〕 一切种智　唯佛具足的、遍知一切法总相别相的圆满智慧。
〔18〕 十种力　即佛十力：知是处非处、知业报、知诸禅定、知众生根、知种种欲、知种种性、知一切至处道、知宿命、知天眼、知漏尽等十种无碍智力。
〔19〕 六根　眼、耳、鼻、舌、身、意六种感知机能；「制伏六根」即不令其放逸逐境。
〔20〕 无二舍行　无有能施之人、受施者、施物的分别执着的布施行；「无二」即离分别二边。
〔21〕 普眼　遍观一切法而无障碍的智慧眼，也是华严「普眼法门」之名；此处愿众生成就遍知一切的慧眼。
〔22〕 痴翳　翳（音 yì），眼中遮障的薄膜；「痴翳」喻愚痴如翳遮眼，令慧目不见实相。
〔23〕 生如来家　入佛种性，以佛所证之法为家业；谓真发菩提心、受持佛法，方算生在佛家。
〔24〕 三有　欲有、色有、无色有，即欲界、色界、无色界三界生死流转之处。
〔25〕 大施海　布施深广如海，喻施行无量无边。
〔26〕 不坚身　血肉之身危脆无常，故称不坚身；「以不坚身易坚固身」谓舍此无常之身，换取坚固不坏的佛法之身（法身、金刚身）。
〔27〕 壅滞　壅（音 yōng）堵塞；壅滞即阻塞不通，此处谓闻法解悟毫无滞碍。
〔28〕 聋聩　聩（音 kuì）天生耳聋；「无聋聩耳」即耳根完好聪彻。
〔29〕 华齿王菩萨　华通「花」；往昔舍牙齿的菩萨榜样之一，与下「六牙象王菩萨」同为举古证今。
〔30〕 六牙象王菩萨　用六牙白象王本生故事：象王自拔六牙施与猎人，是舍牙布施的经典榜样。
〔31〕 优昙华　梵语 udumbara 音译，灵瑞之花，三千年一现，喻希有难遇。
〔32〕 辍身要用　辍（音 chuò）停歇、割取；「辍身要用」指舍去身体最要紧受用的部分，且无所嫌恨。
〔33〕 尔时　文言时间词，「那时、正当其时」，叙述佛典中常用的连接语。
〔34〕 铦白　铦（音 xiān）锋利光洁；「铦白」形容牙齿洁白光锐。
〔35〕 文理　文通「纹」，纹理；「文理回旋」谓齿上纹理回旋成卐字之相。
〔36〕 记别　又作「记莂」，即授记：佛预言弟子将来成佛的名号、劫数、国土等。
〔37〕 那由他　梵语 nayuta，古大数目名，约当千亿，极言其多。
〔38〕 师子座　师子即「狮子」（古无狮字，经中习用师子）；佛菩萨所坐之座称狮子座，喻说法威严无畏。
〔39〕 覆面舌　佛三十二相之「广长舌相」，舌广长可以覆满面至发际，表语业清净、言必真实。
〔40〕 迦尸国王　迦尸（梵 Kāśī）古印度国名；往昔迦尸国王有以己头施人的本生故事，此处为舍头布施的榜样。
〔41〕 第一地　菩萨十地之第一地「欢喜地」；「证得第一地首」愿以证入初地之智为头首。
〔42〕 悦豫　豫即娱乐之「娱」；悦豫即喜悦欢愉。
〔43〕 道场　原指佛成道之处（菩提道场），泛指修行证道之处。
〔44〕 拟将广惠　拟：打算；将：拿、持；「常舒其手拟将广惠」谓常伸出手，准备广行布施。
〔45〕 智身　华严说佛有十身，智身为其一，谓以智慧为体之身；与法身并称。
〔46〕 施度　六度（六波罗蜜）之一，即布施波罗蜜；「度」谓渡生死海而到彼岸。
〔47〕 华鬘　华通「花」，鬘（音 mán）花环；花鬘是印度装饰供养之物，「华鬘手」谓愿得能散花鬘供养的手。
〔48〕 末香　研成粉末之香，撒散以供养佛塔，「末香手」即能散末香之手。
〔49〕 网缦　佛三十二相之「指网缦相」，指间有薄膜相连如鹅鸭之蹼，光丽如赤铜色爪甲。
〔50〕 变化身　佛随机应化、变现示现之身；「得如变化身」愿其身能自在显现世间而无穷尽。
〔51〕 不死界　即涅槃，无生无死之境；「于不死界而得自在」谓于涅槃得大自在。
〔52〕 髓肉　髓（音 suǐ），骨中之骨髓；「身髓肉」即骨中骨髓与肌肉，极言所施之难舍。
〔53〕 从缘无体　诸法依因缘而生起，没有独立自存的实体；「审观诸法从缘无体」即观察万法缘起性空，故不贪着施业与果报。
〔54〕 师子吼　师子即狮子；喻佛菩萨说法无所畏惧、能降伏一切外道邪见，如狮子吼声慑伏百兽。
〔55〕 沮坏　沮（音 jǔ）败坏；「不可沮坏」即不可毁坏。
〔56〕 意生身　梵语 manomayakāya，随意识而任意变化往生之身，圣者所成就之身。
〔57〕 百福相　谓每一妙相皆由百种福德成就；「百福相身」即以百福庄严其身。
〔58〕 三十二相　佛身三十二种显著福相，如足下千辐轮相、眉间白毫相、广长舌相等。
〔59〕 八十种好　三十二大相之外，佛身所有的八十种细微妙好之相。
〔60〕 檀波罗蜜　梵语 dāna-pāramitā 音译；「檀」即布施的略译，「檀波罗蜜」即布施度，六波罗蜜之首。
〔61〕 金刚围山　即金刚山、铁围山，环绕世界边缘、坚固不坏的大山；喻其心如金刚山，任何力量不能破坏。
〔62〕 那罗延　梵语 nārāyaṇa，天上大力士之名，其身坚牢具大神力；佛经常借喻坚固不坏之身力。
〔63〕 被金刚甲胄　被（音 pī，同「披」）穿戴；「被金刚甲胄心」谓心坚如披金刚铠甲，魔军不能伤。
〔64〕 中悔　中途反悔；「心不中悔」谓施与之后不生悔意。
〔65〕 会当　文言虚词，「终当、终归要」；「会当弃舍」谓此身终究要舍离。
〔66〕 身分　此处读 fèn，指身体的各个部分（非现代「身份」义）；「施其身分肢节骨」即施舍身体的骨节肢体。
〔67〕 贞实　贞：坚固；贞实即坚实不虚。
〔68〕 智熏身　熏：熏习浸润；「智熏身」谓以智慧不断熏修所成就之身。
〔69〕 贡高　傲慢自大；「离我慢贡高」即离自以为是、高人一等的慢心。
〔70〕 曲躬　躬（音 gōng）弯身；曲躬即弯腰行礼，表恭敬。
〔71〕 金胁鹿王菩萨　胁（音 xiè），体侧自腋至腰的部分；金胁鹿王用金色鹿王舍身之典，喻施皮布施的菩萨。
〔72〕 阎浮檀　梵语 jambūnada，阎浮河所产之金，称「阎浮金」，传说为世间最上等的金。
〔73〕 连肉爪甲　爪甲即指甲；「连肉」谓连皮带肉取下，喻难舍能舍，乃至以肉甲换法。
〔74〕 七仞火坑　仞（音 rèn），古长度单位，约七八尺；「投身七仞火坑」谓跳入七仞深的火坑以求闻法。
〔75〕 阿鼻狱　梵语 Avīci 音译，即「无间地狱」，受苦没有间断的最重地狱；谓求法者宁入阿鼻，何况人间火坑。
〔76〕 楚毒　楚：打人的荆条；楚毒即酷刑般的痛苦。
〔77〕 三毒　贪、恚（嗔）、痴三种根本烦恼，如火烧身，故名毒火。
〔78〕 三昧　梵语 samādhi 音译，意为「正定」，心专注一境而不散乱的定境。
〔79〕 摄取　此处义为「承揽、代受」：为求法故，连诽谤正法的极恶之人所应受的一切苦，菩萨都代为承受，是极难之句，勿误作「摄化引入」解。
〔80〕 苦蕴　蕴（音 yùn）积聚；「苦蕴」谓苦的积聚（五蕴炽盛之苦）。
〔81〕 安隐　同「安稳」，平顺无忧；「隐」为佛典习用字，非「隐藏」义。
〔82〕 罄舍　罄（音 qìng）尽、空；罄舍即全部舍尽。
〔83〕 妻子　此处「妻子」为并列词：妻与子女，非现代仅指配偶。
〔84〕 五体投地　双手、双膝与头部五处着地的最恭敬礼拜。
〔85〕 名闻利养　名声与财物供养；修行人易贪着的两种世间利益。
〔86〕 戏论　无实义、不能导向解脱的言论与分别；「无戏论法」即离一切虚妄分别的真实之法。
〔87〕 资生　资养生命之物，即衣食财物等生活所需；「资生之具」即生活用品。
〔88〕 教命　王者的教令、政令；「普行教命」谓以国王身份颁行政令禁断杀业。
〔89〕 生类　一切有生命之类，即种种众生。
〔90〕 仁慈莅物　莅（音 lì）临、对待；「仁慈莅物」谓以仁慈之心临待众生，不加侵恼。
〔91〕 三种净戒　即下文「三聚净戒」的略称：摄律仪戒、摄善法戒、饶益有情戒三类菩萨净戒的总纲。
〔92〕 五戒　不杀生、不偷盗、不邪淫、不妄语、不饮酒五种在家戒。
〔93〕 命根　维持一期寿命连续不断的根本；「常住命根」谓寿命相续不夭。
〔94〕 三聚净戒　聚：类；菩萨的三类净戒——摄律仪戒（止一切恶）、摄善法戒（修一切善）、饶益有情戒（度一切众生）。
〔95〕 男形　男根（男性生殖器）；此段是对残损人畜男形恶业的禁断与救疗，故回向愿众生具足丈夫形。
〔96〕 马阴藏相　佛三十二相之一：男根如象马之阴隐密不露，表欲染净尽。
〔97〕 梵行　梵（音 fàn）清净之义；梵行即离欲清净之行。
〔98〕 五欲　财、色、名、食、睡（一说色、声、香、味、触）五种感官欲乐。
〔99〕 大雄　佛的德号，谓能摧伏烦恼魔军的伟大英雄；「无上大雄」即成就佛果。
〔100〕 七丈夫道　七种大丈夫之道（「丈夫」指伟烈有担当的胜士，非泛指性别）；谓以丈夫之行引导众生，即下文列出的丈夫正教、勇猛、精进、智慧、清净等。
