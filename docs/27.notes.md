# 大方广佛华严经卷第二十七 词语注释

① 十回向　华严十地前之五位行门，含救护一切众生离众生相回向等十种。本卷为「十回向品第二十五之五」，专明内施与为法舍身之回向行。
② 菩萨摩诃萨　「摩诃萨」意为「大有情」，指已入地、行广大行之菩萨。本卷屡以此尊称强调所行内施乃大士境界。
③ 连肤顶髻　连同头皮（肤）之头顶髻发。菩萨以内身头分施人，并以之回向令众生得无见顶相。
④ 阎浮提　即南赡部洲，吾人所居之洲。经中多以阎浮提为人间之代表，言「阎浮提中最为第一」以显施物之胜。
⑤ 右膝着地　佛教礼敬姿势，右膝跪地以表恭敬，为菩萨布施时之虔敬仪轨。
⑥ 善知识　能教导正法、引人发菩提心之良师益友。菩萨观来乞者「如善知识而来护想」。
⑦ 善根　由修善所生之根本功德，能为无上菩提之因。菩萨以所修施善根普皆回向一切众生。
⑧ 回向　将所修善根趣向菩提、众生、实际，使功德广大无尽。本卷每段施毕皆「以诸善根如是回向」。
⑨ 无见顶　佛顶相之一，顶上肉髻相之极高胜者，肉眼不能见顶。回向恒愿众生「得无见顶」。
⑩ 卐字　佛三十二相之一，胸前卐字吉祥相。回向愿中言「如卐字发」「卐字庄严」，指佛身相好。
⑪ 陀罗尼　意译「总持」，即摄持无量法义令不散失之法门。菩萨施髻回向愿众生「皆得圆满诸陀罗尼」。
⑫ 一切种智　佛智之一，于一一法相差别皆悉通达之智，即佛果究竟智。回向恒归此智。
⑬ 十种力　即如来十力，佛所独具之十种智力，如处非处智力、业报智力等。回向愿令众生圆满此十力。
⑭ 十力　如来十力之略称，佛独有之十种无所畏智力。菩萨回向恒愿众生「具足十力」「得佛十力」。
⑮ 法界　一切法所依之真如理体，亦指诸法互摄无尽之境。愿文中「法界生身」「遍法界耳」，皆约此义。
⑯ 优昙华　即优昙钵罗华，三千年一现之稀有之华。经以喻菩萨施齿之心「希有难得如优昙华」。
⑰ 波罗蜜　意译「到彼岸」，菩萨六度（布施、持戒、忍辱、精进、禅定、般若）之通称。本卷檀波罗蜜（布施度）为根本。
⑱ 福田　谓如种田能生福果，受供养者即为众生福田。菩萨自为「上福田」，又愿众生「生福田想」。
⑲ 那由他　印度极大数词，或云十万、百万、千万不等，表数量无量。经中形容众生来乞之数「百千亿那由他」。
⑳ 师子座　佛说法之座，喻最胜无畏。菩萨施舌时「安置其人在师子座」，以尊乞者如佛。
㉑ 丈夫　此指大丈夫、雄猛堪任之人，非世俗男女之男。经中以「丈夫形」「大丈夫」表发菩提心、勇猛修梵行之胜根。
㉒ 法身　以法性为体之身，本来自在、无形无相。回向愿众生「得法身、智身」之身，即以法性为身。
㉓ 智身　以一切智为体之身，由修证而得，与法身相对——法身约理、智身约证。
㉔ 意生身　菩萨意愿所化现之身，随意变化、非胎肉所成。回向愿众生「得意生身，犹如佛身」。
㉕ 檀波罗蜜　即布施波罗蜜，六度之首。P12 言菩萨施心「习行檀波罗蜜心」，即修布施度到彼岸之心。
㉖ 那罗延　天上力士之名，喻坚固大力。愿文中「如那罗延坚固幢心」「那罗延藏」，皆喻坚固不可坏。
㉗ 阿鼻狱　意译「无间狱」，八热地狱之最苦者，受苦无间。菩萨为法「尚应久住阿鼻狱」，显为法忘躯之极。
㉘ 五体投地　两肘、两膝、头顶五处皆着地之最敬礼，为求法时至诚恳切之仪。
㉙ 五戒　在家众所持之五种基本戒：不杀、不盗、不邪淫、不妄语、不饮酒。菩萨令众生「住于五戒，永断杀业」。
㉚ 三聚净戒　大乘戒之总纲：摄律仪戒（断一切恶）、摄善法戒（修一切善）、饶益有情戒（度一切众）。菩萨住此三聚而断杀业。
㉛ 马阴藏相　佛三十二相之一，男根密隐体内如马之相。回向愿众生「具丈夫形，成就如来马阴藏相」。
㉜ 善男子　佛对在家信众之通称，亦泛指发心修善之男子。回向愿众生「悉得成就善男子法」。
