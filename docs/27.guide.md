# 大方广佛华严经卷第二十七 导读

## 一、内容总览
本卷为《大方广佛华严经》第二十七卷，属「十回向品第二十五之五」，承接前十回向中之初回向、乃至前卷之回向义，专明菩萨摩诃萨「内施」与「为法舍身」一系之广大行门。全卷以佛子（金刚藏菩萨之口吻）连续敷演二十一类施相：自施连肤顶髻、眼、耳、鼻、齿、舌、头、手足、身血、髓肉、心、肠肾肝肺、肢节诸骨、身皮、手指、连肉爪甲，至为求法投火坑、受众苦、舍国城妻子、禁断杀业、救护毁败男形，层层递进，皆为「以不坚身易坚固身」「以诸善根如是回向」之实修示范，归结于令众生究竟成就如来十力、一切智。

## 二、结构层次（★重点）
全文采用「施相枚举 → 起心作意 → 善根回向 → 为令众生」之固定四段式叠复推进，以「佛子！菩萨摩诃萨」领起每一段：

- **一总标内施**：先举往昔菩萨（宝髻王、欢喜行、胜行王等）为典范 → 引出菩萨见乞者来「心生欢喜」之内施心态 → 起信、起悲、起智、起回向心。
- **次第展开「身分支」施相**（P3-P16）：
  - 上半段为「头面支分施」：连肤顶髻 → 眼 → 耳鼻 → 牙齿 → 舌 → 头 → 手足，由顶至足、由外入内。
  - 下半段为「血肉脏器施」：坏身出血 → 髓肉 → 心 → 肠肾肝肺 → 肢节诸骨 → 身皮 → 手指 → 连肉爪甲，由肤肉入骨髓、由外具入内藏。
- **转入「为法舍身」之殊胜施**（P17-P20）：连肉爪甲求法 → 投七仞火坑求法 → 为法受众苦 → 为法舍国城妻子，施相由「身肉」升为「身命」与「国位」，显菩萨为法忘躯之究竟。
- **收束于「戒护众生」之大悲施**（P21-P22）：作大国王禁断杀业、立三聚净戒 → 救护毁败男形之众生，由「自舍身」转为「护他命」，将布施收归于「摄律仪、摄善法、饶益有情」之三轮体净。
- **每段以「是为……善根回向；为令众生……故」收束**，形成「施—回—愿」之环复结构，回向愿文皆以「愿一切众生得……」十句铺陈，对应所施支分所感之果相。

## 三、关键结论

1. 菩萨内施非为自苦，乃「以不坚身易坚固身」——以无常秽身换取法身、智身、如来身，此为十回向中「救护一切众生离众生相回向」之实修。
2. 每一施相皆具「起心（悲智双运）→ 正施（身业无染）→ 回向（愿众生得果）」之完整三聚，显示菩萨行非徒然舍身，而是以菩提心摄持、以回向力导引之愿行。
3. 回向愿文与所施支分严密对应：施眼愿得净眼、施舌愿得辩才舌、施齿愿得鲜白牙、施心愿得金刚藏心，体现「如是因如是果」之缘起理。
4. 由「自施身」递进至「为法舍命」「舍国位」「护他命戒杀」，显示内施之究竟义不仅是身分之舍，更是三聚净戒之圆满——布施即戒、即忍、即精进、即禅、即般若，六度互摄。
5. 全卷引证往昔无量菩萨（宝髻王、欢喜行、最胜智、常精进、法藏、清净藏等）为本生实例，显示此非空谈，而是菩萨道中实证之典范。

## 四、易混辨析

- **菩萨摩诃萨 vs 菩萨**：「菩萨」通指发菩提心者；「摩诃萨」意为「大有情」，指已入地、行广大行之菩萨。本卷屡称「菩萨摩诃萨」，强调所行乃登地以上之大士内施，非凡夫菩萨所能及。
- **回向 vs 愿**：「回向」是「以已修善根趣向菩提、众生、实际」，是动作；「愿」是回向时所发之具体愿文（「愿一切众生得……」），是回向之内容。本卷每段先回向、后列十愿，二者相连而有别。
- **法身 vs 智身 vs 如来身**：回向愿中频列此三「身」。「法身」以法性为体，本来自在；「智身」以一切智为体，由修证得；「如来身」是法报化三身圆满之果身。三者次第由理、智、果。
- **三聚净戒 vs 三种净戒**：本卷 P21 言「常自安住三种净戒」，即「摄律仪戒、摄善法戒、饶益有情戒」三聚，与「五戒」（不杀等正制）不同——三聚通于大乘，五戒通于在家众。

## 五、阅读提示
读本卷可扣紧「以不坚身易坚固身」一句为纲，留意每一施相后的「愿一切众生得……」回向文与所施支分之对应关系；并注意 P18「为法投火坑」、P20「为法舍国城」二段，是内施由「身分支分」升进至「为法忘躯」「舍王位」之转折枢纽，亦即菩萨「不惜身命求正法」之极致表现。
