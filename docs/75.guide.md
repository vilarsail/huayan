# 大方广佛华严经卷第七十五 导读

## 一、内容总览
本卷为《入法界品》第三十九之十六，善财童子五十三参中走访释迦族女瞿波的一参。善财一路思惟修习受生解脱，来到迦毗罗城，先受无忧德神率一万主宫殿神众迎接赞叹，随后在菩萨集会普现法界光明讲堂中见到瞿波女——八万四千采女围绕，坐宝莲华师子之座。瞿波女自陈所得「观察一切菩萨三昧海解脱门」，并以大段本生故事讲述自己与释迦牟尼佛（当时为威德主太子）在往劫的因缘，末了指授善财去参访佛母摩耶夫人。

## 二、结构层次（文章的骨架与逻辑推进）
- **神众来迎（承接前参）**：善财渐次游行至讲堂 → 无忧德神携一万主宫殿神众出迎赞叹，肯定其勇猛精进，预言不久当得诸佛三业、当入诸佛甚深解脱 → 善财自陈为一切众生发心求法，连用十六个「为……令……」的排比说菩萨于众生的种种身份（为庄严、为父母、为船师、为导师……）。
- **求法发问（问题提出）**：善财入讲堂，见瞿波女而顶礼，提出十一重两难之问：如何在生死中不为生死过患所染、了法自性而不住二乘地、成就法身而示现色身、知法无说而演说诸法……全卷由这组「虽知……而……」的问题驱动。
- **行法开示（先总后分）**：瞿波女先说成就十法则能圆满「因陀罗网普智光明菩萨之行」，再说以十种法承事善知识 → 承佛神力说重颂。
- **解脱门自陈（境界展示）**：自言成就「观察一切菩萨三昧海解脱门」——于一念中知娑婆世界微尘数劫内众生生死业报、诸佛名号本生、声闻独觉菩萨诸众的修行果德，乃至华藏世界海中一切世界。
- **本生叙事（全卷主体）**：往过佛刹微尘数劫，胜行劫、无畏世界——威德主太子与莲华化生的具足妙德童女同诣胜日身如来；太子发菩提心、说布施誓愿，纳女为眷属，继位转轮王广设供养；父王出家得陀罗尼。最后以「彼时太子岂异人乎？今释迦牟尼佛是也」揭橥：太子即释迦牟尼，妙德女即瞿波自己，父王即宝华佛——本生与当下会通。
- **谦己指授（收束）**：瞿波女谦言唯知此一解脱门，普贤解脱门与如来境界等、无量无边，指授善财参问佛母摩耶夫人 → 重颂结叹，善财礼辞而去。

## 三、关键结论
- 亲近善知识、听受其教、忆念修行而不懈退，是远离魔难、速成无上果的根本道路。
- 菩萨以大悲愿力于生死中受生、随类现身，虽处世间而心常清净，不为生死过患所染。
- 于多劫中承事供养无量诸佛、恒不舍离，是得大解脱门的因。
- 普贤解脱门境界与如来境界相等，非狭劣心行所能测知——为后文参访摩耶等大善知识张本。

## 四、易混辨析
- **瞿波女 ≠ 另一位善知识**：瞿波女、释迦瞿波女、具足妙德童女是同一人——「具足妙德」是她本生时的名字，「瞿波」是释迦族女的通称。
- **威德主太子与释迦牟尼**：本生叙事中受父王教、发心布施的太子，即今日的释迦牟尼佛；其父财主王即宝华佛，女母善现即今佛母善目。
- **观察一切菩萨三昧海解脱门 vs 普贤解脱门**：前者是瞿波女自证者；后者是她尚未能知的诸菩萨境界，「如太虚空……无量无边」，二者层级不同。
- **转轮王与法王**：太子七宝具足为转轮王，以世间王政护持佛法；「法王」则指于法自在的佛陀，二者不可混。

## 五、阅读提示
读本卷宜紧扣「佛子！于汝意云何？」——本生故事讲得极长，最终都落在人物身份的揭示上：往劫的供养因缘即是当下解脱门之因。偈颂部分（无忧德神赞、瞿波重颂）是长行的提要，可对照把握全卷脉络。
