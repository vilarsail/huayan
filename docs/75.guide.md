# 大方广佛华严经卷第七十五 导读

## 一、内容总览

本卷为《入法界品》第十六会，承接善财童子五十三参之链。前承「大愿精进力救护一切众生夜神」，下启「佛母摩耶」。主线是善财参访释迦瞿波女（释种女瞿波），由瞿波自述其「观察一切菩萨三昧海解脱」之境界与往昔本生因缘。全卷以「善财问法 → 瞿波略答十法 → 重颂广明 → 善财再问境界 → 瞿波详述所证 → 自陈本生（威德主太子与妙德童女事） → 自陈不及菩萨境界 → 指路下一善知识」一气贯穿，是一部以「菩萨三昧海」为核心、以「菩萨一一毛孔即法界」为归宿的菩萨道次第示范。

## 二、结构层次（★重点）

全卷以「问答—重颂—本生—指授」四重推进：

- **参礼启问（P3-P4）**：善财离前善知识，思惟「受生解脱」渐次游行至「菩萨集会普现法界光明讲堂」→ 主宫殿神无忧德迎请赞善财。
- **无忧德赞善财 + 善财自陈悲愿（P5-P13）**：无忧德以颂赞善财将成佛 → 善财自述菩萨「不舍众生、不自为己」之大悲，列举菩萨为众生之「父母/船师/导师/普贤」等十五喻 → 神众散华颂赞 → 仍随逐不舍。
- **入堂见瞿波 + 问「云何菩萨于生死而不染」等十难（P14-P16）**：善财入堂见释种女瞿波坐宝莲华座，合掌请问十组「不二」难题（了法自性而不住二乘、具佛法而修菩萨行、超过世间而于世受生、证无相而示现诸相……）→ 瞿波印可「谛听」。
- **略答十法 + 重颂（P17-P21）**：瞿波先标「成就十法圆满因陀罗网普智光明菩萨行」→ 释「以十种法承事善知识」→ 承佛神力以重颂十二偈广明各行为「帝网行/普智光明行/身云行/不染行/普照行/大愿行/分身行/智日行/普贤行」。
- **自陈所证「观察一切菩萨三昧海解脱」（P22-P27）**：瞿波告已成就此解脱 → 善财问境界 → 瞿波详述：知娑婆世界佛刹微尘数劫中众生善恶、诸佛名号次第、声闻独觉菩萨各阶善根三昧；知娑婆尽未来际劫海展转不断；知华藏世界海中世界种所摄一切世界；知毗卢遮那世尊往昔因缘海；自结「此解脱能知一切众生心行、菩萨诸三昧、如来解脱光明」。
- **本生因缘（P28-P60）**：善财问「得此解脱其已久如」→ 瞿波自述往昔胜行劫、无畏世界、安隐四天下、高胜树城中，财主王太子威德主游香芽园，遇善现母及具足妙德童女（莲华化生）；妙德梦胜日身如来成道七日；太子以十颂问女德、母以长颂陈女之莲华化生及种种德；太子自陈发菩提心、尽未来际行檀波罗蜜舍内外物；妙德女愿「生生以我施」、共诣佛所；胜日身佛说普眼灯门修多罗，太子妙德各得三昧；父王财主王舍位出家证陀罗尼；太子继位为转轮王，七宝自至，王阎浮提；瞿波自指「妙德女即我身」，六十亿百千那由他佛承事供养，最后佛名广大解，得净智眼、得此解脱 → 自陈虽久修习，仍「未能知菩萨所得普贤解脱门」；菩萨普贤解脱门如虚空、如众生名、如三世海、与如来境界等 → 自陈观菩萨一一毛孔念念见无边世界、诸佛、众生海、三世菩萨行门，求其边际竟不可得 → 推广大悲妙愿引见菩萨。
- **指授下一位善知识（P61）**：瞿波告善财「此世界中有佛母摩耶，汝诣彼问」，以「菩萨云何于诸世间无所染着」等为引。
- **重颂结说（P62-P63）**：瞿波承佛神力以长颂重明本生：过百刹尘劫、清净劫、光明世界、法幢灯佛涅槃后、智山王、善光太子、善名称居士女净日光以爱染心供佛子、二百五十劫不堕恶趣、后生善现家名具妙德、与太子觐胜日身佛发心、于一劫中值六十亿如来、最后广大解佛得净眼、得观菩萨三昧解脱，一念入十方刹海，观菩萨一一毛孔诸刹诸佛诸业心智「了不可得」。

## 三、关键结论

1. **菩萨道以「不舍众生」为根本**：菩萨不自为己求一切智，于生死中无疲厌，为大悲愿力普摄众生，善财与瞿波皆以「亲近善知识、承事供养诸佛、不舍众生」为修行主线。
2. **「因陀罗网普智光明菩萨行」以十法圆满**：依善知识、得广大胜解、清净欲乐、集福智、于诸佛所闻法、心不舍三世佛、同菩萨行、如来护念、大悲妙愿清净、以智力断生死——此十法为本卷纲领。
3. **菩萨一一毛孔即法界**：瞿波所证「观察菩萨三昧海解脱」的极致是「观菩萨一一毛孔念念见无边世界、诸佛、众生、三世菩萨行门，求边际不可得」，与「普贤解脱门与如来境界等」相呼应，显示华严「一即一切、一切即一」的法界互摄观。
4. **本生示范即「受生解脱」之实证**：妙德女以爱染心供养佛子，二百五十劫不堕恶趣，后转为具妙德、与太子共发菩提心、承事六十亿如来得净智眼——烦恼可转为道用，生死即受生解脱之场。
5. **善知识次第相承**：瞿波虽自陈所证甚深，仍谦言「未能知菩萨所得普贤解脱门」「我云何能知能说彼功德行」，并主动指授善财往参佛母摩耶——参学无尽，谦下相承。

## 四、易混辨析

- **善财童子所问「菩萨摩诃萨行」vs「普贤行愿」**：前者泛指菩萨六度万行；后者特指普贤十大愿王所摄的「深心信解、称性起修、周遍法界」之行。瞿波重颂中「普贤行」「帝网行」「分身行」皆为普贤行的不同侧面。
- **瞿波女 vs 佛母摩耶**：瞿波（释种女，亦称释迦瞿波）是释迦牟尼为太子时之妃；摩耶是释迦牟尼之生母。本卷瞿波自陈「妙德女即我身」，其本生与太子（释迦）为偶；卷末指授善财往参摩耶，前后两位释种女性善知识相承。
- **「因陀罗网」vs「普智光明」**：因陀罗网（帝网）喻帝释天宫之网，网珠交映、重重无尽，喻法界事事无碍、一多相入；普智光明指周遍法界之智光。合称「因陀罗网普智光明菩萨行」即以无尽互摄之智光照见法界之菩萨行，是本卷所标之总法门名。
- **「观察一切菩萨三昧海解脱」vs「普贤解脱门」**：前者是瞿波所证，能于菩萨一一毛孔见无边世界诸佛众生，然「求其边际竟不可得」；后者是菩萨究竟境界，如虚空、与如来境界等，瞿波自言「未能知」——前者为入处，后者为极果，二者有浅深之别。
- **威德主太子 vs 财主王 vs 胜日身佛 vs 宝华佛**：威德主太子即今释迦牟尼佛（继位为转轮王）；财主王（其父）即宝华佛（现居东方圆满光世界）；胜日身佛是当时出世之佛，为太子妙德说法；四者为本生故事中四个关键人物的「过去—现在」对应，须辨清。

## 五、阅读提示

读本卷可带着三个问题：①善财问的「十组不二」（了法自性而不住二乘、超过世间而于世受生等）如何可能？瞿波的回答为何从「承事善知识」起？②妙德女以爱染心供养佛子竟能「二百五十劫不堕恶趣」，这传递了什么修行观？③瞿波既已证「观菩萨一一毛孔见无边刹海」，为何仍谦言「未能知普贤解脱门」？此谦下与本卷「指授摩耶」的衔接有何深意？
