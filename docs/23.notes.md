# 大方广佛华严经卷第二十三 词语注释

〔1〕 实叉难陀　唐代来自于阗的三藏法师，八十卷本《华严经》的译者；三藏指通经、律、论三者。
〔2〕 兜率宫中偈赞品　本品名。兜率（dōu shuài）天为欲界第四天，佛在此天宫中，十方来的菩萨以偈颂赞叹佛德。
〔3〕 尔时　那时、正当那时，佛经中承接叙事的惯用语。
〔4〕 佛刹微尘数　刹（chà）即佛国土；把一佛国土碎为微尘，以尘之数喻极多，非实指。
〔5〕 诣佛所　诣（yì），到、趋赴；谓来到佛的处所。
〔6〕 金刚幢菩萨　本卷主要说法者。与坚固幢、勇猛幢等十位名号带「幢」的菩萨自十方而来，先后说偈赞佛；卷末十回向品亦由他演说。
〔7〕 波头摩　梵语 padma，红莲花，此为世界名。
〔8〕 优钵罗　梵语 utpala，青莲花，此为世界名。
〔9〕 栴檀　即旃檀，香木名，此为世界名。
〔10〕 净修梵行　梵行即清净行，指离欲清净的修行。
〔11〕 所谓　就是、即如，引出下文的列举或解释。
〔12〕 顶礼佛足　以己头面触礼佛之足，古印度最恭敬的礼节。
〔13〕 周匝　周围环绕；周匝遍满即四面围绕、遍布。
〔14〕 结跏趺坐　双足交盘而坐的端正坐姿，即打坐。
〔15〕 悉　全部、都。
〔16〕 那由他　梵语 nayuta 的音译，印度大数名，泛指极大之数。
〔17〕 阿僧祇　梵语 asaṃkhya，义为无央数，不可计量的极大数。
〔18〕 承事　承奉侍奉，谓亲近供养诸佛。
〔19〕 毗卢遮那如来　华严经的教主，义译「光明遍照」，表征遍一切处的法身佛。
〔20〕 第一彼岸　即波罗蜜多，度脱生死、到达涅槃彼岸之极致。
〔21〕 金刚定　坚利如金刚、能断一切疑惑的三昧。
〔22〕 承佛神力　仰仗佛陀威神力的加持；华严中菩萨入定、说法前例皆先说此语，示其所说非出于自力。
〔23〕 人师子　人中的狮子，喻佛说法无畏、威德摧伏邪见；师子即狮子。
〔24〕 佛子　经中对菩萨的称呼，谓能绍继佛种、必当成佛。
〔25〕 伽陀药　梵语音译，能解百毒的灵药，喻佛法能灭烦恼之毒。
〔26〕 亦复非非化　承上句「佛身非变化」，谓也不是「非变化」；双遣变化与不化两边，示佛身超离对待。
〔27〕 言语道悉绝　言语之道断绝，即「言语道断」，谓真理非语言思维所能及。
〔28〕 翳眼　翳（yì），眼上障蔽之病；翳眼所见非实，喻众生见佛亦如幻见。
〔29〕 兴世　兴，起；兴世即出现于世间。
〔30〕 随意珠　即如意宝珠，能随人心愿出生种种所需，喻佛能满众生之愿。
〔31〕 靡不　靡（mǐ），无、没有；靡不即无不。
〔32〕 咸　全、都。
〔33〕 般涅槃　般（pán）涅槃即入涅槃、圆寂。
〔34〕 十回向　本卷后半品名。回向即菩萨将所修善根功德转施、导向一切众生与无上菩提；十回向为菩萨阶位中十行之后的十位，本品广说其义。
〔35〕 菩萨智光三昧　三昧即正定；金刚幢演说十回向前所入之定，由十方同名诸佛神力加被而入。
〔36〕 白法　白净的善法，与黑恶之业相对。
〔37〕 助道　助成觉悟之法，即三十七菩提分等道品。
〔38〕 陀罗尼　梵语 dhāraṇī，义译总持，忆持一切佛法不忘不失的慧力。
〔39〕 无留碍辩　无滞碍的辩才，即四无碍辩，为诸佛所加与。
〔40〕 何以故　为什么？自设问答的发端语，下文自答。
〔41〕 摩顶　抚摩其顶，诸佛加持、授记的仪式；诸佛以右手摩金刚幢顶，表加被其说法。
〔42〕 去、来、现在　去、来即过去与未来，与现在合为三世。
〔43〕 回向有十种　十种回向是并列清单，从「一者救护一切众生离众生相回向」到「十者入法界无量回向」，逐条读名目即可，本卷先总列、再详说第一种。
〔44〕 云何　如何、什么是，发起疑问之词。
〔45〕 檀波罗蜜　檀即檀那（dāna），布施；波罗蜜即到彼岸，六度之一。下文尸、羼提、禅、般若诸波罗蜜例此。
〔46〕 尸波罗蜜　尸即尸罗（śīla），持戒。
〔47〕 羼提波罗蜜　羼（chàn）提即忍辱。
〔48〕 禅波罗蜜　禅即禅那（dhyāna），静虑、禅定。
〔49〕 般若波罗蜜　般若（bō rě）即观诸法实相的智慧。
〔50〕 大慈、大悲、大喜、大舍　四无量心：慈予乐、悲拔苦、喜见众生行善而生随喜、舍离怨亲差别而平等。
〔51〕 阎罗王　管理地狱的鬼王；经中与地狱、饿鬼、畜生并举，泛指恶道诸苦。
〔52〕 安隐　隐通「稳」，安隐即安稳，佛经习用语。
〔53〕 非亲友　不是亲友的人；谓菩萨对非亲非故乃至怨家也平等回向守护。
〔54〕 瞋很　很通「狠」，瞋怒凶狠。
〔55〕 憍慢　憍（jiāo）同「骄」，傲慢自大。
〔56〕 盲瞽　瞽（gǔ），盲人；心盲瞽喻无慧目、不识善恶。
〔57〕 日天子　太阳之神；喻菩萨如日普照世间，不因众生不见、世间障蔽而隐没。
〔58〕 生盲　生来失明的人；谓日不因生盲看不见就不出现，喻菩萨不舍任何众生。
〔59〕 乾闼婆城　梵语 gandharva，海上蜃景所成的幻城，喻虚幻不实。
〔60〕 阎浮提　梵语 Jambudvīpa，此世界人类所居之洲（南赡部洲），因阎浮树得名；阎浮提树即其树。
〔61〕 邃谷　邃（suì），深远；邃谷即幽深的山谷，此与崇岩等并举，谓日不被诸物障蔽。
〔62〕 甲胄　甲胄即盔甲；以大愿为甲胄自庄严，喻以愿力护身、入生死而不伤。
〔63〕 阿耨多罗三藐三菩提　梵语 anuttara-samyak-saṃbodhi，义译无上正等正觉，佛所得的圆满之智。
〔64〕 所缘　心识所攀缘、对望的境界（对象）；谓回向时以一切众生为所缘。
〔65〕 荷负　荷（hè）担；承担、背负，谓愿担众生之苦。
〔66〕 爱网所缠，痴盖所覆　贪爱之网缠缚、愚痴之盖覆蔽；盖是烦恼异名，能覆蔽心性令善法不生。
〔67〕 笼槛　槛（jiàn），圈兽的栅栏；苦笼槛喻生死如牢笼。
〔68〕 魔业　与道相违、妨害善根的行为。
〔69〕 一切种智　佛智之名，通达一切法总相、别相的圆满智慧。
〔70〕 无上智王　智慧中之王，即佛。
〔71〕 大壑　壑（hè），深沟大谷；众苦大壑喻无底的生死苦海。
〔72〕 以身为质　质，抵押、人质；谓以自身作担保，赎出地狱恶道中的众生。
〔73〕 五欲　色、声、香、味、触五种感官欲乐；经中谓其乐实是苦的根源。
〔74〕 三有　欲界、色界、无色界三界的生死流转；亦泛称「诸有」。
〔75〕 诸佛所诃　诃同「呵」，呵责；谓贪五欲为诸佛所呵斥。
〔76〕 耽着　耽（dān），沉溺；耽着即贪恋执著。
〔77〕 罥索　罥（juàn），捕兽的绳网；诸苦罥索喻诸苦缠缚众生。
〔78〕 究竟乐、利益乐、不受乐　自「究竟乐」至「一切智乐」是十种乐的并列清单，读时逐条看乐名即可。
〔79〕 调御师　调伏驾御众生之人，佛十号之一「调御丈夫」；下文主兵臣即国王统领军队的大臣，皆喻菩萨引导、统领众生。
〔80〕 俾知实义　俾（bǐ），使；以善巧方便使众生了知真实之义。
〔81〕 四天下　一须弥山四方四大部洲，为一小世界的人类居所；谓不因四天下众生多便有多日并出。
〔82〕 顾复　眷顾覆育，语本《诗经》「顾我复我」，谓慈心照管养育众生。
〔83〕 无所著法性回向　自此以下连举数十种「某某回向」，皆是回向的名义差别，读时逐条抓前半的观法即可，不必求其结构。
〔84〕 五蕴　蕴即积聚；色、受、想、行、识五类身心要素，旧译五阴。
〔85〕 法界印　印，印可、印定；谓以法界之理印证一切善根，使其归实。
〔86〕 非即业修习一切智　疑难句：一切智既不即是业（非即业而修），也不离业而别有（非离业回向）；业报如光影无实，而不离业得一切智，双遣两边。
〔87〕 我、我所　我所即「我所有的」，对身与物的执取；离我、我所谓离人我执与我所执。
〔88〕 暨于法界　暨（jì），及、与；谓遍观法会大众以至于法界。
〔89〕 含识　含有心识情虑的众生，即有情。
〔90〕 为物　物指众生；为物即为一切众生而勤修。
〔91〕 大士　菩萨的通称，德位高深之人。
〔92〕 付嘱　付托嘱累，即郑重嘱咐、托付传承。
〔93〕 法城　以城喻法；佛法能防邪护善，安住其中如城之护人。
〔94〕 有非有　存在与非存在；谓思惟诸法不落有无两边。
〔95〕 无诤处　诤（zhèng），争论；无诤即离一切对待争论的寂灭之境。
