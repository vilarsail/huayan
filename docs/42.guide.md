# 大方广佛华严经卷第四十二 导读

## 一、内容总览

本卷为《大方广佛华严经》卷第四十二，属「十定品第二十七」之三，承接前卷继续由普贤菩萨为佛子宣说菩萨摩诃萨所修十种大三昧。本卷集中讲第八「一切众生差别身大三昧」与第九「法界自在大三昧」两门善巧智。前者以「一身入定、他身起」的入出自在，演说菩萨于种种身、种种界、种种时、种种法中圆融无碍；后者以「于一毛孔入三昧，普见法界」的境界，明菩萨得诸佛摄受、十种海、十种殊胜、十种力及四河入海之喻。全卷以「定体 → 入起自在 → 称赞光明 → 神通彼岸 → 法界自在 → 四河喻收束」为线，层层展开菩萨三昧的体用与功德边际。

## 二、结构层次

全卷由两大三昧构成，各自「征问 → 答释 → 比喻 → 功德收束」，结构对称而层层递进：

- **第八三昧：差别身三昧（境—身—界—时—法圆融）**
  - 「十无所著」立其体 → 列十种无所著（刹、方、劫、众、法、菩萨、愿、三昧、佛、地）作为入定之基；
  - 「云何入？云何起？」总问 → 以「内身入外身起」起首，作长串「入—起」对举：身类（人、夜叉、龙、阿修罗、天、梵王、欲界、地狱、人间）、方域（阎浮提、瞿陀尼、拘卢、毗提诃、四天下、海）、大种（水地火风）、世界（小千、中千、大千、不可说不可说）、根处（眼耳鼻舌身意）、微尘、声闻独觉、自他身、一念亿劫、三世刹那、真如言说；以「真如入，言说起；言说入，真如起」收束，示入起不二；
  - 四喻显其相 → 鬼所持身（他身起）、死尸咒力（同异境起）、比丘心自在（一多身）、大地一味（一入多起）——皆明「自他、同异、一多、一味」自在；
  - 「十种称赞法」「十种光明」「十种无所作」 → 显此三昧之果德，由用归体，至于身语意业无所作；
  - 无量境界差别 → 以幻师咒、阿修罗入藕丝孔、农夫下种、歌罗逻入胎、龙宫兴云、梵宫普现六喻，明差别即无差别；
  - 「十种神通彼岸」收束 → 由差别身三昧通至诸佛尽虚空遍法界神通，乃至一念三世示现。

- **第九三昧：法界自在三昧（根—毛孔—法界）**
  - 「于自眼处乃至意处入三昧」立其门 → 于一一毛孔中入此三昧，自然知世间、世界、阿僧祇、不可说佛刹微尘数世界；
  - 诸佛摄受 → 十方各十千阿僧祇佛刹微尘数名号诸佛现前，为说清净刹、无量身、难思眼耳、无住心、无上神通等，令入如来平等之法；
  - 十方如来护念 → 令得无边身、无碍心、无忘念、决定慧、聪敏、明了、猛利诸根、境界无碍、无碍智、神通示现成佛；
  - 「十种海」「十种殊胜」「十种力」 → 由海而殊胜而力，功德层层增广，力中复开广大力、法身力、善根力等三十七种异名，示功德边际不可说；
  - 无热池四河喻 → 以阿那婆达多龙王宫流出恒伽、私陀、信度、缚刍四河，各从象、师子、牛、马口出银、金刚、金、琉璃沙，喻菩萨以义、法、训辞、无尽四辩才流注一切智海；复以池之金沙、宝树、纵广五十由旬、底布金沙、日光鉴彻展转现影，喻菩提心、善根、智慧、三昧、方便种种庄严，及菩萨于一一毛孔见不可说诸佛国土而不想念时节；
  - 虚空喻收束 → 「虽普入一切世间而离世间想」等十对「虽…而…」对举，明法界自在而不离法性，归于「第九法界自在大三昧善巧智」。

## 三、关键结论

1. 菩萨三昧的入起不二：内身入外身起、一念入亿劫起、真如入言说起，示差别即无差别、三世即刹那，定体本无动摇。
2. 差别身三昧之所以自在，不在身之变换，而在「无所著」——于刹、方、劫、众、法、菩萨、愿、三昧、佛、地十无所著，方得一身多身互为入起。
3. 法界自在三昧以「一一毛孔」为入处，由根门入法界，故能于一毛孔中见不可说佛刹微尘数诸佛国土，时空长短皆不想念。
4. 四河入海喻以「四辩才—四方—四智河」三层叠合，明菩萨度生之行虽分四流，终究同入一切智海，且无疲厌、无能阻挡。
5. 功德边际不可说：从十千阿僧祇到不可说不可说，从十种海到三十七种力之异名，皆显菩萨所修功德唯佛能知、不可说劫无能说尽。

## 四、易混辨析

- **一切众生差别身三昧 vs 法界自在三昧**：前者以「身」为门，明一身多身、自他身、三世身入起自在；后者以「根（眼等六处）—毛孔」为门，明于一毛孔中普见法界。前者重「入起」，后者重「周遍」。
- **入定 vs 起**：入定（入）是菩萨于一境一身上安住三昧，起是于另一境另一身上现身出定；入起同时、自他不二，非先入后起之二元过程。
- **歌罗逻位 vs 六根**：歌罗逻为受生初位（胎初七日之凝滑位），与已成六根体状各别，以业力故次第成就六根——喻菩萨从一切智初位渐次增长而能自在入起有无之境。
- **四辩才 vs 四智河**：四辩才（义、法、训辞、无尽）是能说之用，四智河（愿、波罗蜜、三昧、大悲）是所成之行；前者从口业流出，后者从愿力流出，皆归一切智海。
- **无热恼池 vs 龙宫**：无热池（阿那婆达多龙王所居）出水四河，离诸热恼，喻菩萨菩提心清净无浊；龙宫依地不依空，喻菩萨虽处下而能兴云遍满空中，行布不碍圆融。

## 五、阅读提示

读本卷可抓住「入—起」二字为眼：凡见「某入某起」之长串对举，不要逐对记忆，而要看出其总相——差别法中入、无差别法中起，无差别法中入、差别法中起。四河喻为全卷最精彩的比喻层，宜对照「四辩才—四方—四智河」三层结构细读，体会华严「一即一切、一切即一」之旨如何由比喻落实于菩萨行。
