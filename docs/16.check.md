### 段落 28 【翻译错误】

- **原文**：“无上摩诃萨，　　远离众生想，
　无有能过者，　　故号为无上。
　诸佛所得处，　　无作无分别，
　粗者无所有，　　微细亦复然。
　诸佛所行境，　　于中无有数，
　正觉远离数，　　此是佛真法。
　如来光普照，　　灭除众暗冥，
　是光非有照，　　亦复非无照。
　于法无所著，　　无念亦无染，
　无住无处所，　　不坏于法性。
　此中无有二，　　亦复无有一，
　大智善见者，　　如理巧安住。
　无中无有二，　　无二亦复无，
　三界一切空，　　是则诸佛见。
　凡夫无觉解，　　佛令住正法，
　诸法无所住，　　悟此见自身。
　非身而说身，　　非起而现起，
　无身亦无见，　　是佛无上身。
　如是实慧说，　　诸佛妙法性，
　若闻此法者，　　当得清净眼。”
- **译文**：*“无上的大菩萨，远离了众生之想，没有谁能超过他，所以号称为‘无上’。诸佛所证得的境界，是无作、无分别的，粗大的相没有，微细的相也同样没有。诸佛所行的境界，其中没有数量的概念，正觉的佛远离了数量，这就是佛的真实之法。如来的光明普照，灭除所有黑暗，但这光明并非实有能照，也并非没有能照。对于法无所执着，无所忆念也无所染污，无所安住也无有处所，但不破坏法的本性。这其中没有‘二’，也没有‘一’，有大智慧、善于观察的人，能如理地善巧安住。在‘无’之中没有‘二’，在‘无二’之中也没有‘无’，三界一切都是空的，这就是诸佛的知见。凡夫没有觉悟和理解，佛让他们安住于正法，了知诸法无所住，觉悟这一点就能见到自身的法身。不是身而说身，不是生起而显现为生起，没有身也没有见，这就是佛的无上之身。如同真实慧菩萨所说，这就是诸佛妙法的本性，如果听闻此法的人，应当能得到清净的法眼。”*
- **问题**：译文将「无二亦复无」解作「在‘无二’之中也没有‘无’」，与原文并列结构不符。原句承「无中无有二」而来，意为「无二」这一概念本身也同样不可得，译文义理相反。
- **修改建议**：改为：「在‘无’之中并没有‘二’，而‘无二’本身也同样不可得。」或「‘无’中没有‘二’，连‘无二’也不存在。」
