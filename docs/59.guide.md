# 大方广佛华严经卷第五十九 导读

## 一、内容总览

本卷为《离世间品》第三十八之七，是离世间品的收束部分。前几卷广明菩萨行位因果，本卷则以「最后身菩萨从处胎到涅槃的示现」为线索，把菩萨八相成道（处胎、降生、微笑、七步、童子、王宫、出家、苦行、诣道场、坐道场、降魔、成佛力、转法轮、种白净法、般涅槃）的每一相都列出「十种事」，构成一组「菩萨示现事相门」。卷末普贤菩萨以长颂总摄菩萨无量功德行，并归结于「应发金刚心，学此功德行」，为离世间品作大收束。整卷主旨是：菩萨一切行门皆为调伏众生而示现，依如说修行疾成菩提。

## 二、结构层次

全卷按「菩萨八相示现 → 如来十力 → 转法轮 → 涅槃 → 普贤总颂」一线推进：

- **处胎与降生门（P3–P5）**：先列「示现处胎十事」→ 接「甚微细趣十事」（处胎中即示现发心乃至涅槃）→ 再列「十种生」（正念正知、放大光明、震动佛刹等），由处胎而降生。
- **幼年与出家门（P6–P11）**：微笑自誓十事 → 行七步十事 → 处童子地十事 → 处王宫十事 → 出家十事 → 苦行十事，依次衔接幼年相至苦行相，每段皆以「为调伏众生故如是示现」收束。
- **成道门（P12–P16）**：往诣道场十事 → 坐道场十事 → 坐道场十种奇特未曾有事 → 示现降魔十义 → 成如来力十事，由行向证，从外凡入圣位。
- **转法轮与涅槃门（P17–P19）**：转法轮十事 → 转法轮时于众生心种白净法十事 → 示般涅槃十义，明佛事已毕应入涅槃之因缘。
- **法门总名与流通（P20–P21）**：结名「菩萨广大清净行」，劝如说修行；十方诸佛现身赞叹普贤，共持此经令未来菩萨得闻。
- **普贤总颂（P22–P23）**：普贤承佛神力说长颂，以莲华、法树、师子王、商主、法王、转轮王、大梵王、自在天、须弥山、金刚、密云、法日、智月、迦楼罗等喻，广赞菩萨功德行；末以「应发金刚心，学此功德行」收束全品。

## 三、关键结论

1. 菩萨处胎乃至涅槃一切示现，皆为调伏劣解众生、成熟眷属善根，非为己身，处处点明「为调伏众生故如是示现」。
2. 甚微细趣揭示一相即摄一切相：在母胎中即示现发心、灌顶、成佛、转法轮、般涅槃，显示菩萨行门相即相入、一念该劫的华严境界。
3. 如来十力与转法轮十事，明成佛后业用：具足四无畏、四辩、四谛、无碍解脱，言音普周十方，于阿僧祇劫说法不断。
4. 示般涅槃十义，反复申明「一切行无常、一切有为非安隐、涅槃究竟坚牢」，导众生舍色身愿住净法身。
5. 全品归结于「如说修行」：若不如说行则永离菩提；此法门名菩萨广大清净行，应尊重听受诵持思惟愿乐修行。

## 四、易混辨析

- **菩萨摩诃萨 vs 菩萨**：本卷统称「菩萨摩诃萨」，指大心菩萨、地上大菩萨，特指最后身菩萨；单称「菩萨」则泛指发心行者。摩诃萨意为「大有情」，强调心量大、愿行胜。
- **微细趣 vs 微细**：「甚微细趣」是本卷专有法门名，指处胎中即示现一切菩萨行与如来自在神力的差别门，非寻常所谓细密；末云「得如来无上大智慧微细趣」为果德。
- **如来、应、正等觉**：为佛十号之三，常连用。「如来」谓乘真如道来成正觉；「应」即应供，堪受天人供养；「正等觉」谓正遍知，于一切法无不知。
- **灌顶地 vs 灌顶**：灌顶地为十地之第十法云地，菩萨将成正觉时受职之位；本卷「诸佛与灌顶」「受诸灌顶法」指最后身菩萨于十地满心受佛灌顶，授成佛记。

## 五、阅读提示

读本卷可抓住两条线索：一是「八相示现」之事相推进（每相皆十事，注意「为……故示现」的句式），二是卷末长颂以喻摄行（莲华、法树、师子王、商主、转轮王等），由喻见德。通读时留心「调伏众生」四字在每段末反复出现，为本卷之眼。
