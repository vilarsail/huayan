# 大方广佛华严经卷第十八 导读

## 一、内容总览

本卷《明法品第十八》位于《华严经》十地品之后，承接前卷十地修证之果，进一步阐明菩萨在十地基础上「令法明了」的修行次第。全卷由精进慧菩萨起问、法慧菩萨作答，以偈颂收束，主旨是：菩萨已发一切智心、已入菩萨正位之后，云何修习令诸如来欢喜、速入诸地、所行清净、大愿圆满、得大藏、为众生说法、绍隆三宝，乃至成为大法师、护持正法。整卷是一份由「因行」到「果德」、由「自利」到「利他」的菩萨进修纲领。

## 二、结构层次

全卷以「问→答→颂」三段组织，答文层层递进，是典型的「十法」枚举式展开：

- **起问（P3-P7）**：精进慧菩萨白法慧菩萨 → 先陈已发心者所具功德，再问「云何修习令诸如来欢喜……善根方便皆悉不虚」 → 复颂其义，立全卷总纲。
- **总许少说（P9）**：法慧菩萨赞其「同于如来」之问 → 承佛威神，许说少分 → 定下「谛听、善思」的闻法轨则。
- **不放逸与清净（P10-P11）**：先说「住十种法名不放逸」 → 由不放逸「得十种清净」 → 从根本戒行递进到禅定智慧，这是修行的根基层。
- **令佛欢喜与速入诸地（P12-P15）**：两重「十法令诸佛欢喜」（一约行相、一约安住） → 「十法令速入诸地」 → 「初住地时应善观察」 → 由随顺法而入地，含「自心是法、而无所著」之要义。
- **行清净与愿圆满（P16-P20）**：「十法行清净」 → 「十种增胜法」 → 「十种清净愿」 → 「十法令大愿圆满」 → 「满足愿时得十无尽藏」 → 行—愿—藏层层升进，是修行果德的递增层。
- **随应说法与净诸波罗蜜（P21-P22）**：以「知其所作、因缘、心行、欲乐」为说法前提 → 对治贪瞋痴等分别说 → 自修习中次第净檀、尸、忍、精进、禅、般若、方便、愿、力、智十波罗蜜 → 由利他回摄自利，是「利他即自利」的关键层。
- **度生与绍隆三宝（P23-P24）**：依众生界（恶道、难中、多贪、多瞋、着见、欲色无色界、二乘、大乘）随类度脱 → 以四组「复次」阐明令佛、法、僧种不断 → 回向一切智门，三业无瑕玷 → 由修行扩及僧宝住持。
- **十庄严与大法师果德（P25-P28）**：「念念具足十种庄严」 → 善见药譬喻众生见者烦恼悉除 → 勤修此法次第成就诸行 → 于无边世界为大法师、护持法藏 → 十种「自在」与十种「成就」收束全卷果德 → 「欲以难问令其退屈，无有是处」作结。
- **重颂与结劝（P29-P31）**：法慧菩萨承佛神力以偈重宣 → 「进止安徐如象王，勇猛无畏犹师子，不动如山智如海，亦如大雨除众热」 → 如来欢喜，大众奉行。

## 三、关键结论

1. 菩萨修行以「不放逸」为根本：住十种不放逸法，方得十种清净，方令诸佛欢喜——这是由戒定慧三学的总入口。
2. 修行次第由「行清净→愿圆满→得无尽藏」三阶递进：行满则愿成，愿成则藏显，藏显则能为众生说法。
3. 净诸波罗蜜皆以「无所著」为相：檀以「内外悉舍而无所著」净，乃至般若以「永得休息」净——离相即净。
4. 绍隆三宝即菩萨本业：令佛、法、僧种永不断绝，是菩萨「所行皆回向一切智门」的具体落处。
5. 菩萨成就已，能为大法师：以十种自在巧说深法，一音演畅令众欢喜，唯除如来及胜愿智菩萨，余无能胜——明法行满即等如来。

## 四、易混辨析

- **不放逸 vs 勤精进**：不放逸侧重「守护防非」（护戒、净心、离凡夫、离二乘），偏于防护；精进侧重「勤修不息、勇猛不退」，偏于发趣。文中先说不放逸，后由不放逸「发大精进」，是防护而后发动的次第。
- **十波罗蜜 vs 六波罗蜜**：六度为檀、尸、忍、精进、禅、般若；十波罗蜜于六度外加方便、愿、力、智四度，对应后得位菩萨利他行。本卷于P22一处列尽十波罗蜜，是华严广说的特色。
- **无尽藏 vs 十地**：十地是菩萨位次之升进，无尽藏是菩萨福智圆满后所显之德用藏。前者约阶位，后者约德用，二者相摄而非相同。
- **法慧菩萨 vs 精进慧菩萨**：法慧菩萨为说法主（答者），精进慧菩萨为请法主（问者），二菩萨名号即含「法」与「精进」互为助成的表法义。

## 五、阅读提示

读本卷宜把握「十法」枚举的递进逻辑：每一段「十法」不是并列罗列，而是由前一层的果推到下一层的因，或由前一层的因开出下一层的果。带着「不放逸如何展开为清净、清净如何展开为令佛欢喜、令佛欢喜如何展开为速入诸地」的问题去读，便能见出全卷并非清单堆叠，而是一线贯穿的修行图谱。
