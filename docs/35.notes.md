# 大方广佛华严经卷第三十五 词语注释

〔1〕 实叉难陀　于阗国三藏法师，本经的译者。三藏指精通经、律、论；「奉制译」谓奉皇帝诏命翻译。
〔2〕 十地品　本经第二十六品，专讲菩萨修行的十个阶位（十地）。本卷为品中第二部分，含第二离垢地与第三发光地。
〔3〕 踊住　踊（yǒng），跳跃。众菩萨欢喜踊跃，跳起身停在虚空中散花赞叹。
〔4〕 金刚藏　说十地法门的菩萨，藏有深智如金刚能断疑惑，故于此会受解脱月等请而演说诸地行相。
〔5〕 解脱月菩萨　此会中的当机菩萨，代表大众请问金刚藏，是十地品的发问者。
〔6〕 行相　修行时的相状、相貌。此处指第二地菩萨所行的种种法门之相。
〔7〕 尔时　就在那时。佛经承接前文、引出下文的固定发端语。
〔8〕 十种深心　华严以「十种X」并列展开义理：菩萨每入一地之前，先起十种心作为入地的因。读法是抓住每条心的名目即可，本卷第二地起正直心等十心，第三地起清净心等十心。
〔9〕 何等为十　「是哪十种呢？」自问自答、引出列举的固定句式，下文「所谓」即逐条列出。
〔10〕 顾恋　眷恋贪着。「无顾恋心」即不贪恋自己的身体、财物、名利。
〔11〕 离垢地　菩萨十地中的第二地之名。初地以上渐离烦恼垢染，此地特重持戒，离犯戒之垢，故称离垢地。
〔12〕 性自远离　谓菩萨本性自然远离杀盗等恶，并非因畏惧戒条才不做；因杀生等属「性戒」，其事本身即恶，不待佛制。
〔13〕 不畜刀杖　畜（xù），收藏、蓄养。不收藏刀杖等杀生器具。
〔14〕 不与不取　主人不给予，就绝不拿取。凡物不经给予而取即为盗，连一草一叶也如此，极言持戒之细。
〔15〕 非道　指不正当的淫行（如非适当的对象、时间、部位），是邪淫中最重者，故经文说「况于非道」。
〔16〕 毒害语　此下经文列举种种恶口之言（粗犷语、苦他语等十几项），是并列枚举，读法抓住「所谓」起头与末尾「皆悉舍离」作总结即可。粗犷（guǎng），粗鲁凶暴。
〔17〕 筹量　筹量（chóu liáng），思量衡量。「随时筹量决定语」谓说话随时审度时机、内容确定不乱。
〔18〕 十善业道　十种善业：身三（不杀、不盗、不邪淫）、口四（不妄语、不两舌、不恶口、不绮语）、意三（不贪、不瞋、不邪见）。反面即十不善业道，是堕落三恶道之因。
〔19〕 何以故　「为什么呢？」自设问答、引出理由的固定句式。
〔20〕 无有是处　没有这种道理，即不可能。谓自己不修正行而想教他人修，是办不到的。
〔21〕 有顶处　有顶，即无色界最高的非想非非想天，三界之顶。谓上品十善能感人天乃至三界最高处的果报。
〔22〕 声闻乘　听闻佛的言教而悟道、求个人解脱的教法。此处谓上品十善配合狭劣心与怖畏三界之心，只成就声闻果。
〔23〕 独觉乘　即辟支佛乘。不从他教、自己觉悟因缘之理而得道，但因大悲方便不具足，仍属小乘。
〔24〕 十力　佛具有的十种智力（知是处非处、知业报等）。与「四无畏」（佛说法时四种无所畏惧的自信）并举，皆佛果功德。
〔25〕 上者地狱因　十不善业按造作轻重分上、中、下三品，上品堕地狱、中品堕畜生、下品堕饿鬼；与前文上品十善感人天果正相对应。
〔26〕 二种果报　本段逐一列举十种恶业各得两种人身中的余报，是并列枚举，读法抓「一者……二者……」的格式，每条先说堕三恶道、再说生人中所得。
〔27〕 共财　财物须与他人共有、不能自主，是偷盗业的余报。
〔28〕 法园苑　园苑（yuàn），帝王游憩的园林。菩萨以十善道为佛法的园林，自安住其中，也劝众生入住。
〔29〕 大师心　菩萨对众生所生的十种心之一，谓自任为众生大师、负起引导之责的心，与前面自己心、师心层层递进。
〔30〕 稠林　茂密的森林，比喻烦恼邪见交错丛生、难以走出，如「恶道稠林」「愚痴稠林」「烦恼稠林」。
〔31〕 邪命　不正当的谋生方式，如谄媚欺诈、占相吉凶以求利。相对于八正道中的「正命」。
〔32〕 正命　八正道之一，以正当的方法维持生活。此处谓令众生住于清净的身语意业与正命之中。
〔33〕 三毒　贪、瞋、痴三种根本烦恼，毒害众生善根，故称三毒。
〔34〕 出要　出离生死的要道。谓众生不知寻求出离的方便法门，把不是出要之道当成出要之道。
〔35〕 涅槃　梵语音译，意译圆寂、灭度。烦恼与生死之火灭尽后所证的寂静安乐之境。
〔36〕 重闇　闇同「暗」。重（chóng）闇即重重昏暗，喻极深的愚痴。
〔37〕 阴翳　翳（yì），遮蔽。阴翳谓阴影障蔽，喻愚痴覆盖心眼，故下文说「失智慧光明」。
〔38〕 洄澓　澓（fú），水流回旋。洄澓谓众生在生死中如水回流打转，出不来。
〔39〕 欲觉　觉，念头、寻思。欲觉、恚觉、害觉即贪欲、瞋恚、恼害三种恶念，与下文欲流等同为缠缚众生之心。
〔40〕 身见罗刹　身见，执着五蕴身为实我的恶见；罗刹，食人恶鬼。谓身见如罗刹，在生死中执取众生，将其拖入爱欲密林。
〔41〕 我慢原阜　阜（fù），土山。我慢如高原土丘，众生住于其上；下句「安六处聚落」谓以六根为村落安居，都是喻众生安处烦恼而不觉。
〔42〕 三有　欲有、色有、无色有，即三界生死轮回的代称。
〔43〕 蕴窟宅　五蕴如窟宅，众生执着身心为家宅，在其中不求出离。下文四大毒蛇、五蕴怨贼皆喻此身此心反为害人之物。
〔44〕 空聚　无人居住的空村落，喻六处（六根）之中并无实我实法，看似有主其实空无所有。
〔45〕 四颠倒　把无常、苦、无我、不净的世间，颠倒执着为常、乐、我、净四种妄见。
〔46〕 四大毒蛇　地、水、火、风四大元素和合成身，如四条毒蛇同居一箧、互相侵恼，故以毒蛇为喻。
〔47〕 那由他　古印度巨大数词，通常指千亿或亿亿，泛言极多。
〔48〕 承事　承奉侍奉。谓对佛恭敬尊重、亲自服侍供养。
〔49〕 悉以奉施　悉，全部。谓衣服饮食等一切资生之物全都拿来供奉布施。
〔50〕 阿耨多罗三藐三菩提　梵语音译，意译无上正等正觉，即佛所证的觉悟。谓把善根回向于此，作为成佛之因。
〔51〕 悭嫉　悭（qiān），吝啬。悭嫉即吝啬与嫉妒，是布施、持戒二度的违品，远离之则二度清净。
〔52〕 矾石　矾（fán）石，矿物，古时用来煎炼黄金去杂。喻菩萨住离垢地，如真金提炼后更加明净。
〔53〕 四摄法　布施、爱语、利行、同事四种摄受众生的方法。本卷说二地以爱语偏多、三地以利行偏多，余者随力而修。
〔54〕 十波罗蜜　即十度：布施、持戒、忍辱、精进、禅定、般若、方便、愿、力、智，菩萨到彼岸的十种行门。各随地偏重一门，如二地持戒偏多、三地忍辱偏多。
〔55〕 随力随分　随自己的力量与本分而行。「余非不行，但随力随分」谓其余诸度并非不修，只是程度未到偏重而已。
〔56〕 转轮圣王　统一四天下的圣王，即位时有轮宝自然出现，故称转轮王。二地菩萨多现此身教化众生行十善。
〔57〕 七宝　转轮圣王所具的七种宝：轮宝、象宝、马宝、珠宝、女宝、主藏臣宝、主兵臣宝。具足七宝为王，是其福德自在之相。
〔58〕 周给　周济供给。「为大施主，周给无尽」谓普施众生、供给不竭。
〔59〕 一切智智　佛果圆满的智慧，智中之智；与「一切种」（一切种智，遍知一切法总相别相之智）连用，皆指佛智。
〔60〕 一念顷　一念之间，极短的时间。谓菩萨于如此短的时间内即得千三昧、现千种神变。
〔61〕 三昧　梵语音译，意译正定、正受。二地菩萨一念顷得千三昧、见千佛，三地得百千三昧，皆是入地功德。
〔62〕 无义语　没有意义的杂秽之言，即绮语。颂文以「妄恶乖离无义语」概括妄语、恶口、两舌、绮语四种口业。
〔63〕 烧然　然同「燃」。「饿鬼烧然出猛焰」谓饿鬼身常如火烧、口出猛焰，是饥渴火逼之相。
〔64〕 顶天　即有顶天，三界最高处（非想非非想天）。谓十善之果能感人中受生乃至得顶天的禅定之乐。
〔65〕 笼槛　槛（jiàn），圈兽的栅栏。笼槛即牢笼，「生死笼槛怨所拘」谓众生被生死牢笼所拘、为怨家（烦恼魔）所困。
〔66〕 四流　欲流、有流、见流、无明流，四种使众生漂溺生死的烦恼洪流，故以「漂荡」「没溺」为喻。
〔67〕 焚如　如，形容词词尾，「……的样子」。焚如即烈火燃烧的样子，喻三界之苦如被焚烧。
〔68〕 计蕴为宅　计，妄计、执着。谓众生妄执五蕴为家宅、为自我，安住其中而不求出离，与长行「于诸蕴窟宅不求出离」同义。
〔69〕 靡不　靡（mǐ），无、没有。「靡不恭敬」谓没有不恭敬的，即全都恭敬。
〔70〕 散华　华同「花」。散华谓散布鲜花于空中以为供养。
〔71〕 愍念　愍（mǐn），同「悯」。愍念即怜悯顾念。
〔72〕 律仪　戒律仪则，防非止恶的轨则。颂中赞金刚藏善说智者所应持的戒行之法。
〔73〕 希具阐　希，希望；具，完全地；阐，阐述。谓希望金刚藏把第三地的境界完全阐述出来。
〔74〕 大仙　佛的尊称。佛是仙人中之最大、最胜者，故颂文以大仙代指佛及其施戒等清净行。
〔75〕 大士　菩萨的尊称，义为大道心众生。「无畏大士金刚藏」即称金刚藏菩萨。
〔76〕 有为法　因缘造作、有生灭变化的一切法。第三地菩萨观有为法无常、苦、不净，从而厌离有为、趣向佛智。
〔77〕 前际　际，时间的端点。前际指过去，后际指未来，现在不住——谓一切法不来不去、当下无住，故说刹那生灭。
〔78〕 十种哀愍心　菩萨见众生种种苦而生的十种怜愍，并列枚举，读法抓每条「见诸众生……生哀愍心」的首句。
〔79〕 善法欲　对善法的希求心、好乐心。「无善法欲」谓众生不想修善，故菩萨生哀愍。
〔80〕 无障碍解脱智　此处开始层层推求：欲度众生住涅槃，不离无障碍解脱智；此智不离一切法如实觉，不离无行无生行慧光，不离禅善巧决定观察智，最终不离善巧多闻——说明闻法修禅是度生智慧的根本。
〔81〕 无行无生行慧光　难解语：既无造作之行、又无生灭之相，而能照了诸法的智慧光明，即观诸法不生不灭所发的慧光。
〔82〕 难遭想　难得遭遇之想。谓对能说佛法的人生起百千万劫难遭遇的敬重心。
〔83〕 内外财　外财指国城、妻子、珍宝等身外之物；内财指头目、髓脑、身命等自身所有。菩萨为求佛法两者皆能舍。
〔84〕 相与　给予你。「当以相与」谓（若你敢入火坑）我当把这句佛法给你。
〔85〕 空闲处　寂静无人之处，即阿兰若。菩萨得闻法后在此摄心思维修习。
〔86〕 发光地　菩萨十地中的第三地之名。成就禅定与闻慧，智慧光明发生，净极光通达，故称发光地。
〔87〕 离欲恶不善法　初禅生起的条件：离欲界之欲、离诸恶与不善法。下文有觉有观、离生喜乐是初禅的相状。
〔88〕 有觉有观　觉（寻）是粗的心思，观（伺）是细的分别。初禅尚有寻伺，二禅即「灭觉观」，只以内净一心生定，是四禅由粗到细的次第。
〔89〕 舍念清净　第四禅的相状：舍受（不苦不乐）与念都清净分明。前文「断乐先除，苦喜忧灭」即谓第四禅先断乐受、苦喜忧悉灭。
〔90〕 虚空无边处　四无色定的第一定。超越一切色想而缘无边虚空；下文识无边处、无所有处、非有想非无想处依次更高，合四禅称八定。
〔91〕 非有想非无想处　无色界的最高定，又称有顶天。想心不似有色界之明显有、也不像无想之全无，故名非有想非无想。
〔92〕 心随于慈　心与慈相应。慈、悲、喜、舍是四无量心，能缘无量众生、遍法界一切处，故下文说悲、喜、舍「亦复如是」。
〔93〕 跏趺　跏趺（jiā fū），结跏趺坐，即盘腿而坐。此处谓神通飞行，于虚空中盘坐如飞鸟。
〔94〕 扪摸　扪（mén），按、摸。谓以神通之力，连日月这样的天体能用手触摸。
〔95〕 梵世　梵天世界，指初禅诸天。谓神足通所及，身体的自在乃至梵天境界。
〔96〕 蚊蚋　蚋（ruì），吸血的小虫；虻（méng）亦同类大蝇。谓天耳清净，连蚊虻之声都听得见，极言其细。
〔97〕 他心智　能如实了知他人心念的神通。下文列举有贪心、离贪心等种种心相，皆是此通所知，读法抓「有X心、离X心」的对举格式。
〔98〕 宿命　宿命通，能忆知自己及他人过去世种种事的神通。下文念知一生乃至无量百千生，即此通的展开。
〔99〕 三摩钵底　梵语音译，意译等至，禅定的通名。谓菩萨于诸禅定能入能出，得自在而不执着。
〔100〕 不随其力受生　谓不同于凡夫外道随禅定之力（感果）而受生于定境诸天，菩萨只随愿力、为满菩提分处而受生，故下颂说「不随其力而受生」。
〔101〕 菩提分处　菩提分法，即顺向觉悟能圆满菩提的法门（如三十七道品）。谓菩萨不随禅定势力受生定境，而以愿力随能圆满菩提分处之处受生。
〔102〕 见缚　缚，烦恼的系缚。见缚指身见等见惑（观念上的迷惑），在十烦恼中最先断除；下文欲缚、色缚、有缚、无明缚是其余种种系缚。
〔103〕 不积集　不再积集。谓三地菩萨于无量劫中不积集邪贪、邪瞋、邪痴等烦恼业习，故旧习断尽、善根愈明，如真金再炼而分量不减。
〔104〕 称两　称量斤两。「称两不减」谓真金善炼而不失分量，喻菩萨断惑之后功德不减、更转明净。
〔105〕 譣诐　譣诐（xiǎn bì），邪佞不正。「无譣诐心」是此地菩萨诸心之一，谓心地正直无邪曲。
〔106〕 三十三天王　三十三天（忉利天）的天主，即帝释。三地菩萨多作此天王，方便令天众舍离贪欲。
〔107〕 财贝　贝是古代用作货币的贝壳，财贝即钱财珍宝。
〔108〕 孰能　孰（shú），谁、哪个。「孰能投身大火聚」谓有人试探说：谁敢跳入大火坑，我便给谁佛法。
〔109〕 初发意　初发菩提心、初起求佛道之意愿。「从初发意至得佛」谓从发心直至成佛的整个历程。
〔110〕 阿鼻　阿鼻地狱，意译无间地狱，堕入其中受苦无有间断，是地狱中最苦处。谓从初发心到成佛之间可能遭遇的一切极苦。
〔111〕 四禅无色定　四色界禅定加四无色定，合称八定。颂文总结上文第三地菩萨所成就的禅定次第。
〔112〕 四等五通　四等即四无量心（慈悲喜舍），五通即天眼、天耳、他心、宿命、神足五种神通。谓闻法思维之后，禅定神通依次生起。
〔113〕 忉利王　忉（dāo）利天之主，即帝释天，居须弥山顶，与三十三天王同指。
