# 大方广佛华严经卷第七十六 词语注释

① 法界　一切法之本源与所依，华严宗特重法界缘起，言「入法界门」「周流法界无所障碍」。
② 岚毗尼林　即蓝毗尼园，迦毗罗城外之林园，释迦如来降生之地。本卷为岚毗尼林神所居说法处。
③ 妙德神　即岚毗尼林神，本卷善财所参之善知识，为说菩萨受生藏法与受生自在解脱门。
④ 那由他　梵语，数量词，约当亿或更大之数，形容极多。本卷言「二十亿那由他诸天」围绕林神。
⑤ 生如来家　菩萨成就受生藏，得与诸如来共一体性、同一善根，住于佛家而不退转，为「生如来家」。
⑥ 阿耨多罗三藐三菩提　梵语，意为「无上正等正觉」，即佛所证之究竟果觉。善财自言已发此心而未知菩萨行。
⑦ 善男子　佛经中对在家或出家修行男子之尊称，本卷为林神对善财之称呼。
⑧ 受生藏　菩萨生如来家之十种因法，从「愿常供养诸佛」到「入如来地」共十门，成就此法即生如来家、增长善根。
⑨ 佛刹微尘数　华严常见量词，以一佛刹（一三千大千世界）碎为微尘之数，形容极多、不可计数。
⑩ 菩萨摩诃萨　「摩诃萨」意为「大」，即大菩萨，指已登地、行愿广大之菩萨，此处为神对善财之尊称与说法对象。
⑪ 回向　菩萨修习之一，将所修善根功德回向一切众生、一切智，愿同成佛果。第三受生藏言「回向一切智圆满道心」。
⑫ 三昧　梵语，意为「正定」，心一境性。本卷言「菩萨三昧海」「普门定」「普眼三昧」等。
⑬ 童真位　菩萨阶位之一，表清净无染如童子，第八受生藏所住，于此观一切智门、得菩萨三昧自在。
⑭ 毗卢遮那　梵语，意为「光明遍照」，华严宗奉为法身佛，即释迦如来之法身。本卷言「此世界摩耶夫人为毗卢遮那如来之母」。
⑮ 灌顶　古印度王子继位时以水灌顶之礼，佛教借指菩萨登十地、将继佛位之仪式，受灌顶法即受佛位传承。
⑯ 萨婆若　梵语，意同「一切智」，即佛之究竟智。颂中「久已修行萨婆若」即指久修一切智之道。
⑰ 阎浮提　南赡部洲之梵称，佛出世之洲，三千大千世界百亿阎浮提中皆有佛示现受生。
⑱ 兜率陀天　梵语，欲界第四天，菩萨下生人间前一生补处于此，世尊即从兜率降生阎浮提。
⑲ 夜叉　梵语，天龙八部之一，勇健鬼神，诞生时恭敬围绕散天华。
⑳ 乾闼婆　梵语，天龙八部之一，帝释之乐神，香神之类，菩萨诞生时云集供养。
㉑ 阿修罗　梵语，天龙八部之一，常与帝释战，此卷言其王舍憍慢稽首敬礼菩萨诞生。
㉒ 迦楼罗　梵语，即金翅鸟，天龙八部之一，以龙为食，诞生时垂宝缯幡遍满虚空。
㉓ 紧那罗　梵语，天龙八部之一，歌神，似人而头有角，诞生时欢喜瞻仰歌咏赞叹。
㉔ 摩睺罗伽　梵语，天龙八部之一，即大蟒神，诞生时皆生欢喜，歌咏赞叹，普雨宝云。
㉕ 毕洛叉树　岚毗尼园中摩耶夫人攀之诞菩萨之树，即无忧树类，菩萨从母胁诞生之处。
㉖ 摩耶夫人　释迦如来之生母，于岚毗尼园毕洛叉树下诞菩萨，身毛孔放光现十神变。
㉗ 迦毗罗城　释迦族所居之都城，摩耶夫人出此城入岚毗尼林诞菩萨，卷末指路之瞿波亦居此城。
㉘ 波罗蜜　梵语，意为「到彼岸」，菩萨六度（布施、持戒、忍辱、精进、禅定、般若）等究竟圆满之行。
㉙ 三千大千世界　一佛所化之境，百亿四天下、百亿阎浮提组成；本卷言菩萨诞生时光明普照三千大千世界。
㉚ 善知识　能引导众生发菩提心、修菩萨行之人，善财五十三参所访者皆为善知识，层层引荐。
㉛ 四天下　即一四天下，一小世界之四洲（东胜神、南赡部、西牛贺、北俱卢），百亿四天下即三千大千世界。
㉜ 十号具足　佛有十种尊号（如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛世尊），「十号具足」即圆满具此十号之佛。
㉝ 乳母　古印度王宫为太子设之哺育之人，林神往昔为乳母净光，承事初佛诞生即得普眼三昧。
㉞ 普眼三昧　菩萨所得之定，于此三昧中普见十方无量诸佛，林神往昔为乳母时即得此定。
㉟ 受生自在解脱　岚毗尼林神所证法门，于一念中普见十方微尘数刹海诸佛示现受生神变，念念不断。
㊱ 瞿波　迦毗罗城释种女，善财下一位参访之善知识，林神指路令善财诣彼请问菩萨云何于生死中教化众生。
