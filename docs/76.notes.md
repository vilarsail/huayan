# 大方广佛华严经卷第七十六 词语注释

① 摩耶夫人　释迦牟尼佛的生母，摩耶意为「大幻」。本卷善财所参的第一位善知识，善财尊称「大圣」。
② 观佛境界智　善财当下获得的观法：观见佛所证境界的智慧，为亲近摩耶夫人之准备。
③ 主城神　守护城池之神。本卷宝眼主城神于虚空中散华赞叹，教善财「心城」法门。
④ 心城　以城喻心。菩萨有十种心城法门：守护、庄严、净治、清凉等，谓净治自心如治城郭。
⑤ 如来十力　佛所具十种智力：处非处智力、业异熟智力、根胜劣智力等，唯佛能具。
⑥ 般若波罗蜜　意译「智慧到彼岸」。六波罗蜜之一，此卷中为心城照耀之法与四十二字母所入之门。
⑦ 身众神　从佛往昔行愿所生、具足无量色身眷属之神。莲华法德、妙华光明二神放光照善财顶。
⑧ 耳珰　耳饰。摩耶夫人耳珰放光，令善财见十方诸佛，得十种清净眼。
⑨ 离翳眼　翳，目障。十种眼之一，谓离目障之眼，能了知一切众生之性。
⑩ 刹海　刹，国土；海，言其多深。「观察一切刹海成坏」，谓观世界之成住坏空。
⑪ 罗刹鬼王　罗刹为暴恶之鬼，然守护菩萨法堂之罗刹鬼王善眼，劝善财求善知识、观身如梦——恶道众生亦能护法。
⑫ 十种三昧门　三昧即正定。成就十种三昧，则能常见诸善知识，不致错失。
⑬ 大宝莲华　善财受罗刹教后，感得从地涌出之大宝莲华，台上楼观能普纳十方法界，摩耶夫人于中现座。
⑭ 摩尼　摩尼宝珠，意译如意珠，能随愿出生诸物。
⑮ 普纳十方法界藏　楼观名。谓此一楼观能含纳十方法界，示华严「一摄一切」之相。
⑯ 阎浮檀金　阎浮提河中产之金，佛经中以为金之最美者。
⑰ 受生　菩萨乘愿示现入胎出生。摩耶夫人以愿力为一切受生菩萨之母。
⑱ 阎浮提　此世界（南赡部洲）之名，人类所居。
⑲ 阿耨多罗三藐三菩提　anuttarā-samyak-saṃbodhi 音译，意译无上正等正觉，佛所证之智。
⑳ 五欲　色、声、香、味、触五种感官欲乐。受生菩萨于五欲中自娱而实无染。
㉑ 般涅槃　parinirvāṇa 音译，圆满寂灭。谓佛示现灭度。
㉒ 兜率天　欲界第四天，候补佛（一生补处菩萨）所居。弥勒菩萨今居于此。
㉓ 降神　指菩萨从天下降、入母胎之事。释迦降神自兜率天，入摩耶夫人右胁。
㉔ 三十三天　即忉利天，欲界第二天，帝释所居，四方各有八天故称三十三。
㉕ 四天下　一须弥山四方四大洲，为一世界之单位；百亿四天下即三千大千世界。
㉖ 最后身菩萨　居候补佛位、此身之后即成佛之菩萨。
㉗ 贤劫　现在之大劫。此劫中将有千佛出世，释迦为第四佛，弥勒为第五佛。
㉘ 拘留孙佛　贤劫第一出世之佛（本卷列举贤劫诸佛之始）。
㉙ 弥勒菩萨　候补佛，今居兜率天，贤劫第五佛。本卷预言弥勒下生时摩耶亦为其母。
㉚ 净光　净光劫。摩耶夫人于此劫以道场神身发愿，愿为一切受生菩萨之母。
㉛ 转轮王　转轮圣王，具七宝、王四天下之圣王。净光劫大威德转轮王即毗卢遮那如来前生。
㉜ 恶魔　障碍菩萨成道之天魔。金色光恶魔率众扰乱道场，为转轮王化兵所退。
㉝ 天主光　三十三天天王之女，本卷善财所参的第二位善知识，得无碍念清净庄严解脱，能忆念恒河沙劫诸佛之事。
㉞ 恒河沙　恒河中沙，佛经习用之极多数。天主光历劫供养恒河沙数诸佛。
㉟ 僧伽蓝　saṃghārāma 音译，僧众所居之园，即寺院。
㊱ 字母　华严四十二字母。善知众艺童子唱持字母，每一字皆「入般若波罗蜜门」，为华严著名行法。
㊲ 摩竭提国　中印度之国，王舍城所在，佛陀成道说法之核心地。
㊳ 婆呾那　摩竭提国聚落中之城名，贤胜优婆夷所居。
㊴ 优婆夷　upāsikā 音译，意译近事女，受五戒之在家女居士。贤胜优婆夷得无依处道场解脱。
㊵ 无尽三昧　贤胜优婆夷所得之定，能出生一切智性眼耳鼻舌身意之无尽。
㊶ 婆罗门　brāhmaṇa 音译，印度四种姓之首，司祭祀学问者。最寂静婆罗门得诚愿语解脱。
㊷ 诚愿语　最寂静婆罗门所得解脱：言语必诚，愿无虚发，三世菩萨以此语故不退菩提。
㊸ 德生　妙意华门城童子，与有德童女同为善知识（次卷合说幻住解脱），指善财入弥勒楼阁。
