# 大方广佛华严经卷第三十八 词语注释

〔1〕 实叉难陀　于阗国三藏法师，八十卷本《华严经》的译者；「奉制译」谓奉皇帝之命翻译。
〔2〕 十地品　本经专讲菩萨修行十个阶位（十地）的一品；卷三十八为该品第五部分，含第八地后半与第九地全部。
〔3〕 无央　无央＝无量、无数；「无央大菩萨」谓数量无法计算的大菩萨。
〔4〕 两足尊　佛的尊号，谓福德与智慧两皆具足；上句「一切见者」谓佛正遍知、无所不见。
〔5〕 那由他　印度大数名，通常释为亿，此处泛指极多之数。
〔6〕 微尘数　以微尘计算数量，华严表极多的惯用说法；如「百万三千大千世界微尘数三昧」谓三昧多至如是微尘之数。
〔7〕 四洲　一小世界中的四大部洲（东胜身、南赡部、西牛货、北俱卢洲）。
〔8〕 铁围　铁围山，环绕世界的环形山，与须弥山同为世界安立之名。
〔9〕 迫隘　迫隘（ài）＝拥挤狭窄；颂谓一毛孔内容无量刹土而互不妨碍、不觉逼窄。
〔10〕 解脱月　十地法会中代表大众向金刚藏菩萨请问的菩萨，此处请说第八地行相。
〔11〕 金刚藏菩萨　本会说法之主，得金刚三昧，善说十地之法，故十地一品由其宣说。
〔12〕 助道　助道法＝资助正道现起之法，即三十七菩提分法等福智资粮；七地「善集助道法」为入八地之因。
〔13〕 无生法忍　忍＝安忍、确认不疑；于一切法本自不生之理忍可于心、智慧现前。七地满心得此忍，即入第八地。
〔14〕 不动地　第八地之名。无分别智任运不动、不为烦恼所动，故称不动。
〔15〕 深行菩萨　修行深妙、声闻与下地菩萨难以测知的菩萨；谓八地行相甚深、无差别相可得。
〔16〕 灭尽定　灭尽六识与受想的深定；比丘得心自在者次第入此定则一切动念悉息，喻八地舍一切功用行。
〔17〕 功用行　勉力造作之修行；八地「舍一切功用行，得无功用法」，与「相行」（有相分别之行）皆不现前。
〔18〕 念务　心念与造作营为；「念务皆息」谓身口意任运而行，不再作意勉力。
〔19〕 报行　依无漏果报任运而行；八地舍功用行后，唯住此报行。
〔20〕 四流　欲流、有流、见流、无明流，四种使众生漂泊生死的烦恼之流；下文梦中渡河喻即指救众生出四流而入八地。
〔21〕 梵世　初禅以上梵天世界；生梵世者欲界烦恼不复现起，喻八地一切心意识行皆不现前。
〔22〕 法流门　入于佛法之流（法流）的门径；八地菩萨将取证涅槃时，诸佛亲现其前授与如来智，令入此门、不舍众生。
〔23〕 觉观　觉＝粗略推求，观＝细心思察，即寻思分别；「种种觉观常相侵害」谓凡夫寻思烦恼相续不断。
〔24〕 适得　适＝刚刚、才；「适得」谓才证得。
〔25〕 法明　于法通达明了的智慧光明；「适得此一法明」谓八地菩萨刚证得「一切法无生无分别」一门，而如来法明无量，故不应止。
〔26〕 起智门　诸佛加持、令菩萨生起差别智的方便之门；若诸佛不与八地菩萨此起智门，彼即入究竟涅槃、弃舍利生事业。
〔27〕 阿僧祇　印度极大数名，义为「无央数」；此处与下「歌罗分」「优波尼沙陀分」连用，谓七地诸行较八地一念智业不及其极细一分。
〔28〕 歌罗分　梵语音译数名，指以算数析至极细之分；与下「优波尼沙陀分」皆为「百分不及一」递进式的比喻级差。
〔29〕 优波尼沙陀分　梵语音译数名，义为极少分、近于微少之一分；谓八地一念智业胜过七地所修至此等极细之分。
〔30〕 一切智智　佛智。「一切智」笼总知诸法，「一切智智」为智中之智，唯佛究竟；八地以无功用智趣入其境界。
〔31〕 观世间成　此下八地观世间成坏之智：世界由业集聚而成、业尽而坏，成住坏空各历几时，皆如实知；「几时成住、几时坏住」即成、住、异（坏）、空四阶段之历时。
〔32〕 微尘差别智　知一世界中地水火风、宝物、众生身、国土身各由若干微尘构成的智慧，为八地无功用智所起之一例。
〔33〕 刹利　刹帝利，古印度四姓之王族武士种姓；下文毗舍（农商）、首陀（仆役）亦四姓之一，谓菩萨随众生类别现同类之身。
〔34〕 四天王众　自四天王天经三十三天、夜摩、兜率陀、化乐至他化自在天为欲界六天，再加魔众、梵众；此长列谓菩萨于各趣各类众中现其同类之形。
〔35〕 阿迦尼吒天　色究竟天，色界最高处（有顶）；谓现形遍至自人间乃至色界之顶。
〔36〕 虚空身　此段列举菩萨所知十身——众生、国土、业报、声闻、独觉、菩萨、如来、智、法、虚空身；虚空身以无碍普遍为身，列于末位。
〔37〕 意生身　如来十身（菩提、愿、化、力持、相好庄严、威势、意生、福德、法、智身）之一，谓随意识所往而自在现身。
〔38〕 十自在　命、心、财、业、生、愿、解、如意、智、法十种自在；八地菩萨得此十自在，故为不思议智者等。
〔39〕 善住深心力　此下以「得善住……力」句式列举十种智力（深心、胜心、大悲、大慈、陀罗尼、辩才、神通、大愿、波罗蜜、如来护念），读法是抓每条「得……力」首句及其故。
〔40〕 沮坏　沮（jǔ）＝败坏；「无能沮坏」谓八地智体坚固不可破坏。
〔41〕 童真地　第八地的别名之一，谓离一切过失、如童子纯真；下文「不转地」「难得地」「生地」等十名并列，皆指此地。
〔42〕 阎浮提主　阎浮提即南赡部洲；阎浮提主谓统领此洲的圣王（转轮王），以顶上宝冠喻八地善根胜过一切二乘与七地。
〔43〕 二千世界　二千世界＝中千世界（一千个小千世界）；二千世界主大梵王光明遍照二千界，喻此地菩萨善根光明照彻幽暗。
〔44〕 随力随分　随自己的力量与分际而行；谓八地于余波罗蜜非不修习，只是不专增上。
〔45〕 主千世界　大梵天王统领一个（小）千世界；八地菩萨多示现此王身而说法。
〔46〕 爱语　布施、爱语（慈愍之言）、利行（利益之行）、同事（同其事而摄化）合称四摄法，菩萨摄受众生的四种方便。
〔47〕 灌顶　转轮圣王即位时以海水灌顶之礼；此处诸佛叹八地之忍「与灌顶」，谓堪受第十地法王之位。
〔48〕 法性真常离心念　偈颂承长行诸佛劝住之语：法性常住不异、离心念虑，二乘亦能证得，但诸佛不以此故名为世尊，而以甚深无碍之智；意劝菩萨勿滞守寂灭，当进修佛智。
〔49〕 曩众行　曩（nǎng）＝往昔；「曩众行」谓初地至七地往昔所修诸行，八地一念超越。
〔50〕 密迹金刚　即金刚密迹力士，手持金刚杵护持佛法之神；谓八地菩萨常为梵、释、四王与密迹金刚侍卫。
〔51〕 俱时踊在虚空住　踊＝涌，腾涌而起；谓诸菩萨同时涌身虚空中住，以过诸天之供供养佛。
〔52〕 大自在王　大自在天王（摩醯首罗天），色界之主；此偈谓其与诸天同来供养九地会上的佛。
〔53〕 善逝　佛十号之一，义为善往涅槃彼岸、不复退还生死。
〔54〕 谷响　山谷回声；颂谓菩萨音声心念悉灭而应机说法，如空谷传响，无问不应。
〔55〕 明利　聪敏锐利；「心明利乐辟支」谓心智明利者乐于辟支佛乘。
〔56〕 中乘道　中乘即缘觉（辟支佛）乘，处于声闻（小乘）与菩萨（大乘）之间，故名中乘。
〔57〕 幻师　魔术师；喻菩萨了知一切示现如幻师变作，虽现种种形相而实离有无二边。
〔58〕 善慧地　第九地之名。得法义辞乐说四无碍智、善巧说法，故名善慧。
〔59〕 无记　非善非恶、不可记别为善或恶的法；「善不善无记」三性并举，谓如实知众生一切法行。
〔60〕 稠林　稠密之林，喻众生心、烦恼、业、根、解等相续繁多如林；此下列举十一种稠林，读法抓每类首语（心、烦恼、业、根……）。
〔61〕 随眠　烦恼的别名；眠伏于识中、随缘现起，故名随眠。后文「诸随眠种种相」详列其相。
〔62〕 习气　烦恼现行断后残存的气分习惯；此段列举行、随趣、随业等十种熏习之相。
〔63〕 三聚　正定聚、邪定聚、不定聚，众生的三类；「众生悉在三聚中，或溺于见或行道」谓邪定者溺于恶见、正定者行于圣道。
〔64〕 八万四千　佛经惯用的极多数；谓烦恼、根、解、性、乐欲等各有八万四千差别相，言其无量，非实计数。
〔65〕 软中胜　软（下品）、中（中品）、胜（上品）三等；「知诸根软中胜相」谓知众生根机有上中下差别。
〔66〕 三摩钵底　梵语音译，义为「等至」，禅定的通名；谓随眠与禅定解脱三昧等相违，深伏难拔，唯圣道能出。
〔67〕 后有　未来世的果报之身；「业为田爱水润无明暗覆识为种子生后有芽相」以农事喻十二因缘受生：业为田，爱为水润，无明覆蔽，识为种子，生起来世（后有）之芽。
〔68〕 名色　五蕴总名：名＝受想行识四无色蕴，色＝四大色身；谓投胎之初名与色俱生、不相舍离。
〔69〕 五逆　弑父、弑母、弑阿罗汉、破和合僧、出佛身血五种极重罪；造五逆者入邪定聚，与下「八邪」（反于八正道之八邪行）并举。
〔70〕 四无碍辩　法无碍（知法自相）、义无碍（知诸法别相与义）、辞无碍（言辞无错谬）、乐说无碍（说法无尽）四种自在辩才，为九地菩萨所主；下文以多轮「复次」层层展开。
〔71〕 比智　比量推比而知之智；与「法智」（现量亲证）、「世智」（世间分别之智）、「第一义智」相对，谓四无碍智各依一种智而说。
〔72〕 受职菩萨　受职＝第十地法云地菩萨将绍佛位，如太子受职；谓九地菩萨说法座上，唯佛与受职菩萨威德光明可与其比。
〔73〕 依怙　怙（hù）＝依靠；「作所依怙」谓为一切众生之所依止与护佑。
〔74〕 翦　翦（jiǎn）同「剪」，剪除；「稠林未除翦」谓众生烦恼稠林尚未被剪除。
〔75〕 羁系　羁（jī）＝马络头，引申为束缚；谓随眠与心俱生、常相缠系不断绝。
〔76〕 金刚道灭　金刚道＝金刚喻定，成佛前最后一念之定，断尽最极微细惑习；此二句谓烦恼于禅定中被伏、出定仍退转，必至金刚道灭方毕竟断尽——答上句「但唯妄想非实物」的伏断问题。
〔77〕 根解　根＝根机（信进念定慧之利钝），解＝信解胜解；谓九地菩萨随众生根机与信解之别而说法。
〔78〕 师子　师子＝狮子；「处于法座如师子」喻九地菩萨登法座说法无所畏慑，又以牛王、宝山王、龙王连类设喻。
〔79〕 霔甘露雨　霔（zhù）＝灌注、降下；喻九地菩萨说法如龙王布密云、降甘露雨以充满法海。
〔80〕 尔所　尔所＝如此之多；「闻持尔所诸法门」谓受持如上所说无量法门。
〔81〕 诲诱　教诲诱导；「随机诲诱」谓九地为法王，随众生根机教导引诱而无厌倦。
