# 大方广佛华严经卷第五十七 导读

## 一、内容总览

本卷为《大方广佛华严经》第五十七卷，属「离世间品第三十八之五」，是普贤菩萨向「佛子」（菩萨摩诃萨）连续宣说的一系列「十种」法门。整卷以「菩萨摩诃萨有十种……」为基本句式，从内在习气、取著、修行，到外在道、足、手、腹、藏、心、被甲、器仗、首、眼、耳、鼻、舌、身、意、行、住、坐、卧、所住处、所行处、观察、普观察、奋迅、师子吼，层层铺陈菩萨从心念到身相、从内证到外用的全部庄严。其核心是说明菩萨如何于一切处不离世间而又出离世间，即「不离世间而证菩提」。

## 二、结构层次

全文以「内行 → 外相 → 受用 → 利他」四大块递进，每一块内部以「十种」并列枚举，每段末以「若诸菩萨安住此法，则得如来无上……」收束：

- **内行奠基（P3-P12）**：习气 → 取 → 修 → 成就佛法 → 退失佛法（应远离）→ 离生道 → 决定法 → 出生佛法道 → 大丈夫名号 → 道（一道至十力，最长一段，统摄三学六度七念八正道九次第定十力）。
  - 此段由「过患习气」入手，经「取、修」之主动积集，转入「离生、决定」之不退，终以「大丈夫名号」与「道」总括一切菩萨行。
- **无量庄严（P13-P17）**：无量道 → 无量助道 → 无量修道 → 庄严道。
  - 以虚空、法界、众生界、世界、劫数、语言、如来身、佛音声、佛力、一切智智「十无量」为量，说明菩萨道与如来境界等量；庄严道则特明「不离欲界而入色无色界定」「入邪道而不取为实」「示生恶趣而实不生」等染净不二之奇特行。
- **身相受用（P19-P38）**：足 → 手 → 腹 → 藏 → 心 → 被甲 → 器仗 → 首 → 眼 → 耳 → 鼻 → 舌 → 身 → 意 → 行 → 住 → 坐 → 卧 → 所住处 → 所行处。
  - 由下至上、由外至内、由动至静，将菩萨色身威仪全幅庄严化：足能遍至一切世界，手普覆十方，腹容受一切众生，眼见法界，耳闻十方音声如响，鼻知众生贪恚痴行，舌遍覆佛刹，身示现人天六道，意深入佛三昧；乃至行住坐卧皆为法门，所住处以慈悲喜舍为处，所行处以正念、智慧、波罗蜜为处。
- **观察利他（P39-P42）**：观察 → 普观察 → 奋迅 → 师子吼。
  - 由自证之「观察」转入度他之「普观察」，再以牛王、象王、龙王、金翅鸟王、师子王等「奋迅」喻菩萨威神，最后以十种「师子吼」总收——从「我当必定成正等觉」之菩提心吼，到「最后生菩萨」于王宫诞生、自行七步、唱「我于世间最胜第一」之究竟吼，归于成佛。

## 三、关键结论

1. 菩萨一切行门皆以「不离善知识、不离菩提心、不舍众生」为根本，离此即退失佛法。
2. 「离生道」非离世避俗，而是「超过三界而常在一切世界」「永离烦恼而与一切众生共居」，即出世而不离世。
3. 菩萨道以「无量」为量——虚空、法界、众生界、佛音声、一切智智无量，故菩萨道亦无量，与如来境界等量齐观。
4. 庄严道之极则在「染净不二」：入欲界禅定而不受彼生，入邪道而不取为实，示生地狱饿鬼而实不生，与诸佛同一法身而示求正法——善巧方便，随应示现。
5. 全卷以「师子吼」收束，从初发菩提心到最后生示现成佛，一线贯穿「因行—果证」的全幅菩萨生涯。

## 四、易混辨析

- **离生道 vs 离世间**：离生道指菩萨「出离世间生」之十种行持（出生般若、超过三界而常在世间等），是「行」；离世间是本品品名，统指整品所明菩萨出世不离世之境界，是「品」。
- **观察 vs 普观察**：观察侧重「自了」（知业、知趣、知根、知法、见佛法等十种自证智），普观察侧重「度他」（普观求者、犯戒者、害心者等，安置如来净戒忍力之中）。
- **一道至十力之道（P12）**：此处「一道、二道、三道……十力」之「道」非空间之路，而是以数字递增列菩萨道之十重——一即菩提心，二即智慧方便，三即三解脱门，四即忏悔随喜劝请回向，五即五根，六即六通，七即七念，八即八正道，九即九次第定，十即佛十力，层层升进。
- **被甲 vs 器仗**：被甲（大慈大悲大愿等十甲）侧重「自护、堪忍」，器仗（布施持戒智慧等十仗）侧重「摧破敌障」——一防护、一进攻，合则成菩萨二力。

## 五、阅读提示

本卷是典型的「十种」枚举体，初读易觉重复，实则每一组「十种」都对应菩萨道的一个层面。建议带着两个问题读：其一，菩萨如何「不离世间而证出世」？其二，从足至首、从眼至意，菩萨色身威仪如何全幅庄严化？抓住「安住此法，则得如来无上……」的收束句，即可把握每组法门的归结。
