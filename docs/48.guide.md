# 大方广佛华严经卷第四十八 导读

## 一、内容总览

本卷由普贤菩萨与佛（对机宝手菩萨）相继宣说，分二品：**如来十身相海品第三十四**（普贤菩萨告众，列举如来身上九十七种「大人相」之名义庄严）、**如来随好光明功德品第三十五**（佛告宝手菩萨，说如来随好「圆满王」所放光明，拔地狱众生令生兜率，复由天鼓演法，令诸天子忏悔业障、回向发心，获菩萨十地、肉眼清净）。前品广陈「相海」之境，后品深明「随好放光」之功，一境一用，相即不二。

## 二、结构层次（★重点）

本卷以「相海枚举 → 随好放光 → 天鼓化度 → 忏悔回向 → 肉眼清净」一线推进，由相起用、由用归德：

- **相海总起（普贤发问）**：普贤告诸菩萨「今当为汝演说如来所有相海」 → 顶上三十二大人相（眉间、眼、鼻、舌、齿、唇次第展开） → 颈、肩、胸臆（吉祥海云卐字相） → 右手、左手、手指、手掌 → 阴藏、臀、髀、伊尼延鹿王腨、宝腨上毛 → 足下、足上、足指间、足跟、足趺、足四周、足指端，共九十七相 → 收束「毗卢遮那如来有如是等十华藏世界海微尘数大人相」。
  - 每一相皆以「名：○○云 + 庄严 + 放光 + 普现」为式：先出相名，次说宝庄严，再说放光普照法界，末说光中普现诸佛、菩萨、刹土、说法度生，结构高度整饬。
- **随好放光（佛告宝手）**：如来有随好名「圆满王」 → 出大光明「炽盛」，七百万阿僧祇光明为眷属 → 引往事：菩萨于兜率天宫放「光幢王」照十佛刹微尘数世界 → 地狱众生遇光息苦，得十种清净眼乃至意根，命终生兜率。
- **天鼓演法**：天鼓名「甚可爱乐」 → 告诸天子「毗卢遮那菩萨入离垢三昧，汝当敬礼」 → 反复以「非十方来」喻明业报、音声、光明皆无来去 → 劝忏悔业、烦恼、报、见四障 → 诸天子问「云何悔除」 → 天鼓以「业不从十方来、无生无灭、如幻如镜」明真实忏悔 → 诸天子得无生法忍、发菩提心，天女舍女身发无上意。
- **回向与肉眼清净**：诸天子闻普贤广大回向 → 得十地、见百千亿那由他佛刹微尘数七宝莲华，一一华上有菩萨结跏趺坐放大光明 → 以华云香云供佛 → 身蒙香者业障消灭、譬如比丘入第四禅 → 见盖者种金网转轮王一恒河沙善根。
- **金网转轮王位与肉眼广大**：菩萨住清净金网转轮王位教化众生 → 引明镜世界月智如来本生为例 → 遇光者皆得菩萨第十地位、成就清净肉眼 → 以「亿那由他佛刹碎尘展转八十返」之喻显示肉眼所见广大无量 → 收束「皆清净金网转轮王甚深三昧福德善根之所成就」。

二品以「尔时普贤菩萨」「尔时世尊告宝手」二「尔时」分界：前品由菩萨说佛「相」，后品由佛自说「随好光明」之「用」，由境及用、由相及德。

## 三、关键结论

1. 如来大人相非止「三十二相」，而是「十华藏世界海微尘数大人相」；本品所列九十七相不过略示其端，每一相中皆现诸佛、菩萨、刹海，显示相海即法界，一相摄一切相。
2. 相、好、光、用四位一体：大人相出光明，光明普现诸佛说法；随好「圆满王」出「炽盛」光，光能拔地狱苦、令生兜率；相为体、光为用、化度为功，全卷以此「相—光—用」一贯为骨。
3. 业性本空、真实忏悔：天鼓反复以「非十方来、无生无灭、如幻如镜」明业之无来去；若如是知，是真实忏悔，一切罪恶悉得清净。此即华严「业果缘起而本性空寂」之旨。
4. 功德归趣于普贤行愿：诸天子闻「普贤广大回向」得十地、见莲华藏菩萨；肉眼清净之德亦归「清净金网转轮王甚深三昧福德善根」，为下卷〈普贤行品〉伏笔。

## 四、易混辨析

- **大人相 vs 随好**：大人相（lakṣaṇa）指佛身显著之大相，如顶、眉间、胸臆卐字等；随好（anuvyañjana）指随大人相而起之细好，如足下千辐轮相之旁、随好「圆满王」。本品大人相九十七，随好则于第三十五品方明，二者层次不同。
- **毗卢遮那 vs 卢舍那**：本卷「毗卢遮那如来」即华严所立法身佛，梵语 Vairocana，意为「遍一切处」；古译或作「卢舍那」，同体异译，不可与释迦牟尼之应身混同。
- **离垢三昧 vs 无依印三昧**：离垢三昧是毗卢遮那菩萨所入、能放光照地狱拔苦之三昧；无依印三昧是天鼓劝诸天子所入、悟色受想行识不生不灭之三昧。一为能化之根本三昧，一为所化之悟入三昧。
- **金网转轮王 vs 银铜铁轮王**：转轮王有金、银、铜、铁四等，清净金网转轮王位为最胜，乃菩萨位中所示现；菩萨住此位，肉眼清净、见八十返微尘数佛刹，非世间福报之轮王可比。

## 五、阅读提示

读本卷可带着两个问题：其一，普贤菩萨为何要如此密集地枚举九十七相、几乎每一相都以「云」为名？其二，天鼓所说法为何反复以「非十方来」为喻？前者提示相海即法界云海，后者提示业果本性空寂——把握此二层，则繁复的相名与天鼓的反复譬喻皆有其义，不必逐相记名。
