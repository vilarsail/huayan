# 大方广佛华严经卷第二十九 词语注释

① 十回向品　《华严经》品名，阐述菩萨十种回向行，本卷为第七回向。回向指将所修善根转趣菩提、普施众生。
② 菩萨摩诃萨　梵语 Bodhisattva-mahāsattva，意译「大菩萨」，指发大菩提心、修大行、证大果的菩萨，即登地以上之大士。
③ 等随顺一切众生回向　十回向之第七，谓菩萨以平等心将所积集善根随顺普施一切众生，无一遗漏，三轮体寂而回向菩提。
④ 善根　能生善法之根本，即身口意所修一切善行功德，如布施、持戒、精进等，能为菩提之因。
⑤ 微尘数　以微尘为喻之极数，形容数量微细难知、不可胜计，华严经中常以喻佛刹、众生、善根之多。
⑥ 阿僧祇　梵语 asaṃkhyeya，意为「无数」「无央数」，佛教极大数词，表不可计数之多。
⑦ 善知识　能引导众生舍恶修善、趣向菩提之师友，华严特重亲近善知识为菩萨道根本。
⑧ 三昧　梵语 samādhi，意译正定，心一境性，菩萨住不动三昧等，能起神通智用。
⑨ 堪忍心　能忍受诸苦、逆缘而不动之心，菩萨度生忍辱所成就，亦为忍波罗蜜之德。
⑩ 恶趣门　趣即趣向，恶趣门指通向地狱、饿鬼、畜生三恶道之业门，菩萨修善根即闭此门。
⑪ 菩提心　上求佛道、下化众生之大心，为菩萨行之根本，本卷明一切善根皆菩提心所积集发起。
⑫ 一切种智　佛智之一，能通达一切道相、一切种相之智，唯佛究竟，菩萨发愿趣求。
⑬ 如来十力　佛所具足之十种智力，如处非处智力、业报智力、定智力等，唯佛穷尽，菩萨分证。
⑭ 惠施　即布施，以财物身命乃至善根普施众生，「惠」有恩惠、普施之意。
⑮ 七支具足　指象之七肢体（四足、鼻、牙、尾等）完备端正，喻宝象形体殊妙圆满。
⑯ 龙马王　传说中具大神通之宝马，能涉水如履地、腾空而行，喻宝马之神骏超胜。
⑰ 不放逸心　于善法专精修习、不稍放荡之心，为一切善法之根本，三十七道品所重。
⑱ 自在王位　即转轮圣王或自在天王之王位，菩萨为度生亦能舍之，示「内财外财悉舍」之极。
⑲ 法界　梵语 dharmadhātu，一切法所依之界，华严宗特重法界缘起，谓事相虽殊，理体无二。
⑳ 一弹指顷　弹指一响之极短时间，约一刹那之几分，喻时间之短暂，菩萨即此刹那亦不生疲倦心。
㉑ 无寿者心　不执有实命者、受者之心，与无著、无缚等并列，明三轮体空之施心。
㉒ 白净法　即清净善法，以「白」表善净无染，对治黑恶业，菩萨圆满白净法力。
㉓ 尸波罗蜜　即持戒波罗蜜，梵语 śīla-pāramitā，菩萨三聚净戒，摄律仪、摄善法、饶益有情。
㉔ 波罗蜜　梵语 pāramitā，意译「到彼岸」，谓修此行能从生死此岸到达涅槃彼岸，有六波罗蜜等。
㉕ 精进波罗蜜　梵语 vīrya-pāramitā，于善法勇悍不退，菩萨尽未来劫常无懈怠。
㉖ 般若波罗蜜　梵语 prajñā-pāramitā，智慧到彼岸，了达一切法无体性、自性空，为六度之导。
㉗ 六十种音声　佛所具足之六十种殊胜妙音，如迦陵频伽、深远等，菩萨发愿令众生同得此妙音。
㉘ 师子吼　梵语 siṃhanāda，喻佛菩萨说法无畏，如狮子吼震慑群兽，降伏魔外、安立众生。
㉙ 陀罗尼　梵语 dhāraṇī，意译总持，能摄持无量法义令不散失，菩萨得之能演说妙法无尽。
㉚ 不可说不可说　华严极大数之名，表数量至极、非言说所能及，常以喻世界、佛刹、善根之重重无尽。
㉛ 那由他众生　以那由他喻众生数量之极多，菩萨念念令此无量众生清净成就。
㉜ 业道　身口意所造之业，引众生趣向善恶诸道，名「业道」，与业、报相待而立。
㉝ 法性　梵语 dharmatā，诸法本然之理体，一切法同此一性，本卷明法性与法相不相违。
㉞ 离欲际　断除贪欲之究竟境界，即涅槃离染之实际，与众生安住平等不相违。
㉟ 魔怨　障碍修道之魔与怨敌，含烦恼魔、五阴魔、死魔、天魔等，菩萨成就回向则能摧灭之。
㊱ 金刚幢菩萨　本卷说法之菩萨，承佛神力说十回向品，「金刚幢」表其智慧坚固高显，能摧伏魔怨。
㊲ 两足尊　佛之尊号，谓福、慧两种庄严皆悉圆满具足，于两足众生中最为尊上。
㊳ 调御士　梵语 puruṣadamyaśārathi，佛十号之一，喻佛如善御者，能调伏众生心性令趣善道。
㊴ 业报　身口意所造善恶业，必招感相应果报，纵了知诸法空，业报因果亦不失，为华严空有不二义。
