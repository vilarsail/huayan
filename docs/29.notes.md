# 大方广佛华严经卷第二十九 词语注释

〔1〕 于阗国　古西域佛教王国（今新疆和田一带），大乘经典东传的重要中转地。本卷即由此国高僧实叉难陀译出。
〔2〕 实叉难陀　意译「学喜」，唐代于阗国三藏法师，八十卷《华严经》（新译）的译者。「三藏」指精通经、律、论三藏。
〔3〕 十回向品　八十华严中阐明菩萨十种回向行的一品；本卷属其中第七「等随顺一切众生回向」的后半。
〔4〕 云何　佛经问语，「如何、为什么」；此处「云何为……回向」是自问自答、引出本节主题的固定句式。
〔5〕 菩萨摩诃萨　摩诃萨意为「大有情、大心众生」，指发大愿求佛道的大菩萨，经中常用作菩萨的尊称。
〔6〕 等随顺一切众生回向　十回向之第七。「等」谓平等，「随顺」谓随顺众生根性；以一切善根平等回向一切众生，令同趣佛果。
〔7〕 善根　修行中培养的善法功能，如根能生枝叶，能引生善果；本卷说一切善根悉以回向众生。
〔8〕 所谓　列举提示语，义为「即是下面所说的」，经中用于引出长清单。
〔9〕 小善根　自此句至「普覆育一切世间善根」，是三十余种善根的并列枚举；读法是逐条各看一名目即可，不必深究相互层次。
〔10〕 微尘数　以微尘（极细的尘粒）计数，喻多到不可胜数。
〔11〕 阿僧祇　梵语 asaṃkhya 音译，意为「无数」，华严经中表示极广大数目的惯用语。
〔12〕 善知识　教人善道的良师益友，能引导众生趋向菩提者。
〔13〕 方便善巧　随机应变、灵活教化的智慧手段，与般若实智相对而为菩萨二智之一。
〔14〕 堪忍　堪能忍耐，即忍辱；「得堪忍心」谓忍受一切而不动，下文「堪忍波罗蜜」即忍辱度。
〔15〕 三昧　梵语 samādhi 音译，意译「正定」，心专注一境而不散乱的禅定状态。
〔16〕 恶趣　指地狱、饿鬼、畜生等恶道；「闭恶趣门」谓善根回向能杜绝堕入恶道的门径。
〔17〕 诸根　指眼、耳、鼻、舌、身、意六根；「善摄诸根」谓收摄六根不令放逸。
〔18〕 威仪　行住坐卧的规矩仪则，谓举止合于律仪。
〔19〕 法器　原指法事用具，喻堪能承受佛法的根器；「堪为一切诸佛法器」谓此菩萨堪作受法之器。
〔20〕 福德良田　田能生谷，喻众生于此种植善根即得福报，如农夫耕于良田。
〔21〕 等三世佛　谓心行与过去、现在、未来三世诸佛平等相同。
〔22〕 悉　全、都，副词，经中高频虚词，常作「悉以」「悉令」「悉能」。
〔23〕 生如来家　以菩提心、般若为母出生于佛家，谓入佛门、绍继佛种。
〔24〕 种性　本指种族血统，佛教借喻修行者内在的成佛资质；「净佛种性」谓清净成佛的种姓。
〔25〕 咸　皆、都，副词，与「悉」「皆」同义，如「咸令清净」。
〔26〕 菩提心　「菩提」意为觉悟；求无上正觉之心，是大乘修行的根本发心。
〔27〕 一切种智　佛所具的遍知一切法总相别相的圆满智慧，别于菩萨的道种智。
〔28〕 如来十力　佛所具的十种无碍智力（知处非处、知业报、知诸根、知种种界等），此处谓善根皆为成就十力而修。
〔29〕 尽未来劫　劫为极大的时段；「尽未来劫」谓直到未来终穷，即永无休止之意。
〔30〕 惠施　即布施，「惠」作动词谓施人以恩惠，古汉语用法。
〔31〕 阿僧祇世界珍宝充满　自此句起，以「愿令阿僧祇世界××充满」的同一句式并列约十种布施之物（衣服、妙香、庄严具……宝冠），读法是抓每条末尾的物名。
〔32〕 摩尼宝　梵语 maṇi 音译，意译「如意宝珠」，传说能随意愿出财宝、放光明。
〔33〕 上味　最上等的滋味，指供奉饮食中的至味。
〔34〕 中悔心　中途后悔之心；「无中悔心」谓布施自始至终不生退悔。
〔35〕 热恼心　烦躁苦恼之心，谓布施时因悭吝不舍而生的焦灼不安。
〔36〕 一切智智　一切智中之一切智，是佛智的加强称呼，表智慧圆满无上。
〔37〕 七支具足　谓宝象身相完好，七处（四肢、头、鼻等）悉皆具足；下文「调顺」谓性情柔顺驯服，是相好象王的描述。
〔38〕 龙马王　如龙一样神骏的马中之王，喻宝马的至胜。
〔39〕 妓女　古义指能「敷奏种种妙音」的歌舞乐伎，非后世俗称，此处作为布施之物列举。
〔40〕 不放逸　勤勉警策、不放纵懈怠的心理状态，根本善所之一；「起不放逸心而用布施」谓舍己头时心无懈怠。
〔41〕 顾恋　顾惜贪恋；「心无顾恋」谓施自身血肉骨髓而不恋着己身。
〔42〕 奴仆作使　仆从与供差遣使唤之人；古译经中常列为布施之物，读者勿以今义苛责。
〔43〕 法界　一切法的总称，又指万法的真实体性；「尽虚空遍法界」谓遍及一切存在的全部领域。
〔44〕 无间息　无有间断停息；「无间」谓相续不断。
〔45〕 一弹指顷　弹指之间，极短的瞬间，形容刹那、须臾。
〔46〕 无寿者心　不执著有真实寿命者（我体）之心；「寿者」为《金刚经》「我、人、众生、寿者」四相之一。
〔47〕 愿一切众生财宝丰足　此段连发十条「愿一切众生……」的愿文，是善根回向众生的具体内容；后文「愿一切众生究竟安隐」等十愿同此读法。
〔48〕 安隐　即「安稳」，古译惯用「隐」字，谓安泰稳固、无所忧怖。
〔49〕 为令一切众生得利益安乐故　自此句至本段末，是近百条「为令一切众生……故」的超长排比，每条皆为菩萨以善根回向所发的一个别愿；读法是抓每条「令众生」后面的动宾短语，不必逐条深究。
〔50〕 资生之物　资养生活之物，即衣食财货等一切生资；卷末偈中作「资生具」。
〔51〕 白净法　又单称「白法」，指清净无漏的善法，以白喻纯净，与黑（染污）法相对。
〔52〕 尸波罗蜜　「尸」为梵语 śīla（戒）音译之略，尸波罗蜜即持戒到彼岸，六度之二。
〔53〕 般若波罗蜜　般若（梵语 prajñā）即智慧，般若波罗蜜即智慧到彼岸；「知一切法无体性」正是般若观空之义。
〔54〕 相好　三十二相、八十种好，佛身显著的相与微细的好，果德庄严之相。
〔55〕 六十种音声　谓佛音声具六十种殊妙功德（清彻、深远、无邪、易了等），是佛果音声之相；此处愿众生得之，「发言诚谛」谓言语真实可信。
〔56〕 诚谛　诚实真谛，谓言语真实无妄、可信受。
〔57〕 师子吼　师子即狮子；佛说法无所怖畏，如狮子吼慑伏百兽，喻无畏说法。
〔58〕 法轮　以轮喻佛法；「转法轮」谓说法能碾摧烦恼、辗转流通，「不退转无尽法轮」谓说法永不退失穷尽。
〔59〕 承事　承奉侍奉，谓亲近诸佛菩萨而供养服务。
〔60〕 出兴　出现兴起于世，谓佛或菩萨出现世间、兴行教化。
〔61〕 灌其顶　即「灌顶」，以水灌于头顶，本是古印度王子受位的仪式，佛教借喻佛为法王子授记受职。
〔62〕 诸有　指三有、二十五有，即生死轮回中的一切存在状态；「于诸有中最尊胜」谓在三界众生中最为尊贵。
〔63〕 悭嫉　悭吝与嫉妒，正是回向布施所对治的两种烦恼。
〔64〕 翳浊　翳（yì）为遮蔽眼目之物；翳浊谓如翳膜般障蔽心性的污浊烦恼。
〔65〕 谄曲　谄媚邪曲，心不正直；与下文「质直柔软」相反。
〔66〕 含识　具有心识的一切有情众生，「有情」的异名。
〔67〕 大智眼　观照诸法的智慧，喻如眼之能见；「以大智眼观诸善根」谓以智慧观照所修善根之性。
〔68〕 愿一切众生究竟安隐　自「究竟安隐」至「具足十力调伏众生」十条并列愿文，「究竟」贯穿各条，谓令众生达于彻底的安稳、清净、解脱等。
〔69〕 陀罗尼　梵语 dhāraṇī 音译，意译「总持」，能持善法不散、遮恶法不起的忆念慧力；「得陀罗尼演说妙法」谓说法无尽而忆持不失。
〔70〕 那由他　梵语 nayuta 音译，古代大数之名（一说万亿），表极多。
〔71〕 住无所得　安住于「无所得」的般若空慧，谓于一切法无所执取、无有能得所得。
〔72〕 一切佛刹平等清净　自此句起十条「一切……平等清净」，列举此回向成就所感的平等清净果境；读法抓每条起头的所清净对象。
〔73〕 众生不违一切刹　自此句起一大段「甲不违乙」的连环排比（刹与众生、思与心、业与报、法性与法相、三世、佛与世间等），「不违」即不相违背、相即不二，表万法互融、事事无碍；读法是每句抓两个对举名词，义为「彼此互不妨碍」。
〔74〕 刹众生　「刹」即刹土、佛国世界；「刹众生」谓依刹土而住的众生，与下文「业」「心」「思」「境界」等为对举概念。
〔75〕 思不违心　「思」（梵语 cetanā）指造作并推动身口意的意志作用（心所之一）；此句谓思与心互不相违，句式见「众生不违一切刹」条。
〔76〕 离欲际　离欲的实际边际，指远离烦恼欲的寂灭境地；谓其平等性与一切众生安住平等不相违背。
〔77〕 得业平等　自此句起连用十余个「得……平等」，再续十多个「得……」句，皆谓成就此回向所获的果德；读法抓「得」字后的宾语。
〔78〕 魔怨　魔是修行者的怨敌，指烦恼魔、天魔等；「摧灭一切魔怨」谓破除种种魔障。
〔79〕 欲刺　欲望烦恼如刺在身；「拔诸欲刺」谓除去贪欲之害。
〔80〕 出离乐　出离生死烦恼所得之乐，与世间五欲之乐相对。
〔81〕 无二性　无有分别二边的体性，谓住于不二的中道实相。
〔82〕 神足　神足通，六神通之一，能飞行自在、变现往还；「神足无碍」谓往诣一切佛刹无有障碍。
〔83〕 寂灭处　涅槃寂静之处，指寂灭烦恼生死的境地。
〔84〕 慧眼　五眼之一，能照见真空之理、观众生心行、观诸法无相的智慧之眼。
〔85〕 尔时　「正当那时」，佛经承上启下惯用的时间连接语，此处引出长行之后的说颂。
〔86〕 金刚幢菩萨　本卷末说颂者。「幢」是庄严高显的旌旗之物，金刚幢喻愿行坚固高显；此菩萨承佛威力代佛宣偈。
〔87〕 承佛神力　谓仰仗佛的威神加持而说法，是经中菩萨说法的固定用语，表非自力所宣。
〔88〕 香象　香气殊胜的巨象，象中之王，力大而性柔顺，古译经中常列为贵重布施之物。
〔89〕 两足尊　佛的尊号，谓福足与慧足两皆圆满，为天人之中最尊。
〔90〕 常于诸法不作二　此偈阐明「二」与「不二」俱遣：于诸法既不执为二（对立分别），也不执为不二，二者并离；下句「亦复不作于不二」承上省略「常于诸法」，读颂时宜补足。
〔91〕 语言道　言语概念之路；「二」与「不二」皆只是言说施设、不可执为实法，即「言语道断」之意。
〔92〕 调御士　又作调御丈夫，佛十号之一，谓能调伏驾驭一切众生如调良马者。
〔93〕 庶品　众庶品类，此处泛指一切众生；「愿令庶品同如来」谓愿众生皆同于佛。
〔94〕 正位　正性定聚之位，指圣者所证不退的阶位；「入于正位分别尽」谓证入此位则虚妄分别灭尽。
〔95〕 如来法化生　谓真佛子从佛的教法教化中出生，以法为身故，非由父母胞胎所生。
