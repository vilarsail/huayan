# 大方广佛华严经卷第七十九 导读

## 一、内容总览

本卷属《入法界品第三十九》第二十分，承接上卷善财童子诣弥勒菩萨，是「入楼阁」一节的高潮，也是整部善财五十三参行将收束前的关键转折。本卷主旨：善财由弥勒威神力加持，入毗卢遮那庄严藏楼阁，于一处中普见一切处，亲历弥勒菩萨历劫修行、处处化身、诸佛国土等不可思议自在境界；继而弥勒弹指摄神力，告以「法性如是，如幻如梦」，点破一切庄严皆因缘聚集、自性空寂。最后弥勒自述来处、阐释菩萨十种生处与菩萨种性尊胜，并遣善财往诣文殊师利——五十三参至此由文殊启程、由文殊收束，圆满呼应。

## 二、结构层次

全文以「入阁见境 → 摄破显理 → 释生处 → 指归文殊」四段推进，由事入理、由理发行：

- **入阁见境（P3-P42）**：善财请开楼门 → 弥勒弹指开门、入已还闭 → 见楼阁广博如虚空、阿僧祇庄严具周遍 → 善财才始稽首，由弥勒威神自见其身遍在一切楼阁中。此为大段，内分三层递进：
  - **弥勒本生行化**（P8-P14）：见弥勒初发心、证慈心三昧、修波罗蜜、得忍住地、为转轮王及诸天王、为梵王阿修罗王，处处现身说法救度三恶道——横向铺展「一身无量身」。
  - **菩萨神变与法音**（P15-P26）：见菩萨身云出种种身、出妙音赞一切法门；闻某处某菩萨修何行、某如来成何法——纵向铺展「一音无量法」。
  - **宝镜宝柱华果琉璃**（P23-P32）：以楼阁中一一庄严物为镜，照见净不净世界、诸佛道场、半身色像、曩劫舍身布施——收束「一物无量相」。
- **六重梦喻广显**（P36-P42）：以睡梦、命终业相、鬼持、龙持、梵宫、遍处定、乾闼婆城、幻师等比喻，层层显明「以幻智力见诸法」之理，将前文事相归约为「如幻如梦」。
- **摄破显理（P43-P50）**：弥勒摄神力、弹指告善财起，明示「法性如是，因缘聚集所现之相，如幻如梦如影如像，悉不成就」→ 问答解脱门名（「入三世一切境界不忘念智庄严藏」）→ 答庄严事去处（「于来处去」「无所从来亦无所去」），以龙王降雨、幻师作幻二喻收束。
- **释生处与菩萨种性（P51-P62）**：善财问弥勒从何处来 → 弥勒先以「菩萨无来无去如是而来」总答，复以「大悲、大慈、净戒、大愿、神通、无动摇、无取舍、智慧方便、示现变化」九处展开；复说菩萨十种生处（菩提心、深心、诸地、大愿、大悲、如理观察、大乘、教化众生、智慧方便、修行一切法）与菩萨以般若为母、方便为父等家族喻；末明弥勒生于阎浮提摩罗提国拘吒聚落婆罗门家之因缘。
- **指归文殊（P63-P67）**：弥勒遣善财往诣文殊师利 → 盛赞文殊愿行广大、为诸佛母菩萨师、与善财往昔同生同行 → 「汝先所见诸善知识闻菩萨行入解脱门满足大愿，皆是文殊威神之力」——善财顶礼辞退。

## 三、关键结论

1. 一切入处即一切处，一念即无量劫：善财才始稽首，便自见其身遍在一切楼阁，此即「一即一切、一切即一」法界互摄的实证。
2. 一切庄严皆是因缘聚集所现之相，自性空寂：弥勒摄神力后明示「如幻、如梦、如影、如像，悉不成就」，将前文重重庄严归结为性空缘起。
3. 菩萨以般若为母、方便为父，生于如来家：菩萨种性不在血统而在法，十种生处皆以菩提心、深心、大愿、大悲为根本。
4. 五十三参始终归于文殊：善财历参诸善知识，皆文殊威神之力所贯穿，文殊是「入普贤行门」之关键，参学终点指向普贤行。

## 四、易混辨析

- **弥勒菩萨 vs 一生菩萨**：弥勒即此生补处菩萨（一生补处，将下生阎浮提成佛），「一生菩萨」即一生所系已灌顶者，文中兜率天「一生菩萨功德」即指弥勒本人及其同类补处菩萨。
- **灌顶地 vs 灌顶**：灌顶地指十地满心将成正觉之位；「法水灌顶一生所系」即受灌顶已、一生补处、此生即佛。二者皆邻近佛果，但灌顶地是「位」，灌顶是「事」。
- **无生法忍 vs 无生忍**：文中「得无生忍」「生无生法忍家」即同一法相，指证诸法无生之理而安忍不动，是登地菩萨所证。
- **遍处定 vs 遍处**：遍处（十遍处）是禅观所缘（地水火风青黄赤白等十种周遍），遍处定是依之所入之禅定；文中「比丘入遍处定」是喻，喻善财入楼阁如入定中境界现前。

## 五、阅读提示

读此卷宜先观「楼阁如虚空」一段之重重铺排，留意「于一处中见一切处」如何由事相层层推至「如幻如梦」之理；再看弥勒答「来处」时九个「从……处来」的排比，体会菩萨「无来无去如是而来」的大悲起用。末后文殊一段是整部善财参学收束之伏笔，当与前参文殊处对读。
