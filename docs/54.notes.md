# 大方广佛华严经卷第五十四 词语注释

① 菩萨摩诃萨　即「菩萨中的大菩萨」，指已发大菩提心、行大乘行之圣者。本卷所列十法皆就菩萨摩诃萨而言。
② 大欣慰　菩萨于发心供养、护法、度生等事心生大欢喜慰藉。本卷首列十种大欣慰，由随逐诸佛、远离五畏、令众生成菩提等心行引发。
③ 不活畏　五畏之一，指未发心者忧惧不能存活之怖畏。菩萨一发菩提心即远离此等五畏。
④ 恶名畏　五畏之一，惧恶名声流传之畏。
⑤ 死畏　五畏之一，惧死亡之畏。
⑥ 堕恶道畏　五畏之一，惧命终堕入地狱、饿鬼、畜生等恶趣之畏。
⑦ 大众威德畏　五畏之一，于大众中畏惧自身威德不足之畏，亦称处众畏。
⑧ 舍利　佛茶毗后所得之坚固子及灵骨，建塔供养。菩萨发心于诸佛涅槃后起无量塔供养舍利。
⑨ 优昙华　即优昙钵罗花，三千年一开，喻佛出世难值难遇。菩萨以愿力于未来世欲见如来则便得见。
⑩ 等正觉　梵语三藐三菩提之意译，亦译正等正觉，即诸佛所证无上正遍知。菩萨发愿当来成等正觉。
⑪ 法界　本卷高频法相，指一切法所依之真如理体，亦指重重无尽之诸法相即相入之境界。菩萨以本大愿周遍法界。
⑫ 声闻　闻佛声教而悟道之圣者，修四谛以求入涅槃。
⑬ 独觉　亦名缘觉、辟支佛，无佛世时自悟十二因缘而解脱之圣者。
⑭ 波罗蜜　梵语，意译到彼岸，指菩萨所修六度（施、戒、忍、进、禅、慧）等究竟之行。本卷「深入一切波罗蜜」「满足一切诸波罗蜜」等处皆用此词。
⑮ 乾闼婆　天龙八部之一，即寻香神，帝释之乐神。
⑯ 阿修罗　天龙八部之一，旧译无端正，常与帝释战斗之鬼神类。
⑰ 迦楼罗　天龙八部之一，即金翅鸟，以龙为食。
⑱ 紧那罗　天龙八部之一，即人非人，亦帝释之乐神，似人而头有角。
⑲ 摩睺罗伽　天龙八部之一，即大蟒神。
⑳ 二乘　声闻乘与独觉乘之合称，以其但求自了、趣入涅槃，不及菩萨之大悲广行，故菩萨须离二乘地。
㉑ 阿耨多罗三藐三菩提　梵语，意译无上正等正觉，为佛所证之究竟智。本卷多见，亦简作「阿耨多罗三藐菩提」「阿ou多罗三藐三菩提」（原文本有形讹，即此梵语之略）。
㉒ 法轮　佛所说法，能转众生烦恼而趣涅槃，故以轮喻之。菩萨乐转法轮摧灭异道。
㉓ 实际　真如之异名，指诸法究竟真实之理地。菩萨虽观实际而以愿未满故不取证。
㉔ 善知识　能引导众生舍恶修善、趣向佛道之良师益友。菩萨虽知一切法不由他悟，而不舍离诸善知识。
㉕ 三昧　梵语三昧提，意译正定，即心一境性之禅定。本卷列十种入三昧，于一念中入一切菩萨三昧智。
㉖ 六波罗蜜　布施、持戒、忍辱、精进、禅定、般若六种究竟行，为菩萨所修六度。
㉗ 四摄事　布施、爱语、利行、同事四种摄受众生之法。
㉘ 三十七菩提分法　即三十七道品：四念处、四正勤、四如意足、五根、五力、七觉支、八正道，为趣菩提之分。
㉙ 四无所畏　佛所具四种无畏：一切智无畏、漏尽无畏、说障道无畏、说尽苦道无畏。本卷列于园林法中。
㉚ 十八不共　即十八不共佛法，唯佛独具、不与二乘共之十八种功德法。
㉛ 十善业道　不杀、不盗、不淫、不妄语、不两舌、不恶口、不绮语、不贪、不嗔、不痴十善行，为生欲界天之福德。
㉜ 四梵住　即慈、悲、喜、舍四无量心，以梵天为果，故名四梵住，亦名四无量心禅定。
㉝ 净居天　色界第四禅之五不还天，圣者所居，烦恼不染，亦名净梵天。
㉞ 无色界　三界之一，但有心识而无色身之众生所居，有空无边处等四处。菩萨为令众生离难处而生其中。
㉟ 灌顶　古印度立太子时以四海水浇顶之礼，喻佛为最后身菩萨授记成佛。本卷以「一切智王灌顶记」为菩萨宫殿。
㊱ 陀罗尼　梵语，意译总持，即持善不失、持恶不生之念慧力。菩萨乐陀罗尼以持法不忘转授众生。
㊲ 坏苦　三苦之一，乐受坏灭时所生之苦。
㊳ 行苦　三苦之一，一切有为法刹那生灭、迁流不安之苦。
㊴ 离生位　即见道位，初入圣流，离烦恼生之位。本卷第二印中菩萨住最胜道入离生位。
㊵ 五趣　天、人、畜生、饿鬼、地狱五道（不及阿修罗故为五），众生流转生死之处。
