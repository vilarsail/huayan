# 大方广佛华严经卷第五十四 词语注释

〔1〕 菩萨摩诃萨　梵 bodhisattva-mahāsattva，菩萨中的大菩萨，指德位高深的发大心者，本卷所说「十种 X」的主人公。
〔2〕 十种大欣慰　本卷离世间品以「十种 X」并列展开义理，这是第一组。读法：抓住每条「复作是念……如是思惟，心大欣慰」的首句即可，不必逐字细读。
〔3〕 所谓　文言提示词，相当于「就是下面这些」，用来引出清单的具体内容，后文多为逐条列举。
〔4〕 不活畏　五畏之首：怕活不下去（生计无着）的畏惧。与下文恶名畏、死畏、堕恶道畏、大众威德畏合称菩萨初发心前的五种怖畏，一发心即远离。
〔5〕 形寿　形体和寿命，即一生、尽其有生之年。
〔6〕 舍利　梵 śarīra 音译，佛灭后火化所得的遗骨，弟子起塔供奉。
〔7〕 遗法　佛涅槃后留存于世的教法，即经律论三藏，与「舍利」同为佛身后弟子护持的对象。
〔8〕 黑闇　「闇」同「暗」（àn），黑暗，喻无明烦恼。
〔9〕 安隐处　「安隐」即安稳，指没有恐怖苦恼的境界，此指佛道涅槃。
〔10〕 优昙华　梵 udumbara 音译，灵瑞花，三千年一开，喻佛出世极为难得难遇。
〔11〕 谄曲　谄媚曲折，心不正直；与下文「质直无伪」相对。
〔12〕 大师子吼　「师子」即狮子，佛说法无所畏惧、降伏一切，如狮子吼，喻正音宣流、群邪慑伏。
〔13〕 世界数　世界的数量；与下「世界行、世界说、世界清净」并列，指了知世界的多少、成住坏空的行相、名称说法与净秽之相。
〔14〕 独觉　梵 pratyekabuddha，义译缘觉、辟支佛，无佛之世独自观缘起而悟道者；与「声闻」合称二乘。
〔15〕 阿耨多罗三藐菩提　梵 anuttarā-samyak-saṃbodhi 音译，义为无上正等正觉，即佛果；此处省作「三藐菩提」，与常见的「阿耨多罗三藐三菩提」同义。
〔16〕 依止　依托依靠；此组十种依止指菩萨修行所凭借的十类基础，句式为「依止……，行菩萨行」。
〔17〕 波罗蜜　梵 pāramitā 音译，义为到彼岸，即从生死此岸度到涅槃彼岸的修行法门，常举六种（六度）。
〔18〕 无疑心　对佛法决定不疑的信心。本组十种每条以「发此心时，决定无疑；若生疑心，无有是处」收束，「无有是处」即绝无此理。
〔19〕 慈、悲、喜、舍　四无量心：慈予乐、悲拔苦、喜见众生得乐而喜、舍怨亲平等，是菩萨摄化众生的心行。
〔20〕 妄想颠倒　虚妄分别与四种颠倒（常乐我净之倒见），泛指一切错谬心行。
〔21〕 不由他悟　觉悟不从他人给予、不假外缘，自证自了；与后文「而不舍离诸善知识」并不矛盾——见性自悟，然修学仍须善友。
〔22〕 一念相应智　一念之间与真如实相相应的智慧，说明成觉悟在顿契，不落渐次言说。
〔23〕 降神　指佛示现从兜率天下降、神识入于母胎，是八相成道之始（八相：降神入胎、诞生、出家、苦行、降魔、成道、转法轮、入涅槃）。
〔24〕 般涅槃　梵 parinirvāṇa 音译，「般」义为入，即入于圆满寂灭，指佛示现灭度。
〔25〕 无相是相　疑难句：无相即是相、相即是无相（下文分别/无分别、有/非有、作/无作同例），说诸法相即不二、遮照同时，不可执一边解。
〔26〕 灭尽定　灭尽六识及其心所的深定，三果以上圣者所入；此处说菩萨念念能入而不因之取证实际。
〔27〕 实际　真如实际的略称，指涅槃穷极之境；「不证实际」谓菩萨为度众生不住涅槃。
〔28〕 十种巧密语　「巧密」谓善巧而深密、非浅智可测。本组列举菩萨于经中、受生处、神通变现等处的深密善巧之说。
〔29〕 或成或坏　世界或形成（成劫）或毁坏（坏劫）；「间无空处」谓虚空遍满世界，成坏相续没有空隙。
〔30〕 火灾　坏劫时坏灭世界的三灾（火、水、风）之一，火灾烧至初禅；菩萨于劫火中遍入无碍。
〔31〕 解脱门　通向解脱的门径，也指菩萨自在无碍的功德；此处十种皆以「周遍一切世界」为相。
〔32〕 佛刹　「刹」梵 kṣetra 音译之略，即佛国土、佛世界。
〔33〕 游戏神通　以神通力自在出入种种境界，如游戏然，毫无滞碍劳苦，是菩萨度生的自在于乐。
〔34〕 忆念宿命　即宿命通，能忆知自身及众生过去世种种事；下文天耳、他心、天眼等并列五通六通之名，此卷统称「方便智通」。
〔35〕 善巧智明　本卷「十种明」的「明」即智慧（梵 vidyā），善巧智明谓彻照事理的巧妙智慧，为每一条的结尾语。
〔36〕 戏论　无益于解脱的言说分别，佛教谓一切执着名言的虚妄议论为戏论。
〔37〕 所缘　心识所攀缘、所对的对象（境）；「所缘唯是一相悉不可得」谓众生所缘境界当体不可得。
〔38〕 何以故　文言疑问词「为什么缘故」，自设问答中的问语，用以引出下文解释。
〔39〕 缘起善巧智明　十明中最长的一条的名称：了知众生受生从因缘起、生本无生，故能知因知缘、随应教化；读时可抓「知因、知缘……知调伏」这一长串「知 X」排比的首尾。
〔40〕 一切种智　佛的智慧，通达总相别相一切法种种类别，与一切智（知总相）、道种智（知差别）合称三智。
〔41〕 诸取　种种执取，指欲取、见取、戒禁取、我语取等对境界的执着；「诸取解脱」即离一切执取。
〔42〕 蕴、界、处　五蕴、十八界、十二处，佛教对身心的三种分类（三科）；「蕴、界、处解脱」谓于此三科悉得自在。
〔43〕 无生法忍　忍可安住于诸法不生不灭之理的智慧，七地以上菩萨所得，不再退失。
〔44〕 六波罗蜜　六度：布施、持戒、忍辱、精进、禅定、智慧；下文四摄事（布施、爱语、利行、同事）、三十七菩提分法（四念处至八正道）皆菩萨行的纲要名目。
〔45〕 绍继　「绍」音 shào，继承；绍继慈父境界谓继承佛（慈父）的家业法藏。
〔46〕 十八不共　十八不共法，唯佛独有、不与二乘共的功德（身口意无失等）；与十力、四无所畏并列，皆佛果德门。
〔47〕 十善业道　不杀、不盗、不邪淫、不妄语等十种善业，是欲界人天及菩萨戒行的基本内容，故说以此教化欲界众生。
〔48〕 四梵住　即慈悲喜舍四无量心，为生色界梵天的禅定之因，故说以之教化色界众生。
〔49〕 净居天　色界四禅最高处的天（五净居天），唯三果以上圣者所生，烦恼不染。
〔50〕 轮王　转轮圣王，成就七宝、统治四天下的世间圣王；下「护世、释、梵」指护世四天王、帝释天、大梵天，均为菩萨示现调伏众生之位。
〔51〕 灌顶　原为印度太子即位时以四大海水灌顶的仪式，佛教借喻授记成佛、受法王之位，如「一切智王灌顶记」即受佛位之记别。
〔52〕 陀罗尼　梵 dhāraṇī 音译，义为总持，能持善法不失、遮恶法不起的记忆力与法门；「乐陀罗尼，持法不忘转授众生」正显其义。
〔53〕 异道　异学外道，指佛法以外的修道者及其教法；「摧灭一切异道法」即降伏外道邪见。
〔54〕 八万四千法聚　佛对治众生八万四千烦恼所说的法门总数，「法聚」即法门之类聚，极言教法之多，非实数。
〔55〕 弘誓　弘大誓愿，指菩萨所发四弘誓愿等广大誓约。
〔56〕 普贤行　普贤菩萨所代表的大行，周遍法界、无尽无尽的菩萨行，为华严宗行的总称。
〔57〕 不拣怨亲　「拣」音 jiǎn，拣择分别；不拣怨亲谓普度众生不分怨家亲人，平等摄受。
〔58〕 有根信　扎根深厚之信；与下文无浊信、清净信、离垢信、明彻信、不退转信等并列，是十一种信的排比，读法抓「信」字前的修饰语即可。
〔59〕 深大心　深广宏大之心；本组每条以「不舍……深大心」为式，谓十种永不弃舍的广大愿心。
〔60〕 大乘　梵 mahāyāna，运载众生同登佛果的广大教法，与声闻缘觉二乘相对。
〔61〕 梵行　清净离欲之行；「于一切佛所修行梵行、护持净戒」谓随佛修学戒行。
〔62〕 义门　义理的门类、入手处；「诸法义门」谓诸法所含义理的种种门径。
〔63〕 乖诤　「乖」音 guāi，违背抵触；乖诤即矛盾诤论，说一切法从缘起故无有乖诤。
〔64〕 金剛　「剛」为「刚」的异体，音 gāng，金刚即钻石、最坚利之物，喻诸法实相不可破坏。
〔65〕 如如　真如之境，法尔本然、不变不异；「皆悉如如」谓一切法当体即是真如平等之性。
〔66〕 律仪　戒律仪则，防非止恶的轨范；「菩萨律仪」即菩萨戒。
〔67〕 百福相　佛的三十二相，每一相须经百福（百种善业功德）庄严方能成就，故称三十二种百福相。
〔68〕 白净法　白净即洁白清净，指无漏善法；与黑（恶）业相对。
〔69〕 十种印　「印」谓印证、决定不移之义，如法印印定真实；本组十种皆菩萨决定不退的准则，每条以「是为第 X 印」收束。
〔70〕 苦苦　三苦之一：苦上加苦，指苦苦、坏苦（乐坏为苦）、行苦（迁流为苦）三种苦受，菩萨知此而专求佛法。
〔71〕 忍可　信受认可、安心承受；「深信忍可，解了趣入」谓闻深法能信能受、能解能入。
〔72〕 五趣　天、人、地狱、饿鬼、畜生五类流转之处（或说六趣加阿修罗），即众生轮回的五种去处。
〔73〕 齐限　「齐」同「限」，界限限量；「不以齐限测如来智」谓不可以有限尺度测量佛的无边智慧。
〔74〕 沮坏　「沮」音 jǔ，败坏；沮坏即毁坏、阻坏，谓行菩萨行不顾身命、无能毁坏。
〔75〕 智光照　智慧之光所照；本组十种皆以「……智光照」为式，谓以智慧照见种种法。
〔76〕 修多罗　梵 sūtra 音译，义译为经、契经，指佛所说的经典。
〔77〕 如来地　佛的果位、境界；「悉令安住如来地」谓教化众生令其趋向佛地。
〔78〕 无等住　无与等之住，菩萨独特超胜、声闻独觉不能等同的安住方式；每条以「是为第 X 无等住」收束。
〔79〕 作意　佛教心所名，警觉令心趣境的功用，此处即特意起心、发意去做；「然能作意，于不可说劫行菩萨行」谓虽离妄想仍发意久行。
〔80〕 三界唯心　欲界、色界、无色界一切法唯是心之所现；与「三世唯心」连用，是华严宗著名的唯心偈义，谓万法由心而不废心之无量无边。
