# 大方广佛华严经卷第三十九 导读

## 一、内容总览
本卷为《华严经·十地品》之末章，专讲第十地——法云地。前承第九地（善慧地）之问法，由解脱月菩萨启请，金刚藏菩萨广演菩萨从初地至十地的最高阶位：受职灌顶、莲华化生、放光灭苦、得诸三昧与解脱门、如实知种种界集与如来微细秘密、以大海喻受持佛法、以十山王喻十地次第、以大摩尼珠喻菩萨十事，终以颂偈重宣十地行相与功德。本品是整个十地品的收束，也是菩萨行向佛智过渡的关键阶位。

## 二、结构层次
全文按「天众供养赞叹 → 启请 → 正说十地（受职相、智用、比喻、功德） → 证成流通」一线推进：

- **天众供养与赞叹（P4–P31）**：净居天众、菩萨众、自在天王、天女等以香、华、天乐供养，并以颂偈赞佛身、毛孔光明、八相成道、法性寂灭而示现种种事业 → 为说法铺垫庄严缘起。
- **解脱月启请（P32–P35）**：众会寂静，解脱月菩萨代众请问「从第九地入十地所有功德、神通变化」 → 引出金刚藏正说。
- **正说受职相（P36–P42）**：先总标「得一切种、一切智智受职位」 → 次列百万阿僧祇三昧 → 大宝莲华出生、菩萨坐华座 → 十方放光灭六道苦、照诸乘果 → 诸佛眉间出光明灌顶、以转轮王太子灌顶为喻 → 结名「法云地」。
- **如实知诸法（P43）**：菩萨住此地如实知三界集、世界成坏、三乘行集、佛力无畏集等一切「集」 → 知化、持、微细智、秘密处、入劫智、入毛道微尘等智 → 显此地菩萨能入诸佛一切智慧。
- **得解脱门与受法喻（P44–P51）**：得十解脱为首的无量解脱门、三昧、陀罗尼、神通门 → 以娑伽罗龙王大雨唯大海能受为喻，明唯第十地菩萨能安受诸佛法明法雨 → 解脱月复问「一念能受几佛所法」，金刚藏以十方众生各得闻持陀罗尼作量而不及一分为答 → 结「法云」之名。
- **神通自在与示现（P51–P60）**：菩萨能狭广互作、一尘容世界、一毛孔现佛境界、一念示现成道乃至涅槃 → 众会生疑「佛复云何」 → 金刚藏入「一切佛国土体性三昧」，令大众皆见自身在其身内，见菩提树与一切智通王佛 → 明法云地菩萨身语意业不可测知，乃至九地不知。
- **佛智倍胜与喻说（P61–P68）**：以四天下取一块土、少许土为喻，明菩萨智比佛智如毫末对大地 → 以甘蔗竹苇稻麻丛林充满十方诸菩萨所修智慧比一佛智，百分不及一 → 譬金师作真金严具、摩醯首罗天王光明，明十地菩萨智光超胜九地 → 诸佛更为说三世智乃至一切智智，十波罗蜜中智波罗蜜增上 → 总结略说与广说不能尽。
- **十地总摄与三重比喻（P66–P70）**：以阿耨达池出四大河喻菩提心流出善根入一切智海 → 以大海中十山王喻十地差别：欢喜、离垢、发光、焰慧、难胜、现前、远行、不动、善慧、法云各配一山，各摄一类功德 → 以大海十相喻菩萨行十相 → 以大摩尼珠十性喻菩萨十事出过众圣 → 结「不种善根不得闻」。
- **闻法福德与流通（P70–P73）**：闻此法门福德等同一切智所集福德 → 佛神力故十方世界六种震动、雨华奏乐赞一切智地 → 十方金刚藏菩萨同名来证，文字句义无增减 → 全经十地品至此圆满。
- **重颂（P73–P157）**：金刚藏以长颂重宣十地行相、十山王、十相、十宝渐净，收束全品。

## 三、关键结论
1. 法云地是菩萨地的极位，得「受职位」与「灌顶位」，由诸佛智水灌顶，堕在佛数，具足如来十力，名「安住法云地」。
2. 此地菩萨能于一念安、受、摄、持十方无量诸佛所有大法明、大法照、大法雨，如大海之受龙王大雨，故名法云。
3. 菩萨智光能灭六道众生苦，能现狭广、垢净、一尘容世界等自在神通，而其身语意业乃至九地菩萨皆不能测知。
4. 十地虽有阶次差别，同在一切智中得名，如十山王同在大海；菩萨行以十相不可移夺，如大海十相；菩萨出过众圣，如大摩尼珠十性。
5. 菩萨智与佛智不可比量——如四天下取少许土对无量大地，十方充满诸菩萨所修智慧比一佛智，百分不及一乃至优波尼沙陀分亦不能及。

## 四、易混辨析
- **受职位 vs 灌顶位**：受职位是菩萨由第九地入第十地所得之位名，重在「得一切种、一切智智」；灌顶位是诸佛以智水灌菩萨顶而授之位，如转轮王太子灌水受王职，重在「堕在佛数」。二名同指一地，前者约所得，后者约能授。
- **法云地 vs 善慧地**：善慧地（第九地）以得深解脱行于世间、如实而知不过限为相，重在「慧」之善巧说法；法云地（第十地）以能受诸佛大法明雨、起大悲云震法雷为相，重在「法云」之普覆摄持。九地尚为法王子，十地则堕在佛数。
- **菩萨智 vs 如来智**：本品反复强调二者的不可比量——法云地菩萨神通智力已不可思议，然与佛智相较，如一块土对无边大地、甘蔗丛林之智比一佛智百分不及一。菩萨地是「入佛境界」而非「等佛境界」。
- **十山王喻 vs 大海十相 vs 摩尼珠十性**：三喻皆喻十地，而侧重不同——十山王喻十地各摄一类功德之「差别得名」；大海十相喻菩萨行「不可移夺」之十种行相；摩尼珠十性喻菩萨「出过众圣」之十种事，从初发心到受佛智职层层递进。

## 五、阅读提示
读本卷可抓三条主线：一是「受职灌顶」之事相（莲华、放光、诸佛灌顶），二是「如实知」之智用（界集、化、持、微细、秘密、入劫、入毛道等），三是「三重比喻」之收束（十山、大海、摩尼珠）。长行之后有长颂重宣，可与长行对读以互证。注意本品是十地品之末，十地阶次至此圆满，下卷转入佛不思议法等品。
