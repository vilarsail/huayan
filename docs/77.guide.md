# 大方广佛华严经卷第七十七 导读

## 一、内容总览

本卷为《入法界品第三十九》之十八，紧承善财童子五十三参的末段。善财自德生童子、有德童女处闻「幻住解脱」已，被指引南向海岸国大庄严园，诣毗卢遮那庄严藏大楼阁，觐见弥勒菩萨。全卷以「幻住 → 善知识 → 楼阁赞叹 → 弥勒现前」四段一线贯穿，是善财参访即将圆满、由等觉位入普贤行的关键过渡，亦是华严「善知识」义理最集中的宣说之一。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全文按「法 → 人 → 境 → 现」四重递进，由理解法门层层推向亲见菩萨：

- **幻住解脱（法，总起）**：德生童子、有德童女自说所证「幻住」 → 以十一种「皆幻住」枚举（世界、众生、世间、法、三世、生灭、国土、二乘、菩萨、菩萨众会）→ 收束于「幻境自性不可思议」，自谦唯知此一解脱，引出菩萨「无边诸事幻网」之广大 →
- **善知识义（人，承接）**：指向南方弥勒菩萨，先说弥勒「已满一切波罗蜜、已住一切菩萨地、已蒙灌顶」之德 → 次诫善财「不应以限量心修一善行」 → 以长串「应……无量」排比铺陈菩萨无边行愿 → 转入「求善知识」之十种不应（不疲倦、不厌足、不惮劳苦……） → 再以「善知识任持」十四由、十喻（慈母慈父乳母教师……）、二十种心（大地、金刚、铁围山、给侍、弟子、僮仆……）、十种想（医王良药、导师正道、船师舟楫……）、八喻（雪山大海猛火莲华……）层层叠说善知识功德 → 以「一切菩萨成就佛法皆由善知识力」收束 →
- **楼阁赞叹（境，铺展）**：善财辞退南行，途中自忆往世发意改悔 → 至楼阁前五体投地 → 以深信解入「遍一切处智慧身平等门」 → 决定了知一切因果、远离断常等诸见 → 复以长偈广赞楼阁为「住如是等一切诸功德者之所住处」，以「是……者之所住处」句式反复枚举菩萨不二中道境界（虽观空不起空见、虽行慈不证离瞋、虽住四禅不随禅生等） →
- **弥勒现前（现，收束）**：善财以颂赞楼阁已，愿见弥勒 → 弥勒从别处来，天龙八部及本生眷属围绕 → 善财五体投地 → 弥勒向大众叹善财功德，长颂历述善财以文殊力得见、当来圆满普贤行 → 摩顶授记「不久当具诸功德，犹如文殊及与我」 → 善财以颂答，愿还觐文殊 → 卷终。

## 三、关键结论

1. **幻住为门**：一切世界、众生、法、三世、国土乃至菩萨行愿皆「因缘所生、虚妄分别」，了知其幻而不坏其相，是入普贤行之钥。
2. **善知识为根本**：菩萨从初发心至成佛，一切功德「依善知识生、出、长、住」，承事善知识须发二十种心、十种想，视之如医王、导师、船师、父母。
3. **不以限量心修一善行**：菩萨应普修一切行、普化一切众生、普入一切劫、普生一切处，破「一善一法一愿一忍」之究竟想。
4. **不二中道**：楼阁所表之菩萨境界，虽观空而不起空见，虽了无生而不住无生法性，虽超凡夫而不堕二乘，是「不住生死不住涅槃」的实相行。
5. **弥勒授记**：善财由文殊发起，历参诸善知识，弥勒印证其「已生菩萨家、已长如来种」，当升灌顶位，并嘱其还诣文殊，由文殊引入普贤深妙行。

## 四、易混辨析

- **幻住 vs 幻网**：幻住是德生童子所证之解脱门，偏就「了达诸法如幻」之理；幻网（无边诸事幻网）是菩萨摩诃萨所入，偏就「以幻化差别事业度生」之用，理一而用广。
- **善知识十喻 vs 二十种心**：十喻（慈母慈父乳母教师等）描善知识之德，以「如」字立；二十种心（大地金刚铁围山给侍僮仆等）是学者承事善知识所发之心，以「应发如……心」立。前者赞师，后者策己。
- **灌顶位 vs 灌顶地**：弥勒为「灌顶地中佛长子」（等觉位），善财「当升灌顶位」（当来果），一为已证、一为当证。
- **毗卢遮那庄严藏楼阁 vs 弥勒菩萨**：楼阁是「从菩萨善根果报生」的境，表法界功德藏；弥勒是安处其中的主，表等觉行愿。善财先赞境、后见人，境人互彰。

## 五、阅读提示

读本卷可带着两个问题：其一，德生童子说「幻住」与善财后入楼阁所证「不二中道」如何衔接？其二，弥勒既在楼阁中，为何说「从别处来」？留意「不离本处而普现身」之义贯穿全卷。
