# 大方广佛华严经卷第六十七 导读

## 一、内容总览
本卷属《入法界品第三十九》之八，承接善财童子五十三参的参访历程。本卷连续记述善财参访五位善知识：遍行外道（都萨罗城，住「至一切处菩萨行」）、鬻香长者优钵罗华（广大国，住「调和香法」）、船师婆施罗（楼阁城，住「大悲幢行」）、长者无上胜（可乐城，住「至一切处菩萨行门无依无作神通之力」）、比丘尼师子频申（迦陵迦林日光园，住「成就一切智解脱」）。主线是善财一路南行、逐位参访，各善知识皆自陈所证法门，谦言「唯知此一法」，再指点下一位善知识，层层推演菩萨行门之广大，最终引向婆须蜜多。核心主旨：菩萨行无处不在，世间一切技艺、行业、身份皆可入道，皆可利益众生。

## 二、结构层次（★重点）
本卷以「善财参访」为线索，五段善知识自述并列展开，每段内部结构高度统一，构成层层递进的参学骨架：

- **善财发心起行 → 一路南行寻觅善知识**：每段开头皆有「尔时，善财童子……」过渡，先述善财因前一位教诲而精进求法，再游行至下一处所，见善知识、顶礼、白言「我已先发阿耨多罗三藐三菩提心……云何学菩萨行、修菩萨道」——这是贯穿全卷的固定参访仪轨。
- **善知识自陈法门 → 谦退推让 → 指向下一位**：每段善知识皆先答「善哉善哉」赞其发心，次述自己所证一法门（遍行「至一切处」、长者「调和诸香」、船师「大悲幢」、无上胜「至一切处无依无作」、比丘尼「成就一切智」），再以「我唯知此……如诸菩萨摩诃萨……云何能知能说彼功德行」作谦退收束，最后以「于此南方有……汝诣彼问」指点下一位。这一「自陈—谦退—指路」三段式是本卷骨架的核心节奏。
- **法门内涵由世间入出世间，层层升进**：遍行外道示现「普入一切诸趣」随机说法 → 鬻香长者以「香」喻法，了达诸香根本与业用 → 船师以「航海度宝洲」喻大悲度生 → 无上胜于三千大千乃至十方世界广说五乘因果 → 比丘尼师子频申于日光园中遍坐一切宝树下，对十地菩萨、天龙八部各说不同法门，终以「成就一切智」一念普照三世诸法收束。由「遍入诸趣」到「一念普照」，法门层层升进。
- **园中庄严与比丘尼一身多处**：第五位善知识处，经文以大段铺陈日光园的宝树、宝座、八功德水等种种庄严，再以「遍坐一切诸宝树下大师子座」展示比丘尼一身普应众机、各说别门，是全卷叙事的高潮与收束。

## 三、关键结论
1. 善财童子每次参访皆先自陈「已发阿耨多罗三藐三菩提心」，发心是参学的前提与根本。
2. 五位善知识身份各异（外道、长者、船师、居士、比丘尼），行业各异（遍行、鬻香、航海、理断人间事务、园林说法），示现菩萨行无所不在、不舍一法。
3. 各善知识皆「唯知此一法门」而谦退，并以「如诸菩萨摩诃萨……」推赞上位菩萨功德，显示法门无尽、位位高深，激发善财继续南参。
4. 师子频申比丘尼于一座一园之中对十地菩萨乃至天龙八部各说不同法门，示现「一身普应众机」与「一念普照三世诸法」的般若波罗蜜境界。
5. 善知识是成就菩萨行的根本因——「善知识者，难见难遇」，船师一段中善财思惟十种「成就修行……道因」，将参学本身定位为成佛正因。

## 四、易混辨析
- **遍行外道 vs 一般外道**：遍行外道是菩萨示现于外道众中随机调伏者，外相同外道而内修菩萨行，故善财见其「色相圆满，威光照耀，大梵天王所不能及」，非寻常外道。
- **至一切处菩萨行（遍行）vs 至一切处菩萨行门无依无作神通之力（无上胜）**：二者名号相近但位次不同。遍行所住侧重「普观世间三昧门」「普门般若波罗蜜」，于诸趣随机说法；无上胜侧重「无依无作神通之力」，于三千大千乃至十方世界广说五乘因果，范围更广。
- **大悲幢行（船师）vs 至一切处菩萨行（遍行）**：船师所住「大悲幢行」以航海、运商、济贫为喻，重在「先以世物充满其意，复施法财」，是悲智双运、先世后法的次第；遍行则直入诸趣随机说法，不分世出世先后。
- **般若波罗蜜（师子频申）vs 普门般若波罗蜜（遍行）**：遍行所证为「普门般若波罗蜜」，普门即普入诸趣；师子频申所入为「普眼舍」等十般若波罗蜜门为首，侧重一念普照三世一切诸法、意生身遍供诸佛，是更深入的般若境界。

## 五、阅读提示
读本卷可带着两个问题走：一是善知识为何皆谦言「唯知此一法」并推赞上位菩萨？二是五位善知识的行业（外道、鬻香、航海、理务、园林说法）如何各各成为菩萨行门？抓住这两条线，即可看出本卷「法门无尽、位位高深、不舍一法」的整体意趣。
