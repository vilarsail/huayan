# 大方广佛华严经卷第四十九 词语注释

① 普贤菩萨摩诃萨　普贤，梵名Viśvabhadra/Samantabhadra，表理德、行德之主菩萨；摩诃萨意为「大」，指大菩萨。本卷由普贤为大众宣说菩萨行。
② 我所　附属于「我」之所有物，如身、财、眷属等。执法有我及我所，即起贪瞋造业。
③ 颠倒疑惑　颠倒，指于无常计常、于无我计我等不如理作意；疑惑，于因果谛理犹豫不决，为见惑之一。
④ 瞋心　瞋恚之心，三毒之一。本卷特重「菩萨于他菩萨起一瞋心即成百万障门」，为行人首戒。
⑤ 百万障门　谓起一瞋恚心即成就百万种障碍之门，障菩提、正法、善根、智慧等，广列于本卷。
⑥ 恶知识　引导人退失善根、增长恶见恶行之师友，与善知识相对，为菩萨行之障。
⑦ 乾闼婆　梵语Gandharva，天界乐神，八部众之一，以香为食，亦名寻香神。
⑧ 阿修罗　梵语Asura，六道之一、八部众之一，多瞋好斗，常与帝释征战。
⑨ 迦楼罗　梵语Garuda，意译金翅鸟，八部众之一，以龙为食，翅有金色光。
⑩ 紧那罗　梵语Kiṃnara，意译疑人、歌神，八部众之一，似人而头有一角，善歌咏。
⑪ 摩睺罗伽　梵语Mahoraga，意译大蟒神，八部众之一，属地上之龙类。
⑫ 罗刹　梵语Rākṣasa，恶鬼之总名，行疾速、食人血肉，属八部众之恶类。
⑬ 一切智　佛智之一，知一切法之总相（空、无常等）；广义亦指佛之究竟智，括一切智、道种智、一切种智。
⑭ 三昧　梵语Samādhi，意为「正定」，心一境性，专注不乱，为定之本体。
⑮ 般若波罗蜜　六度之一，到彼岸之智慧，照了一切法性空寂，为菩萨行之眼目。
⑯ 三种律仪　菩萨律仪戒之三聚：摄律仪戒（断一切恶）、摄善法戒（修一切善）、饶益有情戒（度一切众）。
⑰ 二乘　声闻乘与缘觉乘，但求自了生死，不及大乘之普度，为菩萨行人所应舍。
⑱ 菩萨摩诃萨　菩提萨埵摩诃萨埵之略，意为「大道心众生」或「大菩萨」，指发大菩提心、修六度万行之大士。
⑲ 法界　一切法所依之界，理事无碍、事事无碍之总相；华严以法界缘起为一经宗旨。
⑳ 善知识　能教导众生舍恶修善、趣向佛道之师友，华严特重善知识，为菩萨行之清净因缘。
㉑ 陀罗尼门　陀罗尼意为「总持」，总摄忆持无量佛法而不忘失之门，有法、义、咒、忍等类。
㉒ 毛道　即一毛孔之道，喻极小之空间；「一切世界入一毛道」显事事无碍、小中现大之境界。
㉓ 阿耨多罗三藐三菩提　梵语Anuttarā-samyak-saṃbodhi，意为「无上正等正觉」，佛所证之究竟觉果。
㉔ 那由他　梵语Nayuta，极大数量之名，或云十万、百万、亿等，泛指不可计数。
㉕ 佛刹　一佛所教化之国土，如娑婆世界为释迦佛刹、极乐世界为阿弥陀佛刹。
㉖ 微尘数　以极微之尘数比喻数量之大、之不可计，华严常用以显法界缘起重重无尽。
㉗ 六种震动　佛说法现神力时大地所现之六种相：动、起、涌、震、吼、觉（击），表破众生无明。
㉘ 人师子　佛之德号，谓佛于人中最胜，如师子（狮子）于兽中无畏，故以为喻。
㉙ 论师子　亦佛之德号，谓佛于论议中能伏外道邪说，如狮子震吼制伏群兽。
㉚ 十力　佛所具十种智力：知是处非处、知业报、知禅定、知根胜劣、知种种解、知种种界、知一切至处道、知宿命、知天眼、知漏尽。
㉛ 贤劫　现在之劫名，此劫中有千佛出世，如释迦、弥勒等，故称贤劫，对庄严劫、星宿劫而言。
㉜ 广长舌　佛三十二相之一，舌广长覆面乃至发际，表生生世世不妄语；「无碍广长舌」表说法无碍。
㉝ 法身　佛三身之一，以法界理性为身，周遍法界，无生无灭、无形无相，为报化二身之本。
㉞ 实际　真如法性之极理，离相绝名，为诸法究极之处；菩萨不住实际、不入涅槃，表不住理而度生。
㉟ 涅槃　梵语Nirvāṇa，意为「灭度」，灭尽烦恼生死之究竟寂静境界；菩萨为度生而不取证。
㊱ 般涅槃　梵语Parinirvāṇa，意为「圆寂」「究竟入灭」，指佛圣者度生缘尽而入究竟寂灭。
㊲ 舍利　佛及圣者遗体火化后之坚固粒状遗物，为信众供养之福田；「处处般涅槃」即处处留舍利广度众生。
