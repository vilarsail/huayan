# 大方广佛华严经卷第七十二 导读

## 一、内容总览

本卷为《入法界品第三十九之十三》，承上卷寂静音海夜神之后，善财童子参访第二十九位善知识——开敷一切树华夜神。全卷以「问答得法 → 正释法门 → 发心久远问答 → 本生因缘（一切法音圆满盖王行大施） → 重颂结说 → 谦己推胜指授」一线贯穿，集中宣说「菩萨出生广大喜光明解脱门」，核心在于以大悲心普摄众生、以无遮大施成熟有情，并揭示毗卢遮那如来往昔为转轮圣王行大布施的本生因缘，终指善财往参大愿精进力救护一切众生夜神。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷按「问→答→本生→重颂→指授」的华严参访标准范式展开：

- **发起请问与所得法门（P3-P8）**：善财于前夜神处得法已，入甚深自在妙音解脱门 → 转诣开敷一切树华夜神所，顶礼绕匝，自陈已发心、欲学菩萨行 → 夜神先述己业：于日没时分密护众生还归安处；复对憍慢放逸者示老病死相，对悭贪、破戒、瞋恚、懈怠、散乱、恶慧等机各以对治法门教化，令住六度、大乘、愿力、智波罗蜜 → 结示所得法门名「菩萨出生广大喜光明解脱门」。

- **正释法门，由「普摄→本因→遍行」三层递进（P9-P15）**：
  - **普摄众生巧方便智（P11）**：善财问境界云何 → 夜神先明「一切众生所受诸乐皆是如来威德力故」，以十一种「如来……故」排比显佛力摄生 → 次自述入此解脱即忆念毗卢遮那往昔所修菩萨行海，悉皆明见。
  - **本因——如来往昔发心（P12-P13）**：世尊为菩萨时见众生着我我所、住无明暗室、为贪瞋痴悭嫉所缠 → 起大悲心，以十八重「愿……心」「起……心」排比（愿得妙宝资具摄众生、起救护心、起以大智金刚杵破烦恼障山心等）→ 得菩萨力现大神变，遍法界虚空界普雨资生之物随欲满意，普摄众生令出生死，不求其报。
  - **遍行——念念修菩萨行（P14-P15）**：以「念念」十重排比显菩萨行周遍——成熟众生、严净佛刹、普入法界、遍虚空界、入三世、转法轮、以智道利益、现佛成道、修菩萨行不生二想 → 复明所入世界海种种差别（净秽、大小、粗细、正侧、覆仰）皆念念修行入菩萨位。再述毗卢遮那往昔为菩萨时见众生着我不修功德，起大悲具修波罗蜜，为说因果业报证入处欲解国土，令不断佛种。

- **发心久远问答与重颂（P16-P20）**：善财问「发心已久如」 → 夜神先叹此难信难知难解难入难说，一切世间二乘皆不能知，唯佛神力所护、善友所摄、集胜功德者能持能入，明此是如来智慧境界 → 承佛威力为说 → 以长偈重颂：先明佛境界非贪恚痴憍慢所覆者、非着蕴界处计有身见倒想倒人所能知 → 次明佛境界寂静性净离分别 → 复以十二重「是彼之境界」排比，显生于佛家、心净如虚空、大慈悲普覆、欢喜能舍等行相 → 结以从三世佛方便愿种出生、尽劫刹勤修之普贤解脱，劝善财亲近善知识闻法欢喜。

- **本生因缘：一切法音圆满盖王行大施（P21-P39）**——全卷主体，占篇幅最大：
  - **世界层级（P21-P22）**：往古过世界海微尘数劫，有世界海普光明真金摩尼山，佛号普照法界智慧山寂静威德王 → 世界海中世界种普庄严幢 → 世界一切宝色普光明，净秽相杂 → 阎浮提人寿万岁时有王名一切法音圆满盖，威德普被阎浮提内。
  - **五浊兴、众生求救、王发大悲（P23-P24）**：劫欲尽时五浊起（寿短、财乏、形陋、苦多乐少、不修十善） → 风雨不时、苗稼不登、人民匮乏多病 → 无量众生四面周匝高声大呼，以十种想（生安乐想、得宝藏想、遇津梁想、值船筏想、见宝洲想、升天宫想等）归依大王 → 王闻语得百万阿僧祇大悲门，发十种「哀哉众生……我当云何……」大悲语（济住智地、作救护、为归依、决疑见翳膜、作明炬照智城、调御具足佛神力、引导入智门等）。
  - **无遮大施与王心生欢喜（P25-P31）**：击鼓宣令普施 → 开库藏出种种物置四衢道，亦施村营城邑妻子眷属王位，头目耳鼻唇舌牙齿手足皮肉心肾肝肺内外所有悉皆能舍 → 施会处广博清净，师子座十宝严饰 → 阎浮提无量众生咸赞王是大智人、福须弥、功德月 → 王见乞者生悲愍欢喜等十心，经须臾顷欢喜胜过诸天所受诸乐 → 譬如人遭世难失散父母妻子，于旷野忽相值遇情无厌足 → 王因善知识于佛菩提解欲增长，知法性如虚空。于乞者生一子想、父母想、师想、佛想，不拣方处族类形貌，平等无碍普施一切。
  - **宝光明女赞王与本生会归（P33-P39）**：会中有长者女宝光明，端正姝妙皮肤金色目发绀青 → 合掌顶礼作念「我获善利」，脱身璎珞奉王发愿如王所知法所修道所具色相，愿未来悉得如是 → 王言「随汝所欲我皆与汝」 → 宝光明以长偈赞王（偈中详述往昔城邑如饿鬼处、众生相害窃盗纵淫邪见堕恶道、天旱不泽百谷不生，王升宝位后油云普雨、粳米自然生、树中出妙衣、普断暴虐、众生相视如父母专求一切智；复述王降生前先现灵瑞、中夜地震动、华池千叶莲华出光如千日、王生华上端身结跏坐、宝藏涌出宝树生妙衣等瑞相）→ 王赞女「汝能信知他人功德是为希有」，以无价宝衣手自授女并眷属，宝衣普出星宿光明 → 终以「会归」收束：一切法音圆满盖王即今毗卢遮那如来，光明王即净饭王，莲华光夫人即摩耶夫人，宝光童女即夜神自身，王尔时以四摄法所摄众生即此会中一切菩萨，皆住初地乃至十地。

- **重颂、谦己推胜与指授（P40-P44）**：夜神以长偈重颂己之广大眼、清净耳、他心智、宿命智，一念知刹海微尘劫诸佛菩萨五道众生，忆知诸佛始发菩提愿乃至成就菩提道转法轮 → 自谦「我唯知此菩萨出生广大喜光明解脱门」，推赞菩萨摩诃萨亲近供养诸佛、入一切智大愿海、满一切佛诸愿海、普入一切菩萨地海行海解脱门海 → 指授下一善知识大愿精进力救护一切众生夜神，嘱善财往问菩萨云何教化众生、严净佛刹、承事如来、修行佛法 → 善财礼足绕匝殷勤瞻仰辞退而去。

## 三、关键结论

1. **法门核心在「出生广大喜光明」**：此解脱门之体，在于入此解脱即忆念毗卢遮那往昔所修菩萨行海悉皆明见，由见如来本因本行而出生广大欢喜，复以此喜光明普照众生——是以「智见佛行」为因、「大喜光明」为用、「普摄众生」为业。
2. **大悲为本，大施为业**：一切法音圆满盖王（毗卢遮那往昔）见五浊众生苦逼，即发十种大悲语，行无遮大施——内外所有头目皮肉心肾肝肺妻子王位悉皆能舍，于乞者生一子想、佛想，平等普施不求其报，此即往昔菩萨行海之具体落实，亦即「出生广大喜」之因行。
3. **王即是佛，女即是夜神，会众即是菩萨**：本生因缘终以「会归」收束——往昔一切法音圆满盖王即今毗卢遮那，宝光童女即夜神自身，王以四摄法所摄众生即此会中一切菩萨，皆已住初地乃至十地——显示往昔因行与今说法会一如不二，因果相即。
4. **念念周遍法界为菩萨行相**：以「念念」十重排比显菩萨行周遍——成熟众生、严净佛刹、普入法界、遍虚空界、入三世、转法轮、利益众生、现佛成道、修菩萨行不生二想——明一念即摄一切劫、一尘即遍一切界之法界缘起义。
5. **善知识相续不绝**：夜神自谦唯知一法，推赞菩萨摩诃萨无边行愿，复指善财参下一善知识大愿精进力救护一切众生夜神，显示善财五十三参「一参接一参」的法脉相续结构。

## 四、易混辨析

- **开敷一切树华夜神 vs 寂静音海夜神 vs 大愿精进力救护一切众生夜神**：三者皆为《入法界品》中善财所参之主夜神，前卷寂静音海夜神得「念念出生广大喜庄严解脱门」，本卷开敷一切树华夜神得「菩萨出生广大喜光明解脱门」——法门名相近而夜神不同，前者重「念念出生庄严」，后者重「出生光明」与「普摄众生巧方便智」；下一参大愿精进力夜神则重在「大愿精进救护众生」，三位夜神法门递进、各住一解脱门而推胜指后。
- **一切法音圆满盖王 vs 普照法界智慧山寂静威德王佛 vs 毗卢遮那如来**：普照法界智慧山寂静威德王是往古普光明真金摩尼山世界海中出兴之佛，彼佛往修菩萨行时净彼世界海；一切法音圆满盖王则是彼世界中阎浮提人寿万岁时之王，即毗卢遮那如来之前身（往昔为菩萨时之王身）——三者非同一时同一身，而是「彼佛 → 彼佛所化世界中之王（即今毗卢遮那之前身）」之层级关系。
- **五浊 vs 五欲 vs 五蕴**：本卷五浊指劫欲尽时所起之五种浊恶（寿命短促、资财乏少、形色鄙陋、多苦少乐、不修十善专作恶业），属劫浊与见浊烦恼浊命浊众生浊之总相；五欲指色声香味触之欲乐，本卷「盛年好色憍慢放逸五欲自恣」即指此；五蕴为色受想行识，颂中「着蕴界处」即指众生执着五蕴十八界十二处为我——三者名相相近而义不同。
- **四摄法 vs 六度波罗蜜**：四摄法为布施、爱语、利行、同事，菩萨摄化众生之四方便；六度为布施、持戒、忍辱、精进、禅定、般若，自利利他之六度行——本卷王以四摄法所摄众生即此会菩萨，而夜神对机教化则用六度（悭者赞施、破戒赞戒、瞋者教慈等），四摄偏重摄化方便，六度偏重自利利他之行体，二者相摄而非全同。

## 五、阅读提示

读本卷可带着两个问题：(1) 「出生广大喜」之「喜」从何来？——从忆念毗卢遮那往昔菩萨行海悉皆明见而来，从见众生苦起大悲发十种大悲语行无遮大施而来，喜与悲、智与行如何统一？(2) 宝光明女长偈赞王中，往昔城邑如饿鬼处与王升位后油云普雨、粳米自然生、树中出妙衣之对比，反映何种「正法治国」的理想？辨清此二端，便抓住了本卷「智见佛行为因、大悲大施为业、会归因果不二为果」的三分大纲。
