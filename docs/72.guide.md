# 大方广佛华严经卷第七十二 导读

## 一、内容总览
本卷为《入法界品》第三十九之十三。善财童子承上卷从守护一切城增长威力夜神处所得的「菩萨甚深自在妙音解脱」，修行增进，依其指授前往参访开敷一切树华夜神。夜神自陈所证「菩萨出生广大喜光明解脱门」：先说她在娑婆世界日暮之后密护众生归途、以老病死相警醒憍慢者、对机令住各种波罗蜜；再入境界开示，忆念毗卢遮那如来往昔为菩萨时的本生——一切法音圆满盖王的大布施与宝光明童女的赞佛因缘；末了指授善财去参大愿精进力救护一切众生夜神。

## 二、结构层次（文章的骨架与逻辑推进）
- **承前启后（往诣发问）**：善财入妙音解脱门修行增进 → 往诣开敷一切树华夜神所，见她身在众宝香树楼阁内、妙宝师子座上，百万夜神共同围绕 → 顶礼合掌，请问菩萨云何学菩萨行、云何得一切智。
- **解脱门自陈（先功行后证名）**：夜神先述功行——日暮时密护众生还家得正道；见盛年憍慢、五欲自恣者，为现老病死相令生恐怖；进而对机施教：悭吝者赞布施、破戒者扬净戒、瞋恚者教大慈、恼害者令忍辱、懈怠者起精进、散乱者修禅定、恶慧者学般若、乐小乘者住大乘……然后才说出「菩萨出生广大喜光明解脱门」。
- **境界开示（由今溯昔）**：善财问境界 → 夜神言入此解脱能知「如来普摄众生巧方便智」——一切众生所受诸乐皆是如来威德力所致 → 忆念毗卢遮那往昔修菩萨行：见众生着我我所、住无明闇室，起大悲，发二十种饶益众生之心，得菩萨力现大神变，普雨一切资生之物而不求报。
- **重颂（赞叹佛境界甚深）**：佛境界非贪恚痴、憍慢惑覆者所能知，唯净心持法藏者之智眼境界；连用「此某某者之解脱」的排比（寂静住三昧者、慧灯者、正道者、普贤者、无碍眼者）。
- **本生叙事（全卷主体）**：过世界海微尘数劫，普光明真金摩尼山世界海 → 劫欲尽时五浊起，人民困苦，围绕王都哀号 → 一切法音圆满盖王发十种大悲语，开库布施，乃至头目手足内外悉舍 → 设施会处、坐师子座广行布施 → 长者女宝光明脱璎珞奉王、以长偈赞王 → 王授无价宝衣 → 「岂异人乎」揭橥：王即毗卢遮那如来，父即净饭王，母即摩耶夫人，宝光童女即夜神自己。
- **重宣与指授（收束）**：夜神重颂自述广大眼、清净耳、他心智、宿命智之力 → 谦言唯知此一解脱门，诸菩萨层层无尽境界非己能知 → 指授大愿精进力救护一切众生夜神 → 善财礼辞而去。

## 三、关键结论
- 众生所受一切安乐，皆由如来威德力、顺如来教、行如来语而得——见众生得乐生大欢喜，正是「出生广大喜」之本。
- 布施圆满是本生叙事的核心：从衣服饮食到妻子王位乃至头目手足悉皆能舍，视乞者如一子、如父母。
- 佛境界甚深难信难解，二乘尚不能知，唯亲近善知识、爱乐白净法、心净无分别者能入。
- 大王见来乞者「心生欢喜经须臾顷」，胜过诸天于无量劫所受快乐——法喜远胜天乐。

## 四、易混辨析
- **本生与今佛的对应**：一切法音圆满盖王＝毗卢遮那如来；净光明王＝净饭王；莲华光夫人＝摩耶夫人；宝光（宝光明）童女＝开敷一切树华夜神本人。
- **两种解脱门**：上卷守护一切城夜神所授「菩萨甚深自在妙音解脱」（善财已入）；本卷开敷一切树华夜神所证「菩萨出生广大喜光明解脱」——前后两参法门。
- **婆罗门式苦行与对机施教**：夜神对机施教：悭吝赞施、瞋恚教慈——各令住相应波罗蜜。
- **五浊与劫尽**：劫欲尽时五浊始起，众苦丛集——正是大王大悲布施的因缘背景。

## 五、阅读提示
读本卷宜紧扣「岂异人乎」——长篇本生叙事最终都收摄在人物身份的揭示上：今日说法的夜神，正是当年以偈赞佛、蒙王授衣的宝光童女。偈颂（佛境界甚深颂、宝光明赞王偈、夜神重宣颂）是长行的提要，可对照把握。
