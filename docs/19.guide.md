# 大方广佛华严经卷第十九 导读

## 一、内容总览

本卷对应《大方广佛华严经》唐译本卷第十九，涵盖三个品目：先承上启下，写如来升夜摩天宫（升夜摩天宫品第十九），次为夜摩天王偈赞十佛、十慧菩萨承佛神力各说颂偈（夜摩宫中偈赞品第二十），最后功德林菩萨入善思惟三昧，承十方同名诸佛加持，宣说菩萨十种行之前六行（十行品第二十一之一）。全卷以「升处庄严 → 偈赞佛德 → 明法性深义 → 开演十行」一线贯之，由境到众、由赞到法、由理到行，层层推进，是从「十住」转入「十行」位的关键枢纽。

## 二、结构层次（★重点）

- **升处庄严 → 天王偈赞**：如来不离菩提树下而升夜摩天宫宝庄严殿，夜摩天王化作百万庄严宝莲华藏师子座请佛安坐；复承佛神力忆念往昔所种善根，以十首偈赞十方过去如来（名称、宝王、喜目、然灯、饶益、善觉、胜天、无去、无胜、苦行）各曾入此殿 → 说明「此处最吉祥」是承诸佛功德而来。
- **十方菩萨来集 → 放光加被**：十方各有一大菩萨（功德林、慧林、胜林等十慧菩萨）与佛刹微尘数眷属俱来，所从来国、所事佛之名号悉同等无别；世尊从两足放妙色光明普照十方 → 显示主伴齐现、法界平等。
- **十慧菩萨偈赞（理）**：功德林至智林十菩萨，一一承佛威力普观十方说颂，内容依次为：佛身普周法界、六度照世、诸法无生无灭、闻法信解必当作佛、智与无智体性各别、金与金色法法无差、五蕴从业心起、佛身以法为身、心如画师造世间、诸佛离相不可取 → 由「赞佛」转入「明法性」，已为「十行」奠基。
- **入定加持 → 开演十行（行）**：功德林菩萨入善思惟三昧，十方同名诸佛现前加持、授智、摩顶，从定起宣说菩萨十行总名；次第广解欢喜行、饶益行、无违逆行、无屈桡行、离痴乱行、善现行前六行 → 从「理」落到「行」，每一行皆具「行相 + 大愿 + 空观」三段。
- **递进关系**：偈赞品以「理」收摄（诸法无生、唯心所造），十行品以「行」展开（菩萨于度生中行无所著）；前者是后者的理论基础，后者是前者的实践落实。

## 三、关键结论

- 如来不离一处而遍十方，一一会中各谓佛在前，显示法界身土相即无碍。
- 十方菩萨、世界、如来名号悉同，表明佛法法门平等、主伴不二。
- 诸法无生无灭、自性空寂，若能如是解，斯人见如来——见佛不在色身，而在通达法性。
- 「心如工画师，能画诸世间，五蕴悉从生」——一心能造十法界，为华严唯心义之要旨。
- 十行之体即「学三世诸佛所行」，菩萨以大悲为先、以空观为体，行度生事而不著度生相。

## 四、易混辨析

- **十住 vs 十行**：十住（十住品，卷十六前后）重在「心住于理」，是菩萨初安住；十行（本品起）重在「起行度生」，于住理之上发起利他行。本品功德林菩萨即十行主，同名诸佛加持令入善思惟三昧而说十行。
- **欢喜行 vs 饶益行**：欢喜行以「布施」为体，财物乃至身肉皆能惠施，令众生欢喜；饶益行以「持戒」为体，于五欲心无所著且不恼一众生。前者重舍，后者重护。
- **无违逆行 vs 无屈桡行**：无违逆行即「忍辱」，遭众生百千亿口毁辱、器仗逼害经阿僧祇劫而心不动；无屈桡行即「精进」，纵为度一生入阿鼻地狱无数劫受苦亦不生悔。前者耐辱，后者不退。
- **善思惟三昧 vs 善思惟菩萨**：前者是功德林菩萨所入的定名，定名「善思惟」；后者非人名。功德林菩萨是此定之主，十方同名功德林佛现前加持，名号互为呼应。
