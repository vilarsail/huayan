# 大方广佛华严经卷第四十七 词语注释

〔1〕 实叉难陀　于阗（tián）国三藏法师Śikṣānanda的意译名（学喜），八十卷本《华严经》的译者；「三藏」指通晓经、律、论的法师，「奉制译」是奉皇帝之命翻译。
〔2〕 广大佛事　「佛事」指佛利益众生的一切事业。本卷第一大段列举「十种广大佛事」，每条以「是为第X广大佛事」作结，读法是抓每条起首的「一切诸佛……」主句。
〔3〕 去、来、现在　即过去、未来（来）、现在三世；后文「去来今」同义，是竖压缩的三世并称。
〔4〕 兜率陀天　梵语Tuṣita，旧译兜率天，欲界第四天；菩萨成佛前最后住此天，再下生人间，故本卷说诸佛「于兜率陀天皆现受生」。
〔5〕 皆现受生　受生指菩萨乘愿入胎受身；诸佛示现从兜率天下生人间入母胎的过程。
〔6〕 一乘　与「三乘」相对：三乘指声闻、缘觉、菩萨三种教法（差别方便），一乘指圆满一味、究竟成佛的佛乘。
〔7〕 降神母胎　降神指菩萨从兜率天降下神识（入胎）；此段述诸佛示现入胎、住胎、出生的八相成道过程。
〔8〕 如热时焰　热时焰即阳焰（蜃气），日光下旷野中似水无水的幻象；与如幻、如化、如影、如空并列，喻受生之法虚幻不实。
〔9〕 无诤法　梵语araṇā，无诤（zhèng）即不与一切法相违斗诤、离烦恼争论的境界；后文「舍俗威仪，住无诤法」同此。
〔10〕 受最后身　最后身指菩萨在生死中受的最后一次身，此后成佛永离生死。
〔11〕 转妙法轮　法轮喻佛说法——轮能碾摧烦恼、辗转传布不停；「转法轮」即说法，本卷有十种法轮、种种法轮等多处展开。
〔12〕 般涅槃　梵语parinirvāṇa音译，「般」义为入、圆寂，指佛示现灭度；「入般涅槃」即入灭。
〔13〕 随类音　随众生种类而现的语音；佛以各种众生各自能懂的语言说法。
〔14〕 三种巧方便业　指身、语、意三业的善巧运用，经文自释：身业究竟清净、语业常随智慧而行、意业甚深无有障碍。
〔15〕 无上福田　福田喻能生福报之田地，供养佛及圣者如于田播种；「无上福田」谓佛是最殊胜的种福对象。
〔16〕 智慧高幢　幢（chuáng）为柱状丝帛旗帜，庄严具之一；「智慧高幢」喻出家者持佛智慧，高出世间一切外道。
〔17〕 平等地　「如来平等地」指佛所证的无差别境界；谓令众生种善根后，生于佛平等法性之地。
〔18〕 一切世界、一切众生、一切佛刹　这是「一切世界、一切众生、一切佛刹、一切诸法、一切菩萨……」的长排比清单（十个「一切」并列），逐一列举佛于第五佛事中悉能了知的对象，读时可抓每条首词，不必逐项深究。
〔19〕 净法眼　清净法眼，即见法真理、得法眼净——亲见四谛或诸法实相的智慧眼。
〔20〕 那由他　梵语nayuta，印度大数名，意为「多至不可计算」，约当亿或兆级，形容数量极多。
〔21〕 都邑　（dū yì）城池、都市；此段说诸佛入人王、天王及天龙八部诸王的一切都城而作佛事。
〔22〕 毗舍阇王　梵语piśāca，又译毕舍遮，食精气、啖血肉的恶鬼类；与罗刹并列为鬼王，此处指其王所居之城邑。
〔23〕 不鼓自鸣　鼓（gǔ）作动词，击打；乐器无人演奏而自己发声，是佛入城时的瑞相。
〔24〕 教敕　（chì）教诲告诫；「若有教敕」谓佛的教导叮咛，与顾视、行住坐卧等一切举止同为佛事。
〔25〕 世界种　华严世界海结构中的单位：无数世界组成的层级体系（世界种集于香水海上）；「知一切世界种尽无有余」谓佛遍知一切世界结构。
〔26〕 增长佛种　佛种即成佛的种子（菩提心与善根）；令众生供养瞻奉而使佛种增长，毕竟成佛。
〔27〕 阿兰若处　梵语araṇya，远离村落喧闹的寂静处，出家人修行之所；与后文「寂静处」「空闲处」同为第八佛事中佛示现居住的处所。
〔28〕 人、非人　人与非人之略；「非人」指天龙、夜叉、鬼神等八部众，经中常以「人、非人等」总括一切听法众生。
〔29〕 而作佛；事　此处标点疑有讹误，当连读为「求一切智而作佛事」，即示现龙、夜叉等种种身，为求一切智而作利益众生之事；下文「或以声闻身」紧承此句。
〔30〕 所作皆悉已办　即梵语「应作已作」（kṛtya-kṛtya），指佛应做之事皆已完成、生死大事已了，是叹佛果德的固定语。
〔31〕 诸有根本　「有」指三有（欲有、色有、无色有）即生死轮回；「诸有根本」谓轮回的根本（无明爱取），佛示现永断之。
〔32〕 念佛三昧　系心念佛、于佛相好功德得定不乱的三昧；第九佛事中佛为众生宣说此法，令其发心常乐见佛。
〔33〕 悲号涕泣　号（háo）放声大哭；此段写佛入涅槃时众生悲泣恋慕，而佛即以此方便令众生念恩修善，亦是佛事。
〔34〕 舍利　梵语śarīra，佛灭度后火化所遗的坚固子（身骨）；此处谓佛「自碎其身以为舍利」，令众生起净信而供养修福。
〔35〕 爪发　爪（zhǎo）即指甲；牙齿、爪发与舍利同为佛身遗物，皆建塔供养。
〔36〕 白法　白净法，指一切清净善法（对「黑法」即恶法而言）；「具众白法」谓常生善道、具足善法。
〔37〕 自乘果　各随自己所修之乘（声闻乘、缘觉乘或菩萨乘）而得其果位；谓于三有中出离后「各随所愿获自乘果」。
〔38〕 无二行自在法　第二大段总纲：十种「无二」——即佛所行决定不二、无有差别自在之法，每条都以「决定无二」作结，读时抓各条「悉知……即/同一……」的句式。
〔39〕 授记　梵语vyākaraṇa，佛预告某众生何时当成佛、佛号国土等；后文「授记别」同义，「别」是对其一一分别说明。
〔40〕 现觉　现前证知觉悟；「悉能现觉一切诸法」谓佛当下亲证一切法，非从传闻推度。
〔41〕 刹那　梵语kṣaṇa，极短的时间单位；「悉知三世一切刹那即一刹那」谓佛证知时间相即无碍。
〔42〕 决定无一　承上文十句皆言「决定无二」，此处「决定无一」当为「决定无二」之讹（诸本多作无二），义为「三世一切佛刹入一佛刹」此理决定不二。
〔43〕 无忘失法　佛的功德之一：于一切利益众生之事忆念不忘、无有遗失；「十种住」中佛「住无忘失法」。
〔44〕 实际　真如法性的实际理地，即一切法的究竟边际、不生不灭之体性；「不违实际相」「住于实际」皆谓安住此实相。
〔45〕 尽无有余　穷尽而无剩余；「十种知一切法尽无有余」谓佛于过去、未来、现在等十类法悉皆遍知、毫无遗漏，是一总括式的列举。
〔46〕 因陀罗网　梵语Indra-jāla，帝释天宫殿的宝珠网，千珠相映、一珠中现一切珠影，华严用以喻法界万法重重相摄、互摄互入。
〔47〕 大那罗延幢勇健法　本卷第三大段总纲，共十种。「那罗延」（Nārāyaṇa）为天上力士之名，喻佛身坚固勇健、金刚不坏；「幢」喻挺立不可摧。每条以「是为诸佛第X大那罗延幢勇健法」作结，读法是抓每条开头的神变叙述。
〔48〕 所不能中　中（zhòng）作动词，击中、毒害；「世间毒药所不能中」谓一切毒药都不能伤害佛身。
〔49〕 雨大金刚　雨（yù）作动词，降下；谓诸魔尽其势力降下如须弥山大的金刚，佛身不为所害。
〔50〕 铁围山　环绕咸海、围护一小世界的铁山，与须弥山相对；「大铁围山」更大一层，此处喻魔掷山石之巨与佛持世界之能。
〔51〕 须弥山王　梵语Sumeru，一世界中心最高的山，四宝合成，故称「王」；佛能将须弥山、铁围山、大海、宫殿置于毛孔而不惊动众生。
〔52〕 所被　被（pī）覆盖、加被；「唯除如来神力所被」谓众生不觉不知，除非佛神力所覆加令其得知。
〔53〕 佛刹微尘数　华严惯用的大数表达：把一个佛国土碎为微尘，以其尘数喻极多；「不可说不可说佛刹微尘数」层层叠加，形容多到无法言说。
〔54〕 一坐食　日中一食、于一座上进毕的苦行规范；谓佛一食之后结跏趺坐，经无量劫而身不疲厌。
〔55〕 结跏趺坐　即盘腿而坐，两足交叠置于左右股上（趺 fū，足背），为佛及行者入定正坐；此段谓佛于一毛端处结跏趺坐尽未来劫。
〔56〕 靡不　靡（mǐ）无、没有；「法界众生靡不皆闻」即没有众生不闻，「靡不惊慑」同此双重否定句式。
〔57〕 修多罗藏　修多罗即梵语sūtra（经）音译；「藏」谓含藏诸法义，修多罗藏即一切经藏。此段谓佛一舌出无量音声，一音演无量经藏。
〔58〕 普然照世　「然」通「燃」；普燃照世之智慧明灯，与「高升圆满大智慧日」等并列，是佛所转法轮的种种名称。
〔59〕 无能为谕　谕通「喻」（yù）；「一切世法无能为谕」谓佛转法轮的自在神变，世间没有任何事物能比喻它。
〔60〕 胸臆　（xiōng yì）胸口；「以德相庄严胸臆」指佛胸前具足功德之相（如卍字、德字相等），金刚不坏，故魔军不能害。
〔61〕 一毛不竖　连一根汗毛都不竖起；极言佛面对遍满虚空的魔军毫无惊怖，与「容色不变，不动不乱」呼应。
〔62〕 三轮教化　佛度众生的三种轮：神变轮（示现神通）、记心轮（知众生心）、教诫轮（说法教诫）；此处谓先降伏魔军，再以三轮教化令发菩提心。下文「以三种轮教化调伏」同此。
〔63〕 阿耨多罗三藐三菩提　梵语anuttarā-samyak-saṃbodhi音译，意译「无上正等正觉」，即佛所证的一切智智；「发阿耨多罗三藐三菩提意」即发起成佛之心。
〔64〕 无碍音　佛的音声周遍十方、无所障碍；第七那罗延幢法专说佛音：山宫不能障、众生随应皆闻、文字句义悉得解了。
〔65〕 须弥卢　即须弥山之异译（梵语Sumeru的另一种音译）；「须弥卢等一切诸山不能为障」谓佛音声无碍，高山不能遮隔。
〔66〕 无浊、无翳　翳（yì）本指眼疾遮目，引申为遮蔽；谓三世诸佛同一体性，无染浊、无障蔽。
〔67〕 无我所　「我所」即我所有的（我及我所执）；「无我、无我所」谓佛证无我，离我执与我所执；下文「非内、非外」进一步明离对待。
〔68〕 攀缘　心如猿猴攀附外缘、逐境不止；「舍离一切攀缘忆念」谓佛心无所缘著，本性清净。
〔69〕 离量、非量　量（liáng）指认知的准量，非量即错误的认知；谓佛超越正确与错误的一切分别计度，绝「为（有为）」、「无为」的言说对待。
〔70〕 十力　佛所具的十种智力（知是非、业报、根胜劣等十种决断力）；与「十力无畏」并举，是佛果功德的总称。
〔71〕 不断智　相续不断之智，即无间断地照知一切法的智慧；「得不断智，知一切法究竟无余」。
〔72〕 尽诸有漏　有漏（lòu）指与烦恼相应、能漏落生死的法；「尽诸有漏」即断尽一切烦恼，随之「心善解脱，慧善解脱」。
〔73〕 同一法身　第九那罗延幢法：此起是二十余种佛身的长清单（境界无量身、功德无边身、世间无尽身……直至「普了达身」），一一并列、句式整齐，读法是抓每条末尾的「身」字为首眼，知其皆在说佛身之无尽自在。
〔74〕 普贤智　普贤菩萨所表的、遍周法界的广大行愿之智；「以普贤智集诸善行」谓以周遍行愿之智积集善行。
〔75〕 依自乘　依众生自己所修、所宜之乘（声闻、缘觉、菩萨等）而为其施设相应教法；「皆依自乘而施其法」即应机说法。
〔76〕 心、意及识　心（集起）、意（思量）、识（了别）三者，旧译对八识的分层称谓；「开悟……心、意及识不失于时」谓佛应时开悟众生的心意识。
〔77〕 二乘　声闻乘与缘觉乘，自求了脱而不及佛乘广大者；「去、来、现在一切众生及以二乘不能解了」谓此那罗延幢法唯佛与佛乃能究尽。
〔78〕 速疾法　十种速疾之利：每条句式为「一切诸佛若有见者，速得（速能）……」，谓凡见佛者速得种种利益，读时抓住「速」字统领即可。
〔79〕 正位　入圣流之位，即于佛法中得不退转的决定阶位；「若未入正位而得见者，速入正位」谓见佛即速证不退。
〔80〕 满足诸度　「度」即波罗蜜（六度或十度：布施、持戒、忍辱、精进、禅定、般若等）；「满足诸度」谓佛圆满成就一切到彼岸之行，菩萨应常忆念。
〔81〕 梵行　梵（fàn）即清净之义；梵行指离欲清净之行，佛「已具梵行」，为菩萨所当忆念效法。
〔82〕 一切智住　第四大段之一：十种「一切智住」——佛安住于一切智中的十种境界，每条皆以「一切诸佛于一念中，悉知/普……」起首，核心在一念遍知、遍应一切众生。
〔83〕 心、心所行　心王与心所（xīn suǒ）之行相；「心所」是伴随心而起的各种心理活动，谓佛一念中遍知三世一切众生的心与心所法。
〔84〕 佛三昧　第五大段：十种无量不可思议佛三昧，每条句式为「一切诸佛恒在（住）正定，于一念中遍一切处，普……」，谓佛住定而同时遍一切处起用，寂而常照。
〔85〕 无我际　「际」即实际、理际；「说无我际」谓为众生说无我实相之理，与后文「说一切法离欲真际」同为佛三昧中的说法内容。
〔86〕 无碍解脱　本卷末段总纲：十种无碍解脱，核心句式是「能于一尘现不可说不可说……」——于一微尘中普现诸佛出世、转法轮、化众生、诸国土等，示一即一切、小大相容的无碍境界。
