- **新译文**：*那时，善财童子前往大愿精进力救护一切众生夜神的住所，向她的双足顶礼，绕了无数圈，然后在她面前合掌，这样说道：“圣者！我已经发了无上正等正觉的心，但还不知道菩萨应该如何学习菩萨行？如何修习菩萨道？”*
