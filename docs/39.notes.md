# 大方广佛华严经卷第三十九 词语注释

〔1〕 净居天　色界第四禅最上层的五净居天，唯不还果圣者所居；此处净居天子为此会的听众之一。
〔2〕 那由他　梵语音译，印度大数名，约当千亿，经中常用来表极多。
〔3〕 俱然　然，同「燃」。「俱然最上悦意香」即大众共同燃最上好香供佛。
〔4〕 采女　宫中侍女、歌舞之女；此处指天宫的采女。
〔5〕 靡不　靡（mǐ），无、没有；「靡不」即无不、全都。
〔6〕 兜率宫　兜率天（欲界第四天）中的宫殿，菩萨下生成佛前住于此。此处与「入母胎」「出胎」等连举，是佛示现八相成道中的诸相。
〔7〕 涅槃　梵语音译，意译灭度、圆寂；此处指佛示现入灭之相。
〔8〕 幻师　魔术师；以幻师变化种种事物喻佛于世间普现身相而实无所住著。
〔9〕 解脱月　菩萨名，此会中代表大众向金刚藏菩萨请问疑难者。
〔10〕 金刚藏　菩萨名，十地品中说十地义理的法主。
〔11〕 白法　净善之法；白喻清净无垢，与恶法（黑法）相对。「善满足白法」即圆满具足一切善法。
〔12〕 稠林　茂密的森林；喻众生心行、业惑庞杂繁密，难以进入了知，故说「入众生界稠林」。
〔13〕 如来力、无所畏、不共佛法　唯佛独具的功德总称：十力、四无所畏、十八不共佛法；此处谓菩萨常观察这些佛功德。
〔14〕 一切种、一切智智　佛果智慧的称号；一切种智与一切智智皆谓圆满遍知一切，连用以极言其殊胜。
〔15〕 受职位　又称受职地、灌顶位，指十地菩萨受佛智职位之阶段；本卷所述第十地的主要内容即受职。
〔16〕 三昧　梵语音译，意译正定，心专注一境的禅定；下文列举菩萨所入的百万阿僧祇三昧。
〔17〕 海印三昧　如大海能一时映现天上万象，此定中能映现一切法界之事；华严经中著名的三昧。
〔18〕 阿僧祇　梵语音译，意译无数，印度大数之一，常与微尘数连用表极多。
〔19〕 三千大千世界　一佛所化的世界单位，由小千、中千、大千三层世界合成而得名。
〔20〕 摩尼　梵语音译，意译如意珠，能随心出生众宝的宝珠，经中常作比喻。
〔21〕 栴檀王　栴檀（zhān tán），檀香木；「王」谓同类中之最上者。
〔22〕 码瑙　即玛瑙的异体写法。
〔23〕 阎浮檀金　阎浮树畔河水所出之金，佛经中金色品类的最高等。
〔24〕 微尘数　以微尘比喻数量，谓将世界碎为微尘那样多，经中惯用的极数表达。
〔25〕 周匝　匝（zā），环绕一周；周匝即四周围绕。
〔26〕 恶趣　地狱、饿鬼、畜生三恶道；「恶趣休息」谓受职光明照处恶道之苦止息。
〔27〕 齐轮　齐，同「脐」；齐轮即脐部，谓从脐中放光照阎罗王界。
〔28〕 右绕十匝　匝（zā），环绕一周；右绕即向右顺时针绕行（示恭敬），十匝即十周。
〔29〕 譬谕　谕，同「喻」；譬谕即比喻，「算数譬谕所不能及」谓以算数、比喻都无法比拟。
〔30〕 华鬘　鬘（mán），花串、花环；华鬘即花鬘，供养佛的装饰之具。
〔31〕 不退转　谓于无上菩提之位不再退失；见知此光明供养者皆得不退转。
〔32〕 金刚庄严臆德相　臆（yì），胸；指菩萨胸前金刚所成的庄严德相（如卍字相等），受职时诸佛光明出入于此。
〔33〕 十力　佛的十种智力：知处非处、知业报、知根胜劣、知种种界、知种种解、知一切至处道、知禅定解脱、知宿命、天眼、漏尽。
〔34〕 堕在佛数　堕，归入、列入；「堕在佛数」即列入佛的行列，与佛同类。
〔35〕 转轮圣王　统一四天下、具足七宝的理想圣王；经中以太子受王职灌顶之礼，比喻菩萨受诸佛智职。
〔36〕 正后　后，皇后；「母是正后」即太子是正宫皇后所生，以别于妃嫔所出。
〔37〕 灌顶　古印度转轮王太子即位时以四大海水灌其顶，名受王职；此借喻十方诸佛以智慧之水灌菩萨顶、授以佛位。
〔38〕 刹利　刹帝利的简称，古印度四种姓中的王族、武士阶层。
〔39〕 十善道　不杀生、不偷盗、不邪淫、不妄语、不两舌、不恶口、不绮语、不贪、不瞋、不邪见十种善业。
〔40〕 法云地　十地之第十地；谓菩萨具足福德智慧，如大云含雨，能降大法雨润一切众生，故名法云。
〔41〕 欲界集　与色界集、无色界集乃至涅槃界集并列；「集」是四谛中苦集灭道之集，集起、生起义。此段谓菩萨如实知十一种界由何集起。
〔42〕 众生业化　与烦恼化、诸见化乃至如来化并列，共十种「化」；化谓变现造作，谓菩萨如实知众生业等种种变现。
〔43〕 佛持　与法持、僧持、业持、烦恼持、时持、愿持、供养持、行持、劫持、智持并列，共十一种「持」；持谓任持忆念不忘，谓佛于一切事皆能任持。
〔44〕 微细智　谓佛于修行、命终、受生、出家等微细之处无所不知的智慧；下文连举十种「微细智」。
〔45〕 如来秘密处　谓佛身、语、心等不可思议、非二乘所能知的秘密境界；下文列举身秘密、语秘密等十种秘密。
〔46〕 入劫智　劫，时间单位；谓于劫时自在互入互摄的智慧。下文连举一劫入阿僧祇劫等长清单，读法抓「某入某」的两端即可。
〔47〕 毛道智　毛道，凡夫的别称，谓其心行微细散乱如毛发；「入毛道智」谓佛智遍入凡夫境界。此段连举入毛道、入微尘、入众生身等诸种佛所入之智。
〔48〕 不思议解脱　此段列举十种解脱门（不思议、无障碍、净观察、普照明等），此其第一；解脱谓于诸法自在无碍。
〔49〕 陀罗尼　梵语音译，意译总持，于佛的法义忆持不忘；下文「闻持陀罗尼」即专指记闻不忘。
〔50〕 大法明　与「大法照」「大法雨」连用，以光明破暗、雨泽润生为喻，指诸佛所宣说的大法；第十地菩萨能于一念间安受摄持。
〔51〕 能安、能受、能摄、能持　安，容纳安放；受，领受；摄，摄取；持，保持。谓如大海受雨，堪任诸佛大法的灌注。
〔52〕 娑伽罗龙王　娑伽罗，意译咸海；此龙王即大海龙王，经中以它所降大雨唯大海能受，喻第十地菩萨堪受诸佛大法雨。
〔53〕 所霔大雨　霔（zhù），同「注」，倾泻而下；「所霔大雨」即所倾注的大雨。
〔54〕 何以故　为什么呢？佛经中自设问答的发端语，下文即自答其故。
〔55〕 三世法藏　藏（zàng），蕴积；谓过去、现在、未来三世诸佛一切教法之蕴积。
〔56〕 尔所　如此、那么多；「前尔所世界」即前面所说的那样多的世界。
〔57〕 佛事　佛教化众生的事业，如说法、示现成道涅槃等；「现佛事」谓随众生心而示现这些事业。
〔58〕 乱住、次住、倒住、正住　形容世界安立形态的种种差别（杂乱安住、次第安住、颠倒安住、端正安住等）；谓菩萨能令种种形态的世界互相转换。
〔59〕 娆害　娆（rǎo），扰乱；娆害即恼乱伤害，谓于众生无所扰害。
〔60〕 华奁　奁（lián），盛放物品的小匣；华奁即花匣。下文香箧（qiè）为香箱。
〔61〕 嘘气　嘘（xū），缓缓吐气；「以口嘘气」谓以口中吹气而震动世界，不令众生惊怖。
〔62〕 风灾　劫末坏灭世界有火、水、风三灾，风灾为其一；菩萨能随心示现此诸灾相。
〔63〕 乾闼婆　八部众之一，帝释天的奏乐之神，唯以香气为滋养。
〔64〕 护世四王　持国、增长、广目、多闻四大天王，护持四天下、守卫世界的护法天神。
〔65〕 释提桓因　即帝释天，忉利天（三十三天）之主。
〔66〕 摩醯首罗　梵语音译，意译大自在天，色界最高天（色究竟天）之主；第十地菩萨多示现为此天王。
〔67〕 疑网　疑惑重重、缠缚如入网中而难以自出；谓大众闻菩萨神通而生疑惑。
〔68〕 一切佛国土体性三昧　金刚藏菩萨所入的三昧之名；入此定者能于自身之内显现一切佛国土的体性，大众因此得见其身内三千大千世界。
〔69〕 师子座　师子，同「狮子」；佛菩萨的说法之座，喻说法无所畏惧。
〔70〕 得未曾有　佛经惯用语，谓遭遇前所未有之事，生起稀有奇特之心。
〔71〕 四天下　一须弥山四方之四大洲：东胜身洲、南赡部洲、西牛货洲、北俱卢洲。
〔72〕 优波尼沙陀分　梵语音译的极细分数名；谓纵以最小的分数相比，菩萨智慧较之如来仍不及一。
〔73〕 问难　难，读nàn，诘问、质询；「问难无能屈者」谓答一切质询而无人能使其屈服。
〔74〕 金师　金匠，打造金银器物的工匠。
〔75〕 钿厕　钿（diàn），把金银珠贝嵌饰在器物上；厕（cè），间杂。「钿厕其间」谓宝钿夹杂镶嵌其间。
〔76〕 十波罗蜜　波罗蜜，意译到彼岸；谓布施、持戒、忍辱、精进、禅定、般若、方便、愿、力、智十种，此地以智波罗蜜最为增上。
〔77〕 布施、爱语、利行、同事　即四摄法，菩萨摄化众生的四种方式：施以财利、以柔软语安慰、作利益之行助人、与众生同其事而度之。
〔78〕 阿耨达池　意译无热恼池，在雪山之北，池中流出四大河流注阎浮提；经中以十地如池出水，喻从十地流出善根大愿乃至入于一切智海。
〔79〕 十山王　名数读法：本段以十种山王依次配十地——雪山王配欢喜地、香山王配离垢地……须弥卢山王配法云地；每段先说山喻，再以「菩萨所住某地亦复如是」承接法义。
〔80〕 鞞陀梨山王　鞞（pí），音译山名，纯宝所成；偈颂中简称「鞞陀」。
〔81〕 由乾陀山王　音译山名，须弥山周围金山之一；偈颂中简称「由干」。
〔82〕 尼民陀罗山王　音译山名，意译持地，须弥山周围金山之一；偈颂中简称「尼民」。
〔83〕 斫羯罗山王　斫（zhuó），音译山名，即轮围山（铁围山）；偈颂中简称「轮围」。
〔84〕 计都末底山王　音译山名，须弥山周围金山之一；偈颂中简称「计都」。
〔85〕 三摩钵底　梵语音译，意译等至，指深度的禅定境界。
〔86〕 头陀　梵语音译，意译抖擞，谓抖擞烦恼、少欲知足的苦行；「持戒头陀」即持戒与头陀行。
〔87〕 六种十八相动　名数读法：六种为动、起、涌、震、吼、击，每种又分三重（如动、遍动、等遍动），六三成十八相；是说法时大地感动的瑞相。
〔88〕 缯盖　缯（zēng），丝织品；缯盖即丝帛制成的伞盖，供养之具。
〔89〕 妓乐　妓，同「伎」；妓乐即伎乐、音乐歌舞。
〔90〕 他化自在天王宫　他化自在天为欲界六天之顶；华严经十地品即在此天宫宣说，此句指本处说法的会座。
〔91〕 快说　快，精妙畅达；「快说此法」是赞叹金刚藏说法妙善，非快速之义。
〔92〕 三有　欲有、色有、无色有，即三界的生死存在；「三有一切皆无常」谓三界一切悉不常住。
〔93〕 十自在　第八地菩萨成就的十种自在——于命、心、资具、业、受生、胜解、愿、神力、法、智各得自在。
〔94〕 与其职　与（yǔ），授予；「诸佛与其职」即诸佛授菩萨以受职之位，即下偈「与灌顶」之义。
〔95〕 三界王　谓摩醯首罗天王，居三界之顶；第十地菩萨多示现为此王，善演三乘法。
〔96〕 嶷然　嶷（nì），高峻屹立的样子；谓十山王屹然并峙，喻十地安住于佛智之中。
〔97〕 十行超世　偈颂难点：自此以下数句以摩尼宝珠的十种事配十地——发心初配初地、持戒第二配离垢地、禅第三配发光地……第十灌顶配法云地，是上文「大摩尼珠十种性」一段的偈颂复述。
〔98〕 毫末度空　毫末，毛发之末，喻极微；度（duó），测量。谓国土碎为尘、以毫末量虚空尚可知其数，而此十地法门亿劫说之不尽。
