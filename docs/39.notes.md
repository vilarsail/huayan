# 大方广佛华严经卷第三十九 词语注释

① 十地品　《华严经》中宣讲菩萨十地阶位的品目，本卷为十地品第二十六之六，专讲第十地法云地。
② 那由他　印度极大数量词，一说为千亿，一说为万亿，泛指数量极多。文中「净居天众那由他」即言其数之众。
③ 金刚藏菩萨　本品的说法主，为十地菩萨之代表，由解脱月菩萨启请而广说十地行相。十方亦有同名金刚藏菩萨来证。
④ 解脱月菩萨　本品的请法主，代表众会向金刚藏请问十地功德、神通及佛智境界，起承上启下的作用。
⑤ 菩萨摩诃萨　梵语bodhisattva-mahasattva，意为大菩萨，指已登地以上的大乘菩萨。文中「菩萨摩诃萨从初地乃至第九地」即指此。
⑥ 白法　善法之异称，以善法清净洁白故名。文中「善满足白法」即圆满善根净行。
⑦ 受职位　菩萨入第十地所得之位，名为得一切种、一切智智受职位，表菩萨已得佛智之职，堪受灌顶。
⑧ 三昧　梵语samadhi，意为正定、等持，心专注一境而不散乱。本品广列菩萨所得百万阿僧祇三昧，如离垢三昧、海印三昧等。
⑨ 海印三昧　菩萨所得三昧之一，喻如大海能印现万象，定中能映现一切法界事相而不杂乱。
⑩ 阿僧祇　梵语asankhyeya，意为无数、无央数，表不可计数之极大量。文中「百万阿僧祇三昧」「百万阿僧祇光明」等皆极言其多。
⑪ 受一切智胜职位　菩萨所得最后三昧之名，此三昧现前时大宝莲华出生，标志菩萨正式受佛智之职。
⑫ 大宝莲华　菩萨受职时所坐之莲华座，量等百万三千大千世界，以众妙宝庄严，超一切世间境界，为出世善根所生。
⑬ 三千大千世界　佛教宇宙单位，一佛所化之境：一日月所照为一小世界，千小世界为一中世界，千中世界为一大千世界，合称三千大千世界。
⑭ 毗琉璃　梵语vaidurya，青色宝，即青琉璃。文中以毗琉璃摩尼宝为莲华之茎。
⑮ 阎浮檀金　阎浮树下水所产之紫金，色泽赤黄，为金中最胜。文中以之为莲华之叶。
⑯ 声闻　闻佛声教而悟道之小乘圣者，如阿罗汉。本品以声闻智与菩萨智、佛智相较，显十地之胜。
⑰ 辟支佛　梵语pratyekabuddha，意为缘觉、独觉，无佛世自悟十二因缘而解脱者。文中屡以辟支佛智不及十地菩萨。
⑱ 阿耨多罗三藐三菩提　梵语，意为无上正等正觉，即佛之果觉。文中言见此光明者皆于此得不退转。
⑲ 转轮圣王　亦称转轮王，以正法治世之圣王。本品以转轮王太子灌水受王职，喻菩萨受佛智水灌顶而堕佛数。
⑳ 灌顶　诸佛以智水灌菩萨顶，授以受职位，如转轮王取四海水瓶灌太子顶而授王位。灌顶已即堕在佛数。
㉑ 刹利　梵语ksatriya，王种，四姓之二。灌顶刹利王即已受灌顶之转轮王，喻菩萨受职。
㉒ 法云地　菩萨第十地之名。此地菩萨能受诸佛大法明雨，起大悲云震法雷普覆众生，如云如海，故名法云。
㉓ 陀罗尼　梵语dharani，意为总持、能持能遮，即忆持不忘法义之慧力。此地菩萨成就无量阿僧祇陀罗尼门。
㉔ 法明　法之光明，即能照明法义之教法。与法照、法雨并列，喻佛说大法能照、能润众生。
㉕ 娑伽罗龙王　梵语sagara，咸海之主，佛教所说降雨最多之龙。本品以之喻如来大法雨之大，唯大海能受。
㉖ 须弥卢　梵语sumeru，即须弥山，世界之中轴。本品以十山王之须弥卢喻法云地具众德，为十地之最胜。
㉗ 摩醯首罗　梵语mahesvara，即大自在天，居色界顶。本品以之喻十地菩萨多作摩醯首罗天王，于法自在。
㉘ 优波尼沙陀分　梵语upanisad，极细分之量，喻数量之极微，意谓连极小一分也及不上。
㉙ 十波罗蜜　在六度（施、戒、忍、进、禅、慧）外加方便、愿、力、智四波罗蜜，共十度，为菩萨十地所修。
㉚ 波罗蜜　梵语paramita，意为到彼岸、度，指菩萨六度或十度等究竟之行。此地以智波罗蜜最为增上。
㉛ 阿耨达池　梵语anavatapa，意译无热恼，即阿耨达龙王所住之大池，阎浮提四大河皆从此出。喻菩提心流出善根入一切智海。
㉜ 四摄法　菩萨度生之四方便：布施、爱语、利行、同事。文中以四摄充满众生喻如四大河注阎浮提。
㉝ 由乾陀　梵语gandha，香行。本品十山王之一，以喻难胜地菩萨自在如意神通咸在其中。
㉞ 尼民陀罗　梵语nimindhara，持地。十山王之一，喻远行地菩萨方便智慧独觉果证咸在其中。
㉟ 斫羯罗　梵语cakravada，轮围。十山王之一，喻不动地菩萨自在行差别世界咸在其中。
㊱ 计都末底　梵语ketumati，幢相、德相。十山王之一，喻善慧地菩萨世间生灭智行咸在其中。
㊲ 大摩尼珠　如意宝珠，出大海、能放光、随王意雨宝。本品以大摩尼珠十性喻菩萨十事出过众圣。
㊳ 六种十八相动　地震动之相：动、起、涌、震、吼、击六种，各有遍、等遍，合为十八相，表法殊胜。
㊴ 他化自在天　欲界第六天之顶，魔王所居。本品即在他化自在天王宫说十地法。
