# 大方广佛华严经卷第五 导读

## 一、内容总览
本卷是《华严经·世主妙严品第一》的第五段（之五），承接前几卷「菩萨众各得解脱门、各说颂偈赞叹如来」的体例，继续列举普贤菩萨所入十种不思议解脱门及净德妙光、海月光大明两组菩萨所证解脱门，并由各自的说偈展现如来功德海。本卷后半（P12 起）转入新的叙述层：如来师子座一切庄严具中各出佛刹微尘数菩萨，海慧自在神通王等十位上首菩萨依序起座说偈，赞叹道场、菩提树、宫殿、宝地、佛智与十地行，至 P31 善勇猛光幢总赞如来神变。末段（P33）以华藏庄严世界海六种十八相震动、世主各兴供养云收束，引出普贤境界在全法界的周遍展开，为下卷「毗卢遮那品第六」铺垫。

## 二、结构层次
本卷以「三组菩萨说解脱门 + 颂偈」为骨架，再以「师子座涌出菩萨众 + 十位上首依次说偈」承接，终以法界震动收束：

- **普贤入解脱门方便海**（P3-P5）→ 普贤承如来威神入十种不思议解脱门（严净国土、普诣如来所、安立菩萨地、普现身、演说差别名、尘中现菩萨神通、一念现三世劫成坏、示现诸根、神力化现身、显示修行法次第）→ 即以自功德说颂，总摄「佛身无去无来、一切国土明现、念念现三世劫成坏」之法界周遍义。
- **净德妙光组十菩萨各得解脱门**（P6-P8）→ 偏重「神通境界、法界藏、供养藏、无相法界」→ 颂偈归宗于「佛住真如法界藏、众生观见种种身」之真身与化身辩证。
- **海月光大明组十菩萨各得解脱门**（P9-P11）→ 偏重「诸地诸波罗蜜、法界差别处、毗卢遮那大愿海」→ 颂偈以「真如平等无相身、智慧寂静身无量」收束，强调法身普应。
- **师子座涌出菩萨众**（P12）→ 新转折：以「尔时」引入，师子座众宝妙华轮台基陛户牖一一各出佛刹微尘数菩萨，列海慧自在神通王等十位上首，述供养云、右绕、结跏趺坐，明其所证（陀罗尼门、三世平等智地、普门之地）。
- **十位上首依次说偈**（P13-P32）→ 每位皆以「尔时××菩萨承佛威力普观一切道场众海即说颂言」起，十偈次第赞：海慧赞佛身与莲华藏师子座；雷音普震赞佛座与地神庄严；众宝光明髻赞宝地与菩提树；大智日勇猛慧赞如来宫殿；不思议功德宝智印赞菩提树与道场；百目莲华髻赞摩尼妙音与树神；金焰圆满光赞如来十力（初智力、根智力等）；法界普音赞十波罗蜜（布施、净戒、忍、禅、般若、愿、力、智等）；云音净月赞菩萨十地（初地至法云第十地）；善勇猛光幢总赞众生悟入如来智、见佛法身、妙色身、智慧身、音声、光明、相好。
- **法界震动收束**（P33）→ 华藏庄严世界海以佛神力六种十八相震动，世主各兴供养云，明「十方尽法界虚空界一切世界海中悉亦如是」，以一摄多、以多即一，总收全卷。

## 三、关键结论
1. 普贤所入「不思议解脱门方便海」即如来功德海，十门各从「严净国土—普现身—演说名号—尘中现神通—一念现三世」层层展开，统归法界周遍。
2. 三组菩萨（普贤、净德妙光、海月光大明）所证解脱门虽名号各异，皆归于「真如法界藏、无相无形、众生观见种种身」之真身与化身的圆融。
3. 如来师子座一切庄严具中各出佛刹微尘数菩萨，显示「一即一切、一切即一」的华严事事无碍义——座上一个庄严具即摄全法界菩萨众。
4. 十位上首颂偈构成一个完整修学次第：道场庄严 → 菩提树 → 宝地 → 宫殿 → 十力 → 十波罗蜜 → 十地 → 众生悟入，从「境」到「行」到「果」层层递进，尤以法界普音之十波罗蜜、云音净月之十地为菩萨行门的两大纲领。
5. 全卷以华藏世界海六种十八相震动收束，明诸佛出世与法界周遍的相应——一佛坐道场，即全法界一切世界各各有佛坐道场，世主各各随其信解所缘入解脱门。

## 四、易混辨析
- **解脱门 vs 解脱门方便海 vs 解脱门海**：「解脱门」是菩萨所证的单个法门；「方便海」强调普贤以无量方便入；「门海」「众海」「庄严海」则形容其数量广大如海。卷中普贤所入是「不思议解脱门方便海」（总），下列十门是别。
- **法身 vs 妙色身 vs 智慧身**：法身是真如平等无相之体；妙色身是随众生解而变现的相好身；智慧身是三世平等、普随众生心乐的智用。三者不一不异，皆如来身之不同面向（P32 善勇猛光幢偈分述）。
- **莲华藏师子座 vs 华藏庄严世界海**：前者是毗卢遮那所坐之报土师子座（P14 海慧偈），后者是含摄一切世界的整体报土（P33）。前者是「座」，后者是「界」，皆以莲华藏为体。
- **十波罗蜜 vs 六波罗蜜**：本卷法界普音偈（P28）所举为十波罗蜜——布施、净戒、忍、禅（禅定）、般若、愿、力、智（方便、愿、力、智为后四加行），较常言之六度多出方便、愿、力、智四门。
- **十力 vs 十地**：金焰圆满光偈（P26）赞如来十力（处非处智力、根智力、业力、定力、欲力、性力、至处道力、宿命力、天眼力、漏尽力），云音净月偈（P30）赞菩萨十地（初地极欢喜至第十法云地）。前者是佛果之智用，后者是菩萨阶位，不可混为一谈。

## 五、阅读提示
读本卷可带着两个问题走：其一，普贤所入十解脱门与三组菩萨所证法门如何层层收摄于「真如法界藏」？其二，十位上首颂偈的次第（道场→树→地→宫殿→十力→十波罗蜜→十地）是否暗含一个从「境庄严」到「行庄严」到「果庄严」的修学路径？抓住这两条线索，全卷的颂偈便不是堆砌而是有序展开。
