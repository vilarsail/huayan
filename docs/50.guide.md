# 大方广佛华严经卷第五十 导读

## 一、内容总览

本卷为《大方广佛华严经》「如来出现品第三十七」之首卷（之一），承接前文菩萨行愿圆满之后，转入对「如来出现」这一大法的开示。全卷由两番光明发起，经如来性起妙德菩萨启问、普贤菩萨作答，以「如来出现十相」与「如来身十相」两大譬喻体系，阐明佛之所以出现于世的事相因缘与法身遍满的理体境界。

## 二、结构层次（★重点）

全卷以「光明两番启问 → 普贤十相答出现 → 普贤十相答佛身 → 重颂收束」一线贯穿：

- **光明发起（总起）**：世尊眉间放「如来出现」光，入妙德菩萨顶（表请法主）→ 佛口放「无碍无畏」光，入普贤口，普贤身座增胜百倍（表说法主）。两番光明分别加被「问」「答」之主。
- **启请（妙德二请）**：先长行问「如来出现之法」——身相、言音、心意境界、所行、成道、转法、入涅槃、见闻亲近所生善根；后重颂广请，并请以因缘譬喻演说。
- **正答·如来出现十相（事相因缘，以世界成劫为喻）**：
  - 第一相：以三千大千世界「大云降雨、四风轮相依」喻如来四种大智风轮，明「非一缘一事，无量因缘乃成」；
  - 第二至第七相：以「洪霔大雨（二乘不能受）」「雨无所从来」「摩醯首罗知雨滴数（唯菩萨能知）」「能灭能起能止能成分别五味」「一味水随器差别」「先色界后欲界次人天」六喻，次第显法云一味而差别；
  - 第八相（最长）：以世界初成时大莲华瑞、诸风轮成宫殿山川，配如来十种大智光明、灌顶授记、不断三宝种，明佛功德「非神力造，皆由众生善根与佛威德」；
  - 第九相：以「地依水、水依风、风依空、空无所依」喻「慈悲依方便、方便依出现、出现依无碍慧、无碍慧无所依」的相待缘起链；
  - 第十相：以世界成已饶益水陆空居众生，喻如来出现令见者、持戒者、修禅者各得其益。
- **结劝十知（收束事相）**：菩萨知如来出现则知无量、广大、无来去、无行、无身、平等、无尽、无退、无坏、无二。
- **重颂一**：普贤以偈重明出现十相譬喻。
- **正答·如来身十相（法身遍满，以虚空日月等为喻）**：第一相虚空遍至一切色非色处喻佛身遍一切处无身而示现；第二相虚空现一切色无分别喻佛身智光普照无戏论；第三、四相日出阎浮益众生、日照山原先后喻佛智日随根器普益；第五相生盲不见日而蒙益喻无信众生不见佛智日仍得饶益（广列十种光明、毛孔放光令菩萨得十头十眼十地）；第六至第十相以月轮四奇特、梵王不分身普现、医王涂身不坏、海中集光摩尼宝、如意宝王少福不见五喻显如来身。
- **重颂二**：再以偈收束佛身诸喻。

全文骨架：**光明发起 → 请问 → 长行十相（事相）→ 重颂一 → 长行十相（法身）→ 重颂二**，长行与重颂两两对应，事相（出现因缘）与理体（法身遍满）相即不二。

## 三、关键结论

1. 如来出现「非以一缘一事」得成，以无量因缘乃得成就——破「佛由单一因成」之执，显缘起重重无尽。
2. 如来大悲一味法雨无分别，随众生根欲不同起种种大智风轮——一味与无量差别不二。
3. 「慈悲依方便，方便依出现，出现依无碍慧，无碍慧无所依」——层层相待，终归于无依，即缘起而性空。
4. 如来身「遍一切处、无身故为众生示现」——法身无身而普现色身，破「佛有定量身」之执。
5. 佛之饶益普及生盲（无信毁戒）乃至地狱饿鬼畜生——显如来大悲平等无遗。

## 四、易混辨析

- **如来出现 vs 如来身**：先答「出现」（佛出世的事相因缘，约用），后答「如来身」（佛身相体性，约体），体用相即。
- **性起妙德菩萨 vs 普贤菩萨**：妙德为启请者，承眉间光入顶而发问；普贤为作答者，承佛口光入身而身座增胜。一问一答由两番光明分别加被。
- **二乘 vs 菩萨摩诃萨**：二乘「心志狭劣」不能受持如来大法云雨，唯除菩萨以过去觉慧力故一一明了——显华严「唯菩萨境界」之宗趣。
- **法性无生无作 vs 如来出现有相**：法性「无生者、作者、知者、成者」而世界得成，如来出现亦「无生无作而得成就」——非断灭无相，乃「无生而生」的缘起妙相。

## 五、阅读提示

读本卷可带着两个问题：佛既「无身、无分别、无所作」，为何又「出现于世、随机说法」？留意「一味法雨」与「无量差别」如何在同一句中并立——这是华严「理事无碍」最直接的示范。
