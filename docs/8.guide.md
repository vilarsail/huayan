# 大方广佛华严经卷第八 导读

## 一、内容总览
本卷为《华严经》第五品「华藏世界品」之上半，承前卷普贤菩萨之说，专讲「华藏庄严世界海」的成因与层层庄严相。以毗卢遮那如来往昔于微尘数劫中亲近微尘数佛、修微尘数大愿为因，感得此一世界海。全卷由风轮、轮围山、大地、香水海、世界种、二十重世界依次展开，将「因行→果报庄严→世界结构」一线贯通，是研究华严「依正不二」「一多相即」宇宙观的核心文本。

## 二、结构层次
全卷由普贤菩萨十度复告大众，每度「长行 → 颂偈」成对，层层上推：

- **成因追述（P3-P5）**：先明华藏世界海是毗卢遮那修菩萨行所严净 → 转入器界依持之相：以须弥山微尘数风轮持之，最上风轮持香水海，海生大莲华，世界住其中，外有金刚轮山周匝围绕 → 颂偈总括「往昔愿行→今世庄严」因果。
- **大轮围山庄严（P6-P8）**：山住日珠王莲华之上，栴檀摩尼为身、宝王为峰、金刚成立，香水流注、众宝为林 → 颂中点出「诸庄严中现佛身」「毗卢遮那清净身悉入其中」，庄严即佛身。
- **大地庄严（P9-P11）**：金刚所成、清净平坦、摩尼为网普现如来境界，如帝网布列 → 颂中「一一尘中见法界」「一宝中现无边广大劫」，明事理互摄；末句「修普贤愿者能知」收束，点出能观之机。
- **香水海庄严（P12-P14）**：大地中有不可说佛刹微尘数香水海，底岸网华阶陛栏楯层层严饰，诸庄严悉现其中 → 颂末「毗卢遮那往昔严净刹海」再扣因果。
- **两间地与香水河庄严（P15-P17）**：海间之地有树出音说愿、散摩尼宝王充遍 → 颂中「一一尘中咸见佛」「各见所记当来刹」，明一尘摄多劫多佛。
- **世界种安住与形相体性（P18-P23）**：由「有何等世界住」之问引入，列举世界种之依住（莲华海、宝璎珞海、佛音声海等）、形状（须弥、江河、回转、轮辋、坛墠、莲华、佉勒迦等）、体性（摩尼云、光明、宝香焰、众生福德音声、佛功德音声等）→ 颂中点出「一入一切、一切入一，体相无差别」，显一多相即、重重无尽。
- **中央世界种二十重世界（P24-P26）**：最中央无边妙华光香水海出世界种「普照十方炽然宝光明」，最下名最胜光遍照，向上层叠至第十三娑婆世界即毗卢遮那所都，再上至第二十妙宝焰 → 末段总收「十佛刹微尘数各类形世界各各有十佛刹微尘数眷属」，归摄于中央一海及围绕河中，显帝网重重。

## 三、关键结论
1. 华藏世界海全相，皆是毗卢遮那往昔愿行之所严净——依正不二，国土庄严即佛果德用。
2. 器界层层以风轮持之、以金刚围之、以摩尼严之，结构虽繁，归趣在「一一尘中见法界」「一宝中现诸佛」——事即是理，相即是体。
3. 世界种形状体性各各差别无量，却又「一入一切、一切入一，体相无差别」——差别即无差别，多即是一。
4. 娑婆世界位列中央种第十三重，即毗卢遮那所都——此土本是华藏中之一，非凡夫所见的秽土，破「此界秽、他方净」之执。
5. 能见此庄严者，须「修普贤愿、入佛境界大智」——观机条件明确，呼应普贤行愿为入华藏之钥。

## 四、易混辨析
- **风轮 vs 金刚轮山**：风轮在下方层层托持香水海与莲华，是「能持」之动力；金刚轮山周匝围绕世界海外围，是「能护」之界垣。一持于下，一围于外。
- **世界海 vs 世界种 vs 世界**：世界海（如华藏庄严世界海）是最大范围；世界种是海中安住的「种」（类别/聚落），一世界种含不可说佛刹微尘数世界；世界是种中具体的一刹（如娑婆、最胜光遍照）。三者层层含摄。
- **毗卢遮那 vs 卢舍那**：本卷统称「毗卢遮那如来」，指法身佛所显的他受用身，即华藏世界之教主；旧译（如旧《华严》）作「卢舍那」，新译（实叉难陀本）作「毗卢遮那」，所指同一法身。
- **尸罗幢 vs 因陀罗网**：尸罗幢为戒德所成之宝幢（如「众色金刚尸罗幢海」）；因陀罗网即帝释天宫之网，网孔皆现一切，喻重重无尽（如「状犹如因陀罗网」）。一表戒德严身，一表重重互摄。
