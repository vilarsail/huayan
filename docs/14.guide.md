# 大方广佛华严经卷第十四 导读

## 一、内容总览

本卷（《大方广佛华严经》卷第十四）含两品：前为《净行品第十一》之全部，后为《贤首品第十二》之前半（"之一"）。承前卷文殊菩萨答智首菩萨之问，本卷先以一百四十愿偈示菩萨"善用其心"于日用云为中处处发愿、转事为道，次由贤首菩萨以长偈广赞初发心功德，层层递进，由信、戒、波罗蜜、十地、灌顶一路推至海印三昧、佛华严三昧等不可思议境界，点明菩提心功德不可量、菩萨三昧神通无量方便度生之要旨。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

本卷以"问→偈答→广赞"三段一线贯穿：

- **智首设问（总起）** → 智首菩萨以十一组"云何得"问菩萨身语意业、生处具足、智慧、因力、善巧、觉分、波罗蜜、十力、天王守护、为众生依怙、为众生第一等胜妙功德 → 提出修行所应成就的全体目标。
- **文殊偈答：善用其心（承接）** → 文殊师利先总答"若诸菩萨善用其心，则获一切胜妙功德"，指出下手处在"用心"；次以"菩萨在家……睡眠始寤"一百四十颂，将菩萨一日行持（在家、出家、着衣、乞食、见路、见人、饭食、洗浴、礼塔、寝息）每一事转为"当愿众生……"之愿 → 以事显理，于一一境中发菩提心。
- **文殊收束（小结）** → "若诸菩萨如是用心，则获一切胜妙功德……所不能动" → 结证上文，一切世间、声闻缘觉所不能动。
- **贤首广赞发心功德（递进展开）** → 文殊复以偈问贤首，贤首以长偈应之：
  - 先明发心功德无边（"譬如大海一滴水""鸟足所履空""大地一微尘"之喻）→ 言不可量。
  - 次明发心因缘：信三宝、为利众生、不求五欲王位 → 示发心正因。
  - 次以"信"为道元功德母，由信→持戒→功德→善知识→菩提心→波罗蜜→如来家→念佛不动→见法不灭→辩才→大悲→四摄→摧魔→不退地→无生法忍→诸佛授记→佛现前→佛德庄严→三十二相→身光出莲华→调伏众生，如是层层相生，约六十余"若……则……"连锁偈 → 显信→戒→定→慧→悲→方便→神通→灌顶之因果链。
  - 次明菩萨三昧神通：海印三昧、佛华严三昧于一微尘中现无量刹；以一手遍三千供养诸佛；放光出华、香、衣、宝、幢、盖、璎等庄严具普供十方 → 示依正自在。
  - 次明菩萨随乐三昧，以八万四千法门、同事苦行、种种身形（童男童女、天龙八部、外道、邪命、五热炙身、牛狗鹿戒等）随类化度 → 示方便度生。
  - 末以"或边咒语说四谛……或一切语说四谛""知语境界不思议，是名说法三昧力"收束 → 归于说法三昧。

## 三、关键结论

1. "善用其心"是菩萨日用修行之纲领：不必外求胜妙功德，于一一境发愿利他，当下即是菩萨行。
2. 净行一百四十愿偈示范"转事为道"之法：在家、着衣、饭食、见路、见人乃至睡眠，无一不可发愿，无一不是道场。
3. 菩提心功德不可量：初发心即摄佛果功德，"信为道元功德母"，由信起行，由行入地，由地得灌顶成佛。
4. 菩萨以三昧力（海印、佛华严、随乐等）于一微尘中现无量刹、以一手供养十方佛、随类现形度生，显示因陀罗网法界互摄之相。
5. 菩萨度生以"随其所解语言音"说四谛、八万四千法门，同事外道邪行而不被染，"譬如莲华不着水"。

## 四、易混辨析

- **净行品 vs 贤首品**：净行品为文殊所说，重"善用其心"发愿（事中修）；贤首品为贤首所说，重"发心功德"与三昧神通（理上显）。一品示下手，一品示果相。
- **阿阇梨 vs 和尚**：阇梨（阿阇梨）为教授师，主威仪、羯磨、教诫；和尚（邬波驮耶）为受戒本师，主亲教。本卷"受阇梨教""受和尚教"并列，二者有别。
- **僧伽蓝 vs 僧伽梨**：僧伽蓝为寺院（僧众共住处），僧伽梨为三衣中之大衣（僧伽梨衣），本卷"入僧伽蓝""着僧伽梨"各有所指，不可混。
- **海印三昧 vs 佛华严三昧**：海印三昧侧重"一念顿现万法"如海印影；佛华严三昧侧重"以佛华严（因位万行庄严）入法界"，二昧同体异名、侧重不同。
- **不退地 vs 无生法忍**：不退地（不退转地，多指八地或初住）侧重位不退、行不退、念不退；无生法忍侧重亲证无生之理，二者可分可合，本卷"则得至于不退地→则得无生深法忍"递进。

## 五、阅读提示

读净行品时可随文自照：菩萨遇一一境即发一一愿，自己日用中哪些境未发愿？读贤首品时注意"若……则……"连锁偈的因果递推，看由"信"一路如何推到"灌顶成佛"，再读海印、佛华严二昧段时，体会一多相即、一微尘中现无量刹的法界观。
