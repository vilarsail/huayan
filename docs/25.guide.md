# 大方广佛华严经卷第二十五 导读

## 一、内容总览

本卷属《华严经·十回向品》第三部分，承接前卷十回向的次第，正式展开第五、第六两个回向位的修行内涵：先是「无尽功德藏回向」，以随喜、忏悔、劝请所起善根回向严净一切佛土；继而「随顺坚固一切善根回向」，以菩萨种种布施——饮食、车乘、衣华、床座、房舍、灯明、汤药、宝器——所起善根回向利益众生。两条回向贯穿「回自向他、回因向果、回事向理」的华严回向义，由事修层层导入法界无所得的理观。

## 二、结构层次（★重点）

全文按「总明第五回向 → 别显第六回向 → 颂偈收束」三大段推进：

- **第五回向·无尽功德藏**（P3-P8）：
  - 起善根（P4）→ 列忏悔、礼敬、劝请、随喜等所起善根为体；
  - 回向庄严佛土（P4-P5）→ 以一切善根回向「尽法界虚空界一切佛土」，愿一世界具足一切诸佛国土庄严；
  - 回向充满菩萨（P5）→ 愿所修佛刹中诸大菩萨充满，体性真实、智慧通达；
  - 方便回向十事（P6）→ 「方便回向一切佛刹」等十种方便，归于不分别、无所著；
  - 得无尽善根（P6-P7）→ 念三世诸佛、净诸佛刹等九句，得「无尽善根」；
  - 结名显益（P8）→ 「是名第五无尽功德藏回向」，得十种无尽藏（见佛、入法、忆持、决定慧……）。
- **颂偈收束**（P9-P34）：金刚幢菩萨普观十方说颂，重宣第五回向义——菩萨以劝请随喜福无碍回向，庄严佛刹；进而观诸法因缘生、无所得，了知业果平等、众生寂灭，不坏因果而不著相。
- **第六回向·随顺坚固一切善根**（P35-P51）：
  - 总明布施行相（P36）→ 菩萨或为转轮王，施饮食、车乘、衣服、华鬘，乃至身肉、王位、妻子、牢狱救赎；
  - 别明十一种施之回向（P37-P51）→ 依「施食→施饮→施味→施车乘→施衣→施华→施鬘→施香→施涂香→施床座→施房舍→施住处→施灯明→施汤药→施宝器」次第展开，每一种施皆以善根回向，愿众生得对应的法益（智慧食、法味水、惭愧衣、戒香、智幢光……）；
  - 「善摄」为纲（P36）→ 善摄色、受、想、行、识，善摄王位、眷属、资具、惠施，随顺坚固一切善根。

## 三、关键结论

1. **回向即庄严**：菩萨以忏悔、劝请、随喜所起善根回向，等于将三世诸佛一切功德庄严摄入一世界，使一世界即具足一切佛土庄严——这是「一即一切」的华严圆融观在回向位的具体表现。
2. **理事无碍**：事上勤修布施（饮食、身肉、王位），理上观「一切法因缘生、无所得、无作者、无补伽罗」；不坏因果而不取著，是「不坏假名而说实相」的菩萨行。
3. **善摄为根**：第六回向以「善摄五蕴、王位、眷属、资具、惠施」为纲要——能施之物、所施之境、施者本身悉皆善摄，方名「随顺坚固」。
4. **无尽藏为果**：住第五回向得十种无尽藏，从见佛、入法到十力无畏，显示回向功德的果报圆满，与「无尽」之名相应。

## 四、易混辨析

- **回向 vs 随喜**：随喜是「见他善根而生欢喜」，是发起善根的因行之一；回向是将自他所修善根「回转趣向」一切众生、佛菩提，是善根的导向与交付。本卷先列随喜所起善根，再以此善根回向，次第分明。
- **无尽功德藏回向 vs 随顺坚固一切善根回向**：前者以「心念、观解」为主——随喜三世善根、观佛土庄严；后者以「事行布施」为主——饮食、身肉、王位等具体施与。前者偏理，后者偏事，合显理事并修。
- **善摄 vs 摄取**：善摄是菩萨于所施境、所修善根善加护念不令失坏，重在「能摄之心」；摄取是得果时聚集成办，重在「所成之德」。本卷第六回向以善摄为方便，最终得摄取福德。
- **萨婆若 vs 阿耨多罗三藐三菩提**：萨婆若（Sarvajña）即「一切智」，是佛智总体；阿耨多罗三藐三菩提侧重「无上正等正觉」。经中两词并见，义可互通，侧重略异。

## 五、阅读提示

读本卷可带着两个问题：菩萨广修布施、身肉王位皆能施与，何以又说「一切众生无有生」「无众生可流转」？事修与理观如何并行不悖？又，每种布施回向之后皆有一句「为令众生……故」，留意这一收束句式，可见菩萨回向的「为他」宗旨。
