# 大方广佛华严经卷第七十四 词语注释

① 入法界品　《华严经》最后一品，善财童子南参五十三善知识的主体部分，本品为第三十九之十五。
② 善财童子　《入法界品》主参访者，福城东童子，已发菩提心，遍参善知识求菩萨行。
③ 大愿精进力救护一切众生夜神　善财上一参所参夜神，善财于此得菩萨解脱后渐次至岚毗尼林。
④ 岚毗尼林　即蓝毗尼园，迦毗罗城外之林苑，本师释迦降生之处，本卷林神所居、善财参访之所。
⑤ 妙德神　即岚毗尼林神，本卷善知识，为善财说菩萨受生藏与诞生神变法门。
⑥ 那由他　梵语nayuta，印度极大数词，约当千万或亿，泛指极多，如「二十亿那由他诸天」。
⑦ 阿耨多罗三藐三菩提　梵语，意为无上正等正觉，佛果之智，菩萨发心所求。
⑧ 受生藏　菩萨生如来家之十种法门，从愿常供养诸佛到入如来地，总为菩萨受生之因行。
⑨ 佛刹微尘数　以一佛刹研为微尘之数，华严常用极大数喻。
⑩ 菩萨摩诃萨　摩诃萨意为「大」，即大菩萨，登地以上之大心众生，区别于初发心菩萨。
⑪ 三昧　梵语samādhi，正定，心一境性，菩萨所修种种三昧为法门总持。
⑫ 佛刹　一佛所教化之国土，亦称佛国、佛土，如「佛刹微尘数」表极多。
⑬ 童真位　菩萨修行阶位之一，指离染清净、如童子之位，第八受生藏所住。
⑭ 毗卢遮那　梵语Vairocana，光明遍照之意，华严宗立法身佛称，本经以毗卢遮那为释迦之法身。
⑮ 灌顶　梵语abhiṣeka，王位传承之灌水仪式，佛教借指菩萨登第十地受佛智水、继佛位之法。
⑯ 萨婆若　梵语sarvajña，一切智，佛智之总称，颂中「久已修行萨婆若」即久修一切智之行。
⑰ 阎浮提　南赡部洲，即吾人所居之世界，佛降生之处。
⑱ 兜率陀天　欲界六天第四天，佛将降生前于此观察时节因缘，然后下生阎浮提。
⑲ 摩尼　梵语maṇi，如意宝珠，净光能出众宝，华严常作庄严具。
⑳ 娑婆世界　梵语Sahā，意为堪忍，本师释迦所化之三千大千世界。
㉑ 夜叉　梵语yakṣa，飞行鬼神，佛教八部众之一。
㉒ 乾闼婆　梵语gandharva，天乐神，以香为食，八部众之一。
㉓ 阿修罗　梵语asura，常与帝释战之天神，六道之一，八部众之一。
㉔ 迦楼罗　梵语garuḍa，金翅鸟，以龙为食，八部众之一。
㉕ 紧那罗　梵语kiṃnara，人非人歌神，八部众之一。
㉖ 摩睺罗伽　梵语mahoraga，大蟒神，八部众之一。
㉗ 毕洛叉树　岚毗尼园中摩耶夫人攀之诞菩萨之树，即毕钵罗树（菩提树之类）。
㉘ 摩耶夫人　本师释迦生母，迦毗罗城净饭王夫人，于岚毗尼园毕洛叉树下生菩萨。
㉙ 波罗蜜　梵语pāramitā，意为到彼岸，菩萨六度或十度之行，究竟圆满之称。
㉚ 三千大千世界　一佛所化之境，合一千小千、中千、大千而成，即百亿世界。
㉛ 微尘数　以微尘为喻之极大数，华严常用「刹微尘数」表不可思议之量。
㉜ 金刚际　大地最底层之金刚石层，佛教世界观中支撑世界之坚实基底，第十神变大莲华从此涌出。
㉝ 如意宝王　如意宝中之上首，能随愿出生众宝之宝王，作大莲华之台。
㉞ 采女　宫中侍女，悦乐劫喜光夫人将诞生时与二十亿那由他采女诣金华园。
㉟ 普眼三昧　乳母净光捧持初生菩萨时所得之定，普见十方无量诸佛之正定。
㊱ 释种　释迦族之种姓，瞿波为释种女，善财下一参之善知识。
㊲ 瞿波　迦毗罗城释种女，善财下一参之善知识，林神指示善财往参。
