# 大方广佛华严经卷第七十四 词语注释

〔1〕 实叉难陀　唐代来华的于阗国译经僧（652-710），八十卷本《华严经》的译者。「三藏」指通晓经律论三藏的法师；「奉制译」谓奉皇帝诏命翻译。
〔2〕 尔时　文言连接词，「那时候」「正当此时」，用于承接前文、引出下一段叙事，无实义。
〔3〕 善财童子　《入法界品》的主人公，为求菩萨道而历参五十三位善知识的青年。本卷是他参访岚毗尼林神的一段。
〔4〕 大愿精进力救护一切众生夜神　善财前一参所拜访的夜神（夜间护法神），本卷开头说善财刚在其处证得菩萨解脱。
〔5〕 岚毗尼林　即岚毗尼园，古印度迦毗罗城郊的园林，释迦牟尼佛诞生之地。本卷的「岚毗尼林神」即守护此园之神，善财在此参访的对象。
〔6〕 妙德神　即岚毗尼林神的别名，善财到园中寻觅「彼妙德神」就是找这位林神。
〔7〕 那由他　梵语音译数量词，约等于千亿（一说万亿），泛指极多之数。
〔8〕 阿耨多罗三藐三菩提　梵语音译，意为「无上正等正觉」，即佛的圆满觉悟；「发阿耨多罗三藐三菩提心」即发愿成佛之心。
〔9〕 云何　文言疑问词，「如何」「怎么」，常用于自设问答：「云何名X」即「什么叫做X」。
〔10〕 为世大明　成为世间的大光明，喻作众生迷暗中照耀引导的明灯。这是善财问话中「菩萨行」的goal之一。
〔11〕 受生藏　本卷核心概念。「受生」指菩萨乘愿入母胎受身出生；「藏」是含藏、宝藏，指含摄功德的法门。十种受生藏即菩萨「生如来家」所依的十种法门。
〔12〕 趣一切智　「趣」是趣向、趋向；「一切智」即佛的遍知一切之智。「趣一切智」谓朝向佛智前进。
〔13〕 诸度　即诸波罗蜜（六度、十度等），布施、持戒、忍辱、精进、禅定、智慧等到达彼岸的修行法门。「诸度海」喻其深广如海。
〔14〕 所谓　文言提示词，「就是下面所说的」，用于列举展开前文总说，无实义。
〔15〕 佛刹微尘数　把一个佛国土碾碎成微尘，以尘数计量，华严经表示极大量的惯用语。
〔16〕 劫火炽然　「劫火」是坏劫时烧毁世界的大火；「炽然」即炽燃。形容修行功德如劫火般猛烈不熄、无有间歇。
〔17〕 普贤行　普贤菩萨所代表的菩萨广大修行总持，华严经中菩萨行的典范，遍周法界、无尽无碍。
〔18〕 背舍　佛教术语，即「八背舍」，背离舍离贪著的禅观法门。此处「背舍一切诸有趣生」指舍离在诸有（三界）中流转受生。
〔19〕 护念　护持忆念，指诸佛时时摄受加持修行者，「常为诸佛之所护念」是被佛惦记护佑之意。
〔20〕 法忍　于法（尤指甚深法理）安忍不动、信受不疑的智慧力。「具足忍法，成就诸佛法忍光明」谓忍力圆满而放智慧光明。
〔21〕 普门定　普遍开通、门门皆入的禅定，谓一一三昧中能普摄一切三昧门。
〔22〕 白净善法　「白净」喻清净无垢（白色在佛经中表善净）；「白净善法」指出离世间染污的清净善法。
〔23〕 童真位　菩萨阶位之一，离淫欲、保持童子般纯真的清净位（约当十住中童真住）。「住童真位」谓已至此清净阶位。
〔24〕 悉假施设　「假」是假借，「施设」是安立、建立；谓一切世间存在都只是假名安立、并非实有自体。
〔25〕 识心所起　由阿赖耶识等心识所变现生起。承上句「知诸世间悉假施设」，谓世间万相皆是识的显现，唯识无境之义。
〔26〕 毗卢遮那　梵语音译，意为「遍照」，华严经的教主，光明遍照一切法界的佛。此处「三昧毗卢遮那智慧之藏」谓常住在毗卢遮那佛那样的智慧宝藏中。
〔27〕 灌顶法　原为古印度王位继承时以水灌顶的仪式，佛教借喻法王（佛）认证补处菩萨将成佛的仪式。「于三世诸如来所受灌顶法」谓受诸佛的成佛认证。
〔28〕 前际后际没生次第　「前际」指过去，「后际」指未来；「没生」指死后投生（殁而复生）。整句谓了知众生过去未来生死流转的次序。
〔29〕 调伏　调教降伏众生的烦恼心性，使之柔顺向道，是佛教对教化众生的惯用语。
〔30〕 瞻奉　「瞻」是瞻仰，「奉」是侍奉；「恒瞻奉」谓恒常瞻仰礼拜并承事供养。
〔31〕 一切种智　佛三智之一，既知一切法总相（一切智）又知一一法差别相（种智），唯佛圆满具足。
〔32〕 群品　「品」是品类；「群品」即芸芸众生、各类有情。
〔33〕 萨婆若　梵语音译，意为「一切智」，即佛的遍知智慧。「久已修行萨婆若」谓早已修习佛智之道。
〔34〕 阎浮提　梵语音译，即南赡部洲，四大部洲中人类所居的世界，佛在此洲出生说法。
〔35〕 兜率陀天　梵语音译，六欲天中的第四天（兜率天）。补处菩萨成佛前居于此天，释迦牟尼下生前即住此，故云「从兜率陀天而来生此」。
〔36〕 堆阜　「阜」（音fù）为土山；「堆阜」即土堆小丘。瑞相中地自平坦，坑洼土丘皆消失。
〔37〕 株杌　「杌」（音wù）为树桩；「株杌」即残存的树根树桩，与瓦砾荆棘并列为荒地之物，瑞相中皆不现。
〔38〕 宝多罗树　「多罗」为梵语音译，一种高大的棕榈树，其叶可写字（贝叶经），佛经中常以「多罗树」行列喻庄严齐整。
〔39〕 扶疏荫映　「扶疏」形容枝叶繁茂舒展，「荫映」谓枝叶遮覆掩映。形容宝香树茂盛庄严的样子。
〔40〕 华鬘　「华」同「花」；「鬘」（音mán）是串花编成的环状饰物。「华鬘」即花环，为供养具之一。
〔41〕 摩尼　梵语音译，意译「如意珠」，能随心生出诸物的宝珠，佛经常以摩尼宝喻功德神用。
〔42〕 池沼　「沼」（音zhǎo）为小水池；「池沼」泛指池子水塘。
〔43〕 娑婆世界　梵语音译，意为「堪忍」，即我们居住的这一世界，众生能忍受众苦，故称娑婆。
〔44〕 欲色所住天　「欲色」指欲界与色界；「欲色所住天」即居于欲界、色界二界的天众。
〔45〕 乾闼婆　梵语音译，天龙八部之一，帝释天的乐神，以香气为食，善奏音乐，此处前来供养赞颂菩萨。
〔46〕 迦楼罗　梵语音译，天龙八部之一，即金翅鸟神，翅金色，以龙为食，力大无比。
〔47〕 紧那罗　梵语音译，天龙八部之一，歌神，形貌似人而头上有角，善歌咏，此处赞颂菩萨功德。
〔48〕 摩睺罗伽　梵语音译，天龙八部之一，即大蟒神（腹行神），无足腹行，亦能闻法护持。
〔49〕 毕洛叉树　梵语音译树名，即毕钵罗树一类（菩提树属）。传说菩萨诞生的瑞相中，摩耶夫人于毕洛叉树下停留。
〔50〕 诸佛齐中　「齐」是同时、一齐；「十方一切诸佛齐中皆放光明」谓十方诸佛同时在其佛土中放出光明。此句读法：「诸佛齐中」＝诸佛（各自）同时（于其处）。
〔51〕 摩耶夫人　释迦牟尼佛的生母，迦毗罗城净饭王之王妃。本卷岚毗尼林神自述曾为乳母，而摩耶夫人在一切佛的受生处恒为其母，是本卷参访的重要示现者。
〔52〕 迦毗罗城　古印度释迦族的首都，净饭王与摩耶夫人所居，释迦牟尼佛的故乡。
〔53〕 三千大千世界　以须弥山为中心的一个世界为一小千，千个小千为中千，千个中千为大千；「三千」即三重千倍，是一佛所教化的世界范围。
〔54〕 城邑聚落　「城邑」指城池都邑，「聚落」指村庄聚居处，泛指人间大小居所。
〔55〕 靡不皆现　「靡」（音mǐ）是无、没有；「靡不皆现」即没有不显现的，一一皆现。
〔56〕 璎珞　梵语音译（略），用珠玉宝石串成的颈饰、胸饰，佛菩萨与贵族的庄严具。
〔57〕 末香　研成粉末的香料，与「涂香」（涂身的香膏）同为佛前供养之物。
〔58〕 幡缯　「幡」（音fān）是长条形旗帜，「缯」（音zēng）是丝织品；「幡缯」即丝帛所做的供养幡旗。
〔59〕 幢盖　「幢」（音chuáng）是竿上安宝珠丝帛的庄严柱形物，「盖」是伞盖；皆为庄严供养具。
〔60〕 妓乐　「妓」此处同「伎」，指歌舞；「妓乐」即音乐歌舞，此处为供养佛的音声供养。
〔61〕 金刚际　指世界最底层依止的金刚地基之边际，佛经中世界悬浮于金刚轮上，「从金刚际出大莲华」谓此莲华从世界之根底涌出，极言其殊胜。
〔62〕 憍慢　「憍」（音jiāo）同「骄」，自高自大；「憍慢」即憍傲我慢。阿修罗王「舍憍慢心」谓舍离傲慢而顶礼。
〔63〕 稽首　古礼，头叩至地再起的至敬之礼，即叩头；「稽首敬礼」谓至诚顶礼。
〔64〕 缯幡　丝帛所制的幡旗。「迦楼罗王垂宝缯幡」谓金翅鸟王垂挂宝幡遍布虚空以为供养。
〔65〕 普雨　「雨」在此作动词（音yù），降下、洒下之意。「普雨一切宝庄严云」谓普遍降下宝物庄严如云雨般。
〔66〕 庆云　祥瑞的云，古人视为吉祥之兆。「如高山顶出于庆云」喻菩萨诞生时身相光明的瑞相。
〔67〕 而然大炬　前一个「然」是「……的样子」，后一个「然」同「燃」；「然大炬」即点燃火把。谓如黑夜中燃起大火炬。
〔68〕 从母胁生　「胁」（音xié）即肋下、腋下。谓菩萨从母亲右胁侧出生，是佛教圣者诞生的传统记载。
〔69〕 四天下　一个须弥山四方各有一大洲（东胜身、南赡部、西牛货、北俱卢），合称四天下，即一日月所照的世界。
〔70〕 其已久如　文言问句式：「（您得此解脱）到现在已经多久了？」——「其」是语气助词，「已」是已经，「久如」即多久。
〔71〕 乃往古世　经中讲宿世因缘的套语，「乃往」即「从前」；「乃往古世」谓在过去久远之世。
〔72〕 十号具足　「十号」即如来的十种尊号（如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛）；「十号具足」谓圆满具足佛的德号。
〔73〕 采女　古代王宫中地位较低的妃嫔侍女。「二十亿那由他采女」谓喜光夫人（摩耶夫人的前身）与众多宫眷同往金华园。
〔74〕 普眼三昧　能普见十方一切佛与一切处的三昧，得名于「普眼」（遍观之眼）。乳母净光（林神前身）得此三昧后普见无量诸佛。
〔75〕 如初受胎识　「受胎识」即结生识，众生入母胎之刹那最初托生的识。谓得此解脱后见佛受生自在，快速无碍，如同初入母胎的神识一样速疾无碍。
〔76〕 谛观不见顶　仔细端详也看不到佛的头顶，即「无见顶相」，佛三十二相之一，喻佛身相好无有限量。
〔77〕 十力尊　具有如来十力（佛特有的十种智力）的世尊，颂文中对佛的尊称。
〔78〕 般涅槃　梵语音译，「般」意为入、趋；「般涅槃」即入涅槃、圆寂，指佛示现灭度。
〔79〕 释种女　释迦种族出身的女子。下一位善知识瞿波即释迦族女子，传为佛姨母摩诃波阇波提系的释种女。
〔80〕 瞿波　梵语音译（意为牛护、妙婢），本卷末尾指示的下一位善知识之名，迦毗罗城的释种女。
〔81〕 绕无数匝　印度礼法，尊敬对方时绕其身右旋而行（右绕三匝）；「匝」（音zā）即一圈。善财辞行时绕林神无数圈以表敬重。
