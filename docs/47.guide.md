# 大方广佛华严经卷第四十七 导读

## 一、内容总览

本卷属〈佛不思议法品第三十三〉第二部分，承接上卷普贤菩萨受如来威神加被、为大众宣说佛境界的脉络。本品不叙因缘故事，而以纯列举方式系统敷演「诸佛世尊」之不思议功德，将佛之所以为佛的体、相、用层层展开：由「事」（佛在世间所作之广大事业）入「行」（无二、安住、尽知、力、勇健等自受用德）再归「化」（决定、速疾、忆念、一切智住、三昧、无碍解脱等利他之用）。全卷以「十种」为枚举单位，共十二组，结构整严，是华严经中描述佛德最集中的一卷。

## 二、结构层次

全卷以「十大佛事 → 十种自在德 → 十种利他德」三段递进，枚举之中又有内在推进：

- **十种广大佛事（P3-P14）**：以佛一生应化事迹为序——兜率受生 → 降神母胎 → 诞王宫 → 出家 → 成道转法轮 → 入王都教化 → 随类现身 → 说涅槃无常 → 入涅槃起塔供养。这是「事」的层面：佛从生到涅槃，每一阶段皆作无量佛事，摄取人天魔梵乃至天龙八部。
- **十种无二行自在法（P15）**：由事入理，标佛「决定无二」之体——能说、随念、现觉、三世智、刹那即一、佛刹即一、佛语即一、生佛平等、世法佛法无差别、善根同一。十句皆归「平等一相」。
- **十种住（P16）→ 十知尽无有余（P17）→ 十力（P18）**：层层收束于佛之自受用——住觉悟、住大悲、住本愿…；知三世、知众生心、知缘起、知因陀罗网…；力从广大到难动不可坏。
- **十大那罗延幢勇健法（P19-P29）**：本卷最壮丽的段落。以「那罗延」（天上力士）之幢旗为喻，极言佛身不可坏、一毛持世界、一念过不可说微尘数步、一坐食经不可说劫、一身化不可说舌转无尽法轮、降魔不动、无碍音普闻、心无障碍遍知、无量身相、等悟一切如来法。十段皆以「假使」「不可说不可说佛刹微尘数」层层加码，将佛身、佛语、佛心之超越量度推向极致。
- **十种决定法（P30）→ 十速疾法（P31）→ 十应常忆念清净法（P32）**：转回利他——决定（必由兜率下生、必处胎十月、必菩提树下成道…）、速疾（见佛即远离恶趣、圆满功德、断疑…）、忆念（菩萨应常念佛因缘、胜行、满度、大愿…）。由佛之决定，导出众生见佛之速疾利益，再归菩萨应忆念佛德。
- **十一切智住（P33）→ 十无量不可思议佛三昧（P34）→ 十无碍解脱（P35）**：终段三组收束于「一念遍一切处」之境——一念知三世众生心行、一念普现佛兴、一念遍说妙法；恒住正定而遍一切处；一尘现不可说诸佛出兴、转法轮、授记、世界种、一切佛事。由「一念」到「一尘」，将全卷「不思议」推到极点，以「一尘现去来今一切佛事」作结。

通卷过渡以「佛子！诸佛世尊有十种…」「是为十」「是为第N广大佛事」固定句式勾连，枚举之中见秩序，秩序之中见无尽。

## 三、关键结论

1. 佛之一生——从兜率受生到入涅槃起塔——每一阶段皆是「广大佛事」，无一时不利益众生，无一处不作佛事。
2. 佛德之「无二」与「平等」是本卷理骨：三世即一刹那、一切佛刹即一佛刹、一切佛语即一佛语、世法与佛法性无差别，皆归一相一性。
3. 佛身、语、意之超越量度非比喻，而是「一毛持世界」「一念过不可说微尘数步」「一尘现不可说佛事」的实相展现——小大、久暂、一多在佛境界皆相即无碍。
4. 佛之「决定」与众生之「速疾」相互呼应：佛必由兜率下生成道是决定，众生见佛即远恶趣、满功德是速疾——佛之决定是众生利益之根本保证。
5. 全卷归宗于「一念遍一切处」与「一尘现一切佛事」：佛之三昧、解脱不在远方，而在每一念、每一微尘中圆满显现，此即华严「一即一切、一切即一」的法界观。

## 四、易混辨析

- **广大佛事 vs 无碍解脱**：前者是佛在世间所作的具体事业（受生、出家、转法轮、入涅槃等），侧重「行迹」；后者是佛于「一尘」中现不可说诸佛出兴、转法轮、授记等，侧重「法界互摄」的体性自在。前者横说一生，后者竖说一尘。
- **决定法 vs 速疾法**：决定法言佛「必如此」（定从兜率下生、定处胎十月…），是佛自受用之必然；速疾法言众生「见佛即如此」（速离恶趣、速满功德…），是众生他受用之利益。一为佛之定数，一为众生之感益。
- **一切智住 vs 佛三昧**：一切智住侧重「一念中知」——知众生心行、知业果、知所宜、知心乐，是「智」之遍知；佛三昧侧重「恒住正定而遍一切处」——遍说妙法、普入三世、普现佛身，是「定」之遍现。一为知，一为现，然在佛境界知与现不二。
- **那罗延幢勇健法 vs 十力**：十力是佛德之「能」（广大、最上、无量、难获、不退、坚固…），偏抽象；那罗延幢勇健法是佛身之「具体超量」（身不可坏、一毛持世界、一念过微尘数步…），偏事相。前者是德之相，后者是德之用。

## 五、阅读提示

读本卷可带着两个问题：其一，佛既「无二」「平等」「一相无相」，为何又示现从兜率下生、处胎、出家、成道、涅槃这般曲折的一生？——答案在「事」与「理」不二。其二，「一毛端」「一尘」「一念」在本卷反复出现，作者要以此打破读者对时空大小的常识执取，读时不妨将每一处「不可说不可说佛刹微尘数」都视为对「量」概念的解构，而非夸张修辞。
