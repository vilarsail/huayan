# 大方广佛华严经卷第六十四 导读

## 一、内容总览
本卷属《入法界品第三十九》之五，为善财五十三参中段。善财南行，本卷接连参访休舍优婆夷、毗目瞿沙仙人、胜热婆罗门三知识，从「福严依报与发心量」「摩顶授手契入法界」「苦行破执显真」三层面推进，层层推升善财证境。主旨：善知识是入法界门径，菩萨发心广大无量，苦行外相下可藏金刚焰三昧，参学须净信破疑、随教不退。

## 二、结构层次
全卷以「善财三参」为骨架，依南行次第展开，每参以同一问法程式（顶礼→白言「我已发心，未知菩萨云何学菩萨行、修菩萨道」）推进，所证境递进：

- **总起·善知识恩**（P3）→ 以「师傅/眼目/津济」三喻收束，奠定参学基调。
- **第一参·休舍优婆夷**（P4–P27）→ 铺陈普庄严园依报庄严（宝树、宝帐、宝网、光明、宝莲华座）↔ 显正报休舍相好与摄生用（见者病苦除、得不退转）→ 追问发心久近，溯三十六恒河沙佛所承事 → 以「菩萨初发心无有量」等十一种无量门广说发心，并以「不为……故」与「欲……悉无余故」正反两组对仗显发心之广 → 末示「离忧安隐幢」解脱门，推指下参。
- **过渡·善财思惟**（P28）→ 随顺思惟菩萨正教，生十种心，承前引后。
- **第二参·毗目瞿沙仙人**（P29–P45）→ 那罗素国大林树华庄严 ↔ 仙人栴檀树下敷草而坐、徒众服鹿皮树皮草衣 → 善财以「善知识者则是趣向一切智门/乘/船/炬/道/灯/桥/盖/眼/潮」十喻赞善知识 → 仙人摩顶执手，善财自见身往十方十佛刹微尘数世界见佛闻法、经不可说劫 → 由诸三昧光明照故得五重三昧光明 → 放手还本处 → 示「菩萨无胜幢解脱」，推指下参。
- **第三参·胜热婆罗门**（P47–P76）→ 见胜热四面火聚中刀山高峻、投身入火之苦行相 → 善财疑其是魔（以得人身难等十难为念）→ 十千梵天空中解疑：此圣者得金刚焰三昧 → 次第十千诸魔、自在天、化乐天、兜率天、三十三天、龙王、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、欲界诸天各述火光映夺宫殿、舍乐来诣、闻法得益 → 善财悔过 → 婆罗门说颂「顺善知识教必获广大利」→ 善财登刀山投火聚，未至得善住三昧、触火得寂静乐神通三昧 → 示「菩萨无尽轮解脱」，推指下参。

## 三、关键结论
1. 善知识是见佛、闻法、入莲华池的津济，菩萨道全仗善知识示导，参学须净信随教、不疑不退。
2. 菩萨初发心无量，遍满法界、普入世间、究竟十方；发心非为一众生、一世界、一如来，而是尽化一切众生、尽供一切佛、尽净一切刹。
3. 摩顶执手一念顷可令行者遍往十方微尘数佛刹、经不可说劫闻法，三昧光明重重相入，显善知识神力与法界互摄。
4. 苦行外相下可藏金刚焰三昧，火光映夺天宫、令诸天舍乐发心、照息地狱众苦——不可以相状判善知识真伪，疑退即失大利。
5. 三参解脱门名号（离忧安隐幢、无胜幢、无尽轮）递进，皆以幢/轮为喻，表高竖不动、摧破无胜、辗转无穷。

## 四、易混辨析
- **优婆夷 vs 比丘尼**：优婆夷为在家女众（清信女），非出家；休舍居宝园、戴宝冠、垂发，与出家尼有别。
- **婆罗门 vs 外道**：胜热现婆罗门身修苦行，形同外道，实得金刚焰三昧；华严善知识多现非沙门身，破以相取人之执。
- **解脱门 vs 三昧**：解脱门约断障离系立名（如离忧安隐幢）；三昧约定心一处立名（如毗卢遮那藏三昧）。文中善财由解脱智光明照转入三昧光明，二者相资而非一物。
- **不可说不可说转 vs 阿僧祇**：阿僧祇为华严十大数之首，不可说不可说转为辗转相乘之极数，表数量穷极、非算术所及。

## 五、阅读提示
读本卷宜扣「善知识—发心—证境」三线：每参先观境界之相（依报/正报/苦行），再看善财的疑与信（休舍无疑、毗目摩顶、胜热先疑后信），最后看法门名号如何层层递进。注意三参末皆以「如诸菩萨摩诃萨……而我云何能知能说」收束并推指下位，为善知识谦己推人之常式。
