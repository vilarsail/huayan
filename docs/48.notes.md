# 大方广佛华严经卷第四十八 词语注释

〔1〕 于阗国三藏实叉难陀　于阗为今新疆和田一带的古国；实叉难陀（652-710）是著名译经僧，本经（八十华严）的译者；「三藏」指通达经、律、论的法师，「奉制译」谓奉皇帝之命翻译。
〔2〕 相海　佛身相好深广不可测，故以「海」为喻；本品历数如来各身分的相好，共列九十七种。
〔3〕 尔时　那时、当尔之时；佛经叙述中连接说法缘起的常用发语词。
〔4〕 三十二宝庄严大人相　名数难点：本品先说如来顶上三十二相，再依次说眉间、眼、鼻、舌、口、齿、唇、颈、肩、胸、手、阴、臀、髀、腨、足等处，通计九十七相，每相皆以「名：某某云」标名、以「是为X」收束；读时抓每相名称即可，不必逐项细究庄严之语。
〔5〕 大人相　即佛与转轮圣王所共有的三十二种殊胜身体特征，此处泛指如来身上的种种大相。
〔6〕 咸　皆、都；与「悉」同义的总括副词。
〔7〕 摩尼　梵语 maṇi 音译，如意宝珠，能随意现出种种珍宝与光明，本品相好多以其为庄严。
〔8〕 悉　全、都，总括之词；经中习见。
〔9〕 毗琉璃　梵语 vaiḍūrya 音译，青色宝（一说绿色宝石），七宝之一。
〔10〕 华蕊　蕊，音 ruǐ，花心；谓毗琉璃宝如花之中心花蕊，点缀于庄严之间。
〔11〕 弥覆　弥，遍布；弥覆即普遍覆盖、遍满。
〔12〕 三昧　梵语 samādhi 音译，义为正定、等持，心专注一境而不散乱。
〔13〕 佛刹　刹为梵语 kṣetra（刹多罗）之略，即佛国土、世界。
〔14〕 璎珞　以珠玉串成的颈饰、身饰，属于庄严之具。
〔15〕 微尘数　以把世界碎为微尘之数形容极多，华严经惯用的数量词。
〔16〕 结跏趺坐　趺，音 fū，足背；交盘双脚、端身正坐的坐姿，即诸佛入定说法之相。
〔17〕 栴檀　梵语 candana 音译，檀香木，香气远闻，常用作香严之具。
〔18〕 回向　将所修功德转施于特定目标（如菩提、众生），使功德转向趣入；此品劝天众回向增长善根。
〔19〕 阎浮檀金　梵语 Jambūnada，阎浮河中出产之金，佛经中金之上品，色光明净。
〔20〕 因陀罗网　因陀罗即帝释天；帝释天宫以宝珠结成罗网，珠珠相映、重重无尽，华严经常以之喻法界事事无碍、互摄互映。
〔21〕 熙怡　和悦欢喜之貌；「熙怡微笑」谓佛莞尔含笑。
〔22〕 口上㗁　㗁同「腭」，音 è，口腔上壁；此相在如来上颚之处。
〔23〕 口右辅下牙　辅，指牙床外侧与面颊之间；此四相（右辅下牙、右辅上牙、左辅下牙、左辅上牙）分列于口两旁上下牙齿处。
〔24〕 卐字　卐，读 wàn，吉祥万德的标帜；佛胸、手、足等处现此纹相，本品谓胸臆卐字相形如卐字。
〔25〕 弥卢藏　弥卢即须弥山（Sumeru）的异译；「宝焰弥卢藏」谓宝焰积聚如须弥山般广大。
〔26〕 莲华藏　即莲华藏世界海，华严经所说毗卢遮那如来的报身净土，无量世界皆藏于此大莲华中。
〔27〕 师子之座　「师子」同「狮子」；佛所坐之座，因佛说法无畏如狮子王而得名。
〔28〕 右旋　佛身毛发、轮相皆向右（顺时针）旋转，是佛相中的吉相。
〔29〕 普贤行　普贤菩萨所代表的广大愿行，华严修行之典范；诸相好光中亦常演说普贤之行。
〔30〕 绀蒲　果名，皮色绀青；此处谓如来颈相成就，如绀蒲果般圆满柔软细滑。
〔31〕 吉祥海云　胸臆卐字相的名号，「吉祥海云」即卐字之意译，象征万德吉祥聚集如海。
〔32〕 帝青　「帝释青」之略，梵语 indranīla，帝释天宫的青蓝色宝，近于青金石。
〔33〕 千辐轮　三十二相之「千辐轮相」，足底现千辐轮形之纹；辐，车轮中连接轮毂与轮圈的直条。
〔34〕 阴藏　即三十二相之「马阴藏相」，谓佛根相密藏于体内如马阴，示男根之相而无形露。
〔35〕 髀与腨　髀，音 bì，大腿；腨，音 shàn，小腿肚；「上下相称」谓大腿小腿比例匀称。
〔36〕 伊尼延鹿王腨　伊尼延为梵语音译，义为鹿王；腨，音 shàn，小腿肚。此即三十二相之「鹿王腨相」，谓佛小腿圆直匀好如鹿王。
〔37〕 因陀罗尼罗　梵语 indranīla 音译，帝释青宝，深蓝色宝石，与「帝青」同类。
〔38〕 华藏世界海　莲华所藏之世界海，毗卢遮那如来报身净土之名；此品言其大人相有十华藏世界海微尘数之多。
〔39〕 随好　即「八十种好」，随从大相而显现的细微好相；本品第三十五专说随好放光的功德。
〔40〕 宝手菩萨　本品第三十五的当机众（佛对其宣说者），以手中能出无尽宝藏而得名。
〔41〕 如来、应、正等觉　佛的称号：如来（乘真如之道而来）、应（应供，堪受人天供养）、正等觉（真正遍知一切法），于佛十号中略举其三。
〔42〕 阿僧祇　梵语 asaṃkhya 音译，义为「无数」，佛经中的极大数名。
〔43〕 兜率天宫　梵语 Tuṣita，欲界第四天，义为知足；菩萨下生成佛前最后住处。本品说毗卢遮那菩萨于兜率天宫放光济度地狱众生。
〔44〕 众苦休息　休息，古义为止息、止灭；谓地狱众生蒙光照后种种众苦得以止息。
〔45〕 十种清净眼　蒙佛光照而得的眼等清净，能遍见十方无量世界；此品谓地狱众生遇光即得十种清净眼，耳鼻舌身意亦然。
〔46〕 那由他　梵语 nayuta 音译，佛经大数名，通常说为万亿。
〔47〕 阿鼻地狱　梵语 Avīci，译为「无间地狱」，八热地狱中罪苦最深之处；此品谓其极苦众生遇光命终生兜率天。
〔48〕 天鼓　本品关键角色：兜率天宫天然生就之鼓，不挝自鸣，能随众生业缘说法警觉天人；佛经常以天鼓喻佛说法无心而应、非十方来。
〔49〕 离垢三昧　远离尘垢烦恼的正定；毗卢遮那菩萨入此三昧，故能非眼所见而处处示现受生。
〔50〕 我所　「我所有」之略，指我所拥有之物；「我」与「我所」皆佛教所破除的执著。
〔51〕 四维　东南、西南、东北、西北四个隅方向；与四方合成八方，加上下即十方。
〔52〕 业报成佛　谓佛由无量善业果报所成；此处言其来处如天鼓音声，非从十方来。
〔53〕 般若波罗蜜　梵语音译：般若即智慧，波罗蜜即到彼岸；六度之一，此处谓其威德力能出生清净音声。
〔54〕 三十三天　即忉利天，帝释天所居，位于须弥山顶；此品以须弥山顶三十三天的乐具喻天鼓音声非从十方来。
〔55〕 憍慢　憍同「骄」；憍慢即骄傲傲慢，谓修行中不应生起之心。
〔56〕 声闻、辟支佛　声闻，闻佛声教而悟四谛之圣者；辟支佛（pratyekabuddha），无师独悟之圣者；此二乘尚不能知菩萨掌中一光之神力。
〔57〕 五欲乐具　五欲，色声香味触（或财色名食睡）五种感官欲乐；乐具，享乐之物。天鼓劝天子勿贪着五欲，以免障碍善根。
〔58〕 劫火　坏劫之火能烧尽世界；此处喻贪欲缠心如劫火烧须弥山，终不能生念佛之意。
〔59〕 无依印三昧　无所依着之定境，「印」谓证印；天鼓言天人若悟音声与五蕴不生不灭，即入此三昧。
〔60〕 瞻觐　瞻仰朝见；觐，音 jìn，朝见尊长。
〔61〕 净饭王　释迦牟尼佛之父，迦毗罗卫国王；此处言菩萨从此天没、生于人间净饭王家。
〔62〕 摩耶夫人　释迦牟尼佛的生母；菩萨乘栴檀楼阁入其母胎。
〔63〕 梵天、欲天　色界梵天诸神与欲界诸天；此言二类天众承事供养人间的菩萨。
〔64〕 承事　侍奉、承供，谓恭敬周到地服事。
〔65〕 阎浮提　梵语 Jambudvīpa，须弥山南方之洲，即人类所居世界；此言诸天子欲下阎浮提问讯菩萨。
〔66〕 阿耨多罗三藐三菩提　梵语音译，义为「无上正等正觉」，即佛所证得的究竟智慧。
〔67〕 业障、烦恼障、报障、见障　名数：四种障碍——所造恶业之障、贪瞋痴烦恼之障、苦厄果报之障、错误见解之障；天鼓劝天子以众生数等身口意悔除此四障。
〔68〕 尽法界众生数等　疑难句法：谓与全法界众生的数量相等；「以尽法界众生数等身……头……舌……」是一串排比，意为以等同众生数量的身、口、意业，无数次地忏悔除障。
〔69〕 云何　为什么、如何；经中设问启答的常用词。
〔70〕 贪恚痴　恚，音 huì，瞋恨；贪恚痴即贪、瞋、痴三毒。
〔71〕 六趣　天、人、阿修罗、地狱、饿鬼、畜生六种轮回去处；「六趣果报」谓所造诸业感得六道之报。
〔72〕 断常　断见与常见两种邪见：谓死后断灭，或谓有个恒常不变之我；佛不说断常之法（除方便教化）。
〔73〕 玻璃镜　此处「玻璃」指天然水晶（梵语 sphaṭika，旧译颇黎、水玉），非今日人造玻璃；此镜清净鉴彻，能照十方世界一切影像。
〔74〕 幻师　魔术师；佛经常用以喻诸法幻化不实，此处喻诸业能惑人眼而无实体。
〔75〕 兜率陀　即兜率天，梵语 Tuṣita 的另一音译写法；「兜率陀诸天子」即彼天诸天子。
〔76〕 无生法忍　忍，安住不动之义；于诸法不生不灭之理确认不疑而心安不动，是菩萨修行的重要阶位。
〔77〕 六欲天　欲界六层天：四天王天、忉利天、夜摩天、兜率天、化乐天、他化自在天；兜率天为其第四层。
〔78〕 十地　菩萨修行的十个阶位，第十地名法云地，最接近佛果；此品言遇光明者「必得菩萨第十地位」。
〔79〕 普雨　雨，作动词，音 yù；「普雨」谓如雨般普遍降下香云于无量世界。
〔80〕 第四禅　色界四禅中最上一层，身心寂静安乐；此处以比丘入第四禅之乐比喻蒙香者身的安乐。
〔81〕 贪行多者二万一千　名数难点：佛典谓烦恼共八万四千——贪行、瞋行、痴行、等分行（三毒均等）四类，各二万一千；香能了知此诸烦恼悉是虚妄。
〔82〕 清净金网转轮王　金轮王中之最胜者，以清净金网宝衣与金轮为标识；此品用以指住菩萨第十地、放摩尼髻光明教化无量世界的菩萨。
〔83〕 恒河沙　恒河（Ganges）沙粒之数，佛经习用的极多之喻；「一恒河沙善根」谓种如恒河沙数之善根。
〔84〕 明镜世界月智如来　譬喻中假设之佛：其世界名「明镜」，佛名「月智」；众生闻其佛名必得往生彼国，以此喻住转轮王位之菩萨教化无有间断。
〔85〕 比丘、比丘尼、优婆塞、优婆夷　佛教四众弟子：出家男众、出家女众、在家男居士、在家女居士。
〔86〕 本生　梵语 jātaka，佛自说过去世为菩萨时的修行事迹之经，九分教之一类。
〔87〕 梵世　梵天世界，初禅天所在；此处以得初禅者未命终已能见梵天宫殿、受梵世安乐，喻菩萨必获十地之果。
〔88〕 尔许　如此之多、那么多；指上文所说微尘数。
〔89〕 譬谕　谕，同「喻」；譬谕即比喻。
〔90〕 授彼记　即「授记」，佛预先告知某人将来当得作佛；此处谓闻譬喻而生信者，佛为其授成佛之记。
〔91〕 末为微尘　末，用作动词，磨碎；「末为微尘」谓把广大佛土磨碎为微尘，层层展转计量。
〔92〕 业报清净肉眼　非天眼、慧眼，而是由广大福德善根（业报清净）所感得的肉眼，能于一念中明见无量世界微尘数佛。
