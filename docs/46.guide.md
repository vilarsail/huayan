# 大方广佛华严经卷第四十六 导读

## 一、内容总览

本卷是《大方广佛华严经》卷第四十六，属「佛不思议法品第三十三」之首品（之一），承接前文普贤行愿之后，转入对「诸佛不思议法」的系统宣说。经中先由大会菩萨起十种问（佛国土、本愿、种性、出现、身、音声、智慧、自在、无碍、解脱云何不思议），世尊以神力加持青莲华藏菩萨，令其入佛法界、得佛无碍观察，由青莲华藏菩萨承佛神力告莲华藏菩萨，以「佛子」为引，次第宣说诸佛世尊所具之十类（实为二十一数，每数约十种）不思议功德法，从普遍法界的佛法一直到善巧方便，层层展开佛果境界的广大圆满。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷以「十大问起 → 加持受命 → 二十一数枚举」一线贯穿，整体是「总起提问 → 受命敷演 → 分条列举」结构：

- **大会起问（P3）**：十句「云何不思议」并列 → 从佛国土、本愿一直到解脱，框定全卷所议范围（佛果十种不思议境界）。
- **加持受命（P4-P5）**：世尊以神力加持青莲华藏菩萨 → 令其住佛无畏、入佛法界、得佛无碍广大观察 → 青莲华藏菩萨成满普贤大愿、具足总持辩才 → 承佛神力告莲华藏菩萨。
- **敷演正文（P6-P26）**：以「佛子！诸佛世尊有十种……」为固定句式，反复展开，共约二十一数：
  - P6 先标「无量住」总举；
  - P7 普遍法界十种佛法（身眼耳鼻舌意等无边际）；
  - P8-P10 念念出生智、不失时、无比不思议境界（一念中示现无量）；
  - P11-P13 出生十智、普入法、难信受广大法（从「知法无所趣向」到「一微尘中示现众刹」）；
  - P14-P17 离过清净大功德、究竟清净、一切世界佛事、无尽智海法；
  - P18-P22 常法、演说无量法门、为众生作佛事、最胜法、无障碍住；
  - P23 最胜无上庄严（身语意光明法身妙色种族大悲等十）；
  - P24 自在法（六根互用、一念现微尘数佛等，本卷高潮）；
  - P25-P26 无量不思议圆满佛法、善巧方便（从「离戏论」到「本性寂静」，以般若空观收束）。
- **收束（P26 末）**：以「是为诸佛成就十种善巧方便」结，归于般若波罗蜜之空寂实际，呼应「不思议」之题。

各数之间以「佛子！诸佛世尊有十种……何等为十？所谓……是为十」为过渡框架，条目内部多用「一切诸佛……」整齐排比，形成华严特有的「重重无尽」宣说节奏。

## 三、关键结论

1. 诸佛境界以「不思议」为体——十种问总标，全卷二十一数皆在显佛果超情离见、不可测量。
2. 佛功德皆「无边际」「普遍法界」——身、眼、耳、意、解脱、世界、行愿皆无边际，明佛果即法界之全体。
3. 一念与无量互摄——「于一念中」「于一微尘中」「于一毛孔中」示现无量世界、无量佛身，是华严「一即一切」理事无碍观的具体展开。
4. 佛事不舍众生——十种佛事、十种为众生作佛事、调伏不失时，明佛果不偏空寂，恒起大悲度生。
5. 善巧方便以般若空为底——末后十种善巧方便皆归于「诸法本性寂静」「无生无灭」「言语道断」，显不思议之不思议，即空即假即中。

## 四、易混辨析

- **佛不思议法 vs 普贤行愿**：普贤行愿侧重菩萨因地之大愿大行（前品所明），佛不思议法侧重佛果位之功德境界；前者是「因中愿行」，后者是「果上德用」，二者因果相承。
- **普遍法界十种佛法 vs 十种自在法**：前者明佛身语意及世界、行愿之「无边际」（偏就体相周遍），后者明佛于一切法、一切时、一切世界之「无障碍」（偏就业用自在）；一重周遍，一重无碍。
- **法身 vs 色身相好**：法身是「清净无碍、于一切法究竟通达、住于法界无有边际」之理体（第六庄严）；色身相好是「百福所成、见者获益」之报化身相；法身是体，色身是用。
- **般涅槃 vs 无余涅槃**：「般涅槃」泛指入灭（圆寂），「无余涅槃」特指灰身灭智、无余蕴之灭；本卷「常示入于无余涅槃」是示现，非实灭，以「诸佛境界无边际故」。

## 五、阅读提示

读本卷可带着两个问题：其一，佛为何能于一念、一微尘中现无量事？其二，诸佛「离过清净」「究竟清净」与「不舍众生」「调伏不失时」如何统一？循此二问，可于重重排比中不迷失，见到「智圆满」与「悲无尽」的一体两面。
