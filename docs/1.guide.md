# 大方广佛华严经卷第一 导读

## 一、内容总览

《大方广佛华严经》卷第一，于阗国三藏实叉难陀奉诏译，品题「世主妙严品第一之一」，为全经开篇序分。本卷以「道场庄严 → 世尊成最正觉 → 菩萨众与诸天八部围绕」三段一线贯穿，由境到证、由证到众、由众到列，铺陈出如来始成正觉时一切世主云集道场的庄严景象，为下卷诸天颂偈赞叹、普贤三昧兴起作铺垫。文字层层叠叠，是华严「重重无尽」气象之始见。

## 二、结构层次（文章骨架与逻辑推进，★重点）

全文按「境 → 证 → 众 → 列」四层推进：

1. **境（P4）**：菩提场地庄严 → 菩提树庄严 → 宫殿楼阁庄严 → 师子座庄严。
   - 由近及远、由地至树至殿至座，层层展布；
   - 以「佛神力故，令此道场一切庄严于中影现」一句收束 → 境即佛境，物皆佛境之影现。

2. **证（P5）**：世尊于座上成最正觉 → 智入三世平等、身充满世间、音普顺十方 → 譬虚空具含众像、普遍一切 → 一一毛端容受一切世界、三世诸佛神变咸现。
   - 由境之庄严转入果地功德，由「身」到「智」到「神变」 → 由相显性，由显入密。

3. **众（P6）**：十佛世界微尘数菩萨摩诃萨围绕 → 列普贤等二十位上首 → 总述菩萨众功德（往昔与毗卢遮那共集善根、波罗蜜圆满、慧眼明彻、入法界藏、践普光明地、与智俱尽未来际）。
   - 由境之主（佛）→ 法众之首（菩萨），是过渡。

4. **列（P7-P45）**：执金刚神 → 身众/足行/道场神 → 主城、主地、主山、主林、主药、主稼、主河、主海、主水、主火、主风、主空、主方、主夜、主昼神 → 阿修罗、迦楼罗、紧那罗、摩睺罗伽、夜叉、龙王、鸠槃荼、乾闼婆 → 月、日天子 → 忉利、夜摩、兜率、化乐、他化、梵、光音、遍净、广果、大自在诸天。
   - 由内到外、由圣到凡、由地居到空居到色界顶，层层外推；
   - 每段以「复有……所谓：……如是等而为上首，有……数，皆……」模式反复 → 重重无尽列举；
   - 每一举末点明该众共愿共德，呼应菩萨众功德海。

## 三、关键结论

1. 境庄严即佛功德之影现，非外境亦非离心。
2. 如来始成正觉即具足三世、十方、法界一切境界，一一毛端皆容受无边世界。
3. 普贤菩萨居上首，是「普贤愿海」所依；菩萨众与毗卢遮那共集善根，表因果相即。
4. 诸天八部各类世主层次虽别，皆发愿亲近诸佛、利益众生，是「世主妙严」之实。

## 四、易混辨析

- **普贤菩萨 vs 普贤愿海**：本卷「普贤菩萨」是上首菩萨其人；「普贤愿海」是其大愿所成之功德海，众生由此得智身具足。
- **毗卢遮那 vs 卢舍那**：本经毗卢遮那为法身佛名，意「光明遍照」；古译或作卢舍那，实同梵异译，本经体系内统一作毗卢遮那。
- **菩萨 vs 菩萨摩诃萨**：菩萨通指发心者，摩诃萨意为「大」，菩萨摩诃萨特指已具大心大行、堪邻佛果之地上大菩萨。
- **佛世界 vs 佛刹 vs 三千大千世界**：本卷「十佛世界微尘数」以十个佛世界为单位、磨为微尘而计菩萨众数，极言其多；与「佛刹」（一佛教化之土）相关而量级不同。

## 五、阅读提示

本卷为序分，先抓住「境—证—众—列」四段骨架，再以菩萨众功德为眼目通读诸天八部——每一类神众末尾的「皆……」句即其共愿共德，是与菩萨众呼应的关节。读时不必强记名字，注意结构递进与愿德相扣即可。
