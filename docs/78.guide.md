# 大方广佛华严经卷第七十八 导读

## 一、内容总览

本卷为《大方广佛华严经·入法界品第三十九》之十九，承上卷善财童子至楼阁前赞叹、弥勒现前授记之后，由弥勒菩萨继续为善财说法。全卷以「问 → 叹 → 喻」一线贯穿：善财重问菩萨云何学菩萨行、修菩萨道；弥勒先向道场大众称叹善财精进求法、一生超劫之希有功德，令无量众生发心；继而告善财广说「菩提心」之无量功德，以百余则譬喻（良药、宝珠、金刚、明灯、莲华、师子、王子等）层层叠说，收束于「应知悉与一切佛法诸功德等」，最后指善财入毗卢遮那庄严藏大楼阁周遍观察。本卷是全经「菩提心」义理最集中的宣说，亦是善财由参入证、由人入法的关键转折。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全文按「问 → 叹众 → 叹善财 → 广喻菩提心 → 收束指入楼阁」五层推进：

- **重问发起（P3-P6，总起）**：善财合掌重白弥勒，先自陈「已先发阿耨多罗三藐三菩提心」，复叹弥勒「一生当得无上菩提」已超越一切菩萨所住、圆满一切波罗蜜、具足一切菩萨地…… → 以长串「则已……」排比铺陈弥勒之果德 → 收束于重问「菩萨云何学菩萨行？云何修菩萨道？」 → 由赞师之德转入求法之问，是全卷之发起。
- **弥勒叹德（P7-P13，承接）**：弥勒观察大众，指示善财而告诸仁者 → 历述善财「勇猛精进、志愿无杂」「如救头然、无有厌足」「曩于福城受文殊教，展转南行求善知识，经由一百一十善知识已」 → 复以「为大法船度诸有海」「为被四流漂泊者造大法船」等长串「为……者……」排比铺陈善财救护众生之悲行 → 以「余诸菩萨经无量百千万亿那由他劫乃能满足菩萨愿行；此长者子于一生内则能净佛刹、化众生、具足普贤诸行」收束 → 叹善财一生超劫，令无量百千众生发菩提心。
- **叹善财得善利（P15-P16，过渡）**：弥勒告善财「汝获善利……汝善得人身、善住寿命、善值如来、善见文殊师利」 → 由叹人转入叹法，过渡到菩提心功德。
- **广说菩提心功德（P17-P121，铺展，全卷主体）**：弥勒告善财，以「菩提心者，犹如……」句式反复枚举，从「种子、良田、大地」起，依次以「净水、大风、盛火、净日、明灯、大车、宫殿、舍宅、慈父、慈母、乳母、善友、君主、帝王、大海、须弥山、铁围山、雪山、香山、虚空、莲华」等喻，转至「良药、坑阱、金刚、香箧、妙华、白栴檀、黑沉香、善见药王、毗笈摩药、帝释、毗沙门、功德天、龙珠、水清珠、如意珠、功德瓶、如意树、鹅羽衣、白㲲线、快利犁、那罗延、快箭、利矛、坚甲、利刀、利剑、勇将幢、利锯、利斧、兵仗、善手、好足、眼药、钳镊、卧具」等喻，再转以「伏藏、涌泉、明镜、大河、大龙王、命根、甘露、大网、罥索、钩饵、阿伽陀药、除毒药、善持咒、疾风、大宝洲、好种性、住宅、市肆、炼金药、好蜜、正道、好器、时雨、住处、寿行、净琉璃、帝青宝」等喻收束于「举要言之，应知悉与一切佛法诸功德等」。 → 继以「譬如有人得……药/珠」之连譬（无畏药、解脱药、摩诃应伽药、无胜药、毗笈摩药、善见药、珊陀那树、无生根、阿蓝婆药、念力药、大莲华药、翳形药、普集众宝珠、大光明摩尼、水清珠、住水宝、龙宝珠、摩尼冠、如意珠、日精珠、月精珠、龙王宝冠、一切世间庄严藏珠、转轮王摩尼、帝青摩尼、琉璃宝、净光明宝、火焰宝、海藏宝、自在王宝、阎浮檀金、善调龙法、铠仗、黑栴檀、白栴檀、须弥山、波利质多罗树、椰子树、诃宅迦药、小火、灯、灯炷、他化天王金冠、师子王、师子筋弦、师子乳、迦陵频伽鸟、金翅鸟王子、利矛、摩诃那伽、射师弟子、学射、幻师、幻术、猫狸、阎浮金具、磁石、大海人、甘露浆、安缮那药、依附于王、住水中、依猛将、金刚杵、延龄药、调药汁、护命根、王子初生、清净摩尼、咒持药、常持甘露、机关木人、沉香象藏、金刚处生、无根树、金刚器、金刚穿宝、金刚坏山、金刚不全、金刚损缺、小金刚、金刚非凡人、金刚不识宝人、金刚不灭、金刚杵、金刚地、金刚器、金刚际、金刚久水、金刚不烧、金刚座」等百余则譬喻，每喻皆以「菩萨摩诃萨亦复如是」相配 → 以「菩提心成就如是无量无边乃至不可说不可说殊胜功德」收束。
- **指入楼阁（P123，收束）**：弥勒答善财所问「菩萨云何学菩萨行、修菩萨道」 → 令善财入毗卢遮那庄严藏大楼阁中周遍观察 → 「则能了知学菩萨行，学已成就无量功德」 → 由闻思入观行，引出下卷入楼阁之境界。

## 三、关键结论

1. **菩提心为一切佛法根本**：三世如来从菩提心而出生，菩提心能生、能长、能持、能护一切菩萨行愿，举要言之与一切佛法诸功德等。
2. **一生超劫**：余菩萨经无量那由他劫乃能圆满愿行，善财于一生内则能净佛刹、化众生、具足普贤诸行，是「疾得具足一切佛法」之典范。
3. **善知识为发心之缘**：善财之能发心精进，源于文殊师利最初劝导；弥勒印证善财「善见文殊师利大善知识」，善知识是菩提心出生之增上缘。
4. **譬喻即法**：百余则药、珠、金刚、灯、树、王子等喻，非文学铺陈，皆就菩提心一德一用而立——能除烦恼、能破无明、能度生死、能映蔽二乘、能摧魔军，一一皆表菩提心之殊胜功用。
5. **由闻入观**：弥勒广说已，不令善财止于闻解，复指入毗卢遮那楼阁周遍观察，是「由闻思入观行、由善知识口入法界身」之转折。

## 四、易混辨析

- **菩提心 vs 菩萨行**：菩提心是「发心」、是愿求一切智之心体，如种子；菩萨行是依菩提心所起之六度万行，如芽茎枝叶。本卷以「因菩提心出生一切诸菩萨行」明其因果先后。
- **菩萨摩诃萨 vs 善财童子**：菩萨摩诃萨指已入地、行愿深广之大菩萨（如弥勒）；善财是初发心已、历经百一十知识而求行者，弥勒叹其「于一生内」超劫，仍在因地。
- **善见药王 vs 毗笈摩药 vs 阿伽陀药**：皆天竺神药名。善见药王能除一切诸病；毗笈摩药能令毒箭自然堕落；阿伽陀药令无病永安隐。经中各就菩提心一德立喻，非可混同。
- **金刚 vs 金刚杵 vs 金刚座**：金刚喻菩提心之坚利不坏、能穿能摧；金刚杵是释天所执兵器，喻菩提心摧伏魔外；金刚座是佛成道之处，喻菩提心能持菩萨一切愿行波罗蜜而令成等正觉。三物同名金刚而义各别。
- **波利质多罗树 vs 椰子树 vs 无根树**：波利质多罗是忉利天上香树，喻菩提心功德香超胜二乘；椰子树根茎枝叶一切皆受用，喻菩提心始至成佛常利益世间；无根树不从根生而枝叶华果繁茂，喻菩提心无根本可得更长养一切智智。同为树喻而义各有当。

## 五、阅读提示

本卷譬喻层叠、句式反复，读时易生倦怠。建议把握两点：其一，所有譬喻皆归「菩提心一法」，每喻各表一德一用，不必强记名相，留意其用（除病、破暗、映蔽、摧伏、运载、长养）即可；其二，留意全卷「善财问 → 弥勒叹善财 → 弥勒叹菩提心 → 指入楼阁」的推进节奏，前半是赞人，后半是赞法，末尾由赞转入观，为下卷楼阁境界作引。
