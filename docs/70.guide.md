# 大方广佛华严经卷第七十 导读

## 一、内容总览

本卷为《入法界品第三十九之十一》，属善财童子五十三参的中段。善财由喜目观察众生夜神处辗转来到普救众生妙德夜神所，请法参访。本卷核心是普救众生妙德夜神为善财示现「菩萨调伏众生解脱神力」，并自述其往昔本生——于「圆满清净劫」毗卢遮那大威德世界中，身为转轮王女妙德眼，蒙普贤菩萨劝导修补佛像、发菩提心，又经多劫历侍诸佛，终得此「普现一切世间调伏众生解脱门」。整卷以「现神力 → 偈赞请问 → 本生因缘 → 历劫修行 → 结指下一位善知识」为脉络，把普贤行愿的因果次第完整演述一遍。

## 二、结构层次（★重点）

全文按「神力示现 → 偈赞请问 → 自述本生 → 历劫侍佛 → 结指下参」五段推进：

- **现神力、入三昧**（P3-P8）
  - 善财承前善知识教，发愿亲近 → 诣普救众生妙德夜神所
  - 夜神眉间放「智灯普照清净幢」光 → 入善财顶 → 善财得「究竟清净轮三昧」
  - 三昧中见微尘内含佛刹、世界成坏、六道差别，皆见夜神随类现身度脱 → 善财作礼偈赞

- **偈赞 → 请问**（P9-P13）
  - 善财以长偈赞叹夜神眉间光、毛孔光、身光普度 → 问解脱名号、得已久如、修何行清净
  - 夜神答：此是普贤行者境界，承佛力当说

- **本生因缘**（P14-P33）
  - 远劫「圆满清净」、世界「毗卢遮那大威德」、须弥尘数如来出兴
  - 描绘宝灯华幢四天下庄严 → 阎浮提宝华灯国 → 转轮王毗卢遮那妙宝莲华髻、王妃圆满面、王女普智焰妙德眼
  - 菩提树、宝华光明香池、普现三世大莲华 → 普智宝焰妙德幢如来成道前十年间依次放十种光明成熟众生（每光各成一法门，预兆佛将出世）
  - 普贤菩萨化现折伏众生憍慢 → 王女妙德眼见之发愿「得如是身、常不离善知识」
  - 转轮王率众偈赞往诣佛所 → 王女解璎珞散佛，化成宝盖，于中见普贤身中含一切菩萨、自身在普贤身内 → 闻「一切如来转法轮」修多罗 → 得十千三昧、发十佛刹微尘数愿海
  - 更前十大劫：妙眼女于因陀罗幢妙相佛遗法中，受普贤劝修补莲华座佛像，初发菩提心

- **历劫侍佛**（P35-P37）
  - 复述其于宝轮妙庄严世界大光劫中历侍五百佛，身份层层转换：夜神 → 转轮王 → 长者女 → 阿修罗王 → 龙王女 → 海神 → 五通仙 → 主地神 → 妓女，每值一佛即闻法受持、得一种智光明
  - 结归「以得一切智光明故，念念见无量佛，成满普贤诸行」

- **重颂结说 → 结指下参**（P38-P42）
  - 夜神以长偈重宣本生：须弥尘数劫中十组十佛名号，于每组佛所各悟一法门，皆曾供养
  - 自谦唯知此一解脱门 → 推荐善财往诣不远处「寂静音海夜神」
  - 善财礼辞而去

## 三、关键结论

1. **善知识是一切功德的根本**：妙德眼从修补佛像发心起，历劫「常见于佛、常得亲近普贤菩萨」，至今得解脱——善知识贯穿因地到果地，无暂舍离。
2. **一念光明即摄一切法界**：夜神眉间一光入善财顶，便令其于微尘中见尘数佛刹成坏；普智宝焰幢佛成道时即于十方一切世界同时成道——华严「一即一切」的相入观在本卷以神力形式直显。
3. **佛出世前以光明预成熟众生**：佛未成道前千年、九千年……乃至七日前依次放十种名号光明，令众生开悟、清净、知业果、圆满诸根——化导在佛成道之前已层层铺垫。
4. **身份可转、愿行相续**：妙德眼历劫曾为夜神、转轮王、长者女、阿修罗王、龙王女、海神、仙、地神、妓女等身，但亲近普贤、承事诸佛的相续不断，表明菩萨行愿不随身份色相而断。
5. **普贤行愿是入此解脱的总因**：夜神自言此境界即「住普贤菩萨行者境界」，王女亦于普贤身中见自身，普贤是本卷的隐性主尊。

## 四、易混辨析

- **妙德眼 vs 妙德眼童女 vs 妙眼女**：卷中三处所指实为同一人——宝华灯国转轮王之女「普智焰妙德眼」（P17），偈颂中作「莲华妙眼」（P25），更前十大劫中作「妙眼女」（P32），即今普救众生妙德夜神之前身。读者勿误为三人。
- **毗卢遮那妙宝莲华髻（转轮王） vs 毗卢遮那大威德（世界名） vs 毗卢遮那如来（坐菩提树下） vs 毗卢遮那功德藏（佛名）**：均冠「毗卢遮那」而所指不同，分别是转轮王名、世界名、莲华盖中所见佛名、后续历劫所值佛名。
- **普救众生妙德夜神 vs 寂静音海夜神 vs 喜目观察众生夜神**：三者皆为主夜神，前两位为本卷善知识链前后相邻者，后一位为上卷善知识；王妃「圆满面」即今「寂静音海夜神」（P34），与转轮王「今弥勒菩萨是」对应，构成「本生人物 → 当今圣者」的对照表。
- **「普贤行」与「普贤愿」**：本卷王女发十佛刹微尘数「愿海」（P30）成就普贤所有大愿，又入普贤「行」；行偏历劫身口意之修习，愿偏于初发心立誓，二者相资而成「普贤行愿」。

## 五、阅读提示

读本卷可抓住两条线：一是「光明」之线——从夜神眉间光、佛出世前十年次放十光、转轮王女璎珞化盖所显神力，皆以光明为度生媒介；二是「善知识」之线——妙德眼始终由普贤劝发、引导、成熟，至卷末又推善财往参寂静音海。两线交织，即「依善知识得一切智光明」的总义。
