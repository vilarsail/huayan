# 大方广佛华严经卷第六十 导读

## 一、内容总览

本卷为《入法界品第三十九》的开篇（之一），是整部《华严经》末后大段——善财童子五十三参——的序幕。全卷未入善财参访正文，而是先把场景搭起：世尊在室罗筏国逝多林给孤独园，与五百菩萨摩诃萨、五百声闻及无量世主俱。普贤、文殊为菩萨上首，舍利弗、大目揵连等为声闻上首。世尊入「师子频申三昧」，以大悲力现不思议庄严，十方菩萨各从其国来集，兴云现供。然同在林中的大声闻却完全不见如来神变与菩萨境界——此即本卷主旨：同一法会，菩萨见佛境界，声闻不见；同一道场，因善根、愿力、眼目不同而所见迥异。由此引出下卷善财童子南行参访善知识的全部动因。

## 二、结构层次（★重点）

全卷以「列众 → 乞法 → 入定现相 → 十方来集 → 声闻不见 → 菩萨颂德」六层推进，是典型的「先有情世间、后器世间，先总起、后分述、再以颂收束」结构：

- **列众（P3）**：先列菩萨五百，广举名号（幢、威力、藏、眼、冠、髻、光、音、上、胜、自在王、觉等十余类），次列声闻五百，再列世主；→ 以「皆悉成就普贤行愿」一句总括菩萨德相，为下文「菩萨能见、声闻不见」埋伏。
- **乞法（P4）**：菩萨、声闻、世主并眷属同作是念，历数如来十种境界（智行、加持、力、无畏、三昧等）为世所难知，唯除佛加被力与善根力方能趣入；→ 进而求佛显示往昔愿行、波罗蜜、诸地、本事因缘等——这是「请法」的总起。
- **入定现相（P5-P7）**：世尊知众念，入「师子频申三昧」；→ 大庄严楼阁忽然广博无边际，金刚为地、宝网弥覆；→ 逝多林量等不可说佛刹微尘数国土，香河、宝树、莲华、幢幡周遍；→ 虚空之中兴宫殿云、香树云、须弥云、妓乐云等；→ 以「十种不思议」释其所以然，并明十方一切世界亦如是见。
- **十方来集（P8-P17）**：依东、南、西、北、四维、上下十方次第，一一述某方过不可说佛刹微尘数世界海外有世界、有佛、有菩萨，与眷属来向佛所，各兴宝云、香云、衣云、楼阁云、光焰云、音声云等供养；→ 各于其方化作宝庄严楼阁与宝莲华藏师子座，结跏趺坐。→ 十段同构而异名，是华严「一多相即、主伴圆融」的典型铺陈。
- **声闻不见（P18-P21）**：先总收十方菩萨皆从普贤行愿中生，现大神变；→ 转入上首诸大声闻（舍利弗等）在林中而不见如来神力、不见菩萨境界；→ 以「以善根不同故」起，广列十数「本不……」解释不见之因；→ 复以饿鬼不见河、梦人独见天宫、雪山良医、地下宝藏、盲人至宝洲、明眼夜视、比丘入遍处定、翳形药、同生同名二天、灭尽定比丘等一连串譬喻，反复阐明「同处不同见、唯器能入」之理。
- **菩萨颂德（P22-P41）**：十方来集的十位菩萨（毗卢遮那愿光明、不可坏精进王、普胜无上威德王、无碍胜藏王、化现法界愿月王、法慧光焰王、摧破一切魔军智幢王、愿智光明幢、破一切障勇猛智王、法界差别愿）一一承佛神力说颂；→ 各以十颂叹佛德、菩萨行、法界平等、菩提难思，并以「宁受恶道苦、终不舍如来」等大愿收束，为下卷善财发心作先导。

## 三、关键结论

1. **同一法会，所见不同**：佛以一身现不可思议神变，菩萨净眼悉见，声闻同处而不见——根器、善根、愿力决定所见境界，非佛有所偏私。
2. **普贤行愿为见佛之因**：十方菩萨皆从普贤行愿中生，由净智眼、大愿力、善根力故能见如来神变；声闻本不修此，故不见。
3. **一毛孔、一微尘普现法界**：如来能于一毛孔中示现过去诸佛、于一微尘内普现一切法界影像——「一即一切」的华严宗义在本卷反复出现。
4. **大悲为门**：世尊「大悲为身、大悲为门、大悲为首」，以大悲方便入师子频申三昧现相，显佛境界非自证独享，而为利益众生开显。
5. **菩提难思、超过语言**：颂中反复强调佛智、菩提「超过语言道」「不可思议」「思之不可得」，与下卷善财「唯由求法、亲近善知识」方能入法界的逻辑相呼应。

## 四、易混辨析

- **菩萨摩诃萨 vs 菩萨**：本卷屡见「菩萨摩诃萨五百人俱」。「摩诃萨」意为「大」，菩萨摩诃萨特指已发大心、修大行、证大果的大菩萨（地上或胜解行地以上），与初发心菩萨有别；本卷所列皆「成就普贤行愿」之大菩萨。
- **逝多林 vs 给孤独园 vs 祇树给孤独园**：逝多林（Jetavana）即祇陀太子所施之林（逝多=祇陀异译），给孤独园是须达多（给孤独）长者所置精舍，二者合称即祇树给孤独园；本卷言「逝多林给孤独园大庄严重阁」，指同一道场。
- **师子频申三昧 vs 师子奋迅三昧**：频申即奋申、奋迅之意（stretch/yawn of a lion），喻佛入定现威神如狮子舒展振奋；不同经论译法有「频申」「奋迅」「奋疾」之异，义同。
- **声闻 vs 缘觉 vs 二乘**：声闻（śrāvaka）闻佛声教而证四谛；缘觉/缘觉（pratyekabuddha）无佛世自悟十二因缘；二者合称二乘。本卷言「一切声闻诸大弟子」「不与一切二乘所共」，二乘统指声闻、缘觉，皆不能见菩萨境界。
- **实际 vs 真谛 vs 法性**：本卷言声闻「悉觉真谛，皆证实际，深入法性」——真谛指四谛之理，实际指空性极理，法性即诸法实相；三者名异义近，指二乘所证偏真之理，但缺大悲与一切智，故不见佛境界。

## 五、阅读提示

读本卷宜带着两个问题：其一，菩萨与声闻同在林中，为何所见天壤之别？其二，十方菩萨各从其国来集、各兴宝云，这铺陈在「法界缘起」中说明什么？把握这两点，再读下卷善财南行参访便有了一个明确的「能入之门」——发菩提心、依善知识、修普贤行。
