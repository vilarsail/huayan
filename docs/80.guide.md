# 大方广佛华严经卷第八十 导读

## 一、内容总览

本卷为整部《大方广佛华严经》八十卷的压卷之帙，即「入法界品第三十九之二十一」。善财童子历经五十三参、遍访百十余城之后，于普门国苏摩那城思惟文殊师利，文殊遥伸右手过一百一十由旬按其顶，加持令其成就阿僧祇法门、入普贤行道场。随后善财于毗卢遮那如来师子座前见普贤菩萨现大神通，获十种智波罗蜜，普贤摩顶授以一切佛刹微尘数三昧门，复自述往昔劫海修因，终以一部长颂广赞如来功德海一滴之相。本卷以「文殊加持→见普贤身→得智波罗蜜→普贤摩顶→普贤自述因行→颂赞佛德」一线贯穿，是善财五十三参的圆满归宿，亦整部华严「因圆果满」的总结。

## 二、结构层次（★重点）

全文按「加持→现相→证得→授法→回溯因行→广颂果德」六重递进：

- **文殊加持（P4-P7）**：善财至苏摩那城思惟文殊 → 文殊遥伸右手按顶，呵责劣心、开示信根 → 令成就阿僧祇法门、入普贤行道场 → 文殊还摄不现（以「不现」收束文殊缘，转入唯心自证）。
- **发心见普贤（P8-P9）**：善财思惟观察，愿见文殊及微尘数善知识 → 起十种广大心（等虚空界心、净一切国土心等）于金刚藏菩提场毗卢遮那前求见普贤。
- **瑞相与光明（P10-P12）**：由自善根力、如来加被力、普贤同善根力 → 见十种瑞相（佛刹清净） → 见十种光明相（一一尘出微尘数佛光明网云等） → 作念「必见普贤」。
- **见普贤身与毛孔境界（P13-P15）**：善财以普眼、智慧眼观 → 见普贤坐宝莲华师子座 → 一一毛孔出光明云、香焰云、华衣宝树云、色界梵天身云、三世佛刹云等，遍法界虚空界度生 → 重观一一身分一一毛孔皆含三千大千世界，乃至十方三世一切世界、一切佛刹微尘中皆有法界诸佛众会。
- **得智波罗蜜与普贤摩顶（P16-P17）**：见已即得十种智波罗蜜（念念周遍佛刹、往诣佛所、供养如来乃至普贤慧行现在前） → 普贤伸右手摩顶 → 善财得一切佛刹微尘数三昧门，一一三昧以微尘数三昧为眷属，见昔所未见佛海、集助道具、发大誓愿等 → 十方一切世界及一一尘中一切佛所，普贤悉如是摩顶。
- **普贤自述因行（P18-P27）**：普贤问「汝见我此神通力不」 → 善财答「唯然已见」 → 普贤自述过去不可说不可说佛刹微尘数劫中行菩萨行：承事微尘数佛、设广大施会、布施财物城邑妻子乃至身命头目、于佛教中出家护持 → 自忆于一念间不顺佛教、不生瞋害我我所心、唯住大菩提心 → 庄严佛土、救护众生、法海无一文非舍施王位而得 → 以十种力（助道法力、善根力、大志乐力等）得究竟三世平等清净法身及无上色身 → 见闻我名者不退菩提、忆念我者成熟善根、见清净刹者必生其中。
- **善财入普贤身与同等圆满（P28-P32）**：善财观普贤一一毛孔皆有佛刹海、诸佛出兴 → 见自身在普贤身内十方世界教化众生 → 比较前所得善根百分不及一 → 于普贤一毛孔一念所入刹海过前不可说倍 → 于毛孔刹中行一步过微尘数世界，尽未来劫不能知刹海、佛海、菩萨众海边际 → 终得普贤诸行愿海，与普贤等、与诸佛等，一身充满一切世界，力无畏等悉皆同等。
- **颂赞佛德（P33-P37）**：普贤说颂劝听 → 诸菩萨渴仰 → 普贤复说颂赞「佛功德海一滴之相」：先赞佛智广大同虚空、一念普知三世、随众生心示现种种身（或见释迦成佛、或见无量寿、或见阿閦、或见毗卢遮那等），次赞佛于一毛端、一微尘中现恒沙刹土，复赞佛以一音随类令解、八万四千烦恼各说治法、三乘一乘皆方便力，终以「刹尘心念可数知、大海水可饮尽、虚空可量风可系、无能尽说佛功德」收束，劝众生闻已生欢喜信解。

## 三、关键结论

1. 善财五十三参以文殊按顶、见普贤身、得十智波罗蜜、普贤摩顶为圆满，表「因位（文殊智）→ 行位（普贤行）→ 果位（与佛同等）」的证入次第。
2. 普贤一一毛孔即摄三世十方一切佛刹海、一切众生、一切佛出世与菩萨众，此即华严「一即一切、一切即一」的毛孔含法界观。
3. 普贤自述往昔劫海舍转轮王位、城邑妻子、头目身命以求法护法，明菩萨行以难行能行、难忍能忍为根本，法海无一文一旬非舍身命而得。
4. 普贤以十力（助道法力、善根力、大志乐力乃至善知识力）得究竟三世平等清净法身与无上色身，明法身与色身不二、法界平等与随类现身不二。
5. 末后长颂以「佛功德海一滴之相」总收全经：佛以一音随类说法、于一毛端现恒沙刹、三乘一乘皆是方便，劝众生闻已信解当获，慎勿怀疑。

## 四、易混辨析

- **文殊师利 vs 普贤菩萨**：文殊表「智」，本卷按善财顶令其成就法门、入普贤行道场后即还摄不现，是「因位之智」的启发者；普贤表「行」，现大神通、摩顶授三昧、自述因行，是「行位」的圆满者与善财所证的境界本身。二者一启一证、一智一行。
- **法身 vs 色身**：本卷普贤以「究竟三世平等清净法身」与「清净无上色身」并举，前者是体、平等三世、超诸世间，后者是用、随众生心乐而现形入一切刹；非一非异，体用不二。
- **普贤行 vs 普贤愿**：行是劫海中所修的难行苦行（舍身命、承事佛、护持法），愿是所发一切智大誓愿；行愿并举，以行满愿、以愿导行，合称「普贤行愿海」。
- **佛刹微尘数 vs 那由他**：佛刹微尘数是将一个佛刹（三千大千世界）碎为微尘的数量，是华严特有的极大数表述，表数量多至不可思议；那由他（千百亿级）虽大，尚可量度，佛刹微尘数则喻超算数譬谕所及，本卷反复用以状劫数、三昧数、功德数。

## 五、阅读提示

读本卷可带着两个问题入手：一是善财历经五十三参为何最终归宿于普贤而非任何一位善知识？二是普贤一一毛孔何以能含摄三世十方一切佛刹？前者指向华严「行」为入法界的终极门径，后者指向「一即一切」的法界缘起观。读长颂时，可将佛功德「一滴之相」与前七十九卷所述法界无尽缘起互相对照。
