# 大方广佛华严经卷第三十一 导读

## 一、内容总览

本卷为《大方广佛华严经·十回向品第二十五之九》，即十回向中**第九回向——「无著无缚解脱回向」**的全文，由金刚幢菩萨承佛神力宣说。全卷围绕一个核心命题展开：菩萨摩诃萨以「无著无缚解脱心」修习普贤行愿，把一切善根回向给一切众生与无上菩提。所谓「无著」是不执着，「无缚」是不被系缚，「解脱」是心得自在——以这种心修一切行、回一切善根，方契普贤境界。卷末以金刚幢菩萨的颂偈总收前义，并广述如来从兜率降神、入胎、诞生、出家、降魔、成道、说法、涅槃等八相示现的自在力。

## 二、结构层次（★重点）

全卷是一篇典型的「总起 → 一根多枝广说 → 收束 → 颂偈重宣」结构，以「无著无缚解脱心」一句为贯穿全篇的轴心：

- **总起（P3-P5）**：先以「云何为菩萨摩诃萨无著无缚解脱回向」发问 → 次说菩萨于一切善根「心生尊重」（出生死、摄取善根、悔过业、随喜、礼敬、劝法等九类）→ 由尊重生信解、得安住、势力增长 → 引出「以诸善根如是回向」。
- **长行广说（P5 后半–P28）**：以数十个排比句「以无著无缚解脱心，成就／修习／安住普贤……」层层铺开，可归为几大轮：
  - **身语意业与普贤行愿**（普贤身语意业、精进、诸根行愿、回向行愿）→ 显示普贤行愿的全幅面貌。
  - **自在神通力**（一身容受无量佛刹、一华庄严十方、一毛孔纳不可说世界、一身普现一切佛前）→ 显示事事无碍、一多相即的法界观。
  - **「甚微细智」系列**（色甚微细、刹甚微细、劫甚微细、众生界甚微细、世界甚微细、法界甚微细、诸劫甚微细、一切法甚微细）→ 这是本卷最具特色的一轮，菩萨于一念中如实了知一切极微细境界而不恐怖不迷惑，显示「微细相容安立」的华严十玄门义。
  - **菩萨与如来八相行门**（一生补处、生兜率天、住母胎、诞生、师子游行七步、处王宫、出家、坐道场、破魔军、成菩提、转法轮、大涅槃）→ 显示从菩萨行到如来境的完整阶位。
- **回向平等（P29-P30）**：以「不分别若世间若世间法……不分别若法若智」九对「不分别」收束 → 显示回向时三轮体空、能所双亡；继而学三世诸佛回向、满三世诸佛平等、住三世诸佛境界。
- **结叹（P31）**：归结第九回向名义与功德——金刚轮围山不能坏、色相第一、摧破魔业、普现十方、得一切智施作佛事。
- **颂偈重宣（P32-P33）**：金刚幢菩萨以偈颂总括前义，先述尊重善根、回向众生，再广述如来八相自在与菩萨一念了知无量劫、无量世界的普贤大行，最后以「若人能修此回向，则为学佛所行道，当得一切佛功德，及以一切佛智慧」作结。

全文推进逻辑：**尊重善根（因）→ 无著无缚解脱心修普贤行（行）→ 得种种甚微细智与自在神通（德）→ 不分别三轮而回向（契理）→ 学三世佛、满三世佛平等（归果）→ 颂偈重宣（摄持）**。

## 三、关键结论

1. **「无著无缚解脱心」是本卷眼目**：一切普贤行愿、自在神通、甚微细智，皆须以此心为根本方能成就；离此心则成有漏有缚之行。
2. **普贤行的极致是「一多相即、微细相容」**：一毛端容不可说佛刹、一念摄不可说劫、一华严十方世界——这正是华严宗「十玄门」中「微细相容安立门」「一多相即不同门」的具体展开。
3. **回向必含三轮体空**：真正的回向是「不分别若自若他、若施物若受施者、若善根若回向」——能回向者、所回向物、回向对象皆不可得，方名无著无缚。
4. **菩萨行即是学佛所行**：回向的根本义是「学过去诸佛回向、成未来诸佛回向、住现在诸佛回向」，回向不是另立一法，而是随顺三世诸佛所行之道。
5. **从菩萨初发心到如来大涅槃，皆是一念中之所了知**：本卷将菩萨与如来的全部行位（一生补处、降神、入胎、诞生、出家、成道、说法、涅槃）摄于一念甚微细智中，显示因果位位相即。

## 四、易混辨析

- **回向 vs 普贤行愿**：回向是「把所修善根指向众生与菩提」的动作与发心；普贤行愿是「尽未来际修菩萨行」的具体行门内容。本卷中「普贤回向行愿」合称，即以回向心修普贤行。
- **无著 vs 无缚 vs 解脱**：无著是于境不执着（破「想倒」），无缚是不被烦恼业报所系（破「心倒」），解脱是心得自在、于法无碍（破「见倒」）——三者递进，本卷云「舍离一切想倒、心倒、见倒」。
- **甚微细智 vs 一切智**：甚微细智是菩萨于一念中如实了知差别事相（色、刹、劫、众生界、法界等极微细境）的差别智；一切智是佛地总持平等的体得。本卷先成就诸甚微细智，究竟「得一切智」「到一切智地」。
- **法界 vs 佛刹 vs 世界**：佛刹是一佛所教化的国土；世界是泛指十方一切染净刹土（仰、覆、广、狭、杂染、清净等）；法界则是涵盖一切世界、尽虚空遍法界的总体相。本卷中「以一切法界佛刹作一佛刹」即显示三者的相即关系。

## 五、阅读提示

读本卷可带着两个问题：(1)「无著无缚解脱心」到底在每一句「以……心，成就……」中起什么作用——它如何使普贤行愿成为「无漏」而非「有漏」？(2)「甚微细智」一连数十种，是否可以归纳为几大类（色身、刹土、劫时、众生、法界、诸法），它们共同指向的「一念了知」境界与华严「十玄门」如何对应？
