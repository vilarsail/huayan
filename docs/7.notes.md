# 大方广佛华严经卷第七 词语注释

① 三昧　梵语 samādhi，意为正定、等持。心一境性，离沉掉。本卷三昧名类繁多，皆为普贤从定起说之体。
② 普贤菩萨摩诃萨　「摩诃萨」即「大」，意为大菩萨。普贤为华严经宣说法门的当机者，表「理」「行」「愿」之德。
③ 莲华藏师子之座　普贤所坐之座。「莲华藏」表清净含藏法界，「师子」表无畏、降伏魔外，为佛菩萨说法之座。
④ 一切诸佛毗卢遮那如来藏身　普贤所入三昧之名。谓此三昧含藏十方诸佛法身之德，普入法界、示众影像，为发起华严法门的根本定。
⑤ 法界海漩　喻法界重重无尽、漩流互摄之相。此三昧能随入法界海漩，无不周遍。
⑥ 微尘　极细之尘，喻极小、极多。华严以「一微尘中现无量刹」表大小相即、事事无碍。
⑦ 法轮　喻佛法、教化。转法轮即宣说正法令世，破众生烦恼。诸佛护持法轮使无断绝。
⑧ 世界海微尘数　形容数量极大，如世界海碎为微尘之数。华严经常用以表「不可说、不可数」的重重无尽。
⑨ 毗卢遮那　梵语 Vairocana，意为「遍一切处」，华严宗视为法身佛、卢舍那（报身）之所从出，为法界体性之总表。
⑩ 善男子　佛对在家菩萨或修行者的通称。诸佛赞普贤「善男子」，许其为承佛力、修愿行之大士。
⑪ 佛子　佛呼菩萨之词，意为「佛之子」。此处诸佛称普贤，普贤亦以此称大众，表承佛家业、续佛慧命。
⑫ 普贤愿海　普贤所发广大行愿，如十大愿王。世界海起具因缘中列「普贤菩萨自在愿力」，与如来神力、众生行业并立。
⑬ 陀罗尼　梵语 dhāraṇī，意为总持、能持能遮。菩萨所得「陀罗尼海云」，能总持一切佛法不忘不失。
⑭ 兜率天宫　欲界第四天，补处菩萨所居。菩萨示现「从兜率天宫没、下生成佛」，即佛降生前的最后身历程。
⑮ 般涅槃　梵语 parinirvāṇa，意为圆寂、入灭。此处指如来示现入大涅槃，为八相成道之一。
⑯ 摩尼王　「摩尼」如意宝珠，「王」谓最胜。十种大摩尼王云为诸佛神力所雨，表法财普施。
⑰ 真如　梵语 tathatā，诸法实相、本然之理。菩萨「依真而住非国土」，表普贤身相如虚空，依法身真性而住。
⑱ 虚空藏　菩萨名，亦表法。此处颂云「真如平等虚空藏」，喻法身含藏功德如虚空广大无边。
⑲ 神变　佛菩萨以神通力所作变化。诸佛神变海与普贤三昧力，令十方世界海微动、普雨摩尼云。
⑳ 善知识　能教人远离恶法、修行善法之师友。清净方便海首举「亲近一切善知识」，为菩萨修行的根本外缘。
㉑ 无差别门　世界海十事之末。谓一一世界海中，诸佛威力、道场、众会、光明、名号、音声、法轮等皆无差别，归于一真法界。
㉒ 阿修罗　六道之一，有天福而无天德，常与帝释战。此处指一类以阿修罗形为所依的世界住体。
㉓ 金刚手　执金刚杵的力士，护法神。世界海有「依如幻业生大力阿修罗形金刚手住」者，亦有「住坚固金刚海」者。
㉔ 清净方便海　菩萨严净世界之方便行海。以亲近善知识、修波罗蜜、观察诸地等十事为内容，为世界海庄严之因。
㉕ 波罗蜜　梵语 pāramitā，意为「到彼岸」，菩萨六度或十度之行。清净方便海中「修治一切诸波罗蜜悉圆满」为严净刹土之因。
㉖ 菩萨诸地　菩萨修行阶位，如十地、欢喜地至法云地等。观察诸地而入住，即由地前趣入地上之实行。
㉗ 一乘法　唯一成佛之教。诸佛或唯显一乘，或显不可思议诸乘，皆随众生心乐而示现差别。
㉘ 阿僧祇　梵语 asaṃkhyeya，意为无量数、不可计数，为印度极大数词之一，常用于劫量。
㉙ 菩提心　梵语 bodhi-citta，为利众生愿成佛道之心。众生发菩提心则世界海成纯清净劫，显心业与器界互感。
㉚ 道场众会　佛说法处之菩萨海会。普贤为道场众海而说世界海十事，令其入佛智、住普贤愿。
