# 大方广佛华严经卷第二十 导读

## 一、内容总览
本卷为《大方广佛华严经》卷第二十，承上卷「十行品第二十一之一」继续宣讲菩萨十行之第七至第十——无著行、难得行、善法行、真实行，由功德林菩萨承佛神力演说。十行属菩萨修行阶位中的核心行门，前六行（欢喜行至善现行）已在上卷述毕，本卷收束十行圆满，并以法界六种震动、十方同名功德林菩萨来证、功德林重颂为结。全卷主线是「行门渐深 → 无著 → 难得 → 善法 → 真实」，层层由「离执」推进到「称法界而起用」，最终以「无尽大悲与无二实相」收摄。

## 二、结构层次
全卷按「行门四段 → 法界现瑞 → 十方来证 → 重颂收束」四阶展开：

- **无著行（P3）**：以「于念念中能入阿僧祇世界，心无所著」立宗 → 历举供养、见佛、闻法、刹土、相好、三昧、众生趣等十数境，一一「无所著」 → 以「法界如幻、佛如影、菩萨行如梦、说法如响、世间如化」五喻收摄 → 落到「一毛端处尽未来劫修菩萨行」，显无著而任运起用。
- **难得行（P4）**：先列十种善根（难得乃至与一切佛同一性） → 以「船师不住此岸彼岸中流」为喻，明「不住生死不住涅槃」而度众生 → 极演「不增不减众生界、无二法界」的圆融义 → 再以「钻木出火」喻化生无尽 → 最后以「众生不知恩报、充满烦恼，正是我所修行处」翻转大悲心，显难得之所以难得。
- **善法行（P5）**：以十种陀罗尼（清净光明、具足义、觉悟实法等）出生十种辩才无尽 → 菩萨化身金色，于一音中现无量音，于不可说众会一念酬对 → 结出「十种身」（不生不灭、不实不妄、不迁不坏等）与「为众生作舍、救、归、导、师、灯、光、炬、照、明」十用。
- **真实行（P6）**：以「如说能行，如行能说」立宗 → 学三世诸佛真实语、入其种性 → 具足十力智（是处非处、业报、根利钝等）而仍不舍菩萨行 → 发增上心「先令众生得无上菩提，然后成佛」 → 普入世间现无量身，入因陀罗网法界，成就师子吼、无碍法轮。
- **法界现瑞与十方来证（P7-P8）**：十方世界六种震动、雨天华香等 → 十万佛刹微尘数同名功德林菩萨俱来，作证「十方世界悉亦如是」，显一即一切、主伴圆融。
- **重颂收束（P9-P111）**：功德林以颂重宣十行义 → 先礼赞三世诸佛离垢无碍 → 逐行颂出菩萨所行道（檀波罗蜜、智地、法界、三昧、忍、身业、神通、方便等），末以「假使无量无边佛于无量劫说不尽」叹德无尽收结。

## 三、关键结论
1. 十行的义理核心是「无所著」：从无著行到真实行，皆以「不住、不染、不二」为体，以「不舍大愿、不舍众生」为用，体用不二方为真实行。
2. 众生界与法界无二：难得行中明「众生界即法界」，故不增不减、不生不灭；化度众生而不执众生想，是菩萨入法界的真实相。
3. 法界如幻：无著行五喻（幻、影、梦、响、化）显一切法无实而业报不失，是「即相离相」的观行枢要。
4. 先度众生后自成佛：真实行中菩萨发增上心，「不请之友」的悲愿，体现华严「自利利他本自圆融」的菩萨种性。
5. 一即一切：一毛端处见无量诸佛、一音现无量音、一念酬对不可说众会，皆显因陀罗网法界重重无尽义。

## 四、易混辨析
- **无著行 vs 真实行**：无著行重在「离执不著」，从所缘境上明不著；真实行重在「如说能行，如行能说」，从能行言行的相应上明真实。前者是行相之离染，后者是行体之诚谛。
- **难得行 vs 善法行**：难得行以「十善根」为体、以「不住二岸度众生」为用；善法行以「十陀罗尼、十辩才」为体、以「十身、十用」为用。前者偏叹其「难」，后者偏赞其「法」之清净无尽。
- **不住生死不住涅槃 vs 不住此岸彼岸中流**：前者约「圣凡二界」立名，后者约「船师度河」为喻，义同喻别——皆是中道不二、悲智双运之义。
- **陀罗尼 vs 三昧**：三昧译「等持」，偏于「心一境性」的定体；陀罗尼译「总持」，偏于「持法不失、持恶不生」的慧用。善法行中由诸陀罗尼出生诸辩才，是依慧起用义。

## 五、阅读提示
读本卷宜紧扣「无所著」三字为纲——无著行直标其名，难得行明「难在不著而能度」，善法行明「不著而辩才无尽」，真实行明「不著而如说能行」。偈颂部分可先抓每颂末句「彼某者行此（斯）道」的格式，即知在颂何种行相，再回看上长行对应义理，便能前后贯通。
