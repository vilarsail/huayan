# 大方广佛华严经卷第七十一 词语注释

① 普救众生妙德夜神　上一位（第34参）夜神的名字。善财在她那里听闻「菩萨普现一切世间调伏众生解脱门」后，才转访本卷的寂静音海夜神。
② 寂静音海夜神　本卷前半所访的第35参善知识，所得法门为「念念出生广大喜庄严解脱门」。
③ 阿耨多罗三藐三菩提　梵语音译，意译为无上正等正觉，即佛的觉悟；善财每参必先自陈「已发阿耨多罗三藐三菩提心」。
④ 善知识　能引导众生趣向善法、觉悟的老师。善财童子遍历百城、五十三参，参访的全是善知识。
⑤ 念念出生广大喜庄严解脱门　寂静音海夜神的法门：在每一个念头之中都出生广大欢喜、以此庄严，故名。
⑥ 乐欲心　喜爱与希愿之心。夜神先发起清净平等的乐欲心等一系列心，作为修行的起点。
⑦ 不退转位　菩萨修行达到不再退失的阶位。夜神发心「攀缘不退转位永不退转」。
⑧ 五蕴　色、受、想、行、识五类要素，佛教对身心的分析。经中说众生爱着五蕴，夜神为说无依境界。
⑨ 法施　以佛法布施众生，与财施相对。夜神自述「以此等无量法施摄诸众生」。
⑩ 三昧　梵语音译，意为正定。夜神追述本生时，每见一佛即得一个三昧，各有名称。
⑪ 毗卢遮那　梵语音译，意为光明遍照，华严宗所尊的法身佛。本卷观佛境界皆观毗卢遮那如来。
⑫ 佛刹微尘数　以一个佛国土碎为微尘的数量，形容极多。华严惯用「某某微尘数」表无量数。
⑬ 萨婆若　梵语音译，意为一切智，佛所成就的遍知。经中有「量与法界萨婆若等」「住萨婆若道」。
⑭ 譬谕　同「譬喻」。夜神以大地、大水、大火、虚空、满月等三十余个比喻说明解脱的德相。
⑮ 十大法藏　夜神答「云何修行得此解脱」：修布施、净戒、堪忍、精进、禅定、般若、方便、诸愿、诸力、净智十种广大法藏。
⑯ 华藏庄严世界海　《华严经》所描述的整个宇宙总体，由无数世界海组成；发心段即从此世界海往东定位。
⑰ 清净光金庄严　夜神往昔发心的世界名，在华藏世界海东十个世界海之外，形如楼阁，净秽相杂。
⑱ 菩提树神　守护菩提道场的女神。夜神本生最初即在清净光金庄严世界作菩提树神而发心。
⑲ 迦罗鸠孙驮　拘留孙佛的音译，贤劫第一尊（应身）佛。夜神生此娑婆世界贤劫后首先值遇的佛。
⑳ 拘那含牟尼　贤劫第二尊佛，迦罗鸠孙驮佛之后夜神所值遇的如来。
㉑ 陀罗尼　梵语音译，意为总持，能总摄忆持无量佛法而不忘失的力量。
㉒ 修多罗　梵语音译，即契经，佛所说经典的通称。经中有「悟解一切修多罗云」。
㉓ 贤劫　现在的大劫之名，因千佛将在其中出世而得名，释迦牟尼佛是第四尊。
㉔ 守护一切城增长威力　本卷后半所访的第36参主夜神之名，寂静音海夜神指路让善财前往请教。
㉕ 菩萨甚深自在妙音解脱　守护一切城夜神的法门：以甚深自在的妙音为众生说法，故亦称大法师。
㉖ 金刚那罗延藏　那罗延为力士天名，喻坚固之力。形容闻法众生求一切智之心坚固犹如金刚那罗延藏。
㉗ 陀罗尼轮　轮喻法轮运转不息。夜神得十种大威德陀罗尼轮，各以普入、普持、普说等立名。
㉘ 闻慧　从听闻佛法所得的智慧，与思慧、修慧并列。夜神「或为众生说闻慧法、思慧法、修慧法」。
㉙ 授记　佛预先告知某众生将来成佛的名号与劫国。夜神为众生说「一佛授记海法」等。
㉚ 离垢光明　守护一切城夜神往昔发心的劫名。夜神本生即在此劫中，历须弥山微尘数佛出家学道。
㉛ 法界功德云　离垢光明劫中的世界名，以现一切众生业摩尼王海为体，形如莲华。
㉜ 须弥山微尘数　以须弥山碎为微尘的数量，形容极多。此劫中有须弥山微尘数如来出兴于世。
㉝ 转轮王　统一四天下、以轮宝引导的圣王。夜神本生曾是清净日光明面转轮王，佛涅槃后出家护法。
㉞ 多罗树　东印度的棕榈科高树，其叶可书写经文。本生中王比丘上升虚空「高七多罗树」。
㉟ 比丘尼　出家的女性僧人。转轮王之女法轮化光即比丘尼，是守护一切城夜神的前身。
㊱ 法轮化光　本生中转轮王之女、比丘尼之名；因守护佛法令十万比丘尼不退转，即今夜神。
㊲ 开敷一切树华　第37参主夜神之名，守护一切城夜神卷末指路，让善财前往请问如何学一切智。
㊳ 总持海　总持（陀罗尼）众多如海。善财得入妙音解脱后「入无边三昧海，入广大总持海」。
