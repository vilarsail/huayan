# 大方广佛华严经卷第七十一 词语注释

〔1〕 于阗国　古西域国名，在今新疆和田一带，大乘佛教经典传入汉地的重要中转地。
〔2〕 实叉难陀　于阗国三藏法师，八十卷《华严经》的译者；「奉制译」谓奉皇帝诏命翻译。
〔3〕 入法界品　《华严经》最后一品，叙善财童子五十三参、历访善知识以证入法界之事；本卷为其第十二分会。
〔4〕 尔时　那时；经中承上启下、标示时间转换的常用发端词。
〔5〕 善财童子　入法界品的主角，发菩提心后遍参善知识的童子，此卷正参访诸主夜神。
〔6〕 普救众生妙德夜神　善财上一参所亲近的善知识（夜神），此处告别。
〔7〕 夜神　即主夜神，掌护夜晚的天神；入法界品中诸夜神多为大菩萨权现。
〔8〕 圣者　对已证圣位者的尊称，善财用以称呼所参的夜神。
〔9〕 阿耨多罗三藐三菩提心　梵语音译，「无上正等正觉」之心，即上求佛道、下化众生的志愿。
〔10〕 菩萨行　菩萨修行的种种法门与行为；善财求学的总目标。
〔11〕 云何　如何、怎样；经中设问的常用虚词。
〔12〕 念念出生广大喜庄严解脱门　寂静音海夜神所证解脱，谓于一念一念之间生出广大欢喜与庄严功德。
〔13〕 何事业　善财连发四问——「为何事业？行何境界？起何方便？作何观察？」，问此解脱以何为业用、以何为所行境、起何方便、作何种观行。
〔14〕 乐欲心　乐（yào）欲，好乐希求；乐欲心指炽然向上的求道意愿。
〔15〕 攀缘　心攀附外境而起念分别；此处赞神「念念攀缘一切境」而心无分别。
〔16〕 不退转位　菩萨不再退失所证的阶位（即阿鞞跋致），通常指八地以上。
〔17〕 爱别离苦　八苦之一，与所爱之人事物离别之苦；下文「怨憎会苦」谓与怨憎者相会之苦。
〔18〕 依怙　怙（hù），依靠；「作依怙心」即发愿作险难众生的保护者。
〔19〕 所谓　提示下文列举之辞，犹今语「即是」。
〔20〕 采女　宫中供役使的女子、嫔妃侍女。
〔21〕 波罗蜜　梵语音译，意译「到彼岸」；华严说十波罗蜜，即六度之外加方便、愿、力、智四种，本卷均见。
〔22〕 见稠林　稠林即密林；「见」指种种错误的见解，喻邪见密布如林、行人难以走出。
〔23〕 无明　愚痴，不明缘起实相的根本烦恼；「生死夜无明昏寐」喻众生在长夜昏迷。
〔24〕 般若　梵语音译（bō rě），智慧之义；指照见实相的智慧，非世间聪明。
〔25〕 闇心　闇同「暗」，愚痴暗昧之心。
〔26〕 二乘　声闻乘与缘觉乘，只求自度、不发广度众生之愿。
〔27〕 城廓　廓同「郭」，外城；城廓泛指城邑。
〔28〕 法王城　法王即佛；法王城喻佛法王所治之境，即一切智地。
〔29〕 四隅　东、南、西、北四正方之外的四个斜角方位。
〔30〕 不净观门　观身不净以对治贪欲的观法，针对「贪行多者」。
〔31〕 大慈观门　观众生皆可乐以对治瞋恚的慈悲观法，针对「瞋行多者」。
〔32〕 等分行者　贪、瞋、痴三毒均等之人，对上文贪行多、瞋行多、痴行多而言。
〔33〕 五蕴　蕴即积聚；色、受、想、行、识五种组成身心的要素。
〔34〕 憍慢　憍同「骄」，自高凌人之慢心。
〔35〕 谄曲　心曲意逢迎、谄媚而不正直。
〔36〕 三昧　梵语音译，意译「正定」，心住一境而不散乱。
〔37〕 辩才　说法的才辩，谓语无滞碍、能随机宣说。
〔38〕 毗卢遮那如来　梵语音译，意译「遍一切处」，华严经的教主、法身佛。
〔39〕 佛刹微尘数　把一佛国土碎为微尘，以尘数喻极多；下文「世界转微尘数劫」「须弥山微尘数」同理。
〔40〕 夜叉王　夜叉为捷疾鬼神，八部众之一；经中常举诸「王」身云以显佛于一毛孔现无量类身。
〔41〕 乾闼婆王　乾闼婆（gān tà pó）为帝释的乐神，不食酒肉、唯以香气为养，八部众之一。
〔42〕 阿修罗王　阿修罗为常与天战斗的多福多瞋之神，八部众之一。
〔43〕 迦楼罗王　迦楼罗即金翅鸟神，以龙为食，八部众之一。
〔44〕 紧那罗王　紧那罗为歌神，形似人而头有角，八部众之一。
〔45〕 摩睺罗伽王　摩睺罗伽（mó hóu luó qié）为大蟒神，八部众之一。
〔46〕 梵王　大梵天王，色界初禅天之王。
〔47〕 萨婆若　梵语音译，意译「一切智」，指佛的一切种智。
〔48〕 何以故　为什么呢？经中设问之辞，下文自答。
〔49〕 须弥山　一小世界中心之高山，日月众星绕行其侧。
〔50〕 呼响　回声；喻说法随叩而应、无有实体。
〔51〕 如如　真如常住、不改不异之相；「虚空如如」谓如虚空般平等寂静。
〔52〕 摩尼　梵语音译，如意宝珠，能随心出生种种珍宝光明。
〔53〕 寂静音海夜神　本卷前半所参的善知识，主夜神，所证法门为「念念出生广大喜庄严解脱」。
〔54〕 十大法藏　名数：夜神举修十种广大法藏（布施、净戒、堪忍、精进、禅定、般若、方便、诸愿、诸力、净智），即十波罗蜜的展开；读法抓每条首句。
〔55〕 其已久如　犹言「有多久了」，问某事（如发心）以来经过多久。
〔56〕 华藏庄严世界海　即莲华藏世界，毗卢遮那如来所居净土，无量世界层层含摄如大海。
〔57〕 世界种　华严世界结构：世界海中分出世界种，世界种下安立众多世界。
〔58〕 璎珞　珠玉串成的装饰品，庄严身首之饰。
〔59〕 净秽相杂　谓该世界清净与秽恶参杂，即凡圣同居之土。
〔60〕 菩提树神　守护菩提道场之树神；寂静音海夜神往昔曾为此神而见佛发心。
〔61〕 出兴于世　出现于世间，经中惯用以指佛成道说法。
〔62〕 转正法轮　轮喻佛法能碾摧惑障、运转不息；转法轮即说法。
〔63〕 承事　侍奉、承顺服役。
〔64〕 娑婆世界　梵语音译，意译「堪忍」，释迦佛教化的世界。
〔65〕 迦罗鸠孙驮如来　即拘留孙佛，贤劫中已出世的最初一尊佛。
〔66〕 拘那含牟尼如来　贤劫中第二尊出世之佛。
〔67〕 迦叶如来　贤劫中第三尊出世之佛，非释迦弟子中的大迦叶尊者。
〔68〕 法界安立海　安立，建立施设；法界安立海谓法界中一切世界之建立，浩瀚如海。
〔69〕 陀罗尼　梵语音译，意译「总持」，能总持无量法门与文义而不失。
〔70〕 修多罗　梵语音译，意译「契经」，经典之通称。
〔71〕 本事　佛往昔因地修行之事；「本事海」谓无量往昔事迹。
〔72〕 劫海　劫，梵语「劫波」之略，极长的时间单位；劫海谓劫数之多如海。
〔73〕 贤劫　现在之住劫，因此劫将有千佛出世而得名。
〔74〕 王贼　「水火及王贼」诸恐怖中的「王贼」：官府横暴与盗贼劫夺之难。
〔75〕 炽然　然同「燃」，燃烧猛烈貌，喻烦恼如火炽盛。
〔76〕 楚毒　楚，痛楚；楚毒谓酷烈之苦。
〔77〕 菩提场　佛成道之处；此处指菩提场中的如来法会。
〔78〕 守护一切城增长威力　本卷后半善财所参的主夜神之名，继寂静音海夜神之后的善知识。
〔79〕 计有　妄计（执）诸法实有，即执为实存。
〔80〕 劣智浅识人　此二句须反读：「（岂是）劣智浅识之人（所能）知尊境界」，隐含反问。
〔81〕 师子之座　师子即狮子；佛菩萨所坐之座喻其说法无畏如狮子王。
〔82〕 无上摄　摄，摄化、摄受；以无上之法引导众生。
〔83〕 佛种性　佛的法脉种子；「守护一切佛种性」即令诸佛家业不断绝。
〔84〕 甚深自在妙音解脱　守护一切城增长威力夜神所证的法门，以自在妙音说法无碍。
〔85〕 白法　白净之善法，对「黑法」恶法而言。
〔86〕 那罗延　梵语音译，天上大力士之名，身极坚固；「那罗延藏」喻其心坚固不可坏。
〔87〕 助道之法　助道，资助正道之法，即三十七菩提分等道品。
〔88〕 十种观察法界　名数：夜神以无量、无边、无限等十句观察法界；读法抓每条「我知法界」起首。
〔89〕 何者为十　设问列举之辞：「哪十种？」下文逐条自答，长清单皆循此式。
〔90〕 如来一音　谓佛以一音声说法，众生各随其类皆能解了。
〔91〕 陀罗尼轮　轮喻法能碾摧障惑、运转不息；下举十种大威德陀罗尼轮，各以十千陀罗尼为眷属。
〔92〕 十千　十千即一万。
〔93〕 闻慧　闻、思、修三慧之一，从听闻而得的智慧；下文思慧、修慧依次转深。
〔94〕 一有法　有，指三有（欲、色、无色界）中的生存；一有法谓就某一类存在所说之法，与「一切有法」对举。
〔95〕 授记　佛预记众生将来成佛之名号、劫数、国土等。
〔96〕 四天下　一须弥山四方之四大洲（东胜身、南赡部、西牛货、北俱卢），一世界的住人之处。
〔97〕 那由他　梵语数名，或说千亿，泛指极大之数。
〔98〕 转轮王　即转轮圣王，统一四天下、具七宝的圣王；此处即后来出家护法的王。
〔99〕 涅槃　梵语音译，意译灭度；「佛涅槃后」谓佛入灭之后。
〔100〕 千部异众　谓教团分裂成千种部众，各执异说。
〔101〕 末劫　末法之世；正法、像法之后教法衰微、诤乱滋起的时期。
〔102〕 法炬　炬，火把；法炬喻佛法能照破黑暗。
〔103〕 多罗树　梵语音译，棕榈科高树；「高七多罗树」极言其高。
〔104〕 法轮化光　比丘尼名，即彼国王之女，是守护一切城增长威力夜神的往昔之身。
〔105〕 于汝意云何　「你意下以为如何？」经中引出说喻问答的常用设问。
〔106〕 岂异人乎　反问句式：「岂是别人吗？」意即「正是此人」，下文「今普贤菩萨是」即其自答。
〔107〕 普贤菩萨　华严会上代表大行大愿的大菩萨；此处示现彼转轮圣王之后身。
〔108〕 栴檀　梵语音译，檀香木，香中之上品。
〔109〕 波头摩华　梵语音译，赤莲华。
〔110〕 心城　心如城郭能守能御；「守护心城」谓守护自心，不为烦恼所侵。
〔111〕 戏论语　戏论，无益于道、增长烦恼的言论。
〔112〕 二语　前后不一、模棱两可的虚诳之语。
〔113〕 开敷一切树华　此佛会中的主夜神，善财下一位将参访的善知识；开敷，敷即开放，谓花开。
〔114〕 刹转微尘劫　将诸世界（刹）展转碎为微尘，一尘一劫，喻劫数极多。
〔115〕 含识　具有心识的一切有情，即众生。
〔116〕 总持　即陀罗尼的异称，总一切法、持无量义。
〔117〕 诸有　三有、二十五有，指生死轮回中的一切存在形态。
〔118〕 调御师　即「调御丈夫」，佛的十号之一，能调伏驾驭众生之心。
