# 大方广佛华严经卷第七十一 词语注释

① 入法界品　《华严经》最后一品，述善财童子五十三参、历参善知识求菩萨道之事，本卷为该品之十二。
② 善财童子　南行求法之青年菩萨，遍参五十三位善知识，为《入法界品》主角，代表发心求道之行者。
③ 普救众生妙德夜神　善财前一所参之夜神，传「普现一切世间调伏众生解脱门」，本卷承其后转入寂静音海夜神所。
④ 寂静音海夜神　本卷善财所参之主夜神，得「念念出生广大喜庄严解脱门」，自述多劫承事诸佛之本生因缘。
⑤ 阿耨多罗三藐三菩提　梵语，意为无上正等正觉，即佛果之智，菩萨发心所求之最高目标。
⑥ 善知识　能教导菩萨行、令入佛道之师友，善财即以依止善知识为参学路径。
⑦ 念念出生广大喜庄严解脱门　寂静音海夜神所得法门之名，谓于每一刹那中亲见如来色身光明神变，由此出生广大欢喜庄严之解脱境界。
⑧ 乐欲心　志愿好乐之心，夜神先发十六种清净乐欲心为修因，如离垢、不退、普现救护等。
⑨ 不退转位　菩萨于菩提道不退转之阶位，至此则道心坚固，不再退堕二乘或生死。
⑩ 忍波罗蜜　六波罗蜜之一，忍辱度，安受打骂、苦逼、法义不惊不乱之心，夜神对瞋众生令住此度。
⑪ 精进波罗蜜　六度之一，精进度，勇猛修善断恶无倦怠，夜神对懈怠众生令得此度。
⑫ 禅波罗蜜　六度之一，禅定度，心一境性、寂静不动，夜神对散乱众生令得此度。
⑬ 稠林　喻妄见邪执交络难出，如稠密之林，「见稠林」「无明暗障」指诸见错综、愚暗覆心之状态。
⑭ 般若波罗蜜　六度之一，智慧度，照了一切法实相之智，夜神对无智众生令得此度。
⑮ 三界　欲界、色界、无色界，即有情生死流转之三种存在层级，夜神令染着三界者出生死。
⑯ 二乘　声闻、缘觉二乘，但求自了生死、不度众生，不及佛乘之究竟，夜神令人超越二乘住如来地。
⑰ 五蕴　色受想行识，构成有情身心之五法，众生爱着五蕴为我，夜神令其得住无依境界。
⑱ 法施　以佛法教化众生之布施，对财施而言，夜神以无量法施摄受各类机根众生。
⑲ 三昧　梵语三摩地，意译正定，心注一境、平等任持之定，夜神历值诸佛各得一三昧。
⑳ 法界　一切法之界，统摄佛与众生、器世间与有情世间之总相，本卷云「量与法界萨婆若等」。
㉑ 毗卢遮那　梵语，意为遍一切处，华严宗所立法身佛，此土教主，夜神观其念念出清净色身光明神变。
㉒ 佛刹微尘数　以一佛刹（佛国土）碎为微尘之数为量，表极多数，华严经中常用之数事喻。
㉓ 乾闼婆　八部之一，天乐神，香神，夜神往昔曾为乾闼婆王承事诸佛。
㉔ 阿修罗　八部之一，好斗之鬼神，夜神往昔曾为阿修罗王。
㉕ 迦楼罗　八部之一，金翅鸟，以龙为食，夜神往昔曾为迦楼罗王。
㉖ 紧那罗　八部之一，歌神，人非人，夜神往昔曾为紧那罗王。
㉗ 摩睺罗伽　八部之一，大蟒神，夜神往昔曾为摩睺罗伽王。
㉘ 萨婆若　梵语，即一切智，佛之究竟智，夜神云其欢喜「量与法界萨婆若等」。
㉙ 如意珠　梵语摩尼珠，能随意出生所需之物，喻解脱门能出生无量自在之力。
㉚ 华藏庄严世界海　毗卢遮那如来所依之广大世界海，娑婆世界在其中，夜神自述其发心修行之所在。
㉛ 菩提树神　守护菩提树之道场神，夜神往昔为「具足福德灯光明幢」菩提树神，见佛成道而发心。
㉜ 法云　喻佛法如云普覆一切，亦为十地最高之第十地名，本卷云一一法海中悟解一切法云。
㉝ 娑婆世界　梵语，意译堪忍，即释迦牟尼佛所教化之此方世界，夜神自清净光金庄严世界命终生此。
㉞ 迦罗鸠孙驮　贤劫第一佛，即拘留孙佛，夜神生此娑婆后首值之佛，得离尘垢光明三昧。
㉟ 拘那含牟尼　贤劫第二佛，即拘那含牟尼佛，夜神值之得普现一切诸刹海三昧。
㊱ 迦叶　贤劫第三佛，即迦叶佛，夜神值之得演一切众生言音海三昧。
㊲ 陀罗尼　梵语，意译总持，忆持文义不忘之念慧力，夜神得「速疾陀罗尼力」受持一切文义。
㊳ 修多罗　梵语，意译经契，佛所说教法之文句，本卷云一一法门中悟解一切修多罗云。
㊴ 贤劫　现处之劫名，此劫中有千佛出世，迦罗鸠孙驮至释迦及未来弥勒等皆在此劫。
㊵ 菩萨摩诃萨　梵语，意译大菩萨，指登地以上、已发大心、堪任大行之菩萨，夜神谦言未及彼功德行。
