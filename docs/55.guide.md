# 大方广佛华严经卷第五十五 导读

## 一、内容总览

本卷属《大方广佛华严经·离世间品第三十八》之三，承前两卷普慧菩萨二百问、普贤菩萨叠答之体例，继续由普贤菩萨为菩萨摩诃萨开示一系列法门。全卷以「十种」为单位，枚举菩萨从初发心到究竟菩提所应发起、安住、成就的各类心行——由「无下劣心」起步，经「如山增上心」「如海智」「如宝住」「如金刚大乘誓愿心」「大发起」「究竟大事」「不坏信」「得授记」「善根回向」「得智慧」「发广大心」「伏藏」「律仪」「自在」，凡十五门，层层升进，统摄菩萨因地到果地的一切行相。其核心在于：菩萨于「一切法无所得」的空性中，仍炽然修行、不舍大悲、不证实际，以「无所得」与「勤修行」不二为宗。

## 二、结构层次（★重点）

全卷结构是「枚举式叠答」，每门皆以「佛子！菩萨摩诃萨有十种X」起，以「若诸菩萨安住此法，则得Y」结，形成「标名→列十→结益」的标准段式。其内在推进如下：

- **发心阶（因地起点）**：十无下劣心 → 十如山增上心。前者立菩萨「不当自轻」之本志（降魔、破外道、满波罗蜜、舍身命、一念相应慧知一切法）；后者进言「如山不动」之增上意，勤修一切智、观法性空、敬奉善知识、忍辱受苦、不为功德染着、尽未来劫行菩萨行。

- **解行阶（广大境智）**：十如海智 → 十如宝住。如海智重在「入」——入众生界、世界、虚空界、法界、三世劫数、诸佛大会，明菩萨智量深广如海；如宝住重在「住」——住于诸佛所、闻法不忘、此殁彼生不迷、知一法出一切法、修而不证实际、知法一性而无性。

- **誓愿阶（金刚坚固定慧）**：十如金刚大乘誓愿心 → 十大发起。前者立「不可坏」之誓：尽三世觉了诸法、一毛端处度无量众生、严净十方世界、回向善根、供养诸佛、忍众生恼害、尽未来劫行道、以心为本而不证、了达一切不可得而不舍大悲。后者由誓起「行」：供养诸佛、长养菩萨善根、庄严佛塔、教化众生、庄严世界、为一众生尽未来劫行菩萨行、供养舍利造像、成无上菩提演说正法。

- **究竟阶（果地圆成）**：十究竟大事 → 十不坏信 → 十得授记 → 十善根回向 → 十得智慧 → 十发广大心 → 十伏藏 → 十律仪 → 十自在。由「究竟大事」收束发心行相，以「不坏信」立其信根，以「得授记」明其果证，以「善根回向」同善知识心行愿、平等、清净、成满，以「得智慧」开其智用，以「发广大心」扩其心量，以「伏藏」显其法财，以「律仪」护其戒行，终以「十自在」——命、心、资具、业、受生、解、愿、神力、法、智——圆满菩萨至佛果间的全体大用。

- **过渡衔接**：各门以「佛子！菩萨摩诃萨……」领起，「是为第N」「佛子！是为……十种X」「若诸菩萨安住此法……」收束，环环相扣；前一门的「结益」即下一门的「所入」，形成「发心→解行→誓愿→究竟→自在」的因果链。

## 三、关键结论

1. 菩萨行以「无下劣心」为始、以「十自在」为终，因地心行与果地德用一贯相承。
2. 「一切法无所得」与「炽然勤修善业、不舍大愿」不二——菩萨了达诸法空寂，仍以大悲为首、尽未来劫行菩萨道，是本卷反复宣示的核心宗要。
3. 善知识、善根回向、不坏信三者，是菩萨「不断菩萨行」的关键支撑——同善知识愿心行善根、信乐不坏、恭敬供养，方得授记与智慧。
4. 「如金刚」之誓愿不可坏，菩萨于诃骂楚挞、截割手足耳鼻乃至级头，皆能忍受，不动恚害——此即金刚性之具体所指。
5. 十自在总摄菩萨于寿命、三昧、庄严、受报、受生、见解、愿、神通、法门、智用上的无碍大用，是「安住此法即圆满诸佛诸波罗蜜」的果地功德。

## 四、易混辨析

- **无下劣心 vs 如山增上心**：前者是「不自轻、不退怯」的初发意，重在立大志愿；后者是「不动摇、不退转」的坚固意，重在久修不动。前者破「下劣」，后者立「增上」。
- **如海智 vs 如宝住**：如海智重在「入一切界、劫、众生、法界」的智量广大，如海纳百川；如宝住重在「安住」于诸佛所、正法、实际彼岸的善巧坚固，如宝处众宝。
- **如金刚大乘誓愿心 vs 大发起**：誓愿心是「立不可坏之愿」，大发起是「依愿起行」——前者是心之坚，后者是行之勤。
- **不坏信 vs 得授记**：不坏信是菩萨对佛、法、僧、善知识、众生、大愿、大行等不可坏坏的信心；得授记是依此信解行所得的佛之记莂。信为因，记为果。
- **律仪 vs 自在**：律仪是「不诽谤、不退、不损害、能降魔、满足波罗蜜」的防护行；自在是防护既圆所显的无碍大用。戒为方便，自在为果。

## 五、阅读提示

读本卷可带着两个问题：其一，菩萨既了达「一切法皆无所得」，为何仍炽然修行、不舍大愿？其二，「十」这个数字在每一门反复出现，其表法意义为何？前者是空与悲的辩证，后者是「十十相摄、重重无尽」的华严数法门。把握这两点，便能透过枚举的繁复，见到菩萨「不证实际、不舍大悲」的一贯精神。
