# 大方广佛华严经卷第五十二 词语注释

① 菩萨摩诃萨　梵语摩诃萨意为「大」，即「大菩萨」，指已发大心、修大行、趣大果的菩萨，华严经中普贤说法的对象与听众。
② 如来、应、正等觉　佛十号中之三：如来（乘真如之道来成正觉）、应供（应受天人供养）、正等觉（正且平等之正觉）。经中每以三号合称指佛。
③ 真如无差别境界　十种如来境界之第六。真如为诸法本然之理，于一切法中平等无二、无有差别。
④ 无境界境界　十种如来境界之第十，指「一切处无有」之究竟境——非有境非无境，是如来境界之极。
⑤ 阎浮提　即南赡部洲，佛所化之地球人间。本卷以阎浮提等四天下河流喻如来智海之量。
⑥ 拘耶尼　西牛货洲，旧译瞿耶尼，四大部洲之西洲。经中言「西拘耶尼有五千河流入大海」。
⑦ 弗婆提　东胜神洲，旧译弗婆提，四大部洲之东洲。「东弗婆提有七千五百河流入大海」。
⑧ 郁单越　北俱芦洲，旧译郁单越，四大部洲之北洲，福报最胜。「北郁单越有一万河流入大海」。
⑨ 娑竭罗龙王　咸海龙王，译曰碱水海龙。经中以娑竭罗龙王连雨大海喻如来智海之深广，其太子名阎浮幢。
⑩ 优波尼沙陀分　梵语 upaniṣad 音译，译为「极少分」「微细分」，为印度极其微小的数量单位，喻百分、千分所不能及之分。
⑪ 菩提分法　趣向菩提之道品，通指三十七道品（四念处、四正勤等七科），为菩萨所修趣佛果之行。
⑫ 欢喜地　菩萨十地之初地，初证真如、生大欢喜，名欢喜地。经中言「从初欢喜地乃至究竟无障碍地」。
⑬ 十力　佛所具之十种智力（处非处智力、业报智力、根胜劣智力等），佛之独特功德。经中「十力牟尼」「十力能拔善根人」即指佛。
⑭ 那由他　梵语 nayuta 音译，极大数量名，译曰兆、亿或万亿，泛指数量极多。经中「百千亿那由他劫」「那由他世界」等。
⑮ 金翅鸟王　梵语迦楼罗，佛教中能食龙之大鸟。经中以金翅鸟王以翅辟水搏取龙喻佛以止观两翅鼓生死爱水、摄取善根成熟众生。
⑯ 成正觉　梵语 abhisaṃbodhi，指成佛证无上正等正觉。本卷广明如来成正觉之一相无相、一性无性。
⑰ 无相性　诸法实相离一切相之性。经中列十种无性（无相、无尽、无生、无灭、无我、无非我等），言众生与佛同一「无性」。
⑱ 无生性　诸法本来自性不生之理，为十种无性之一，亦是佛成正觉所证之实相。
⑲ 善觉智三昧　佛所入三昧名。经言如来成正觉时「以一相方便入善觉智三昧」，于一成正觉广大身现众生数等身住于身中。
⑳ 转法轮　梵语 dharmacakra pravartana，佛说法度生之谓。本卷明「无起无转而转法轮」，以文字言音无所住为体。
㉑ 离欲际　离烦恼欲之究竟际，十种涅槃所如之一，指涅槃即究竟离欲之境。
㉒ 究竟无碍无畏　佛所入三昧之名。入此定已，于成正觉一一身、一一口各出众生数等言音而转法轮，令一切众生皆生欢喜。
㉓ 般涅槃　梵语 parinirvāṇa，译入灭、圆寂，指佛示现化缘已讫而入灭。本卷明「涅槃无生无出故无灭」。
㉔ 法性际　诸法本性之极际，与真如、实际、法界同体异名，本卷以「如法性际涅槃，如来涅槃亦如是」等十句明涅槃自性。
㉕ 不动三昧　佛示涅槃时所入三昧名。入此定已，一一身放无量光、出阿僧祇莲华，华蕊师子座上有佛结跏趺坐。
㉖ 阿僧祇　梵语 asaṃkhyeya 音译，意为「无数」，极长时间或极多数之名。经中「一一光明各出阿僧祇莲华」。
㉗ 结跏趺坐　佛之常坐法，两足交叠置两股上。经言师子座上皆有如来结跏趺坐。
㉘ 金刚　梵语 vajra，喻坚固不坏。经中以「食少金刚终竟不消要穿其身」喻于佛所种少善根必穿烦恼身、至无为智。
㉙ 无余涅槃　烦恼与残习皆尽之究竟涅槃，对「有余涅槃」而言。经言少善根「必能烧尽一切烦恼，究竟得于无余涅槃」。
㉚ 善见　雪山中药王树名。见、闻、嗅、尝、触、乃至取其地土，皆能除病清净六根，喻佛无上药王利益众生。
㉛ 广长舌　佛三十二相之一，舌广覆面、长发覆头，表口业久劫不妄语。经言「具广长舌，解语言法」。
㉜ 念佛三昧　专念忆佛而得之三昧，经言「若于如来生忆念者，则得念佛三昧清净」。
㉝ 如来秘密之处　此如来出现法门之十种异名之首，谓此法甚深微密，唯佛与菩萨能知，非余众生所及。
㉞ 转轮圣王　世间福报最胜之王，具七宝。经中以其七宝唯太子得、无太子则宝散灭，喻此法门唯菩萨真子能持。
㉟ 生如来家　谓闻此法门信解悟入，即成为佛真子，得佛种性，名为生如来家。
㊱ 阿耨多罗三藐三菩提　梵语 anuttarā-samyak-saṃbodhi 音译，译无上正等正觉，即佛所证之究竟果。
㊲ 六波罗蜜　布施、持戒、忍辱、精进、禅定、般若六种度生死至彼岸之法，菩萨所必修。
㊳ 佛刹微尘数　以一佛刹磨为微尘之数量，喻数极大。经中十方有八十不可说百千亿那由他佛刹微尘数如来同名普贤现身作证。
㊴ 毗卢遮那　梵语 Vairocana，译遍一切处，为华严经之法身佛，本卷明「毗卢遮那本愿力故」加持十方菩萨来集作证。
㊵ 普光明世界　十方同名普贤菩萨之所从来处，彼世界佛名普幢自在如来，所说之法与此界不增不减。
