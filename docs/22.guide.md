# 大方广佛华严经卷第二十二 导读

## 一、内容总览

本卷为《华严经》「六天品」序列之第三——升兜率天宫品第二十三，承「夜摩天宫」之后，如来不离菩提树下及须弥顶、夜摩天宫，以神力往诣兜率陀天一切妙宝所庄严殿。全卷以「庄严—奉迎—赞佛—受请入殿—结坐演法」为线，铺陈兜率天王敷座、十方天子云集供养、诸天菩萨共见如来神变、兜率天王以颂叹过去诸佛、世尊受请入殿结跏趺坐，开显「因位善根所感，果位神力所现」的华严庄严境界，为下卷「兜率宫中偈赞品」诸天赞佛铺路。

## 二、结构层次

全文以「处—座—众—迎—赞—受」六段递进，境、众、佛三层互摄：

- **神力不离而往（处）**：以「不离菩提树下」起，显一多相即、不动而往 → 殿中敷摩尼藏师子座，过去善根所感、如来净法所起。
- **层层庄严（座）**：自「百万亿层级」起，以二十余段「百万亿……」排比 → 宝帐、华鬘、香网、宝铃、璎珞、宝衣、宝盖、栴檀、莲华藏沉水香，由粗至细、由色至声香，总显无尽庄严。再列「雨一切天华云……雨一切天沉水香云」之供养云、诸天妓乐与百千亿赞叹音声，由座庄严扩为虚空庄严。
- **十众围绕（众）**：先列初发心至灌顶诸位菩萨各得法益 → 次列诸天、龙王、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽乃至色界诸天（无烦、无热、善见、善现、阿迦尼吒）恭敬礼拜 → 复列华手、香手、鬘手等「手菩萨」各雨供养。十方兜率天王「悉亦如是」敷座，显主伴圆融。
- **奉迎供养（迎）**：兜率天王率十万亿天子雨华、香、鬘、盖、衣、宝云奉迎 → 诸天各以天衣盛华香宝散佛 → 住虚空中天子起十种心（智慧、欢喜、尊重、供养、信解、福田、深信、难遇、踊跃、欢喜）各庄严虚空 → 不可说菩萨以「波罗蜜所生、无生法忍所生」等法性所生之具供养，一一身复出不可说菩萨充满法界赞叹如来。
- **大众见佛神变（赞）**：大众见如来身一一毛孔出百千亿那由他阿僧祇光明，照不思议无边法界，出大妙音演不思议赞颂 → 复现诸佛出兴世间、妙宝光焰、无尽庄严，皆从如来无障碍一切智及不思议胜德生 → 世尊大悲普覆，令未信者信、已信者增长、已净者成熟、已熟者调伏，犹如普贤得佛自在。
- **天王颂古佛、受请入殿（受）**：兜率天王忆念过去佛所种善根，以十颂赞叹无碍月、广智、普眼、珊瑚、论师子、日照、无边光、法幢、智灯、功德光十佛曾入此殿，显此处吉祥 → 世尊以佛庄严自庄严，受天王请入一切宝庄严殿 → 殿中自然出过诸天供养之具，妓乐歌赞炽然不息 → 世尊于摩尼宝藏师子座结跏趺坐，法身清净、与三世佛同境，十方兜率陀天悉亦如是。

过渡以「尔时」「复有」「如此世界兜率天王……十方一切诸世界悉亦如是」为枢纽，由「处」展「座」，由「座」展「众」，由「众」展「迎」，由「迎」显「佛德」，由「佛德」收归「受请入殿、结坐演法」，层层递进、处处主伴同然。

## 三、关键结论

1. **不动而往、一多相即**：如来不离菩提树下而遍至须弥、夜摩、兜率，十方四天下阎浮提中皆见如来坐树下，显华严「一处即一切处」之法界缘起。
2. **庄严皆善根所生**：师子座、供养具皆「过去修行善根所得」「一切如来净法所起」，菩萨所供之具亦「波罗蜜所生、无生法忍所生」，境严即是因严，因严即是果严。
3. **主伴圆融、十方同等**：此界兜率天王敷座庄严，十方一切世界兜率天王「如是敷座、如是庄严、如是仪则」悉皆同等，显一即一切、主伴互融。
4. **佛身神变即一切智之用**：佛身一一毛孔出百千亿光明、现不可说诸佛、妙宝光焰，皆从「如来所住无障碍一切智」及「不思议胜德」生，以大悲普覆令众生信、增、净、熟、伏五阶善根增上。
5. **古佛道场、今佛重光**：兜率天王以十颂叹过去十佛皆曾入此庄严殿，明「此殿即过去诸佛成道处」，今佛受请入殿结坐，即续佛慧命、三世一际。

## 四、易混辨析

- **兜率陀天 vs 兜率天王 vs 兜率天子**：兜率陀天是欲界第四天（知足天）；兜率天王为此天之主，奉佛敷座、说颂叹古佛；兜率天子为天众，雨华香供养。经文「兜率陀天王」即天王，「兜率陀天子」即天子，不可混读。
- **那由他 vs 阿僧祇 vs 不可说**：三者皆为极大数。「那由他」通常为千亿或更大数；「阿僧祇」意为无数，为菩萨位数之极；「不可说」更在阿僧祇之上，表不可称量。经中常「百千亿那由他阿僧祇」连用以显无尽。
- **波罗蜜 vs 波罗蜜所生**：波罗蜜（到此岸、度）为菩萨六度行；「波罗蜜所生」则指由修波罗蜜所感得的供养之具（如宝盖），是「果严由因严」之体现，非波罗蜜本身。
- **灌顶菩萨 vs 灌顶天子**：灌顶菩萨为十地满心菩萨，蒙佛智水灌顶、受佛职位；灌顶天子为兜率天中同修灌顶善根之天子，举身持座，阶位远低于灌顶菩萨。
- **无生法忍 vs 无生善根**：「无生法忍」为菩萨证诸法无生之理而心安住；「无生善根」则指顺无生理所修之善根，二者体同而用别，经中以「无生法忍所生一切衣」配菩萨所供之具。

## 五、阅读提示

读本卷可带着两问：一者，如来「不离菩提树下」而能遍至兜率，究竟以何为「往」？留意「佛神力故」「如来威神力故」「往昔善根之所流故」三处提示。二者，无尽庄严之具何以皆归于「善根所生」？通读时勾画「所生」「所起」「所现」「所严」诸字，可见因位善根、果位神力、法界性德三者交彻，方为华严庄严之实义。
