# 大方广佛华严经卷第二十一 导读

## 一、内容总览
本卷为《大方广佛华严经》卷第二十一，属「十无尽藏品第二十二」，由功德林菩萨承佛神力，为诸菩萨演说菩萨摩诃萨所修十种无尽藏。全卷以「十藏」为纲，依次阐明信、戒、惭、愧、闻、施、慧、念、持、辩十大藏，每一藏皆由「何等为……」发问引入，再层层展开其相、其义、其用，末以「十种无尽法」收束，显明此十藏所以名为「无尽」之故。其旨在于揭示菩萨道之修学次第与无尽功德，归趣无上菩提。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全卷采「总起 → 分述（十藏）→ 收束（无尽法）」之结构，由境行到果德，层层递进：

- **总起标名**：功德林菩萨先告众佛子，标举「过去未来现在诸佛已说当说今说」之十藏名目 → 确立十藏乃三世诸佛共说之法门。
- **十藏分述（主体）**：每一藏均依「何等为是藏 → 此菩萨云何修 → 修已得何功德 → 结名」之固定范式展开：
  - **信藏**：从「信一切法空、无相、无愿」等十种信 → 引出闻诸佛法、众生、法界等十种不可思议而心不怯弱 → 成就「无边无尽信」，护持佛种性。
  - **戒藏**：列普饶益、不受、不住等十种戒名 → 逐一释义（云何为……）→ 末以「一切众生毁犯皆由颠倒」发菩提愿收束。
  - **惭藏、愧藏**：由忆念过去造恶生惭 → 于五欲贪求生愧 → 各以「三世诸佛皆悉知见」为警策，回向菩提。
  - **闻藏**：以「是事有故是事有」等十二对法相，分世间出世间、有为无为、有记无记 → 涵括缘起、五蕴、三界、四谛等法相体系 → 发愿持多闻藏度生。
  - **施藏**：十种施（分减、竭尽、内、外、内外、一切、过去、未来、现在、究竟）→ 多以转轮王位舍身舍国为喻，显菩萨难行之施。
  - **慧藏**：于色、受想行识、无明、爱、声闻、独觉、菩萨各如实知集灭道 → 了达「一切法不可坏」→ 末列十种不可尽之慧藏相。
  - **念藏**：忆念过去无量劫、佛名号、十二部经、众会、法、根性、烦恼、三昧 → 列十种念相（寂静、清净等）。
  - **持藏**：持佛所说修多罗文句义理无忘 → 叹此藏「唯佛能了」。
  - **辩藏**：深慧了实相，广说诸法 → 以广长舌出妙音声充满十方 → 成就尽虚空遍法界无边身，演说无尽。
- **收束总结**：以「十种无尽法」（饶益众生、本愿回向、劫无断绝等）收束 → 显十藏之所以为「无尽大藏」之根本因。

## 三、关键结论
1. 十无尽藏为三世诸佛共说之法，菩萨摩诃萨必修之行，统摄信解行证，归趣无上菩提。
2. 每一藏皆以「发菩提愿、广为众生说真实法」为究竟取向，自利利他不二。
3. 菩萨之戒施惭愧等行，皆以「了知法性空寂、三世诸佛悉知见」为内在警策与动力，异于二乘与凡夫。
4. 「无尽」之义，不在数量之多，而在「不可坏」「无变异」「无退转」「普入一切佛法之门」之体性与大用。
5. 辩藏所成就之「尽虚空遍法界无边身」，显示菩萨说法度生之境界与法界同量。

## 四、易混辨析
- **惭藏 vs 愧藏**：惭侧重「忆念过去自作诸恶」而内心羞耻，愧侧重「于五欲贪求无厌」而起愧耻；前者向内自省，后者对外境之欲起厌离。经中惭以「更相恼害」之众生互相关系为缘起，愧以「母人腹中入胎受生」之不净为警策。
- **闻藏 vs 慧藏**：闻藏重在「知法相差别」（有无可起灭、世出世间、有为无为、有记无记等分类），偏于多闻广识；慧藏重在「如实知」集灭道与法性不可坏，偏于智慧通达实相。闻为入门，慧为究竟。
- **念藏 vs 持藏**：念藏是「忆念」过去劫、佛名、十二部经等而不忘；持藏是「受持」佛所说修多罗文句义理而无所失。念偏于自心忆持之力，持偏于受持弘传之用；念藏列十种念之体相，持藏唯叹「唯佛能了」。
- **数缘灭 vs 非数缘灭**：数缘灭即「择灭无为」，依智慧简择断烦恼所显之涅槃；非数缘灭即「非择灭无为」，不依简择，由缘缺不生所显。二者同属无为法，但因断灭之缘不同而有别。

## 五、阅读提示
读本卷可带着两个问题：其一，十藏之间是否有修学先后或相摄关系？其二，「无尽」一名如何贯通于信、戒、施等各藏？留意每一藏末尾「是名菩萨摩诃萨第×藏」的结名与发愿回向，可见菩萨行门虽异而归趣一致。
