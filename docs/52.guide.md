# 大方广佛华严经卷第五十二 导读

## 一、内容总览

本卷为《大方广佛华严经》「如来出现品第三十七」的最后一部分（之三），承接前二卷对如来身、语、意功德的开显，由普贤菩萨为会众宣讲如来五种甚深行相：**境界、所行、成正觉、转法轮、般涅槃**，并以「见闻亲近所种善根不虚」收束全品，引出十方同名普贤如来现身作证、授记大众。全卷以「境界无量 → 行无所行 → 正觉一相无相 → 法轮无转而转 → 涅槃无生无灭 → 善根金刚不坏」为线索，层层递进，将「如来出现」从外在神变引归于众生自心，最终归结到「此法门唯为菩萨说、唯如来真子能持」的秘教收束。

## 二、结构层次（文章的骨架与逻辑推进，★重点）

全卷以普贤菩萨五次发起「佛子！菩萨摩诃萨应云何知……」的问答为骨架，每一问后必以长行敷陈、继之以颂偈重明，构成五重「长行→偈颂」的严整结构：

- **一、如来境界（P3–P20）**
 以「十种境界」（一切世间、三世、刹、法、众生、真如无差别、法界无碍、实际无边、虚空无量、无境界）展开 → 以龙王降雨、海水从心力所起为喻 → 收于「如来智海从往昔大愿生起」，颂偈四首明「心佛境界不二」。

- **二、如来行（P21–P32）**
 立宗：「无碍行、真如行」是如来行 → 以真如不生不动不起、法界非量非无量、鸟飞虚空不可量三喻 → 复以金翅鸟王辟水搏龙喻佛拔取善根将熟众生、日月游空喻佛教化无动念 → 颂偈六首重明。

- **三、如来成正觉（P33–P46）**
 这一段是全卷义理最密之处。先明正觉体性：于一切义无所观察、住中道、出过文字 → 以大海印现众生身喻菩提普印心行 → 次明正觉所「得」之身：得一切众生、法、刹、三世、佛、真如、法界、虚空界等「量等身」，三轮清净 → 次明「一性无性」：于身中普见众生成正觉、入涅槃，同归于无性 → 次明「化与不化等无有别」之对答 → 最后明一毛孔遍法界、自心念念有佛成正觉 → 颂偈十二首收摄。

- **四、转法轮（P47–P59）**
 以「九种转相」展开：无起无转、三种转断所应断、离欲际非际、无言说、究竟寂灭、一切文字言语、知声如响、一音出一切音、无遗无尽 → 以文字普入一切事语算数世间出世间处、普入无所住为喻 → 复说「究竟无碍无畏三昧」为法轮出生处 → 颂偈十首明文字不内不外不失不积而能转法轮。

- **五、般涅槃（P60–P75）**
 先立「根本自性」：以真如、实际、法界、虚空、法性、离欲际、无相际、我性际、一切法性际、真如际十种「如……涅槃，如来涅槃亦如是」展开 → 明「涅槃无生无出故无灭」、如来不为菩萨说究竟涅槃 → 以日影现净水器、火大一处息灭、幻师现身三喻明「一处示现涅槃非一切灭度」 → 复明不动三昧中放光出华、华有师子座、座有如来结跏趺坐、身数等众生数 → 颂偈十二首收束。

- **六、见闻所种善根不虚（P76–P86）**
 以食少金刚终竟穿身、干草投芥火必烧尽、雪山善见药王树三喻，明于如来所种少善根必至无为究竟智处、必断烦恼、必得六根清净 → 收归「此法门名如来秘密之处」等十名，明唯为趣向大乘菩萨说，喻以转轮圣王七宝唯太子得、无太子则宝散灭 → 明闻已信解者生如来家、得无师自然智 → 颂偈六首。

- **七、瑞相与十方证（P87–P101）**
 六种震动、十八相动、雨一切云 → 十方同名普贤如来现身作证、授记一生当得菩提、当来同号「佛殊胜境界」 → 十方菩萨来集作证「如是文句、如是义理，不增不减」 → 普贤最后颂偈四首收束全品，劝「汝等当持莫放逸」。

全卷以五问为纵、以喻为横、以颂偈为节，自「境界」推至「善根不虚」，最终十方普贤现身共说一法，结构呈「总起→分述五重→结劝」之递进。

## 三、关键结论

1. **如来境界即众生心境界**：心无量故佛境界无量，二者无缚无脱，以思惟分别而显现，实无来处——佛境不在心外。
2. **如来行即真如行**：不生、不动、不起，无住处而普为众生示现，如金翅鸟王辟水搏龙、日月游空无动念。
3. **成正觉即同于一相无相**：成正觉时于身中普见众生成正觉、入涅槃，皆同一「无性」；化与不化等无有异，一毛孔遍法界、自心念念有佛成正觉——正觉不在众生心外。
4. **转法轮而无转**：法轮以文字言音为体而无所住，一音出一切音、无遗无尽，言音实相即法轮。
5. **涅槃无生无灭**：涅槃即真如、法界、实际之异名，无生无出故无灭；如来一处示现涅槃非一切灭度，如日影器坏、火一处息、幻师一处隐。
6. **于佛所种少善根如金刚不消**：必穿有为烦恼身过、必烧尽烦恼、必得六根清净，究竟至无余涅槃——此为「如来秘密之处」法门，唯菩萨能持，二乘不闻。

## 四、易混辨析

- **如来境界 vs 如来行 vs 如来成正觉**：境界约「所知境」之广大量；行约「能修之行」的无生无动；成正觉约「所证之果」的一相无相、一性无性。三者由境、行、果次第展开，但皆归「无性」「无相」之实相。

- **成正觉 vs 转法轮 vs 般涅槃**：成正觉是「能证之果」，约自利究竟；转法轮是「化他之用」，约利他说法；般涅槃是「示现之极」，约化缘已讫而示灭。三者看似有别，实则皆「无生无出」「无转无灭」——正觉无相故、法轮无起故、涅槃无生故。

- **无境界境界 vs 如来境界**：前者是十种境界之第十，指「一切处无有」之究竟境；后者总摄前十，是「无境界境界无量」之佛境界。两者是「别」与「总」的关系，不可混为一谈。

- **实际 vs 真如 vs 法界 vs 法性**：本卷在「涅槃」「成正觉」两段反复并列此四者，皆为诸法本然之理的异名——实际约「至极无妄」、真如约「本然不异」、法界约「摄一切法」、法性约「诸法本体」，于「如来涅槃亦如是」「如来成正觉同于一相无相」处所指是一，立名有别。

- **化与不化等无有别 vs 成与不成无增减**：前者就「能化之心、所化之佛」论，化佛与不化之真身体性无别；后者就「众生成正觉与否」论，成与不成于菩提无增减。两段对答同显「菩提无相」之宗，而一是约「能化」、一是约「所化」。

## 五、阅读提示

本卷五重问答可依「境→行→果→用→灭」次第读：先识境之量，次观行之寂，次悟果之无相，次见用之无转，次了灭之无灭，最后归宗于「善根金刚不消」与「法门唯菩萨能持」。读时注意每一喻皆与所立宗义严密对应——龙王降雨喻心佛境不二、金翅鸟喻佛拔善根人、日影器坏喻涅槃非佛咎、雪山药王喻见闻六根清净——喻即是宗，不可滑过。
