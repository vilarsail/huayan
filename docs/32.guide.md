# 大方广佛华严经卷第三十二 导读

## 一、内容总览

本卷是《十回向品第二十五之十》，即十回向品的最后一卷，专明第十回向——「菩萨摩诃萨等法界无量回向」。前九回向各有一种所缘与善根为所回向（如救护众生、随顺坚固、真如相、无缚著解脱等），此第十回向总收前九，将菩萨以离垢缯系顶、住法师位、广行法施所起一切善根，悉皆回向同于法界之无量、无边、无限、无际。全卷由「菩萨自利之行」展开，层层推及「普为众生」「等法界」的广大回向，终以愿得种种清净妙身、摄取众生为收束。

## 二、结构层次

全文以「法施善根 → 多重回向 → 离染清净 → 普利众生」一线贯穿，由近及远、由自及他：

- **立菩萨行相**（P4）：以离垢缽系顶、住法师位、广行法施 → 起大慈悲安立众生、为作导首、为作坚固善友 → 标举此回向所依之善根。
- **念佛修梵行回向**（P5-P6）：发愿忆念三世诸佛 → 于一世界尽未来劫修菩萨行 → 普为一切众生 → 修二十种清净梵行（不破、不缺、不杂…无恚） → 推出「自净方能净他」之因果理：菩萨于梵行自不清净则不能令他清净。
- **等法界无量回向**（P7-P9）：以法施善根愿得「遍法界无量」之身、心、音声、众会、菩萨业、菩萨住、菩萨法、菩萨行、菩萨回向 → 复以法界无量、无边、无限、无际、无断、一性、自性清净、随顺、庄严、不可失坏十义，一一配属善根回向 → 显「法界即回向、回向即法界」之理事无碍。
- **离染不着回向**（P10-P14）：连续「不为」诸般染着回向（不取着业、报、心、法、事、因、语言、名句文身、回向、利益众生；不为色声香味触法、求生天、求眷属、求生死乐等） → 转为「但为」教化众生、成满一切智智、得无碍智、被坚固大愿铠、住普贤地 → 由遮遣显建立。
- **心行与愿力回向**（P15-P16）：以十种平等心回向（本性平等、法性平等、无诤平等…） → 复为令众生离地狱、不入畜生、不往阎罗处、满足善根、转十力轮等广大愿 → 摄四无量心（慈悲喜舍）、缘起法、不退转、净智慧离垢光明。
- **果德与音声身相回向**（P17-P21）：告诫不应贪着三有五欲 → 以无贪、无瞋、无痴等九善根回向 → 愿一切众生得三十二种清净妙音（净妙音、柔软音、天鼓音…普至法界音） → 愿得离众过恶之清净法身、妙相、业果、一切智心 → 愿得十种清净妙身（光明身、离浊身、无染身…无障碍身）如净明镜普现众生 → 终以「入一切众生、一切佛刹、一切诸法、一切三世」收束。

## 三、关键结论

1. **等法界无量即第十回向之体**：菩萨以法界之无量、无边、无限、无际等十义为回向之量，回向与法界同等，无二无别，体现理事无碍、一性平等之华严宗义。
2. **自利为利他之基**：菩萨于梵行自不清净则不能令他清净，自住正法方能使众生安住——回向虽为众生，必先修自心之梵行与善根。
3. **离染方能善回向**：善根回向不应取着业、报、心、法、事、因、名句文身乃至回向本身，遮遣一切执着后，方为「但为成满一切智智」之清净回向。
4. **法施为最胜所缘**：以离垢缯系顶、住法师位、广行法施为发端，回向之善根以法施为首，所获音声、辩才、法藏皆从法施生，显菩萨以法利他之根本行。

## 四、易混辨析

- **回向 vs 愿**：回向是「以己善根趣向菩提、众生、实际」之动作与方向；愿是「立期愿、立志愿」之前心。本卷善根回向中含众多「愿得」「愿以」句，回向是体、愿是用，二者相即不离。
- **法界无量 vs 法界无边 vs 法界无限 vs 法界无际**：四者皆约法界之广大，但义有别——无量约数之不可数，无边约方隅之穷尽，无限约分齐之无界限，无际约涯际之无终始；菩萨于一一回向配此四义乃至无断、一性、自性清净等共十义。
- **梵行 vs 善根**：梵行特指清净无染之修行（不破、不缺、不杂等二十种），偏就戒行与离欲；善根泛指一切无贪、无瞋、无痴等所生善法，可含施、戒、定、慧诸行。本卷先以善根回向，复别明梵行之自他因果。
- **法身 vs 妙身 vs 清净身**：法身约离过德显之理性身；妙身约种种差别业用之应化身（光明身、离浊身等）；清净身通因果，约无染垢之共相。三者层层递进，终归「成就清净功德一切智身」。

## 五、阅读提示

带着以下问题读：菩萨为何要「等法界」地回向？遮遣「不为」与建立「但为」如何并行不悖？最后愿得如净明镜之妙身，与「等法界无量」之开题如何呼应？留意「法界」一词在全卷十余种不同修饰下所显之体相用。
