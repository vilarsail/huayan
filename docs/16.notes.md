# 大方广佛华严经卷第十六 词语注释

〔1〕 实叉难陀　于阗国（今新疆和田）僧人，唐代来华译经的三藏法师（通晓经、律、论），八十卷本《华严经》即由其主持译出。「奉　制译」谓奉皇帝诏命翻译。
〔2〕 尔时　正当其时，佛经叙事承上启下的惯用发语词，此处作「那时」解。
〔3〕 四天下　一个世界单位中的四洲：东胜身洲、南赡部洲、西牛货洲、北俱卢洲，位于须弥山四方咸海中。
〔4〕 阎浮提　四洲中的南赡部洲，即人类所居之世界；经言「一切阎浮提皆言佛在中」，谓处处众生各见佛在其处说法。
〔5〕 悉　全、都，总括副词，佛经高频用字。
〔6〕 靡不　靡（mǐ），无不、没有不，双重否定表遍指；「靡不自谓恒对于佛」即人人都自认为一直在佛前。
〔7〕 上升须弥　须弥山，义译妙高山，印度宇宙观中的世界中心，帝释天宫居其山顶；须弥山顶品（第十三）记佛不离菩提树而身现升于须弥顶，「升」即登临。此品为说十住的预备序分。
〔8〕 天帝释　忉利天（三十三天）之主帝释天（释提桓因），居于须弥山顶善见城；此品中他是请主，以殿供养请佛说法。
〔9〕 妙胜殿　帝释天宫中的殿堂名，本卷佛升须弥顶说法之处。
〔10〕 普光明藏　座名，「藏」谓含藏功德如宝藏，此座普放光明；华严各会说法之座皆有名目。
〔11〕 十千层级　十千即一万；「十千层级、十千金网、十千种帐……」以同一数词反复排比，极言座具庄严之多，读时可一并扫过。
〔12〕 迥极　迥（jiǒng），高远；迥极庄严谓庄严到极处。
〔13〕 弥覆　弥，遍满；遍满覆盖。
〔14〕 缯绮　缯（zēng），丝帛；绮（qǐ），织有花纹的丝织品，泛指上等丝织物。
〔15〕 珠璎　璎（yīng），璎珞，串珠所成的颈饰；珠璎谓成串宝珠交络装饰。
〔16〕 梵王　大梵天王，色界初禅天之主，常率梵众供佛护法。
〔17〕 敷置　敷，铺设；铺设安置，指帝释为佛敷设宝座。
〔18〕 曲躬　弯腰屈身致敬之貌；「曲躬合掌」即躬身合掌行礼。
〔19〕 善来　迎请之赞语，「来得正好」，对尊贵客者的礼赞问候；「善来世尊」即恭迎世尊光临。
〔20〕 善逝　如来十号之一（梵语 Sugata），义为善善而逝、往于最胜处；与「如来、应（应供）、正等觉」同为佛之尊号，偈语中连举以申敬。
〔21〕 迦叶如来　此偈历举过去诸佛——拘那牟尼即拘那含牟尼佛、迦罗鸠驮即拘留孙佛，与迦叶为贤劫先三佛；毗婆尸、尸弃、毗舍浮为过去庄严劫三佛；弗沙、提舍、波头摩、然灯亦皆古佛。谓诸佛往昔皆曾入此殿说法，故此殿恒时最吉祥。
〔22〕 拘那牟尼　拘那含牟尼佛，过去七佛中之第五佛，贤劫第二佛；偈中为押韵而略作此名。
〔23〕 迦罗鸠驮　即拘留孙佛，过去七佛中之第四佛，贤劫第一佛；偈中用异译名。
〔24〕 毗舍浮　过去七佛之第三佛（庄严劫末佛），意译遍一切自在。
〔25〕 三垢　贪、瞋、痴三种烦恼垢染；「无三垢」谓佛离三毒。
〔26〕 尸弃　过去七佛之第二佛，意译顶髻、火首。
〔27〕 毗婆尸　过去七佛之第一佛，意译胜观、遍见。
〔28〕 弗沙　过去古佛名（梵语音译），释迦往昔曾因赞弗沙佛而超劫成道。
〔29〕 提舍　过去古佛名（梵语音译）。
〔30〕 波头摩　梵语音译，红莲花；此处为过去古佛名，下文「波头摩华世界」则作世界名。
〔31〕 然灯　即燃灯佛，曾为释迦牟尼授记之过去佛。
〔32〕 忉利天王　忉利（dāo lì）天即三十三天，居须弥山顶，其天王即帝释；与「天帝释」「诸释天王」同指一人。
〔33〕 结跏趺坐　两足交叠加于两股上而坐，佛门坐禅之正坐威仪，表安定不动。
〔34〕 须弥顶上　须弥顶上偈赞品（第十四）：法慧、一切慧、胜慧等十位来集菩萨皆以「慧」立名，依次各说一段偈颂赞佛，且前后辗转引证（如「如德慧所说」），读时按人分段即可。偈（jì），梵语「偈陀」之略，韵文颂体。
〔35〕 佛刹微尘数　把一个佛国土碎为微尘，以其尘数计量，华严惯用的极大数量词；「百佛刹微尘数国土外」谓远至那样多国土之外。
〔36〕 法慧菩萨　本卷十住品说法主，从东方因陀罗华世界率众而来，承佛神力入定而说十住；十位同来菩萨皆以「慧」为名，与十住法门以慧建立相应。
〔37〕 因陀罗　梵语帝释天名之音译；因陀罗华世界即以帝释天华立名（佛经另以「因陀罗网」喻重重无尽）。
〔38〕 优钵罗　梵语音译，青莲花。
〔39〕 阿卢那　梵语音译，义为晓红、赤色，花名。
〔40〕 那罗陀　梵语音译花名（那罗陀亦仙人名），此处作世界名。
〔41〕 梵行　清净离欲之行；「净修梵行」谓在佛所修清净行。
〔42〕 顶礼佛足　以自己头面礼接佛足，佛门最恭敬之礼。
〔43〕 毗卢遮那藏师子之座　毗卢遮那，梵语音译「光明遍照」，华严教主佛名；藏，谓其座含藏庄严如宝藏。师子之座即狮子座（师子＝狮子），喻说法无畏。
〔44〕 化座　菩萨以神变化现出的座位；「化座而安坐」谓各自化座安坐。
〔45〕 佛子　菩萨之通称，谓从佛口生、绍继佛种；本品中法慧说法时对众菩萨的称呼。
〔46〕 闇　「暗」的异体字；「世闇」谓世间的愚痴黑暗。
〔47〕 云何　怎么、如何，经中设问发端的惯用虚词；「云何为菩萨发心住」即「什么是菩萨发心住」。
〔48〕 牟尼　义为寂默、圣者，佛之通称（如释迦牟尼）；「牟尼离三世」谓佛超离三世诸相。
〔49〕 五蕴　色、受、想、行、识五类身心要素的聚合，凡夫于中妄执为实我；「妄取五蕴相」即执此为实。
〔50〕 卢舍那　梵语音译，义为「光明遍照」，与毗卢遮那同体异译，华严宗立为报身佛；此偈谓了知诸法自性无所有，即见卢舍那。
〔51〕 翳　yì，遮蔽眼目的白膜病，喻无明遮蔽慧眼；「目有翳」即眼中生翳。
〔52〕 瞽者　gǔ，盲人；喻无智慧者不见佛。
〔53〕 法眼　清净法眼，能观诸法实相之智慧眼；「未得法眼」谓尚未见法性。
〔54〕 无漏　漏喻烦恼渗漏，无漏即离烦恼的清净法；「无漏得自在」谓断惑后自在无碍。
〔55〕 如德慧所说　德慧指前文功德慧菩萨，本会诸菩萨依次各说偈后互相引证，读时以此串连各段。
〔56〕 大士　菩萨之美称，义为大道心众生；「精进慧大士」即精进慧菩萨。
〔57〕 实际　法性究竟之际、真实至极之处；「安住于实际」谓心安住于真如实际。
〔58〕 有诤　诤（zhèng），烦恼斗诤；「有诤说生死，无诤即涅槃」谓有诤心处即是生死，诤念息处即是涅槃。
〔59〕 涅槃　梵语音译，义为寂灭，烦恼与生死之火息灭后的解脱境界；「咸证涅槃」谓令众生都证得涅槃。
〔60〕 真如　诸法真实不异、常住不改的体性；「寂灭真如相」谓寂灭的真如之相。
〔61〕 宁受地狱苦　宁（nìng），宁可；设誓之辞，谓宁堕地狱也要得闻佛名，极言闻法之可贵。
〔62〕 现证　当下亲证，不假推度而知；「如实而现证」谓如于实相直接体证。
〔63〕 和合相　众缘和合所现之相，谓诸法无独立自体；「离诸和合相」即不执和合假相，是名无上觉。
〔64〕 知以一故众　一与多相待而立：由一故立多、由众故有一，一多相依相即；此颂下句「知以众故一」申明同一义，是华严一多相摄之门。
〔65〕 摩诃萨　摩诃萨埵之略，义为大有情、大菩萨；「无上摩诃萨」赞菩萨中之最上者。
〔66〕 三有　欲界、色界、无色界三种生存状态，即生死流转的三处。
〔67〕 世间塔　塔为世人恭敬供养之处；谓闻佛名生净信者，人天归敬，其身犹如世间的宝塔。
〔68〕 无量方便三昧　定名；法慧欲说十住，先入此具无量方便之定，承十方同名诸佛加持而后说法——华严中说大法必先入定，为通例。
〔69〕 善男子　佛对发心听法者之美称，与「善女人」对举；此为诸佛赞叹法慧之辞。
〔70〕 十种住　十住品（第十五）法慧菩萨所说之菩萨十个住位——初发心住至灌顶住；「住」谓安住于佛法功德而不动，是菩萨五十二位中的一段。
〔71〕 无碍智　诸佛共与法慧的十种智之首（无碍、无著、无断、无痴、无异、无失、无量、无胜、无懈、无夺），谓其说法之智圆备无碍；无夺谓不可动夺。
〔72〕 各申右手　申，伸出；诸佛各伸右手摩法慧菩萨之顶——摩顶为加持授职之仪式，表印可其说法。
〔73〕 住三世诸佛家　谓菩萨以三世诸佛之家为其住处，生在佛家、绍继佛种，故称佛子；此句总明十住菩萨之身份。
〔74〕 初发心住　十住总清单起首，十位依次为：初发心住、治地住、修行住、生贵住、具足方便住、正心住、不退住、童真住、王子住、灌顶住；读法是先记住十位名目，再逐一看「云何为菩萨X住」下的释义（每住皆含一个十法清单＋一个劝学十法清单）。
〔75〕 灌顶　本为印度太子即位时以四海水灌其头顶的仪式，借喻菩萨位极、将绍继佛位；十住以「灌顶住」为最高位，取义于此。
〔76〕 值遇　值，逢着；遇到。「难可值遇」即极难碰上。
〔77〕 神足　神足通，神变飞行自在之通力；「或见神足」谓或因亲见佛之神变而发心，与下记别、教诫并列发心之缘。
〔78〕 记别　又作授记，佛为众生预先记别未来修行果位之言。
〔79〕 教诫　教诲训诫，佛对弟子的开示教导。
〔80〕 剧苦　剧，极重；极深重之苦。
〔81〕 乐住生死　乐（lè），甘愿；劝学法之一，谓不厌生死而甘住世间教化众生。
〔82〕 即自开解　本卷每住末尾反复出现的结句：「有所闻法，即自开解，不由他教」——谓菩萨闻法即能自己开悟解了，不待他人教导，是十住劝学的通例结语。
〔83〕 怜愍　愍（mǐn），同「悯」；哀怜同情，为治地住十心之一。
〔84〕 虚闲寂静　虚闲，安闲清静；谓修学当乐于闲静独处。
〔85〕 一切法不如名　谓诸法并不与其名称相称——名是假立，实无一名一实相应；修行住十观之一。
〔86〕 圣教中生　生贵住之要义：菩萨从佛圣教法中生，喻生在佛家，故名胜「生贵」。
〔87〕 修集　修习积集；谓于三世佛法次第了知、积集、圆满。
〔88〕 饶益　使人得利益安乐；谓所修善根皆为利他。
〔89〕 调伏　调理降伏（众生身心的烦恼恶行），令其善顺。
〔90〕 无生法忍　忍（rěn），安忍认许；了知诸法本自不生之实相、心安住不动而不再退失的智慧，正心住闻赞毁诸法而不动所趣向者。
〔91〕 文随于义　文辞随顺义理，义理亦依凭文辞，文义互依不二；与「非有即有、无相即相」等十句同为相即不二的遮诠句式，读作「A即B、B即A」。
〔92〕 非有即有　相即句式：非有（空）即是有（有），空有不二；不退住所学十种广大法之例，皆表两边相即、不落对待。
〔93〕 随意受生　随自己意愿自在受生（投生），神通自在之一，童真住十业之一。
〔94〕 诣　yì，到、往见；「来诣于此」谓来到此处。
〔95〕 习气　烦恼断后残存的熏习气分（如盛香器皿香去而气在）；「善知习气相续」谓知其相续不断之相。
〔96〕 威仪　行、住、坐、卧的仪则规矩；「善解诸威仪」谓通晓种种威仪差别。
〔97〕 前际后际　际，边际；前际指过去，后际指未来，泛指时间的始终，「善知前际后际事」谓尽知三世之事。
〔98〕 世谛　世俗谛，随顺世间言说施设的道理；与「第一义谛」（胜义谛，出世间真实之理）对举，合称二谛，王子住菩萨善知演说二谛。
〔99〕 第一义谛　胜义谛、真谛，诸法真实的道理，离言绝相。
〔100〕 法王　佛之尊称，谓于一切法得大自在者；「法王处善巧、轨度、宫殿……」十句皆说佛地境界，为王子住菩萨所应学。
〔101〕 轨度　规则法度；「法王处轨度」谓佛行事之法则。
〔102〕 宴寝　宴（yàn），安息；安卧起居，「法王宴寝」喻佛住于寂灭安息之处。
〔103〕 住持　安住摄持（世界）令不坏失；「住持无数世界」为灌顶住十智之一，亦见于偈「照耀世界住持智」。
〔104〕 身业　身体所造之业，与语业、意业合称三业；「身及身业」谓其身与其身之造作。
〔105〕 神通变现　此长句极言灌顶住菩萨之神变与三世智、心境界、智境界深不可测，乃至法王子亦不能知——读时注意「皆不可知」「亦不能知」是层层推进的叹语。
〔106〕 法王子　候补佛位之菩萨（如文殊师利称法王子），犹世间王子之继王位；谓灌顶住菩萨境界之深，连法王子也不能知。
〔107〕 一切种智　佛智之名，兼知一切法总相与别相的圆满智慧；劝学诸佛十智之目的即增长此智。
〔108〕 六种震动　动、起、涌、震、吼、击六相，每相各有「遍、等遍」三层，共十八种，是佛说大法时大地震动的瑞相；此段「雨天妙华」以下皆说法瑞应，连读即可。
〔109〕 雨天妙华　雨（yù）作动词，如雨降下；天末香、天华鬘、天宝衣等谓空中散落之供养物。
〔110〕 末香　末（mò），粉末；研成细末之香。
〔111〕 华鬘　华同「花」；鬘（mán），花串、花环。
〔112〕 不鼓自鸣　鼓，奏击；乐器无人演奏而自鸣，天乐供养之瑞相。
〔113〕 法云　十方来证之菩萨同名「法慧」、所从来国同名「法云」、彼土佛同名「妙法」——表十住法门遍于十方，一切世界文句义理无二无别，故来作证。
〔114〕 暨　jì，及、至；「观察十方暨于法界」谓观察十方乃至法界。
〔115〕 相好　三十二相、八十种好，佛身微妙庄严之形相。
〔116〕 记心　他心通之记说，谓了知众生心念而为之记；与记别（记未来果报）不同。
〔117〕 三世因果名为处　处，道理成立之依据（承「是处非处智」）；谓三世因果之理为「是处」（成立），执众生自性实有为「非处」（不成立），菩萨欲于此决断了知。
〔118〕 入住出　禅定的三相：入定、住定、出定；「欲悉了知入住出」谓于诸禅解脱三昧的入、住、出皆欲了知。
〔119〕 宿住　宿世所住之事，即过去生的经历（宿命通所知境）；「欲悉了知其宿住」谓欲知众生过去世事。
〔120〕 结惑　结使惑恼，烦恼的异名（结谓系缚众生于生死）。
〔121〕 安立　施设建立；「法王善巧安立处」谓佛以善巧建立之境界，王子住菩萨随所观而了知。
〔122〕 不迫隘　隘（ài），狭窄；谓置无量世界众生于一毛端而互不拥挤，极言神力自在。
〔123〕 抹为尘　抹（mò），磨碎；将国土磨碎为微尘以数其数，极言算数之广。
〔124〕 独觉及声闻　二乘行者：独觉（缘觉，无师自悟者）与声闻（亲闻佛声教而悟者）；偈谓初发心之义深远，世间众生及二乘尚不能知。
〔125〕 称举　称量举起；「欲以一毛悉称举」谓以一毛端称举无量世界。
〔126〕 轮围山　环绕四洲外围咸海的山系（铁围山），世界之边围。
〔127〕 随类演　随众生根类不同而各随其类演说妙音；「普应十方随类演」谓一音随类皆解。
〔128〕 阿僧祇　梵语音译数名，义为无央数；「阿僧祇劫」谓极久远的时劫。
〔129〕 一向　专一向着、唯独；「一向志求无上道」谓专心一意追求佛道。
〔130〕 第二治地住菩萨　末后长颂自「第二治地住」起，依治地、修行、生贵……灌顶住次第重述十住义；读法是每段首句标出位次，随文回对前文长行各住之义。
〔131〕 谛念　谛，审实不虚；如实审细地思惟，谓于三世佛法思惟决定无疑。
〔132〕 展转成　展转即辗转，互为缘起而相待成立；谓一多、文义、有无等一切相待而成，无独立自性。
〔133〕 逮得　逮（dài），及、得到；逮得即获得。
〔134〕 加持　佛以神力加被扶助于菩萨；「神力加持无怯畏」谓得佛加持而无所畏惧。
〔135〕 教诏　教导诏示；「以此教诏法王子」谓以此法教示灌顶位菩萨。
〔136〕 成满　圆满成就；「成满最上第一法」谓成就圆满最胜法。
